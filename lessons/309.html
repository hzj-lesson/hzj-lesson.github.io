小学五年级数学简易方程

📝 备课方案

**教学目标** 1. 结合具体情境，理解用字母表示数的意义，会用字母表示运算定律、计算公式和简单的数量关系。 2. 理解方程的意义，能正确判断一个式子是不是方程；理解等式的性质，能运用等式的性质解简易方程，并养成自觉检验的习惯。 3. 学会解形如 x + a = b、x - a = b、ax = b、x ÷ a = b、ax + b = c 的方程。 4. 能找出实际问题中的等量关系，用列方程的方法解决简单的实际问题，体会方程是刻画数量关系的重要工具，发展代数思维。 **教学重点**：理解方程的意义，运用等式的性质正确解简易方程。 **教学难点**：理解等式的性质，根据实际问题找准等量关系并列方程。 **教学方法**：天平演示、观察对比、合作探究、实际应用。 **教学准备**：多媒体课件、天平演示教具或模拟课件、砝码、方程卡片、练习纸。 **课时安排**：5 课时（第 1 课时：用字母表示数；第 2 课时：方程的意义；第 3 课时：等式的性质；第 4 课时：解方程；第 5 课时：列方程解决问题）

📖 课堂讲义 · 核心知识点

**一、用字母表示数** 可以用字母表示数或数量关系。如买 3 支铅笔共 a 元，每支 a ÷ 3 元；正方形边长是 a，周长是 4a，面积是 a × a，记作 a 的平方。用字母表示运算定律，如加法交换律 a + b = b + a；用字母表示公式，如路程 s、速度 v、时间 t，s = vt。 书写规则：数与字母相乘时乘号省略，数写在字母前面，如 4a；1 与字母相乘时 1 省略；两个相同字母相乘写成平方形式。 **二、方程与等式的关系** 含有未知数的等式叫方程，它必须同时是"等式"且"含未知数"。 | 名称 | 判断条件 | 举例 | |---|---|---| | 等式 | 用等号连接 | 4 + 5 = 9 | | 方程 | 含有未知数的等式 | x + 5 = 9 | | 不等式 | 用大于号、小于号连接 | x + 5 > 9 | 可见方程一定是等式，等式不一定是方程，如 3 + 5 = 8 是等式但不是方程。 **三、等式的性质** 性质 1：等式两边同时加上或减去同一个数，左右两边仍然相等。 性质 2：等式两边同时乘同一个数，或同时除以同一个不为 0 的数，左右两边仍然相等。 可用天平演示理解：两边同时加、减同样重的砝码，或同时扩大、缩小相同的倍数，天平仍平衡。 **四、解方程** 使方程左右两边相等的未知数的值叫方程的解，求方程的解的过程叫解方程，依据是等式的性质。形如 x + a = b 两边同时减 a；x - a = b 两边同时加 a；ax = b 两边同时除以 a；x ÷ a = b 两边同时乘 a。书写时等号上下对齐，解完要检验。如解 x + 3 = 8 得 x = 5，代入左边 5 + 3 = 8，正确。 **五、列方程解决问题的一般步骤** 1. 读题，找出等量关系。 2. 设未知数，写"解：设……为 x"。 3. 根据等量关系列方程。 4. 解方程。 5. 检验并作答。 例如：小明 9 岁，比妈妈小 27 岁，妈妈几岁？等量关系：小明年龄 + 27 = 妈妈年龄。设妈妈 x 岁，9 + 27 = x，解得 x = 36。 **六、易错提醒** 1. 方程必须同时是"等式"且"含未知数"。 2. 解方程两边要同时变化，等号上下对齐。 3. 等式的性质 2 强调除以"不为 0"的数。 4. 列方程要找对等量关系，别忘了写"解：设……"和检验。

🔍 课堂讲义 · 重点难点解析

**重点一：用字母表示数** 例题：商店运来苹果 a 千克，梨比苹果多 15 千克。用式子表示梨的质量。 分析：梨的质量 = 苹果的质量 + 15，把"苹果的质量"用字母 a 表示。 解答：梨的质量是（a + 15）千克。 小结：用字母表示数，关键是把具体数量"翻译"成字母式子；表示数量时式子要加括号再写单位。 **重点二：等式的性质与解方程** 例题：解方程 x - 8 = 12，并检验。 分析：根据等式的性质 1，方程两边同时加上 8，左边只剩下 x。 解答：x - 8 + 8 = 12 + 8，x = 20。检验：代入 20，左边 20 - 8 = 12，与右边相等。 小结：解方程就是用等式的性质把未知数逐步"孤立"出来，解完要检验。 **难点一：形如 ax = b 的方程** 例题：解方程 3x = 7.8。 分析：根据等式的性质 2，两边同时除以 3，x 前的系数就消去了。 解答：3x ÷ 3 = 7.8 ÷ 3，x = 2.6。 小结：x 乘几就两边除以几，x 除以几就两边乘几，用逆运算消去未知数旁边的数。 **难点二：列方程解决问题** 例题：果园里有苹果树 120 棵，比梨树的 3 倍少 30 棵，梨树有多少棵？ 分析：等量关系：梨树的 3 倍 - 30 = 苹果树的棵数。设梨树有 x 棵。 解答：3x - 30 = 120，两边同时加 30 得 3x = 150，再同时除以 3，x = 50。检验：50 × 3 - 30 = 120，正确。答：梨树有 50 棵。 小结：列方程的关键是找等量关系，"比某数的几倍少（多）几"是常见表述，可借助线段图理解。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（用字母表示数）** 一辆汽车每小时行 v 千米，t 小时行了多少千米？当 v = 60，t = 3.5 时，行了多少千米？ - 分析：路程 = 速度 × 时间，先用字母式子表示，再代入数值计算。 - 解答：t 小时行 vt 千米；当 v = 60、t = 3.5 时，60 × 3.5 = 210（千米）。答：行了 210 千米。 - 方法小结：先列字母式子，再代入数值计算；代入时数字与字母间的乘号要写出来。 **例题 2（解方程）** 解方程 5x + 4 = 24，并检验。 - 分析：把 5x 看作一个整体，先两边同时减 4，再两边同时除以 5。 - 解答：5x + 4 - 4 = 24 - 4，5x = 20，5x ÷ 5 = 20 ÷ 5，x = 4。检验：左边 5 × 4 + 4 = 24，与右边相等。 - 方法小结：形如 ax + b = c 的方程，把 ax 看作一个整体，"先消加减、再消乘除"。 **例题 3（列方程解决问题）** 学校图书室有科技书 450 本，比故事书的 2 倍还多 50 本，故事书有多少本？ - 分析：等量关系：故事书的 2 倍 + 50 = 科技书的数量。求故事书，设故事书有 x 本。 - 解答：2x + 50 = 450，两边同时减 50，得 2x = 400，再同时除以 2，x = 200。检验：200 × 2 + 50 = 450，正确。答：故事书有 200 本。 - 方法小结：列方程"五步走"——找等量关系、设未知数、列方程、解方程、检验作答；把"几倍多几"翻译成表达式是关键。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 方程的意义

  1. 1. 含有（ ）的（ ）叫方程。
    答：未知数；等式。两者缺一不可。
  2. 2. 判断：x + 3 = 8 是方程。（ ）
    答：正确。它含有未知数 x，又是等式。
  3. 3. 解方程 x + 5 = 12，x =（ ）。
    答：7。根据等式的性质 1，两边同时减 5。

中等 · 解方程

  1. 1. 解方程 x - 3.5 = 6.5，并检验。
    答：两边同时加 3.5，x = 10。检验：10 - 3.5 = 6.5，正确。
  2. 2. 解方程 4x = 36，并检验。
    答：两边同时除以 4，x = 9。检验正确。
  3. 3. 用含有字母的式子表示：比 a 的 3 倍多 5 的数是（ ）。
    答：3a + 5。

难 · 稍复杂的方程

  1. 1. 解方程 3x + 7 = 28。
    答：两边同时减 7 得 3x = 21，再除以 3，x = 7。检验正确。
  2. 2. 解方程 6x - 9 = 33。
    答：两边同时加 9 得 6x = 42，再除以 6，x = 7。检验正确。
  3. 3. 一个数的 4 倍加上 6 等于 50，这个数是多少？用列方程的方法解答。
    答：设这个数为 x，4x + 6 = 50，4x = 44，x = 11。

综合 · 列方程解决问题

  1. 1. 爸爸今年 36 岁，比小华年龄的 3 倍大 3 岁，小华今年多少岁？
    答：设小华今年 x 岁，3x + 3 = 36，3x = 33，x = 11。小华今年 11 岁。
  2. 2. 一个长方形的周长是 48 厘米，长是宽的 3 倍，宽是多少厘米？
    答：设宽为 x 厘米，长为 3x 厘米。2 ×（x + 3x）= 48，8x = 48，x = 6。
  3. 3. 甲、乙两地相距 360 千米，一辆客车和一辆货车同时从两地相向开出，3 小时相遇。客车每小时行 65 千米，货车每小时行多少千米？
    答：设货车每小时行 x 千米。（65 + x）× 3 = 360，65 + x = 120，x = 55。

💬 课后反馈

**学生常见错误** 1. 把等式与方程混为一谈，认为"等式就是方程"或"方程就是等式"。 2. 用字母表示数时把数字写在字母后面，如写成 a4。 3. 解方程只在一边操作，等号不对齐。 4. 列方程找错等量关系，设未知数不写"解：设……"。 **教学改进建议** 1. 用天平演示等式的性质，让学生理解两边同时变化的道理。 2. 设计"等式、方程、不等式"分类卡片游戏，强化概念辨析。 3. 解方程强调书写格式：等号上下对齐，解完必检验。 4. 列方程前先画线段图表示等量关系。 **分层辅导** - 基础弱：先练等式判断和用字母表示简单的量，解方程只练三种基本形式。 - 学有余力：探究未知数在等式两边都出现的方程，尝试解决相遇问题。 **给家长的建议** 让孩子把家里的物品用字母式子表示，如"每袋米重 m 千克，两袋共 2m 千克"；鼓励孩子讲出解方程的过程和道理。
