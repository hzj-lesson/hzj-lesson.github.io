高中高一数学《不等式》教案

高中高一数学不等式

📝 备课方案

**教学目标** 1. 理解不等式的性质，掌握比较两个代数式大小的基本方法（作差法、作商法）。 2. 掌握基本不等式 $\frac{a+b}{2}\geqslant\sqrt{ab}$（a、b>0）及其应用条件，能求最值。 3. 掌握一元二次不等式的解法（因式分解、图像法），理解三个"二次"的关系。 4. 会解简单的分式不等式和绝对值不等式，能解决含参不等式的基本问题。 **教学重点**：基本不等式求最值，一元二次不等式的解法。 **教学难点**：基本不等式"一正二定三相等"条件的把握，含参一元二次不等式的分类讨论。 **教学方法**：性质推导、图像结合、变式训练、分类讨论思想渗透。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、不等式的基本性质** 1. $a>b \Leftrightarrow a-b>0$ 2. 传递性：$a>b,\ b>c \Rightarrow a>c$ 3. 可加性：$a>b \Rightarrow a+c>b+c$；同向可加：$a>b,\ c>d \Rightarrow a+c>b+d$ 4. 可乘性：$a>b,\ c>0 \Rightarrow ac>bc$；$a>b,\ c<0 \Rightarrow ac<bc$（乘负数要变号） 5. 同向正数可乘：$a>b>0,\ c>d>0 \Rightarrow ac>bd$ 6. 倒数性质：$a>b>0 \Rightarrow \frac{1}{a}<\frac{1}{b}$ 7. 乘方/开方：$a>b>0 \Rightarrow a^n>b^n$，$\sqrt[n]{a}>\sqrt[n]{b}$（n 为正整数） **二、基本不等式（均值不等式）** - 对任意正数 a、b：$\frac{a+b}{2}\geqslant\sqrt{ab}$，当且仅当 a=b 时取等号 - 常用变形：$a+b\geqslant 2\sqrt{ab}$；$ab\leqslant\left(\frac{a+b}{2}\right)^2$ - **使用条件（一正二定三相等）**：①a、b 为正 ②和或积为定值 ③能取到等号（a=b 可实现） **三、一元二次不等式 ax²+bx+c>0（或 <0）的解法** - 步骤：①判断 a 的正负（a<0 两边乘-1 变号）②因式分解或求根 ③结合图像（抛物线开口方向）写解集 - 三个"二次"的关系：一元二次方程 ax²+bx+c=0 的根是二次函数 y=ax²+bx+c 与 x 轴交点的横坐标，也是对应不等式的边界点 - Δ<0 时：a>0 且 ax²+bx+c>0 恒成立（解集为 R）；ax²+bx+c<0 无解（解集为 ∅） **四、分式与绝对值不等式** - 分式不等式：$\frac{f(x)}{g(x)}>0 \Leftrightarrow f(x)g(x)>0$（注意 g(x)≠0） - 绝对值不等式：$|x|<a \Leftrightarrow -a<x<a$（a>0）；$|x|>a \Leftrightarrow x<-a$ 或 $x>a$（a>0）

🔍 课堂讲义 · 重点难点解析

**重点一：作差法比较大小** 作差 → 因式分解/配方 → 判断符号。例：比较 $a^2+b^2$ 与 $2ab$：$a^2+b^2-2ab=(a-b)^2\geqslant0$，所以 $a^2+b^2\geqslant2ab$（a=b 时取等）。 **重点二：基本不等式求最值（一正二定三相等）** - 求 $x+\frac{1}{x}$（x>0）最小值：$x+\frac{1}{x}\geqslant2\sqrt{x\cdot\frac{1}{x}}=2$，当 x=1 时取等号，最小值为 2 - 若 x>1，求 $x+\frac{1}{x-1}$ 最小值：配凑 $x+\frac{1}{x-1}=(x-1)+\frac{1}{x-1}+1\geqslant2+1=3$，当 x-1=1 即 x=2 时取等 - 常见错误：不满足"正"（如 x<0 要用 -x 转化）、不满足"定值"、等号取不到 **难点一：一元二次不等式的含参讨论** 对含参数 a 的 ax²+bx+c>0： - 先讨论 a=0（一次不等式） - a≠0 时，再按 Δ>0、Δ=0、Δ<0 分类；两根大小时还要比较根的大小 - 例：解关于 x 的不等式 $x^2-(a+1)x+a>0$：因式分解 $(x-1)(x-a)>0$，需比较 1 与 a 的大小，分 a>1、a=1、a<1 三种情况讨论 **难点二：恒成立问题** f(x)>0 恒成立（x∈R）： - 二次函数：开口向上（a>0）且 Δ<0 - 或直接求 f(x) 的最小值，令其 >0 - 例：x²+ax+1>0 恒成立 → Δ=a²-4<0 → -2<a<2 **常见误区** - 不等式同乘负数忘记变号 - 基本不等式用错条件（未检验"正、定、等"） - 分式不等式直接去分母（要先判断分母符号或移项通分）

✏️ 课堂讲义 · 典型例题精讲

**例1（性质应用）**：已知 a>b>0，比较 $\frac{a}{b}$ 与 $\frac{a+1}{b+1}$ 的大小。 **解**：$\frac{a}{b}-\frac{a+1}{b+1}=\frac{a(b+1)-b(a+1)}{b(b+1)}=\frac{a-b}{b(b+1)}>0$（因 a>b>0），所以 $\frac{a}{b}>\frac{a+1}{b+1}$。 **关键**：作差法 + 判断符号。 **例2（基本不等式求最值）**：已知 x>0，y>0，且 x+y=4，求 xy 的最大值。 **解**：$xy\leqslant\left(\frac{x+y}{2}\right)^2=\left(\frac{4}{2}\right)^2=4$，当 x=y=2 时取等号，xy 最大值为 4。 **关键**：和为定值，积有最大值（正数条件下）。 **例3（一元二次不等式）**：解不等式 $x^2-5x+6>0$。 **解**：因式分解 $(x-2)(x-3)>0$，两根 2、3，开口向上，大于零取两边：x<2 或 x>3。 **关键**："大于取两边，小于取中间"（开口向上时）。 **例4（恒成立）**：若不等式 $ax^2+2ax+1>0$ 对一切 x∈R 恒成立，求 a 的取值范围。 **解**：a=0 时，1>0 恒成立，符合。a≠0 时需 a>0 且 Δ=4a²-4a<0 → 0<a<1。综上：0≤a<1。 **关键**：不要漏掉 a=0 的情形（二次项系数为零）。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 性质与比较

  1. 1. 已知 a>b，判断下列结论是否正确：①a+c>b+c ②ac>bc ③a²>b² ④1/a<1/b
    答：①对（可加性）；②错（c<0 时变号）；③错（需 a、b 均为正或讨论绝对值）；④错（需 a、b 同号且为正）。
  2. 2. 用作差法比较 a²+a+1 与 3a 的大小（a 为实数）。
    答：a²+a+1-3a=a²-2a+1=(a-1)²≥0，所以 a²+a+1≥3a，a=1 时取等号。
  3. 3. 写出基本不等式及其使用条件。
    答：(a+b)/2≥√(ab)（a、b>0），当且仅当 a=b 时取等号。条件：一正二定三相等。

中等 · 基本不等式

  1. 1. 已知 x>0，求 x+4/x 的最小值。
    答：x+4/x≥2√(x·4/x)=4，当 x=2 时取等号，最小值为 4。
  2. 2. 已知 x>2，求 x+1/(x-2) 的最小值。
    答：x+1/(x-2)=(x-2)+1/(x-2)+2≥2+2=4，当 x-2=1 即 x=3 时取等号，最小值为 4。
  3. 3. 已知 0<x<1，求 x(1-x) 的最大值。
    答：x(1-x)≤[(x+1-x)/2]²=(1/2)²=1/4，当 x=1/2 时取等号，最大值为 1/4。

难 · 不等式解法

  1. 1. 解不等式：①x²-3x-4<0 ②-x²+2x+3≥0 ③(x-1)/(x+2)>0
    答：①(x-4)(x+1)<0 → -1<x<4。②x²-2x-3≤0 → (x-3)(x+1)≤0 → -1≤x≤3。③(x-1)(x+2)>0 且 x≠-2 → x<-2 或 x>1。
  2. 2. 解关于 x 的不等式 x²-(2a+1)x+a²+a>0。
    答：因式分解 (x-a)(x-a-1)>0，两根 a 与 a+1（a<a+1），开口向上，解集为 x<a 或 x>a+1。
  3. 3. 不等式 |2x-1|<3 的解集是什么？
    答：-3<2x-1<3 → -2<2x<4 → -1<x<2。

综合 · 恒成立与综合

  1. 1. 若 x²+ax+4≥0 对一切 x∈R 恒成立，求 a 的范围。
    答：Δ=a²-16≤0 → -4≤a≤4。
  2. 2. 已知 x、y 为正数，且 1/x+1/y=1，求 x+y 的最小值。
    答：x+y=(x+y)(1/x+1/y)=2+x/y+y/x≥2+2=4，当 x=y=2 时取等号，最小值为 4。
  3. 3. 建造一个底面为正方形、容积为 8 m³ 的无盖长方体水池，怎样设计底面边长和高度使用料最省？
    答：设底面边长 a、高 h，a²h=8。用料（侧面积+底面积）S=a²+4ah=a²+4a·8/a²=a²+32/a。由基本不等式 a²+32/a=a²+16/a+16/a≥3·∛(a²·16/a·16/a)=3·∛256≈3×6.35=19，等号当 a²=16/a 即 a=2 时取得，此时 h=2。即底面 2×2 m、高 2 m 用料最省。

💬 课后反馈

不等式是高中数学的基础工具，学生常见问题：基本不等式求最值时忽视"一正二定三相等"的条件、一元二次不等式解法中符号错误、含参问题分类讨论不完整、恒成立问题漏掉二次项系数为零的情形。建议：用"三个二次"的关系图强化一元二次不等式的直观理解；把基本不等式的条件编成口诀（一正二定三相等）并配合变式训练；含参不等式从"要不要讨论、讨论什么、怎么讨论"三步引导。
