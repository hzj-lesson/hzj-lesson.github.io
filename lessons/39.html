初中七年级数学《正数和负数》教案

初中七年级数学正数和负数

📝 备课方案

**教学目标** 1. 理解正数、负数的概念，会用正负数表示生活中具有相反意义的量，体会引入负数的必要性。 2. 理解 0 既不是正数也不是负数，知道 0 除了表示"没有"外，还表示起点、分界等意义。 3. 掌握数轴的三要素（原点、正方向、单位长度），会画数轴，能在数轴上表示有理数并读数。 4. 理解相反数、绝对值的意义，会求一个数的相反数和绝对值，能借助数轴或法则比较有理数的大小。 **教学重点**：用正负数表示相反意义的量；相反数、绝对值的意义与求法。 **教学难点**：绝对值的概念；比较两个负数的大小。 **教学方法**：生活情境导入法、数形结合法、对比讨论法。 **教学准备**：课件（温度计、海拔、收支图表）、数轴模型、练习题卡、分类卡。 **课时安排**：3 课时（第 1 课时：正数和负数；第 2 课时：数轴与相反数；第 3 课时：绝对值与有理数大小比较）。

📖 课堂讲义 · 核心知识点

**一、正数和负数——相反意义的量** 生活中有许多"意义相反"的量：零上 8℃ 与零下 5℃，收入 200 元与支出 80 元，上升 15 米与下降 3 米，向东走 50 米与向西走 20 米。为了表示这些相反意义的量，人们把其中一种规定为正，用正数表示；另一种就用负数表示。 - 大于 0 的数叫正数，如 3、0.5、7/8，正数前面可以写"+"号（+3），也可省略不写。 - 在正数前面加上负号"-"得到的数叫负数，如 -3、-0.5，负号不能省略。 例：零上 5℃ 记作 +5℃（或 5℃），零下 3℃ 记作 -3℃；收入 200 元记作 +200 元，支出 80 元记作 -80 元。 有了负数，表示相反意义的量就简洁、准确了，这就是引入负数的必要性。 **二、0 的意义** 0 既不是正数，也不是负数，它是正数和负数的"分界点"。 0 不只是"没有"：温度计上的 0℃ 表示水结冰的温度，不是没有温度；起跑线记作 0 米是测量的起点；电梯的 0 层是楼层分界。海平面的高度记为 0 米，高出海平面用正数，低于海平面用负数。 **三、数轴** 规定了原点、正方向、单位长度的直线叫数轴。三要素缺一不可： - 原点：0 所在的位置； - 正方向：通常向右（或向上），用箭头表示； - 单位长度：取适当的长度作为 1，刻度要均匀。 画法：画一条水平直线，标上原点 O，选定正方向（向右），选好单位长度，然后从左到右标出刻度。 在数轴上表示有理数：正数在原点的右边，负数在原点的左边。任何一个有理数都能在数轴上找到唯一的对应点。 **四、相反数** 只有符号不同的两个数互为相反数，如 5 与 -5、0.3 与 -0.3。a 的相反数是 -a，特别地，0 的相反数是 0。 - 相反数的几何意义：在数轴上，互为相反数的两个点位于原点两侧，且到原点的距离相等。 - 求一个数的相反数，只需在这个数前面添一个负号：-(-3)=3。 - 多重符号化简：数负号的个数，负号有奇数个结果为负，偶数个结果为正。如 -[-(+2)] 有 2 个负号，结果为 +2。 **五、绝对值** 绝对值表示"距离"：在数轴上，表示一个数的点到原点的距离，叫做这个数的绝对值，记作 |a|。因为距离不可能是负的，所以任何数的绝对值都是非负数，即 |a|≥0。 求法法则：正数的绝对值是它本身，负数的绝对值是它的相反数，0 的绝对值是 0。 例：|5|=5，|-5|=5，|0|=0。 绝对值的重要应用：若 |x|=3，则 x=±3（原点到 3 和 -3 的距离都是 3）。|a| 表示数轴上 a 到原点的距离，|a-b| 则表示 a 与 b 两点之间的距离。 **六、有理数的大小比较** 1. 数轴法：在数轴上，右边的数总比左边的数大。 2. 法则法：正数大于 0，0 大于负数，正数大于负数；两个负数比较大小，绝对值大的反而小。 例：比较 -3 和 -5。|-3|=3，|-5|=5，因为 3<5，所以 -3>-5（在数轴上 -3 在 -5 的右边）。 为什么"绝对值大的反而小"？离原点越远的负数，位置越靠左，数就越小。 **易错提醒** 1. 把 0 当成正数或负数。 2. 相反数与绝对值混淆：-5 的相反数是 5，绝对值是 5，含义完全不同。 3. 比较两个负数时凭"感觉"判大小，不知道用绝对值比。 4. 画数轴漏掉三要素之一，或单位长度不均匀。

🔍 课堂讲义 · 重点难点解析

**重点一：用正负数表示相反意义的量** 例题：某仓库入库 +200 吨表示运进 200 吨，那么运出 150 吨怎样表示？如果规定向西走记作正，向东走 30 米记作什么？ 分析：入库与运出意义相反，规定入库为正，则运出为负；规定向西为正，则向东为负。 解答：运出 150 吨记作 -150 吨；向东走 30 米记作 -30 米。 小结：先看"规定哪种记为正"，与之相反的另一种就记为负，单位不能丢。 **难点一：绝对值的概念与求法** 例题：求 |+7|、|-4|、|0| 的值；若 |x|=5，求 x。 分析：绝对值表示到原点的距离，正数的绝对值是本身，负数的绝对值是相反数。 解答：|+7|=7，|-4|=4，|0|=0；|x|=5 说明 x 到原点距离为 5，所以 x=5 或 x=-5。 小结：求绝对值看符号——"正本身、负相反、零还是零"；已知绝对值求原数，答案往往有两个，别忘了负数。 **难点二：比较两个负数的大小** 例题：比较 -2.5 与 -3 的大小，并说明理由。 分析：求两个负数的绝对值：|-2.5|=2.5，|-3|=3；因为 2.5<3，绝对值小的负数反而大。 解答：-2.5>-3。理由：绝对值大的负数离原点远、位置靠左、数更小。 小结：负数比大小三步走：先取绝对值，再比绝对值大小，最后"绝对值大的反而小"。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：正负数分类与表示** 题目：把 +3、-2、0、4.5、-1/2 中的正数、负数分别指出来；再回答：某地海拔 -155 米表示什么意思？ 分析：大于 0 的是正数，小于 0 的是负数，0 两者都不是；海拔为负表示低于海平面。 解答：正数有 +3、4.5；负数有 -2、-1/2；0 既不是正数也不是负数。-155 米表示该地比海平面低 155 米。 方法小结：分类题先找符号，正号（或省略）是正数，负号是负数，0 单独归一类。 **例题二（提高）：数轴与相反数** 题目：在数轴上标出 2、-2、1.5 三个数，并说出 2 与 -2 的关系。 分析：数轴上正数在原点右、负数在原点左；2 和 -2 只有符号不同。 解答：2 在原点右边两个单位，-2 在原点左边两个单位，1.5 在原点右边一个半单位；2 与 -2 互为相反数，且到原点距离相等。 方法小结：画数轴先定三要素，再按单位长度找点；互为相反数的两点关于原点对称。 **例题三（综合）：绝对值与大小比较** 题目：比较 -7/8 与 -5/6 的大小，并用数轴检验。 分析：|-7/8|=7/8=21/24，|-5/6|=5/6=20/24；21/24>20/24，绝对值大的负数反而小。 解答：-7/8<-5/6。数轴上 -7/8 在 -5/6 的左边，符合"左小右大"。 方法小结：异分母分数比较先通分再比绝对值，最后记住"绝对值大者反而小"，数轴检验更直观。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 正负数的意义

  1. 1. 填空：零上 7℃ 记作 +7℃，零下 3℃ 记作（ ）；海平面以上 80 米记作 +80 米，海平面以下 25 米记作（ ）。
    答：零下 3℃ 记作 -3℃；海平面以下 25 米记作 -25 米。正数表示规定的正方向，相反意义用负数，注意带单位。
  2. 2. 下列各数中，哪些是正数？哪些是负数？0.5、-7、0、+12、-3.2、4。
    答：正数：0.5、+12、4；负数：-7、-3.2；0 既不是正数也不是负数。先看符号，正号或省略为正，负号为负，0 单独归类。
  3. 3. 如果上升 5 米记作 +5 米，那么下降 8 米记作（ ）；如果支出 100 元记作 -100 元，那么收入 300 元记作（ ）。
    答：下降 8 米记作 -8 米；收入 300 元记作 +300 元。关键是先确定哪种记为正，相反意义的量就记为负。

中等 · 数轴与相反数

  1. 1. 画一条数轴，并在数轴上表示出 -3、0、2.5 三个点。
    答：画水平直线，标原点 O（0）、正方向（向右箭头）、单位长度；-3 在原点左三个单位，2.5 在原点右两个半单位，0 就是原点。三要素缺一不可。
  2. 2. 填空：4 的相反数是（ ），-6 的相反数是（ ），0 的相反数是（ ），a 的相反数是（ ）。
    答：4 的相反数是 -4，-6 的相反数是 6，0 的相反数是 0，a 的相反数是 -a。只有符号不同的两个数互为相反数。
  3. 3. 化简：-(+3)、-(-5)、-[-(+2)]。
    答：-(+3)=-3；-(-5)=5；-[-(+2)]=2。数负号的个数：奇数个负号结果为负，偶数个负号结果为正。

难 · 绝对值

  1. 1. 求下列各数的绝对值：|+8|、|-3.5|、|0|、|-1/4|。
    答：|+8|=8，|-3.5|=3.5，|0|=0，|-1/4|=1/4。正数的绝对值是本身，负数的绝对值是它的相反数，0 的绝对值是 0。
  2. 2. 若 |x|=6，求 x 的值；若 |x-2|=0，求 x 的值。
    答：|x|=6，则 x=6 或 x=-6；|x-2|=0，说明 x-2 到原点距离为 0，即 x-2=0，所以 x=2。绝对值等于非零数时原数有两个。
  3. 3. 用"大于"或"小于"填空：|a|（ ）0 恒成立；当 a<0 时，|a|=（ ），此时 |a| 与 a 的关系是（ ）。
    答：|a|≥0 恒成立（填"大于或等于"）；当 a<0 时，|a|=-a，此时 |a| 大于 a（因为正数大于负数）。

综合 · 有理数大小比较

  1. 1. 比较大小，并说明理由：-3 与 -4；-1/2 与 -1/3。
    答：-3>-4：|-3|=3，|-4|=4，绝对值大的负数反而小；-1/2<-1/3：|-1/2|=1/2=3/6，|-1/3|=1/3=2/6，绝对值大的反而小。
  2. 2. 把下列各数按从小到大的顺序排列：-2、0、3、-3.5、1/2。
    答：从小到大：-3.5、-2、0、1/2、3。负数小于 0 小于正数，两个负数比较绝对值大的反而小。
  3. 3. 某天五座城市的最高气温分别是：北京 5℃、哈尔滨 -12℃、上海 8℃、广州 15℃、乌鲁木齐 -5℃。请把这些温度按从低到高排列，并说说是怎么比较的。
    答：从低到高：-12℃、-5℃、5℃、8℃、15℃。比较方法：负数小于正数，两个负数比绝对值，绝对值大的温度更低。

💬 课后反馈

**学生常见错误** 1. 认为 0 是正数或负数，不知道 0 是正负数的分界。 2. 用正负数表示相反意义的量时忘记写单位，或把规定的正方向搞反。 3. 相反数与绝对值混淆：把 -5 的绝对值写成 -5，或把相反数写成 5 却说成绝对值。 4. 比较两个负数大小时凭"数感"判断，不看绝对值，导致判断相反。 **教学改进建议** 1. 用温度计、电梯、海拔等实物图引入，让学生直观感受"分界点 0"的含义。 2. 建立"反义词表"：上升/下降、收入/支出、入库/出库、向东/向西，先配对再定符号。 3. 用数轴把相反数和绝对值放在一起教：到原点距离相等但方向不同的是相反数，只看距离看绝对值，距离永远非负。 4. 负数比较大小坚持"先取绝对值、再比大小、最后反着说"，配数轴直观检验。 **分层辅导建议** - 基础层：重点练正负数识别和相反意义的量的表示，先过关符号与单位。 - 提高层：练数轴作图、相反数与绝对值的求法，逐步脱离数轴直接计算。 - 拓展层：练含字母的绝对值（如 a<0 时 |a|=-a）和综合大小比较，为后续学习打基础。 **给家长的建议** 1. 看天气预报时让孩子说说零下温度怎么表示，看超市小票说说收入和支出的正负数。 2. 在家里的墙上画一条数轴，孩子可以把每天的心情、成绩的位置标上去。 3. 玩"绝对值和相反数"抢答游戏：你说 -8，孩子抢答"相反数 8，绝对值 8"，又快又准。
