初中九年级物理《电磁波与现代通信》教案

初中九年级物理电磁波与现代通信

📝 备课方案

**教材分析** 本节介绍电磁波的产生、传播特性（真空中速度等于光速）及其在现代通信中的广泛应用，是"信息与通信"板块的基础，连接生活科技。 **教学目标** 1. 知道电磁波由变化的电流产生，能在空间传播，真空中速度 $c = 3\times10^8,m/s$（等于光速）。 2. 了解电磁波谱常识（无线电波、微波、红外线、可见光、紫外线、X 射线、γ 射线）及频率/波长关系。 3. 认识电磁波在广播、移动通信、卫星通信、微波加热等方面的应用。 **教学重点** 电磁波的产生与传播速度；现代通信对电磁波的依赖。 **教学难点** 电磁波的产生机制（变化的电场与磁场交替）；波速、波长、频率关系 $c = \lambda f$。 **课时** 1 课时 **教学过程** 水波类比→电磁波产生→速度→波速公式→应用实例→科技展望。

📖 课堂讲义 · 核心知识点

**一、电磁波的产生** - 条件：变化的电流（迅速变化的电场）会在周围空间产生变化的磁场，变化的磁场又产生变化的电场，二者交替激发，由近及远传播，形成电磁波。 - 简单记：变化 的电流 → 变化的电磁场 → 电磁波。 - 振荡电路（如天线中的高频电流）是电磁波的发射源。 **二、电磁波的传播** - 电磁波传播不需要介质，真空中也能传播（与声波不同，声波需介质）。 - 真空中波速 $c = 3\times10^8,m/s$，与光速相同（光本质也是电磁波）。 - 在空气中波速近似等于真空中波速。 - 波速、波长、频率关系：$c = \lambda f$（$c$ 波速，$ \lambda $ 波长 m，$f$ 频率 Hz）。频率越高，波长越短。 **三、电磁波谱（按频率由低到高）** 无线电波 → 微波 → 红外线 → 可见光 → 紫外线 → X 射线 → γ 射线。 - 无线电波/微波：通信、广播、雷达。 - 红外线：遥控、夜视、加热。 - 可见光：照明、光纤通信。 - 紫外线：消毒、验钞。 - X 射线：透视医疗；γ 射线：探伤、放疗。 **四、现代通信应用** - 无线电广播：声音信号调制到无线电波发射。 - 移动通信（手机）：基站通过电磁波中转，实现移动通话与上网。 - 卫星通信：通信卫星作中继，覆盖广、距离远。 - 光纤通信：激光（光，属电磁波）在光导纤维中传输，容量大、抗干扰。 - 微波加热：微波炉用微波使食物水分子振动发热。 - 互联网/WiFi：以电磁波（射频/微波）承载数字信号。

🔍 课堂讲义 · 重点难点解析

**难点一：电磁波为何不需要介质也能传播** 声波是机械波，靠介质振动传播；电磁波是变化的电磁场本身，电场生磁场、磁场生电场，自我维持向前传播，故真空中亦可。可类比：声波像"人群接力传话"需人在场，电磁波像"火把依次点燃"无需介质传递物质，只传能量与信息。 **难点二：波速公式 $c=\lambda f$ 的含义** 任何电磁波在真空中速度恒为 $c$。由 $c=\lambda f$ 可知，频率 $f$ 越大，波长 $\lambda$ 越小（反比）。例如可见光中紫光频率高、波长短；无线电波频率低、波长长。通信中不同频段用于不同用途即基于此。 **难点三：变化的电流才产生电磁波** 稳定电流（直流电）只产生恒定磁场，不产生电磁波；必须是"变化/振荡"的电流（如交变电流、开关瞬间）才辐射电磁波。手机、WiFi 都用高频振荡电流。 **常见失误** 1. 误以为电磁波传播需要空气 → 真空中也能传（太阳光到达地球即为证）。 2. 把波速记成声速 340 m/s → 电磁波速是 $3\times10^8,m/s$。 3. 混淆频率与波长关系 → 高频短波，非正比。

✏️ 课堂讲义 · 典型例题精讲

**例1（产生）** 电磁波是怎样产生的？ 解析：变化的电流在其周围产生变化的磁场，变化的磁场又产生变化的电场，电场磁场交替激发、由近及远传播，形成电磁波。简记：变化的电流→变化的电磁场→电磁波。 关键：必须"变化"的电流，稳定直流电不产生。 **例2（速度）** 光从太阳到地球约 $8$ 分 $20$ 秒，说明什么？ 解析：光属电磁波，真空中速 $c=3\times10^8,m/s$；能在真空传播且速等于光速，证明电磁波不需介质、以光速传播。日地距离约 $1.5\times10^{11},m$。 关键：电磁波=光速、真空可传。 **例3（波速公式）** 某无线电波频率 $f=100,MHz$，求其波长 $\lambda$。（$c=3\times10^8,m/s$） 解析：由 $c=\lambda f$，$\lambda = \frac{c}{f} = \frac{3\times10^8}{(100\times10^6)} = 3,m$。 关键：高频短波；先统一单位（$100,MHz=10^8,Hz$）。 **例4（应用辨析）** 手机通话依靠什么？微波炉为什么能加热食物？ 解析：手机通过高频电磁波（射频）经基站中转实现通信；微波炉用微波（电磁波）使食物内水分子高频振动、摩擦生热，从而加热。 关键：通信靠电磁波载信息；微波靠电磁波传能量。 **例5（对比）** 电磁波与声波在传播条件上有何不同？各举通信中一例。 解析：电磁波不需介质、真空可传、速为光速；声波需介质、空气中约 $340,m/s$。通信中：卫星通信靠电磁波（太空真空可传）；而水中声呐靠声波（利用水介质）。说明不同场景选不同波。 关键：介质需求是二者根本区别。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 电磁波是怎样产生的？它在真空中的传播速度是多少？
    答：电磁波由变化的电流产生：变化的电流周围产生变化的磁场，变化的磁场又产生变化的电场，二者交替激发、由近及远传播形成电磁波。真空中传播速度 $c = 3\times10^8,m/s$，等于光速（光本质也是电磁波）。
  2. 2. 列举电磁波谱从低频到高频的主要成员。
    答：无线电波 → 微波 → 红外线 → 可见光 → 紫外线 → X 射线 → γ 射线。频率越低波长越长，频率越高波长越短。

中等 · 计算与辨析

  1. 1. 已知电磁波波速 $c=3\times10^8,m/s$，某电台频率 $f=90,MHz$，求其波长 $\lambda$（用 $c=\lambda f$）。
    答：统一单位：$f=90,MHz=9.0\times10^7,Hz$。由 $\lambda = \frac{c}{f} = \frac{3\times10^8}{9.0\times10^7} \approx 3.33,m$。结论：该广播波长约 $3.33,m$，属中波/短波范围，频率越低波长越长。
  2. 2. 为什么电磁波能在真空中传播，而声音不能？请举一个太空通信的例子。
    答：电磁波是交替激发的电磁场，自我维持向前传播，不依赖物质介质；声波是机械波，靠介质质点振动传递，真空无介质故不能传。例子：卫星通信、月球与地球间的测控信号都靠电磁波穿越太空真空，证明电磁波可真空传播。

难 · 综合理解

  1. 1. 解释微波炉加热原理，并说明为什么金属容器不能放进微波炉（从电磁波与能量角度）。
    答：微波炉发射微波（高频电磁波），使食物中的水、脂肪等极性分子随电场方向高频翻转振动，分子间摩擦生热，从内部加热食物。金属容器不能放入：金属会反射微波，且微波在金属表面感应出强大涡流，可能产生电火花、损坏磁控管甚至起火；此外金属不吸收微波，食物也加热不均。故应使用陶瓷/耐热玻璃器皿。
  2. 2. 比较光纤通信与卫星通信的异同（都基于电磁波），各有什么优点？
    答：相同：都利用电磁波（光或射频）承载信息，实现远距离通信。不同：光纤通信以激光在玻璃纤维中传输，优点——容量极大、抗电磁干扰、保密性好、损耗低，适合陆上干线；卫星通信以微波经通信卫星中继，优点——覆盖广、跨越海洋山地、无需铺线，适合偏远与移动场景。二者互补构成现代通信网。

综合 · 科技探究

  1. 1. 设计一份"电磁波与生活"小调查提纲：至少列出 4 个身边的电磁波应用，并说明各自利用电磁波的什么特性。
    答：提纲：①手机/WiFi——利用无线电射频电磁波载数字信号，实现无线通信（不需介质、速快）；②电视机遥控器——利用红外线电磁波的指向性与热效应遥控；③紫外线消毒灯——利用紫外线高能破坏微生物 DNA 杀菌；④医用 X 光机——利用 X 射线穿透性差异成像查骨；⑤微波炉——利用微波使水分子振动发热。每个应用说明所用波段（无线电/红外/紫外/X/微波）及特性（载信息/热效应/杀菌/穿透/加热）。
  2. 2. 有人说"5G 比 4G 快是因为电磁波跑得更快"，对吗？用 $c=\lambda f$ 知识解释真实原因。
    答：错误。所有电磁波在真空中速度都是 $c=3\times10^8,m/s$，5G 与 4G 电磁波速相同。真实原因：5G 使用更高频率（$f$ 更大）的频段，由 $c=\lambda f$，高频对应更短波长，可容纳更宽带宽、更大信道容量，且采用更先进调制与多天线（MIMO）技术，从而单位时间传更多数据，速率更快。即"快"来自频率/带宽/技术，而非波速增加。

💬 课后反馈

电磁波是现代通信的基础，学生能记住"变化的电流产生电磁波、速度等于光速（$3\times10^8,m/s$）"，但易把波速与声速混淆、误以为需介质。建议结合手机、WiFi、卫星通信、微波炉等生活场景讲清应用，并用 $c=\lambda f$ 说明频率与波长关系，感受科技对生活的改变。
