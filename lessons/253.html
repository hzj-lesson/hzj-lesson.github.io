初中九年级物理《电能 电功》教案

初中九年级物理电能 电功

📝 备课方案

**教材分析** 本课是人教版《物理》九年级全一册第十八章第一节，是电学由"电路规律"走向"能量分析"的枢纽。学生在八年级已掌握电流、电压、电阻、欧姆定律与串并联规律，本节引入电能与电功两个能量概念，介绍电能表的使用，为后续电功率、焦耳定律及生活用电打下基础。 **教学目标** 1. 知道电能及其单位（焦耳 $J$、千瓦时 $kW\cdot h$），知道 $1\,kW\cdot h = 3.6\times10^6\,J$。 2. 会读电能表，能由月初、月末示数计算家庭用电量，会分析常见铭牌参数。 3. 理解电功的概念，知道电流做功的过程就是电能转化为其他形式能的过程。 4. 掌握电功公式 $W = UIt$ 及各量的单位，会进行简单计算。 **教学重点** 电能表读数与用电量计算；电功公式 $W = UIt$。 **教学难点** 电功概念的建立；$kW\cdot h$ 与 $J$ 的换算及公式变式应用。 **课时** 1 课时 **教学过程** 生活电费单导入→电能与单位→电能表读数训练→电功概念→$W=UIt$ 例题→小结作业。

📖 课堂讲义 · 核心知识点

**一、电能** - 定义：电流做功时消耗的能量叫电能。电能的单位是焦耳（$J$），生活中常用"度"，即千瓦时（$kW\cdot h$）。 - 换算关系：$1\,kW\cdot h = 3.6\times10^6\,J$。 - 电能的转化：发电厂把其他形式的能转化为电能，用电器把电能转化为光能、内能、机械能等。家庭交电费，买的实际是"电能"。 **二、电能表** - 作用：测量电路消耗电能多少的仪表，计数单位是 $kW\cdot h$，计数器最后一位是小数位。 - 常见铭牌参数（如 $220V\;10(20)A\;2500r/(kW\cdot h)$）：$220V$ 表示电能表适用的额定电压；$10A$ 为标定电流，$20A$ 为短时允许通过的额定最大电流；$2500r/(kW\cdot h)$ 表示每消耗 $1\,kW\cdot h$ 的电能，转盘转过 $2500$ 转。 - 某月用电量 = 月末示数 − 月初示数。 **三、电功** - 定义：电流所做的功叫电功，符号 $W$。电流做功的实质：把电能转化为其他形式的能（消耗了多少电能，就做了多少电功）。 - 大小与什么有关：与电压 $U$、电流 $I$、通电时间 $t$ 有关，公式 $W = UIt$。单位：焦耳（$J$），$1\,J = 1\,V\cdot A\cdot s$。 - 常用变式：由 $W = Pt$（$P$ 用 $kW$、$t$ 用 $h$ 时 $W$ 单位为 $kW\cdot h$）；纯电阻电路中还可写成 $W = I^2Rt = \frac{U^2}{R}t$。 - 记法要点：电流做了多少功，就消耗了多少电能，二者数值相等、一一对应；读数单位与焦耳按 $1\,kW\cdot h = 3.6\times10^6\,J$ 互通。

🔍 课堂讲义 · 重点难点解析

**难点一：电功与电能的关系** 电功是电能转化的量度。电流做功的过程，就是消耗电能、把电能转化为其他形式能的过程，二者数值相等、方向对应。例如电灯通电 $1$ 小时，若消耗了 $0.04\,kW\cdot h$ 电能，则电流做功也是 $0.04\,kW\cdot h$，电能主要转化为光能与内能。 **难点二：电能表的读数与用电量** 电能表计数器的最后一位是小数位。例如月初示数 $1384.6\,kW\cdot h$，月末示数 $1468.2\,kW\cdot h$，则本月用电 $1468.2-1384.6 = 83.6\,kW\cdot h$，即 $83.6$ 度。注意相减时要对齐小数位。 **难点三：$W=UIt$ 的使用条件** 公式中的 $U$、$I$、$t$ 必须是同一用电器、同一段时间内的对应量（同时性、同体性）。单位统一用 $V$、$A$、$s$ 时，$W$ 的单位是 $J$。若已知功率用 $W=Pt$，则需注意功率单位选 $kW$、时间单位选 $h$，此时 $W$ 单位是 $kW\cdot h$，避免两种单位混搭。 **常见失误** 1. 电能表读数忽略最后一位是小数。 2. $1\,kW\cdot h$ 误记为 $3.6\times10^5\,J$（应为 $3.6\times10^6\,J$）。 3. 套 $W=UIt$ 时三个量不是同一用电器的对应值。

✏️ 课堂讲义 · 典型例题精讲

**例1（电能表读数）** 某同学家电能表月初示数为 $1384.6\,kW\cdot h$，月末示数为 $1468.2\,kW\cdot h$，本月用电多少度？合多少焦耳？ 解析：用电量 $W = 1468.2-1384.6 = 83.6\,kW\cdot h$，即 $83.6$ 度。合 $83.6\times3.6\times10^6 \approx 3.01\times10^8\,J$。 关键：示数之差即用电量；度与焦的换算系数是 $3.6\times10^6$。 **例2（铭牌参数）** 电能表上标有 $220V\;10(20)A$，各数字表示什么？使用时电流有何限制？ 解析：$220V$ 是电能表适用的额定电压；$10A$ 是标定电流；$20A$ 是短时间允许通过的最大电流。家庭干路电流一般不应超过 $10\,A$，瞬时也不宜超过 $20\,A$，否则电能表易损坏甚至烧毁。 关键：看清额定最大电流，避免超负荷。 **例3（公式计算）** 某电动机接在 $220\,V$ 电路中，正常工作时电流为 $5\,A$，通电 $10\,s$ 电流做了多少功？消耗多少电能？ 解析：$W = UIt = 220\times5\times10 = 1.1\times10^4\,J$。电流做功 $1.1\times10^4\,J$，消耗电能也是 $1.1\times10^4\,J$。 关键：电流做功等于消耗的电能；单位 $V\cdot A\cdot s$ 对应 $J$。 **例4（变式应用）** 一只电水壶的功率是 $1000\,W$，烧开一壶水消耗电能 $0.1\,kW\cdot h$，需通电多少秒？ 解析：$W = 0.1\,kW\cdot h = 3.6\times10^5\,J$。由 $W = Pt$ 得 $t = \frac{W}{P} = \frac{3.6\times10^5}{1000} = 360\,s$。 关键：电能单位换算后再套 $W=Pt$，保证单位配套。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 电能有哪些单位？它们之间的换算关系是什么？
    答：电能的单位有焦耳（$J$）和千瓦时（$kW\cdot h$），$1\,kW\cdot h = 3.6\times10^6\,J$。千瓦时俗称"度"，是家庭用电量的常用单位。
  2. 2. 电能表的作用是什么？读数单位是什么？计数器最后一位表示什么？
    答：电能表用来测量电路消耗电能的多少，计数单位为 $kW\cdot h$（度）。计数器上的数字最后一位是小数位，读数时不能漏掉。

中等 · 计算应用

  1. 1. 月初电能表示数为 $1025.4\,kW\cdot h$，月末为 $1087.9\,kW\cdot h$，求本月用电多少度？合多少焦？
    答：本月用电 $W = 1087.9-1025.4 = 62.5\,kW\cdot h$（度）。合 $62.5\times3.6\times10^6 = 2.25\times10^8\,J$。
  2. 2. 一盏电灯接在 $220\,V$ 电路上，通过的电流为 $0.18\,A$，通电 $100\,s$，电流做了多少功？
    答：由 $W=UIt = 220\times0.18\times100 = 3960\,J$。即电流做了 $3.96\times10^3\,J$ 的功，消耗了等量电能。

难 · 铭牌与综合

  1. 1. 电能表上标有 $3000r/(kW\cdot h)$，某段时间转盘转了 $150$ 转，这段时间消耗了多少电能？
    答：每消耗 $1\,kW\cdot h$ 转 $3000$ 转，则 $150$ 转对应电能 $W = \frac{150}{3000} = 0.05\,kW\cdot h = 0.05\times3.6\times10^6 = 1.8\times10^5\,J$。
  2. 2. 家庭电路电压为 $220\,V$，某电热器正常工作时电流为 $4\,A$，工作 $30$ 分钟，电流做功多少？消耗电能多少千瓦时？
    答：先统一单位：$t=30\times60=1800\,s$。$W = UIt = 220\times4\times1800 = 1.584\times10^6\,J$。换算为 $kW\cdot h$：$1.584\times10^6 \div 3.6\times10^6 = 0.44\,kW\cdot h$。

综合 · 生活实践

  1. 1. 观察家里的电能表，读出上月与本月（或连续两次）的示数，估算家中一个月的用电量，并对标某几件大功率电器说明"电都消耗在哪了"。
    答：示例：两次示数差为 $120\,kW\cdot h$，即一月用电 $120$ 度。估算方法：空调约 $2000\,W$ 每天开 $3\,h$，耗电 $0.01$ 度 ×...，实际用 $W=Pt$ 逐项估算各电器（$W=Pt$，$P$ 取 $kW$、$t$ 取 $h$），把各项相加与电表读数对照，体会电能与电功的对应关系，并寻找节能空间（如待机电器拔插头）。
  2. 2. 为什么说"一度电可以做很多事"？请设计三个节能小方案并说明依据的物理知识。
    答：一度电 $=1\,kW\cdot h = 3.6\times10^6\,J$，可供 $100\,W$ 灯泡亮 $10\,h$、使 $25\,W$ 台灯亮 $40\,h$。节能方案示例：①随手关灯、人走灯灭——减少通电时间 $t$，由 $W=Pt$ 省电；②电视、机顶盒不用时拔电源——消除待机损耗（待机仍耗电）；③空调温度夏季调高 $1\sim2\,^{\circ}C$——降低压缩机工作功率与时间。依据：电能 $W=Pt$，节能关键是减小功率或缩短工作时间。

💬 课后反馈

电能与电功是电学能量观建立的起点。学生能较快学会读电能表并计算用电量，但常在 $kW\cdot h$ 与 $J$ 的换算（$1\,kW\cdot h=3.6\times10^6\,J$）、$W=UIt$ 的同时性同体性上出错。建议用家庭电费单、电能表实物（或图片）创设真实情境，通过"算自家电费""估算一度电能做什么"等任务强化单位的物理意义，再过渡到 $W=UIt$ 的计算。还可设计"看表说电"环节：出示不同电器同时工作的情景，让学生根据电能表转盘转速或读数差判断哪件电器耗电最多，把电功计算与生活观察结合起来；课后让学生连续抄录一周电能表示数，绘制"家庭用电日曲线"，体会电能计量在家庭能源管理中的作用，实现从课堂例题到生活实践的迁移。本课是电学能量观的起点，讲透"电能可计量、可转化"，后续电功率、焦耳定律的学习便有了坚实的观念基础。
