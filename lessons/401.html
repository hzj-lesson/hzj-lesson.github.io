高中高一化学《硫的化合物》教案

高中高一化学硫的化合物

📝 备课方案

**教学目标** 1. 认识硫单质的物理性质与化学性质，能写出硫与氧气等反应的方程式，理解硫的常见价态（-2、0、+4、+6）与氧化性、还原性的关系。 2. 掌握二氧化硫的性质：酸性氧化物通性、还原性、弱氧化性与漂白性，能区分 SO₂ 使溴水褪色（还原性）与使品红褪色（漂白性）的原理，认识 SO₃ 及硫酸的工业制法。 3. 掌握浓硫酸的吸水性、脱水性、强氧化性三大特性及对应实验现象，理解常温下铁、铝在浓硫酸中的钝化及其应用。 4. 掌握 SO₄²⁻ 的检验方法并能说出排除干扰的理由；了解硫酸型酸雨的成因、危害与防治措施，树立绿色化学观念。 **教学重点**：SO₂ 的三重性质；浓硫酸的三大特性；SO₄²⁻ 的检验。 **教学难点**：SO₂ 中 +4 价硫「既有氧化性又有还原性」的判断与应用；SO₂ 漂白与 HClO 漂白的区别；浓硫酸与铜反应的实验分析。 **教学方法**：实验探究法、对比归纳法、情境教学法、价态分析图示法。 **教学准备**：硫粉、SO₂ 气体（或亚硫酸钠与盐酸现场制取）、品红溶液、溴水、酸性 KMnO₄ 溶液、浓硫酸、蔗糖、铜片、BaCl₂ 溶液、稀盐酸、课件与任务单。 **课时安排**：3 课时（第 1 课时：硫与二氧化硫；第 2 课时：浓硫酸三大特性与硫酸根检验；第 3 课时：SO₃、硫酸工业与酸雨防治）。

📖 课堂讲义 · 核心知识点

**一、硫单质** 硫（俗称硫黄）是淡黄色固体，质脆，不溶于水，微溶于酒精。硫的常见价态：-2（H₂S、硫化物）、0（S 单质）、+4（SO₂、H₂SO₃）、+6（SO₃、H₂SO₄）。0 价是中间价态，硫既有氧化性又有还原性。 与氧气反应：S + O₂ =（点燃）SO₂，硫在空气中燃烧发出淡蓝色火焰，在纯氧中燃烧发出明亮的蓝紫色火焰，生成有刺激性气味的气体。 与金属：2Na + S =（△）Na₂S（加热时剧烈反应）；2Cu + S =（△）Cu₂S（硫的氧化性较弱，把变价金属氧化到低价，注意 Fe 与 S 生成 FeS 而不是 Fe₂S₃）。 与氢气：H₂ + S =（△）H₂S（体现硫的弱氧化性）。 **二、二氧化硫** 物理性质：无色、有刺激性气味的有毒气体，密度比空气大，易溶于水（1 体积水约溶 40 体积 SO₂）。 SO₂ 中硫为 +4 价（中间价态），遇强氧化剂表现还原性，遇强还原剂表现氧化性： 1. 酸性氧化物通性：SO₂ + H₂O ⇌ H₂SO₃（亚硫酸，中强酸、易分解）；SO₂ + 2NaOH = Na₂SO₃ + H₂O；SO₂ + NaOH = NaHSO₃（SO₂ 过量时）。 2. 还原性（+4 → +6）：2SO₂ + O₂ ⇌（催化剂，△）2SO₃；SO₂ + Br₂ + 2H₂O = H₂SO₄ + 2HBr（使溴水褪色）；5SO₂ + 2KMnO₄ + 2H₂O = K₂SO₄ + 2MnSO₄ + 2H₂SO₄（使酸性 KMnO₄ 溶液褪色）。 3. 弱氧化性（+4 → 0）：SO₂ + 2H₂S = 3S↓ + 2H₂O（归中反应）。 4. 漂白性：与某些有色物质（如品红）化合生成不稳定的无色物质，加热或久置后恢复原色。SO₂ 不能漂白酸碱指示剂（使石蕊只变红不褪色）。 三种「褪色」辨析： | 试剂 | 使品红褪色 | 使溴水褪色 | 使石蕊变色 | |---|---|---|---| | SO₂ | 褪色，加热恢复（漂白性、化合型） | 褪色（还原性、氧化还原） | 只变红不褪色（酸性） | | 氯水 | 褪色，加热不恢复（HClO 氧化漂白） | 褪色（氧化 Cl₂ 置换 Br₂） | 先变红后褪色 | **三、三氧化硫与硫酸工业** SO₃ 是 +6 价硫的氧化物，无色固体（标况下为晶体），易溶于水，只具有酸性氧化物性质（S 已是最高价，只有氧化性）：SO₃ + H₂O = H₂SO₄。 工业制硫酸（接触法）三步：① 造气：S + O₂ =（点燃）SO₂ 或 4FeS₂ + 11O₂ =（高温）2Fe₂O₃ + 8SO₂；② 催化氧化：2SO₂ + O₂ ⇌（催化剂，△）2SO₃；③ 吸收：SO₃ + H₂O = H₂SO₄（工业上用 98.3% 浓硫酸吸收 SO₃，防止形成酸雾，再稀释）。 **四、浓硫酸的三大特性** 1. 吸水性：吸收现成的水分子（气体中、结晶水合物中的水），作干燥剂。可干燥 H₂、O₂、Cl₂、CO₂、SO₂ 等，不能干燥 NH₃（反应生成盐）、不能干燥 HI、H₂S（被氧化）。 2. 脱水性：把有机物中的 H、O 按 2:1（水的组成）脱去，属于化学变化。蔗糖中加入浓硫酸，变黑（炭化）且体积膨胀成疏松多孔的海绵状（伴随 C 与浓硫酸反应产气）。 3. 强氧化性：冷浓硫酸使 Fe、Al 钝化（生成致密氧化膜，可用铁罐、铝罐运输）；加热时氧化多数金属（Pt、Au 除外）： Cu + 2H₂SO₄（浓）=（△）CuSO₄ + SO₂↑ + 2H₂O（现象：铜溶解、产生刺激性气味气体、溶液变蓝绿——注意浓硫酸变稀后反应停止）。 C + 2H₂SO₄（浓）=（△）CO₂↑ + 2SO₂↑ + 2H₂O（浓硫酸氧化非金属单质，被还原为 SO₂）。 **五、SO₄²⁻ 的检验** 操作：先加足量稀盐酸酸化（排除 CO₃²⁻、SO₃²⁻、Ag⁺ 干扰：BaCO₃、BaSO₃ 也是白色沉淀，Ag⁺ 遇 Cl⁻ 生成 AgCl），无沉淀；再加 BaCl₂ 溶液，产生白色沉淀则含 SO₄²⁻。 原理：Ba²⁺ + SO₄²⁻ = BaSO₄↓。BaSO₄ 不溶于水和酸（故也可用作「钡餐」，而 BaCO₃ 溶于胃酸有毒）。 **六、酸雨的成因与防治** pH 小于 5.6 的降水称为酸雨。硫酸型酸雨的两条形成途径： - 液相氧化：SO₂ + H₂O ⇌ H₂SO₃，2H₂SO₃ + O₂ = 2H₂SO₄（催化剂：尘埃中的金属离子）。 - 气相氧化：2SO₂ + O₂ ⇌（催化剂/粉尘）2SO₃，SO₃ + H₂O = H₂SO₄。 危害：腐蚀建筑与文物、酸化土壤与水体、危害植物与人体健康。 防治：燃煤脱硫（石灰石-石膏法：2CaCO₃ + 2SO₂ + O₂ = 2CaSO₄ + 2CO₂）、尾气氨法吸收、开发清洁能源、减少含硫燃料使用。 **易错提醒** 1. SO₂ 使溴水、酸性 KMnO₄ 褪色是还原性，不是漂白性；使品红褪色才是漂白性。 2. 浓硫酸的吸水性与脱水性不同：吸水收「现成的水」，脱水夺「有机物中的 H 和 O」。 3. Cu 与浓硫酸反应必须加热，浓硫酸变稀后反应停止，不能说「硫酸完全反应」。 4. 检验 SO₄²⁻ 先酸化的酸只能用稀盐酸（或稀硝酸），不能用稀硫酸（引入 SO₄²⁻）。

🔍 课堂讲义 · 重点难点解析

**重点一：SO₂ 多重性质的情境判断** 例题：将 SO₂ 分别通入品红溶液、溴水、滴有酚酞的 NaOH 溶液中，各有什么现象？分别体现什么性质？ 分析：逐一判断反应类型——与品红是化合漂白，与溴水是氧化还原，与 NaOH 是酸性氧化物成盐。 解答：品红褪色，加热后恢复红色——漂白性（化合型、可逆）；溴水褪色，生成 H₂SO₄ 与 HBr——还原性（SO₂ + Br₂ + 2H₂O = H₂SO₄ + 2HBr）；酚酞的红色褪去且加热不复色——酸性氧化物与碱反应（SO₂ + 2OH⁻ = SO₃²⁻ + H₂O）。 小结：判断 SO₂ 的性质先看「与谁反应、生成什么」，褪色类问题必须区分原理，不能一律答漂白性。 **难点一：SO₂ 既是氧化剂又是还原剂的价态分析** 例题：反应 SO₂ + 2H₂S = 3S↓ + 2H₂O 中，氧化剂与还原剂是什么？氧化产物与还原产物的质量比是多少？ 分析：SO₂ 中 S 为 +4 价降至 0 价，得电子作氧化剂；H₂S 中 S 为 -2 价升至 0 价，失电子作还原剂。 解答：SO₂ 是氧化剂，H₂S 是还原剂。氧化产物与还原产物都是 S，其中 2 个 S 来自 H₂S（氧化产物），1 个 S 来自 SO₂（还原产物），质量比 2:1。 小结：同种元素不同价态「高价降、低价升」向中间价归中，称归中反应；产物比例按化合价变化计量。 **难点二：浓硫酸与铜反应的实验分析** 例题：铜片与浓硫酸共热。(1) 写出方程式；(2) 描述现象；(3) 反应一段时间后不再产生气体，原因是什么？ 分析：Cu 与浓硫酸反应被氧化为 Cu²⁺，浓硫酸被还原为 SO₂；随反应进行硫酸被消耗且生成水，浓度变稀。 解答：(1) Cu + 2H₂SO₄（浓）=（△）CuSO₄ + SO₂↑ + 2H₂O。(2) 现象：铜片溶解，产生有刺激性气味的气体，溶液逐渐变蓝（浓硫酸过量时偏绿，稀释后变蓝）。(3) 随反应进行，硫酸被消耗并生成水，浓度变稀，而稀硫酸不与铜反应，故气体停止产生——「变稀即停」是本实验的关键结论。 小结：浓硫酸的反应要关注「浓度变化」，变稀后性质改变，反应自动停止。 **易错警示：SO₄²⁻ 检验中盐酸的作用** 例题：某同学检验未知液中是否含 SO₄²⁻，先加 BaCl₂ 产生白色沉淀即下结论，错在哪里？ 解答：未排除干扰离子。若原溶液含 CO₃²⁻ 或 SO₃²⁻，会生成 BaCO₃、BaSO₃ 白色沉淀；含 Ag⁺ 则生成 AgCl 沉淀。正确做法：先加足量稀盐酸（无沉淀排除上述干扰），再加 BaCl₂ 溶液，有白色沉淀才可确认含 SO₄²⁻。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：硫的价态与性质** 题目：硫的化合价有 -2、0、+4、+6。(1) 只具有氧化性的是哪些价态？只具有还原性的是哪些价态？(2) 写出硫在纯氧中燃烧的现象与方程式。 分析：最高价只有氧化性，最低价只有还原性，中间价态两性兼有。 解答：(1) +6 价（SO₃、浓硫酸中的 S）只有氧化性；-2 价（H₂S、硫化物中的 S）只有还原性；0 价与 +4 价既有氧化性又有还原性。(2) 硫在纯氧中燃烧发出明亮的蓝紫色火焰，生成有刺激性气味的气体：S + O₂ =（点燃）SO₂。 方法小结：价态定性质——「高价氧化、低价还原、中间两性」，这是分析含硫物质反应的方向标。 **例题二（提高）：SO₂ 与氯水漂白的对比实验** 题目：将品红溶液分成两份，分别通入足量 SO₂ 和氯水，都完全褪色。再分别将两份褪色溶液加热至沸腾，现象有何不同？结论是什么？ 分析：SO₂ 漂白生成不稳定的无色物质，受热分解恢复颜色；HClO 氧化漂白破坏发色结构，不可逆。 解答：通 SO₂ 的那份加热后恢复红色（无色化合物分解，SO₂ 逸出）；通氯水的那份加热后不恢复颜色。结论：SO₂ 的漂白是化合型、暂时性、可逆的；HClO 的漂白是氧化型、永久性、不可逆的。 方法小结：「加热是否恢复红色」是区分两类漂白的标准实验方法，注意 SO₂ 使石蕊变红而不褪色也是易考细节。 **例题三（综合）：硫酸根检验与定量计算** 题目：取某工业废水 25.00 mL，先加足量稀盐酸无明显现象，再加入足量 BaCl₂ 溶液，过滤、洗涤、干燥得白色沉淀 2.33 g。(1) 写出发生反应的离子方程式；(2) 求废水中 SO₄²⁻ 的物质的量浓度（写出设、写、算、答）。 分析：先酸化排除干扰，沉淀为 BaSO₄；由 BaSO₄ 的量推 SO₄²⁻ 的量。 解答： (1) Ba²⁺ + SO₄²⁻ = BaSO₄↓（先加稀盐酸无现象，说明无 CO₃²⁻、SO₃²⁻、Ag⁺ 干扰）。 (2) 设 SO₄²⁻ 的物质的量为 x。 n(BaSO₄) = 2.33 g ÷ 233 g/mol = 0.01 mol，由 Ba²⁺ ~ SO₄²⁻ 得 x = 0.01 mol。 c(SO₄²⁻) = 0.01 mol ÷ 0.025 L = 0.4 mol/L。 答：废水中 SO₄²⁻ 的物质的量浓度为 0.4 mol/L。 方法小结：定量检验题按「检验流程定成分、沉淀质量定物质的量、体积定浓度」三步走，注意单位换算。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 硫与二氧化硫识记

  1. 1. 填空：硫俗称________，是________色固体；硫在空气中燃烧发出________色火焰，在纯氧中燃烧发出________色火焰；SO₂ 是________色、有________气味的________毒气体。
    答：俗称硫黄，淡黄色固体；空气中淡蓝色火焰，纯氧中蓝紫色火焰；SO₂ 是无色、有刺激性气味的有毒气体，易溶于水。
  2. 2. 完成方程式：(1) 硫在氧气中燃烧；(2) SO₂ 与水反应；(3) SO₂ 与 H₂S 反应；(4) SO₂ 使溴水褪色。
    答：(1) S + O₂ =（点燃）SO₂；(2) SO₂ + H₂O ⇌ H₂SO₃；(3) SO₂ + 2H₂S = 3S↓ + 2H₂O；(4) SO₂ + Br₂ + 2H₂O = H₂SO₄ + 2HBr。
  3. 3. 填空：浓硫酸的三大特性是________、________、________；常温下浓硫酸能使铁、铝________，因此可用________罐运输浓硫酸。
    答：吸水性、脱水性、强氧化性；钝化（生成致密氧化膜）；铁罐或铝罐。钝化是化学变化，氧化膜致密使反应停止。

中等 · 性质辨析与运用

  1. 1. SO₂ 使下列试剂褪色的原理分别是什么？(1) 品红溶液；(2) 溴水；(3) 酸性 KMnO₄ 溶液；(4) 滴有酚酞的 NaOH 溶液。
    答：(1) 漂白性（与品红化合成不稳定无色物，加热恢复）；(2) 还原性（SO₂ + Br₂ + 2H₂O = H₂SO₄ + 2HBr）；(3) 还原性（+4 价硫被 KMnO₄ 氧化为 +6 价）；(4) 酸性氧化物的通性（SO₂ + 2OH⁻ = SO₃²⁻ + H₂O，红色褪去，加热不复色）。
  2. 2. 某同学设计检验 Na₂SO₃ 样品中是否混有 Na₂SO₄：取样加水溶解，先加足量稀盐酸，将产生的气体通入品红溶液（褪色），至不再产生气体后再向溶液中滴加 BaCl₂ 溶液，出现白色沉淀，结论是混有 Na₂SO₄。评价该方案并说明每一步的理由。
    答：方案合理。第一步加足量稀盐酸：一是排除 CO₃²⁻ 等干扰，二是把 SO₃²⁻ 完全转化为 SO₂ 除去，防止 SO₃²⁻ 与 Ba²⁺ 生成 BaSO₃ 干扰检验；气体使品红褪色证明含 SO₃²⁻；酸化除尽 SO₃²⁻ 后再加 BaCl₂，白色沉淀只能是 BaSO₄，证明混有 SO₄²⁻。关键点：必须「先除尽 SO₃²⁻ 再检 SO₄²⁻」。
  3. 3. 实验现象描述：向装有品红溶液的试管中通入 SO₂ 至褪色，将试管在酒精灯上加热。描述整个过程的颜色变化并解释；若改通氯水再加热，现象有何不同？
    答：通 SO₂：品红红色褪去，生成不稳定的无色物质；加热后无色物质分解，SO₂ 逸出，红色恢复。改通氯水：HClO 将品红氧化破坏，红色褪去且加热后不恢复。结论：SO₂ 漂白可逆、HClO 漂白不可逆。

难 · 计算与推断

  1. 1. 计算：6.4 g 铜与 25 mL 18.4 mol/L 的浓硫酸共热充分反应（Cu + 2H₂SO₄（浓）=（△）CuSO₄ + SO₂↑ + 2H₂O）。(1) 通过计算说明哪种反应物有剩余；(2) 求标况下生成 SO₂ 的体积；(3) 求被还原的硫酸的物质的量（写出设、写、算、答）。
    答：设消耗 H₂SO₄ 为 y mol。n(Cu) = 6.4 g ÷ 64 g/mol = 0.1 mol，由 Cu ~ 2H₂SO₄ 得 y = 0.2 mol < 0.025 L × 18.4 mol/L = 0.46 mol，故硫酸过量（但因浓硫酸变稀后不再反应，实际消耗略少于 0.2 mol，按恰好概念计算）。(2) 由 Cu ~ SO₂ 得 n(SO₂) = 0.1 mol，V = 0.1 × 22.4 = 2.24 L。(3) 被还原的硫酸即进入 SO₂ 的部分，n = 0.1 mol。答：铜完全反应、硫酸有剩余；SO₂ 为 2.24 L；被还原硫酸 0.1 mol。
  2. 2. 推断：淡黄色固体 A 在氧气中燃烧生成有刺激性气味的气体 B；B 通入溴水使其褪色；B 与 H₂S 混合生成淡黄色固体 C。(1) 写出 A、B、C 的化学式；(2) 写出 A 燃烧、B 与 H₂S 反应的方程式；(3) 在 B 与 H₂S 的反应中指出氧化剂、还原剂及氧化产物与还原产物的质量比。
    答：(1) A 是 S，B 是 SO₂，C 是 S。(2) S + O₂ =（点燃）SO₂；SO₂ + 2H₂S = 3S↓ + 2H₂O。(3) SO₂ 是氧化剂（S 由 +4 降到 0），H₂S 是还原剂（S 由 -2 升到 0）；氧化产物来自 H₂S（2 个 S），还原产物来自 SO₂（1 个 S），质量比 2:1。
  3. 3. 计算：将 4.8 g 硫粉在足量氧气中完全燃烧，生成的气体全部通入 200 mL 2 mol/L 的 NaOH 溶液中。(1) 求生成 SO₂ 的物质的量；(2) 通过计算判断产物是 Na₂SO₃ 还是 NaHSO₃（写出设、写、算、答）。
    答：(1) 设生成 SO₂ 为 x mol。n(S) = 4.8 g ÷ 32 g/mol = 0.15 mol，由 S ~ SO₂ 得 x = 0.15 mol。(2) n(NaOH) = 0.2 L × 2 mol/L = 0.4 mol。n(NaOH) ÷ n(SO₂) = 0.4 ÷ 0.15 ≈ 2.67。产物判断：n(NaOH)/n(SO₂) = 2 时全为 Na₂SO₃，= 1 时全为 NaHSO₃，介于 1 与 2 之间时两者共存；此处比值大于 2，SO₂ 不足，NaOH 过量，产物为 Na₂SO₃（剩余 NaOH）。答：SO₂ 0.15 mol，产物为 Na₂SO₃ 与剩余 NaOH 的混合溶液。

综合 · 实验与工业环保

  1. 1. 实验综合：蔗糖与浓硫酸的「黑面包」实验：向小烧杯中的蔗糖加入几滴水搅拌均匀，再注入 10 mL 浓硫酸，用玻璃棒搅拌，蔗糖逐渐变黑、体积膨胀成疏松多孔的「黑面包」，并有刺激性气味气体放出。(1) 解释「变黑」「膨胀」「刺激性气体」三个现象；(2) 写出炭与浓硫酸反应的方程式；(3) 说明该实验中浓硫酸体现的性质。
    答：(1) 变黑：浓硫酸脱水性，把蔗糖中的 H、O 按 2:1 脱去使其炭化；膨胀：炭与浓硫酸反应生成大量气体（CO₂、SO₂），把炭「吹」成多孔疏松结构；刺激性气体：SO₂ 生成。(2) C + 2H₂SO₄（浓）=（△）CO₂↑ + 2SO₂↑ + 2H₂O。(3) 先体现脱水性（炭化），后体现强氧化性（与炭反应），开始放热可视为反应发生的热量来源；几滴水的作用是引发放热。
  2. 2. 工业流程：接触法制硫酸。(1) 写出三步反应的化学方程式并注明条件；(2) 为什么用 98.3% 浓硫酸吸收 SO₃ 而不用水？(3) 尾气中残留的 SO₂ 用氨水吸收，写出方程式，并说明这样处理的双重意义。
    答：(1) 造气：S + O₂ =（点燃）SO₂（或 4FeS₂ + 11O₂ =（高温）2Fe₂O₃ + 8SO₂）；催化氧化：2SO₂ + O₂ ⇌（催化剂，△）2SO₃；吸收：SO₃ + H₂O = H₂SO₄。(2) 用水吸收 SO₃ 易形成酸雾，吸收慢且腐蚀设备；98.3% 浓硫酸不形成酸雾，吸收效率高，之后可稀释得任意浓度硫酸。(3) SO₂ + 2NH₃·H₂O = (NH₄)₂SO₃ + H₂O。意义：既减少 SO₂ 排放防止酸雨，又回收硫资源制成化肥原料，一举两得。
  3. 3. 环保综合：某燃煤电厂烟气含 SO₂ 0.2 mol，采用石灰石-石膏法脱硫，总反应为 2CaCO₃ + 2SO₂ + O₂ = 2CaSO₄ + 2CO₂。(1) 求理论上消耗 CaCO₃ 的质量（写出设、写、算、答）；(2) 说明酸雨的危害（至少两条）；(3) 提出两条个人与社会层面的减排措施。
    答：(1) 设消耗 CaCO₃ 为 x mol。由 2CaCO₃ ~ 2SO₂ 知 n(CaCO₃) = n(SO₂) = 0.2 mol，m = 0.2 × 100 = 20 g。答：消耗 CaCO₃ 20 g。(2) 危害：腐蚀大理石建筑与金属设施、破坏文物；酸化湖泊土壤，危害水生生物与农作物；刺激呼吸道危害人体健康。(3) 措施：社会层面——燃煤脱硫、推广清洁能源、工厂尾气处理达标排放；个人层面——节约用电、绿色出行减少化石燃料消耗。

💬 课后反馈

**学生常见错误** 1. SO₂ 的「褪色」张冠李戴：把使溴水、酸性 KMnO₄ 褪色说成漂白性，本质是没建立「氧化还原褪色」与「化合漂白」两类原理的区分框架。 2. 浓硫酸吸水性与脱水性混淆：把蔗糖炭化说成吸水性，把干燥剂的作用说成脱水性；对「吸现成的水、夺化合态的 H 和 O」理解不透。 3. Cu 与浓硫酸反应的细节丢失：不写加热条件、不标 ↑、忽略「浓硫酸变稀后反应停止」，计算时误按稀硫酸也能反应处理。 4. SO₄²⁻ 检验流程不完整：省略「先加稀盐酸」步骤或说不出排除哪些干扰（CO₃²⁻、SO₃²⁻、Ag⁺），酸化时误用稀硫酸。 **教学改进建议** 1. 建立硫的价态三角图（-2、0、+4、+6），把每个价态的代表性物质与反应填进图里，用「价态定性质」统领全章。 2. 漂白专题用三组对比实验（SO₂、氯水、活性炭）加「加热是否复原」检验，当堂形成结论表格，一表防混淆。 3. SO₄²⁻ 检验训练完整表述模板：「取样——加足量稀盐酸（排除××干扰）——无沉淀——加 BaCl₂ 溶液——白色沉淀——结论」，逐步内化为规范答题语言。 **分层辅导建议** - 基础层：过关硫及其化合物的重要方程式与颜色、现象记忆。 - 提高层：强化 SO₂ 多重性质的情境判断、浓硫酸特性归类和 SO₄²⁻ 检验方案设计。 - 拓展层：完成硫酸与变价金属的计算、混合物判断计算（NaOH 与 SO₂ 比例问题）和工业流程题。 **给家长的建议** 1. 孩子复习时可以请其讲解「为什么 SO₂ 使品红褪色加热能恢复，而氯水不能」，讲清原理比背结论有效。 2. 结合生活讨论酸雨：雨后观察建筑物、大理石雕像被腐蚀的图片或新闻，引导孩子用本章知识解释成因与防治。
