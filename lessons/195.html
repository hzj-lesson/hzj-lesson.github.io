初中七年级数学《平面直角坐标系》教案

初中七年级数学平面直角坐标系

📝 备课方案

**教学目标** 1. 理解平面直角坐标系的组成，会确定点的坐标。 2. 掌握各象限内及坐标轴上点的坐标特征。 3. 掌握关于坐标轴、原点对称的点的坐标关系及坐标平移规律。 **教学重点**：点的坐标与图形位置的对应关系。 **教学难点**：坐标平移规律与对称坐标的灵活运用。 **教学方法**：数轴类比引入、方格纸操作、规律归纳。 **课时安排**：2 课时

📖 课堂讲义 · 核心知识点

**一、平面直角坐标系的构成** - 两条互相垂直、原点重合的数轴组成平面直角坐标系。 - 水平的叫 x 轴（横轴，向右为正），竖直的叫 y 轴（纵轴，向上为正），交点叫原点 O。 - 坐标平面被坐标轴分成四个象限，按逆时针依次为第一、二、三、四象限。 - 坐标轴上的点不属于任何象限。 **二、点的坐标** - 过点 P 分别作 x 轴、y 轴的垂线，垂足对应的数 a、b 组成有序数对 $(a,b)$。 - 横坐标在前，纵坐标在后。如 $P(3,-2)$ 表示横坐标为 3、纵坐标为 -2。 - 坐标平面内的点与有序实数对一一对应。 **三、各象限及坐标轴上点的坐标特征** - 第一象限：$(+,+)$；第二象限：$(-,+)$；第三象限：$(-,-)$；第四象限：$(+,-)$。 - x 轴上点：纵坐标为 0，记为 $(a,0)$；y 轴上点：横坐标为 0，记为 $(0,b)$。 - 原点：$(0,0)$。 **四、点到坐标轴的距离** - 点 $P(x,y)$ 到 x 轴的距离是 $|y|$，到 y 轴的距离是 $|x|$。 - 到原点的距离为 $\\sqrt{x^2+y^2}$。 **五、对称点的坐标关系** - 关于 x 轴对称：横坐标相同，纵坐标互为相反数：$(x,y)\rightarrow(x,-y)$。 - 关于 y 轴对称：纵坐标相同，横坐标互为相反数：$(x,y)\rightarrow(-x,y)$。 - 关于原点对称：横、纵坐标都互为相反数：$(x,y)\rightarrow(-x,-y)$。 **六、坐标系中的平移** - 点 $(x,y)$ 向右平移 a 个单位：$(x+a,y)$；向左平移 a 个单位：$(x-a,y)$。 - 点 $(x,y)$ 向上平移 b 个单位：$(x,y+b)$；向下平移 b 个单位：$(x,y-b)$。 - 图形平移：所有点的横（纵）坐标作相同变化，图形形状大小不变。 ![平面直角坐标系](/images/coordinate.svg)

🔍 课堂讲义 · 重点难点解析

**重点：由点定坐标、由坐标定点** 确定点的坐标：先过点作 x 轴的垂线读横坐标，再过点作 y 轴的垂线读纵坐标。由坐标描点：先找横坐标位置，再找纵坐标位置，交点即为所求。强调"横坐标在前、纵坐标在后"的书写顺序，防止写反。 **难点一：象限符号规律** 学生易混淆第二象限（横负纵正）与第四象限（横正纵负）。可通过在坐标系中标记四个象限的符号组合记忆，或借助"坐标轴分界、正负看方向"的口诀，并多描点练习。 **难点二：平移与对称的坐标变化混淆** 关于 x 轴对称是"纵变横不变"，关于 y 轴对称是"横变纵不变"，关于原点对称是"都变"；左右平移变横坐标（左减右加），上下平移变纵坐标（下减上加）。列表对比记忆效果更好。 **迷你示例**：点 $A(2,-3)$ 关于 x 轴对称点为 $(2,3)$，关于 y 轴对称点为 $(-2,-3)$，关于原点对称点为 $(-2,3)$，向右平移 4 个单位为 $(6,-3)$。

✏️ 课堂讲义 · 典型例题精讲

**例1**：指出点 $A(3,2)$、$B(-1,4)$、$C(-2,-3)$、$D(5,-1)$、$E(0,4)$ 分别在哪一象限或坐标轴上。 解：A 在第一象限；B 在第二象限；C 在第三象限；D 在第四象限；E 横坐标为 0，在 y 轴上。 关键：看横纵坐标符号，横纵为 0 则在坐标轴上。 **例2**：点 $P(2a-4,a+1)$ 在 x 轴上，求 a 的值及点 P 的坐标。 解：x 轴上点的纵坐标为 0，所以 $a+1=0$，$a=-1$，横坐标 $2a-4=2\times(-1)-4=-6$，所以 $P(-6,0)$。 关键：坐标轴上的点坐标特征：x 轴上纵坐标为 0。 **例3**：点 $A(2,3)$ 关于 x 轴对称的点为 $B$，点 $B$ 关于 y 轴对称的点为 $C$，求点 C 的坐标。 解：$A(2,3)$ 关于 x 轴对称得 $B(2,-3)$（横不变，纵取反）；$B(2,-3)$ 关于 y 轴对称得 $C(-2,-3)$（横取反，纵不变）。 关键：连续对称逐次代入，横、纵坐标按要求取相反数。 **例4**：将点 $P(-2,5)$ 先向上平移 3 个单位，再向左平移 2 个单位，求新点坐标。 解：向上平移 3 个单位：$(-2,5)\rightarrow(-2,5+3)=(-2,8)$；再向左平移 2 个单位：$(-2,8)\rightarrow(-2-2,8)=(-4,8)$。 关键：上下平移变纵坐标（上加下减），左右平移变横坐标（左减右加）。 **例5**：点 $P(a,b)$ 到 x 轴的距离为 3，到 y 轴的距离为 4，且 $a>0$、$b<0$，求点 P 的坐标。 解：到 x 轴距离 $|b|=3$，到 y 轴距离 $|a|=4$。又 $a>0$、$b<0$，所以 $a=4$，$b=-3$，点 P 坐标为 $(4,-3)$。 关键：距离取绝对值，结合象限符号确定具体数值。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念辨析

  1. 1. 说出点 $A(1,2)$、$B(-3,5)$、$C(-4,-1)$、$D(2,-6)$ 各在第几象限。
    答：A：横正纵正，第一象限；B：横负纵正，第二象限；C：横负纵负，第三象限；D：横正纵负，第四象限。
  2. 2. 原点 O 的坐标是什么？它属于哪个象限？
    答：原点坐标为 $(0,0)$，原点不属于任何象限，它是两条坐标轴的交点。

中等 · 对称与平移

  1. 1. 写出点 $P(3,-4)$ 关于 x 轴、y 轴、原点对称的点的坐标。
    答：关于 x 轴对称：$(3,4)$（横不变纵取反）；关于 y 轴对称：$(-3,-4)$（横取反纵不变）；关于原点对称：$(-3,4)$（横纵都取反）。
  2. 2. 将点 $A(-1,2)$ 向右平移 4 个单位后得到 $A'$，求 $A'$ 的坐标，再向下平移 3 个单位得 $A''$，求 $A''$。
    答：向右平移 4 个单位：$(-1,2)\rightarrow(-1+4,2)=(3,2)$；再向下平移 3 个单位：$(3,2)\rightarrow(3,2-3)=(3,-1)$。所以 $A'(3,2)$，$A''(3,-1)$。

难 · 坐标特征应用

  1. 1. 若点 $M(m-1,m+2)$ 在第二象限，求 m 的取值范围。
    答：第二象限横坐标为负、纵坐标为正，即 $m-1<0$ 且 $m+2>0$。由 $m-1<0$ 得 $m<1$，由 $m+2>0$ 得 $m>-2$，所以 $-2<m<1$。
  2. 2. 若点 $P(3a-6,a+2)$ 在 x 轴上方，且到 x 轴的距离为 3，求 a 的值及点 P 的坐标。
    答：点到 x 轴距离为 $|a+2|=3$，所以 $a+2=3$ 或 $a+2=-3$，得 $a=1$ 或 $a=-5$。当 $a=1$ 时 $P(-3,3)$，在 x 轴上方，符合；当 $a=-5$ 时 $P(-21,-3)$，纵坐标为负，在 x 轴下方，不符合题意舍去。所以 $a=1$，$P(-3,3)$。

综合 · 综合应用

  1. 1. 已知点 $A(0,0)$、$B(4,0)$、$C(4,3)$、$D(0,3)$，判断四边形 ABCD 的形状，并求其面积。
    答：AB 在 x 轴上长 4，DC 在直线 $y=3$ 上长 4，AD 在 y 轴上长 3，BC 在直线 $x=4$ 上长 3，且 AB 垂直 AD，故 ABCD 是长方形。面积 $=4\times3=12$。
  2. 2. 已知点 $A(1,1)$、$B(5,1)$、$C(5,4)$，求三角形 ABC 的面积；若将三角形 ABC 向右平移 3 个单位，求三个顶点的坐标。
    答：$A(1,1)$、$B(5,1)$ 在同一水平线上，底边 $AB=5-1=4$；点 C 到 AB 的距离为纵坐标差 $4-1=3$，所以面积 $S=\\frac{1}{2}\times4\times3=6$。向右平移 3 个单位，横坐标加 3、纵坐标不变，得 $A'(4,1)$、$B'(8,1)$、$C'(8,4)$。

💬 课后反馈

平面直角坐标系是数形结合的桥梁，核心是"点"与"有序数对"的一一对应。学生需熟练各象限符号特征、对称与平移的坐标变化规律，并会求点到坐标轴的距离。教学中宜让学生在方格纸上动手描点连线，直观感受图形与坐标的关系，为后续函数学习奠定基础。
