小学二年级科学《磁铁》教案

小学二年级科学磁铁

📝 备课方案

**教学目标** 1. 通过观察和实验认识磁铁的性质：磁铁能吸引铁一类材料制成的物体，磁铁有两个磁极。 2. 通过实验发现磁极间"同极相斥、异极相吸"的规律，知道指南针是利用磁铁指示方向的。 3. 能用磁铁识别物体是否含铁，能利用磁铁的性质解决简单的实际问题（如分离混合物、找失落的钢针）。 4. 在探究活动中培养"先猜想、再实验、后结论"的科学态度，体验合作与分享的快乐。 **教学重点**：磁铁能吸引铁制品；磁铁有 N、S 两个磁极以及同极相斥、异极相吸的规律。 **教学难点**：通过实验发现磁极间的相互作用规律；理解磁铁指示南北方向的原理。 **教学方法**：猜想—实验—结论三步探究法、小组合作、游戏化体验。 **教学准备**：条形磁铁、U 形磁铁、环形磁铁（每组若干）、铁钉、回形针、铜丝、铝片、塑料片、木块、指南针、水槽（漂浮实验用）。 **课时安排**：2 课时（第 1 课时：磁铁能吸什么；第 2 课时：磁极与磁极间的相互作用）

📖 课堂讲义 · 核心知识点

**一、磁铁能吸什么** - 磁铁能吸引**铁**、**镍**、**钴**等材料制成的物体，生活中最常见的是吸铁制品。 - 实验发现：磁铁能吸铁钉、回形针、铁片；不能吸铜丝、铝片、塑料片、木块、纸片。 - **注意**：磁铁不能吸引所有的金属。铜、铝等金属，磁铁吸不起来。 **二、磁铁的形状** 磁铁有很多形状：条形磁铁、U 形磁铁（马蹄形）、环形磁铁、圆柱形磁铁、磁针等。无论什么形状，磁铁都有磁极。 **三、磁极** - 磁铁上磁性**最强**的部分叫**磁极**，每个磁铁都有**两个磁极**，在磁铁的两端。 - 条形磁铁的两端磁性最强，中间磁性最弱（用回形针可以验证：两端能吸很多个，中间几乎吸不住）。 - 磁极用字母表示：**N 极**（北极，指北的一端）和 **S 极**（南极，指南的一端）。 **四、磁极间的相互作用（重要）** 用两块磁铁相互靠近，会看到： - **同极相斥**：N 对 N、S 对 S，相互排斥（推开）。 - **异极相吸**：N 对 S，相互吸引（吸住）。 - 这是磁铁最重要的规律，可以用小实验验证：让一块磁铁漂浮在水面（或用绳子吊起来），另一块靠近它。 **五、磁铁能指示方向** - 可以自由转动的磁针（如指南针里的磁针），静止时**一端指南、一端指北**。 - **指南针**就是利用磁铁指示方向的原理制成的，是我国古代的四大发明之一。 - 使用指南针：把指南针放平，等磁针静止，红色一端（N 极）指北，白色一端（S 极）指南。 **六、生活中的磁铁** | 物品 | 磁铁的作用 | |---|---| | 冰箱门 | 门封条里有磁条，帮助关紧 | | 文具盒 | 磁铁吸住盒盖 | | 扬声器（喇叭） | 用磁铁产生声音 | | 指南针 | 指示方向 | | 磁悬浮列车 | 利用"同极相斥"让列车浮起来 | **七、爱护磁铁** 磁铁怕摔、怕高温、怕靠近强磁场（如电视机、银行卡），要轻拿轻放，用完单独存放。

🔍 课堂讲义 · 重点难点解析

**重点一：磁铁能吸什么（实验探究）** - 例题：桌上有一堆材料：铁钉、铜钥匙、铝片、塑料尺、回形针、橡皮。用磁铁靠近，哪些能被吸起来？ 分析：用磁铁逐个靠近，观察是否被吸引。 解答：铁钉、回形针能被吸起来；铜钥匙、铝片、塑料尺、橡皮不能被吸起来。 小结：磁铁能吸铁一类材料，不能吸铜、铝、塑料、橡胶等。判断"能不能被磁铁吸"，最好的办法就是做实验试一试。 **重点二：磁铁两端磁性最强** - 例题：怎样证明条形磁铁的中间磁性最弱？ 分析：把磁铁水平放置，从一端到另一端依次靠近回形针，数一数各位置能吸起几枚。 解答：两端能吸起很多回形针，中间几乎吸不起来，说明两端磁性最强、中间最弱。 小结：磁极（两端）磁性最强，这就是磁铁两端叫磁极的原因。 **难点一：同极相斥、异极相吸** - 例题：把两块条形磁铁的同名磁极（N 对 N）相互靠近，会怎样？不同名磁极（N 对 S）靠近呢？ 分析：用绳子吊起一块磁铁，另一块分别用 N 端、S 端靠近它的 N 端观察。 解答：N 对 N 相互排斥（推开），N 对 S 相互吸引（吸在一起）。 小结：记住规律"同极相斥、异极相吸"，这是判断磁极的依据。 **难点二：磁铁指示方向** - 例题：把一块条形磁铁用绳子吊起来，让它自由转动，静止后它的两端各指向哪里？ 分析：磁铁能指示南北，是因为地球本身是一个大磁体。 解答：静止后，磁铁的一端指南（S 极），另一端指北（N 极）。 小结：可以自由转动的磁铁，静止时总是一端指南、一端指北，指南针就是利用这个原理。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（磁铁能吸什么）** 小华想把混在一起的铁屑和木屑分开，用磁铁行吗？怎么分？ - 分析：磁铁能吸铁，不能吸木头。 - 解答：行。用磁铁靠近混合物，铁屑被吸到磁铁上，木屑留在原处，就可以分开了。 - 方法小结：利用磁铁"吸铁不吸其他材料"的性质，可以分离铁与其他材料的混合物。 **例题 2（磁极间的相互作用）** 一块条形磁铁的 A 端和另一块的 B 端相互吸引，说明 A 端和 B 端是什么极？为什么？ - 分析：磁极间"异极相吸"，能吸引说明是不同名磁极。 - 解答：A 端和 B 端是不同名磁极（一个 N 极一个 S 极）。 - 方法小结：看见"相吸"就想到"异极"，看见"相斥"就想到"同极"。 **例题 3（磁铁指示方向）** 在野外迷路了，身边只有一个可以自由转动的磁针，怎样判断方向？ - 分析：磁针静止后一端指南、一端指北。 - 解答：把磁针水平放置并让它自由转动，等它静止，指南的一端是南方，指北的一端是北方。 - 方法小结：磁铁能指示南北方向，这是指南针能指引方向的原因。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 磁铁能吸什么

  1. 1. 磁铁能吸引（ ）一类材料制成的物体。
    答：铁（还有镍、钴）。
  2. 2. 下面哪些物体能被磁铁吸起来？铁钉、铜钥匙、回形针、塑料尺。
    答：铁钉、回形针。
  3. 3. 判断：磁铁能吸引所有的金属。（ ）
    答：错误。磁铁不能吸铜、铝等金属。

中等 · 磁极的认识

  1. 1. 磁铁上磁性最强的部分叫（ ），每个磁铁都有（ ）个磁极。
    答：磁极；两（N 极和 S 极）。
  2. 2. 条形磁铁哪部分磁性最强？哪部分最弱？
    答：两端（磁极）最强，中间最弱。
  3. 3. 指南针红色一端指向哪个方向？
    答：北方（N 极指北）。

难 · 磁极的相互作用

  1. 1. 两块磁铁 N 极和 N 极靠近，会怎样？N 极和 S 极靠近呢？
    答：N 对 N 相互排斥（同极相斥）；N 对 S 相互吸引（异极相吸）。
  2. 2. 一块磁铁能吸住另一块磁铁，说明这两块磁铁靠近的两端是什么极？
    答：不同名磁极（一个 N 极一个 S 极），因为异极相吸。
  3. 3. 把一块条形磁铁用绳子吊起来自由转动，静止后它会怎样？
    答：一端指南、一端指北（S 极指南、N 极指北），因为地球是个大磁体。

综合 · 生活中的磁铁

  1. 1. 生活中哪些地方用到了磁铁？至少写出三处。
    答：示例：冰箱门封条、文具盒盖、喇叭、指南针、磁悬浮列车、门吸。写出三处合理答案即可。
  2. 2. 妈妈缝衣服时把一根钢针掉在地毯里，用眼睛找不到，你有什么好办法？
    答：用磁铁在地毯上来回移动，钢针会被磁铁吸起来。利用磁铁能吸铁的性质。
  3. 3. 磁悬浮列车为什么能"浮"在轨道上？用磁铁的知识解释。
    答：利用磁铁"同极相斥"的原理，列车底部和轨道上的磁铁同名磁极相对，相互排斥，把列车托起来。

💬 课后反馈

**学生常见错误** 1. 误以为磁铁能吸所有金属，把铜钥匙、铝片也当成"能被吸"。 2. 认为磁铁中间也有磁极，不知道磁极在两端、中间磁性最弱。 3. 把"同极相斥、异极相吸"记反，需要动手实验反复验证。 4. 用磁铁时用力摔打、靠近手机和银行卡，损坏磁铁也损坏物品。 **教学改进建议** 1. 一定要让学生亲手做"吸一吸"实验，用真实材料纠正"磁铁吸所有金属"的错误前概念。 2. 用"吊起来的磁铁"做演示，现象直观，学生容易记住"同斥异吸"。 3. 结合指南针介绍我国古代四大发明，渗透科学史教育。 **分层辅导** - 基础弱：只要求掌握"吸铁、有南北极、同斥异吸"三个核心结论。 - 学有余力：探究"隔着纸、水磁铁还能吸铁吗"，认识磁力可以穿透一些材料。 **给家长的建议** 家里的冰箱贴、文具盒磁扣都是现成的教具。可以和孩子玩"找一找家里哪里有磁铁"的游戏，再试试"隔着纸能吸住回形针吗"。
