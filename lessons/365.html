小学四年级数学《大数的认识》教案

小学四年级数学大数的认识

📝 备课方案

**教学目标** 1. 认识亿以内和亿以上的数，理解数位、数级、计数单位等概念，掌握十进制计数法。 2. 能正确读、写大数，会比较两个大数的大小。 3. 会把整万、整亿的数改写成用"万"或"亿"作单位的数，能运用"四舍五入"法求一个大数的近似数。 4. 在观察、操作、交流中感受大数与现实生活的联系，培养数感，增强学习数学的兴趣和自信心。 **教学重点**：掌握多位数的读法和写法，正确理解数位顺序表。 **教学难点**：中间或末尾有 0 的多位数的读写；用"四舍五入"法求近似数。 **教学方法**：情境教学法、讲解示范法、小组合作探究法。 **教学准备**：多媒体课件、数位顺序表挂图、计数器演示软件、我国人口普查数据资料、学生用数位卡片。 **课时安排**：本单元共 6 课时。其中亿以内数的认识 3 课时，亿以上数的认识 2 课时，整理和复习 1 课时。本课为第 1 课时，完成亿以内数的读法和写法教学。

📖 课堂讲义 · 核心知识点

一、计数单位与数位 1. 计数单位：用来计数的单位有"个、十、百、千、万、十万、百万、千万、亿……"。每相邻两个计数单位之间的进率都是 10，这种计数方法叫"十进制计数法"。 2. 数位：计数单位所占的位置叫作数位，如"千位"表示有几个千，"亿位"表示有几个亿。同一个数字所在的数位不同，表示的大小也不同：数字 5 在千位上表示 5 个千，在千万位上就表示 5 个千万。 3. 数位与计数单位的区别：数位是"位置"，计数单位是"大小"。"个位"是一个数位，"个"是一个计数单位，两者不能混为一谈。 二、数位顺序表与数级 按照我国计数的习惯，从右往左每四个数位是一级，分为个级、万级和亿级。 | 数级 | 亿级 | | | | 万级 | | | | 个级 | | | | |------|------|--|--|--|------|--|--|--|------|--|--|--| | 数位 | 亿位 | 千万位 | 百万位 | 十万位 | 万位 | 千位 | 百位 | 十位 | 个位 | | | | | 计数单位 | 亿 | 千万 | 百万 | 十万 | 万 | 千 | 百 | 十 | 个 | | | | 个级表示多少个一，万级表示多少个万，亿级表示多少个亿，读数和写数都按级进行。 三、多位数的读法 1. 读数前先分级：从个位起，每四个数位分一级，可以用竖线隔开。 2. 从高位读起，亿级、万级的数要按个级的读法来读，再在后面加"亿"字或"万"字。 3. 每级末尾不管有几个 0 都不读；其他数位上有一个 0 或连续几个 0，都只读一个"零"。 例如：64010000 分级为 6401｜0000，读作"六千四百零一万"。 四、多位数的写法 1. 从高位写起，先写亿级，再写万级，最后写个级。 2. 哪一个数位上一个单位也没有，就在那一位上写 0 占位。 例如：写"三百零五万四千"是 3054000。 五、大数的大小比较 1. 位数不同时，位数多的数就大。 2. 位数相同时，从最高位比起，逐位比较，最高位上的数大的数就大。 六、改写与省略 1. 改写成用"万"作单位的数：整万的数，去掉末尾的 4 个 0，再写一个"万"字。例如 3600000 等于 360 万。 2. 改写成用"亿"作单位的数：整亿的数，去掉末尾的 8 个 0，再写一个"亿"字。例如 1300000000 等于 13 亿。 3. 用"四舍五入"法求近似数：先确定省略哪一位后面的尾数，再看尾数最高位上的数字，小于或等于 4 就舍去，大于或等于 5 就向前一位进 1。 七、易错提醒 1. 写数时漏写占位的 0，如把"三千零五十"写成 350，正确是 3050。 2. 读数时把每级中间的连续 0 读成两个"零"，实际只读一个。 3. 改写是精确值，用等号连接；求近似数是近似值，用"约等于"连接，两者不可混淆。

🔍 课堂讲义 · 重点难点解析

难点一：数位与计数单位、十进制计数法 分析：学生容易把"数位"与"计数单位"混为一谈，也不理解为什么"十万"和"万"之间的进率是 10。 解答：借助计数器演示，万位上满 10 颗珠子就向十万位进 1，直观看出十个一万是十万，从而得出每相邻两个计数单位之间的进率都是 10。 小结：数位顺序表是读数和写数的"地图"，要多读多记；相邻计数单位进率是 10，这是"十进制计数法"的核心。 重点一：含 0 的多位数的读写 分析：学生知道"0 不读"和"0 要读"，但分不清 0 在末尾还是中间。例如 40020000 与 40020003，前者末尾的 0 不读，后者中间的 0 要读。 解答：40020000 分级为 4002｜0000，读作"四千零二万"，个级四个 0 全在末尾，都不读；40020003 分级为 4002｜0003，读作"四千零二万零三"。 小结：读大数先分级，再看 0 的位置——每级末尾的 0 不读，每级中间的 0 只读一个零。 难点二：用"四舍五入"法求近似数 分析：学生常把"改写"和"省略"混为一谈，或在省略万位后面的尾数时看错位数。 解答：先明确要求。改写要求是整万数，直接去掉 4 个 0 加"万"字；省略万位后面的尾数，先找到万位，再看千位上的数字决定舍去还是进一。例如 6452000 省略万位后面的尾数，万位是 5，千位是 2，应舍去，约等于 645 万。 小结：改写求的是精确值，用等号；省略求的是近似值，用约等号。判断标准永远是"尾数最高位"上的数字。

✏️ 课堂讲义 · 典型例题精讲

例题一：读出下面各数。 据第七次全国人口普查，我国人口总数约为 1411780000 人，请你把这个数读出来。 分析：读数要先分级，这个数有十位数，说明含有亿级，应分为亿级、万级和个级三级。 解答：1411780000 分级为 14｜1178｜0000。亿级是 14，读作"十四亿"；万级是 1178，读作"一千一百七十八万"；个级是 0000，末尾的 0 都不读。这个数读作"十四亿一千一百七十八万"。 方法小结：读大数先分级再读数，亿级和万级的数按个级的方法读，读完加上"亿"或"万"字，每级末尾的 0 不读。 例题二：写出下面各数。 （1）三千零八十五万零六 （2）五亿零二十万 分析：写数要按级来写，哪一位上一个单位也没有，就用 0 占位。 解答：（1）三千零八十五万，万级写作 3085；个级是"零六"，写作 0006。合起来是 30850006。 （2）亿级写 5，万级"零二十万"写作 0020，个级没有单位写 0000。合起来是 500200000。 方法小结：写数先想清楚每个数级分别是几，再逐级书写，0 占位要写够位数，写完可分级检查。 例题三：改一改、省一省。 某省在校小学生约有 7264000 人。（1）省略万位后面的尾数，求出近似数；（2）如果该省在校小学生恰好是 7260000 人，把它改写成用"万"作单位的数。 分析：第（1）问是求近似数，要看万位后面的千位；第（2）问是整万数的改写，直接去 0 加"万"字。 解答：（1）7264000 的万位是 6，千位是 4，舍去，约等于 726 万。 （2）7260000 去掉末尾 4 个 0，等于 726 万。 方法小结：省略尾数看"尾数最高位"四舍五入，改写直接去掉 0 加"万"字；两者结果相同但意义不同，一个精确一个近似。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 读数写数基本功

  1. 1. 读出下面各数：5008000、900700800。
    答：5008000 读作五百万八千；900700800 读作九亿零七十万零八百。
  2. 2. 写出下面各数：四千万、三百零六万四千。
    答：四千万写作 40000000；三百零六万四千写作 3064000。
  3. 3. 用 1、3、5、8 和四个 0 组成一个最大的八位数和一个最小的八位数。
    答：最大的八位数：85310000；最小的八位数：10003568。

中等 · 写数与比较大小

  1. 1. 把下列各数改写成用"万"作单位的数：2400000、8050000。
    答：2400000 等于 240 万；8050000 等于 805 万。
  2. 2. 比较大小，填上大于号、小于号或等号：99999 ○ 100000；8 万 ○ 80000。
    答：99999 小于 100000（位数少）；8 万等于 80000。
  3. 3. 一个数由 5 个千万、3 个十万和 4 个百组成，这个数写作多少？读作什么？
    答：写作 50300400，读作五千零三十万零四百。

难 · 四舍五入求近似数

  1. 1. 省略万位后面的尾数：274600、3050900、5999900。
    答：274600 约等于 27 万（千位是 4，舍去）；3050900 约等于 305 万（千位是 0）；5999900 约等于 600 万（千位是 9，向万位进 1）。
  2. 2. 括号里最大能填几：39（ ）000 约等于 39 万。
    答：千位上的数必须舍去，只能是 0 到 4，最大填 4。
  3. 3. 一个数省略万位后面的尾数后约是 8 万，这个数最大是多少？最小是多少？
    答：最大是 84999（千位是 4，舍去）；最小是 75000（千位是 5，向前进 1）。

综合 · 生活中的大数

  1. 1. 2023 年我国粮食总产量约 69541 万吨，省略亿位后面的尾数约是多少亿吨？
    答：69541 万吨等于 695410000 吨，亿位是 6，千万位是 9，进 1，约等于 7 亿吨。
  2. 2. 我国的陆地面积约 960 万平方千米。横线上的数是近似数还是精确数？为什么？
    答：是近似数。国土面积很难精确测量，题干用"约"字表示，是经过四舍五入得到的近似数。
  3. 3. 用 5、6、7 和 5 个 0 组成一个只读一个零的八位数，至少写出两个。
    答：答案不唯一，如 56000007（五千六百万零七）、60000057（六千万零五十七）、70000056（七千万零五十六）。

💬 课后反馈

一、常见错误 1. 分级不熟练，读、写大数时漏级或错级，例如把"十二万零五百"写成 120500。 2. 0 的读写规则混淆：每级中间的连续 0 只读一个零，末尾的 0 不读，个别学生会多读或漏读。 3. 写数时占位 0 漏写，导致位数不足。 4. 改写与省略不分，错把近似值当精确值。 二、教学改进建议 1. 多让学生上黑板分级演示，把"先分级、再读写"变成习惯动作。 2. 设计"0 的读写"专项对比练习，集中辨析。 3. 用"改错诊断"形式，把典型错误编成判断题，全班一起找错因。 三、分层辅导 对学困生：放慢速度，借助数位顺序表逐级读写，先会"四位一级"再提高速度。 对学优生：增加改写与省略的对比练习，鼓励用大数数据编题互测。 四、给家长的建议 1. 平时多带孩子看新闻中的数据，如人口数、城市里程数，让孩子试着读一读。 2. 检查作业时重点关注 0 的处理和分级是否正确。 3. 让孩子把"四舍五入"的规则说给你听，能说清楚才算真正掌握。
