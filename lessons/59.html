初中九年级化学《常见的碱》教案

初中九年级化学常见的碱

📝 备课方案

**教材分析** 本节学习两种常见碱——氢氧化钠与氢氧化钙，掌握碱的通性（与指示剂、非金属氧化物、酸反应）、特性（NaOH 潮解与变质、Ca(OH)₂ 的制取）及用途，是"酸、碱、盐"核心内容。 **教学目标** 1. 掌握 NaOH、Ca(OH)₂ 的俗名、物理性质与化学性质（与指示剂、CO₂、酸反应的方程式）。 2. 理解碱的通性源于 $OH^-$，会用化学方程式描述典型反应。 3. 知道 NaOH 易潮解变质需密封保存，Ca(OH)₂ 由 CaO 与水制得（生石灰→熟石灰）。 **教学重点** 两种碱的性质、化学方程式；碱的通性。 **教学难点** NaOH 与 CO₂ 反应无明显现象的判断；Ca(OH)₂ 的制取与用途；碱溶液使指示剂变色。 **课时** 2 课时 **教学过程** 实物观察→NaOH 性质实验→Ca(OH)₂ 性质→通性归纳→方程式书写→保存与用途。

📖 课堂讲义 · 核心知识点

**一、氢氧化钠 NaOH（火碱/烧碱/苛性钠）** - 物理性质：白色固体，易溶于水且溶解放热；强腐蚀性；暴露空气易吸收水分而潮解（作干燥剂）。 - 与指示剂：水溶液使紫色石蕊试液变蓝，使无色酚酞试液变红。 - 与酸（中和）：NaOH + HCl = NaCl + H₂O；2NaOH + H₂SO₄ = Na₂SO₄ + 2H₂O。 - 与非金属氧化物（酸性氧化物）： 2NaOH + CO₂ = Na₂CO₃ + H₂O 2NaOH + SO₂ = Na₂SO₃ + H₂O - 制取：Na₂CO₃ + Ca(OH)₂ = CaCO₃↓ + 2NaOH（工业制 NaOH）。 - 保存：密封！因易潮解且吸收 CO₂ 变质（生成 Na₂CO₃）。 **二、氢氧化钙 Ca(OH)₂（熟石灰/消石灰）** - 物理性质：白色粉末，微溶于水，其水溶液称"石灰水"，溶解度随温度升高而减小。 - 与指示剂：使石蕊变蓝、酚酞变红。 - 与酸：Ca(OH)₂ + 2HCl = CaCl₂ + 2H₂O。 - 与非金属氧化物：Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O（石灰水变浑浊，检验 CO₂）。 - 制取（生石灰加水）：CaO + H₂O = Ca(OH)₂（剧烈放热，生石灰→熟石灰）。 - 用途 ：改良酸性土壤；建筑材料（石灰浆）；配制波尔多液；消毒。 **三、碱的通性（本质：在水溶液中解离出 OH⁻）** 1. 使酸碱指示剂变色（石蕊蓝、酚酞红）。 2. 与酸发生中和反应生成盐和水。 3. 与某些非金属氧化物（CO₂、SO₂）反应生成盐和水。 注意：不溶性碱（如 Cu(OH)₂）一般不与盐反应，通性主要针对可溶性碱溶液。 **四、常见易错** - NaOH 俗名三写：烧碱、火碱、苛性钠；Ca(OH)₂：熟石灰、消石灰。 - 检验 CO₂ 用澄清石灰水（变浑浊），吸收/除去 CO₂ 用 NaOH 溶液（反应无明显现象但更彻底）。

🔍 课堂讲义 · 重点难点解析

**难点一：NaOH 与 CO₂ 反应"看不见"怎么办** 2NaOH + CO₂ = Na₂CO₃ + H₂O 无沉淀气体，肉眼难判断。检验方法：①加稀盐酸，若产生使澄清石灰水变浑浊的气体（CO₂），说明已生成 Na₂CO₃（变质）；②加 CaCl₂ 溶液，若产生白色沉淀 CaCO₃，证有 Na₂CO₃。区别：检验 CO₂ 用石灰水（有现象），吸收 CO₂ 用 NaOH（更彻底但无现象），不可混。 **难点二：Ca(OH)₂ 为何微溶且溶解度随升温减小** 多数固体溶解度随温升而增，但 Ca(OH)₂ 反常——升温溶解度减小（因其溶解过程放热）。故配石灰水宜用冷水，且石灰水常现少量未溶白色固体。 **难点三：碱的通性源于 OH⁻，但并非所有碱都"通"** 只有可溶碱（NaOH、KOH、Ca(OH)₂、Ba(OH)₂ 等）在水中有 OH⁻，才显通性；难溶碱（如 Fe(OH)₃、Cu(OH)₂）难电离，不与盐/酸性氧化物在溶液中普遍反应。 **常见失误** 1. 把 NaOH 与 CO₂ 产物写成 Na₂CO₃ + H₂O 时漏系数 2（应为 2NaOH）。 2. 检验 CO₂ 误用 NaOH 溶液（无现象）→ 应用澄清石灰水。 3. 生石灰 CaO 与水反应写成生成 Ca(OH) 漏下标 2。

✏️ 课堂讲义 · 典型例题精讲

**例1（俗名性质）** 说出 NaOH 的俗名、潮解含义及保存方法。 解析：俗名烧碱、火碱、苛性钠。潮解指固体吸收空气中水分表面变潮溶解。因易潮解且吸 CO₂ 变质，必须密封保存。 关键：密封保存是两原因——潮解+变质。 **例2（方程式）** 写出 NaOH 与 CO₂、HCl 反应的方程式。 解析：2NaOH + CO₂ = Na₂CO₃ + H₂O（与非金属氧化物）；NaOH + HCl = NaCl + H₂O（中和）。注意配平：NaOH 前系数 2。 关键：碱+酸性氧化物→盐+水；碱+酸→盐+水。 **例3（CO₂检验）** 为什么澄清石灰水可检验 CO₂？现象是什么？ 解析：Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O，生成白色沉淀 CaCO₃ 使石灰水变浑浊，现象明显，故用于检验 CO₂。而 NaOH 吸收 CO₂ 无明显现象，用于除 CO₂。 关键：检验用石灰水（有浑浊），吸收用 NaOH。 **例4（制取）** 生石灰如何变成熟石灰？写出方程式并说现象。 解析：CaO + H₂O = Ca(OH)₂，生石灰加水剧烈放热、放出大量热并生成白色熟石灰粉末。建筑上用此反应制石灰浆。 关键：CaO(生石灰) + H₂O → Ca(OH)₂(熟石灰)，放热。 **例5（变质探究）** 如何证明久置 NaOH 固体已部分变质？ 解析：取样加水溶解，①加足量 CaCl₂ 溶液，若产生白色沉淀（CaCO₃），证明含 Na₂CO₃（已变质）；②取上层清液加酚酞，若变红，证明仍含 NaOH（部分变质）。综合：白色沉淀+酚酞红→部分变质。 关键：先除 Na₂CO₃ 干扰（加 CaCl₂）再检 NaOH，顺序不能反。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 性质与俗名

  1. 1. 写出氢氧化钠和氢氧化钙的俗名，并说明它们使指示剂变色的规律。
    答：氢氧化钠俗名：烧碱、火碱、苛性钠；氢氧化钙俗名：熟石灰、消石灰。二者水溶液均呈碱性，能使紫色石蕊试液变蓝、使无色酚酞试液变红（源于溶液中解离出 OH⁻）。
  2. 2. 完成方程式：1) 2NaOH + CO₂ = ? 2) Ca(OH)₂ + CO₂ = ?
    答：1) 2NaOH + CO₂ = Na₂CO₃ + H₂O（生成碳酸钠和水）。2) Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O（生成白色碳酸钙沉淀，石灰水变浑浊，用于检验 CO₂）。

中等 · 反应与应用

  1. 1. 为什么 NaOH 必须密封保存？写出相关变质方程式。
    答：NaOH 必须密封保存有两点原因：①易吸收空气中水分而潮解；②能与空气中 CO₂ 反应变质。方程式：2NaOH + CO₂ = Na₂CO₃ + H₂O。久置会变成 Na₂CO₃，故实验室 NaOH 用橡胶塞瓶密封保存，并防止吸湿。
  2. 2. 用生石灰制熟石灰的方程式是什么？该反应有何用途与现象？
    答：CaO + H₂O = Ca(OH)₂。现象：生石灰加水剧烈放热、体积膨胀并生成白色熟石灰。用途：建筑上制石灰浆粉刷；农业上用石灰水改良酸性土壤、配制波尔多液杀菌；也用于消毒。

难 · 实验探究

  1. 1. 有两瓶失去标签的无色溶液，分别是 NaOH 溶液和 Ca(OH)₂ 溶液，如何用一种试剂区分？写出操作、现象与结论。
    答：方法一（通 CO₂）：分别通入 CO₂，溶液变浑浊的是 Ca(OH)₂（Ca(OH)₂+CO₂=CaCO₃↓+H₂O），无明显现象的是 NaOH（虽反应但无沉淀）。方法二（加 Na₂CO₃）：分别滴加碳酸钠溶液，产生白色沉淀的是 Ca(OH)₂（Ca(OH)₂+Na₂CO₃=CaCO₃↓+2NaOH），无沉淀的是 NaOH。结论：利用 Ca²⁺ 生成 CaCO₃ 沉淀可区分。
  2. 2. 探究久置 NaOH 是否变质及变质程度（部分/完全），设计实验方案。
    答：方案：①取样溶于水；②加过量 CaCl₂ 溶液（或 BaCl₂），若产生白色沉淀，说明含 Na₂CO₃，已变质；沉淀后取上层清液；③向清液滴酚酞，若变红→仍含 NaOH，为部分变质；若不变红→NaOH 已全变成 Na₂CO₃，为完全变质。注意：CaCl₂ 须过量以除尽 CO₃²⁻，避免干扰 NaOH 检验；不能用 Ca(OH)₂ 代替（会引入 OH⁻ 误导酚酞）。

综合 · 综合运用

  1. 1. 归纳碱的通性（至少 3 条），并说明其微观本质；举出生活中利用碱的 2 个实例。
    答：碱的通性（源于水中解离出 OH⁻）：①使指示剂变色（石蕊蓝、酚酞红）；②与酸中和生成盐和水（如改良土壤酸性的熟石灰）；③与某些非金属氧化物（CO₂、SO₂）反应生成盐和水（如 NaOH 吸收 SO₂ 防污染）。生活实例：用熟石灰 Ca(OH)₂ 改良酸性土壤、处理酸性废水；用 NaOH 除油污（与油脂反应皂化）；用石灰浆刷墙（吸收 CO₂ 变硬成 CaCO₃）。本质皆因 OH⁻ 参与反应。
  2. 2. 工业上用 Na₂CO₃ 与 Ca(OH)₂ 反应制 NaOH，写出方程式，并从复分解反应条件说明为何能发生。
    答：方程式：Na₂CO₃ + Ca(OH)₂ = CaCO₃↓ + 2NaOH。该反应是复分解反应，发生条件是生成沉淀、气体或水之一；此处生成了难溶的 CaCO₃ 白色沉淀，使反应向右进行，故能发生并得到 NaOH 溶液，再蒸发浓缩可得固体 NaOH。这也是工业制取烧碱的方法之一（联合制碱法的副产利用）。

💬 课后反馈

氢氧化钠（烧碱）和氢氧化钙（熟石灰）是常见碱代表，学生掌握了使石蕊变蓝、酚酞变红及与 CO₂ 反应，但易漏写 NaOH 前系数 2、混淆"检验 CO₂ 用石灰水"与"吸收 CO₂ 用 NaOH"。建议通过实验现象记忆，规范方程式书写，强调 NaOH 密封保存（潮解+变质）的要点。
