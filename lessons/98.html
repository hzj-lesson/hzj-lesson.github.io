初中九年级化学《化学肥料》教案

初中九年级化学化学肥料

📝 备课方案

**教学目标** 1. 了解氮肥、磷肥、钾肥、复合肥的作用与主要品种。 2. 掌握常见化肥的化学式，会判断化肥的种类。 3. 掌握铵态氮肥的检验方法（与碱混合加热产生氨气）。 4. 了解铵态氮肥不能与碱性物质混用的原因。 5. 认识化肥、农药对环境的影响，树立合理使用化肥农药的意识。 **教学重点**：化肥的种类、作用与鉴别；铵态氮肥的检验。 **教学难点**：化肥种类的判断；铵态氮肥的检验与相关化学方程式。 **教学方法**：实物展示、实验探究（铵盐检验）、归纳总结。 **课时安排**：1 课时

📖 课堂讲义 · 核心知识点

**一、氮肥** - 作用：促进植物**茎叶生长**，使叶色浓绿（促进光合作用）。 - 缺氮症状：植株矮小、叶片发黄。 - 常见氮肥：尿素 $CO(NH_2)_2$（含氮量最高约 46.7%，中性肥料，最常用）、碳酸氢铵 $NH_4HCO_3$（易分解有氨味，不能暴晒）、硝酸铵 $NH_4NO_3$（易爆，不能受猛烈撞击）、氯化铵 $NH_4Cl$。 - 铵态氮肥含 $NH_4^+$，化学式特点：含铵根 $NH_4^+$。 **二、磷肥** - 作用：促进植物**根系发育**，增强抗旱、抗寒能力，促进早熟。 - 缺磷症状：植株矮小、根系不发达、生长迟缓。 - 常见磷肥：磷矿粉 $Ca_3(PO_4)_2$、过磷酸钙（$Ca(H_2PO_4)_2$ 与 CaSO4 的混合物）、重过磷酸钙。 **三、钾肥** - 作用：促进植物**茎秆健壮**，增强抗倒伏、抗病虫害能力，促进糖分和淀粉的合成。 - 缺钾症状：茎秆软弱、易倒伏、易染病虫害。 - 常见钾肥：氯化钾 $KCl$、硫酸钾 $K_2SO_4$、草木灰（主要成分 $K_2CO_3$，水溶液显碱性）。 **四、复合肥料** - 定义：同时含有**氮、磷、钾中的两种或两种以上**营养元素的化肥。 - 常见复合肥：硝酸钾 $KNO_3$（含 N、K）、磷酸二氢铵 $NH_4H_2PO_4$（含 N、P）、磷酸氢二铵 $(NH_4)_2HPO_4$、磷酸二氢钾 $KH_2PO_4$。 - 判断方法：看化学式中是否同时含 N、P、K 中的两种以上。 **五、铵态氮肥与碱的反应及检验** - 铵态氮肥（含 $NH_4^+$）与碱（如熟石灰 $Ca(OH)_2$、NaOH）混合研磨（或加热），产生有刺激性气味的**氨气**：$NH_4HCO_3 + Ca(OH)_2 \rightarrow CaCO_3 \downarrow + NH_3 \uparrow + 2H_2O$；$2NH_4Cl + Ca(OH)_2 \xrightarrow{\Delta} CaCl_2 + 2NH_3 \uparrow + 2H_2O$。 - 检验 $NH_4^+$ 的方法：取少量样品与**熟石灰**混合研磨，若有刺激性气味气体产生，且该气体能使**湿润的红色石蕊试纸变蓝**，则证明含铵根离子（氨气溶于水显碱性）。 - 铵态氮肥**不能与碱性物质**（草 木灰、熟石灰）混合使用，否则会生成氨气逸散，使肥效降低。 **六、化肥对环境的影响** - 不合理施用化肥的危害：污染水体（水体富营养化、水华/赤潮）、污染土壤、破坏土壤结构。 - 合理施用：按需施用、配方施肥、与有机肥配合使用；发展生态农业。

🔍 课堂讲义 · 重点难点解析

**重点一：化肥种类的判断** 看化学式判断化肥种类：只含 N 元素的是氮肥（如尿素、碳酸氢铵）；只含 P 的是磷肥（如磷矿粉）；只含 K 的是钾肥（如氯化钾、草木灰）；含 N、P、K 中两种以上的是复合肥（如硝酸钾含 N、K）。学生常见错误：把硝酸钾（KNO3）误判为钾肥或氮肥——它同时含 N 和 K，是复合肥；把草木灰（主要成分 K2CO3）误判为钾盐复合肥——它只含 K，是钾肥。判断时逐一列出化学式中的营养元素，看含几种。 **重点二：铵态氮肥的检验** 检验 $NH_4^+$ 分两步描述：加碱（熟石灰）研磨→产生刺激性气味气体；用湿润的红色石蕊试纸检验气体→试纸变蓝。写方程式时注意氨气要标"$\uparrow$"，加热或研磨条件要注明。学生常漏掉"湿润的红色石蕊试纸变蓝"这一现象，或把试纸写错（石蕊试纸只有"湿润红色"才能测碱性气体，氨气遇水生成 NH3·H2O 显碱性使红色石蕊变蓝）。判断铵态氮肥能否与草木灰混用，看草木灰是否显碱性（K2CO3 溶液显碱性，不能混用）。 **难点：铵态氮肥与碱性物质不能混用的原因** 铵态氮肥中的 $NH_4^+$ 与碱性物质中的 $OH^-$ 反应生成氨气（$NH_4^+ + OH^- \xrightarrow{\Delta} NH_3 \uparrow + H_2O$），氨气挥发，氮元素流失，肥效降低。所以碳酸氢铵、氯化铵、硝酸铵等都不能与熟石灰、草木灰等碱性物质混合使用或贮存。这也是"检验铵盐要加碱研磨"的原理基础——检验和混用规则来自同一个化学反应，理解原理后两个知识点都不会忘。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：下列化肥中，属于复合肥料的是（ ） A. 尿素 $CO(NH_2)_2$ B. 硝酸钾 $KNO_3$ C. 氯化钾 $KCl$ D. 磷矿粉 $Ca_3(PO_4)_2$ 解析：尿素只含氮元素，是氮肥；硝酸钾同时含钾元素和氮元素，属于复合肥；氯化钾只含钾元素，是钾肥；磷矿粉只含磷元素，是磷肥。故选 B。 关键：复合肥的定义是同时含 N、P、K 中两种或两种以上营养元素，逐一列出化学式所含营养元素再判断。 **例 2**：写出常见氮肥、磷肥、钾肥各一种的化学式，并简述它们对植物生长的主要作用。 解析：氮肥如尿素 $CO(NH_2)_2$，促进茎叶生长、使叶色浓绿；磷肥如磷矿粉 $Ca_3(PO_4)_2$，促进根系发育、增强抗寒抗旱能力；钾肥如氯化钾 $KCl$，促进茎秆健壮、增强抗倒伏抗病虫害能力。 关键：记住口诀「氮长叶、磷长根、钾壮秆」——对应各元素的主要作用。 **例 3**：某同学怀疑自己买的化肥是铵态氮肥，如何用实验验证？写出操作、现象和结论。 解析：取少量化肥样品放入研钵，加入少量熟石灰（氢氧化钙）粉末，混合研磨。现象：产生有刺激性气味的气体；把湿润的红色石蕊试纸放在容器口，试纸变蓝。结论：该化肥含 $NH_4^+$，是铵态氮肥。相关反应：$2NH_4Cl + Ca(OH)_2 \xrightarrow{\Delta} CaCl_2 + 2NH_3 \uparrow + 2H_2O$（以氯化铵为例）。 关键：检验铵根三步——加熟石灰研磨、闻到刺激性气味、湿润红色石蕊试纸变蓝，三者缺一不可。 **例 4**：为什么碳酸氢铵不能与草木灰混合使用？ 解析：碳酸氢铵是铵态氮肥，含 $NH_4^+$；草木灰的主要成分是 $K_2CO_3$，其水溶液显碱性，含 $OH^-$。混合后 $NH_4^+$ 与 $OH^-$ 反应生成氨气（$NH_4^+ + OH^- \xrightarrow{\Delta} NH_3 \uparrow + H_2O$），氨气逸散到空气中，氮元素流失，使氮肥的肥效降低。所以铵态氮肥都不能与熟石灰、草木灰等碱性物质混合使用。 关键：铵态氮肥忌碱——混用会生成氨气跑掉，原理与检验铵盐完全相同。 **例 5**：过量施用化肥会对环境造成哪些危害？应如何合理施用？ 解析：危害：①化肥中的氮、磷元素随雨水进入河流湖泊，使水体富营养化，引发水华（淡水中）、赤潮（海水中）；②长期过量施用使土壤板结、酸化，破坏土壤结构；③污染地下水。合理施用：根据作物需要和土壤情况配方施肥、按需限量施用、化肥与有机肥配合使用、发展生态农业。 关键：答题从"水体、土壤、地下水"三个角度说明危害，从"按需配方、限量配合"谈措施。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 化肥种类与作用

  1. 1. 氮肥、磷肥、钾肥各有什么作用？分别写出两种常见化肥的化学式。
    答：氮肥促进植物茎叶生长、使叶色浓绿，如尿素 $CO(NH_2)_2$、碳酸氢铵 $NH_4HCO_3$；磷肥促进根系发育、增强抗寒抗旱能力、促进早熟，如磷矿粉 $Ca_3(PO_4)_2$、过磷酸钙；钾肥促进茎秆健壮、增强抗倒伏抗病虫害能力，如氯化钾 $KCl$、硫酸钾 $K_2SO_4$。记忆口诀「氮长叶、磷长根、钾壮秆」。
  2. 2. 什么是复合肥料？举两个例子并说明所含元素。
    答：复合肥料是同时含有氮、磷、钾三种营养元素中两种或两种以上的化肥。如硝酸钾 $KNO_3$，同时含氮元素和钾元素；磷酸二氢铵 $NH_4H_2PO_4$，同时含氮元素和磷元素。判断方法是列出化学式中所含的 N、P 、K 元素，含有两种以上即为复合肥。
  3. 3. 常见的化学肥料按营养元素分为哪几类？各举一例。
    答：分为四类：氮肥（如尿素 $CO(NH_2)_2$）、磷肥（如磷矿粉 $Ca_3(PO_4)_2$）、钾肥（如氯化钾 $KCl$）、复合肥（如硝酸钾 $KNO_3$）。此外还有微量元素肥料。化肥能为植物提供 N、P、K 等营养元素，其中氮、磷、钾是植物需要量最大的三种元素。

中等 · 铵态氮肥检验

  1. 1. 如何检验一种化肥中是否含有铵根离子（$NH_4^+$）？请写出操作、现象和结论。
    答：操作：取少量化肥样品于研钵中，加入少量熟石灰（$Ca(OH)_2$）粉末，用研杵混合研磨；同时在容器口放一片湿润的红色石蕊试纸。现象：闻到刺激性气味的气体，湿润的红色石蕊试纸变蓝。结论：该化肥中含 $NH_4^+$，属于铵态氮肥。原理：铵盐与碱反应放出氨气，氨气溶于水显碱性，使红色石蕊试纸变蓝。
  2. 2. 写出氯化铵与熟石灰混合加热反应的化学方程式，并说明该反应的应用。
    答：方程式：$2NH_4Cl + Ca(OH)_2 \xrightarrow{\Delta} CaCl_2 + 2NH_3 \uparrow + 2H_2O$。应用：①实验室利用该反应原理可制取少量氨气；②利用该反应检验铵态氮肥（产生刺激性气味、能使湿润红色石蕊试纸变蓝的氨气）；③同时说明铵态氮肥不能与熟石灰等碱性物质混用，否则生成氨气逸散、肥效降低。
  3. 3. 为什么铵态氮肥不能与草木灰混合使用？
    答：草木灰的主要成分是碳酸钾（$K_2CO_3$），其水溶液显碱性，含有大量 $OH^-$。铵态氮肥中的 $NH_4^+$ 与 $OH^-$ 反应生成氨气：$NH_4^+ + OH^- \xrightarrow{\Delta} NH_3 \uparrow + H_2O$，氨气挥发到空气中，导致氮元素流失，氮肥的肥效明显降低。所以铵态氮肥（如碳酸氢铵、氯化铵、硝酸铵）不能与熟石灰、草木灰等碱性物质混合使用。

难 · 化肥鉴别

  1. 1. 现有四瓶失去标签的化肥：尿素、氯化铵、硫酸钾、磷矿粉，请用实验方法鉴别它们。
    答：①先看外观与溶解性：磷矿粉是灰白色粉末、难溶于水；其余三种都是白色晶体、易溶于水，先分出磷矿粉。②取剩余三种样品各少许，分别加入熟石灰研磨：有刺激性气味气体（能使湿润红色石蕊试纸变蓝）的是氯化铵（铵态氮肥），无明显现象的是尿素和硫酸钾。③取无明显现象的两种样品配成溶液，各滴加氯化钡溶液：产生白色沉淀（BaSO4）的是硫酸钾，无明显现象的是尿素。因为尿素含 $CO(NH_2)_2$ 不含 SO4 2-，K2SO4 含 SO4 2-。
  2. 2. 某化肥包装袋上标有"硝酸铵 NH4NO3，含氮量 ≥ 35%"。请计算：①硝酸铵中氮元素的质量分数是多少？②该包装袋上标注的含氮量是否真实？（相对原子质量：N=14，H=1，O=16）
    答：①硝酸铵 $NH_4NO_3$ 的相对分子质量 = 14 + 1×4 + 14 + 16×3 = 80；其中氮元素质量为 14 + 14 = 28。氮元素的质量分数 = $\\frac{28}{80} \times 100\% = 35\%$。②包装标注"含氮量 ≥ 35%"与实际理论值 35% 相符，说明标注真实（理论上限为 35%，纯硝酸铵含氮量就是 35%，若实际样品含杂质则含氮量应小于 35%）。

综合 · 化肥综合应用

  1. 1. 某农户的农作物出现叶片发黄、生长迟缓、易倒伏的症状。请分析他应分别施用哪类化肥，并说明判断依据。
    答：叶片发黄说明缺氮，应施用氮肥（如尿素 $CO(NH_2)_2$），因为氮肥促进茎叶生长、使叶色浓绿。生长迟缓、根系不发达可能同时缺磷，可补施磷肥促进根系发育。易倒伏说明缺钾，应施用钾肥（如氯化钾 $KCl$），因为钾肥促进茎秆健壮、增强抗倒伏能力。也可选用复合肥（如硝酸钾 $KNO_3$）同时补充氮和钾。判断依据是「氮长叶、磷长根、钾壮秆」。
  2. 2. 某同学取少量土壤样品测定其酸碱性，发现土壤显碱性。请设计实验证明某袋化肥是否为氯化铵，并判断该化肥能否用于此碱性土壤。
    答：检验是否为氯化铵（$NH_4Cl$）：取少量样品与熟石灰混合研磨，若产生刺激性气味气体且能使湿润红色石蕊试纸变蓝，则证明含 $NH_4^+$；另取样品溶于水，滴加硝酸银溶液和稀硝酸，若产生不溶于稀硝酸的白色沉淀（AgCl），则证明含 $Cl^-$。两者都符合即为氯化铵。判断能否用于碱性土壤：氯化铵是铵态氮肥，在碱性土壤中 $NH_4^+$ 与 $OH^-$ 反应生成氨气挥发，氮肥失效，且土壤本身不缺碱，所以不宜施用在碱性土壤上，应选用尿素等非铵态氮肥。

💬 课后反馈

本课是农业化学与实验鉴别的结合点。常见错误：把硝酸钾误判为钾肥（它是 N、K 复合肥）、铵根检验漏写"湿润红色石蕊试纸变蓝"、误认为铵态氮肥可与草木灰混用、含氮量计算忘乘化学计量数。建议用"化肥分类表"（元素种类→类别→作用→代表物）整理，用口诀「氮长叶、磷长根、钾壮秆」帮助记忆。中考常考化肥鉴别与含氮量计算，务必训练"加碱研磨—闻气味—试纸变蓝"三步检验法和"化学式列元素定类别"的判断方法。
