高中高二数学《数列综合》教案

高中高二数学数列综合

📝 备课方案

**教学目标** 1. 知识与技 能：综合运用等差、等比数列通项与求和公式，熟练掌握由递推求通项的 5 大方法（公式、累加、累乘、构造、待定系数）。 2. 过程与方法：通过分类讨论、构造新数列的训练，提高转化与化归能力。 3. 情感态度：体会数列问题"以不变应万变"的数学思想，形成严谨的解题习惯。 **教学重点**：等差与等比数列的综合应用；递推数列求通项；错位相减与裂项相消求和。 **教学难点**：含有字母参数的递推求通项；非等差非等比数列向等差等比的转化。 **教学方法**：例题精讲 + 变式训练 + 课堂限时演练。 **课时安排**：3 课时（第 1 课时求通项；第 2 课时求和；第 3 课时综合应用与测试） **教学准备**：PPT、配套导学案、近三年高考真题 3 道。

📖 课堂讲义 · 核心知识点

**一、数列通项的求法（5 大方法）** 1. **公式法**：已知 a₁ 和公差 d（或公比 q）直接代入等差/等比通项公式。 2. **累加法**：形如 aₙ₊₁ - aₙ = f(n) 的递推，累加后求通项。 例：a₁=1，aₙ₊₁ = aₙ + 2n，则 aₙ = 1 + 2·(1+2+…+(n-1)) = n² - n + 1。 3. **累乘法**：形如 aₙ₊₁ / aₙ = f(n) 的递推，逐项相乘后求通项。 例：a₁=2，aₙ₊₁ / aₙ = n/(n+1)，累乘得 aₙ = 2/(n(n+1))。 4. **构造法（核心）**：将非等差非等比数列转化为等比数列。 ① 形如 aₙ₊₁ = p·aₙ + q（p≠1）：两边同除 pⁿ⁺¹ 或加减构造等比。 ② 形如 aₙ₊₁ = p·aₙ + q·rⁿ：两边同除 rⁿ⁺¹。 ③ 形如 aₙ₊₁ = p·aₙ/q：取对数后用累乘。 5. **待定系数法**：已知数列是某已知形式（如 aₙ = pn+q 或 A·pⁿ⁺B），代入递推定系数。 **二、数列求和的常用技巧** 1. **公式法**：等差 Sₙ = n·a₁ + n(n-1)d/2；等比 Sₙ = a₁(1-qⁿ)/(1-q)。 2. **分组求和**：拆成多个等差/等比之和。 3. **错位相减**：通项为 aₙ = (An+B)·qⁿ 形式。 例：Sₙ = 1·x + 2·x² + … + n·xⁿ，两边乘 x 后相减。 4. **裂项相消**：通项能写成 1/(k(k+1)) = 1/k - 1/(k+1) 等形式。 常用裂项： - $\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$ - $\dfrac{1}{n(n+2)} = \dfrac{1}{2}\left(\dfrac{1}{n} - \dfrac{1}{n+2}\right)$ - $\dfrac{1}{(2n-1)(2n+1)} = \dfrac{1}{2}\left(\dfrac{1}{2n-1} - \dfrac{1}{2n+1}\right)$ 5. **倒序相加**：用于组合数求和（如 Sₙ = Cₙ⁰ + Cₙ¹ + … + Cₙⁿ）。 6. **并项求和**：奇偶分组后求和。 **三、数列与函数、不等式的综合** 1. 数列单调性：aₙ₊₁ - aₙ 与 0 比较，或 aₙ₊₁/aₙ 与 1 比较（项为正）。 2. 数列最大（小）项：解不等式 aₙ ≥ aₙ₊₁ 且 aₙ ≥ aₙ₋₁。 3. 与不等式结合：常用放缩技巧（如 lg(n+1) > lg n/(n+1) 等）。 4. 与函数结合：把数列看作正整数集上的函数，借助函数单调性证明。

🔍 课堂讲义 · 重点难点解析

**难点一：构造法求通项** 关键口诀："见到线性递推 aₙ₊₁ = p·aₙ + q，先把它配成等比"。 具体步骤（以 aₙ₊₁ = 2aₙ + 3 为例）： ① 找不动点：解 x = 2x + 3，得 x = -3； ② 变形：aₙ₊₁ + 3 = 2(aₙ + 3)； ③ 新数列 {aₙ + 3} 是公比为 2 的等比； ④ 通项 aₙ + 3 = (a₁ + 3)·2ⁿ⁻¹，得 aₙ = (a₁+3)·2ⁿ⁻¹ - 3。 **难点二：错位相减的细节** 写 Sₙ 后乘公比 q 得 qSₙ，两式错位相减。注意： - 末项是 n·qⁿ 还是 (n-1)·qⁿ⁻¹，容易出错； - 约分时检查公比 q ≠ 1（q=1 时用公式法）。 **难点三：含参讨论** 当递推或求和式中含字母参数时，要按参数范围分类讨论，不能一概而论。如 aₙ₊₁ = q·aₙ + r 中 q 与 1 的关系决定方法。 **易错点提醒**： - 等比数列求和公式分母 1-q 与 1-qⁿ 写反； - 累加法只适用于 aₙ₊₁ - aₙ 为 n 的简单函数形式； - 构造法取不动点时，要验算 a₁ 是否满足新等比的首项。

✏️ 课堂讲义 · 典型例题精讲

**例 1（构造法基础）**：已知 a₁ = 1，aₙ₊₁ = 2aₙ + 1，求通项 aₙ。 **分析**：递推含常数项，用构造法。 **解**：解不动点 x = 2x + 1，得 x = -1。 两边减 -1：aₙ₊₁ - (-1) = 2(aₙ - (-1))，即 aₙ₊₁ + 1 = 2(aₙ + 1)。 所以 {aₙ + 1} 是首项 a₁ + 1 = 2、公比 2 的等比数列。 aₙ + 1 = 2·2ⁿ⁻¹ = 2ⁿ，得 **aₙ = 2ⁿ - 1**。 验证：a₁ = 2¹ - 1 = 1 ✓；a₂ = 2·1+1 = 3 = 2²-1 ✓。 --- **例 2（错位相减求和）**：求 Sₙ = 1·2 + 2·2² + 3·2³ + … + n·2ⁿ。 **分析**：通项 aₙ = n·2ⁿ，是等差×等比，用错位相减。 **解**：Sₙ = 1·2 + 2·2² + 3·2³ + … + n·2ⁿ。 两边乘 2：2Sₙ = 1·2² + 2·2³ + … + (n-1)·2ⁿ + n·2ⁿ⁺¹。 两式相减：-Sₙ = (2 + 2² + … + 2ⁿ) - n·2ⁿ⁺¹ = $\dfrac{2(2^n - 1)}{2 - 1} - n \cdot 2^{n+1}$ = 2ⁿ⁺¹ - 2 - n·2ⁿ⁺¹ = (1-n)·2ⁿ⁺¹ - 2。 所以 **Sₙ = (n-1)·2ⁿ⁺¹ + 2**。 验证：n=1 时 S₁ = (0)·4+2 = 2 = 1·2 ✓。 --- **例 3（裂项相消）**：求 $\dfrac{1}{1\times 3} + \dfrac{1}{3\times 5} + \cdots + \dfrac{1}{(2n-1)(2n+1)}$。 **分析**：分母为相邻奇数之积，用裂项。 **解**：$\dfrac{1}{(2n-1)(2n+1)} = \dfrac{1}{2}\left(\dfrac{1}{2n-1} - \dfrac{1}{2n+1}\right)$。 求和时相消： $S_n = \dfrac{1}{2}\left(\dfrac{1}{1} - \dfrac{1}{3} + \dfrac{1}{3} - \dfrac{1}{5} + \cdots + \dfrac{1}{2n-1} - \dfrac{1}{2n+1}\right)$ $= \dfrac{1}{2}\left(1 - \dfrac{1}{2n+1}\right) = \dfrac{n}{2n+1}$。 验证：n=1 时 $\dfrac{1}{1\times 3} = \dfrac{1}{3}$；公式 $\dfrac{n}{2n+1} = \dfrac{1}{3}$ ✓。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 通项求法

  1. 1. 已知 a₁=1, aₙ₊₁=3aₙ+2，求 aₙ。
    答：解不动点 x=3x+2 得 x=-1，aₙ₊₁+1=3(aₙ+1)，{aₙ+1} 公比 3 首项 2，故 aₙ+1=2·3ⁿ⁻¹，即 aₙ=2·3ⁿ⁻¹-1。
  2. 2. 已知 a₁=2, aₙ₊₁-aₙ=2n，求 aₙ。
    答：累加：aₙ=a₁+Σ(k=1→n-1) 2k = 2+2·(n-1)n/2 = n²-n+2。
  3. 3. 已知 a₁=1, aₙ₊₁=(n+1)aₙ/(n+2)，求 aₙ。
    答：累乘：aₙ=1·Π(k=1→n-1)(k+1)/(k+2) = 1·2/3·3/4·…·n/(n+1) = 2/(n+1)。

中等 · 求和方法

  1. 1. 求 Sₙ=1·3+2·3²+3·3³+…+n·3ⁿ。
    答：错位相减：Sₙ=1·3+2·3²+…+n·3ⁿ；3Sₙ=1·3²+…+(n-1)·3ⁿ+n·3ⁿ⁺¹；相减得-2Sₙ=(3+3²+…+3ⁿ)-n·3ⁿ⁺¹=(3ⁿ⁺¹-3)/2 - n·3ⁿ⁺¹，故 Sₙ=[(2n-1)·3ⁿ⁺¹+3]/4。
  2. 2. 求 1/(1·2)+1/(2·3)+…+1/(n(n+1))。
    答：裂项：1/(n(n+1))=1/n-1/(n+1)，相消得 Sₙ=1-1/(n+1)=n/(n+1)。
  3. 3. 求 Sₙ=1²+3²+5²+…+(2n-1)²。
    答：(2k-1)²=4k²-4k+1，求和得 4·n(n+1)(2n+1)/6 - 4·n(n+1)/2 + n = n(2n-1)(2n+1)/3。

难 · 综合应用

  1. 1. 已知 {aₙ} 满足 aₙ₊₁ = 2aₙ + 3ⁿ, a₁=1，求 aₙ。
    答：两边同除 3ⁿ⁺¹：aₙ₊₁/3ⁿ⁺¹ = (2/3)·aₙ/3ⁿ + 1/3。令 bₙ=aₙ/3ⁿ，则 bₙ₊₁=(2/3)bₙ+1/3，不动点 b=1，故 bₙ-1=(2/3)ⁿ⁻¹·(b₁-1)=(2/3)ⁿ⁻¹·(1/3-1)=-(2/3)ⁿ/3，bₙ=1-(2/3)ⁿ/3，所以 aₙ = 3ⁿ·[1-(2/3)ⁿ/3] = 3ⁿ - 2ⁿ/3 = (3·3ⁿ - 2ⁿ)/3。
  2. 2. 数列 {aₙ} 满足 a₁=1，(aₙ₊₁-aₙ)/(aₙ₊₁+aₙ) = 1/(2n+1)，求 aₙ。
    答：由 (aₙ₊₁-aₙ)/(aₙ₊₁+aₙ)=1/(2n+1)，交叉相乘得 (2n+1)(aₙ₊₁-aₙ)=aₙ₊₁+a₅ₙ，即 2n·aₙ₊₁=(2n+2)aₙ，故 aₙ₊₁=(n+1)/n·aₙ。累乘 aₙ=a₁·Π(k=1→n-1)(k+1)/k = 1·2/1·3/2·…·n/(n-1) = n。验证 aₙ=n 满足原递推：aₙ₊₁-aₙ=1，aₙ₊₁+aₙ=2n+1，比=1/(2n+1) ✓。

综合 · 高考真题

  1. 1. （2024·新课标 II）已知 {aₙ} 满足 a₁=1, aₙ₊₁-aₙ=2ⁿ，求 aₙ 和 Sₙ。
    答：累加：aₙ=1+Σ(k=1→n-1) 2ᵏ = 1+(2ⁿ-2) = 2ⁿ-1。Sₙ=Σ(2ᵏ-1)=Σ2ᵏ - n = 2ⁿ⁺¹-2-n。
  2. 2. （2023·甲卷）{aₙ} 是公差不为零的等差数列, a₁=1, a₂, a₃, a₅ 成等比, 求通项。
    答：设公差 d, a₂=1+d, a₃=1+2d, a₅=1+4d。由 (1+2d)²=(1+d)(1+4d)，1+4d+4d²=1+5d+4d²，得 d=2。aₙ=1+2(n-1)=2n-1。

💬 课后反馈

**本节重点反馈** 1. 构造法是核心思想，几乎所有非等差非等比的线性递推都能通过"找不动点 + 配凑"转化为等比。建议学生熟练背诵"aₙ₊₁ = p·aₙ + q"型的解题模板。 2. 错位相减和裂项相消是求和两大工具，必须区分适用题型：错位看"等差×等比"，裂项看"分母能拆成差"。 3. 高考数列大题通常综合通项、求和、不等式证明，学生要养成"先定方法再动手"的习惯。 4. 易错点：错位相减末项、构造法首项验证、裂项相消的相消方向。下节课将通过 5 道变式题巩固。
