初中九年级物理《串联和并联》教案

初中九年级物理串联和并联

📝 备课方案

**教材分析** 本节在学生认识了电路的基本组成、会画电路图之后，介绍电路的两种基本连接方式——串联与并联。串联与并联是最基础的电路结构，贯穿整个电学（电流、电压、电阻规律均以串并联为前提），家庭电路、生活用电的认知也由此起步，是本册电学承上启下的重要内容。 **教学目标** 1. 知道串联电路和并联电路的连接特点，理解二者的区别。 2. 会连接简单的串联电路和并联电路，能画出相应的电路图。 3. 能识别常见的串、并联电路，会使用"电流路径法"等方法判断电路连接方式。 4. 通过动手连接电路，体会开关在串联、并联电路中的不同控制作用。 **教学重点** 串、并联电路的连接特点与识别方法。 **教学难点** 正确识别较复杂电路是串联还是并联；按电路图连接实物电路。 **课时** 1 课时 **教学过程** 用两灯一开关引发"怎样接才能分别控制"的冲突→连接串联电路观察特点→连接并联电路观察特点→列表对比总结→电路图与实物互转练习→识别方法归纳。

📖 课堂讲义 · 核心知识点

**一、电路的两种基本连接方式** 用电器逐个顺次连接起来的电路叫串联电路；用电器并列连接起来的电路叫并联电路。 **二、串联电路** - 连接方式：元件首尾依次相连，电流只有一条路径，无分支。 - 特点：电流依次流过每个用电器，各处电流相等；一只开关控制所有用电器，开关位置不影响其控制作用；一盏灯断路（烧坏），整个电路都断路，各用电器互相影响、不能独立工作。 - 应用：节日小彩灯（一串）多采用串联（实际多为串并联混合），开关与用电器串联。 **三、并联电路** - 连接方式：电路出现分支点，电流在分支点"分流"，电流有干路与支路之分。 - 特点：干路开关控制整个电路，支路开关只控制它所在的那条支路；各支路用电器互不影响，一盏灯熄灭，其余支路照常工作；各支路两端电压相等。 - 应用：家庭电路、教室照明、马路路灯（互不影响）、电灯与电冰箱等家电都采用并联。 **四、电路图与实物电路连接** 串联电路图画法：电源正极→开关→灯 L1→灯 L2→电源负极，沿电流路径"一笔画"。 并联电路图画法：先画干路，再把两条支路并列接在分支点与汇合点之间。 实物连接要点：①连接前开关要断开；②按电流方向从电源正极出发逐点连接；③并联一般用"先串后并"——先把一条支路连成回路，再找出两个分支点把另一支路并上去。 **五、串并联电路的识别方法** ①电流路径法（最常用）：从电源正极出发沿电流走一圈，若只有一条路径、电流依次通过所有用电器，则是串联；若电流在分支点分成两路以上（有干路和支路），则是并联。 ②节点法：两用电器顺次首尾相接为串联；两用电器两端分别接在相同两个节点之间（首首相连、尾尾相接）为并联。 ③拆除法：拆去一个用电器，若其他用电器仍能工作，则为并联；若都不工作，则为串联。 ④等效法：电源去掉时不影响判断——只看用电器之间的连接关系。

🔍 课堂讲义 · 重点难点解析

**难点一：串联与并联的本质区别** 本质区别看"电流路径条数"：串联只有一条路径，电流必须依次流过每个用电器，所以互相影响；并联电流有多条路径，某条支路断开，电流可走其余支路，所以互不影响。由此可推：家庭电路中各用电器互不影响，必为并联。 **难点二：开关的控制作用与位置** 串联电路中无论开关放在何处（灯前、灯后、电源旁），都能控制整个电路，因为只有一条电流路径，开关断开即断路。并联电路中干路开关控制所有用电器；支路开关只控制所在支路，放在不同支路开关的控制范围不同。 **难点三：由电路图连接实物电路（并联易错）** 连接并联实物图最容易错的地方是找错分支点。步骤：先在电路图中确定分支点和汇合点；实物连接时先连通一条支路与干路组成完整回路，再从两个节点分别引出导线接入第二条支路；接完后按电流方向检查一遍，确保没有"短路"。 判断是否短路的小技巧：电流若可以不经过任何用电器直接从电源正极回到负极，就发生了短路，连接必错。 **常见失误** 1. 误以为开关在干路"只控制一盏灯"——干路开关控制所有支路。 2. 识别电路只看用电器位置不看电流路径，把并联当串联或反之。 3. 画并联电路图时让两支路导线"十字相交"相接而不标节点。

✏️ 课堂讲义 · 典型例题精讲

**例1（识别串联）** 一个电路中只有一只开关和两盏灯，闭合开关两灯都亮，断开开关两灯都灭，能否确定两灯是串联？ 解析：不能。若两灯串联，开关控制所有灯，符合；但若两灯并联且开关接在干路，开关同样控制所有灯。要确定连接方式，可再取下一盏灯观察另一盏：若熄灭则串联，若仍亮则并联（并联互不影响）。 关键：开关在干路时并联也能"全亮全灭"，须用"拆灯观察"判断。 **例2（识别并联）** 教室里的电灯：一盏灯坏了，其他灯仍然发光，说明教室照明电路的连接方式是什么？马路两边的路灯呢？ 解析：一盏坏掉其他仍亮，说明各灯互不影响、电流各有通路，故是并联。马路路灯通常共用一个控制开关，也采用并联（个别灯损坏不影响其余），保证夜间照明。 关键：判断依据是用电器是否互相影响，互不影响必为并联。 **例3（开关作用）** 有电源、两盏灯和两个开关，要求：只闭合开关 S1 时只有 L1 亮；只闭合 S2 时 L1、L2 都不亮；同时闭合 S1、S2 时两灯都亮。画出电路图。 解析：由"只闭合 S1 时只有 L1 亮"可知 S1 只控制 L1，在 L1 所在支路；L2 必须由 S2 单独控制，S2 在 L2 所在支路；同时 S1 又在干路（否则只闭合 S1 时电源无回路）。设计：电源→S1（干路）→分支：支路1为 L1，支路2为 S2 与 L2 串联，两支路汇合回电源。 关键：先确定每个开关控制的用电器，再确定其在干路还是支路，最后合并成电路图。 **例4（按图连实物）** 按电路图连接实物（两灯并联，S1 控制 L1，S2 控制 L2，S 控制干路）。简述连接顺序。 解析：①开关全部断开；②从电源正极出发连干路开关 S 的一个接线柱；③S 的另一接线柱连到分支点 a，把 L1 与 S1 串联后接在 a、b 之间，构成一条支路；④把 L2 与 S2 串联后同样接在 a、b 之间（与 L1 支路并联）；⑤b 点接回电源负极。检查：电流从正极出发有两条不经过对方的独立通路。 关键：先串后并，找准分支点与汇合点，最后沿电流方向整体检查。 **例5（综合识别）** 如图电路：灯 L1、L2、L3 中，S1 控制 L1，S2 同时控制 L2 和 L3，且 L2、L3 互不影响。判断 L1、L2、L3 的连接方式。 解析：L1 由 S1 单独控制且与其他灯互不影响，说明 L1 是一个独立支路；L2、L3 互不影响说明二者也是互相并联的支路；三者并联后共用一个电源，S2 若在包含 L2、L3 两支路的"总开关"位置即为它们的干路开关。故三灯并联。 关键：各灯是否独立由自己的开关控制，是判断并联的有力依据。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 什么叫串联电路？什么叫并联电路？
    答：把电路元件逐个顺次连接起来的电路叫串联电路，电流只有一条路径、无分支。把电路元件并列地连接起来的电路叫并联电路，电路出现分支，电流有干路与支路之分。
  2. 2. 串联电路和并联电路中开关的作用有什么不同？
    答：串联电路中一只开关就能控制所有用电器，开关放在什么位置都能控制整个电路。并联电路中，干路开关控制整个电路（所有用电器），支路开关只控制它所在的那条支路。

中等 · 特点应用

  1. 1. 为什么家庭电路中各用电器（电灯、电视、冰箱等）要采用并联连接？
    答：因为并联的各用电器互不影响，可以独立工作。采用并联后，关掉一盏灯、修好一台电器都不影响其他用电器正常使用；且各支路电压相同，便于用电器在额定电压下工作。若串联，任何一处断开整个电路都断路，所有电器都不能工作。
  2. 2. 一个电路中有两盏灯，用开关分别接在干路和支路都能改变控制范围。请说明：若取下一盏灯另一盏仍亮，则两灯是哪种连接方式？
    答：另一盏仍亮，说明电流还能经另一条路径流过它，两灯互不影响，所以是并联。若串联，取下一盏灯电路即断路，另一盏必然熄灭。

难 · 电路设计

  1. 1. 用电源、开关 S、S1、S2 和三盏灯 L1、L2、L3 设计电路：S 控制所有灯，S1 控制 L1，S2 控制 L2、L3 所在的一组灯（L2、L3 串联）。画出电路图。
    答：设计：电源正极→干路开关 S→分支点。L1 与 S1 串联成支路1；L2 与 L3 串联后再与 S2 串联成支路2（S2 控制整个支路2）；两分支在汇合点合流回电源负极。这样 S 断则全灭；闭合 S、S1 只 L1 亮；闭合 S、S2 则 L2、L3 同时亮；S1、S2 都闭合三灯全亮。
  2. 2. 医院病房需要指示灯与电铃：护士台一个电铃、一盏指示灯，病房内每床一个开关。要求：任意按下一个开关，电铃响且指示灯亮，能提示有病人呼叫。按此要求，病房内各开关之间以及开关与电铃（指示灯）之间应如何连接？
    答：指示灯与电铃应串联在同一回路中（这样铃响灯必亮、灯亮铃必响）；各床位开关应并联在呼叫电路里，这样任意一个开关闭合都能使电路接通、铃响灯亮；护士台可再设一个开关作为复位断开。即"床头开关并联、铃灯串入干路"，只要一路闭合整条干路就有电流。

综合 · 实验探究

  1. 1. 设计实验探究"串联电路中开关位置是否影响其作用"，写出步骤与结论。
    答：步骤：①把两盏灯、一只开关与电源串联成电路；②将开关分别接在电源正极与 L1 之间、L1 与 L2 之间、L2 与负极之间三个位置；③每换一次位置就闭合、断开开关，观察两灯的亮灭变化。结论：无论开关放在串联电路的哪个位置，断开开关两灯都熄灭，闭合开关两灯都亮，说明串联电路中开关位置不影响其作用，都能控制整个电路。
  2. 2. 给你两盏灯、两个开关、一个电源和若干导线，请连接一个"前后门都能独立控制同一盏走廊灯"的电路（双控思路：各开关都能单独让灯亮或灭，先实现两个开关并联控制即可），并解释原理。
    答：简便方案（两个并联开关）：把 S1、S2 并联后再与灯串联接入电源。闭合 S1 或 S2 任一，电路都接通、灯亮；两开关都断开灯灭。原理：并联的任一开关闭合都能形成电流通路，实现对同一用电器的"任一开关可控"。若要实现真正的双控（任一开关都可独立改变灯的状态），需用单刀双掷开关将灯接在两开关的两掷头之间——两个开关状态不同时灯亮，相同时灯灭。

💬 课后反馈

串并联电路是电学结构的基础，学生刚接触时最易出错：一是只凭用电器位置判断串并联，不会沿电流路径分析；二是连接并联实物图时找不到分支点、出现短路；三是不理解支路开关与干路开关的控制范围。建议把"电流路径法"作为主方法反复训练，配合"拆灯观察""开关独立控制"等生活化问题（病房呼叫、教室照明、双控灯）突破难点，并在实物连接中强化"先串后并、开关断开"的规范。
