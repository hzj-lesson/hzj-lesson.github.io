初中九年级物理《电与磁（磁现象）》教案

初中九年级物理电与磁（磁现象）

📝 备课方案

**教学目标** 1. 了解磁体、磁极及磁场、磁感线的概念，理解磁极间相互作用。 2. 理解电流的磁效应，掌握安培定则判断通电螺线管的磁极。 3. 了解电磁铁、电磁继电器、电动机与发电机的工作原理，认识电与 磁的相互联系。 **教学重点**：安培定则的运用，电磁铁与电磁继电器，电动机、发电机原理。 **教学难点**：磁感线方向的理解与安培定则的空间想象。 **教学方法**：实验演示（奥斯特实验、电磁铁）、模型与图像分析、联系生活。 **课时安排**：4 课时

📖 课堂讲义 · 核心知识点

**一、磁现象** - 磁体：具有磁性的物体，磁极有南极（S）与北极（N）。 - 磁极间相互作用：同名磁极互相排斥，异名磁极互相吸引。 - 磁化：使原来没有磁性的物体获得磁性的过程。 - 磁体性质：磁体具有指向性（指南北）；磁极磁性最强，中间最弱。 **二、磁场与磁感线** - 磁场：磁体周围存在的特殊物质，对放入其中的磁体产生磁力作用。 - 磁场方向：小磁针静止时 N 极所指的方向即该点磁场方向。 - 磁感线：为描述磁场而画的带箭头曲线（假想、不真实存在）。 - 磁感线特点：从 N 极出发回到 S 极（磁体外部）；不相交；磁感线密集处磁场强。 - 地磁场：地球周围存在的磁场，地磁北极在地理南极附近，地磁南极在地理北极附近。 **三、电流的磁效应（电生磁）** - 奥斯特实验：通电导线周围存在磁场，磁场方向与电流方向有关。 - 结论：电流周围存在磁场（电生磁），磁场的强弱与电流大小、线圈匝数有关。 **四、通电螺线管与安培定则** - 通电螺线管相当于条形磁体，磁极与电流方向有关。 - 安培定则（右手螺旋定则）：用右手握住螺线管，四指弯曲指向电流方向，大拇指所指方向即为螺线管的 N 极。 **五、电磁铁与电磁继电器** - 电磁铁：插有铁芯的螺线管，磁性随电流增大（匝数增多）而增强。 - 优点：磁性有无可由电流通断控制，磁性强弱可调，磁极方向可改变。 - 应用：电磁起重机、电磁继电器（利用电磁铁控制工作电路通断，实现低压控制高压、远距离控制）。 **六、磁场对电流的作用（磁生电之电机）** - 通电导体在磁场中受到力的作用，力的方向与电流方向、磁场方向有关。 - 应用：电动机，将电能转化为机械能，原理是通电线圈在磁场中受力转动。 **七、电磁感应** - 法拉第发现：闭合电路的部分导体做切割磁感线运动时产生电流——感应电流。 - 应用：发电机，将机械能转化为电能。 - 交流电：电流方向周期性变化的电流，我国交流电频率 50 Hz。 ![磁场与磁感线](/images/magnetic-field.svg)

🔍 课堂讲义 · 重点难点解析

**重点：安培定则的应用** 用安培定则判断通电螺线管磁极的步骤：① 标出电流方向（从电源正极出发沿导线走，螺线管中电流方向一致）；② 用右手握住螺线管，四指弯曲方向与电流方向一致；③ 大拇指所指一端即 N 极。反之已知磁极可判断电流方向、电源正负极。 **难点一：磁感线与磁场** 磁感线是假想的曲线，不是真实存在的；磁场是真实存在的。学生常误认为磁感线"真实存在"或"能相交"。磁感线方向即小磁针 N 极指向，磁体外部从 N 到 S，内部从 S 到 N。 **难点二：电动机与发电机原理混淆** 电动机：通电（给电）才转，电能→机械能，利用"通电导体在磁场中受力运动"，涉及电流方向改变→受力方向改变。发电机：转动才生电，机械能→电能，利用"电磁感应"。区别记忆口诀："电动机转靠通电，发电机电靠转动"。 **迷你示例**：通电螺线管正面电流向上，用安培定则可知左端为 N 极、右端为 S 极。

✏️ 课堂讲义 · 典型例题精讲

**例1**：磁体靠近时，同名磁极会怎样？异名磁极会怎样？ 解：同名磁极互相排斥，异名磁极互相吸引。 关键：磁极间作用规律"同斥异吸"，与电荷作用规律一致。 **例2**：如图，通电螺线管的电源正极在左侧，电流从螺线管左端流入，用安培定则判断螺线管的 N 极。 解：用右手握住螺线管，四指弯曲方向与电流方向（从正面看从左端流入）一致，大拇指指向螺线管右端，故右端为 N 极、左端为 S 极。 关键：安培定则——四指顺电流，拇指指 N 极。 **例3**：闭合电路的一部分导体在磁场中做切割磁感线运动，会产生什么现象？是什么原理？ 解：产生感应电流，这是电磁感应现象，由法拉第发现，是发电机的工作原理。 关键：闭合电路、部分导体、切割磁感线——三者缺一不可。 **例4**：电动机工作时能量如何转化？它利用了哪个原理？ 解：电动机将电能转化为机械能，利用的原理是通电导体（线圈）在磁场中受到力的作用而运动。 关键：电动机是"电→力→机械能"，电生磁的延伸应用。 **例5**：电磁起重机为什么能吊起重物，断电后重物能放下？ 解：电磁起重机内部是电磁铁，通电时有磁性（吸引钢铁），断电后磁性消失（放下重物）。电磁铁磁性的有无由电流控制，磁性强弱由电流大小与匝数控制。 关键：电磁铁磁性可控，这是它优于永磁体的地方。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念辨析

  1. 1. 磁极间的相互作用规律是什么？
    答：同名磁极互相排斥，异名磁极互相吸引。
  2. 2. 磁感线的方向是怎样规定的？磁体外部磁感线方向如何？
    答：磁场方向规定为小磁针 N 极所指的方向，磁感线上某点的切线方向即该点磁场方向。磁体外部磁感线从 N 极出发回到 S 极。

中等 · 电与磁关系

  1. 1. 奥斯特实验说明了什么？
    答：奥斯特实验说明通电导线周围存在磁场（电流周围存在磁场，即电流的磁效应），并且磁场方向与电流方向有关。这是"电生磁"的证据。
  2. 2. 发电机和电动机各利用什么原理？能量如何转化？
    答：发电机利用电磁感应原理，将机械能转化为电能；电动机利用通电导体在磁场中受力运动的原理，将电能转化为机械能。

难 · 安培定则

  1. 1. 已知通电螺线管右端是 N 极，请用安培定则判断螺线管中电流方向（从正面看线圈中电流的方向），并确定电源正负极。
    答：用右手握住螺线管，大拇指指向右端（N 极），四指弯曲方向即电流方向：从正面看，电流从螺线管右端流入、左端流出（即螺线管中电流沿四指方向环绕）。因此电源正极接在螺线管右端接线柱，负极接左端接线柱。
  2. 2. ![通电螺线管示意图](/images/hw-solenoid.svg) 如图，把通电螺线管的右端靠近小磁针，小磁针的 N 极被吸引，则该螺线管的右端是什么极？
    答：小磁针的 N 极被吸引，说明螺线管右端与小磁针 N 极是异名磁极，异名磁极互相吸引，所以螺线管的右端是 S 极（左端为 N 极）。

综合 · 综合应用

  1. 1. 综合：电磁继电器如何实现"用弱电控制强电"？以水位报警器为例说明。
    答：电磁继电器由电磁铁、衔铁、弹簧、触点等组成。控制电路（弱电）接通时，电磁铁有磁性吸引衔铁，使触点闭合，工作电路（强电，如大功率用电器）接通；控制电路断开时磁性消失，弹簧把衔铁拉起，触点断开。水位报警器中，水位达到一定高度时控制电路接通（如浮子使触点闭合），电磁铁吸合衔铁，接通报警电路（电铃）的电源，发出警报，从而实现用低电压小电流控制高电压大电流电路。
  2. 2. 电磁铁与永磁体相比有哪些优点？
    答：① 磁性有无可由电流的通断控制；② 磁性强弱可由电流大小、线圈匝数调节；③ 磁极方向可由电流方向改变。因此电磁铁可以制成电磁起重机、电磁继电器、电铃等，在自动控制和远距离控制中广泛应用。
  3. 3. 电磁铁与永磁体相比有哪些优点？
    答：① 磁性有无可由电流的通断控制；② 磁性强弱可由电流大小、线圈匝数调节；③ 磁极方向可由电流方向改变。因此电磁铁可以制成电磁起重机、电磁继电器、电铃等，在自动控制和远距离控制中广泛应用。

💬 课后反馈

电与磁是九年级电学的拓展板块，核心是磁现象基础、电流的磁效应（奥斯特实验）、安培定则、电磁铁与电磁继电器，以及电动机（通电受力）和发电机（电磁感应）的原理。学生易混淆电动机与发电机原理，需通过能量转化与"给电还是给动"区分。教学中多做演示实验、画螺线管绕向图，强化安培定则的空间想象。
