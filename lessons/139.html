初中七年级生物《绿色植物的呼吸作用》教案

初中七年级生物绿色植物的呼吸作用

📝 备课方案

**教学目标** 1. 描述呼吸作用的概念，写出呼吸作用的反应式，明确其实质是分解有机物、释放能量。 2. 通过实验验证呼吸作用消耗氧气、产生二氧化碳、释放热量。 3. 理解呼吸作用在农业生产和果蔬保鲜中的应用（松土、排涝、低温干燥储藏等）。 4. 比较光合作用与呼吸作用的区别与联系，树立能量流动和物质循环的观念。 **教学重点**：呼吸作用的概念、反应式与三个验证实验。 **教学难点**：光合作用与呼吸作用的区别与联系。 **教学方法**：实验演示、对比表格、生活实例分析。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、呼吸作用的概念** - 细胞利用氧，将有机物分解成二氧化碳和水，并且将储存在有机物中的能量释放出来，供给生命活动的需要，这个过程叫呼吸作用。 - 场所：主要在线粒体中。所有活的植物细胞都能进行呼吸作用。 - 反应式：有机物（储存能量）+ O₂ → CO₂ + H₂O + 能量。 **二、呼吸作用的三组验证实验（重点）** 1. 萌发种子使蜡烛熄灭：萌发的种子呼吸作用旺盛，消耗瓶内氧气，氧气不足使蜡烛熄灭——证明呼吸作用消耗氧气。 2. 萌发种子使澄清石灰水变浑浊：呼吸作用产生的 CO₂ 使澄清石灰水变浑浊——证明呼吸作用产生二氧化碳。 3. 萌发种子瓶内温度升高（瓶壁发热）：呼吸作用释放能量，部分以热能形式散失——证明呼吸作用释放热量。 4. 补充实验：萌发种子干重减少，有机物被分解消耗。 **三、呼吸作用的实质与意义** - 实质：分解有机物、释放能量（有机物 → 无机物，储存能量 → 释放能量）。 - 意义：为植物各种生命活动（细胞分裂、吸收无机盐、物质运输等）提供能量。 **四、呼吸作用的应用** - 促进呼吸：农田及时松土（透气）、排涝（防止根部缺氧）、移栽后通风。 - 抑制呼吸：粮食储藏用低温、干燥、密封（低氧）；果蔬保鲜用低温、低氧；水果装箱前降温。 **五、光合作用与呼吸作用的比较** - 部位：光合作用在叶绿体，呼吸作用在所有活细胞的线粒体。 - 原料：光合作用 CO₂ + H₂O，呼吸作用有机物 + O₂。 - 产物：光合作用有机物（储存能量）+ O₂，呼吸作用 CO₂ + H₂O。 - 条件：光合作用需光照，呼吸作用有光无光都进行。 - 能量变化：光合作用储存能量，呼吸作用释放能量。 - 联系：光合作用制造的有机物是呼吸作用的原料，呼吸作用释放的能量来源于光合作用储存的能量。 **六、易错提醒** - 呼吸作用需光吗？不需要，白天黑夜都在进行； - 呼吸作用只在叶片进行吗？不是，所有活细胞； - 呼吸作用分解的是有机物，不是无机物； - 大棚夜间降温是为了降低呼吸作用、减少有机物消耗。

🔍 课堂讲义 · 重点难点解析

**重点：呼吸作用反应式与三个实验的对应** 反应式「有机物 + O₂ → CO₂ + H₂O + 能量」必须与实验一一对应：燃烧蜡烛熄灭对应「消耗 O₂」；石灰水变浑浊对应「产生 CO₂」；瓶壁发热对应「释放能量」；干重减少对应「分解有机物」。做实验分析题时，先回忆「该实验的现象」，再回到反应式「找原料或产物」。学生常见错误是分不清哪个实验证明哪个结论，建议把「现象—结论」做成连线记忆：蜡烛灭→耗氧，石灰水浑→产 CO₂，发热→放能。 **难点：光合作用与呼吸作用的区别联系** 二者是中考必考的综合题。区别用「五对照」记忆：场所（叶绿体 vs 线粒体）、条件（需光 vs 无需光）、原料（CO₂+H₂O vs 有机物+O₂）、产物（有机物+O₂ vs CO₂+H₂O）、能量（储存 vs 释放）。联系：光合作用制造的有机物是呼吸作用分解的原料，呼吸作用释放的能量正是光合作用储存的太阳能。同一株植物白天光合作用强于呼吸作用时表现为释放 O₂、积累有机物；夜间只进行呼吸作用，消耗有机物。故果蔬要低温储藏、夜间温室要适当降温。 **常见错误** - 误以为呼吸作用只在夜间进行； - 把呼吸作用场所写成叶绿体； - 光合作用与呼吸作用原料产物颠倒； - 不理解的温度对呼吸的影响（低温抑制呼吸利于保鲜）。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：填空：呼吸作用的场所主要是__，实质是分解__、释放__。 解析：呼吸作用主要在线粒体中进行，实质是分解有机物、释放能量。答案：线粒体、有机物、能量。 关键：场所线粒体，原料有机物，产物 CO₂ 和水。 **例 2**：实验分析：将萌发的大豆种子装入密封瓶，一段时间后将燃着的蜡烛伸入瓶内，蜡烛熄灭。说明了什么？ 解析：萌发种子呼吸作用旺盛，消耗了瓶内的氧气，使瓶内氧气减少，蜡烛因缺氧而熄灭。证明呼吸作用消耗氧气。 关键：蜡烛熄灭 = 氧气被消耗，对应反应式左侧的 O₂。 **例 3**：实验分析：把萌发的种子装入密封瓶，过一段时间向瓶内注入澄清石灰水并震荡，石灰水变浑浊。说明了什么？ 解析：呼吸作用产生了二氧化碳，CO₂ 使澄清石灰水变浑浊。证明呼吸作用产生二氧化碳。 关键：石灰水变浑浊是 CO₂ 的检测方法，对应反应式右侧的 CO₂。 **例 4**：简答：北方农民在储存粮食时，为什么要晒干并低温密封保存？ 解析：种子含水量高、温度适宜时呼吸作用旺盛，会大量消耗有机物、产生热量，使粮堆发热甚至霉变。晒干（降低水分）、低温、密封（低氧）都能抑 制呼吸作用，减少有机物消耗，延长储存时间。 关键：抑制呼吸 = 减少有机物消耗 = 利于储存。 **例 5**：比较题：比较光合作用与呼吸作用在原料、产物和能量变化上的不同。 解析：光合作用原料是 CO₂ 和 H₂O，产物是有机物（储存能量）和 O₂，将光能转变成化学能储存起来；呼吸作用原料是有机物和 O₂，产物是 CO₂ 和 H₂O，将有机物中的化学能释放出来。二者原料与产物正好相反。 关键：两反应式互为逆过程，能量方向相反。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念与反应式

  1. 1. 写出呼吸作用的文字反应式，并指出原料、产物、场所
    答：反应式：有机物（储存能量）+ 氧气 → 二氧化碳 + 水 + 能量。原料是有机物和氧气，产物是二氧化碳和水，释放的能量供生命活动利用。场所主要是活细胞内的线粒体。
  2. 2. 填空：呼吸作用的实质是__有机物、__能量；光合作用的实质是__有机物、__能量。
    答：呼吸作用：分解有机物、释放能量；光合作用：合成有机物（制造有机物）、储存能量。两者能量方向相反：光合作用把光能储存在有机物中，呼吸作用把有机物中的能量释放出来。
  3. 3. 判断：呼吸作用只在夜间进行。（对/错）并说明理由。
    答：错误。呼吸作用是所有活细胞时刻都在进行的生命活动，有光、无光条件下都在进行。白天植物既进行光合作用又进行呼吸作用，夜间只进行呼吸作用。

中等 · 实验分析

  1. 1. 设计实验验证「呼吸作用产生二氧化碳」，写出材料、步骤与预期现象
    答：材料：萌发的种子、密封瓶、澄清石灰水。步骤：① 将萌发种子装入密封瓶，放置一段时间；② 打开瓶塞，迅速向瓶内注入澄清石灰水并震荡；③ 观察石灰水变化（另设一空瓶加石灰水作对照）。预期：装有萌发种子的瓶中石灰水变浑浊，空瓶不变浑。结论：呼吸作用产生二氧化碳。
  2. 2. 为什么用萌发的种子而不是干燥的种子做呼吸作用实验？
    答：因为萌发的种子呼吸作用非常旺盛，有机物分解快，产生的 CO₂ 多、消耗的 O₂ 多、释放的热量多，实验现象明显。干燥种子呼吸作用极其微弱，几乎测不到，不利于观察。这体现了「活的、代谢旺盛的细胞呼吸作用强」。
  3. 3. 分析：保温瓶内装入萌发种子后温度为什么会升高？温度升高说明什么？
    答：萌发种子呼吸作用旺盛，分解有机物释放能量，能量除供生命活动利用外，其余以热能形式散失，使瓶内温度升高。温度升高说明呼吸作用释放了能量（热量）。

难 · 应用分析

  1. 1. 为什么农田淹水后要及时排涝？
    答：农田淹水后，土壤空隙被水充满，空气不足，根系得不到充足的氧气，呼吸作用受抑制，能量供应不足，影响根对水分和无机盐的吸收，严重时会导致烂根。及时排涝可使土壤通气良好，保证根的正常呼吸作用，促进植物生长。
  2. 2. 新鲜水果保鲜常用低温储存，其生物学原理是什么？
    答：低温能抑制水果细胞中酶的活性，从而抑制呼吸作用，减少有机物（糖分、维生素等）的分解消耗和水分散失，延缓果实衰老变质，延长保鲜期。同样道理，还可采用低氧（充氮气）储存，因为氧气不足也能抑制呼吸作用。
  3. 3. 分析：为什么刚收下的粮食堆在一起会「发热」？
    答：刚收获的粮食含水量较高，种子仍是活的，呼吸作用旺盛，大量分解有机物并释放热量，热量在粮堆中不易散失，导致粮堆发热。若不及时晾晒，高温潮湿会进一步加快呼吸作用，甚至引起霉变。因此要及时晾晒降低含水量，抑制呼吸作用。

综合 · 光合呼吸综合

  1. 1. 比较光合作用与呼吸作用的区别（部位、条件、原料、产物、能量），并说明二者的联系
    答：区别：① 部位不同：光合作用在叶绿体，呼吸作用在所有活细胞的线粒体；② 条件不同：光合作用需要光，呼吸作用有光无光均可；③ 原料不同：光合作用需要 CO₂ 和水，呼吸作用需要有机物和 O₂；④ 产物不同：光合作用产生有机物和 O₂，呼吸作用产生 CO₂ 和水；⑤ 能量变化不同：光合作用储存能量，呼吸作用释放能量。联系：光合作用制造的有机物是呼吸作用的原料，呼吸作用释放的能量正是光合作用储存的能量，二者相互依存、共同维持植物的碳—氧平衡和能量流动。
  2. 2. 在一个密闭的透明温室中，白天光照充足时，温室内 CO₂ 浓度如何变化？夜间呢？
    答：白天光照充足时，植物光合作用强，消耗大量 CO₂，而呼吸作用同时进行也产生 CO₂，但由于光合作用消耗的 CO₂ 多于呼吸作用产生的，所以温室内 CO₂ 浓度下降；夜间无光，光合作用停止，只进行呼吸作用产生 CO₂，所以 CO₂ 浓度上升。这也是温室内白天要通风补充 CO₂（增施气肥）的原因。
  3. 3. 综合分析：设计一个实验比较萌发种子与干燥种子呼吸作用的强弱（写出假设、材料、步骤、预期）
    答：假设：萌发种子的呼吸作用比干燥种子旺盛。材料：萌发种子、干燥种子各若干，两个密封瓶、两支燃着的蜡烛。步骤：① 分别把萌发种子和干燥种子装入两个相同的密封瓶，密封放置相同时间；② 同时打开瓶塞，把燃着的蜡烛分别伸入两瓶；③ 观察蜡烛熄灭的时间。预期：萌发种子瓶中的蜡烛很快熄灭，干燥种子瓶中的蜡烛燃烧较久。结论：萌发种子呼吸作用强，消耗氧气多，证明呼吸作用强弱与细胞代谢旺盛程度有关。注意：两组除种子状态外其他条件均相同，保证单一变量。

💬 课后反馈

呼吸作用的教学主线是「反应式 + 三组实验 + 生产应用」，难点在光合作用与呼吸作用的比较与综合应用。学生常把场所、原料产物写反，误以为呼吸作用只在夜间进行。建议用「现象—结论」连线法巩固三个实验，用五对照表归纳光合呼吸差异，再通过松土、排涝、低温保鲜等生活实例训练知识的迁移应用。
