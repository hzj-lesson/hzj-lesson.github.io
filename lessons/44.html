初中九年级数学《一元二次方程》教案

初中九年级数学一元二次方程

📝 备课方案

**教学目标** 1. 理解一元二次方程的概念，掌握它的一般形式 ax² + bx + c = 0（a ≠ 0），能确定二次项系数、一次项系数和常数项。 2. 掌握解一元二次方程的四种方法：直接开平方法、配方法、公式法、因式分解法，能根据方程特点选择合适的方法。 3. 理解判别式 Δ = b² - 4ac 的意义，能根据判别式的符号判断一元二次方程根的情况。 4. 掌握一元二次方程根与系数的关系（韦达定理），能利用它解决相关问题，并能建立一元二次方程模型解决实际应用问题。 **教学重点**：四种解法的掌握与应用，判别式与根的关系，韦达定理的应用。 **教学难点**：配方法的完整过程，实际问题中的建模与根的取舍。 **教学方法**：对比教学法、探究发现法、讲练结合法、建模教学法。 **教学准备**：一元二次方程解法对比表、练习题库、课件、小组讨论任务单。 **课时安排**：5 课时（第 1 课时：概念与一般形式；第 2 课时：直接开平方与配方法；第 3 课时：公式法；第 4 课时：因式分解法与解法选择；第 5 课时：判别式、韦达定理与实际问题）。

📖 课堂讲义 · 核心知识点

**一、一元二次方程的概念与一般形式** 只含有一个未知数，并且未知数的最高次数是 2 的整式方程，叫做**一元二次方程**。 一般形式：**ax² + bx + c = 0（a ≠ 0）**，其中 ax² 是二次项，a 是二次项系数；bx 是一次项，b 是一次项系数；c 是常数项。 注意三点： 1. 必须是一个未知数，最高次数是 2，且是整式方程。 2. 二次项系数 a 不能为 0（否则就不是二次方程）；b、c 可以为 0。 3. 判断方程要先化为一般形式，再确定各项系数。 例：把方程 (x - 1)² = 4 化为一般形式：x² - 2x + 1 = 4，即 x² - 2x - 3 = 0，其中 a = 1，b = -2，c = -3。 **二、解一元二次方程的四种方法** 1. 直接开平方法：适用于形如 x² = p（p ≥ 0）或 (x + m)² = n（n ≥ 0）的方程。开平方时注意正负两个根。例：x² = 9，则 x = ±3。 2. 配方法：把方程左边配成完全平方式。步骤：移项使常数项在右边、把二次项系数化为 1、两边加一次项系数一半的平方、开平方求解。 3. 公式法：求根公式 x = (-b ± √(b² - 4ac)) ÷ (2a)。步骤：化为一般形式、确定 a、b、c、计算 Δ = b² - 4ac、代入公式。 4. 因式分解法：把方程化为两个一次因式的乘积等于 0 的形式，令每个因式等于 0。依据是"若 A × B = 0，则 A = 0 或 B = 0"。 | 解法 | 适用情况 | 示例 | |---|---|---| | 直接开平方法 | 左边是完全平方式、右边是常数 | x² = 25，x = ±5 | | 配方法 | 二次项系数为 1 或易化为 1 的一般式 | x² + 6x + 8 = 0 | | 公式法 | 所有一元二次方程（通法） | 2x² - 3x + 1 = 0 | | 因式分解法 | 方程便于分解成两个因式 | x² - 5x + 6 = 0 | **三、配方法完整过程示例** 解 x² + 6x - 7 = 0： 第一步移项：x² + 6x = 7； 第二步配方：两边加 (6÷2)² = 9，得 x² + 6x + 9 = 16，即 (x + 3)² = 16； 第三步开方：x + 3 = ±4； 第四步求解：x₁ = 1，x₂ = -7。 **四、公式法完整过程示例** 解 2x² - 4x - 6 = 0： a = 2，b = -4，c = -6； Δ = b² - 4ac = (-4)² - 4 × 2 × (-6) = 16 + 48 = 64； x = (-b ± √Δ) ÷ (2a) = (4 ± √64) ÷ (2 × 2) = (4 ± 8) ÷ 4； x₁ = (4 + 8) ÷ 4 = 3，x₂ = (4 - 8) ÷ 4 = -1。 **五、判别式与根的关系** 对于一元二次方程 ax² + bx + c = 0（a ≠ 0），令判别式 **Δ = b² - 4ac**： 1. Δ 大于 0 时，方程有两个不相等的实数根； 2. Δ = 0 时，方程有两个相等的实数根； 3. Δ 小于 0 时，方程没有实数根。 利用判别式可以不解方程判断根的情况，也可以根据根的情况确定字母系数的取值范围。 例：判断 3x² - 2x + 1 = 0 的根的情况。Δ = (-2)² - 4 × 3 × 1 = 4 - 12 = -8 小于 0，所以方程没有实数根。 **六、根与系数的关系（韦达定理）** 若一元二次方程 ax² + bx + c = 0（a ≠ 0）的两个根为 x₁、x₂，则 **x₁ + x₂ = -b/a，x₁ · x₂ = c/a**。 例：方程 x² - 5x + 6 = 0 的两个根为 2 和 3，验证：x₁ + x₂ = 5 = -b/a = -(-5)/1，x₁ · x₂ = 6 = c/a = 6/1，正确。 应用：已知一根求另一根、求两根之和之积、由两根求方程、构造新方程。 **七、实际应用（建模）** 列一元二次方程解应用题的步骤：审题设未知数、找等量关系列方程、解方程、检验根的合理性（实际问题中不符合实际的根要舍去）、作答。 常见模型：增长率（下降率）问题、面积问题、传播问题、握手与比赛场次问题、利润问题。 **易错提醒** 1. 用公式法时把 b、c 的符号弄错，特别是负系数。 2. 配方法忘加"一次项系数一半的平方"或两边只加一边。 3. 实际问题解出两个根后不检验，没有舍去不符合题意的根。

🔍 课堂讲义 · 重点难点解析

**重点一：用公式法解一元二次方程** 例题：用公式法解方程 3x² - 5x + 2 = 0。 分析：先化为一般形式（已经是），再确定 a、b、c，计算判别式，代入求根公式。 解答：a = 3，b = -5，c = 2；Δ = b² - 4ac = (-5)² - 4 × 3 × 2 = 25 - 24 = 1 大于 0，方程有两个不等的实数根。x = (5 ± √1) ÷ (2 × 3) = (5 ± 1) ÷ 6，所以 x₁ = (5 + 1) ÷ 6 = 1，x₂ = (5 - 1) ÷ 6 = 2/3。 小结：公式法是解一元二次方程的通法。关键是正确确定 a、b、c，注意把负数带括号代入，计算要细心。 **难点一：用配方法解方程** 例题：用配方法解方程 2x² + 4x - 6 = 0。 分析：配方前先把二次项系数化为 1，再按"移项、配方、开方、求解"四步做。 解答：两边同除以 2，得 x² + 2x - 3 = 0；移项得 x² + 2x = 3；配方：两边加 (2÷2)² = 1，得 x² + 2x + 1 = 4，即 (x + 1)² = 4；开方得 x + 1 = ±2；解得 x₁ = 1，x₂ = -3。 小结：配方方法的口诀是"一移二除三配方，四开五解"。配方时加的是"一次项系数一半的平方"，加到两边才不改变方程的解。 **难点二：判别式的应用** 例题：关于 x 的一元二次方程 kx² - 4x + 2 = 0 有两个不相等的实数根，求 k 的取值范围。 分析：方程是一元二次方程，k ≠ 0；有两个不相等实数根，判别式大于 0。 解答：Δ = (-4)² - 4 × k × 2 = 16 - 8k。因为有两个不相等实数根，所以 Δ 大于 0，即 16 - 8k 大于 0，解得 k 小于 2。又因为是一元二次方程，k ≠ 0。所以 k 的取值范围是 k 小于 2 且 k ≠ 0。 小结：这类题要同时考虑两个条件：二次项系数不为 0 和判别式的符号要求，缺一不可。 **难点三：实际问题建模与根的取舍** 例题：某工厂 2022 年产量为 100 万件，2024 年产量达到 144 万件，求这两年产量年平均增长率。 分析：设年平均增长率为 x，2023 年产量为 100(1 + x)，2024 年为 100(1 + x)²。 解答：列方程 100(1 + x)² = 144，即 (1 + x)² = 1.44，开方得 1 + x = ±1.2。因为增长率不为负，所以 1 + x = 1.2，x = 0.2 = 20%。答：年平均增长率为 20%。 小结：增长（下降）率问题设增长率为 x，经过 n 年后为原值乘 (1 + x) 的 n 次方；解出的负根要舍去。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：直接开平方法与因式分解法** 题目：解方程：（1）(x - 3)² = 16；（2）x² - 5x = 0。 分析：（1）左边是完全平方式，用直接开平方法；（2）左边有公因式 x，用因式分解法。 解答：（1）x - 3 = ±4，x₁ = 7，x₂ = -1。（2）x(x - 5) = 0，所以 x = 0 或 x - 5 = 0，x₁ = 0，x₂ = 5。 方法小结：看到"完全平方式 = 常数"用直接开平方；看到式子能提取公因式或能分解因式，优先用因式分解法，最简便。 **例题二（提高）：配方法解方程** 题目：用配方法解方程 x² - 8x + 12 = 0。 分析：二次项系数已是 1，直接移项配方。 解答：移项：x² - 8x = -12；配方：两边加 (8÷2)² = 16，得 x² - 8x + 16 = 4，即 (x - 4)² = 4；开方：x - 4 = ±2；解得 x₁ = 6，x₂ = 2。 方法小结：配方的关键是加"一次项系数一半的平方"。配方后左边的 (x - 4)² 中的 -4 就是一次项系数 -8 的一半，记住这一规律能减少错误。 **例题三（综合）：韦达定理与综合应用** 题目：已知关于 x 的一元二次方程 x² - (2k + 1)x + k² + 1 = 0 有两个不相等的实数根 x₁、x₂。 （1）求 k 的取值范围； （2）若 x₁ + x₂ = x₁ · x₂，求 k 的值。 分析：（1）判别式大于 0；（2）用韦达定理把两根和、两根积用 k 表示，代入条件解 k。 解答：（1）Δ = (2k + 1)² - 4(k² + 1) = 4k² + 4k + 1 - 4k² - 4 = 4k - 3。有两个不相等实数根，4k - 3 大于 0，k 大于 3/4。 （2）由韦达定理：x₁ + x₂ = 2k + 1，x₁ · x₂ = k² + 1。由 x₁ + x₂ = x₁ · x₂，得 2k + 1 = k² + 1，即 k² - 2k = 0，k(k - 2) = 0，k = 0 或 k = 2。又 k 大于 3/4，所以 k = 2（k = 0 舍去）。 方法小结：含参数的方程问题，先由判别式求出参数范围，再由韦达定理建立方程求解，最后检验结果是否在范围内。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念与基本解法

  1. 1. 把方程 x² - 4x = 5 化为一般形式，并说出它的二次项系数、一次项系数和常数项。
    答：化为一般形式：x² - 4x - 5 = 0。二次项系数 a = 1，一次项系数 b = -4，常数项 c = -5。注意化为一般形式后是 ax² + bx + c = 0 的形式，移项要变号。
  2. 2. 用直接开平方法解方程：x² = 25；（x - 2）² = 9。
    答：x² = 25，x = ±5；即 x₁ = 5，x₂ = -5。（x - 2）² = 9，x - 2 = ±3，x₁ = 5，x₂ = -1。直接开平方要取正负两个根。
  3. 3. 用因式分解法解方程：x² - 3x = 0；（x + 1）（x - 2）= 0。
    答：x² - 3x = 0，x(x - 3) = 0，x = 0 或 x = 3，x₁ = 0，x₂ = 3。（x + 1)(x - 2) = 0，x + 1 = 0 或 x - 2 = 0，x₁ = -1，x₂ = 2。依据是"若 A × B = 0，则 A = 0 或 B = 0"。

中等 · 公式法与配方法

  1. 1. 用公式法解方程：x² - 4x - 12 = 0。
    答：a = 1，b = -4，c = -12；Δ = (-4)² - 4 × 1 × (-12) = 16 + 48 = 64。x = (4 ± √64) ÷ 2 = (4 ± 8) ÷ 2，x₁ = 6，x₂ = -2。也可用因式分解：(x - 6)(x + 2) = 0。
  2. 2. 用配方法解方程：x² + 6x - 7 = 0。
    答：移项：x² + 6x = 7；配方：两边加 (6÷2)² = 9，得 x² + 6x + 9 = 16，即 (x + 3)² = 16；开方：x + 3 = ±4；x₁ = 1，x₂ = -7。配方时一次项系数 6 的一半是 3，其平方 9 要加到等式两边。
  3. 3. 用适当的方法解方程：2x² - 5x + 3 = 0。
    答：方法一（公式法）：a = 2，b = -5，c = 3；Δ = 25 - 24 = 1；x = (5 ± 1) ÷ 4，x₁ = 1，x₂ = 1.5（即 3/2）。方法二（因式分解）：(2x - 3)(x - 1) = 0，同样得 x₁ = 1，x₂ = 3/2。两种方法结果相同，说明解法选择不唯一。

难 · 判别式与韦达定理

  1. 1. 不解方程，判断方程 2x² - 3x + 4 = 0 的根的情况。
    答：Δ = (-3)² - 4 × 2 × 4 = 9 - 32 = -23 小于 0，所以方程没有实数根。判别式小于 0 时方程无实数根。
  2. 2. 已知方程 x² - 6x + k = 0 有两个相等的实数根，求 k 的值。
    答：方程有两个相等实数根，Δ = 0。Δ = (-6)² - 4 × 1 × k = 36 - 4k = 0，解得 k = 9。此时方程为 x² - 6x + 9 = 0，即 (x - 3)² = 0，两根相等。
  3. 3. 已知方程 x² - 3x - 5 = 0 的两个根为 x₁、x₂，求 x₁ + x₂ 和 x₁ · x₂ 的值。
    答：由韦达定理：x₁ + x₂ = -b/a = -(-3)/1 = 3，x₁ · x₂ = c/a = -5/1 = -5。韦达定理直接由系数可得两根之和与两根之积，无需解方程。

综合 · 实际应用与综合探究

  1. 1. 某商品原价每件 50 元，经过两次降价后降为每件 32 元，求两次降价的平均降价率。
    答：设平均降价率为 x，列方程 50(1 - x)² = 32，即 (1 - x)² = 0.64，1 - x = ±0.8。降价率 x 应在 0 到 1 之间，取 1 - x = 0.8，x = 0.2 = 20%。答：平均降价率为 20%。负根要舍去。
  2. 2. 一个长方形的长比宽多 4 米，面积为 96 平方米，求长方形的长和宽。
    答：设宽为 x 米，则长为 (x + 4) 米。列方程 x(x + 4) = 96，即 x² + 4x - 96 = 0，因式分解得 (x + 12)(x - 8) = 0，x₁ = -12（舍去），x₂ = 8。宽为 8 米，长为 8 + 4 = 12 米。答：长为 12 米，宽为 8 米。实际问题中负根不符合实际，必须舍去。
  3. 3. 某次聚会上，每两个人都要握一次手，一共握手 66 次，参加聚会的有多少人？
    答：设共有 n 人，则每人要与 (n - 1) 个人握手，两人之间只算一次，握手总次数 = n(n - 1) ÷ 2。列方程 n(n - 1) ÷ 2 = 66，即 n² - n - 132 = 0，因式分解得 (n - 12)(n + 11) = 0，n = 12 或 n = -11（舍去）。参加聚会的有 12 人。握手、比赛场次问题常用 "n(n - 1) ÷ 2" 建模。

💬 课后反馈

**学生常见错误** 1. 系数符号错误：用公式法时把负系数 b、c 代入出错，如把 b = -5 写成 5，导致判别式和求根公式算错。 2. 配方法漏步骤：忘记把二次项系数化为 1 就配方，或"一次项系数一半的平方"只加在一边，破坏了等式。 3. 直接开平方丢根：只写正根，漏写负根，如 x² = 9 只写 x = 3。 4. 实际问题不检验：解出两个根后不检验，把负根、不符合题意的根直接当答案，如面积问题中出现负边长。 **教学改进建议** 1. 建立解法选择表：让学生先观察方程结构再选方法，形成"能分解就分解，能开方就开方，否则用公式"的判断流程。 2. 强调"代入"的规范性：用公式法时要求学生把 a、b、c 连同符号写清楚，先算判别式再代公式，一步一检查。 3. 结合二次函数图像讲解判别式：判别式的三种情况对应抛物线与 x 轴交点的三种情况，帮助学生形象理解。 4. 实际问题教学采用"建模三步法"：画图或列表找等量关系、列方程、检验取舍，养成检验习惯。 **分层辅导建议** - 基础层：重点掌握直接开平方和因式分解两种方法，配方法、公式法先模仿再独立完成。 - 提高层：熟练掌握四种解法并能灵活选择，完成判别式确定参数范围的题型。 - 拓展层：完成韦达定理综合题和实际应用建模题，尝试一题多解并比较优劣。 **给家长的建议** 1. 让孩子每天口算 1-15 的平方数，为公式法和配方法打好计算基础。 2. 遇到应用题时，先让孩子说一说题目中的等量关系再动笔，培养建模意识。 3. 发现孩子用公式法总出错时，提醒他先写下"a、b、c 的值"再代入，步骤写清楚就能减少错误。
