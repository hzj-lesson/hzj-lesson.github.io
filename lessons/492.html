高中高一化学化学反应中的能量变化

📝 备课方案

**教学目标** 1. 了解化学反应中的能量变化，理解吸热反应与放热反应的判断依据。 2. 掌握化学键与化学反应中能量变化的关系（断裂吸收、形成释放）。 3. 理解反应热（焓变 ΔH）的概念，会书写热化学方程式。 4. 掌握盖斯定律，会利用盖斯定律进行反应热的计算。 **教学重点**：反应热 ΔH 的理解与热化学方程式书写，盖斯定律应用。 **教学难点**：ΔH 的符号判断与计算，热化学方程式中各物质状态对 ΔH 的影响。 **教学方法**：实验演示（中和热、铝热反应）、能量图分析、类比推导、计算训练。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、化学键与能量** - 化学反应的本质：旧化学键断裂 + 新化学键形成 - 键断裂吸收能量，键形成释放能量 - 反应热 = 断裂旧键吸收的总能量 - 形成新键释放的总能量 - 若断键吸收 < 成键释放 → 放热反应（ΔH<0）；反之吸热反应（ΔH>0） **二、放热反应与吸热反应** - 常见放热反应：燃烧、中和、金属与酸反应、铝热反应、大部分化合反应 - 常见吸热反应：C+CO₂=2CO、C+H₂O=CO+H₂、Ba(OH)₂·8H₂O 与 NH₄Cl 反应、大多数分解反应、铵盐溶解 - 判断依据：反应物总能量 > 生成物总能量 → 放热；反之吸热 **三、反应热与焓变 ΔH** - ΔH = 生成物总能量 - 反应物总能量 = 反应物键能总和 - 生成物键能总和 - 放热反应 ΔH<0，吸热反应 ΔH>0 - 单位：kJ/mol（指每摩尔反应） **四、热化学方程式** - 书写注意：①标注物质聚集状态（s、l、g、aq）②化学计量数表示物质的量，可为分数 ③ΔH 与计量数对应（计量数加倍，ΔH 加倍）④注明温度和压强（25℃、101 kPa 时可不写） **五、盖斯定律** - 内容：化学反应的反应热只与反应体系的始态和终态有关，与反应途径无关 - 应用：ΔH₁+ΔH₂=ΔH₃（方程式相加减，ΔH 相应加减） - 意义：可计算难以直接测定的反应热

🔍 课堂讲义 · 重点难点解析

**重点一：放热反应与吸热反应的判断** 1. 从能量角度：反应物总能量 > 生成物总能量 → 放热（多余能量以热能释放） 2. 从键能角度：断键吸能 < 成键放能 → 放热 3. 常见特例记忆：吸热反应常考的四个（C+CO₂、C+H₂O、Ba(OH)₂+NH₄Cl、大多数分解）；其余常见反应多为放热 4. 注意：放热反应也可能需要加热引发（如铝热反应需高温引发但本身是放热反应） **重点二：热化学方程式的书写规范（易错）** - 漏写状态：H₂(g) 与 H₂(l) 的 ΔH 不同（气态变液态放热） - 计量数与 ΔH 对应：2H₂(g)+O₂(g)=2H₂O(l) ΔH=-571.6 kJ/mol，若写 1 mol H₂，ΔH 应减半 - 可逆反应：热化学方程式写的是"反应进行到底"的 ΔH，不代表实际转化 - 判断正误常考：状态是否标注、ΔH 符号与计量数是否匹配 **难点：盖斯定律的计算** - 目标反应 = 若干已知反应线性组合 → ΔH 同样线性组合 - 例：已知 C(s)+O₂(g)=CO₂(g) ΔH₁、CO(g)+½O₂(g)=CO₂(g) ΔH₂，求 C(s)+½O₂(g)=CO(g) 的 ΔH：ΔH=ΔH₁-ΔH₂ - 步骤：①写出目标方程式 ②消元法（把中间物质消掉）③ΔH 同步运算 **常见误区** - ΔH 符号写反（放热写正） - 忘记"反应物总能量与生成物总能量比较"这一本质，死记反应类型 - 盖斯定律运算时 ΔH 忘记乘以系数或变号

✏️ 课堂讲义 · 典型例题精讲

**例1（键能计算）**：已知 H-H 键能 436 kJ/mol、Cl-Cl 键能 243 kJ/mol、H-Cl 键能 431 kJ/mol，计算 H₂(g)+Cl₂(g)=2HCl(g) 的反应热。 **解**：ΔH = 断键吸能 - 成键放能 = (436+243) - 2×431 = 679-862 = -183 kJ/mol。放热 183 kJ/mol。 **关键**：断键总和减成键总和。 **例2（能量图判断）**：某反应的能量变化图显示反应物总能量高于生成物总能量，判断该反应是吸热还是放热，ΔH 的符号？ **解**：反应物能量高，反应过程中能量降低，为放热反应，ΔH<0。 **关键**：能量降低放热。 **例3（热化学方程式正误）**：判断 "H₂(g)+O₂(g)=H₂O(l) ΔH=-285.8 kJ/mol" 是否书写正确（H₂ 未配平）。 **解**：该式未配平（H₂ 系数应为 1 时 O₂ 系数为 1/2），正确写法：H₂(g)+½O₂(g)=H₂O(l) ΔH=-285.8 kJ/mol，或 2H₂(g)+O₂(g)=2H₂O(l) ΔH=-571.6 kJ/mol。 **关键**：计量数可为分数，但必须与 ΔH 对应。 **例4（盖斯定律）**：已知： ①C(s)+O₂(g)=CO₂(g) ΔH₁=-393.5 kJ/mol ②CO(g)+½O₂(g)=CO₂(g) ΔH₂=-283.0 kJ/mol 求 C(s)+½O₂(g)=CO(g) 的反应热。 **解**：目标 = ①-②，ΔH = ΔH₁-ΔH₂ = -393.5-(-283.0) = -110.5 kJ/mol。 **关键**：目标反应由已知反应线性组合，ΔH 同步加减。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念理解

  1. 1. 化学反应中能量变化的本质是什么？
    答：化学键断裂吸收能量、形成释放能量，两者之差决定反应放热还是吸热。
  2. 2. 放热反应和吸热反应的 ΔH 符号分别是什么？
    答：放热反应 ΔH<0，吸热反应 ΔH>0。
  3. 3. 列举两个常见的放热反应和两个常见的吸热反应。
    答：放热：燃烧、中和反应；吸热：C+CO₂=2CO、Ba(OH)₂·8H₂O 与 NH₄Cl 的反应。

中等 · 能量与键能

  1. 1. 已知 H-H 键 436 kJ/mol，Cl-Cl 键 243 kJ/mol，H-Cl 键 431 kJ/mol，求 H₂+Cl₂=2HCl 的反应热。
    答：ΔH=(436+243)-2×431=-183 kJ/mol，放热 183 kJ/mol。
  2. 2. 为什么"放热反应不一定需要加热才反应"？举一例。
    答：放热反应是反应物总能量高于生成物总能量，一旦引发就会持续放热。如铝热反应需要高温引发，但本质是放热反应。
  3. 3. 热化学方程式书写有哪些注意事项？
    答：①标注物质状态；②计量数表示物质的量可为分数；③ΔH 与计量数对应；④注明温度压强（通常 25℃、101 kPa 可不写）。

难 · 盖斯定律

  1. 1. 已知 C(s)+O₂(g)=CO₂(g) ΔH=-393.5 kJ/mol，CO(g)+½O₂(g)=CO₂(g) ΔH=-283 kJ/mol，求 C(s)+½O₂(g)=CO(g) 的 ΔH。
    答：ΔH=ΔH₁-ΔH₂=-393.5-(-283)=-110.5 kJ/mol。
  2. 2. 已知 2H₂(g)+O₂(g)=2H₂O(l) ΔH=-571.6 kJ/mol，求 H₂(g)+½O₂(g)=H₂O(l) 的 ΔH。
    答：ΔH=-571.6/2=-285.8 kJ/mol。

综合 · 综合应用

  1. 1. 已知：CH₄(g)+2O₂(g)=CO₂(g)+2H₂O(l) ΔH=-890.3 kJ/mol，若燃烧 16 g 甲烷（M=16 g/mol），放热多少？
    答：16 g CH₄ 为 1 mol，放热 890.3 kJ。
  2. 2. 利用盖斯定律：已知 S(s)+O₂(g)=SO₂(g) ΔH₁=-296.8 kJ/mol，2SO₂(g)+O₂(g)=2SO₃(g) ΔH₂=-197.8 kJ/mol，求 2S(s)+3O₂(g)=2SO₃(g) 的 ΔH。
    答：2×①+②：ΔH=2×(-296.8)+(-197.8)=-791.4 kJ/mol。

💬 课后反馈

化学反应中的能量变化是化学热力学的入门章节，学生常见问题：ΔH 符号判断错误、键能与能量两种计算方法混淆、热化学方程式状态标注遗漏、盖斯定律运算时系数和符号处理失误。建议：用能量图（反应物-生成物能量高低）建立直观判断；把"断键吸能减成键放能"和"生成物能量减反应物能量"两种方法对比讲解；盖斯定律用"消元法"配以专项计算训练，强调 ΔH 与计量数同倍变化。
