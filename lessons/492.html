高中高二语文《古文：阿房宫赋》教案

高中高二语文古文：阿房宫赋

📝 备课方案

**教学目标** 1. 结合注释疏通全文，积累「毕、一、兀、举、族、鉴」等重点实词和「焉、而、之」等虚词，掌握名词作动词、意动用法与判断句、被动句等文言现象。 2. 了解「赋」体「铺采摛文、体物写志」的特点，赏析本文铺排夸饰、骈散结合的语言艺术。 3. 理清「铺叙阿房宫—议论秦之亡—讽谏当世」的思路，理解借古讽今的写法与「爱民」的主旨。 4. 知人论世，了解杜牧写作本文的时代背景，认识「后人哀之而不鉴之」的警世意义。 **教学重点**：落实文言字词句；把握赋体铺排夸饰的特点与文章由叙到议的思路。 **教学难点**：理解「鼎铛玉石，金块珠砾」等意动用法；体会结尾「后人哀之而不鉴之」的层层递进的讽谏力量。 **教学方法**：诵读法、字词归纳法、诵读与品析结合法、比较阅读法。 **教学准备**：多媒体课件（阿房宫复原图、朗诵音频）、杜牧生平与晚唐背景资料、文言字词梳理卡片。 **课时安排**：3 课时（第 1 课时：通读正音、疏通一至二段；第 2 课时：疏通三至四段、归纳文言现象；第 3 课时：赏析赋体手法、探究主旨与诵读成篇）。

📖 课堂讲义 · 核心知识点

**一、作者与背景** 杜牧（803-852），字牧之，号樊川居士，京兆万年（今陕西西安）人，晚唐杰出的诗人、散文家，与李商隐并称「小李杜」，为别于杜甫，人称「小杜」。26 岁举进士，官至中书舍人，有《樊川文集》传世。诗以七绝最工，如《泊秦淮》《赤壁》《过华清宫绝句》等，咏史怀古诗尤见识力。 本文作于唐敬宗宝历元年（825），时杜牧年仅 23 岁。敬宗即位后大起宫室、沉溺声色，朝政日非。杜牧在《上知己文章启》中自述：「宝历大起宫室，广声色，故作《阿房宫赋》。」文章借秦筑阿房宫、奢而速亡的史事讽谏当世，是借古讽今的典范。 **二、赋体特点** 赋是介于诗与散文之间的文体，讲求「铺采摛文，体物写志」：用铺陈排比渲染事物，用夸饰之辞增强气势，多押韵、多对偶。本文骈散结合：铺叙部分四六成句、音韵铿锵，议论部分散句推进、斩截有力，充分体现了唐代文赋骈散交融的风貌。 **三、结构思路** | 段落 | 内容 | 手法 | |---|---|---| | 第 1 段 | 建宫之因与宫之壮丽（六王毕，四海一→覆压三百余里→五步一楼，十步一阁） | 铺排、夸饰、比喻（长桥如龙、复道如虹） | | 第 2 段 | 宫中人物：宫人之多、珍宝之富（明星荧荧，开妆镜也→鼎铛玉石，金块珠砾） | 铺排、判断句群、夸张 | | 第 3 段 | 由奢到亡：取之尽锱铢，用之如泥沙→戍卒叫，函谷举，楚人一炬，可怜焦土 | 排比比较、递进 | | 第 4 段 | 议论：灭六国者六国也……后人哀之而不鉴之 | 散句议论、假设推理 | 前半极写其盛，后半痛写其亡，盛衰对照，讽喻自见。 **四、重点实词虚词** | 类别 | 例句 | 讲解 | |---|---|---| | 通假/避讳 | 剽掠其人 | 「人」即「民」，避唐太宗李世民讳 | | 名词作动词 | 六王毕，四海一 | 一：数词作动词，统一 | | 名词作动词 | 蜀山兀 | 兀：形容词作动词，（树木被砍尽而）山秃 | | 名词作动词 | 辇来于秦 | 辇：名词作状语，乘辇车 | | 名词作动词 | 朝歌夜弦 | 歌、弦：名词作动词，唱歌、弹琴 | | 名词作动词 | 族秦者秦也 | 族：名词作动词，灭族 | | 意动用法 | 鼎铛玉石，金块珠砾 | 把鼎当作铛，把玉当作石，把金当作土块，把珠当作石子 | | 动词作名词 | 燕赵之收藏，韩魏之经营 | 收藏、经营：指收藏、聚敛的金玉珍宝 | | 重点虚词 | 杳不知其所之也 | 之：动词，到、往 | | 重点虚词 | 盘盘焉，囷囷焉 | 焉：形容词词尾，……的样子 | | 重点虚词 | 不敢言而敢怒 | 而：连词，表转折 | | 重点虚词 | 后人哀之而不鉴之 | 而：表转折；之：代词，指秦（统治者） | **五、特殊句式** 1. 判断句：「灭六国者六国也，非秦也」「族秦者秦也，非天下也」，「……者……也」表判断，斩钉截铁。 2. 被动句：「戍卒叫，函谷举」，「举」意为被攻占，意念被动。 3. 宾语前置：「秦人不暇自哀」，即「不暇哀自」，来不及为自己哀叹。 4. 省略句：「（阿房宫）覆压三百余里，（阿房宫）隔离天日」。 **六、名句与主旨** 「秦爱纷奢，人亦念其家。奈何取之尽锱铢，用之如泥沙」——以对偶与反问揭示掠夺之酷；「灭六国者六国也，非秦也；族秦者秦也，非天下也」——指出亡国根源在统治者自身不爱其民；「秦人不暇自哀，而后人哀之；后人哀之而不鉴之，亦使后人而复哀后人也」——层层推演，警醒后世以秦为鉴，戒奢爱民。

🔍 课堂讲义 · 重点难点解析

**重点一：意动用法的理解** 例题：「鼎铛玉石，金块珠砾」四个词类活用应如何理解？ 分析：鼎、玉、金、珠本为名物，铛、石、块、砾为低贱之物，此句以名物名物。 解答：铛、石、块、砾在此是意动用法（以名词的宾语地位构成「把……当作……」）：把宝鼎看作铁锅，把美玉看作石头，把黄金看作土块，把珍珠看作石子。四组「贵物贱用」的对照，写尽秦人挥霍无度，为下文「取之尽锱铢，用之如泥沙」的议论张本。 小结：意动用法题按「译成把……当作……」处理，再联系语境说效果。 **重点二：铺排与夸饰的赋家笔法** 例题：第 1 段「五步一楼，十步一阁」「矗不知其几千万落」在写法上有何特点？ 分析：赋以铺陈为能事，数字与排比并用。 解答：「五步」「十步」极言楼阁之密，「几千万落」极言其多，皆属夸饰；「廊腰缦回，檐牙高啄」「盘盘焉，囷囷焉」以比喻与叠词状其形态，四六句式连绵铺排，音节铿锵。铺排夸饰把阿房宫的壮丽写到极致，为下文「楚人一炬，可怜焦土」的骤然崩塌蓄足反差之力。 小结：赏析铺排，须兼顾「修辞＋句式＋蓄势功能」三个层面。 **难点一：借古讽今的层次** 例题：第 4 段「秦人不暇自哀，而后人哀之；后人哀之而不鉴之，亦使后人而复哀后人也」是怎样层层推进的？ 分析：抓住「哀」与「鉴」两个动词的转换，注意「后人」的多层所指。 解答：第一层，秦人来不及为自己哀叹，只有后人替它哀叹——亡国之祸秦己未知；第二层，后人哀叹秦却不引以为鉴，那么「后人」也会步秦后尘，被更后的人所哀叹。由「哀」到「鉴」，由「秦」到「后人」，三层递进，把讽谏的矛头从历史推向当下（唐敬宗大起宫室），言在此而意在彼，讽喻警醒之力极强。 小结：递进句群题要理清「代词所指」与「动词转换」，方能见其逻辑之力。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：重点句子翻译** 题目：翻译「六王毕，四海一；蜀山兀，阿房出」。 分析：四个短句四个关键字——毕、一、兀、出，注意「一」「兀」的活用。 解答：六国灭亡了，天下统一了；蜀山的树木被砍光了，阿房宫建成了。要点：「毕」为完结，「一」为统一（数词活用为动词），「兀」为山秃（形容 詞活用为动词）。十二字写尽秦统一天下、大兴土木的进程，对偶精工，起势峻拔。 方法小结：翻译短句先定活用，再补足语意，力求简练。 **例题二（提高）：判断句群赏析** 题目：「明星荧荧，开妆镜也；绿云扰扰，梳晓鬟也……」这一组句子采用什么句式？有何表达效果？ 分析：每句以「……也」收束，先设景后解释，实为一组解释性判断句。 解答：这是连续的解释性判断句（「……也」表判断兼解释），先写「明星荧荧」「绿云扰扰」「烟斜雾横」「雷霆乍惊」等景象，再揭示其为宫人开镜、梳鬟、焚香、宫车经过。倒果为因、层层设疑，铺排出宫女之众、宫廷生活之奢；四个「也」字连用，节奏铿锵，如画卷徐徐展开，尽显赋体铺排之美。 方法小结：判断句群题从「句式特点＋铺排效果＋表现内容」三方面作答。 **例题三（综合）：主旨探究** 题目：「使六国各爱其人，则足以拒秦；使秦复爱六国之人，则递三世可至万世而为君」两个假设句在议论中有何作用？ 分析：两个假设分别指向六国与秦，其归结点是同一个「爱」字。 解答：假设六国各自爱护本国民众，就足以抗拒秦的兼并；假设秦也爱护六国遗民，就能传之三世以至万世。两个假设从正面对「仁爱其民」的意义作反证式推演，与「族秦者秦也」的判断互为表里，把全文议论凝聚为一个「爱民」的核心——不爱其民者亡，爱民者昌，讽谏当世之意不言自明。 方法小结：假设句的作用题，抓住「假设条件」与「结论指向」的对应关系。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 名句默写与字词释义

  1. 1. 默写：六王毕，________；蜀山兀，________。覆压三百余里，________。
    答：六王毕，四海一；蜀山兀，阿房出。覆压三百余里，隔离天日。注意「覆压」「隔离」的写法。
  2. 2. 解释加点词：①六王毕（毕）②直走咸阳（走）③不霁何虹（霁）④函谷举（举）⑤族秦者秦也（族）。
    答：①毕：完结；②走：趋向；③霁：雨后初晴；④举：被攻占；⑤族：灭族（名词作动词）。
  3. 3. 默写结尾两句：「秦人不暇自哀，________；________，亦使后人而复哀后人也。」
    答：秦人不暇自哀，而后人哀之；后人哀之而不鉴之，亦使后人而复哀后人也。注意「暇」「鉴」的写法。

中等 · 课内翻译与文言现象

  1. 1. 翻译：鼎铛玉石，金块珠砾，弃掷逦迤，秦人视之，亦不甚惜。
    答：（秦人）把宝鼎当作铁锅，把美玉当作石头，把黄金当作土块，把珍珠当作石子，扔得到处都是，秦人看到这些，也不觉得很可惜。要点：四个名词的意动用法；逦迤，连绵不断（此处指抛弃得到处都是）。
  2. 2. 指出下列句中的词类活用并释义：①四海一 ②辇来于秦 ③朝歌夜弦 ④燕赵之收藏，韩魏之经营。
    答：①「一」，数词作动词，统一；②「辇」，名词作状语，乘辇车；③「歌」「弦」，名词作动词，唱歌、弹琴；④「收藏」「经营」，动词作名词，指收藏、聚敛的金玉珍宝。
  3. 3. 翻译：戍卒叫，函谷举，楚人一炬，可怜焦土！
    答：戍边的士卒（陈胜、吴广起义）一声呐喊，函谷关被攻占，楚人（项羽）放一把火，可惜（富丽堂皇的阿房宫化为）一片焦土！要点：「举」含被动，「一炬」为数量词活用为动词（放一把火），「可怜」是可惜（古今异义）。

难 · 手法鉴赏与句式分析

  1. 1. 第 3 段「使负栋之柱，多于南亩之农夫……」连用六个「多于」的比较句，有怎样的表达效果？
    答：连用六组比较，将宫殿的柱、椽、钉头、瓦缝、栏杆、管弦与农夫、工女、粟粒、帛缕、城郭、人语一一对比，极言秦取之奢、用之费；排比铺陈如数家珍，数字对照触目惊心，为「天下之人，不敢言而敢怒」的爆发蓄势，赋体之铺排在议论中大显威力的典型。
  2. 2. 「长桥卧波，未云何龙？复道行空，不霁何虹？」两个问句有何妙处？
    答：以疑问句写比喻：见长桥卧于水上，无云何以有龙？见复道凌空，天未放晴何以有虹？先以龙、虹设疑，妙在把建筑比作神奇景象而不直说，问中含赞，写出阿房宫建筑之奇巧壮丽，笔致空灵摇曳。
  3. 3. 「秦人不暇自哀」一句存在宾语前置现象，请还原语序并说明这类句式在文言中的规律。
    答：「自哀」即「哀自」，哀叹自己，代词「自」作宾语前置于动词之前。规律：文言中代词作宾语，在否定句或强调语境中常置于动词前，如「不暇自哀」「忌不自信」。本句前置于篇末议论，突显秦人「不及自省」之态，为「后人哀之」的递进张本。

综合 · 比较阅读与探究写作

  1. 1. 比较阅读：《阿房宫赋》与《过秦论》（贾谊）同为借古讽今之作，试从文体与议论角度比较其异同。
    答：同：都以秦之兴亡为镜，归结于「仁爱其民」方能长治久安，借古讽今。异：《过秦论》为史论散文，以叙述史实为主、末段点题，气盛而言直；《阿房宫赋》为赋体，以铺排描写为主、叙议结合，形象而言婉。一重史理，一重辞采，各极其妙。
  2. 2. 「后人哀之而不鉴之，亦使后人而复哀后人也」，请结合杜牧写作背景，谈谈这句话对唐敬宗乃至后世的警示意义。
    答：敬宗大起宫室、广声色，与秦之奢靡如出一辙。杜牧以秦喻唐：若当政者只知哀叹秦亡而不引为鉴戒，重蹈奢靡覆辙，必将被后人所哀。这句话把历史的教训推向当下的现实，警示统治者戒奢从俭、爱惜民力，也警示一切后来者以史为鉴——这正是文章超越时代的思想意义。
  3. 3. 微写作（200 字左右）：以「由《阿房宫赋》想到的」为题，联系历史或现实写一段议论文字，须引用原文一句并有自己的观点。
    答：示例：杜牧说「后人哀之而不鉴之，亦使后人而复哀后人也」，一句话道尽历史的循环。阿房宫的焦土犹在眼前，唐敬宗的宫室又已动工；修的是宫殿，塌的是人心。历史上多少王朝，不是亡于强敌，而是亡于忘记为什么强大。以史为鉴，不是背诵教训，而是在每一次欲望面前想起那句「可怜焦土」。（引用准确、观点明确即可酌情给分）

💬 课后反馈

**学生常见错误** 1. 实词释义想当然：「毕」误译为「完毕生活」，「举」漏看被动，「可怜」按今义理解为「值得怜悯」。 2. 意动用法不会翻译：「鼎铛玉石，金块珠砾」答不出「把……当作……」，或与使动混淆。 3. 「后人」的所指理不清：结尾三层递进读成简单重复，说不出「哀」与「鉴」的转换之妙。 4. 默写失分：「逦迤」「剽掠」「锱铢」「呕哑」等生僻词易错，长句铺排处易漏字。 **教学改进建议** 1. 字词教学用「分类归档」：活用（名词作动词、意动）、通假避讳、古今异义三类分表梳理，配合课后检测滚动过关。 2. 诵读分层推进：一至二段读出铺排的气势与节奏，三至四段读出议论的顿挫与斩截，以声气体会骈散之别。 3. 主旨探究提供《上知己文章启》材料，让学生把「宝历大起宫室」与文末讽谏对应，真正理解借古讽今的笔法。 **分层辅导建议** - 基础层：过关重点实词虚词、活用句式与两处名句默写，能顺畅朗读并翻译主要段落。 - 提高层：掌握判断句群、排比比较等赋体手法的赏析规范，能分层解读结尾递进句。 - 拓展层：对读《过秦论》全文，写一篇「秦亡教训」的比较短评，训练史论思维。 **给家长的建议** 1. 请孩子把第 1 段与第 4 段分别朗读给家人听，家长可问「哪句最有气势、哪句最发人深省」，帮助孩子积累文言语感。 2. 鼓励孩子把「后人哀之而不鉴之」的道理讲给家人听，并结合身边事例谈谈「以史为鉴」，锻炼思辨表达。
