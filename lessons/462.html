高中高一化学《物质分类与化学反应》教案

高中高一化学物质分类与化学反应

📝 备课方案

**教学目标** 1. 能运用树状分类法和交叉分类法对常见物质进行分类，掌握单质、氧化物、酸、碱、盐的概念，能准确判断典型物质（如 Fe₂O₃、NaHCO₃、盐酸、冰水混合物等）所属类别。 2. 认识分散系及其分类依据，掌握胶体的本质特征（分散质粒子直径介于 1~100 nm 之间）与丁达尔效应、介稳性等性质，能制备氢氧化铁胶体并说出操作注意事项。 3. 掌握化合、分解、置换、复分解四种基本反应类型，能从化合价升降和电子转移的角度理解氧化还原反应，会判断氧化剂与还原剂，会分析电子转移的方向和数目。 4. 理解电解质与非电解质、离子反应的概念，掌握离子方程式的书写步骤与拆分规则，能判断离子方程式的正误。 **教学重点**：物质分类树的建构；氧化还原反应的特征与本质；离子方程式的书写。 **教学难点**：氧化还原反应中电子转移方向与数目的表示；离子方程式中强电解质的拆分判断。 **教学方法**：概念图解法、表格对比法、实验演示法、小组讨论法。 **教学准备**：激光笔、新制 Fe(OH)₃ 胶体与 CuSO₄ 溶液、半透膜与滤纸、物质分类卡片、课件、任务单。 **课时安排**：3 课时（第 1 课时：物质的分类与胶体；第 2 课时：四种基本反应类型与氧化还原反应；第 3 课时：电解质与离子方程式）。

📖 课堂讲义 · 核心知识点

**一、物质的分类（树状分类法）** 分类是研究和学习化学的常用方法，树状分类法按照层次一级一级向下分： 纯净物（只含一种物质） - 单质：金属单质（Fe、Cu）、非金属单质（O₂、C） - 化合物：氧化物（CO₂、Fe₂O₃）、酸（HCl、H₂SO₄）、碱（NaOH、Ca(OH)₂）、盐（NaCl、Na₂CO₃） 混合物（含两种或以上物质）：空气、盐酸、溶液、胶体、合金 | 类别 | 定义要点 | 实例 | 易错点 | |---|---|---|---| | 单质 | 同种元素组成的纯净物 | O₂、Fe | O₃ 与 O₂ 混合是混合物 | | 氧化物 | 两种元素组成，其一为氧 | CO₂、CaO | 不含「两种元素」的不叫氧化物 | | 酸 | 电离出的阳离子全部是 H⁺ | H₂SO₄ | NaHSO₄ 电离还有 Na⁺，是盐 | | 碱 | 电离出的阴离子全部是 OH⁻ | NaOH | 氨水是碱但 NH₃ 本身不是 | | 盐 | 金属离子（或 NH₄⁺）与酸根离子 | Na₂CO₃、NH₄Cl | 酸式盐、碱式盐都是盐 | 交叉分类法：一种物质可从多个角度归类，如 Na₂CO₃ 既是钠盐又是碳酸盐。 酸性氧化物不一定是非金属氧化物（如 Mn₂O₇ 是金属氧化物却是酸性氧化物）；碱性氧化物一定是金属氧化物，但金属氧化物不一定是碱性氧化物（Al₂O₃ 是两性氧化物）。 **二、分散系与胶体** 把一种（或多种）物质分散到另一种（或多种）物质中得到的体系叫分散系，被分散的物质叫分散质，起分散作用的叫分散剂。按分散质粒子直径大小分三类： | 分散系 | 粒子直径 | 外观 | 稳定性 | 实例 | |---|---|---|---|---| | 溶液 | 小于 1 nm | 均一透明 | 稳定 | 食盐水 | | 胶体 | 1~100 nm | 较均一 | 介稳定 | Fe(OH)₃ 胶体、豆浆、烟雾 | | 浊液 | 大于 100 nm | 不均一浑浊 | 不稳定 | 泥水、油水 | 胶体的三大性质： 1. 丁达尔效应：用激光笔照射，有一条光亮的「通路」，可用于区分胶体与溶液。 2. 介稳性：胶体粒子直径小、具有布朗运动和胶粒带电，稳定性介于溶液与浊液之间。 3. 透过性：胶体能透过滤纸，不能透过半透膜（可用渗析法提纯胶体）。 氢氧化铁胶体的制备：向沸水中滴加几滴饱和 FeCl₃ 溶液，继续加热至液体呈红褐色，停止加热。方程式：FeCl₃ + 3H₂O =（△）Fe(OH)₃（胶体）+ 3HCl。注意：不能用自来水（含电解质会使胶体聚沉）、不能搅拌、不能久煮。 **三、四种基本反应类型** | 类型 | 通式 | 举例 | 与氧化还原的关系 | |---|---|---|---| | 化合反应 | A + B → AB | CaO + H₂O = Ca(OH)₂ | 有单质参加的化合多为氧化还原 | | 分解反应 | AB → A + B | CaCO₃ =（高温）CaO + CO₂↑ | 有单质生成的分解多为氧化还原 | | 置换反应 | A + BC → AC + B | Fe + CuSO₄ = FeSO₄ + Cu | 一定是氧化还原反应 | | 复分解反应 | AB + CD → AD + CB | NaOH + HCl = NaCl + H₂O | 一定不是氧化还原反应 | **四、氧化还原反应** 特征（判断依据）：反应前后元素化合价有升降。本质：电子的转移（得失或偏移）。 记忆口诀：**升失氧、降得还**——化合价升高、失去电子、被氧化、作还原剂；化合价降低、得到电子、被还原、作氧化剂。 氧化剂与还原剂是同时存在、相互依存的： | 角色 | 化合价 | 电子 | 性质变化 | 常见物质 | |---|---|---|---|---| | 氧化剂 | 降低 | 得电子 | 被还原、发生还原反应 | O₂、Cl₂、浓硫酸、HNO₃、KMnO₄、Fe³⁺ | | 还原剂 | 升高 | 失电子 | 被氧化、发生氧化反应 | H₂、C、CO、活泼金属、Fe²⁺、I⁻ | 分析电子转移常用双线桥：在方程式上下画箭头，标出「失去/得到几个电子」。例如 2Na + Cl₂ = 2NaCl 中，每个 Na 原子失去 1 个电子化合价由 0 升到 +1，每个 Cl 原子得到 1 个电子化合价由 0 降到 -1，反应中共转移 2 个电子。 **五、电解质与离子反应** 电解质：在水溶液中或熔融状态下能导电的**化合物**，包括酸、碱、盐、活泼金属氧化物和水。非电解质：在上述条件下都不导电的化合物，如蔗糖、酒精、CO₂、SO₂、NH₃（CO₂ 等是先与水反应生成酸后才电离，自身不电离）。单质既不是电解质也不是非电解质。 离子反应：电解质在溶液中的反应实质上是离子之间的反应。 离子方程式书写四步：写（写出正确的化学方程式）、拆（把易溶且易电离的强酸、强碱、可溶盐拆成离子符号）、删（删去方程式两边相同的离子）、查（检查质量守恒与电荷守恒）。 拆分口诀：**强酸、强碱、可溶盐，拆成离子写两边；沉淀、气体、弱电解质（水、弱酸、弱碱）、氧化物，保留化学式写原样。** 示例：盐酸与碳酸钙：CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑；强酸与强碱中和的实质：H⁺ + OH⁻ = H₂O；铁与硫酸铜溶液：Fe + Cu²⁺ = Fe²⁺ + Cu。 **易错提醒** 1. 冰水混合物是纯净物（只含 H₂O）；盐酸是混合物，但 HCl 是电解质。 2. 单质和化合物按「是否同种元素、是否纯净物」判断，不能只看元素名称。 3. 置换反应一定是氧化还原反应，但氧化还原反应不一定是置换反应（如 CO 还原 Fe₂O₃）。 4. 电荷不守恒是离子方程式书写最常见错误，写完必查两边的电荷总数。

🔍 课堂讲义 · 重点难点解析

**重点一：用树状分类法给物质「上户口」** 例题：将 Na₂CO₃、CuO、稀硫酸、O₃、KOH、空气、蒸馏水、铁粉分别归入纯净物或混合物，再把纯净物进一步细分。 分析：先看组成物质种类数分混合物与纯净物；纯净物再按元素种数分单质与化合物；化合物按性质分氧化物、酸、碱、盐。 解答：混合物有稀硫酸（硫酸和水）、空气；纯净物有 Na₂CO₃（盐）、CuO（金属氧化物）、O₃（非金属单质）、KOH（碱）、蒸馏水（氧化物）、铁粉（金属单质）。 小结：分类先定「纯净/混合」，再逐级向下；注意盐酸、溶液、合金都是混合物。 **难点一：胶体的本质与丁达尔效应** 例题：用激光笔分别照射盛有 CuSO₄ 溶液和 Fe(OH)₃ 胶体的两只烧杯，现象有什么不同？能否用丁达尔效应区分二者？ 分析：CuSO₄ 溶液中分散质粒子直径小于 1 nm，Fe(OH)₃ 胶体粒子直径在 1~100 nm 之间，能对光散射。 解答：Fe(OH)₃ 胶体中出现一条光亮的「通路」，CuSO₄ 溶液没有，此现象可区分二者。注意：溶液是否有颜色与丁达尔效应无关，有色的 CuSO₄ 溶液也不会出现光路。 小结：胶体区别于溶液的本质特征是分散质粒子直径在 1~100 nm 之间，丁达尔效应只是外在表现。 **难点二：氧化还原反应中电子转移的分析** 例题：H₂ 还原 CuO 的反应 H₂ + CuO =（△）Cu + H₂O 中，指出氧化剂、还原剂、被氧化与被还原的元素，并分析电子转移。 分析：Cu 由 +2 价降到 0 价得电子，H 由 0 价升到 +1 价失电子。 解答：CuO 是氧化剂（Cu 被还原），H₂ 是还原剂（H 被氧化），每生成 1 个 H₂O 分子转移 2 个电子。 再看一道歧化反应：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ 中，Na₂O₂ 中氧为 -1 价，一部分升到 0 价（O₂）失电子，一部分降到 -2 价（NaOH）得电子，Na₂O₂ 既是氧化剂又是还原剂。 小结：先标化合价，再看升降定角色；同种元素同一价态部分升部分降的反应叫歧化反应，该物质既作氧化剂又作还原剂。 **易错警示：复分解反应一定不是氧化还原反应** 例题：判断 HCl + NaOH = NaCl + H₂O 是否为氧化还原反应。 解答：反应前后各元素化合价均无变化（H +1、Cl -1、Na +1、O -2），不属于氧化还原反应。复分解反应只是离子互换，一定没有电子转移。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：物质类别判断** 题目：下列物质中，属于纯净物的是（ ），属于酸性氧化物的是（ ）。A. 冰水混合物 B. 纯净的盐酸 C. CO₂ D. Na₂CO₃ E. 澄清石灰水 分析：纯净物只含一种物质；酸性氧化物是能与碱反应生成盐和水的氧化物。 解答：冰水混合物只含 H₂O 一种物质，是纯净物，选 A；CO₂ 能与 NaOH 反应生成 Na₂CO₃ 和水，是酸性氧化物，选 C。盐酸、石灰水是混合物；Na₂CO₃ 是盐。 方法小结：判断物质类别抓住两条——组成物质种数（纯净/混合）与组成元素种数（单质/化合物），不能被「混合物」字样迷惑。 **例题二（提高）：离子方程式的书写与正误判断** 题目：写出下列反应的离子方程式，并判断正误：(1) 稀硫酸与氢氧化钡溶液反应；(2) 碳酸钙与稀盐酸反应；(3) 铁与稀硫酸反应。 分析：先写化学方程式，再按「拆、删、查」处理。拆分时注意 BaSO₄ 是沉淀不能拆。 解答： (1) H₂SO₄ + Ba(OH)₂ = BaSO₄↓ + 2H₂O，离子方程式：2H⁺ + SO₄²⁻ + Ba²⁺ + 2OH⁻ = BaSO₄↓ + 2H₂O。 (2) CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑，离子方程式：CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑（CaCO₃ 保留化学式）。 (3) Fe + H₂SO₄ = FeSO₄ + H₂↑，离子方程式：Fe + 2H⁺ = Fe²⁺ + H₂↑。 方法小结：离子方程式写完必查三守恒——质量守恒、电荷守恒、电子（得失）守恒；常见错误是把 BaSO₄、CaCO₃、H₂O 等弱电解质或沉淀拆成了离子。 **例题三（综合）：氧化还原综合分析** 题目：向 CuSO₄ 溶液中加入过量铁粉，析出红色固体。反应方程式为 Fe + CuSO₄ = FeSO₄ + Cu。(1) 指出氧化剂和还原剂；(2) 若加入 5.6 g 铁粉恰好完全反应，求析出铜的质量，并计算转移电子的物质的量。 分析：Fe 化合价由 0 升到 +2 失 2 个电子作还原剂，Cu²⁺ 由 +2 降到 0 得 2 个电子作氧化剂。按方程式 Fe ~ Cu ~ 2e⁻ 计算。 解答： (1) CuSO₄（Cu²⁺）是氧化剂，Fe 是还原剂。 (2) 设析出铜的质量为 x。 n(Fe) = 5.6 g ÷ 56 g/mol = 0.1 mol Fe + CuSO₄ = FeSO₄ + Cu 1 mol …… 1 mol 0.1 mol …… x 所以 n(Cu) = 0.1 mol，x = 0.1 mol × 64 g/mol = 6.4 g。 每 1 mol Fe 反应转移 2 mol 电子，转移电子 n(e⁻) = 0.1 mol × 2 = 0.2 mol。 答：析出铜 6.4 g，转移电子 0.2 mol。 方法小结：氧化还原计算抓住「电子守恒」或方程式比例关系，先算物质的量再算质量。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 分类与概念辨析

  1. 1. 将下列物质分类：Na₂CO₃、CuO、盐酸、O₃、KOH、空气、蒸馏水、铁粉。写出哪些是混合物，哪些是纯净物，并把纯净物归类（单质/氧化物/酸/碱/盐）。
    答：混合物：盐酸（HCl 的水溶液）、空气。纯净物：O₃（非金属单质）、铁粉（金属单质）、蒸馏水（氧化物）、CuO（金属氧化物）、KOH（碱）、Na₂CO₃（盐）。判断依据：混合物含多种物质，纯净物只含一种物质。
  2. 2. 写出符合下列条件的化学方程式各一个：化合反应、分解反应、置换反应、复分解反应，并指出其中哪些是氧化还原反应。
    答：示例：化合 C + O₂ =（点燃）CO₂（是氧化还原）；分解 2H₂O =（通电）2H₂↑ + O₂↑（是氧化还原）；置换 Fe + CuSO₄ = FeSO₄ + Cu（一定是氧化还原）；复分解 NaOH + HCl = NaCl + H₂O（一定不是氧化还原）。
  3. 3. 填空：氧化还原反应的特征是反应前后有________，本质是有________；化合价升高的反应物________电子，被________，作________剂。
    答：特征：化合价升降；本质：电子转移（得失或偏移）。化合价升高的反应物失去电子，被氧化，作还原剂。口诀：升失氧、降得还。

中等 · 胶体与电解质运用

  1. 1. 下列事实与胶体性质无关的是（ ）：A. 用激光笔照射豆浆出现光亮通路；B. 河流入海口形成三角洲；C. 将泥水静置后变澄清；D. 胶体能透过滤纸但不能透过半透膜。说明理由。
    答：选 C。泥水是浊液，静置澄清是浊液中大颗粒沉降，与胶体性质无关。A 是丁达尔效应；B 是海水中电解质使胶体聚沉；D 是胶体粒子的透过性特点。
  2. 2. 下列物质中，属于电解质的是________，属于非电解质的是________：NaCl、蔗糖、熔融 NaOH、铜丝、CO₂、蒸馏水、酒精。
    答：电解质：NaCl、熔融 NaOH、蒸馏水（水是极弱电解质）。非电解质：蔗糖、酒精、CO₂。铜丝是单质，既不是电解质也不是非电解质。注意 CO₂ 自身不能电离，是非电解质。
  3. 3. 写出下列反应的离子方程式：(1) 稀硫酸与氢氧化钡溶液；(2) 碳酸氢钠溶液与足量稀盐酸；(3) 铁与稀盐酸。
    答：(1) 2H⁺ + SO₄²⁻ + Ba²⁺ + 2OH⁻ = BaSO₄↓ + 2H₂O；(2) HCO₃⁻ + H⁺ = H₂O + CO₂↑（NaHCO₃ 是可溶盐要拆，HCO₃⁻ 是弱酸酸式根不能拆成 CO₃²⁻ 和 H⁺）；(3) Fe + 2H⁺ = Fe²⁺ + H₂↑。

难 · 氧化还原深度分析

  1. 1. 将 7.8 g 过氧化钠（Na₂O₂）加入足量水中，完全反应：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑。求：(1) 标准状况下生成 O₂ 的体积；(2) 指出氧化剂和还原剂；(3) 计算转移电子的物质的量（写出设、写、算、答）。
    答：设生成 O₂ 的物质的量为 x。n(Na₂O₂) = 7.8 g ÷ 78 g/mol = 0.1 mol。由方程式 2Na₂O₂ ~ 1 O₂，得 x = 0.05 mol，标况体积 V = 0.05 mol × 22.4 L/mol = 1.12 L。(2) Na₂O₂ 中氧为 -1 价，反应后部分升为 0 价、部分降为 -2 价，Na₂O₂ 既是氧化剂又是还原剂（歧化反应）。(3) 每 2 mol Na₂O₂ 转移 2 mol 电子，故转移电子 0.1 mol。答：O₂ 为 1.12 L，转移电子 0.1 mol。
  2. 2. 下列离子方程式正确的是（ ）：A. 铁与稀盐酸：2Fe + 6H⁺ = 2Fe³⁺ + 3H₂↑；B. 氢氧化钠溶液与盐酸：H⁺ + OH⁻ = H₂O；C. 大理石与稀盐酸：CO₃²⁻ + 2H⁺ = H₂O + CO₂↑；D. 氯化钡溶液与硫酸钠溶液：Ba²⁺ + SO₄²⁻ = BaSO₄↓。
    答：选 B、D。A 错：铁与非氧化性稀酸反应生成 Fe²⁺，应为 Fe + 2H⁺ = Fe²⁺ + H₂↑。C 错：大理石主要成分 CaCO₃ 难溶，不能拆成 CO₃²⁻，应为 CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑。
  3. 3. 歧化反应分析：3S + 6KOH =（△）2K₂S + K₂SO₃ + 3H₂O。当 9.6 g 硫（0.3 mol）完全参加反应时，作氧化剂的硫与作还原剂的硫的物质的量之比是多少？转移电子多少摩尔？
    答：3 mol S 中 2 mol 化合价从 0 降到 -2（生成 K₂S）作氧化剂，1 mol 从 0 升到 +4（生成 K₂SO₃）作还原剂，二者之比为 2:1。0.3 mol S 参加反应时，作氧化剂 0.2 mol、作还原剂 0.1 mol；每个作还原剂的 S 失 4 个电子，转移电子 n(e⁻) = 0.1 mol × 4 = 0.4 mol。

综合 · 实验探究与综合应用

  1. 1. 实验探究：化学小组制备并检验 Fe(OH)₃ 胶体。有同学提出如下三种操作：甲——向饱和 FeCl₃ 溶液中滴加 NaOH 溶液；乙——向冷水中滴加饱和 FeCl₃ 溶液再加热；丙——向沸水中滴加几滴饱和 FeCl₃ 溶液，加热至红褐色立即停止。哪种正确？说明错误操作的后果，并写出正确的化学方程式。
    答：丙正确。甲中 Fe³⁺ 与 OH⁻ 直接反应生成 Fe(OH)₃ 沉淀而不是胶体；乙中冷水里水解慢，久煮同样会聚沉成沉淀。正确反应：FeCl₃ + 3H₂O =（△）Fe(OH)₃（胶体）+ 3HCl。制备用自来水会因电解质使胶体聚沉，搅拌或久煮也会破坏胶体。
  2. 2. 工业情景：印刷电路板厂用 FeCl₃ 溶液腐蚀覆铜板，反应为 2FeCl₃ + Cu = 2FeCl₂ + CuCl₂。(1) 写出离子方程式并标明氧化剂；(2) 说明该反应为什么是氧化还原反应；(3) 腐蚀液长期使用后 Fe³⁺ 浓度下降，可加入一种物质使其恢复，写出离子方程式。
    答：(1) 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺，氧化剂是 FeCl₃（Fe³⁺）。(2) 反应中铁元素从 +3 降到 +2、铜从 0 升到 +2，有化合价升降即有电子转移，属于氧化还原反应。(3) 通入足量氯气使其恢复：2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻（氯气把 Fe²⁺ 重新氧化为 Fe³⁺，且不引入新杂质离子）。
  3. 3. 综合计算：向 100 mL CuSO₄ 溶液中加入 5.6 g 铁粉，恰好完全反应析出红色固体。(1) 写出离子方程式；(2) 求析出铜的质量和原溶液中 CuSO₄ 的物质的量浓度；(3) 求转移电子的物质的量（写出设、写、算、答）。
    答：(1) Fe + Cu²⁺ = Fe²⁺ + Cu。(2) 设析出铜的质量为 x，n(Fe) = 5.6 g ÷ 56 g/mol = 0.1 mol。由 Fe ~ Cu 知 n(Cu) = 0.1 mol，x = 0.1 × 64 = 6.4 g；n(CuSO₄) = 0.1 mol，c = 0.1 mol ÷ 0.1 L = 1 mol/L。(3) 每摩尔 Fe 失 2 mol 电子，n(e⁻) = 0.2 mol。答：析出铜 6.4 g，浓度 1 mol/L，转移电子 0.2 mol。

💬 课后反馈

**学生常见错误** 1. 物质分类凭印象：把盐酸、冰水混合物误归为纯净物，把 NaHSO₄ 误归为酸，根源是没抓住「组成物质种数」和「电离产物」两个判断标准。 2. 胶体判断只看外观：认为有色溶液一定有丁达尔效应，或把淀粉溶液当成溶液（实为胶体），没有抓住粒子直径 1~100 nm 这一本质。 3. 离子方程式拆分出错：把 CaCO₃、BaSO₄ 等沉淀拆成离子，把 HCO₃⁻ 拆成 H⁺ 和 CO₃²⁻，写完不查电荷守恒，出现「两边电荷不等」仍不自知。 4. 氧化还原概念混淆：把「被氧化」与「作氧化剂」搞反，分析歧化反应（如 Na₂O₂ 与水）时不会拆分同种元素的两种价态变化。 **教学改进建议** 1. 用「先标价、再看升降、后定角色」三步法训练氧化还原分析，每题坚持完整走三步，形成思维程序。 2. 离子方程式训练坚持「写、拆、删、查」四步留痕，重点强化沉淀、气体、弱电解质「三不拆」清单，配合正误判断选择题集中纠错。 3. 分类教学借助卡片实物分类活动，让学生自己搭分类树，比教师直接给出图示记忆更牢。 **分层辅导建议** - 基础层：过关四种基本反应类型和常见物质归类，先准确再求快；离子方程式只练不拆型的写法。 - 提高层：强化强电解质拆分判断与电荷守恒检查，练习中等难度离子方程式书写。 - 拓展层：训练歧化反应电子转移分析、离子方程式正误判断的综合选择题与信息型方程式书写。 **给家长的建议** 1. 孩子学习氧化还原时可鼓励其把「升失氧、降得还」口诀讲给家长听，能复述清楚才算真懂。 2. 关注作业中离子方程式的书写痕迹，发现孩子跳步、不检查时及时提醒，督促其养成「写完必查三守恒」的习惯。
