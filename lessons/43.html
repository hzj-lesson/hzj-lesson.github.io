初中八年级数学《勾股定理》教案

初中八年级数学勾股定理

📝 备课方案

**教学目标** 1. 通过观察、实验、猜想，探索并掌握勾股定理：直角三角形两条直角边的平方和等于斜边的平方，会用字母表示 a² + b² = c²。 2. 会用勾股定理求直角三角形的边长，能识别并运用常见的勾股数（如 3、4、5；5、12、13；6、8、10）。 3. 掌握勾股定理的逆定理，会运用三边的数量关系判断一个三角形是否为直角三角形。 4. 了解面积法、拼图法证明勾股定理的基本思路，体会数形结合思想，能运用勾股定理解决最短路径、实际测量等问题。 **教学重点**：勾股定理及其逆定理的内容，勾股定理在求边长和实际问题中的应用。 **教学难点**：勾股定理的证明（面积法与拼图法），以及用逆定理判定直角三角形的思路。 **教学方法**：自主探究法、面积验证法、数形结合法、讲练结合法。 **教学准备**：方格纸、直角三角形纸板（拼图用）、勾股定理演示课件、练习题卡。 **课时安排**：3 课时（第 1 课时：勾股定理的探索与证明；第 2 课时：勾股定理的应用与勾股数；第 3 课时：勾股定理的逆定理与综合应用）。

📖 课堂讲义 · 核心知识点

**一、勾股定理的内容** 在直角三角形中，两条直角边的平方和等于斜边的平方。如果直角三角形的两条直角边长分别为 a、b，斜边长为 c，那么 **a² + b² = c²**。 注意三点： 1. 勾股定理只适用于**直角三角形**，非直角三角形不能直接使用。 2. 公式中的 c 一定是**斜边**，也就是直角所对的边，它是三边中最长的一边。 3. 求第三边时要灵活变形：已知两条直角边求斜边，c = √(a² + b²)；已知斜边和一条直角边求另一条直角边，a = √(c² - b²)。 验证方法：在方格纸上画一个直角边分别为 3、4 的直角三角形，量出斜边长 5，发现 3² + 4² = 9 + 16 = 25 = 5²，说明 3、4、5 满足勾股定理。 **二、勾股定理的证明（面积法与拼图法）** 证明勾股定理最常用的思想是**面积法**：用两种不同的方法表示同一个图形的面积，得到等式。 1. 赵爽弦图（我国东汉赵爽发明）：用四个全等的直角三角形（直角边为 a、b，斜边为 c）拼成一个边长为 c 的大正方形，中间留下一个边长为 (b - a) 的小正方形。 - 大正方形面积 = c²。 - 大正方形面积 = 4 个三角形面积 + 小正方形面积 = 4 × (1/2 ab) + (b - a)² = 2ab + b² - 2ab + a² = a² + b²。 - 所以 a² + b² = c²。 2. 总统拼图（勾股拼图）：把四个全等的直角三角形拼成一个大的正方形，利用大正方形的面积等于四个三角形面积加中间小正方形面积，也能得到 a² + b² = c²。 面积法证明的关键步骤：找对图形、列出两种面积表达式、化简等式。 **三、勾股数** 能够成为直角三角形三条边长的**三个正整数**，称为勾股数。 常见勾股数：3、4、5；5、12、13；6、8、10；7、24、25；8、15、17；9、40、41。 规律：一组勾股数的整数倍仍然是勾股数。例如 3、4、5 同时乘 2 得 6、8、10，同时乘 3 得 9、12、15，它们都是勾股数。 | 勾股数 | 验证 a² + b² = c² | |---|---| | 3、4、5 | 9 + 16 = 25 | | 5、12、13 | 25 + 144 = 169 | | 6、8、10 | 36 + 64 = 100 | | 7、24、25 | 49 + 576 = 625 | **四、勾股定理的逆定理** 如果三角形的三边长 a、b、c 满足 a² + b² = c²，那么这个三角形是**直角三角形**，且边 c 所对的角是直角。 用途：由三边的数量关系判断三角形是不是直角三角形。步骤： 1. 找出最长边（把它当作 c）； 2. 计算较短两边的平方和； 3. 与最长边的平方比较：相等就是直角三角形，不相等就不是。 例：判断 6、8、10 能否构成直角三角形。最长边是 10，6² + 8² = 36 + 64 = 100，10² = 100，两者相等，所以 6、8、10 能构成直角三角形，且 10 所对的角是直角。 **五、勾股定理的应用** 1. 求边长：已知直角三角形的任意两边，用勾股定理求第三边。 2. 最短路径问题：立体图形（如圆柱、长方体）表面上的最短路线，先把侧面展开成平面图形，再利用"两点之间线段最短"和勾股定理计算。 3. 实际测量：测河宽、测旗杆或大树高度、梯子靠墙、风筝断线等问题，关键是把实际问题抽象成直角三角形。 4. 折叠问题：折叠前后重合部分相等，通常能构造直角三角形，用勾股定理列方程求解。 **易错提醒** 1. 用错斜边：求边时没有先确定斜边，把直角边当斜边代入公式。 2. 乱用勾股定理：把非直角三角形当直角三角形使用勾股定理。 3. 漏掉符号：边长是正数，开方只取正值；实际问题中要检验结果是否符合实际。 ![勾股定理示意图](/images/pythagorean.svg)

🔍 课堂讲义 · 重点难点解析

**重点一：勾股定理的直接应用（求第三边）** 例题：在 Rt△ABC 中，∠C = 90°，a = 6，b = 8，求 c。 分析：∠C 是直角，所以 c 是斜边，用 a² + b² = c² 计算。 解答：c² = a² + b² = 6² + 8² = 36 + 64 = 100，所以 c = √100 = 10。 小结：求斜边时把两条直角边的平方相加再开方；要先判断谁是斜边。 **难点一：用面积法证明勾股定理** 例题：用四个直角边为 a、b、斜边为 c 的全等直角三角形，拼成一个边长为 (a + b) 的大正方形，中间留下一个边长为 c 的小正方形。请你说明为什么 a² + b² = c²。 分析：大正方形的面积可以用两种方法表示。 解答：方法一：大正方形边长是 a + b，面积 S = (a + b)²。方法二：大正方形由四个直角三角形和中间的小正方形组成，S = 4 × (1/2 ab) + c² = 2ab + c²。因为面积不变，所以 (a + b)² = 2ab + c²，展开得 a² + 2ab + b² = 2ab + c²，两边同时减去 2ab，得 a² + b² = c²。 小结：面积法的本质是"同一图形的面积，用两种方法表示，建立等式"。这是证明勾股定理最经典的思路。 **难点二：用勾股定理的逆定理判定直角三角形** 例题：三角形的三边长分别为 9、12、15，试判断它是不是直角三角形。 分析：先找出最长边 15，当作 c；再算较短两边 9、12 的平方和，与 15² 比较。 解答：9² + 12² = 81 + 144 = 225，15² = 225，因为 9² + 12² = 15²，所以这个三角形是直角三角形，且 15 所对的角是直角。 小结：判定步骤三步：找最长边、算平方和、比大小。相等是直角三角形，不相等则不是。 **难点三：勾股定理与实际问题** 例题：一个梯子长 5 米，斜靠在一面墙上，梯子的底端离墙角 3 米，梯子的顶端离地面多少米？ 分析：梯子、墙面、地面构成直角三角形，梯子是斜边。 解答：设梯子顶端离地面 h 米，由勾股定理：h² + 3² = 5²，h² = 25 - 9 = 16，h = 4（米）。答：梯子顶端离地面 4 米。 小结：解决实际问题的关键是把实际图形抽象成直角三角形，明确哪条边是斜边，再用勾股定理列式计算。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：求直角三角形的边长** 题目：在 Rt△ABC 中，∠C = 90°，a = 5，c = 13，求 b。 分析：∠C 是直角，c 是斜边，用 b² = c² - a² 求另一条直角边。 解答：b² = c² - a² = 13² - 5² = 169 - 25 = 144，b = √144 = 12。 方法小结：已知斜边和一条直角边求另一条直角边，用平方差再开方。本题的 5、12、13 是一组常见的勾股数。 **例题二（提高）：立体图形上的最短路径** 题目：一个圆柱形杯子，底面周长 24 厘米，高 8 厘米。一只蚂蚁从杯子底部边缘上的点 A，沿杯壁爬到杯口正上方的点 B，求蚂蚁爬行的最短路线长。（点 B 在点 A 的正上方） 分析：把圆柱侧面展开成一个长方形，蚂蚁的路线在展开图上走。长方形的宽等于底面周长 24 厘米，长方形的长等于高 8 厘米。展开后 A、B 两点的水平距离等于底面周长的一半，即 24 ÷ 2 = 12 厘米，垂直距离等于高 8 厘米。最短路线就是连接 A、B 的线段（两点之间线段最短）。 解答：最短路线 = √(12² + 8²) = √(144 + 64) = √208 = 4√13（厘米）。 方法小结：立体图形表面上的最短路径，先展开成平面图形，再把两点之间的线段用勾股定理求出长度。 **例题三（综合）：勾股定理的实际应用** 题目：一根旗杆在离地面 9 米处折断，旗杆顶部落在离旗杆底部 12 米处，求旗杆折断前的高度。 分析：折断后，未折断的 9 米、地面上的 12 米和折断倒下的部分构成一个直角三角形，其中倒下的部分是斜边。 解答：设倒下部分长 c 米，由勾股定理：c = √(9² + 12²) = √(81 + 144) = √225 = 15（米）。旗杆折断前的高度 = 9 + 15 = 24（米）。 方法小结：这类问题先画示意图，把实际问题抽象成直角三角形，分清直角边和斜边，再用勾股定理求解。注意旗杆原高是两段之和。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 勾股定理求边长

  1. 1. 在 Rt△ABC 中，∠C = 90°，a = 3，b = 4，求斜边 c 的长。
    答：由勾股定理 c² = a² + b² = 3² + 4² = 9 + 16 = 25，c = √25 = 5。3、4、5 是最基本的勾股数。
  2. 2. 在 Rt△ABC 中，∠C = 90°，a = 8，c = 17，求直角边 b 的长。
    答：b² = c² - a² = 17² - 8² = 289 - 64 = 225，b = √225 = 15。注意斜边是 c = 17，8、15、17 是一组勾股数。
  3. 3. 填空：勾股定理的内容是：直角三角形两条（ ）的平方和等于（ ）的平方；直角边分别为 6 和 8 的直角三角形，斜边长为（ ）。
    答：直角边；斜边。斜边 c = √(6² + 8²) = √(36 + 64) = √100 = 10。6、8、10 是 3、4、5 的 2 倍，也是勾股数。

中等 · 勾股数与逆定理

  1. 1. 判断下列三组长度的线段能否构成直角三角形：（1）5、12、13；（2）4、5、6；（3）9、12、15。
    答：（1）5² + 12² = 25 + 144 = 169 = 13²，能构成直角三角形；（2）4² + 5² = 16 + 25 = 41 ≠ 36 = 6²，不能构成直角三角形；（3）9² + 12² = 81 + 144 = 225 = 15²，能构成直角三角形。用逆定理判断，先找最长边。
  2. 2. 一个三角形的三边长分别为 15、20、25，试判断它是否是直角三角形，如果是，指出哪条边所对的角是直角。
    答：最长边是 25，15² + 20² = 225 + 400 = 625 = 25²，所以它是直角三角形，且边长为 25 的边所对的角是直角。15、20、25 是 3、4、5 的 5 倍。
  3. 3. 已知直角三角形两条直角边的长分别为 9 和 12，求斜边上的高。
    答：斜边 c = √(9² + 12²) = √(81 + 144) = √225 = 15。设斜边上的高为 h，用面积法：S = 1/2 × 9 × 12 = 54，又 S = 1/2 × 15 × h，所以 54 = 1/2 × 15h，解得 h = 54 × 2 ÷ 15 = 7.2。斜边上的高为 7.2。

难 · 综合应用与探究

  1. 1. ![梯子靠墙示意图](/images/hw-ladder.svg) 如图，一架长 2.5 米的梯子斜靠在墙上，梯脚离墙脚 0.7 米。如果梯子顶端下滑 0.4 米，那么梯脚向外滑动了多少米？
    答：原来梯顶高度 h₁ = √(2.5² - 0.7²) = √(6.25 - 0.49) = √5.76 = 2.4（米）。下滑 0.4 米后梯顶高度为 2.4 - 0.4 = 2（米），此时梯脚离墙 x = √(2.5² - 2²) = √(6.25 - 4) = √2.25 = 1.5（米），所以梯脚向外滑动了 1.5 - 0.7 = 0.8（米）。
  2. 2. 一块长方形草坪，长 12 米，宽 5 米。一只小狗从草坪的一个角跑到对角的顶点，它至少跑多少米？
    答：从对角点跑到对角点，就是求长方形对角线的长度。对角线 d = √(12² + 5²) = √(144 + 25) = √169 = 13（米）。小狗至少跑 13 米。12、5、13 是勾股数。
  3. 3. 在 Rt△ABC 中，∠C = 90°，a、b、c 分别为直角边和斜边。若 a + b = 17，c = 13，求直角三角形的面积。
    答：由勾股定理 a² + b² = c² = 169。又 (a + b)² = a² + b² + 2ab = 289，所以 169 + 2ab = 289，2ab = 120，ab = 60。三角形面积 S = 1/2 ab = 30。用完全平方公式结合勾股定理求面积，是常见技巧。

综合 · 实际应用与综合探究

  1. 1. 一艘轮船在海上航行，从港口出发向东航行 24 海里后转向正南，又航行了 18 海里到达目的地。目的地距港口多少海里？
    答：轮船先向东再向南，两次航行的路线互相垂直，构成直角三角形，两直角边分别为 24 海里和 18 海里。距离 = √(24² + 18²) = √(576 + 324) = √900 = 30（海里）。目的地距港口 30 海里。
  2. 2. 有一根长 20 厘米的木棍，要放进长、宽、高分别为 12 厘米、9 厘米、16 厘米的长方体纸盒中，这根木棍能否水平放进纸盒？
    答：纸盒最长的一条对角线是体对角线。底面对角线 = √(12² + 9²) = √(144 + 81) = √225 = 15（厘米），体对角线 = √(15² + 16²) = √(225 + 256) = √481 ≈ 21.93（厘米）。因为 21.93 大于 20，所以这根木棍可以斜着放进纸盒（但水平放进时底面最长只有对角线 15 厘米，放不下）。此题考察长方体体对角线的求法。
  3. 3. 探究活动：请你用四个全等的直角三角形拼成一个图形来验证勾股定理，写出你的拼法，并说明为什么能验证 a² + b² = c²。
    答：示例（总统拼图）：把四个直角边为 a、b、斜边为 c 的全等直角三角形拼成一个边长为 (a + b) 的大正方形，四个三角形的斜边围在中间形成边长为 c 的小正方形。大正方形面积 = (a + b)²；另一方面，大正方形面积 = 4 × (1/2 ab) + c² = 2ab + c²。所以 (a + b)² = 2ab + c²，即 a² + 2ab + b² = 2ab + c²，化简得 a² + b² = c²。关键是利用面积相等建立等式。

💬 课后反馈

**学生常见错误** 1. 找错斜边：求边长时没有先确定哪条边是斜边，把直角边当成斜边代入公式，导致结果错误。 2. 逆定理判定不严谨：不找最长边就计算，或者把"平方和"算成"和的平方"，如把 3² + 4² 算成 (3 + 4)²。 3. 开方取负值：写边长时写出负根，忘了边长必须是正数；实际问题中也不检验结果是否符合实际。 4. 实际问题不会建模：分不清哪个是直角边、哪个是斜边，画不出正确的示意图。 **教学改进建议** 1. 强化"先找斜边"的习惯：解题前先画出图形，标出直角和斜边，再套公式，形成规范流程。 2. 用格点图直观验证：在方格纸上画直角三角形，数格子验证勾股定理，帮助学生建立直观认识。 3. 开展拼图活动：组织学生用纸板剪四个直角三角形动手拼图，亲自经历"面积法"证明过程，理解更深刻。 4. 整理勾股数口诀：如"3 4 5、5 12 13、6 8 10、7 24 25、8 15 17"，帮助学生快速识别和应用。 **分层辅导建议** - 基础层：只做"已知两边求第三边"的单一题型，重点纠正斜边判断，熟练后再进入逆定理。 - 提高层：练习逆定理判定和实际测量问题，强调"画图、建模、检验"三步法。 - 拓展层：探究最短路径、折叠问题、拼图证明，发展空间观念和数形结合思想。 **给家长的建议** 1. 和孩子一起观察生活中的直角三角形：楼梯、屋顶、晾衣架，说一说哪些地方能用到勾股定理。 2. 陪孩子玩"拼图验证"游戏：用硬纸剪直角三角形拼正方形，直观感受 a² + b² = c²。 3. 每天让孩子口算 3、4、5 等勾股数的平方，练熟"平方表"，提高计算速度和准确率。
