高中高一数学《数列》教案

高中高一数学数列

📝 备课方案

**一、教学目标** 1. 理解数列、通项、等差数列与等比数列的概念； 2. 掌握等差、等比数列的通项公式与前 n 项和公式； 3. 能运用中项关系与下标性质解决简单综合问题。 **二、教学重难点** - 重点：等差、等比数列的通项与前 n 项和公式； - 难点：求和公式的选用，以及等比数列中公比 $q=1$ 的讨论。 **三、课时安排**：3 课时（概念 1 课时、等差数列 1 课时、等比数列 1 课时）。 **四、教学过程**：生活实例引入（如阶梯水价、复利）→ 概念建构 → 公式推导（归纳法）→ 例题示范 → 巩固练习 → 小结与作业。

📖 课堂讲义 · 核心知识点

**一、数列的基本概念** - **数列**：按一定次序排列的一列数，一般记为 $\{a_1, a_2, \dots, a_n, \dots\}$，简记为数列 $\{a_n\}$。 - **项**：数列中的每一个数叫做数列的一项，$a_n$ 叫做第 n 项（通项）。 - **通项公式**：如果数列 $\{a_n\}$ 的第 n 项 $a_n$ 与 n 之间的函数关系可用一个公式表示，该公式叫做通项公式，即 $a_n=f(n)$。 **二、等差数列** - **定义**：一般地，如果一个数列从第 2 项起，每一项与它的前一项的差都等于同一个常数，这个数列叫做等差数列，该常数叫做公差，常用字母 d 表示，即 $a_{n+1}-a_n=d$（常数）。 - **通项公式**： $$a_n=a_1+(n-1)d$$ - **前 n 项和公式**： $$S_n=\\frac{n(a_1+a_n)}{2}=\\frac{n[2a_1+(n-1)d]}{2}$$ - **等差中项**：若 a, b, c 成等差数列，则 b 为 a 与 c 的等差中项，且 $$2b=a+c \iff b=\\frac{a+c}{2}$$ - **常用性质**：若 $m+n=p+q$，则 $a_m+a_n=a_p+a_q$；若项数为奇数 $2k-1$，则 $S_{2k-1}=(2k-1)a_k$（$a_k$ 为中项）。 **三、等比数列** - **定义**：一般地，如果一个数列从第 2 项起，每一项与它的前一项的比都等于同一个常数，这个数列叫做等比数列，该常数叫做公比，常用字母 q 表示（$q\neq 0$），即 $\\frac{a_{n+1}}{a_n}=q$（常数）。 - **通项公式**： $$a_n=a_1q^{n-1}$$ - **前 n 项和公式**（$q\neq 1$）： $$S_n=\\frac{a_1(1-q^n)}{1-q}=\\frac{a_1(q^n-1)}{q-1}\quad (q\neq 1)$$ 当 $q=1$ 时，数列为常数列，$S_n=na_1$。 - **等比中项**：若 a, b, c 成等比数列，则 b 为 a 与 c 的等比中项，且 $$b^2=ac \iff b=\pm\\sqrt{ac}$$ - **常用性质**：若 $m+n=p+q$，则 $a_m\cdot a_n=a_p\cdot a_q$；且 $S_n, S_{2n}-S_n, S_{3n}-S_{2n}$ 也成等比数列（公比为 $q^n$）。

🔍 课堂讲义 · 重点难点解析

**难点一：求和公式的选用** 求等差数列前 n 项和时，若已知首项 $a_1$ 与末项 $a_n$，用 $S_n=\\frac{n(a_1+a_n)}{2}$ 更直接；若已知 $a_1$ 与公差 d，则用 $S_n=\\frac{n[2a_1+(n-1)d]}{2}$ 更方便。不少同学不先判断"已知什么、求什么"，生搬硬套导致计算复杂甚至出错。 **难点二：等比数列公比 q 的取值** 等比数列求和公式 $S_n=\\frac{a_1(1-q^n)}{1-q}$ 仅在 $q\neq 1$ 时成立；当 $q=1$ 时数列为常数列，和应为 $S_n=na_1$。**常见错误**：忘记讨论 $q=1$ 的情况直接套公式，导致分母为 0 而报错。 **难点三：下标性质的巧用** 遇到"已知某几项求另一些项"时，优先考虑下标和性质（如 $m+n=p+q\Rightarrow a_m+a_n=a_p+a_q$），往往比先求 $a_1,d$ 更快捷。 **小例**：已知等差数列 $\{a_n\}$ 中 $a_3=7,\ a_7=15$，求 $a_{11}$。 下标 3,7,11 成等差（$3+11=2\times7$），故 $a_3,a_7,a_{11}$ 也成等差，即 $2a_7=a_3+a_{11}$，得 $a_{11}=2a_7-a_3=2\times15-7=23$。利用性质比先求 d 更简洁。

✏️ 课堂讲义 · 典型例题精讲

**例 1（等差数列通项与求和）** 已知等差数列 $\{a_n\}$ 首项 $a_1=1$，公差 $d=2$，求 $a_{10}$ 与 $S_{10}$。 **解**： 由通项公式： $$a_{10 }=a_1+(10-1)d=1+9\times2=1+18=19$$ 由求和公式： $$S_{10}=\\frac{10(a_1+a_{10})}{2}=\\frac{10\times(1+19)}{2}=\\frac{10\times20}{2}=100$$ **关键**：先用通项求出末项 $a_{10}$，再代入求和公式；也可直接用 $S_n=\\frac{n[2a_1+(n-1)d]}{2}$ 验证：$S_{10}=\\frac{10[2\times1+9\times2]}{2}=\\frac{10\times20}{2}=100$，两种方法结果一致。 **例 2（等比数列通项与求和）** 已知等比数列 $\{a_n\}$ 中 $a_1=2,\ q=3$，求 $a_5$ 与 $S_5$。 **解**： 通项： $$a_5=a_1q^{5-1}=2\times3^4=2\times81=162$$ 求和（注意 $q=3\neq1$）： $$S_5=\\frac{a_1(1-q^5)}{1-q}=\\frac{2(1-3^5)}{1-3}=\\frac{2(1-243)}{-2}=\\frac{2\times(-242)}{-2}=242$$ **关键**：等比求和必须先确认 $q\neq1$；本题 $3^5=243$，分子 $1-243=-242$，除以 $-2$ 得正数，不要漏掉负号。 **例 3（等差中项设元）** 三个数成等差数列，和为 21，首尾两数之积为 32，求这三个数。 **解**： 设这三个数为 $a-d,\ a,\ a+d$（利用中项对称设元，自动消去一次项）。 由和为 21：$(a-d)+a+(a+d)=3a=21$，得 $a=7$。 由首尾积为 32：$(a-d)(a+d)=a^2-d^2=32$，即 $49-d^2=32$，得 $d^2=17$，$d=\pm\\sqrt{17}$。 故三数为 $7-\\sqrt{17},\ 7,\ 7+\\sqrt{17}$（或顺序互换）。 **关键**：成等差数列的三个数常设为 $a-d,a,a+d$，可大幅简化方程。 **例 4（奇数求和）** 求 $1+3+5+\cdots+99$ 的和。 **解**： 这是首项 $a_1=1$、公差 $d=2$ 的等差数列，末项 $a_n=99$。 先求项数 n：$a_n=a_1+(n-1)d\Rightarrow 99=1+(n-1)\times2\Rightarrow 98=(n-1)\times2\Rightarrow n-1=49\Rightarrow n=50$。 再求和： $$S_{50}=\\frac{50(a_1+a_{50})}{2}=\\frac{50\times(1+99)}{2}=\\frac{50\times100}{2}=2500$$ **关键**：求和前务必先确定项数 n，很多同学直接用 99 当项数导致错误。实际上前 n 个奇数和为 $n^2$，本题即 $50^2=2500$。 **例 5（等比数列性质）** 等比数列 $\{a_n\}$ 中，已知 $a_2\cdot a_8=16$，求 $a_5$。 **解**： 由等比性质：若 $m+n=p+q$ 则 $a_m a_n=a_p a_q$。这里 $2+8=10=5+5$，故 $$a_2 a_8 = a_5\cdot a_5 = a_5^2=16$$ 所以 $a_5=\pm4$。 **关键**：利用对称下标性质可避免求 $a_1,q$。注意 $a_5^2=16$ 应得 $a_5=\pm4$，不能只写 4。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念与公式

  1. 1. 写出等差数列与等比数列的通项公式，并说明各字母含义。
    答：等差数列：$a_n=a_1+(n-1)d$，其中 $a_1$ 为首项、d 为公差、n 为项数；等比数列：$a_n=a_1q^{n-1}$，其中 q 为公比（$q\neq0$）。
  2. 2. 等差中项与等比中项的公式分别是什么？
    答：等差中项 $b=\\frac{a+c}{2}$（即 $2b=a+c$）；等比中项 $b=\pm\\sqrt{ac}$（即 $b^2=ac$）。
  3. 3. 等差数列 $\{a_n\}$ 中 $a_1=2,d=3$，求 $a_5$。
    答：$a_5=a_1+4d=2+4\times3=2+12=14$。

中等 · 通项与求和

  1. 1. 等差数列 $a_1=3,d=4$，求 $S_{10}$。
    答：$S_{10}=\\frac{10[2a_1+9d]}{2}=\\frac{10[2\times3+9\times4]}{2}=\\frac{10\times42}{2}=210$。
  2. 2. 已知等差数列 $a_3=5,a_8=20$，求 $a_1$ 与 d。
    答：由 $a_3=a_1+2d=5$，$a_8=a_1+7d=20$；两式相减得 $5d=15\Rightarrow d=3$，代回得 $a_1=5-6=-1$。
  3. 3. 等比数列 $a_1=3,q=2$，求 $S_5$。
    答：$S_5=\\frac{3(1-2^5)}{1-2}=\\frac{3(1-32)}{-1}=\\frac{3\times(-31)}{-1}=93$。

难 · 性质与综合

  1. 1. 三个数成等比数列，其积为 64，其和为 14，求这三个数。
    答：设三数为 $\\frac{a}{q},a,aq$。积 $\\frac{a}{q}\cdot a\cdot aq=a^3=64\Rightarrow a=4$。和 $\\frac{4}{q}+4+4q=14\Rightarrow \\frac{1}{q}+q=\\frac{5}{2}\Rightarrow 2q^2-5q+2=0\Rightarrow (2q-1)(q-2)=0\Rightarrow q=2$ 或 $q=\\frac{1}{2}$。故三数为 $2,4,8$（或 $8,4,2$）。
  2. 2. 求 $2+4+6+\cdots+100$ 的和。
    答：首项 2、公差 2、末项 100，项数 $n=\\frac{100-2}{2}+1=50$，故 $S_{50}=\\frac{50(2+100)}{2}=\\frac{50\times102}{2}=2550$。
  3. 3. 等差数列 $\{a_n\}$ 中 $a_2+a_4+a_6=24$，求 $a_4$。
    答：由等差性质 $a_2+a_6=2a_4$，故 $2a_4+a_4=3a_4=24\Rightarrow a_4=8$。

综合 · 拓展应用

  1. 1. 已知等比数列 $\{a_n\}$ 满足 $a_3=4,a_6=32$，求 $a_1,q$ 及 $S_6$。
    答：$\\frac{a_6}{a_3}=q^3=\\frac{32}{4}=8\Rightarrow q=2$；$a_3=a_1q^2=4a_1=4\Rightarrow a_1=1$。$S_6=\\frac{1(1-2^6)}{1-2}=\\frac{1-64}{-1}=63$。
  2. 2. 等差数列前 n 项和 $S_n=2n^2+3n$，求 $a_n$ 及首项、公差。
    答：$a_1=S_1=5$；$n\ge2$ 时 $a_n=S_n-S_{n-1}=(2n^2+3n)-[2(n-1)^2+3(n-1)]=(2n^2+3n)-(2n^2-n-1)=4n+1$。代入 $n=1$ 得 $5=a_1$ 成立，故 $a_n=4n+1$，公差 $d=a_2-a_1=9-5=4$。
  3. 3. 某楼每层之间的台阶数相同，从第 1 层到第 3 层共 48 级，问第 1 层到第 10 层共多少级？
    答：设每层间台阶数为 d，第 1 到第 3 层有 2 个层间，即 $2d=48\Rightarrow d=24$。第 1 到第 10 层有 9 个层间，共 $9\times24=216$ 级。

💬 课后反馈

学生常见错误：一是求和时未先确定项数 n，误把末项当项数；二是等比求和忘记讨论 $q=1$ 导致分母为 0；三是混淆等差中项 $2b=a+c$ 与等比中项 $b^2=ac$。考试建议：优先利用下标性质（如 $m+n=p+q$ 时 $a_m+a_n=a_p+a_q$）简化计算，并养成"先判类型、再选公式"的习惯。
