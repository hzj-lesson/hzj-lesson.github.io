小学三年级道德与法治我们的学校

📝 备课方案

**教学目标** 1. 了解学校的基本设施和各个部门的职能，知道学校是我们学习、生活、成长的重要场所。 2. 学会有礼貌地向学校工作人员求助，能用恰当的方式表达自己的需求。 3. 通过参观、采访、调查等活动，增强对学校的认同感和归属感，学会尊重学校里的每一位劳动者。 4. 树立"学校的事就是大家的事"的主人翁意识，主动为学校做力所能及的事。 **教学重点**：了解学校的设施与部门职能，学会有礼貌地求助。 **教学难点**：引导学生从"使用者"转变为"小主人"，主动关心和服务学校。 **教学方法**：参观访问、小组调查、情景模拟、交流分享。 **教学准备**：学校平面图、采访记录表、课件（学校各部门照片）。 **课时安排**：2 课时（第 1 课时：我们的学校有什么；第 2 课时：我为学校做点事）

📖 课堂讲义 · 核心知识点

**一、学校是我们的第二个家** 学校是我们学习、生活、成长的地方：我们在这里上课、读书、运动、交朋友，一天中大部分时间都在学校里度过。学校就像我们的第二个家，每一位老师、同学和工作人员都是这个大家庭的一员。 **二、学校有哪些地方（小调查）** 让我们"逛一逛"学校，找一找这些场所： - 教室：我们上课、学习的地方 - 操场：上体育课、做操、课间活动的地方 - 图书室：借书、阅读的地方 - 实验室：做科学实验的地方 - 音乐教室、美术教室：上艺术课的地方 - 医务室：老师帮我们处理小伤病的地方 - 食堂：为我们准备午餐的地方 - 门卫室：保安叔叔守护校园安全的地方 **三、学校的部门与职能（认识它们）** | 部门/场所 | 它们为我们做什么 | |---|---| | 校长室 | 管理学校的全面工作 | | 教导处 | 安排课程、组织教学活动 | | 总务处 | 负责校园设施、物资保障 | | 医务室 | 处理伤病、宣传健康知识 | | 门卫室 | 守护校园安全、接待来访 | | 食堂 | 准备营养卫生的午餐 | | 图书室 | 提供图书借阅和阅读指导 | **四、有礼貌地求助（情景练习）** 在学校遇到困难，要**有礼貌**地找合适的老师或工作人员帮忙： - 忘记带文具 → 找同学或班主任借 - 身体不舒服 → 去医务室，告诉校医 - 捡到东西 → 交给班主任或门卫，说明情况 - 找不到教室 → 问路过的老师或高年级同学 礼貌用语：称呼要恰当（老师、叔叔、阿姨），多用"请问""谢谢""麻烦您"。 **五、我是学校小主人（我能做什么）** - 爱护公物：不刻划桌椅、不弄脏墙壁、轻关门窗、爱护图书 - 节约资源：随手关灯、节约用水、节约用纸 - 维护卫生：不乱扔垃圾、主动捡起地上的纸屑 - 帮助他人：帮助新同学熟悉校园、帮老师收发作业 **六、尊重每一位劳动者** 学校里的校长、老师、保安、保洁阿姨、食堂师傅，每一位工作人员都在为我们的成长付出劳动。尊重他们的劳动：见面主动问好、听从他们的提醒、不乱扔垃圾、不浪费饭菜。

🔍 课堂讲义 · 重点难点解析

**重点一：认识学校的部门与职能** - 例题：如果你在操场上摔倒了，膝盖擦破了皮，应该去哪里？找谁？ 分析：擦伤属于小伤病，要找医务室。 参考答案：应该去医务室，找校医老师帮忙处理伤口。 小结：遇到问题先想"这事归谁管、去哪里解决"，再有礼貌地求助。 **重点二：有礼貌地求助** - 例题：你忘带美术课要用的彩笔了，应该怎样向同学借？ 分析：要有称呼、有请求、有感谢，还要说明归还时间。 参考答案：走到同学身边，微笑着说："××同学，请问你有多余的彩笔可以借我用一下吗？我下课后就还给你，谢谢你！" 小结：求助四步曲——称呼问好、说明来意、礼貌请求、表示感谢。 **难点一：从"使用者"到"小主人"** - 例题：有人说"学校的事是老师的事，和我们没关系"，你同意吗？为什么？ 分析：学校是我们大家的，每个人都是小主人。 参考答案：不同意。我们是学校的小主人，爱护公物、保持卫生、帮助同学都是我们该做的，学校好我们大家都好。 小结：小主人意识就是"学校的事，人人有责"。 **难点二：合理分工、共同做事** - 例题：班级要办一期"爱校"黑板报，可以怎样分工？ 分析：按特长分工，人人参与。 参考答案：会画画的画插图，字写得好的写文字，会查资料的搜集内容，其他人负责擦黑板、搬桌椅。大家分工合作，效率高。 小结：做事先分工、再合作，每个人都有用武之地。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（认识学校）** 你的学校里有哪些场所？它们各有什么用？请至少说出四个。 - 分析：回想学校里的场所和用途。 - 参考答案：教室——上课学习；操场——上体育课、做操；图书室——借书阅读；医务室——处理小伤病；食堂——吃午饭。说出四个且用途正确即可。 - 方法小结：介绍场所要说"在哪里＋用来做什么"。 **例题 2（礼貌求助）** 小明在校园里迷路了，找不到一年级（2）班教室，他该怎样向路过的老师求助？ - 分析：用上"称呼、问好、说清事由、感谢"。 - 参考答案：小明走上前，微笑着说："老师您好！我是一年级（2）班的，新来的，找不到教室了，请问一年级（2）班怎么走？谢谢老师！" - 方法小结：求助时把话说清楚，态度礼貌，别人更愿意帮忙。 **例题 3（小主人行动）** 放学时你看到走廊的灯还亮着，你会怎么做？ - 分析：这是节约资源、爱护学校的事。 - 参考答案：我会走过去把灯关掉；如果够不着，就告诉老师或高年级的同学帮忙关。 - 方法小结：小主人就要"眼里有活"，看到浪费就主动行动。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 认识学校

  1. 1. 学校的图书室是用来做什么的？
    答：用来借书和阅读的。
  2. 2. 身体不舒服应该去哪里？
    答：去医务室，找校医老师。
  3. 3. 判断：学校的设施和老师一样，都需要我们爱护。（ ）
    答：正确。学校是大家的，人人有责爱护。

中等 · 礼貌求助

  1. 1. 你捡到一支钢笔，应该怎么做？
    答：先看看周围有没有人找，找不到就交给班主任或门卫，说明在哪儿捡到的，方便失主认领。
  2. 2. 向别人求助时，要用到哪些礼貌用语？
    答：称呼（老师、叔叔、阿姨）、请问、谢谢、麻烦您等。
  3. 3. 下面哪种求助方式更好？为什么？A. 大声喊"谁帮我一下" B. 走到老师面前礼貌地说清需求。
    答：B 更好。有称呼、有礼貌、把话说清楚，别人更愿意帮忙。

难 · 小主人行动

  1. 1. 看到水龙头没关紧、一直在滴水，你会怎么做？
    答：走过去拧紧水龙头；如果拧不动就告诉老师或保洁阿姨。节约用水人人有责。
  2. 2. 班级里来了新同学，你作为"小主人"可以做些什么？
    答：带他参观校园、介绍老师和同学、告诉他图书室和医务室在哪、课间主动找他玩。
  3. 3. 有人说"我只要不破坏公物就行了"，你同意吗？为什么？
    答：不同意。小主人不仅要"不破坏"，还要主动维护：看到灯没关就关掉、看到纸屑就捡起、看到水龙头滴水就拧紧。

综合 · 实践调查

  1. 1. 采访一位学校工作人员（保安、保洁阿姨、食堂师傅等），问问他每天做什么、累不累，把采访结果写下来。
    答：示例：我采访了门卫爷爷，他每天 6 点到校开门，晚上 9 点才锁门，还要登记来访人员，很辛苦。我以后见到他会主动问好。采访真实、记录清楚即可。
  2. 2. 画出学校的平面图，标出教室、操场、图书室、医务室的位置。
    答：能画出主要场所并标注位置即可，布局大致准确就行。
  3. 3. 为学校提一条"让校园更美好"的小建议。
    答：示例：在图书室门口放一个还书箱；操场上多放几个垃圾桶；在花坛旁立"爱护花草"提示牌。建议合理即可。

💬 课后反馈

**学生常见错误** 1. 求助时只喊"老师"不说清事由，或态度生硬，别人不知道要帮什么。 2. 认为"学校的事是老师的事"，缺乏小主人意识。 3. 把"爱护公物"理解为"不破坏就够了"，不知道还要主动维护。 4. 不认识学校各部门的职能，遇到问题不知道找谁。 **教学改进建议** 1. 组织一次"校园寻宝"活动：按任务单找到学校各场所并采访工作人员。 2. 多用情景剧表演"求助"场景，让学生在演中学。 3. 设立"班级小岗位"（关灯员、节水员、图书管理员），让学生真正参与学校管理。 **分层辅导** - 基础弱：以认识场所和学会礼貌求助为主，多用图片和情景剧辅助。 - 学有余力：尝试设计一份"新生校园指南"，帮助新同学快速熟悉学校。 **给家长的建议** 接送孩子时，多和孩子聊聊学校里的工作人员，教孩子遇到困难要有礼貌地求助；让孩子讲讲自己在学校做的"小主人"的事，及时表扬。
