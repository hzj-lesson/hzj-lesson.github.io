高中高一化学《氮的化合物》教案

高中高一化学氮的化合物

📝 备课方案

**教学目标** 1. 认识氮气的性质与用途，理解 N≡N 键能大导致 N₂ 化学性质稳定的原因，能写出 N₂ 与氧气、氢气反应的方程式，了解氮的固定的概念。 2. 掌握 NO 与 NO₂ 的性质差异（颜色、溶解性、与氧气和水的反应），能写出相互转化方程式；了解氮氧化物对环境的影响。 3. 掌握氨的物理性质（极易溶于水）与化学性质（与水、酸反应、催化氧化），理解喷泉实验的原理，掌握实验室制氨的药品、装置、收集与验满方法；掌握铵盐的性质与 NH₄⁺ 的检验。 4. 掌握硝酸的强氧化性与不稳定性，能写出浓、稀硝酸与铜反应的方程式，理解常温下铁、铝在冷浓硝酸中的钝化，了解硝酸与金属反应的还原产物规律。 **教学重点**：NO 与 NO₂ 的性质与转化；氨的性质与喷泉实验；硝酸与铜的反应。 **教学难点**：喷泉实验的压强差原理；硝酸与金属反应中还原产物随浓度变化的规律；NH₄⁺ 检验方案的完整表述。 **教学方法**：实验探究法、对比归纳法、情境教学法、问题链驱动法。 **教学准备**：喷泉实验装置（烧瓶、胶头滴管、烧杯、酚酞）、NH₄Cl 与 Ca(OH)₂、红色石蕊试纸、铜片、浓硝酸与稀硝酸、NO₂ 气体样品（视频）、课件与任务单。 **课时安排**：3 课时（第 1 课时：氮气与氮的氧化物；第 2 课时：氨、铵盐与喷泉实验、实验室制氨；第 3 课时：硝酸与氮氧化物的环境问题）。

📖 课堂讲义 · 核心知识点

**一、氮气与氮的固定** N₂ 是无色、无味气体，占空气体积的约 78%。氮原子最外层 5 个电子，N₂ 分子中存在 N≡N 三键，键能很大（946 kJ/mol），断键困难，因此 N₂ 化学性质很稳定，通常情况下难与其他物质反应，可用作保护气（焊接金属、充入食品包装袋防腐）。 与氧气（放电或高温下才反应，是汽车尾气中 NO 的来源之一）：N₂ + O₂ =（放电或高温）2NO。 与氢气（工业合成氨）：N₂ + 3H₂ ⇌（催化剂，高温高压）2NH₃。 与活泼金属：3Mg + N₂ =（点燃）Mg₃N₂。 氮的固定：将空气中游离态的氮转变为氮的化合物的过程，包括自然固氮（雷电固氮、豆科植物根瘤菌固氮）和人工固氮（合成氨工业）。 **二、氮的氧化物** 氮有 +1 到 +5 五种正价氧化物，重点是 NO 与 NO₂： | 项目 | NO | NO₂ | |---|---|---| | 颜色气味 | 无色、无味 | 红棕色、刺激性气味 | | 毒性 | 有毒（与血红蛋白结合） | 有毒 | | 水溶性 | 难溶于水 | 与水反应 | | 与 O₂ 反应 | 2NO + O₂ = 2NO₂ | 不与 O₂ 直接反应 | | 与水反应 | 不反应 | 3NO₂ + H₂O = 2HNO₃ + NO | | 收集方法 | 只能排水法 | 向上排空气法 | NO₂ 与水的反应是工业制硝酸的基础：3NO₂ + H₂O = 2HNO₃ + NO（NO₂ 中 +4 价 N 一部分升到 +5、一部分降到 +2，是歧化反应）。 转化链：N₂ →（放电）NO →（O₂）NO₂ →（H₂O）HNO₃。把 NO、NO₂ 的混合气体与足量氧气一起通入水中可完全转化为硝酸（4NO + 3O₂ + 2H₂O = 4HNO₃；4NO₂ + O₂ + 2H₂O = 4HNO₃）。 将盛满 NO₂ 的试管倒扣于水中：红棕色褪去，气体体积减为原来的 1/3，水上升进入试管，所得溶液为硝酸。 **三、氨与铵盐** 氨的物理性质：无色、有刺激性气味的气体，密度比空气小，极易溶于水（1 体积水约溶解 700 体积氨），易液化（液化放氨制冷剂）。 化学性质： 1. 与水反应：NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻。氨水显弱碱性，一水合氨是弱碱，部分电离；氨水中的微粒有 NH₃、H₂O、NH₃·H₂O 三种分子和 NH₄⁺、OH⁻（还有极少量 H⁺）。 2. 与酸反应：NH₃ + HCl = NH₄Cl（两支玻璃棒分别蘸浓氨水与浓盐酸靠近产生白烟，可用于互检）；2NH₃ + H₂SO₄ = (NH₄)₂SO₄。 3. 催化氧化：4NH₃ + 5O₂ =（催化剂，△）4NO + 6H₂O（工业制硝酸的第一步）。 喷泉实验原理：挤入少量水溶解大量 NH₃，瓶内压强骤减，内外压强差把水压入瓶中形成喷泉；氨水显碱性，酚酞变红成红色喷泉。凡能造成瓶内压强急剧减小（气体极易溶于水或与液体反应）的装置都能形成喷泉。 铵盐的性质： 1. 都易溶于水。 2. 不稳定性，受热易分解：NH₄Cl =（△）NH₃↑ + HCl↑（试管上部遇冷重新化合成白色固体，看似「升华」实为化学变化——先分解后化合）；NH₄HCO₃ =（△）NH₃↑ + H₂O + CO₂↑。 3. 与碱反应放出氨气：NH₄⁺ + OH⁻ =（△）NH₃↑ + H₂O。 NH₄⁺ 的检验：取样加 NaOH 溶液并加热，将湿润的红色石蕊试纸靠近管口，试纸变蓝则含 NH₄⁺。 实验室制氨：药品为 NH₄Cl 与 Ca(OH)₂ 固体，加热：2NH₄Cl + Ca(OH)₂ =（△）CaCl₂ + 2NH₃↑ + 2H₂O。用向下排空气法收集（密度比空气小），湿润红色石蕊试纸验满（变蓝即满），用碱石灰干燥（不能用浓硫酸、无水 CaCl₂），尾气用水吸收并防倒吸。 **四、硝酸** 物理性质：无色、易挥发、有刺激性气味的液体，能与水任意比互溶。浓硝酸通常呈黄色，因分解产生的 NO₂ 溶于其中。 不稳定性：4HNO₃ =（光照或△）4NO₂↑ + O₂↑ + 2H₂O，故浓硝酸保存在棕色瓶中、置于阴凉处。 强氧化性：无论浓稀都有强氧化性，与金属反应不生成 H₂。 规律：浓硝酸还原产物为 NO₂，稀硝酸为 NO；常温下浓硝酸使 Fe、Al 钝化；变价金属被氧化到最高价。 Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O（产生红棕色气体）； 3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（无色气体，遇空气变红棕色）。 与 C、S 等非金属也能反应（浓硝酸加热）：C + 4HNO₃（浓）=（△）CO₂↑ + 4NO₂↑ + 2H₂O。 王水：浓硝酸与浓盐酸按体积比 1:3 混合，氧化性极强，能溶解金、铂等不活泼金属。 定量关系（以浓硝酸与铜为例）：每 4 mol HNO₃ 参加反应，2 mol 被还原（进入 NO₂），2 mol 起酸的作用（进入 Cu(NO₃)₂），被还原的占一半；稀硝酸中 8 mol 仅 2 mol 被还原，占四分之一。 **五、氮氧化物与环境的保护问题** NO、NO₂ 是大气污染物：形成酸雨（硝酸型）、光化学烟雾、破坏臭氧层。汽车尾气含 NO，可用催化转化处理：2NO + 2CO =（催化剂）N₂ + 2CO₂。 **易错提醒** 1. NO 只能用排水法收集（遇 O₂ 立即反应），NO₂ 只能用向上排空气法（与水反应）。 2. 「白烟」与「白雾」不同：NH₃ 与 HCl 产生的是烟（固体小颗粒）。 3. 硝酸与金属不生成 H₂；常温下 Fe、Al 遇冷浓硝酸钝化，但加热时仍可反应。 4. 制氨干燥剂用碱石灰；NH₄Cl 受热分解不是升华。

🔍 课堂讲义 · 重点难点解析

**重点一：NO 与 NO₂ 的性质对比与转化** 例题：将盛满 NO₂ 的试管倒扣于盛水的水槽中，描述现象并解释，写出方程式。 分析：NO₂ 与水反应生成 HNO₃ 和 NO，NO 不溶于水占据剩余体积。 解答：现象为红棕色迅速褪去，水面上升，最终试管内剩余约 1/3 体积的无色气体，试管内液体为硝酸。方程式：3NO₂ + H₂O = 2HNO₃ + NO。剩余气体若再通入 O₂，又变红棕色并继续与水反应，最终可全部吸收（4NO₂ + O₂ + 2H₂O = 4HNO₃）。 小结：抓住「3NO₂ 生成 1NO」的体积关系（剩 1/3）与颜色变化（红棕→无色）两个特征。 **难点一：喷泉实验的原理** 例题：为什么挤压胶头滴管后，烧杯中的水会沿玻璃管喷入烧瓶形成喷泉？红色从何而来？ 分析：从压强差角度分析——氨极易溶于水使瓶内气压骤降。 解答：胶头滴管挤入的少量水溶解了大量 NH₃（1 体积水溶约 700 体积氨），瓶内气体急剧减少、压强骤降，远小于外界大气压；烧杯中的水在大气压作用下沿导管被压入烧瓶，形成喷泉。氨水显碱性：NH₃·H₂O ⇌ NH₄⁺ + OH⁻，使酚酞变红，故为红色喷泉。形成喷泉的本质条件是容器内外产生足够大的压强差。 小结：喷泉实验与「气体溶解性/反应性」挂钩，凡气体极易溶于液体或与液体剧烈反应（如 HCl 与水、CO₂ 与 NaOH 溶液）均可形成喷泉。 **难点二：硝酸与金属反应的产物规律** 例题：分别写出铜与浓硝酸、稀硝酸反应的方程式，指出其中的「硝酸的角色分配」，并解释常温下铁在浓硝酸中的现象。 分析：HNO₃ 中 +5 价 N 被还原，浓硝酸得 1 个电子生成 NO₂，稀硝酸得 3 个电子生成 NO；方程式中的 HNO₃ 一部分被还原、一部分成盐。 解答：Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O，4 份硝酸中 2 份被还原、2 份起酸的作用；3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O，8 份中 2 份被还原、6 份起酸的作用。常温下铁遇浓硝酸表面被氧化生成致密氧化膜，反应停止，即钝化，故可用铝罐、铁罐运输冷浓硝酸。 小结：记规律「浓生 NO₂、稀生 NO、冷浓遇 Fe/Al 钝化、无 H₂」；计算时区分「被还原的硝酸」与「总消耗的硝酸」。 **易错警示：NH₄Cl 受热不是升华** 例题：加热试管中的 NH₄Cl 固体，白色固体在试管上部重新出现，有同学认为是升华。对吗？ 解答：不对。NH₄Cl 受热分解：NH₄Cl =（△）NH₃↑ + HCl↑，两种气体上升到试管温度较低处重新化合：NH₃ + HCl = NH₄Cl，白色固体重新出现。整个过程经历了「分解—化合」两次化学变化，而升华是物理变化，二者有本质区别。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：氮氧化物性质判断** 题目：下列关于 NO 和 NO₂ 的说法正确的是（ ）。A. NO 是红棕色气体；B. NO₂ 可用排水法收集；C. NO 只能用排水法收集；D. NO₂ 与水反应生成硝酸和 NO。 分析：逐项对照两者性质表。 解答：选 C、D。A 错，NO 是无色气体，NO₂ 才是红棕色；B 错，NO₂ 与水反应，不能排水收集，用向上排空气法；C 对，NO 难溶于水且遇 O₂ 反应，只能排水法；D 对，3NO₂ + H₂O = 2HNO₃ + NO。 方法小结：两种氧化物按「颜色、溶解性、与 O₂、与水」四点对比记忆，收集方法由性质决定。 **例题二（提高）：实验室制氨的综合考查** 题目：实验室用 NH₄Cl 与 Ca(OH)₂ 制取并收集干燥的氨气。(1) 写出化学方程式；(2) 说明收集与验满方法；(3) 能否用浓硫酸干燥氨气？应选用什么干燥剂？ 分析：氨密度比空气小且极易溶于水；氨是碱性气体，与酸性干燥剂反应。 解答：(1) 2NH₄Cl + Ca(OH)₂ =（△）CaCl₂ + 2NH₃↑ + 2H₂O。(2) 用向下排空气法收集；将湿润的红色石蕊试纸置于管口，试纸变蓝说明已收集满（或用蘸浓盐酸的玻璃棒靠近管口，产生白烟则满）。(3) 不能，浓硫酸与氨反应生成硫酸铵（2NH₃ + H₂SO₄ = (NH₄)₂SO₄）；应选用碱石灰（碱性干燥剂）。 方法小结：气体实验题按「制—净—干—收—验—尾」六环节逐一核对，干燥剂性质必须与气体性质匹配。 **例题三（综合）：硝酸与铜的多步计算** 题目：将 3.2 g 铜片投入 50 mL 足量浓硝酸中充分反应（Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O）。(1) 求标况下生成 NO₂ 的体积；(2) 求被还原的硝酸与消耗的硝酸总量的物质的量；(3) 若改用足量稀硝酸，生成气体的体积如何变化（写出设、写、算、答）。 分析：n(Cu) = 3.2 ÷ 64 = 0.05 mol；按方程式比例计算；浓硝酸产 NO₂、稀硝酸产 NO，比例不同。 解答： (1) 设生成 NO₂ 为 x mol。由 Cu ~ 2NO₂ 得 x = 0.05 × 2 = 0.1 mol，V = 0.1 × 22.4 = 2.24 L。 (2) 被还原的硝酸 = 进入 NO₂ 的量 = 0.1 mol；消耗硝酸总量 = 4 × 0.05 = 0.2 mol（被还原的占一半）。 (3) 改用稀硝酸：3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O，0.05 mol Cu 生成 NO 为 0.05 × 2/3 ≈ 0.033 mol，V ≈ 0.75 L，比浓硝酸的 2.24 L 明显减少。 答：NO₂ 2.24 L；被还原硝酸 0.1 mol、耗酸总量 0.2 mol；稀硝酸时气体减少为约 0.75 L。 方法小结：硝酸计算抓两条比例线——金属与气体的比例、被还原硝酸与总耗酸的比例；浓度不同则还原产物不同。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 氮及其化合物识记

  1. 1. 填空：N₂ 化学性质稳定的原因是________；N₂ 与 O₂ 在________条件下化合生成________（填化学式）；工业合成氨的化学方程式是________（注明条件）。
    答：N₂ 分子中 N≡N 三键键能大，不易断裂；放电或高温；NO。N₂ + 3H₂ ⇌（催化剂，高温高压）2NH₃。
  2. 2. 填空：NO 是________色气体，________溶于水，能与________反应；NO₂ 是________色、有________气味的气体，与水反应的方程式是________。
    答：NO 无色、难溶（不溶）于水，能与 O₂ 反应（2NO + O₂ = 2NO₂）；NO₂ 红棕色、刺激性气味；3NO₂ + H₂O = 2HNO₃ + NO。
  3. 3. 完成方程式：(1) 氨的催化氧化；(2) 氨与盐酸反应；(3) NH₄HCO₃ 受热分解；(4) 铜与稀硝酸反应。
    答：(1) 4NH₃ + 5O₂ =（催化剂，△）4NO + 6H₂O；(2) NH₃ + HCl = NH₄Cl；(3) NH₄HCO₃ =（△）NH₃↑ + H₂O + CO₂↑；(4) 3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。

中等 · 性质运用与实验

  1. 1. 检验某白色晶体是否为铵盐：取样加入________溶液并________，将________的红色石蕊试纸靠近管口，若________则含 NH₄⁺。写出对应的离子方程式。
    答：加入 NaOH 溶液并加热，将湿润的红色石蕊试纸靠近管口，试纸变蓝则含 NH₄⁺。离子方程式：NH₄⁺ + OH⁻ =（△）NH₃↑ + H₂O。注意「加热」与「湿润」两个关键词缺一不可。
  2. 2. 喷泉实验：烧瓶中分别充满下列气体，挤压胶头滴管（内为水）能否形成喷泉？说明理由。(1) NH₃；(2) NO；(3) CO₂（烧杯中为 NaOH 溶液）。
    答：(1) 能。NH₃ 极易溶于水（1:700），瓶内压强骤减，形成红色喷泉（氨水显碱性）。(2) 不能。NO 难溶于水且不与水反应，瓶内压强几乎不变。(3) 能。CO₂ 与 NaOH 溶液剧烈反应（CO₂ + 2OH⁻ = CO₃²⁻ + H₂O），压强骤减形成喷泉。结论：气体极易溶于液体或与液体快速反应即可形成喷泉。
  3. 3. 实验室制氨：(1) 写出化学方程式；(2) 选择收集方法并说明理由；(3) 干燥氨气能否用浓硫酸和无水氯化钙？应选什么？
    答：(1) 2NH₄Cl + Ca(OH)₂ =（△）CaCl₂ + 2NH₃↑ + 2H₂O。(2) 向下排空气法，因氨密度比空气小且极易溶于水（不能用排水法）。(3) 都不能：浓硫酸与氨反应生成 (NH₄)₂SO₄；无水 CaCl₂ 与氨结合生成 CaCl₂·8NH₃。应选用碱石灰。

难 · 计算与推断

  1. 1. 计算：3.2 g 铜与足量浓硝酸反应（Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O）。(1) 求标况下生成 NO₂ 的体积；(2) 求被还原的硝酸的物质的量；(3) 求转移电子的物质的量（写出设、写、算、答）。
    答：设生成 NO₂ 为 x mol。n(Cu) = 3.2 g ÷ 64 g/mol = 0.05 mol。(1) 由 Cu ~ 2NO₂ 得 x = 0.1 mol，V = 0.1 × 22.4 = 2.24 L。(2) 被还原的硝酸即进入 NO₂ 的部分，n = 0.1 mol。(3) 每个 Cu 失 2 个电子，n(e⁻) = 0.05 × 2 = 0.1 mol（与 NO₂ 中 N 得电子数 0.1 mol 相等，电子守恒）。答：NO₂ 2.24 L，被还原硝酸 0.1 mol，转移电子 0.1 mol。
  2. 2. 推断与计算：把 30 mL NO₂ 和 NO 的混合气体通入倒扣在水中且盛满水的量筒里，充分反应后量筒内剩余气体 12 mL（同温同压）。求原混合气体中 NO₂ 与 NO 的体积比。
    答：设 NO₂ 为 x mL，NO 为 y mL。依题意：x + y = 30。NO 不与水反应、不溶于水，NO₂ 与水反应：3NO₂ + H₂O = 2HNO₃ + NO，每 3 mL NO₂ 反应后变为 1 mL NO。剩余气体 = y + x/3 = 12。联立两式：把 y = 30 - x 代入，得 30 - x + x/3 = 12，即 2x/3 = 18，x = 27，y = 3。答：原混合气体中 NO₂ 与 NO 的体积比为 27:3 = 9:1。
  3. 3. 信息计算：汽车尾气催化转化：2NO + 2CO =（催化剂）N₂ + 2CO₂。某尾气样品中含 NO 0.06 mol，(1) 求需 CO 的质量和生成 N₂ 的体积（标况）；(2) 说明该反应对环境保护的意义（写出设、写、算、答）。
    答：设需 CO 为 x mol，生成 N₂ 为 y mol。n(NO) = 0.06 mol，由 2NO ~ 2CO 得 x = 0.06 mol，m(CO) = 0.06 × 28 = 1.68 g；由 2NO ~ 1N₂ 得 y = 0.03 mol，V = 0.03 × 22.4 = 0.672 L。(2) 意义：把有毒的 NO（和 CO）转化为无毒的 N₂ 和 CO₂，减少光化学烟雾和酸雨的成因。答：需 CO 1.68 g，生成 N₂ 0.672 L。

综合 · 实验与工业应用

  1. 1. 实验综合：实验室制取并验证氨的性质。提供药品：NH₄Cl 固体、Ca(OH)₂ 固体、碱石灰、浓硫酸、湿润红色石蕊试纸。(1) 设计制气装置要点并写方程式；(2) 设计两个验证氨性质的实验（喷泉实验除外）；(3) 说明收集氨气时试管口棉花的作用。
    答：(1) 固固加热装置（与制 O₂ 类似），试管口略向下倾斜：2NH₄Cl + Ca(OH)₂ =（△）CaCl₂ + 2NH₃↑ + 2H₂O。(2) 实验一：玻璃棒蘸浓盐酸靠近氨气瓶口，产生白烟（NH₃ + HCl = NH₄Cl），证明氨与酸反应；实验二：把充满氨气的烧瓶倒扣入滴有酚酞的水中，水迅速上升且变红，证明氨极易溶于水、氨水显碱性（或收集满后做喷泉实验）。(3) 试管口塞一团棉花：防止氨气与空气对流，提高收集纯度，同时减少氨气逸出污染空气。
  2. 2. 工业流程：工业制硝酸的完整流程为合成氨、氨的催化氧化、NO₂ 的吸收。(1) 写出三步的化学方程式（注明条件）；(2) 吸收塔中通入过量空气的目的（用方程式说明）；(3) 说明该流程与「氮的固定」的关系。
    答：(1) 合成氨：N₂ + 3H₂ ⇌（催化剂，高温高压）2NH₃；催化氧化：4NH₃ + 5O₂ =（催化剂，△）4NO + 6H₂O；吸收：3NO₂ + H₂O = 2HNO₃ + NO。(2) 通入过量空气使生成的 NO 继续氧化：2NO + O₂ = 2NO₂，生成的 NO₂ 再被水吸收（4NO₂ + O₂ + 2H₂O = 4HNO₃），使 NO 循环利用、提高原料转化率。(3) 合成氨把游离态氮（N₂）转化为化合态氮（NH₃），属于人工固氮；整条流程是固氮成果的深加工。
  3. 3. 综合实验：将盛满 12 mL NO₂ 气体的试管倒扣于水槽中（实验一），反应完毕后再向试管中通入 3 mL O₂（实验二）。(1) 描述实验一的现象并写方程式；(2) 解释实验二中气体颜色先变红棕色后消失的原因并写方程式；(3) 两步实验结束后试管内是否还有气体？溶液约占试管容积的多少（同温同压）？
    答：(1) 红棕色逐渐褪去，水面上升，试管内剩余约 1/3 体积（4 mL）的无色气体，试管内形成硝酸溶液：3NO₂ + H₂O = 2HNO₃ + NO。(2) 通入 O₂ 后 NO 被氧化：2NO + O₂ = 2NO₂，无色气体变为红棕色；随后 NO₂ 继续与水反应并最终与 O₂、H₂O 完全反应：4NO + 3O₂ + 2H₂O = 4HNO₃，12 mL NO₂ 恰好需 3 mL O₂ 使其全部转化为硝酸，气体完全溶解，红棕色消失。(3) 无气体剩余。12 mL NO₂ 按总式 4NO₂ + O₂ + 2H₂O = 4HNO₃ 恰好需 3 mL O₂，气体全部被吸收，溶液充满试管，约占试管容积的 100%。

💬 课后反馈

**学生常见错误** 1. NO 与 NO₂ 性质混淆：收集方法选错（NO₂ 用排水法、NO 用排空气法），倒扣水中实验记不清「剩 1/3 气体」的量关系。 2. 喷泉实验原理答不完整：只说「溶于水」，不讲压强差这一本质，也不会迁移到 CO₂ 与 NaOH 溶液的变式情境。 3. 硝酸规律记反或丢条件：浓稀硝酸的还原产物写反；忘记常温钝化的「冷、浓」条件；与金属反应方程式中误写 H₂。 4. NH₄⁺ 检验表述不完整：漏写「加热」或「湿润的红色石蕊试纸」，把「白烟」说成「白雾」；认为 NH₄Cl 受热是升华。 **教学改进建议** 1. NO、NO₂ 用对比表格加「倒扣水中」演示（或视频）突破，强化「颜色变化 + 体积关系」两大特征，配变式计算（剩余体积、通 O₂ 完全吸收）。 2. 喷泉实验先做再析：演示后用「为什么」问题链（水为何上升？红色从何来？换成 NO 行不行？换成 NaOH 溶液呢？）层层追问，把原理讲透并迁移。 3. 硝酸与金属反应总结成规律卡片：「浓生 NO₂、稀生 NO、冷浓钝化 Fe/Al、不产 H₂」，并用「被还原的硝酸」专项练习区分两种角色。 **分层辅导建议** - 基础层：过关 N₂、NO、NO₂、NH₃、HNO₃ 的核心方程式与颜色状态记忆。 - 提高层：强化喷泉实验原理表述、NH₄⁺ 检验的规范书写和实验室制氨全流程。 - 拓展层：完成硝酸与铜的多步计算、NO/NO₂/O₂ 混合气体溶于水的计算和工业制硝酸流程题。 **给家长的建议** 1. 孩子复习时可让其讲解喷泉实验和「红色喷泉为什么是红的」，能说清压强差与碱性的关系即是掌握。 2. 结合新闻谈氮氧化物污染（雾霾、光化学烟雾）与汽车尾气催化转化器，引导孩子用本章方程式解释环保技术的化学原理。
