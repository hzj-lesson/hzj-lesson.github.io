高中高二化学《水溶液中的离子平衡》教案

高中高二化学水溶液中的离子平衡

📝 备课方案

**教学目标** 1. 理解弱电解质电离平衡的特征，会书写强、弱电解质的电离方程式，知道电离平衡常数的含义、表达式及其只受温度影响。 2. 理解水的电离和水的离子积 Kw，掌握 25℃ 时 Kw = 1×10⁻¹⁴，会进行 c(H⁺)、c(OH⁻) 与 pH 之间的简单换算，知道酸、碱抑制水的电离。 3. 了解酸碱中和滴定的原理，认识滴定管的结构并掌握规范操作，能根据滴定终点酸碱性正确选择指示剂，会进行滴定的简单计算与误差分析。 4. 通过滴定曲线分析培养定量意识和数形结合能力，养成严谨、规范的实验操作习惯。 **教学重点**：弱电解质的电离平衡与 Ka；水的离子积与 pH 计算；中和滴定的原理、操作与计算。 **教学难点**：电离平衡常数的计算；多元弱酸分步电离；滴定曲线的突跃分析与指示剂选择；滴定误差分析。 **教学方法**：实验探究法、定量分析法、数形结合法、讲练结合法。 **教学准备**：pH 计（或精密 pH 试纸）、酸式滴定管、碱式滴定管、锥形瓶、铁架台、蝴蝶夹、0.1000 mol/L NaOH 标准液、待测盐酸、甲基橙、酚酞、课件与滴定操作视频。 **课时安排**：3 课时（第 1 课时：弱电解质的电离平衡；第 2 课时：水的电离与 pH 计算；第 3 课时：酸碱中和滴定与滴定曲线）。

📖 课堂讲义 · 核心知识点

**一、强电解质与弱电解质** | 比较 | 强电解质 | 弱电解质 | |---|---|---| | 电离程度 | 完全电离 | 部分电离 | | 电离方程式 | 用「=」，如 HCl = H⁺ + Cl⁻ | 用「⇌」，如 CH₃COOH ⇌ CH₃COO⁻ + H⁺ | | 溶液中微粒 | 只有离子（水合离子） | 离子与分子共存 | | 类别 | 强酸、强碱、大部分盐 | 弱酸、弱碱、水 | 注意：电解质的强弱与溶解性无关，如 BaSO₄ 难溶但属于强电解质；与溶液导电能力也无绝对关系，导电能力取决于离子浓度。 **二、弱电解质的电离平衡与电离平衡常数** 弱电解质的电离是可逆的，存在类似化学平衡的电离平衡。以醋酸为例：CH₃COOH ⇌ CH₃COO⁻ + H⁺。 电离平衡常数：Ka = c(CH₃COO⁻) × c(H⁺) ÷ c(CH₃COOH)。一水合氨：Kb = c(NH₄⁺) × c(OH⁻) ÷ c(NH₃·H₂O)。 - Ka（Kb）越大，弱酸（弱碱）酸性（碱性）越强，如 Ka：醋酸 > 碳酸（第一步）> 次氯酸； - 电离常数只与温度有关，升温促进电离，Ka 增大； - 多元弱酸分步电离，且第一步远大于第二步，如 H₃PO₄：Ka₁ 远大于 Ka₂ 远大于 Ka₃，其酸性主要由第一步决定； - 加水稀释促进电离，但离子浓度减小；加入酸、碱或对应盐可抑制电离。 **三、水的电离与水的离子积** 水是极弱的电解质：H₂O ⇌ H⁺ + OH⁻。25℃ 时纯水中 c(H⁺) = c(OH⁻) = 1×10⁻⁷ mol/L。 水的离子积：Kw = c(H⁺) × c(OH⁻)。25℃ 时 Kw = 1×10⁻¹⁴。 - Kw 只与温度有关，升温促进水的电离，如 100℃ 时 Kw ≈ 1×10⁻¹²，此时纯水 pH = 6，但仍为中性（c(H⁺) 与 c(OH⁻) 仍相等）； - 酸、碱抑制水的电离；水解的盐促进水的电离； - 酸性溶液 c(H⁺) > c(OH⁻)，碱性溶液 c(H⁺) < c(OH⁻)，任何水溶液中 Kw 关系式都成立。 **四、pH 及其计算** pH = -lg c(H⁺)，即 pH 等于氢离子浓度以 10 为底的对数的相反数（文字表述：c(H⁺) = 1×10⁻ⁿ mol/L 时，pH = n）。 - c(H⁺) 每增大 10 倍，pH 减小 1； - 先求 c(H⁺) 再求 pH；碱溶液先求 c(OH⁻)，再用 c(H⁺) = Kw ÷ c(OH⁻) 换算； - 强酸稀释：pH = 2 的盐酸稀释 100 倍后 pH = 4；弱酸稀释后因继续电离，pH 变化小于 2（2 < pH < 4）；无限稀释都趋近于 7。 **五、酸碱中和滴定** 原理：H⁺ + OH⁻ = H₂O。一元酸碱恰好反应时 c(酸) × V(酸) = c(碱) × V(碱)；二元酸（碱）要乘元数。 仪器：酸式滴定管（玻璃活塞，盛酸性、强氧化性溶液）；碱式滴定管（橡胶管加玻璃珠，盛碱性溶液）。 主要操作流程：检漏 → 洗涤 → 润洗（用所盛溶液 3～5 mL 润洗 2～3 次）→ 装液、排气泡、调零读数 → 取一定体积待测液放入锥形瓶 → 滴入指示剂 → 滴定（左手控制活塞、右手摇动锥形瓶、眼睛注视瓶内颜色变化）→ 终点判断（最后一滴使指示剂变色且半分钟内不复原）→ 读取消耗体积。 终点时酸碱恰好完全反应，但由于生成盐的水解等原因，终点溶液不一定显中性。 **六、指示剂与滴定曲线** | 指示剂 | 变色范围 | 颜色变化（酸性 → 碱性） | |---|---|---| | 甲基橙 | 3.1～4.4 | 红色 → 橙色 → 黄色 | | 酚酞 | 8.2～10.0 | 无色 → 粉红色 → 红色 | | 石蕊 | 5.0～8.0 | 红色 → 紫色 → 蓝色（变色不明显，不用于滴定） | 指示剂选择原则：变色范围处于或部分处于滴定突跃范围内，且终点颜色变化明显。 - 强碱滴强酸（如 NaOH 滴盐酸）：终点附近突跃大，酚酞或甲基橙均可； - 强碱滴弱酸（如 NaOH 滴醋酸）：恰好中和时生成醋酸钠，溶液显碱性，选酚酞； - 强酸滴弱碱（如盐酸滴氨水）：恰好中和时生成氯化铵，溶液显酸性，选甲基橙。 **易错提醒** 1. 弱电解质电离方程式误用「=」。 2. 计算碱溶液 pH 忘先用 Kw 换算。 3. 稀释弱酸时套用强酸公式。 4. 滴定管读数忽略「0 刻度在上、估读一位」。

🔍 课堂讲义 · 重点难点解析

**重点一：电离平衡常数的理解与计算** 例题：25℃ 时，0.10 mol/L 的醋酸溶液 pH = 3。求该温度下醋酸的电离平衡常数 Ka。 分析：由 pH 求 c(H⁺)，再近似处理 c(CH₃COOH) ≈ 0.10 mol/L，代入 Ka 表达式。 解答：c(H⁺) = 1×10⁻³ mol/L。电离出的 c(CH₃COO⁻) ≈ c(H⁺) = 1×10⁻³ mol/L（水的电离可忽略）。平衡时 c(CH₃COOH) ≈ 0.10 - 0.001 ≈ 0.10 mol/L。 Ka = c(CH₃COO⁻) × c(H⁺) ÷ c(CH₃COOH) = 1×10⁻³ × 1×10⁻³ ÷ 0.10 = 1×10⁻⁵。 答：Ka ≈ 1×10⁻⁵。 小结：弱酸 Ka 计算的近似——已电离部分远小于初始浓度，可直接用初始浓度代替平衡浓度。 **难点一：pH 的计算与稀释规律** 例题：25℃ 时，（1）pH = 2 的盐酸稀释 100 倍，pH 变为多少？（2）pH = 2 的醋酸稀释 100 倍，pH 范围是多少？ 分析：强酸完全电离，稀释 n 倍 c(H⁺) 缩小 n 倍；弱酸稀释时电离平衡右移，c(H⁺) 减小得慢。 解答：（1）c(H⁺) 由 1×10⁻² mol/L 变为 1×10⁻⁴ mol/L，pH = 4。（2）稀释中醋酸继续电离，c(H⁺) 大于 1×10⁻⁴ mol/L 而小于 1×10⁻² mol/L，故 2 < pH < 4。 小结：「强酸直除，弱酸打折」——每稀释 10 倍，强酸 pH 加 1，弱酸 pH 加不到 1。 **难点二：中和滴定的误差分析** 例题：用 0.1000 mol/L NaOH 标准液滴定未知浓度盐酸，下列操作对结果（c 待测偏高、偏低或无影响）分别有什么影响？（1）滴定管未用标准液润洗；（2）锥形瓶用待测液润洗；（3）滴定前滴定管尖嘴有气泡、滴定后气泡消失。 分析：误差都归结为 V(标准) 读数的偏差，再由 c(待测) = c(标准) × V(标准) ÷ V(待测) 判断。 解答：（1）标准液被管内残留水稀释，消耗体积偏大，结果偏高；（2）锥形瓶内待测物增多，消耗体积偏大，结果偏高（锥形瓶只需蒸馏水洗净，不得润洗）；（3）气泡体积被计入消耗体积，V(标准) 偏大，结果偏高。 小结：误差分析口诀——看操作引起「V(标准) 偏大还是偏小」，V 偏大结果偏高，V 偏小结果偏低。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：pH 与离子浓度换算** 题目：25℃ 时，某盐酸的 pH = 3。（1）求该溶液中 c(H⁺) 和 c(Cl⁻)；（2）求由水电离出的 c(H⁺)。 分析：pH 直接给 c(H⁺)；盐酸中 Cl⁻ 与 H⁺ 等量；酸抑制水的电离，溶液中的 H⁺ 几乎全部来自酸。 解答：（1）pH = 3，即 c(H⁺) = 1×10⁻³ mol/L；盐酸一元强酸完全电离，c(Cl⁻) = c(H⁺) = 1×10⁻³ mol/L。（2）水电离出的 c(OH⁻) = Kw ÷ c(H⁺) = 1×10⁻¹⁴ ÷ 1×10⁻³ = 1×10⁻¹¹ mol/L，水电离出的 c(H⁺) 等于水电离出的 c(OH⁻)，故为 1×10⁻¹¹ mol/L。 方法小结：酸碱溶液中「水电离出的 c(H⁺)」等于水电离出的 c(OH⁻)，常通过 Kw 换算求出。 **例题二（提高）：酸碱混合后 pH 计算** 题目：25℃ 时，将 pH = 3 的盐酸与 pH = 11 的 NaOH 溶液等体积混合，求混合液的 pH。 分析：分别求酸中 c(H⁺) 与碱中 c(OH⁻)，比较谁过量。 解答：酸中 c(H⁺) = 1×10⁻³ mol/L；碱中 c(OH⁻) = Kw ÷ c(H⁺) = 1×10⁻¹⁴ ÷ 1×10⁻¹¹ = 1×10⁻³ mol/L。等体积混合时 n(H⁺) = n(OH⁻)，恰好完全中和，生成 NaCl 不水解，溶液呈中性，pH = 7。 方法小结：25℃ 时 pH 之和为 14 的强酸与强碱等体积混合恰好中和；若 pH 之和大于 14 则碱过量、小于 14 则酸过量。 **例题三（综合）：滴定测定待测液浓度** 题目：用 0.1000 mol/L 的 NaOH 标准液滴定 20.00 mL 未知浓度的盐酸，选择酚酞作指示剂，达到终点时消耗 NaOH 溶液 18.00 mL。求盐酸的物质的量浓度。 分析：按 c(酸) × V(酸) = c(碱) × V(碱) 计算。 解答：设盐酸浓度为 c。 c × 20.00 mL = 0.1000 mol/L × 18.00 mL c = (0.1000 × 18.00) ÷ 20.00 = 0.0900 mol/L。 答：该盐酸的浓度为 0.0900 mol/L。 方法小结：滴定计算四步——写化学方程式（或离子方程式）→ 找计量关系 → 列比例式 → 求解并保留与数据一致的位数。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 电离方程式与 pH 概念

  1. 1. 写出下列电离方程式：（1）醋酸；（2）一水合氨；（3）盐酸。
    答：（1）CH₃COOH ⇌ CH₃COO⁻ + H⁺；（2）NH₃·H₂O ⇌ NH₄⁺ + OH⁻；（3）HCl = H⁺ + Cl⁻。弱电解质用「⇌」，强电解质用「=」。
  2. 2. 25℃ 时，c(H⁺) = 1×10⁻⁵ mol/L 的溶液，pH 是多少？该溶液中 c(OH⁻) 是多少？
    答：pH = 5；c(OH⁻) = Kw ÷ c(H⁺) = 1×10⁻¹⁴ ÷ 1×10⁻⁵ = 1×10⁻⁹ mol/L。
  3. 3. 酸碱中和滴定中，锥形瓶是否需要用待测液润洗？为什么？
    答：不需要。锥形瓶若用待测液润洗，会使瓶内待测物质的量增多，消耗标准液体积偏大，导致测定结果偏高；只需用蒸馏水洗净即可。

中等 · 水的电离与溶液酸碱性

  1. 1. 25℃ 时，pH = 2 的盐酸中：c(H⁺) 是多少？c(Cl⁻) 是多少？由水电离出的 c(H⁺) 是多少？
    答：c(H⁺) = 1×10⁻² mol/L；盐酸完全电离，c(Cl⁻) = 1×10⁻² mol/L；水电离出的 c(H⁺) = 水电离出的 c(OH⁻) = Kw ÷ c(H⁺) = 1×10⁻¹⁴ ÷ 1×10⁻² = 1×10⁻¹² mol/L。
  2. 2. 25℃ 时，将 pH = 12 的 NaOH 溶液稀释 100 倍，稀释后溶液的 pH 是多少？
    答：pH = 10。c(OH⁻) 由 1×10⁻² mol/L 变为 1×10⁻⁴ mol/L，c(H⁺) = 1×10⁻¹⁴ ÷ 1×10⁻⁴ = 1×10⁻¹⁰ mol/L，pH = 10。
  3. 3. 用 NaOH 标准液滴定醋酸溶液，应选用酚酞还是甲基橙作指示剂？说明理由。
    答：选酚酞。恰好中和时生成醋酸钠，醋酸根水解使溶液显碱性（pH 约 8～9），处于酚酞变色范围（8.2～10.0）内；甲基橙变色范围在酸性区（3.1～4.4），会在酸大量过量时变色，误差大。

难 · Ka 计算与混合 pH

  1. 1. 25℃ 时，某 0.10 mol/L 的一元弱酸 HA 溶液 pH = 3。求 HA 的电离平衡常数 Ka（忽略水的电离）。
    答：c(H⁺) = 1×10⁻³ mol/L，则 c(A⁻) ≈ 1×10⁻³ mol/L，平衡时 c(HA) ≈ 0.10 mol/L。Ka = c(H⁺) × c(A⁻) ÷ c(HA) = 1×10⁻³ × 1×10⁻³ ÷ 0.10 = 1×10⁻⁵。
  2. 2. 25℃ 时，将 pH = 2 的盐酸与 pH = 4 的盐酸等体积混合，求混合液的 pH（对数可用文字说明）。
    答：混合后 c(H⁺) = (1×10⁻² + 1×10⁻⁴) ÷ 2 ≈ 5×10⁻³ mol/L。pH = -lg(5×10⁻³)，即 5×10⁻³ 介于 1×10⁻² 与 1×10⁻³ 之间，pH 约为 2.3（两 pH 相差 2 的同种酸等体积混合，pH 约为小值加 0.3）。
  3. 3. 25℃ 时，将 pH = 2 的盐酸与 pH = 11 的 NaOH 溶液等体积混合，求混合液的 pH。
    答：酸中 c(H⁺) = 1×10⁻² mol/L，碱中 c(OH⁻) = 1×10⁻³ mol/L，酸过量。混合后 c(H⁺) = (1×10⁻² - 1×10⁻³) ÷ 2 = 4.5×10⁻³ mol/L，pH 约为 2.3（pH = 3 - lg 4.5 ≈ 3 - 0.65 = 2.35，答 2.3～2.4 均可）。

综合 · 滴定实验全流程分析

  1. 1. 简述用标准 NaOH 溶液滴定待测盐酸的完整操作流程（从准备到读数），并说明终点如何判断。
    答：①检漏：检查滴定管是否漏水；②洗涤：先自来水后蒸馏水洗净；③润洗：用标准液润洗碱式滴定管 2～3 次；④装液、排气泡、调液面至 0 刻度附近并读数；⑤用移液管（或酸式滴定管）取一定体积待测盐酸放入锥形瓶，滴加 2～3 滴酚酞；⑥左手控制活塞、右手摇瓶、眼睛注视瓶内颜色变化，逐滴滴入；⑦当最后一滴使溶液变浅红色且半分钟不褪色即达终点，读数（视线与凹液面最低处相平，估读一位）。终点前后各读一次数，差值为消耗体积。
  2. 2. 滴定中发生下列情况，测定结果偏高、偏低还是无影响？（1）滴定前俯视读取碱式滴定管起始读数、滴定后平视读数；（2）锥形瓶内有少量蒸馏水；（3）用甲基橙代替酚酞滴定醋酸。
    答：（1）滴定管 0 刻度在上，起始俯视读数偏小，使 V(标准) = 终读 - 起读 偏大，结果偏高；（2）无影响，待测物质的量不变，多出的水只稀释溶液不改变物质的量；（3）偏低，甲基橙在酸性范围变色，酸尚未完全被中和就判断为终点，V(标准) 偏小，故结果偏低（此处中和点显碱性，应选酚酞）。
  3. 3. 设计一个方案：测定某品牌食醋（主要成分为醋酸）中醋酸的大致浓度。写出需要的主要仪器、指示剂选择及浓度计算关系式。
    答：步骤：将食醋准确稀释定容（如稀释 10 倍），取一定体积（如 20.00 mL）放入锥形瓶，加 2～3 滴酚酞，用已知浓度（如 0.1000 mol/L）的 NaOH 标准液滴定至浅红色半分钟不褪。仪器：碱式滴定管、移液管、锥形瓶、容量瓶、铁架台等。指示剂：酚酞（终点生成醋酸钠显碱性）。计算：c(醋酸) = c(NaOH) × V(NaOH) ÷ V(食醋样品)，再乘稀释倍数。

💬 课后反馈

**学生常见错误** 1. 电离方程式写错符号：弱电解质写成完全电离，多元弱酸不分步电离或把各步合并颠倒主次。 2. pH 计算忽略 Kw 换算：求碱溶液 pH 直接把 c(OH⁻) 当 c(H⁺) 用，或忘记酸碱混合前先折算过量问题。 3. 稀释问题套错规律：对弱酸稀释也按「每 10 倍加 1」处理，忽视电离平衡的移动。 4. 滴定操作与误差分析混乱：分不清哪个量被扭曲，尤其是滴定管「0 刻度在上」导致的读数方向问题。 **教学改进建议** 1. 坚持「先写平衡式、再写常数式」的两步走，把电离平衡与化学平衡的形式统一，学生就不容易把 Ka 用错。 2. pH 计算配备「换算流程卡」：碱 → c(OH⁻) → c(H⁺) → pH；混合 → 先比过量 → 再算剩余浓度。 3. 滴定用真实操作加录像回放：先放手操作一遍，再对照视频找错，误差分析题让学生「先说操作、再算偏差」，条理更清。 **分层辅导建议** - 基础层：过关强、弱电解质判断与电离方程式，pH 与 c(H⁺) 的单向换算。 - 提高层：完成 Ka 计算与酸碱混合计算，掌握滴定计算公式。 - 拓展层：训练滴定曲线分析（起点、突跃、终点位置与指示剂匹配）、误差分析与实验方案设计。 **给家长的建议** 1. 可提醒孩子把「pH 三步换算」和「滴定误差口诀（看 V 偏大还是偏小）」抄在错题本首页，考前反复看。 2. 鼓励孩子用洗碗时的食醋、小苏打水等家用品说一说酸碱性，把「离子平衡」和生活经验连起来，减少畏难情绪。
