高中高一数学《函数的概念与性质》教案

高中高一数学函数的概念与性质

📝 备课方案

**教学目标** 1. 理解函数的概念，明确函数的三要素（定义域、对应关系、值域），理解符号 f(x) 的含义，会求简单函数的定义域与值域。 2. 理解相等函数的概念，掌握判断两个函数是否为同一函数的方法；掌握求函数定义域的一般方法与常见依据。 3. 理解函数的单调性、最大（小）值的概念，掌握用定义证明函数单调性的基本步骤，能利用单调性比较大小、求最值。 4. 理解函数奇偶性的概念，掌握判断奇偶性的方法，能利用奇偶性、单调性解决简单的综合问题，体会数形结合思想。 **教学重点**：函数的概念及三要素；函数单调性的定义与证明；函数奇偶性的判断与简单应用。 **教学难点**：对"y=f(x)"中对应关系 f 的理解；用定义证明函数的单调性；含参数函数的单调性、奇偶性讨论。 **教学方法**：数形结合法、问题驱动法、讲练结合法。借助函数图象直观理解单调性与奇偶性，再上升到符号语言严格论证。 **教学准备**：多媒体课件、函数图象软件（几何画板或 Desmos）、学生作图用方格纸、随堂练习单。 **课时安排**：本章安排 5 课时。第 1 课时函数的概念及其表示，第 2 课时函数的定义域与值域，第 3 课时函数的单调性，第 4 课时函数的最大（小）值，第 5 课时函数的奇偶性（含奇偶性与单调性的综合应用）。

📖 课堂讲义 · 核心知识点

**一、函数的概念** 设 A、B 是非空的实数集，如果按照某种确定的对应关系 f，使对于集合 A 中的任意一个数 x，在集合 B 中都有唯一确定的数 y 和它对应，那么就称 f：A→B 为从集合 A 到集合 B 的一个函数，记作 $y=f(x)$，$x\in A$。其中 x 叫作自变量，x 的取值范围 A 叫作函数的定义域；与 x 的值相对应的 y 值叫作函数值，函数值的集合 $\{f(x)\mid x\in A\}$ 叫作函数的值域。 函数的三要素是定义域、对应关系与值域。由于值域由定义域和对应关系唯一确定，判断两个函数是否为同一函数只需看定义域与对应关系是否一致。例如 $f(x)=x$ 与 $g(x)=\frac{x^2}{x}$ 不是同一函数，因为 g 的定义域为 {x|x≠0}；而 $f(x)=x^2$ 与 $g(t)=t^2$ 是同一函数，因为定义域、对应关系都相同，与用什么字母无关。 **二、函数的表示方法** 函数的三种常用表示法：解析法（用数学式子表示，如 y=2x+1）、列表法（用表格列出 x 与 y 的对应值）、图象法（用图象表示）。三者各有所长：解析法精确简洁，列表法直观具体，图象法形象生动。一个函数对应一个图象，图象上任意一点的横坐标都在定义域内，纵坐标都在值域内。 **三、求函数的定义域** 求定义域的常见依据：分式的分母不为 0；偶次根式的被开方数大于或等于 0；零次幂的底数不为 0；对数的真数大于 0；实际问题还要符合实际背景。例如函数 $f(x)=\frac{\sqrt{x+1}}{x-2}$ 的定义域需满足 $x+1\ge 0$ 且 $x-2\neq 0$，即 $[-1,2)\cup(2,+\infty)$。 **四、求函数的值域** 常见方法：观察法、配方法、换元法、分离常数法、图象法。如 $f(x)=x^2-2x+3$ 配方得 $f(x)=(x-1)^2+2\ge 2$，值域为 [2,+∞)。求值域必须先明确定义域，定义域不同值域可能不同。 **五、函数的单调性** 设函数 f(x) 的定义域为 I，区间 $D\subseteq I$。若对任意 $x_1,x_2\in D$，当 $x_1<x_2$ 时都有 $f(x_1)<f(x_2)$，则称 f(x) 在区间 D 上单调递增；若当 $x_1<x_2$ 时都有 $f(x_1)>f(x_2)$，则称 f(x) 在区间 D 上单调递减。 单调性是函数的局部性质，一个函数可以既有递增区间又有递减区间。证明单调性必须用定义法（取值、作差、变形、定号），不能仅凭图象观察。 **六、函数的奇偶性** 设函数 f(x) 的定义域关于原点对称。若对定义域内任意 x 都有 $f(-x)=f(x)$，则 f(x) 是偶函数，图象关于 y 轴对称；若对定义域内任意 x 都有 $f(-x)=-f(x)$，则 f(x) 是奇函数，图象关于原点对称。若定义域不关于原点对称，则函数既不是奇函数也不是偶函数。若定义域关于原点对称，则可考虑 f(x)+f(-x) 是否恒为 0 来判断奇偶性。 **表格一：单调性与奇偶性对比** | 性质 | 符号语言 | 图象特征 | 判断要点 | |------|----------|----------|----------| | 单调递增 | $x_1<x_2$ 时 $f(x_1)<f(x_2)$ | 图象从左到右上升 | 作差 $f(x_1)-f(x_2)$，判符号 | | 单调递减 | $x_1<x_2$ 时 $f(x_1)>f(x_2)$ | 图象从左到右下降 | 作差、变形、定号 | | 偶函数 | $f(-x)=f(x)$ | 关于 y 轴对称 | 先看定义域是否对称，再比 $f(-x)$ 与 $f(x)$ | | 奇函数 | $f(-x)=-f(x)$ | 关于原点对称 | 先看定义域是否对称，再比 $f(-x)$ 与 $-f(x)$ | **表格二：常见函数的单调区间** | 函数 | 单调递增区间 | 单调递减区间 | |------|--------------|--------------| | $y=kx+b$（k>0） | R | 无 | | $y=kx+b$（k<0） | 无 | R | | $y=\frac{k}{x}$（k>0） | $(-\infty,0)$ 和 $(0,+\infty)$ | 无 | | $y=ax^2+bx+c$（a>0） | $[-\frac{b}{2a},+\infty)$ | $(-\infty,-\frac{b}{2a}]$ | **七、易错提醒** 1. 求定义域漏条件：分式与根式同时出现时只考虑根式、忘记分母不为 0。 2. 判断同一函数只看解析式，不看定义域。 3. 单调递减区间误用"∪"连接，如把 $y=\frac{1}{x}$ 的递减区间写作 $(-\infty,0)\cup(0,+\infty)$，应写作 $(-\infty,0)$ 和 $(0,+\infty)$。 4. 判断奇偶性不先检验定义域是否关于原点对称，直接化简解析式下结论。 5. 求值域时不考虑定义域，把解析式中的 x 一律当作全体实数。

🔍 课堂讲义 · 重点难点解析

**重点一：函数的三要素与同一函数的判断** 例题：判断下列各组函数是否表示同一函数。（1）$f(x)=x$，$g(x)=(\sqrt{x})^2$；（2）$f(x)=|x|$，$g(t)=\sqrt{t^2}$。 分析：判断同一函数看两点——定义域是否相同、对应关系是否相同，与自变量用什么字母无关。 解答：（1）f(x)=x 的定义域为 R，$g(x)=(\sqrt{x})^2$ 的定义域为 [0,+∞)，定义域不同，不是同一函数。（2）$g(t)=\sqrt{t^2}=|t|$，定义域为 R，对应关系与 f(x)=|x| 相同，是同一函数。 小结：判断同一函数只比较定义域与对应关系两点。利用 $\sqrt{x^2}=|x|$ 化简时要注意符号。 **重点二：求函数的定义域** 例题：求函数 $f(x)=\frac{\sqrt{x^2-x-6}}{x-2}$ 的定义域。 分析：偶次根式与分式同时出现，必须同时满足"被开方数大于等于 0"和"分母不为 0"两个条件。 解答：需 $x^2-x-6\ge 0$ 且 $x-2\neq 0$。由 $x^2-x-6=(x-3)(x+2)\ge 0$ 得 $x\le -2$ 或 $x\ge 3$；又 $x\neq 2$。所以定义域为 $(-\infty,-2]\cup[3,+\infty)$。 小结：求定义域的本质是解不等式（组），条件一个都不能少，结果写成区间或集合形式。 **难点一：用定义证明函数的单调性** 例题：证明函数 $f(x)=x+\frac{1}{x}$ 在区间 (0,1] 上单调递减。 分析：任取 $0<x_1<x_2\le 1$，作差 $f(x_1)-f(x_2)$，通过通分、因式分解变形，再判断符号。 解答：任取 $0<x_1<x_2\le 1$，则 $f(x_1)-f(x_2)=(x_1-x_2)+(\frac{1}{x_1}-\frac{1}{x_2})=(x_1-x_2)(1-\frac{1}{x_1x_2})$。因为 $0<x_1<x_2\le 1$，所以 $x_1-x_2<0$，且 $0<x_1x_2<1$，$\frac{1}{x_1x_2}>1$，故 $1-\frac{1}{x_1x_2}<0$。于是 $f(x_1)-f(x_2)>0$，即 $f(x_1)>f(x_2)$，所以 f(x) 在 (0,1] 上单调递减。 小结：定义法证明单调性四步：取值、作差、变形、定号。变形的目标是分解出"$x_1-x_2$"，使符号判定变得容易。 **难点二：函数奇偶性的判断** 例题：判断函数 $f(x)=\frac{x^2+x}{x+1}$ 的奇偶性。 分析：先看定义域。分母不能为 0，定义域为 {x|x≠-1}，不关于原点对称，直接下结论。 解答：函数定义域为 $(-\infty,-1)\cup(-1,+\infty)$，不关于原点对称，所以 f(x) 既不是奇函数也不是偶函数。 小结：判断奇偶性第一步永远是检验定义域。定义域不对称，直接判定"非奇非偶"，无需再化简解析式。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（求定义域与函数值）** 题目：已知函数 $f(x)=\frac{\sqrt{x+3}}{x^2-4}$。（1）求 f(x) 的定义域；（2）求 f(1) 的值。 分析：同时含偶次根式与分式，须满足被开方数非负、分母不为 0 两个条件。 解答：（1）需 $x+3\ge 0$ 且 $x^2-4\neq 0$，即 $x\ge -3$ 且 $x\neq \pm 2$，所以定义域为 $[-3,-2)\cup(-2,2)\cup(2,+\infty)$。（2）$f(1)=\frac{\sqrt{1+3}}{1-4}=\frac{2}{-3}=-\frac{2}{3}$。 方法小结：求定义域要"逐一列出条件、再取交集"。求函数值直接代入，注意分母是否为 0。 **例题 2（利用单调性求闭区间上的最值）** 题目：已知函数 $f(x)=x^2-4x+3$，$x\in[0,3]$，求 f(x) 的最大值与最小值。 分析：二次函数开口向上，先配方求对称轴，看对称轴是否落在给定区间内，再结合单调性求最值。 解答：$f(x)=(x-2)^2-1$，对称轴 x=2 在区间 [0,3] 内。f(x) 在 [0,2] 上单调递减，在 [2,3] 上单调递增，所以最小值 $f(2)=-1$。最大值在端点处取得：$f(0)=3$，$f(3)=0$，故最大值为 3。 方法小结：二次函数闭区间最值问题：配方找对称轴，判断对称轴与区间的位置关系，再比较端点与对称轴处的函数值。区间含参数时需分类讨论。 **例题 3（奇偶性与单调性的综合应用）** 题目：已知 f(x) 是定义在 R 上的偶函数，且在 [0,+∞) 上单调递增。若 $f(a)<f(2)$，求 a 的取值范围。 分析：偶函数满足 $f(x)=f(|x|)$，把比较 $f(a)$ 与 $f(2)$ 转化为比较 $|a|$ 与 2。 解答：f(x) 为偶函数，$f(a)=f(|a|)$。又 f(x) 在 [0,+∞) 上单调递增，所以 $f(|a|)<f(2)$ 等价于 $|a|<2$，解得 $-2<a<2$。 方法小结：偶函数图象关于 y 轴对称，在对称区间上单调性相反。利用"$f(a)=f(|a|)$"把问题转化到定义域的非负部分，是解偶函数不等式的重要技巧。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 函数的概念与定义域

  1. 1. 求函数 $f(x)=\sqrt{x-1}$ 的定义域。
    答：需 $x-1\ge 0$，得 $x\ge 1$，定义域为 [1,+∞)。
  2. 2. 求函数 $f(x)=\frac{1}{x-3}$ 的定义域。
    答：分母不能为 0，$x\neq 3$，定义域为 $(-\infty,3)\cup(3,+\infty)$。
  3. 3. 已知 $f(x)=x^2-1$，求 f(2) 与 f(a)。
    答：$f(2)=2^2-1=3$；$f(a)=a^2-1$。
  4. 4. 判断 $f(x)=x$ 与 $g(x)=\sqrt[3]{x^3}$ 是否为同一函数。
    答：$g(x)=\sqrt[3]{x^3}=x$，定义域都是 R，对应关系相同，所以是同一函数。

中等 · 定义域、值域与单调性判断

  1. 1. 求函数 $f(x)=\frac{\sqrt{2-x}}{x+1}$ 的定义域。
    答：需 $2-x\ge 0$ 且 $x+1\neq 0$，即 $x\le 2$ 且 $x\neq -1$，定义域为 $(-\infty,-1)\cup(-1,2]$。
  2. 2. 求函数 $f(x)=x^2-2x+3$，$x\in[0,2]$ 的值域。
    答：$f(x)=(x-1)^2+2$，对称轴 x=1 在区间内，最小值 $f(1)=2$，最大值 $f(0)=f(2)=3$，值域为 [2,3]。
  3. 3. 判断函数 $f(x)=x^2$ 在区间 $(-\infty,0)$ 上的单调性。
    答：任取 $x_1<x_2<0$，则 $f(x_1)-f(x_2)=x_1^2-x_2^2=(x_1-x_2)(x_1+x_2)$。因 $x_1-x_2<0$、$x_1+x_2<0$，故差为正，$f(x_1)>f(x_2)$，所以 f(x) 在 $(-\infty,0)$ 上单调递减。
  4. 4. 用定义证明函数 $f(x)=2x+1$ 在 R 上单调递增。
    答：任取 $x_1<x_2$，$f(x_1)-f(x_2)=2(x_1-x_2)<0$，即 $f(x_1)<f(x_2)$，所以 f(x) 在 R 上单调递增。

难 · 单调性证明与奇偶性应用

  1. 1. 证明函数 $f(x)=x+\frac{1}{x}$ 在区间 (1,+∞) 上单调递增。
    答：任取 $1<x_1<x_2$，$f(x_1)-f(x_2)=(x_1-x_2)(1-\frac{1}{x_1x_2})$。因 $x_1-x_2<0$，且 $x_1x_2>1$ 得 $1-\frac{1}{x_1x_2}>0$，故差为负，$f(x_1)<f(x_2)$，所以 f(x) 在 (1,+∞) 上单调递增。
  2. 2. 判断函数 $f(x)=x^3$ 的奇偶性。
    答：定义域为 R，关于原点对称。$f(-x)=(-x)^3=-x^3=-f(x)$，所以 $f(x)=x^3$ 是奇函数。
  3. 3. 已知 f(x) 是奇函数，当 x>0 时 $f(x)=x^2-2x$，求 x<0 时 f(x) 的解析式。
    答：当 $x<0$ 时 $-x>0$，$f(-x)=(-x)^2-2(-x)=x^2+2x$。由奇函数 $f(x)=-f(-x)$，得 $f(x)=-x^2-2x$。
  4. 4. 已知偶函数 f(x) 在 [0,+∞) 上单调递减，比较 f(1)、f(-2)、f(3) 的大小。
    答：$f(-2)=f(2)$。因 f(x) 在 [0,+∞) 上单调递减且 $1<2<3$，所以 $f(1)>f(2)>f(3)$，即 $f(1)>f(-2)>f(3)$。

综合 · 函数的综合应用

  1. 1. 已知 $f(x)=x^2-2ax+3$，$x\in[0,2]$。（1）当 a=1 时求最小值；（2）若 f(x) 在 [0,2] 上的最小值为 3，求 a 的取值范围。
    答：（1）a=1 时 $f(x)=(x-1)^2+2$，最小值 $f(1)=2$。（2）对称轴 x=a。若 a≤0，f(x) 在 [0,2] 上单调递增，最小值 $f(0)=3$，符合；若 0<a<2，最小值 $f(a)=3-a^2=3$，得 a=0，与范围矛盾，舍去；若 a≥2，最小值 $f(2)=7-4a=3$，得 a=1，与范围矛盾，舍去。综上 a 的取值范围为 $(-\infty,0]$。
  2. 2. 定义在 [-2,2] 上的偶函数 f(x)，当 0≤x≤2 时单调递减，且 $f(1-m)<f(m)$，求 m 的取值范围。
    答：由偶函数与单调性，$f(1-m)<f(m)$ 等价于 $|1-m|>|m|$，平方得 $1-2m>0$，$m<1/2$。又 $-2\le 1-m\le 2$ 且 $-2\le m\le 2$，即 $-1\le m\le 3$ 且 $-2\le m\le 2$。取交集得 $-1\le m<1/2$。
  3. 3. 已知函数 f(x) 对任意 x、y∈R 都有 $f(x+y)=f(x)+f(y)$，且当 x>0 时 $f(x)<0$，$f(1)=-2$。（1）判断 f(x) 的奇偶性；（2）判断 f(x) 在 R 上的单调性。
    答：（1）令 x=y=0，得 $f(0)=2f(0)$，故 $f(0)=0$；令 y=-x，得 $f(x)+f(-x)=f(0)=0$，即 $f(-x)=-f(x)$，所以 f(x) 是奇函数。（2）任取 $x_1<x_2$，则 $x_2-x_1>0$，$f(x_2)-f(x_1)=f(x_2-x_1)<0$，所以 $f(x_1)>f(x_2)$，f(x) 在 R 上单调递减。

💬 课后反馈

**常见错误** 1. 求定义域只考虑一个条件，分式与根式同时出现时漏掉"分母不为 0"。 2. 判断同一函数只看解析式，忽视定义域；或用字母不同就误判为不同函数。 3. 单调性区间用"∪"连接，如把 $y=\frac{1}{x}$ 的递减区间误写成 $(-\infty,0)\cup(0,+\infty)$。 4. 判断奇偶性不先看定义域是否关于原点对称，直接化简解析式下结论。 5. 用定义证明单调性时不会变形，作差后无法确定符号；或符号判断与大小关系倒置。 **教学改进建议** 1. 借助函数图象软件动态演示单调性与奇偶性，让学生直观感受"上升、下降、对称"的图象特征。 2. 树立"定义域优先"意识：先求定义域，再研究其他性质，课堂反复示范并让学生养成习惯。 3. 设计"同一函数辨析"题组（定义域不同、对应关系不同、仅字母不同），通过对比强化三要素。 4. 把单调性证明拆分为"取值—作差—变形—定号"四步分步训练，先练变形技巧，再练完整书写。 **分层辅导** 学困生：重点掌握定义域的求法与单调性、奇偶性的基本判断，提供"先写条件、再求交集"的步骤模板；学优生：研究含参数的最值、抽象函数的单调性与奇偶性证明，提升抽象思维与分类讨论能力。 **给家长的建议** 1. 请孩子画一画一次、二次、反比例函数的图象，说一说各自的增减区间与对称性。 2. 鼓励孩子用"取值、作差、变形、定号"四步给家长讲一遍单调性证明，讲得清才是真理解。 3. 提醒孩子整理错题本，重点标注"定义域、奇偶性检验、单调区间不并集"等易错点，定期回顾。
