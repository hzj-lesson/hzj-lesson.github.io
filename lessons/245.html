初中九年级物理串、并联电路中电流的规律

📝 备课方案

**教材分析** 本节通过探究实验揭示串、并联电路中的电流规律：串联电路电流处处相等，并联电路干路电流等于各支路电流之和。本节是"电流和电路"章的规律总结，是学生第一次用电流表开展的定量探究，既巩固电流表使用，又为电压规律、欧姆定律学习提供方法示范。 **教学目标** 1. 通过探究实验得出并理解串联电路电流处处相等的规律。 2. 通过探究实验得出并联电路中干路电流等于各支路电流之和的规律。 3. 会用上述规律解决简单的电路计算与判断问题。 4. 经历完整的科学探究过程，体会换用不同规格灯泡多次实验、归纳普遍规律的方法。 **教学重点** 探究实验方案的制定与结论得出；规律的运用。 **教学难点** 设计合理的实验记录表并分析数据得出结论；理解"多次实验避免偶然性"的必要性。 **课时** 1 课时 **教学过程** 设问引入（两灯电流谁大谁小）→提出问题作出猜想→设计实验→分组探究串联规律→分组探究并联规律→分析论证得出结论→练习巩固。

📖 课堂讲义 · 核心知识点

**一、探究串联电路中电流的规律** 提出问题：串联电路中，通过各处的电流有什么关系？ 猜想与假设：串联电流只有一条路径，电流"排队"流过各灯，各处电流可能相等。 设计实验：把电流表分别接入串联电路的 $a$（L1 前）、$b$（L1 与 L2 之间）、$c$（L2 后）三点，测出三处电流 $I_a$、$I_b$、$I_c$；换用不同规格的灯泡多次测量。 结论：串联电路中各处电流相等。$I_a=I_b=I_c$，写成 $I=I_1=I_2$。 注意：必须换用不同规格灯泡做多次实验，避免由偶然数据得出片面结论。 **二、探究并联电路中电流的规律** 提出问题：并联电路中，干路电流与各支路电流有什么关系？ 猜想：干路电流可能等于各支路电流之和（相当于"水渠分两渠"）。 设计实验：用电流表分别测干路电流 $I$、支路电流 $I_1$、$I_2$；换用不同规格灯泡重复实验，记录数据。 结论：并联电路中，干路电流等于各支路电流之和。$I=I_1+I_2$。 注意：测量某支路电流时电流表要串联在该支路；测干路电流时要接在分支点之前（干路上）。 **三、理解与运用要点** 1. 串联"处处相等"：电流表接在串联电路任何位置读数都相同，故串联电路中电流表位置不影响测量结果。 2. 并联各支路电流不一定相等：支路电流大小由该支路用电器的情况决定，只有两盏灯规格相同时两支路电流才相等。支路越"通畅"（灯泡越亮、电阻越小）电流越大。 3. 并联电路某支路断开：该支路无电流，其余支路照常工作，干路电流变小（等于其余支路电流之和）。 4. 规律可推广到多灯：串联各处仍相等；并联干路电流等于所有支路电流之和。

🔍 课堂讲义 · 重点难点解析

**难点一：为什么串联电流处处相等** 串联只有一条电流路径，导体中的电流是电荷的定向移动。单位时间内通过导线任意截面的电荷量必须相同（电荷不会在某处堆积也不会凭空产生），否则该处就会"越积越多"或"越来越少"，故串联电路中通过各用电器、各点的电流必然相等。 **难点二：并联干路电流与支路电流的关系** 并联电路中电流在分支点"分流"：干路总电荷分别流向各条支路，单位时间通过干路某截面的电荷量等于通过各支路截面的电荷量之和，故干路电流等于各支路电流之和 $I=I_1+I_2$。可类比：一条大河分成两条支流，总水量等于两条支流水量之和。 **难点三：探究实验中的"多次实验"** 只用一组规格相同的灯泡做一次实验就下结论，可能是巧合（如两只灯泡相同恰好电流相等），不能反映普遍规律。要换用不同规格（不同电阻、不同亮度）的灯泡再做几次，得到的数据仍符合规律时，才能得出普遍结论——这是科学探究的基本方法，也是本课实验设计的考查重点。 **常见失误** 1. 把电流表并联在某支路上测该支路电流——应串联在该支路。 2. 测干路电流时把电流表接在分支点与汇合点之间——那里既有支路又测不到真实干路电流。 3. 误认为并联各支路电流一定相等。 4. 只做一次实验就得出结论。

✏️ 课堂讲义 · 典型例题精讲

**例1（串联规律应用）** 两灯 L1、L2 串联，用电流表测得通过 L1 的电流为 $0.3\,A$，通过 L2 的电流是多少？若把电流表改接在 L1 前，读数变吗？ 解析：串联电路电流处处相等，$I_2=I_1=0.3\,A$；电流表在串联电路中任何位置读数都相同，改接后仍为 $0.3\,A$。 关键：串联 $I=I_1=I_2$，读数与位置无关。 **例2（并联规律应用）** 两灯 L1、L2 并联，干路电流 $I=0.8\,A$，通过 L1 的电流 $I_1=0.3\,A$，通过 L2 的电流是多少？若断开 L2 支路，干路电流如何变化？ 解析：并联干路电流等于各支路电流之和，$I_2=I-I_1=0.8-0.3=0.5\,A$。断开 L2 支路后，$I_2$ 变为 0，干路电流 $I'=I_1=0.3\,A$，比原来小（L1 仍正常发光）。 关键：$I=I_1+I_2$，支路通断只改变相应支路电流与干路电流。 **例3（实验数据分析）** 某小组测得串联电路 $a$、$b$、$c$ 三点电流均为 $0.22\,A$、$0.22\,A$、$0.22\,A$。他们据此得出"串联电流处处相等"，老师说结论成立但做法还需完善。为什么？ 解析：实验结论正确，但只用一组相同灯泡做了测量，可能只是偶然现象。应换用不同规格的灯泡（不同电阻、不同亮度）改变电源电压再做几次，多次测量结果都满足各处电流相等，才能得出普遍规律，避免偶然性。 关键：多次实验、更换器材是得出普遍规律的必要环节。 **例4（综合电路分析）** 如图：L1、L2 并联，电流表 A1 测 L1 支路电流为 $0.2\,A$，A2 测干路电流为 $0.6\,A$。求通过 L2 的电流，并判断若换用规格不同的灯泡，两灯电流是否一定相等。 解析：$I_2=I_干-I_1=0.6-0.2=0.4\,A$。L1、L2 规格不同，其支路电流不一定相等——支路电流由各支路用电器决定，只有两灯完全相同才相等。故换不同规格灯泡后两灯电流一般不相等。 关键：并联"干路＝支路之和"，支路电流不一定相等。 **例5（故障与电流变化）** 三盏灯并联，总干路电流为 $1.2\,A$。若其中一盏灯烧坏断路，干路电流变为 $0.8\,A$，求该灯原支路电流及另两灯的工作情况。 解析：烧坏前干路电流等于三条支路电流之和；烧坏后该支路电流为 0，干路电流等于另两条支路电流之和，故该灯原支路电流 $I=1.2-0.8=0.4\,A$。另两灯所在支路不受影响，照常工作、电流不变。 关键：并联各支路互不影响，某支路断开只使干路电流减去该支路电流。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 规律识记

  1. 1. 写出串联电路中电流的规律，并用公式表示。
    答：串联电路中电流处处相等：$I=I_1=I_2$。即通过串联电路中每个用电器、每段导线的电流都相同。
  2. 2. 写出并联电路中电流的规律，并用公式表示。
    答：并联电路中，干路电流等于各支路电流之和：$I=I_1+I_2$（多支路时为各支路电流相加）。

中等 · 简单计算

  1. 1. 两灯 L1、L2 串联，通过 L1 的电流为 $0.25\,A$，则通过 L2 的电流和通过电源的电流各是多少？
    答：串联电路电流处处相等，故通过 L2 的电流为 $0.25\,A$，通过电源、导线的电流也均为 $0.25\,A$。
  2. 2. 两灯 L1、L2 并联，通过 L1 的电流为 $0.3\,A$，干路电流为 $0.9\,A$，求通过 L2 的电流。
    答：由并联电路干路电流等于各支路电流之和：$I_2=I-I_1=0.9-0.3=0.6\,A$。

难 · 电路分析

  1. 1. L1、L2、L3 三灯并联，干路电流 $1.5\,A$，$I_1=0.4\,A$，$I_2=0.6\,A$，求 $I_3$。若再并联一盏 L4，干路电流会怎样变化？
    答：$I_3=I-I_1-I_2=1.5-0.4-0.6=0.5\,A$。再并联 L4 相当于多了一条支路，干路电流等于各支路电流之和，会增大（增大到原电流加 L4 支路电流）。
  2. 2. 两个相同的小灯泡串联接入电路，与两个相同的小灯泡并联接入同一电源，两种情况下通过每个灯泡的电流相同吗？为什么？
    答：不相同。串联时电流处处相等，$I_串=\frac{U}{2R}$（每个灯分得一半电压）；并联时每个灯两端电压均为电源电压，通过每个灯的电流 $I_并=\frac{U}{R}$，是串联时的 2 倍。说明灯的工作状态由它实际两端电压决定，电路连接方式不同，灯的电流可能不同。（此处定量关系到欧姆定律后进一步理解。）

综合 · 实验探究

  1. 1. 设计探究"并联电路干路电流与支路电流关系"的实验，写出步骤、实验记录表要点与结论。
    答：步骤：①按电路图连接并联电路（L1、L2 两灯并联）；②断开开关，把电流表串联接入干路，闭合开关读出干路电流 $I$ 并记录；③把电流表分别串入 L1 支路、L2 支路，测出 $I_1$、$I_2$ 并记录；④换用不同规格的灯泡重复以上测量，再做 2～3 次。记录表要点：实验次数、$I$（A）、$I_1$（A）、$I_2$（A）、$I_1+I_2$（A）。结论：并联电路中干路电流等于各支路电流之和，$I=I_1+I_2$。
  2. 2. 在并联电路实验中，某同学把电流表并联在 L1 支路两端（而非串入支路），闭合开关后会出现什么现象？为什么？
    答：把电流表并联在 L1 支路两端，因电流表电阻极小相当于导线，会把 L1 短路：电流几乎不经过 L1，L1 不亮；此时干路电流几乎全部流过电流表，电流表读数很大（约等于原来干路加 L1 支路的电流之和甚至更大），可能损坏电流表和电源。正确做法：断开被测支路，把电流表串联接入 L1 支路后再闭合开关读数。

💬 课后反馈

本节是电学第一次定量探究，重点在"规律"与"方法"双线并进。学生常出的问题：测支路电流时把电流表并联而短路；测干路电流错接在支路区；凭一组数据就下结论，忽视更换灯泡多次实验的科学性；误认为并联各支路电流必相等。建议探究课上放手让学生试错、纠错，用"河水分流"类比帮助理解 $I=I_1+I_2$，并把"串联处处相等、并联干路等于支路之和"作为后续电学计算的基本依据反复运用。
