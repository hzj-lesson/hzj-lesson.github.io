初中九年级化学《生活中常见的盐》教案

初中九年级化学生活中常见的盐

📝 备课方案

**教学目标** 1. 认识氯化钠、碳酸钠、碳酸氢钠、碳酸钙的俗名、主要用途。 2. 掌握盐的化学性质（与金属、酸、碱、盐的反应）。 3. 理解复分解反应的定义及发生条件，会判断复分解反应能否发生。 4. 掌握粗盐提纯的操作（溶解、过滤、蒸发），理解各步骤的作用。 **教学重点**：常见盐的性质与用途；复分解反应及发生条件。 **教学难点**：复分解反应发生条件的判断；盐的化学性质应用。 **教学方法**：实验演示、分类归纳、反应规律总结。 **课时安排**：2 课时

📖 课堂讲义 · 核心知识点

**一、生活中常见的盐（注意：化学中的"盐"≠食盐）** - 氯化钠（$NaCl$）：俗名**食盐**，无色晶体、易溶于水、有咸味。用途：调味、腌制食品、配制生理盐水（0.9%）、融雪、农业选种。粗盐中因含 MgCl2、CaCl2 等杂质而潮解。 - 碳酸钠（$Na_2CO_3$）：俗名**纯碱、苏打**，白色粉末、易溶于水、水溶液显**碱性**（所以俗称纯碱，但属于盐）。用途：玻璃、造纸、纺织、洗涤剂（去油污）。 - 碳酸氢钠（$NaHCO_3$）：俗名**小苏打**，白色细小晶体、能溶于水。用途：焙制糕点的发酵粉、治疗胃酸过多的药物（与盐酸反应：$NaHCO_3 + HCl \rightarrow NaCl + H_2O + CO_2 \uparrow$）。 - 碳酸钙（$CaCO_3$）：大理石、石灰石的主要成分，难溶于水、白色固体。用途：建筑材料、补钙剂。高温分解：$CaCO_3 \xrightarrow{高温} CaO + CO_2 \uparrow$。 **二、盐的化学性质（盐的通性）** - ①盐 + 金属 → 新盐 + 新金属（置换反应）。条件：金属的活动性要**排在盐中金属前面**（K、Ca、Na 除外），盐必须可溶。如 $Fe + CuSO_4 \rightarrow FeSO_4 + Cu$（铁钉表面析出红色铜，溶液由蓝色变浅绿色）。 - ②盐 + 酸 → 新盐 + 新酸。如 $BaCl_2 + H_2SO_4 \rightarrow BaSO_4 \downarrow + 2HCl$（生成不溶于稀硝酸的白色沉淀）。 - ③盐 + 碱 → 新盐 + 新碱。条件：反应物均可溶，生成物有**沉淀**、气体或水。如 $CuSO_4 + 2NaOH \rightarrow Cu(OH)_2 \downarrow + Na_2SO_4$（蓝色沉淀）。 - ④盐 + 盐 → 新盐 + 新盐。条件：反应物均可溶，生成物有**沉淀**。如 $NaCl + AgNO_3 \rightarrow AgCl \downarrow + NaNO_3$（白色沉淀不溶于稀硝酸）。 **三、复分解反应** - 定义：由**两种化合物**互相交换成分，生成**另外两种化合物**的反应，表达式：AB + CD → AD + CB。 - 发生条件（生成物方向）：生成物中有**沉淀**（$\downarrow$）、**气体**（$\uparrow$）或**水**生成，三者具备其一，复分解反应才能发生。 - 常见沉淀记忆：白色沉淀——BaSO4、AgCl（不溶于稀硝酸）、CaCO3、BaCO3、Mg(OH)2；蓝色沉淀——Cu(OH)2；红褐色沉淀——Fe(OH)3。 - 酸碱中和反应是复分解反应的特例（酸 + 碱 → 盐 + 水）。 **四、粗盐提纯** - 步骤：**溶解 → 过滤 → 蒸发**（再转移、洗涤）。 - 溶解：用玻璃棒**搅拌**，加速溶解。 - 过滤：除去不溶性杂质（泥沙），要点"一贴二低三靠"，玻璃棒**引流**。 - 蒸发：加热蒸发皿，用玻璃棒**不断搅拌**（防止液体局部过热飞溅），当出现较多固体时停止加热，利用余热蒸干。 - 粗盐中可溶性杂质（MgCl2、CaCl2、Na2SO4）需通过化学方法进一步除去。

🔍 课堂讲义 · 重点难点解析

**重点一：复分解反应发生条件的判断** 判断复分解反应能否发生，分两步：第一步看反应物条件——酸 + 碱（或金属氧化物）不要求反应物可溶，其余（盐 + 盐、盐 + 碱）要求反应物都可溶；第二步看生成物条件——生成物中必须有沉淀、气体或水三者之一。学生常犯的错误：只盯生成物忘了反应物要可溶；对常见沉淀不熟悉，误以为 CuSO4 + NaCl 能反应（生成物 Na2SO4、CuCl2 都可溶，无沉淀生成，反应不发生）。解题要"先查反应物溶解性，再查生成物有无沉淀/气体/水"。 **重点二：盐的化学性质——金属与盐溶液的置换** 铁与硫酸铜溶液反应是重点：铁钉表面覆盖一层红色物质（铜），溶液由蓝色逐渐变为浅绿色（Fe2+ 溶液呈浅绿色）。条件：活动性强的金属置换活动性弱的金属（K、Ca、Na 太活泼不能直接置换），且盐要可溶。判断"某金属能否与某盐溶液反应"先比活动性：Cu 不能置换 FeSO4 中的铁，因为 Cu 排在 Fe 后面。反应产物中金属的活动性顺序要熟记：K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au。 **难点：碳酸盐的检验与推断** 检验碳酸根（$CO_3^{2-}$）的通用方法：取样，滴加稀盐酸，若产生能使澄清石灰水变浑浊的气体，则含碳酸根。$Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow$。这是鉴别碳酸盐的重要方法。做题时注意区分碳酸钠（纯碱）显碱性但它是盐，不是碱；检验盐溶液中的阴离子常用"沉淀法"（加 BaCl2 检验 SO4 2-、加 AgNO3 检验 Cl-，沉淀都不溶于稀硝酸）。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：写出下列物质的俗名和主要用途：NaCl、Na2CO3、NaHCO3、CaCO3。 解析：NaCl——食盐，调味、腌制品、配制生理盐水、融雪；Na2CO3——纯碱（苏打），玻璃、造纸、纺织、洗涤剂；NaHCO3——小苏打，发酵粉（焙制糕点）、治疗胃酸过多；CaCO3——大理石/石灰石的主要成分，建筑材料、补钙剂。注意：Na2CO3 虽俗名"纯碱"，但它属于盐，水溶液显碱性。 关键：俗名与化学式一一对应，别把苏打（Na2CO3）与小苏打（NaHCO3）搞混。 **例 2**：判断下列反应能否发生，能发生的写出化学方程式：①Fe + CuSO4；②Cu + FeSO4；③Na2CO3 + HCl；④NaCl + KNO3。 解析：①能发生，$Fe + CuSO_4 \rightarrow FeSO_4 + Cu$（Fe 比 Cu 活泼）。②不能发生，Cu 排在 Fe 后面，活动性弱不能置换 Fe。③能发生，$Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow$（生成气体）。④不能发生，四种物质都可溶，生成物 NaCl、KNO3 都可溶，无沉淀、气体或水生成，不满足复分解反应条件。 关键：置换看金属活动性顺序；复分解反应判断按"反应物可溶？生成物有无沉淀/气体/水？"两步走。 **例 3**：如何鉴别一瓶无色溶液是碳酸钠溶液？写出操作、现象和结论。 解析：取样，加入适量稀盐酸，若有气泡产生，将生成的气体通入澄清石灰水，石灰水变浑浊，说明该溶液是碳酸钠溶液（含 $CO_3^{2-}$）。方程式：$Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow$，$CO_2 + Ca(OH)_2 \rightarrow CaCO_3 \downarrow + H_2O$。 关键：检验碳酸根的通法——加酸产生能使石灰水变浑浊的气体；现象描述要完整（气泡、石灰水变浑浊）。 **例 4**：向硫酸铜溶液中滴加氢氧化钠溶液，观察到的现象是什么？写出化学方程式并说明该反应属于什么基本反应类型。 解析：现象：产生蓝色沉淀（氢氧化铜），溶液蓝色变浅。方程式：$CuSO_4 + 2NaOH \rightarrow Cu(OH)_2 \downarrow + Na_2SO_4$。该反应是两种化合物互相交换成分生成另外两种化合物，属于复分解反应；也属于碱与盐的反应，生成物中有沉淀 Cu(OH)2，满足复分解反应发生条件。 关键：记住常见沉淀颜色——Cu(OH)2 蓝色沉淀、Fe(OH)3 红褐色沉淀、AgCl 和 BaSO4 白色且不溶于稀硝酸。 **例 5**：粗盐提纯实验中，需要哪些仪器？各步骤中玻璃棒的作用分别是什么？ 解析：仪器：烧杯、玻璃棒、漏斗、铁架台、蒸发皿、酒精灯、量筒等。溶解时玻璃 棒用于**搅拌**（加速溶解）；过滤时用于**引流**（使液体沿玻璃棒流下，防止液体溅出）；蒸发时用于**搅拌**（防止液体局部过热造成液滴飞溅）。过滤后蒸发时出现较多固体就停止加热，利用余热蒸干，防止固体飞溅。 关键：玻璃棒在不同步骤作用不同——溶解搅拌、过滤引流、蒸发防飞溅，是高频考点。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 常见盐的俗名与用途

  1. 1. 写出氯化钠、碳酸钠、碳酸氢钠、碳酸钙的化学式、俗名和主要用途。
    答：氯化钠（$NaCl$），俗名食盐，用途：调味、腌制食品、配制生理盐水、融雪剂。碳酸钠（$Na_2CO_3$），俗名纯碱、苏打，用途：玻璃、造纸、纺织、洗涤剂，水溶液显碱性。碳酸氢钠（$NaHCO_3$），俗名小苏打，用途：焙制糕点发酵粉、治疗胃酸过多。碳酸钙（$CaCO_3$），大理石、石灰石的主要成分，用途：建筑材料、补钙剂。
  2. 2. 为什么碳酸钠被称为"纯碱"？它属于碱还是盐？
    答：碳酸钠（$Na_2CO_3$）的俗名叫纯碱，是因为它的水溶液显碱性，在工业上常被用作碱类物质使用。但从化学分类看，碳酸钠由钠离子和碳酸根离子构成，属于盐（钠盐、碳酸盐），不是碱。碱是电离出的阴离子全部是氢氧根离子的化合物，而碳酸钠中没有氢氧根。
  3. 3. 小苏打可以治疗胃酸过多，写出相关反应的化学方程式，并说明原理。
    答：小苏打（$NaHCO_3$）与胃酸中的盐酸反应：$NaHCO_3 + HCl \rightarrow NaCl + H_2O + CO_2 \uparrow$。原理：碳酸氢钠能与盐酸反应，消耗胃液中过多的盐酸，生成中性的氯化钠、水和二氧化碳，从而缓解胃酸过多的症状。注意服用后会有打嗝现象（CO2 排出）。

中等 · 盐的化学性质

  1. 1. 把铁钉放入硫酸铜溶液中，观察到的现象是什么？写出化学方程式，并说明该反应的类型。
    答：现象：铁钉表面覆盖一层红色物质（铜），溶液由蓝色逐渐变为浅绿色。方程式：$Fe + CuSO_4 \rightarrow FeSO_4 + Cu$。该反应是一种单质（铁）与一种化合物（硫酸铜）反应生成另一种单质（铜）和另一种化合物（硫酸亚铁），属于置换反应；也是盐（CuSO4）与金属（Fe）的反应。
  2. 2. 向氯化钡溶液中滴加稀硫酸，有什么现象？写出化学方程式，并指出该反应属于哪类反应。
    答：现象：产生白色沉淀。方程式：$BaCl_2 + H_2SO_4 \rightarrow BaSO_4 \downarrow + 2HCl$。生成物中的硫酸钡是白色沉淀，且不溶于稀硝酸，可用于检验 $SO_4^{2-}$。该反应是盐与酸的反应，两种化合物互相交换成分生成另外两种化合物，属于复分解反应，生成物有沉淀 BaSO4，满足发生条件。
  3. 3. 用化学方程式表示碳酸钠与稀盐酸的反应，并说明如何检验生成的气体。
    答：$Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow$。将生成的气体通入澄清石灰水中，若石灰水变浑浊，证明生成的气体是二氧化碳：$CO_2 + Ca(OH)_2 \rightarrow CaCO_3 \downarrow + H_2O$。这一方法也是检验碳酸根离子的依据——加稀盐酸产生能使澄清石灰水变浑浊的气体，说明含 $CO_3^{2-}$。

难 · 复分解反应判断

  1. 1. 判断下列反应能否发生，能发生的写出化学方程式：①Cu(OH)2 + HCl；②Na2CO3 + KNO3；③NaCl + AgNO3；④BaCl2 + Na2SO4。
    答：①能发生（酸碱中和），$Cu(OH)_2 + 2HCl \rightarrow CuCl_2 + 2H_2O$，生成物中有水，符合条件，现象是蓝色沉淀溶解。②不能发生，反应物、生成物都可溶，无沉淀、气体或水生成。③能发生，$NaCl + AgNO_3 \rightarrow AgNO_3 + NaNO_3$ 不对，应为 $NaCl + AgNO_3 \rightarrow AgCl \downarrow + NaNO_3$，生成不溶于稀硝酸的白色沉淀 AgCl。④能发生，$BaCl_2 + Na_2SO_4 \rightarrow BaSO_4 \downarrow + 2NaCl$，生成白色沉淀 BaSO4。
  2. 2. 现有 NaCl、Na2CO3、Na2SO4 三种白色粉末，如何用化学方法鉴别？写出操作、现象和结论。
    答：①取样于三支试管中，各滴加稀盐酸：产生能使澄清石灰水变浑浊气体的是碳酸钠（$Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow$），无明显现象的是 NaCl 和 Na2SO4。②再取无明显现象的两种样品，各滴加氯化钡溶液：产生白色沉淀的是硫酸钠（$Na_2SO_4 + BaCl_2 \rightarrow BaSO_4 \downarrow + 2NaCl$），无明显现象的是氯化钠。也可用 AgNO3 溶液检验 Cl-（白色沉淀 AgCl 不溶于稀硝酸）来进一步确认。

综合 · 粗盐提纯与综合应用

  1. 1. 粗盐提纯的实验步骤是什么？每一步用到哪些仪器？玻璃棒分别起什么作用？
    答：步骤：溶解、过滤、蒸发。①溶解：烧杯、玻璃棒、量筒、药匙等，玻璃棒搅拌，加速粗盐溶解。②过滤：铁架台、漏斗、烧杯、玻璃棒，玻璃棒引流，防止液体溅出和冲破滤纸，按"一贴二低三靠"操作。③蒸发：蒸发皿、铁架台、酒精灯、玻璃棒，玻璃棒不断搅拌，防止液体局部过热造成液滴飞溅；出现较多固体时停止加热，利用余热蒸干。最后得到较纯净的食盐。
  2. 2. 粗盐提纯后得到的食盐是否纯净？若需进一步除去可溶性杂质（如 MgCl2、CaCl2、Na2SO4），可加入什么试剂？
    答：过滤只能除去不溶性杂质（泥沙），得到的食盐中仍含有可溶性杂质 MgCl2、CaCl2、Na2SO4，所以不是纯净的。进一步除杂：加过量 BaCl2 溶液除去 SO4 2-（生成 BaSO4 沉淀）；加过量 NaOH 溶液除去 Mg2+（生成 Mg(OH)2 沉淀）；加过量 Na2CO3 溶液除去 Ca2+ 和过量的 Ba2+（生成 CaCO3、BaCO3 沉淀）；过滤后再加适量稀盐酸除去过量的 OH- 和 CO3 2-，最后蒸发结晶。注意试剂加入顺序和过量试剂的处理。

💬 课后反馈

本课是"盐"的专题，核心是盐的通性和复分解反应。常见错误：苏打与小苏打混淆、把纯碱当碱、复分解反应判断只看生成物不看反应物溶解性、把碳酸钙当成"易溶于水"、Cu(OH)2 沉淀颜色记错。建议用"盐的四条通性"框架整理化学方程式，用"沉淀颜色记忆表"（白：AgCl、BaSO4、CaCO3；蓝：Cu(OH)2；红褐：Fe(OH)3）强化记忆。中考常考复分解反应判断与粗盐提纯操作，务必训练"先查溶解性、再看沉淀气体水"的两步判断法。
