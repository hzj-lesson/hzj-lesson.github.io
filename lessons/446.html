高中高二化学《盐类的水解》教案

高中高二化学盐类的水解

📝 备课方案

**教学目标** 1. 知道盐类水解的实质，能从微粒观（盐电离出的离子与水电离出的 H⁺ 或 OH⁻ 结合生成弱电解质）解释盐溶液的酸碱性。 2. 记住盐类水解的规律（有弱才水解、谁强显谁性等），会判断常见盐溶液的酸碱性，会正确书写常见盐的水解离子方程式。 3. 能运用电荷守恒、物料守恒比较盐溶液中各离子浓度的大小，建立「微粒种类—浓度排序—守恒关系」的分析模型。 4. 了解盐类水解在生产生活中的应用（泡沫灭火器、配制溶液、化肥使用、净水与除杂等），体会化学原理的实际价值。 **教学重点**：盐类水解的规律与水解方程式书写；盐溶液酸碱性的判断；盐溶液中离子浓度大小比较。 **教学难点**：水解平衡的建立与移动的理解；三个守恒关系（电荷守恒、物料守恒、质子守恒）的建立与综合运用。 **教学方法**：实验探究法（测盐溶液 pH）、微粒图示法、对比归纳法、讲练结合法。 **教学准备**：pH 计或精密 pH 试纸、NaCl 溶液、Na₂CO₃ 溶液、NH₄Cl 溶液、CH₃COONa 溶液、Al₂(SO₄)₃ 溶液、NaHCO₃ 溶液、玻璃棒、表面皿、课件。 **课时安排**：2 课时（第 1 课时：水解原理与规律、水解方程式；第 2 课时：离子浓度比较与水解应用）。

📖 课堂讲义 · 核心知识点

**一、盐溶液酸碱性的实验探究** 用 pH 试纸分别测定相同浓度的几种盐溶液： | 盐 | 类型 | 溶液酸碱性 | 原因 | |---|---|---|---| | NaCl、KNO₃ | 强酸强碱盐 | 中性（pH = 7） | 不水解 | | CH₃COONa、Na₂CO₃ | 强碱弱酸盐 | 碱性（pH > 7） | 弱酸根离子结合 H⁺ | | NH₄Cl、Al₂(SO₄)₃ | 强酸弱碱盐 | 酸性（pH < 7） | 弱碱阳离子结合 OH⁻ | | CH₃COONH₄ 等 | 弱酸弱碱盐 | 视酸碱相对强弱 | 阴、阳离子都水解 | **二、盐类水解的原理与实质** 盐溶于水后电离出的弱酸根离子或弱碱阳离子，与水电离出的 H⁺ 或 OH⁻ 结合生成弱电解质，破坏了水的电离平衡，使水的电离正向移动，导致 c(H⁺) 与 c(OH⁻) 不再相等，溶液显示酸性或碱性。 实质：生成弱电解质，促进了水的电离。 典型例子： - CH₃COONa：CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻（结合 H⁺，剩余 OH⁻，显碱性）； - NH₄Cl：NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺（结合 OH⁻，剩余 H⁺，显酸性）； - Na₂CO₃（分步，以第一步为主）：CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻；HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻。 **三、盐类水解的规律** 口诀：有弱才水解，无弱不水解；谁弱谁水解，越弱越水解；谁强显谁性，都弱比强弱。 - 强酸强碱盐不水解，溶液中性； - 强碱弱酸盐水解显碱性，对应酸越弱，水解程度越大，碱性越强； - 强酸弱碱盐水解显酸性，对应碱越弱，酸性越强； - 弱酸弱碱盐水解的酸碱性取决于两者电离常数（Ka 与 Kb）的相对大小。 **四、水解方程式书写要领** 1. 一般用「⇌」，不用「=」； 2. 生成物一般不标「↓」「↑」（生成物量少）； 3. 多价阴离子（如 CO₃²⁻、PO₄³⁻）分步水解，以第一步为主，通常只写第一步； 4. 阴离子水解写「结合 H₂O 生成 OH⁻」，阳离子水解写「结合 H₂O 生成 H⁺」。 **五、盐溶液中离子浓度大小比较** 以 Na₂CO₃ 溶液为例，微粒有：Na⁺、CO₃²⁻、HCO₃⁻、H₂CO₃、H⁺、OH⁻。 排序：c(Na⁺) > c(CO₃²⁻) > c(OH⁻) > c(HCO₃⁻) > c(H⁺)。 两个基本守恒： - 电荷守恒（阳离子所带正电荷总浓度 = 阴离子所带负电荷总浓度）：c(Na⁺) + c(H⁺) = 2c(CO₃²⁻) + c(HCO₃⁻) + c(OH⁻)； - 物料守恒（某元素的各种形式总浓度不变）：c(Na⁺) = 2 × [c(CO₃²⁻) + c(HCO₃⁻) + c(H₂CO₃)]。 分析步骤：①列出所有微粒；②按「不水解的微粒浓度最大」排定主体；③考虑水解产生的微量微粒；④用守恒式校验。 **六、水解平衡的移动** - 升温促进水解（水解吸热）：如热的纯碱溶液去油污能力更强； - 加水稀释促进水解：水解程度增大，但离子浓度减小； - 加入酸、碱或能反应的盐会移动水解平衡（双水解）。 **七、盐类水解的应用** 1. 泡沫灭火器：Al₂(SO₄)₃ 溶液与 NaHCO₃ 溶液混合发生双水解，Al³⁺ + 3HCO₃⁻ = Al(OH)₃↓ + 3CO₂↑（双水解因互相促进趋于完全，用「=」并标沉淀、气体）； 2. 配制易水解盐溶液：配制 FeCl₃ 溶液时先将 FeCl₃ 溶于较浓盐酸再加水稀释，用 H⁺ 抑制 Fe³⁺ 水解； 3. 化肥使用：草木灰（主要成分 K₂CO₃）与铵态氮肥（如 NH₄Cl）不能混合施用，水解显碱性的碳酸钾会促使铵根分解为氨气逸出； 4. 净水：明矾 KAl(SO₄)₂·12H₂O 电离出的 Al³⁺ 水解生成 Al(OH)₃ 胶体，吸附水中悬浮杂质； 5. 除杂与蒸干：加热蒸干 FeCl₃、AlCl₃ 溶液，因 HCl 挥发促进水解，最终得到 Fe(OH)₃、Al(OH)₃（灼烧后得对应氧化物），不能得到无水盐。 **易错提醒** 1. 把「盐溶液显酸性」误写成「盐是酸」。 2. 双水解方程式误用「⇌」和漏标「↓」「↑」。 3. 离子排序忘记「不水解主体离子最大」。 4. 稀释促进水解误认为离子浓度增大。

🔍 课堂讲义 · 重点难点解析

**重点一：盐溶液酸碱性的微观解释** 例题：用离子方程式和文字解释 NH₄Cl 溶液显酸性的原因。 分析：从「盐电离 → 水电离 → 离子结合」的微粒变化链条入手。 解答：NH₄Cl 完全电离出 NH₄⁺ 和 Cl⁻；水微弱电离出 H⁺ 和 OH⁻；NH₄⁺ 与 OH⁻ 结合成弱电解质 NH₃·H₂O：NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺，该结合消耗了 OH⁻，促使水的电离正向移动，溶液中 c(H⁺) > c(OH⁻)，故显酸性。 小结：解释酸碱性三要素——谁电离、谁结合、剩下谁多；Cl⁻ 不水解，只是「旁观者」。 **难点一：离子浓度大小比较与守恒关系** 例题：Na₂CO₃ 溶液中：（1）将 c(Na⁺)、c(CO₃²⁻)、c(HCO₃⁻)、c(H⁺)、c(OH⁻) 由大到小排序；（2）c(Na⁺) 与 2c(CO₃²⁻) 哪个大？（3）写出电荷守恒式。 分析：主体排前、微量排后，再用守恒校验。 解答：（1）c(Na⁺) > c(CO₃²⁻) > c(OH⁻) > c(HCO₃⁻) > c(H⁺)（Na⁺ 不水解浓度最大；CO₃²⁻ 少部分水解，仍远大于水解产物；OH⁻ 来自水的电离和水解，多于 HCO₃⁻）；（2）因为部分 CO₃²⁻ 转化为 HCO₃⁻ 和 H₂CO₃，由物料守恒 c(Na⁺) = 2[c(CO₃²⁻) + c(HCO₃⁻) + c(H₂CO₃)]，故 c(Na⁺) > 2c(CO₃²⁻)；（3）c(Na⁺) + c(H⁺) = 2c(CO₃²⁻) + c(HCO₃⁻) + c(OH⁻)。 小结：守恒是「万能校验器」——排序拿不准时，用电荷守恒和物料守恒找等量关系。 **难点二：水解平衡移动的应用判断** 例题：（1）为什么实验室配制 FeCl₃ 溶液时要加少量盐酸？（2）加热蒸干 FeCl₃ 溶液能否得到无水 FeCl₃？最终产物是什么？ 分析：Fe³⁺ + 3H₂O ⇌ Fe(OH)₃ + 3H⁺，水解产生 H⁺ 且水解吸热。 解答：（1）加盐酸增大 c(H⁺)，使水解平衡逆向移动（被抑制），防止溶液浑浊；（2）不能。加热促进水解，蒸干过程中 HCl 挥发逸出，进一步促使水解趋于完全，最终得到 Fe(OH)₃，灼烧后分解为 Fe₂O₃；若要获得无水盐，需在 HCl 气流中加热蒸干。 小结：挥发性酸盐「蒸干得水解产物」，不挥发性酸盐（如 Na₂SO₄）蒸干仍得原盐。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：判断酸碱性并写水解方程式** 题目：判断 Na₂CO₃ 溶液、NH₄Cl 溶液、KNO₃ 溶液的酸碱性，并写出发生水解的离子方程式。 分析：先看组成盐的酸碱强弱，强碱弱酸盐显碱性、强酸弱碱盐显酸性、强酸强碱盐显中性。 解答：Na₂CO₃ 显碱性：CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻；NH₄Cl 显酸性：NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺；KNO₃ 是强酸强碱盐，不水解，显中性。 方法小结：判断四步——找弱离子、定酸碱性、写结合式、配平检查（用「⇌」）。 **例题二（提高）：CH₃COONa 溶液浓度排序** 题目：在 CH₃COONa 溶液中，将 c(Na⁺)、c(CH₃COO⁻)、c(OH⁻)、c(H⁺) 由大到小排序，并写出电荷守恒式。 分析：Na⁺ 不水解，CH₃COO⁻ 部分水解，溶液显碱性。 解答：c(Na⁺) > c(CH₃COO⁻) > c(OH⁻) > c(H⁺)。电荷守恒：c(Na⁺) + c(H⁺) = c(CH₃COO⁻) + c(OH⁻)。 方法小结：一元弱酸盐排序模板——「不水解阳离子 > 弱酸根 > OH⁻ > H⁺」；二元弱酸盐在弱酸根与 OH⁻ 之间多一步权衡（如碳酸钠中 OH⁻ > HCO₃⁻）。 **例题三（综合）：泡沫灭火器的化学原理** 题目：泡沫灭火器内分别装有 Al₂(SO₄)₃ 溶液和 NaHCO₃ 溶液。倒置混合后喷出大量泡沫。请写出反应的离子方程式，并解释为什么用 NaHCO₃ 而不是 Na₂CO₃ 效果更好。 分析：Al³⁺ 水解显酸性、HCO₃⁻ 水解显碱性，两者混合后互相促进水解（双水解）趋于完全。 解答：Al³⁺ + 3HCO₃⁻ = Al(OH)₃↓ + 3CO₂↑。产生大量 CO₂ 和 Al(OH)₃ 泡沫覆盖可燃物隔绝空气。与 Na₂CO₃ 相比，HCO₃⁻ 直接结合 H⁺ 生成 H₂CO₃，不需要先经历 CO₃²⁻ 的第一步水解，反应速率更快、放出 CO₂ 更多更快，灭火效果好。 方法小结：双水解趋于完全的判据——「强酸弱碱盐 + 弱酸强碱盐」且产物有沉淀或气体（如 Al³⁺ 与 HCO₃⁻、Al³⁺ 与 CO₃²⁻、Al³⁺ 与 S²⁻ 等），方程式用「=」并标注沉淀与气体。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 酸碱性判断与水解方程式

  1. 1. 填空：Na₂CO₃ 溶液显（　）性，原因是（　）离子发生水解；NH₄Cl 溶液显（　）性；KNO₃ 溶液显（　）性。
    答：碱；CO₃²⁻（碳酸根）；酸；中性。规律：强碱弱酸盐显碱性，强酸弱碱盐显酸性，强酸强碱盐显中性。
  2. 2. 写出下列水解的离子方程式：（1）CH₃COONa；（2）NH₄Cl。
    答：（1）CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻；（2）NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺。注意用「⇌」，不标沉淀、气体符号。
  3. 3. 判断正误并说明理由：（1）盐溶液一定显中性；（2）加热蒸干 K₂CO₃ 溶液可以得到 K₂CO₃ 固体；（3）加水稀释 Na₂CO₃ 溶液，水解程度增大。
    答：（1）错，如 Na₂CO₃ 显碱性、NH₄Cl 显酸性；（2）对，K₂CO₃ 属于不挥发性强碱弱酸盐：水解生成的 H₂CO₃ 不会像 HCl 那样挥发离开体系，水解不能趋于完全，蒸干结晶仍得 K₂CO₃（对比 FeCl₃ 蒸干得 Fe(OH)₃）；（3）对，稀释促进水解。

中等 · 水解规律运用

  1. 1. 相同浓度的 Na₂CO₃ 溶液和 NaHCO₃ 溶液，哪种碱性强？用「越弱越水解」解释。
    答：Na₂CO₃ 碱性强。CO₃²⁻ 对应的「酸」是 HCO₃⁻，HCO₃⁻ 对应的「酸」是 H₂CO₃；HCO₃⁻ 比 H₂CO₃ 更难电离（更弱），所以 CO₃²⁻ 水解程度更大，碱性更强。
  2. 2. 加热蒸干 FeCl₃ 溶液，最终得到什么固体？写出相关的水解离子方程式，并说明理由。
    答：最终得到 Fe(OH)₃（灼烧后得 Fe₂O₃）。水解：Fe³⁺ + 3H₂O ⇌ Fe(OH)₃ + 3H⁺。加热促进水解，且蒸干时 HCl 挥发逸出，使水解不断右移趋于完全，所以得不到无水 FeCl₃。
  3. 3. CH₃COONa 溶液中，c(Na⁺)、c(CH₃COO⁻)、c(OH⁻)、c(H⁺) 由大到小的顺序是什么？写出电荷守恒式。
    答：c(Na⁺) > c(CH₃COO⁻) > c(OH⁻) > c(H⁺)。电荷守恒：c(Na⁺) + c(H⁺) = c(CH₃COO⁻) + c(OH⁻)。

难 · 守恒关系与浓度比较

  1. 1. Na₂CO₃ 溶液中：c(Na⁺) 与 2c(CO₃²⁻) 哪个大？写出物料守恒式加以说明。
    答：c(Na⁺) 大。物料守恒：c(Na⁺) = 2 × [c(CO₃²⁻) + c(HCO₃⁻) + c(H₂CO₃)]，由于部分 CO₃²⁻ 水解为 HCO₃⁻ 和 H₂CO₃，括号内总量大于 c(CO₃²⁻)，故 c(Na⁺) > 2c(CO₃²⁻)。
  2. 2. NH₄Cl 溶液中，c(Cl⁻)、c(NH₄⁺)、c(H⁺)、c(OH⁻) 由大到小的顺序是什么？由水电离出的 c(H⁺) 与 1×10⁻⁷ mol/L 相比是大还是小？
    答：c(Cl⁻) > c(NH₄⁺) > c(H⁺) > c(OH⁻)（NH₄⁺ 部分水解，且水解产生的 H⁺ 少量）。水电离出的 c(H⁺) 大于 1×10⁻⁷ mol/L——水解的盐促进水的电离（溶液中全部 H⁺ 都来自水）。
  3. 3. NaHCO₃ 溶液中存在电荷守恒 c(Na⁺) + c(H⁺) = c(HCO₃⁻) + 2c(CO₃²⁻) + c(OH⁻)。请解释为什么 CO₃²⁻ 的系数是 2，并说明该溶液显碱性的主要原因。
    答：电荷守恒按每个离子所带电荷数计，1 个 CO₃²⁻ 带 2 个单位负电荷，所以乘 2。NaHCO₃ 中 HCO₃⁻ 的水解程度大于其电离程度（水解：HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻；电离：HCO₃⁻ ⇌ CO₃²⁻ + H⁺），水解占优使 c(OH⁻) > c(H⁺)，故溶液显碱性。

综合 · 水解应用与实验方案

  1. 1. 泡沫灭火器中 Al₂(SO₄)₃ 溶液与 NaHCO₃ 溶液混合的离子方程式是什么？请从「双水解」角度解释反应能趋于完全的原因。
    答：Al³⁺ + 3HCO₃⁻ = Al(OH)₃↓ + 3CO₂↑。Al³⁺ 水解显酸性、HCO₃⁻ 水解显碱性，混合后各自消耗对方水解产物（H⁺ 与 OH⁻），两个水解互相促进、叠加趋于完全，生成 Al(OH)₃ 沉淀和大量 CO₂，喷出泡沫覆盖火源。因趋于完全，方程式用「=」并标「↓」「↑」。
  2. 2. 草木灰（主要成分 K₂CO₃）不能与铵态氮肥（如 NH₄Cl）混合施用，请用化学用语解释原因。
    答：K₂CO₃ 水解显碱性：CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻，溶液中 c(OH⁻) 较大；铵根遇碱放出氨气：NH₄⁺ + OH⁻ = NH₃↑ + H₂O，导致氮元素以氨气形式逸散，降低肥效。
  3. 3. 实验室要配制澄清的 FeCl₃ 溶液，请写出正确的操作步骤并用平衡移动原理解释每一步的作用。
    答：操作：①将 FeCl₃ 固体溶于较浓盐酸中，②再加蒸馏水稀释到所需体积。解释：Fe³⁺ + 3H₂O ⇌ Fe(OH)₃ + 3H⁺，直接溶于水时水解生成 Fe(OH)₃ 使溶液浑浊；先溶于盐酸可增大 c(H⁺)，使水解平衡逆向移动（抑制水解）；稀释时保持一定酸度，防止再出现浑浊。注意不能加热促进水解，也不能用碱调节。

💬 课后反馈

**学生常见错误** 1. 只背口诀不懂原理：能背「谁强显谁性」，但被问「为什么」时写不出「离子结合水电离出的 H⁺ 或 OH⁻」这条微观主线。 2. 水解方程式书写不规范：该用「⇌」写成「=」；多价阴离子（CO₃²⁻、PO₄³⁻）不分步、一步写成最终产物；双水解又误用「⇌」、漏标沉淀气体。 3. 离子排序凭感觉：忘记「不水解的微粒浓度最大」，把水解产物 HCO₃⁻ 排在 OH⁻ 前。 4. 守恒式列错系数：电荷守恒中二价离子忘记乘 2，物料守恒中比例关系（如钠与碳 2:1）写反。 **教学改进建议** 1. 用「三段微观链条」统一解释所有水解：盐电离 → 弱离子结合水电离的离子 → 剩余谁多显谁性，让学生人人会讲道理。 2. 排序题建立「两步走」模板：先排「主体」（不水解离子、弱酸根），再排「微量」（OH⁻、HCO₃⁻、H⁺），最后用两个守恒校验。 3. 对比实验强化记忆：课上用 pH 试纸实测 NaCl、Na₂CO₃、NH₄Cl、CH₃COONa 四种溶液，让规律从数据中来。 **分层辅导建议** - 基础层：过关盐的类型判断与四种典型水解方程式。 - 提高层：完成一元、二元弱酸盐的排序题，学会列电荷守恒与物料守恒。 - 拓展层：训练双水解方程式、蒸干结晶判断、配制溶液与除杂方案设计。 **给家长的建议** 1. 请孩子给您讲一讲「纯碱为什么是碱性的却叫盐」，讲得清楚说明原理真懂了。 2. 结合生活提问巩固：比如问「为什么热的碱面水洗油腻更干净」「明矾为什么能净水」，让课堂知识落到生活。
