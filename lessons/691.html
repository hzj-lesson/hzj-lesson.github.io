小学三年级语文《古诗三首：绝句/惠崇春江晚景/三衢道中》教案

小学三年级语文古诗三首：绝句/惠崇春江晚景/三衢道中

📝 备课方案

**教学目标** 1. 认识"鸳、鸯、惠、崇、豚、衢"等生字，会写"融、燕、鸳、鸯"等字，读准"蒌蒿""三衢"等词语的字音。 2. 正确、流利、有感情地朗读三首古诗，背诵三首古诗，默写《绝句》。 3. 借助注释和插图了解诗句意思，抓住景物想象画面，感受春天的美好和生机。 4. 了解三位诗人的朝代等文学常识，初步感受三首诗中"动静结合"的写法。 **教学重点**：读熟背熟三首古诗，理解诗句意思，想象诗中描绘的春天景象。 **教学难点**：体会"泥融飞燕子，沙暖睡鸳鸯"等诗句中动静结合的妙处；记住诗人与朝代的对应。 **教学方法**：诵读法、想象画面法、比较阅读法、资料补充法。 **教学准备**：春景图片、三位诗人头像卡、生字卡片、多媒体课件。 **课时安排**：2 课时（第 1 课时：《绝句》《惠崇春江晚景》；第 2 课时：《三衢道中》，三首诗比较与积累）。

📖 课堂讲义 · 核心知识点

**一、三首古诗读一读** 绝句 【唐】杜甫 迟日江山丽，春风花草香。 泥融飞燕子，沙暖睡鸳鸯。 惠崇春江晚景 【宋】苏轼 竹外桃花三两枝，春江水暖鸭先知。 蒌蒿满地芦芽短，正是河豚欲上时。 三衢道中 【宋】曾几 梅子黄时日日晴，小溪泛尽却山行。 绿阴不减来时路，添得黄鹂四五声。 **二、认读重点字词（注音）** 鸳鸯（yuān yāng）——一种水鸟，常成双成对。 蒌蒿（lóu hāo）——一种长在河滩上的野草。 河豚（hé tún）——一种味道鲜美但内脏有毒的鱼。 三衢（sān qú）——山名，在今浙江衢州一带。 泛（fàn）——乘船。却（què）——再、又。阴（yīn）——树荫。 融（róng）——融化。燕（yàn）——燕子。 **三、字词与诗意理解** | 诗句 | 关键词 | 意思 | |---|---|---| | 迟日江山丽 | 迟日：春日，春天白天变长 | 春天的太阳照耀，江山秀丽，春风送来花草的芳香 | | 泥融飞燕子 | 泥融：冻泥融化，又软又湿 | 燕子衔着湿泥飞来飞去，忙着筑巢 | | 沙暖睡鸳鸯 | | 沙滩被晒暖了，鸳鸯静静地睡着 | | 竹外桃花三两枝 | | 竹林外两三枝桃花刚刚开放 | | 春江水暖鸭先知 | | 江水变暖，在水里游的鸭子最先知道 | | 蒌蒿满地芦芽短 | 芦芽：芦苇的嫩芽 | 河滩上蒌蒿长满，芦苇抽出短短的嫩芽 | | 小溪泛尽却山行 | 泛：乘船；却：再、又 | 乘小船到小溪的尽头，再走山路继续前行 | | 绿阴不减来时路 | | 山路上绿树成荫，不比来时差 | | 添得黄鹂四五声 | | 还不时传来黄鹂清脆的鸣叫 | **四、认识三位诗人** | 诗人 | 朝代 | 简介 | |---|---|---| | 杜甫 | 唐代 | 伟大的现实主义诗人，被尊为"诗圣"，他的诗被称为"诗史" | | 苏轼 | 北宋 | 文学家、书画家，字子瞻，号东坡居士，"唐宋八大家"之一 | | 曾几 | 南宋 | 诗人，字吉甫，号茶山居士 | **五、三首诗比一比** | 诗题 | 作者 | 季节 | 主要景物 | |---|---|---|---| | 绝句 | 杜甫（唐） | 春天 | 迟日、春风、花草、燕子、鸳鸯 | | 惠崇春江晚景 | 苏轼（宋） | 早春 | 桃花、江水、鸭子、蒌蒿、芦芽、河豚 | | 三衢道中 | 曾几（宋） | 初夏 | 梅子、小溪、绿阴、黄鹂 | 发现：《绝句》《惠崇春江晚景》写的是春天，《三衢道中》写的是初夏（梅子黄时）。三首诗都抓住了有代表性的景物，写出季节的特点。 **六、动静结合写景** 《绝句》中，"泥融飞燕子"是动态——燕子飞来飞去忙着筑巢；"沙暖睡鸳鸯"是静态——鸳鸯安静地睡着。一动一静，春天既生机勃勃又安闲舒适。 《惠崇春江晚景》中，桃花初放是静，鸭子戏水是动。 《三衢道中》中，绿阴是静，黄鹂鸣叫是动，叫声反而衬出山中的清幽。 **易错提醒** 1. "惠崇春江晚景"是苏轼为僧人惠崇的画作写的题画诗，有的版本也写作"晓景"，课本上用的是"晚景"。 2. "蒌蒿"读 lóu hāo；"三衢"的"衢"读 qú。 3. 默写《绝句》时，"鸳鸯"两个字都是"鸟"字旁，别写错。 4. 别把朝代弄混：杜甫是唐代，苏轼是北宋，曾几是南宋。

🔍 课堂讲义 · 重点难点解析

**重点一：想象画面，读懂诗意** 例题：用自己的话说说"泥融飞燕子，沙暖睡鸳鸯"的意思。 分析：抓住"泥融""飞""沙暖""睡"四个词，想画面：春天泥土什么样？燕子在做什么？ 解答：春天到了，冻泥融化，又软又湿，燕子飞来飞去衔泥筑巢；沙滩被太阳晒暖了，鸳鸯安安静静地睡在上面。 小结：读懂诗句的关键是把字词变成画面，画面清楚了，意思就明白了。 **重点二：读出节奏和韵味** 例题：给《三衢道中》划分朗读节奏。 分析：七言诗一般按"四三"停顿。 解答：梅子黄时/日日晴，小溪泛尽/却山行。绿阴不减/来时路，添得黄鹂/四五声。 小结：七言诗四三停顿最常见，读的时候语速可稍快，读出游山玩水的轻快心情。 **难点一：体会动静结合的妙处** 例题："沙暖睡鸳鸯"是写静，"泥融飞燕子"是写动，这样一静一动写出了怎样的春天？ 分析：分别想两个画面带给人的感觉，再合起来想整体。 解答：燕子飞舞，写出春天的生机和忙碌；鸳鸯安睡，写出春天的温暖和安宁。一动一静，春天既热闹又恬静，画面有变化、更生动。 小结：动静结合是古诗写景的常用方法，动静搭配，画面才有生气。 **难点二：理解"春江水暖鸭先知"的道理** 例题：为什么说"春江水暖鸭先知"？ 分析：想一想：谁天天在江水里活动？它最先感受到什么？ 解答：鸭子常年在水中游戏，江水刚刚变暖，它们最先知道。这句话还告诉我们：只有亲身接触、亲身实践，才能最先了解事物的情况。 小结：好诗句常常藏着道理，读诗时多问一个"为什么"，收获就更多。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：文学常识填空** 题目：《绝句》的作者是（　）代诗人（　）；《惠崇春江晚景》的作者是（　）代诗人（　）；《三衢道中》的作者是（　）代诗人（　）。 分析：记住三首诗和诗人、朝代的对应关系，可以联想记忆：杜甫写春日绝句，苏轼题画赞早春，曾几初夏游三衢。 解答：依次填：唐、杜甫；宋（北宋）、苏轼；宋（南宋）、曾几。 方法小结：诗人配朝代，可以做"人物卡片"帮助记忆，一人一卡，写上朝代和代表作。 **例题二（提高）：按诗意选画面** 题目：诗中"竹外桃花三两枝，春江水暖鸭先知"描绘的画面是（　）。 A. 竹林里开着大片桃花，鸭子在岸上晒太阳 B. 竹林外两三枝桃花开放，鸭子在江水中游戏 C. 桃花落满江面，鸭子潜水捉鱼 分析：逐句对照："竹外桃花三两枝"是竹林外有三两枝桃花，不是大片；"春江水暖鸭先知"是鸭子在江水中感知暖意。 解答：选 B。 方法小结：选择画面题要逐词核对：地点（竹外）、数量（三两枝）、动作（游水），一个都不能错。 **例题三（综合）：三首诗比季节** 题目：三首诗写的分别是什么季节？从哪些景物看出来的？ 分析：抓有代表性的景物判断季节：燕子筑巢、鸳鸯戏水；桃花初放、芦芽短；梅子黄时。 解答：《绝句》写春天，从春日、春风、燕子、鸳鸯看出；《惠崇春江晚景》写早春，从桃花初放、江水初暖、芦芽短看出；《三衢道中》写初夏，从"梅子黄时"看出。 方法小结：判断季节抓"信号景物"：燕子和鸳鸯报春，桃花芦芽报早春，梅子黄时报初夏。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 诵读与积累

  1. 1. 背诵《绝句》，默写一遍。
    答：迟日江山丽，春风花草香。泥融飞燕子，沙暖睡鸳鸯。注意"鸳鸯"两个字都是鸟字旁。
  2. 2. 给下面的词注音：鸳鸯（　）（　）、蒌蒿（　）（　）、三衢（　）。
    答：yuān yāng、lóu hāo、qú。注意"蒌蒿"都是草字头，读 lóu hāo。
  3. 3. 填空：《绝句》的作者是（　）代诗人（　）；《三衢道中》的作者是（　）代诗人（　）。
    答：唐、杜甫；宋、曾几。

中等 · 诗意理解

  1. 1. 用自己的话说说"小溪泛尽却山行"的意思。
    答：乘小船沿着小溪走到尽头，再改走山路继续前行。"泛"是乘船，"却"是再、又。
  2. 2. 把诗句和对应的景物连一连：迟日江山丽、春江水暖、梅子黄时、绿阴不减。景物：春日、江水、初夏、树荫。
    答：迟日江山丽连春日，春江水暖连江水，梅子黄时连初夏，绿阴不减连树荫。
  3. 3. 选择：《惠崇春江晚景》中"正是河豚欲上时"的"欲"的意思是（　）。A. 想要　B. 将要　C. 欲望
    答：选 B。"欲上"指正要逆流而上。

难 · 品味赏析

  1. 1. "泥融飞燕子，沙暖睡鸳鸯"一动一静，这样写好在哪里？
    答："飞燕子"写出春天的生机勃勃，"睡鸳鸯"写出春天的温暖安宁；一动一静，画面有变化，把春天既热闹又恬静的特点写活了。
  2. 2. "添得黄鹂四五声"中"添"字用得好，好在哪里？
    答：来时路上有绿阴，回来时绿阴不减，又"添"了黄鹂的鸣叫。"添"字写出旅途中意外的惊喜，有声有色，游兴更浓，也以鸟声反衬出山林的清幽。
  3. 3. 三首诗都写了自然景物，你最喜欢哪一首里的哪一句？结合诗句说说理由。
    答：示例：我最喜欢"春江水暖鸭先知"，因为鸭子在水中游玩，最先知道江水变暖，画面活泼有趣，还告诉我们亲身实践才能最先了解情况的道理。（能结合诗句、理由充分即可）

综合 · 诗画与生活

  1. 1. 诗配画：选一首诗，把诗中的景象画下来，并在画旁题上诗句。
    答：画《绝句》可画春日、花草、燕子、鸳鸯；画《惠崇春江晚景》可画竹林、桃花、戏水的鸭子。要求景物和诗句对应，画面完整。
  2. 2. 向家人介绍：选一首诗，按"作者朝代—诗句意思—有趣的地方"的顺序讲给家人听。
    答：示例：《惠崇春江晚景》是宋代苏轼为画家惠崇的画写的题画诗。竹林外桃花刚开两三枝，江水变暖鸭子先知道。有趣的是"鸭先知"，鸭子最先感受到春天。
  3. 3. 小练笔：用两三句话写一写你在春天（或初夏）看到的景色，试着用上诗中的一个词语（如"春日""桃花""绿阴"）。
    答：示例：周末我们去郊外，春日的阳光暖暖的，路边桃花开了三两枝，河里的小鸭子游来游去。要求景物的季节和词语搭配合理。

💬 课后反馈

**学生常见错误** 1. 字音：把"蒌蒿（lóu hāo）""三衢（qú）"读错，把"鸳鸯"写成同音字。 2. 常识混淆：把杜甫说成宋代、苏轼说成唐代；把《惠崇春江晚景》的作者记成惠崇（惠崇是画家，诗是苏轼写的）。 3. 诗意理解偏差：把"迟日"理解成"迟到的太阳"；逐字硬译"泥融飞燕子"。 4. 背诵串诗：三首诗都是写景，背到一半互相串，如把"梅子黄时"背进《绝句》里。 **教学改进建议** 1. 每首诗配一幅"景物卡片"，先摆景物说画面，再看画面背诗句，降低背诵难度。 2. 制作"诗人名片"：杜甫（唐·诗圣）、苏轼（北宋·东坡居士）、曾几（南宋·茶山居士），课前一分钟抢答对应关系。 3. 用"动静找一找"游戏巩固写法：在三首诗里分别找出动态和静态的景物，学生出题互考。 **分层辅导建议** - 基础层：读准、读熟、会背《绝句》，认识课后生字。 - 提高层：三首都会背，能说出诗句意思和主要景物。 - 拓展层：能赏析动静结合的写法，比较三首诗的季节与景物差异，积累更多写春的诗句。 **给家长的建议** 1. 亲子赛诗会：和家人比一比谁背得多、背得有感情，激发孩子背诵兴趣。 2. 走进生活找诗句：春天散步时看到桃花、燕子，引导孩子想起"竹外桃花三两枝""泥融飞燕子"，让古诗活起来。
