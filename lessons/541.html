高中高三数学《直线与圆锥曲线》教案

高中高三数学直线与圆锥曲线

📝 备课方案

**教学目标** 1. 掌握直线方程的五种形式与两条直线的位置关系，能求点到直线的距离。 2. 掌握椭圆、双曲线、抛物线的定义、标准方程与几何性质（范围、对称性、顶点、焦点、离心率、渐近线、准线）。 3. 掌握直线与圆锥曲线的位置关系判定，熟练运用"联立方程、韦达定理"解决弦长、中点弦、面积等问题。 4. 强化数形结合与设而不求思想，提升圆锥曲线综合题的运算求解能力与规范书写能力。 **教学重点**：椭圆、双曲线、抛物线的定义与标准方程；直线与圆锥曲线联立、韦达定理的综合应用。 **教学难点**：离心率范围的求解；弦长、中点弦与面积问题中的参数运算；最值与定值问题的处理策略。 **教学方法**：定义回归法、设而不求法、数形结合法、运算规范训练法。 **教学准备**：多媒体课件、圆锥曲线动态演示课件、高考解析几何真题汇编、运算规范学案。 **课时安排**：共 2 课时。第 1 课时圆锥曲线的定义与性质，第 2 课时直线与圆锥曲线的综合问题，并安排限时训练与课堂小结。

📖 课堂讲义 · 核心知识点

**一、直线方程与位置关系** 直线方程的五种形式：点斜式 $y-y_0=k(x-x_0)$；斜截式 $y=kx+b$；两点式；截距式 $\frac{x}{a}+\frac{y}{b}=1$；一般式 $Ax+By+C=0$。求直线方程先判断斜率是否存在。 两条直线平行：$k_1=k_2$（或 $A_1B_2=A_2B_1$）；垂直：$k_1k_2=-1$（或 $A_1A_2+B_1B_2=0$）。 点到直线距离 $d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$；平行直线间距离 $d=\frac{|C_1-C_2|}{\sqrt{A^2+B^2}}$。 直线与圆的位置关系用圆心到直线的距离 d 与半径 r 比较；弦长 $|AB|=2\sqrt{r^2-d^2}$。 **二、椭圆** 定义：平面内到两定点 $F_1$、$F_2$ 距离之和等于常数 2a（$2a>|F_1F_2|$）的点的轨迹。 标准方程：$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$），$c^2=a^2-b^2$。 性质：范围 $|x|\le a$，$|y|\le b$；离心率 $e=\frac{c}{a}\in(0,1)$，e 越接近 1 椭圆越扁；通径长 $\frac{2b^2}{a}$；焦半径 $|PF_1|=a+ex_0$，$|PF_2|=a-ex_0$。焦点三角形面积 $S=b^2\tan\frac{\theta}{2}$（θ 为 $\angle F_1PF_2$）。 **三、双曲线与抛物线** 双曲线：定义 $\big||PF_1|-|PF_2|\big|=2a$（$0<2a<|F_1F_2|$）；标准方程 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$，$c^2=a^2+b^2$；渐近线 $y=\pm\frac{b}{a}x$；离心率 $e=\frac{c}{a}>1$；焦点到渐近线的距离为 b。 抛物线：到定点 F（焦点）与定直线 l（准线）距离相等的点的轨迹。$y^2=2px$（p>0）：焦点 $(\frac{p}{2},0)$，准线 $x=-\frac{p}{2}$；焦半径 $|PF|=x_0+\frac{p}{2}$；通径 2p；焦点弦 $|AB|=x_1+x_2+p=\frac{2p}{\sin^2\theta}$，且 $\frac{1}{|AF|}+\frac{1}{|BF|}=\frac{2}{p}$。 **四、直线与圆锥曲线的位置关系** 联立直线 $y=kx+m$ 与圆锥曲线方程，消元得一元二次方程。$\Delta>0$ 相交、$\Delta=0$ 相切、$\Delta<0$ 相离。注意讨论二次项系数是否为 0。 韦达定理：$x_1+x_2=-\frac{b}{a}$，$x_1x_2=\frac{c}{a}$。 弦长公式：$|AB|=\sqrt{1+k^2}\cdot|x_1-x_2|=\sqrt{1+k^2}\cdot\frac{\sqrt{\Delta}}{|a|}$。 中点弦（点差法）：设弦端点 $A(x_1,y_1)$、$B(x_2,y_2)$，代入曲线方程相减，得弦斜率与中点的关系，如椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 中 $k=-\frac{b^2x_0}{a^2y_0}$。

🔍 课堂讲义 · 重点难点解析

**重点一：椭圆标准方程与性质** 例题：已知椭圆 $C:\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$）过点 $(\sqrt{2},1)$，离心率为 $\frac{\sqrt{2}}{2}$，求椭圆 C 的方程。 分析：由离心率得 a、b 关系，结合点在椭圆上列方程组。 解答：$e=\frac{c}{a}=\frac{\sqrt{2}}{2}$，$b^2=a^2-c^2=\frac{1}{2}a^2$，椭圆方程为 $\frac{x^2}{a^2}+\frac{2y^2}{a^2}=1$。代入 $(\sqrt{2},1)$ 得 $\frac{2}{a^2}+\frac{2}{a^2}=1$，$a^2=4$，$b^2=2$，故方程为 $\frac{x^2}{4}+\frac{y^2}{2}=1$。 小结：求标准方程的本质是求 a、b；充分利用离心率与点在曲线上两个条件。 **重点二：直线与抛物线的位置关系** 例题：已知抛物线 $y^2=4x$，过焦点的直线 l 交抛物线于 A、B 两点，若 $|AB|=8$，求直线 l 的方程。 分析：设直线点斜式，联立消元，用焦点弦长公式。 解答：焦点 F(1,0)。设 $y=k(x-1)$，联立得 $k^2x^2-(2k^2+4)x+k^2=0$，$x_1+x_2=\frac{2k^2+4}{k^2}$。焦点弦 $|AB|=x_1+x_2+2=8$，得 $k^2=1$，$k=\pm1$，直线为 $y=\pm(x-1)$。斜率不存在时 $|AB|=4$，不合题意。 小结：过焦点的弦用焦半径求和运算量小；直线设斜截式前先考虑斜率不存在的情形。 **难点一：中点弦与点差法** 例题：已知椭圆 $\frac{x^2}{2}+y^2=1$，求以点 $(1,\frac{1}{2})$ 为中点的弦所在直线的方程。 分析：设弦端点，代入曲线方程相减，用点差法求斜率。 解答：设端点 $A(x_1,y_1)$、$B(x_2,y_2)$，则 $\frac{x_1^2-x_2^2}{2}+y_1^2-y_2^2=0$，即 $\frac{(x_1-x_2)(x_1+x_2)}{2}+(y_1-y_2)(y_1+y_2)=0$。由 $x_1+x_2=2$，$y_1+y_2=1$，得 $k=\frac{y_1-y_2}{x_1-x_2}=-\frac{x_1+x_2}{2(y_1+y_2)}=-1$。直线方程为 $y-\frac{1}{2}=-(x-1)$，即 $2x+2y-3=0$。经检验直线与椭圆相交，符合题意。 小结：点差法"设而不求"直接得斜率与中点关系；算出直线后必须检验其与曲线是否真的相交。 **难点二：圆锥曲线中的面积最值** 例题：已知椭圆 $\frac{x^2}{4}+\frac{y^2}{3}=1$，过右焦点 F 的直线交椭圆于 A、B 两点，求 $\triangle AOB$ 面积的最大值。 分析：设 $x=my+1$ 回避斜率讨论，联立韦达，化面积为关于 m 的函数。 解答：联立 $x=my+1$ 与椭圆得 $(3m^2+4)y^2+6my-9=0$，$|y_1-y_2|=\frac{12\sqrt{m^2+1}}{3m^2+4}$。$S=\frac{1}{2}\cdot1\cdot|y_1-y_2|=\frac{6\sqrt{m^2+1}}{3m^2+4}$。令 $t=\sqrt{m^2+1}\ge1$，则 $S=\frac{6t}{3t^2+1}$，在 $[1,+\infty)$ 上单调递减，$t=1$（即 m=0）时取最大，$S_{\max}=\frac{6}{4}=\frac{3}{2}$。 小结：设 $x=my+b$ 可回避斜率不存在的讨论；面积最值化为参数的一元函数，用单调性或不等式求最值。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（椭圆定义与直线相交综合）** 题目：已知椭圆 C 的中心在原点，焦点在 x 轴上，离心率 $e=\frac{\sqrt{3}}{2}$，过点 $(1,\frac{1}{2})$。（1）求椭圆 C 的方程；（2）若直线 $y=kx+1$ 与椭圆 C 恒有两个公共点，求 k 的取值范围。 分析：（1）列方程组求 a、b；（2）联立用判别式。 解答：（1）$e=\frac{c}{a}=\frac{\sqrt{3}}{2}$，$b^2=a^2-c^2=\frac{1}{4}a^2$，方程化为 $\frac{x^2}{a^2}+\frac{4y^2}{a^2}=1$。代入 $(1,\frac{1}{2})$ 得 $a^2=2$，$b^2=\frac{1}{2}$，方程为 $\frac{x^2}{2}+2y^2=1$。（2）联立得 $(\frac{1}{2}+2k^2)x^2+4kx+1=0$，$\Delta=16k^2-2-8k^2=8k^2-2>0$，得 $k>\frac{1}{2}$ 或 $k<-\frac{1}{2}$。 方法小结：直线与椭圆恒有两交点等价于判别式大于 0；求标准方程列 a、b 方程组。 **例题 2（抛物线焦点弦性质）** 题目：已知抛物线 $y^2=2px$（$p>0$）的焦点为 F，直线 l 过 F 与抛物线交于 A、B 两点，若 $|AF|=3$，$|BF|=1$，求 p 的值。 分析：过焦点 F 的焦点弦上，A、B 分居 F 两侧，焦半径满足 $|AF|=x_A+\frac{p}{2}$，$|BF|=x_B+\frac{p}{2}$，本题用焦点弦性质 $\frac{1}{|AF|}+\frac{1}{|BF|}=\frac{2}{p}$ 直接求解。 解答：$\frac{1}{3}+\frac{1}{1}=\frac{2}{p}$，$\frac{4}{3}=\frac{2}{p}$，$p=\frac{3}{2}$。 方法小结：过焦点的弦优先使用 $\frac{1}{|AF|}+\frac{1}{|BF|}=\frac{2}{p}$ 与 $|AB|=x_1+x_2+p$ 等性质，避免繁琐联立；本题亦可用焦半径定义列方程验证，两种途径结论一致。 **例题 3（中点弦问题，设而不求）** 题目：已知椭圆 $C:\frac{x^2}{4}+\frac{y^2}{3}=1$，直线 l 与椭圆交于 A、B 两点，线段 AB 的中点为 $(1,\frac{3}{4})$，求直线 l 的方程。 分析：用点差法直接求斜率。 解答：设 $A(x_1,y_1)$、$B(x_2,y_2)$，代入相减得 $\frac{(x_1-x_2)(x_1+x_2)}{4}+\frac{(y_1-y_2)(y_1+y_2)}{3}=0$。$x_1+x_2=2$，$y_1+y_2=\frac{3}{2}$，故 $k=-\frac{3}{4}\cdot\frac{2}{3/2}=-1$。直线为 $y-\frac{3}{4}=-(x-1)$，即 $4x+4y-7=0$。检验：代入椭圆 $\Delta>0$，符合题意。 方法小结：中点弦"点差法"一步到位；得出直线后须检验是否与曲线相交（判别式大于 0）。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 曲线性质入门

  1. 1. 求椭圆 $\frac{x^2}{25}+\frac{y^2}{9}=1$ 的焦点坐标、离心率与长轴长。
    答：$c=\sqrt{25-9}=4$，焦点 $(\pm4,0)$，离心率 $e=\frac{c}{a}=\frac{4}{5}$，长轴长 $2a=10$。
  2. 2. 求双曲线 $\frac{x^2}{4}-\frac{y^2}{5}=1$ 的渐近线方程与离心率。
    答：$a=2$，$b=\sqrt{5}$，$c=3$，渐近线 $y=\pm\frac{\sqrt{5}}{2}x$，离心率 $e=\frac{3}{2}$。
  3. 3. 求抛物线 $y^2=8x$ 的焦点坐标与准线方程。
    答：$2p=8$，$p=4$，焦点 $(2,0)$，准线 $x=-2$。
  4. 4. 已知椭圆焦点在 x 轴上，焦距为 $4\sqrt{3}$，且过点 $(0,2)$，求椭圆的标准方程。
    答：设 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$，过 $(0,2)$ 得 $b=2$；$c=2\sqrt{3}$，$a^2=b^2+c^2=16$，方程为 $\frac{x^2}{16}+\frac{y^2}{4}=1$。

中等 · 直线与曲线关系

  1. 1. 已知直线 l 过点 (2,1) 且与直线 $2x-y+3=0$ 垂直，求直线 l 的方程。
    答：已知直线斜率为 2，故 $k_l=-\frac{1}{2}$，方程为 $y-1=-\frac{1}{2}(x-2)$，即 $x+2y-4=0$。
  2. 2. 求点 (1,2) 到直线 $3x+4y-1=0$ 的距离。
    答：$d=\frac{|3+8-1|}{\sqrt{3^2+4^2}}=\frac{10}{5}=2$。
  3. 3. 已知椭圆 $\frac{x^2}{9}+\frac{y^2}{4}=1$ 的右焦点为 F，求过 F 且垂直于 x 轴的直线被椭圆截得的弦长。
    答：$c=\sqrt{9-4}=\sqrt{5}$，直线 $x=\sqrt{5}$，代入得 $y^2=\frac{16}{9}$，弦长 $2|y|=\frac{8}{3}$。
  4. 4. 直线 $y=x+m$ 与圆 $x^2+y^2=2$ 相切，求 m。
    答：圆心 (0,0) 到直线 $x-y+m=0$ 的距离 $d=\frac{|m|}{\sqrt{2}}=\sqrt{2}$，$|m|=2$，$m=\pm2$。

难 · 离心率与弦长综合

  1. 1. 已知椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$）的离心率为 $\frac{\sqrt{2}}{2}$，且过点 $(1,\frac{\sqrt{2}}{2})$，求椭圆方程及焦点坐标。
    答：$e=\frac{\sqrt{2}}{2}$，$b^2=\frac{1}{2}a^2$。代入点得 $\frac{1}{a^2}+\frac{1}{a^2}=1$，$a^2=2$，$b^2=1$。方程 $\frac{x^2}{2}+y^2=1$，$c=1$，焦点 $(\pm1,0)$。
  2. 2. 设双曲线 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$（$a,b>0$）的渐近线与圆 $x^2+y^2-4x+3=0$ 相切，求双曲线的离心率。
    答：圆 $(x-2)^2+y^2=1$，圆心 (2,0)，半径 1。圆心到渐近线 $bx-ay=0$ 的距离 $\frac{2b}{c}=1$，$c=2b$，$a=\sqrt{c^2-b^2}=\sqrt{3}b$，$e=\frac{c}{a}=\frac{2\sqrt{3}}{3}$。
  3. 3. 已知过抛物线 $y^2=2px$（$p>0$）焦点 F 的直线交抛物线于 A、B 两点，且 $|AF|=2$，$|BF|=8$，求 p。
    答：由 $\frac{1}{|AF|}+\frac{1}{|BF|}=\frac{2}{p}$，$\frac{1}{2}+\frac{1}{8}=\frac{2}{p}$，$p=\frac{16}{5}$。
  4. 4. 已知椭圆 $\frac{x^2}{4}+\frac{y^2}{3}=1$，直线 $y=2x+m$ 与椭圆恒有两个交点，求 m 的取值范围。
    答：联立得 $19x^2+16mx+4m^2-12=0$，$\Delta=256m^2-76(4m^2-12)=912-48m^2>0$，$m^2<19$，$m\in(-\sqrt{19},\sqrt{19})$。

综合 · 高考真题对接

  1. 1. 已知椭圆 $C:\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$）的离心率为 $\frac{\sqrt{3}}{2}$，短轴长为 2。（1）求椭圆 C 的方程；（2）设直线 l 过右焦点 F 与椭圆交于 A、B 两点，求 $\triangle AOB$ 面积的最大值。
    答：（1）$b=1$，$c^2=\frac{3}{4}a^2$，$b^2=\frac{a^2}{4}=1$，$a^2=4$，方程为 $\frac{x^2}{4}+y^2=1$。（2）$F(\sqrt{3},0)$，设 $x=my+\sqrt{3}$，联立得 $(m^2+4)y^2+2\sqrt{3}my-1=0$，$|y_1-y_2|=\frac{4\sqrt{m^2+1}}{m^2+4}$。$S=\frac{1}{2}\cdot\sqrt{3}\cdot|y_1-y_2|=\frac{2\sqrt{3}t}{t^2+3}$（$t=\sqrt{m^2+1}\ge1$），由 $t^2+3\ge2\sqrt{3}t$ 得 $S\le1$，当 $t=\sqrt{3}$ 时取等，故面积最大值为 1。
  2. 2. 已知椭圆 $\frac{x^2}{4}+\frac{y^2}{3}=1$ 上一点 P 到左焦点 $F_1$ 的距离为 1，求点 P 到右焦点 $F_2$ 的距离及 P 到右准线的距离。
    答：$a=2$，$c=1$，$|PF_1|+|PF_2|=4$，故 $|PF_2|=3$。由第二定义，P 到右焦点与到右准线距离之比为 $e=\frac{1}{2}$，右准线 $x=\frac{a^2}{c}=4$，$d=\frac{|PF_2|}{e}=6$。
  3. 3. 已知抛物线 $y^2=4x$，过焦点 F 的直线与抛物线交于 A、B 两点，以 AB 为直径的圆与抛物线的准线位置关系如何？
    答：设 $A(x_1,y_1)$，$B(x_2,y_2)$，圆心横坐标 $\frac{x_1+x_2}{2}$，半径 $r=\frac{|AB|}{2}=\frac{x_1+x_2+2}{2}$。圆心到准线 $x=-1$ 的距离 $d=\frac{x_1+x_2}{2}+1=r$，故圆与准线相切。
  4. 4. 已知椭圆 $C:\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b>0$）的焦距为 2，离心率为 $\frac{\sqrt{2}}{2}$。（1）求椭圆方程；（2）设过右焦点 F 的直线与椭圆交于 A、B 两点，且 $|AB|=\frac{3\sqrt{2}}{2}$，求直线 AB 的方程。
    答：（1）$c=1$，$a=\sqrt{2}$，$b=1$，方程为 $\frac{x^2}{2}+y^2=1$。（2）设 $y=k(x-1)$，联立得 $(\frac{1}{2}+k^2)x^2-2k^2x+k^2-1=0$，$|AB|=\sqrt{1+k^2}\cdot\frac{\sqrt{2k^2+2}}{\frac{1}{2}+k^2}=\frac{\sqrt{2}(k^2+1)}{k^2+\frac{1}{2}}=\frac{3\sqrt{2}}{2}$，解得 $k^2=\frac{1}{2}$。故直线为 $x-\sqrt{2}y-1=0$ 或 $x+\sqrt{2}y-1=0$（斜率不存在时弦长 $\sqrt{2}$，不合题意）。

💬 课后反馈

**常见错误** 1. 椭圆、双曲线 a、b、c 关系混淆（椭圆 $c^2=a^2-b^2$，双曲线 $c^2=a^2+b^2$）。2. 渐近线方程写错，焦点与准线对应错误。3. 联立消元后漏掉二次项系数为 0 的讨论。4. 弦长公式中 $\Delta$ 代错，韦达定理符号写错。 **教学改进建议** 1. 制作三类曲线性质对照表，课前默写。2. 强化"设而不求"意识，规范联立、判别式、韦达三步书写。3. 用动态课件直观演示离心率变化对曲线形状的影响。 **分层辅导** 学困生：过关标准方程与基本量计算，掌握直线与圆位置关系；学优生：挑战面积最值、定值定点与存在性综合题，体会设参消参与整体代换。
