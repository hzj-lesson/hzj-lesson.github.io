小学六年级语文《古诗三首：寒食/迢迢牵牛星/十五夜望月》教案

小学六年级语文古诗三首：寒食/迢迢牵牛星/十五夜望月

📝 备课方案

**教学目标** 1. 认识诗人韩翃、王建，了解《古诗十九首》；会认会写本课生字，能正确、流利、有感情地朗读并背诵三首诗（其中《迢迢牵牛星》要求背诵）。 2. 借助注释理解三首诗的诗意，了解寒食节、七夕、中秋等传统节日习俗。 3. 体会三首诗的情感：《寒食》的含蓄讽喻，《迢迢牵牛星》的相思之苦，《十五夜望月》的思乡之情。 4. 学习抓住"节日、景物、人物"理解古诗的方法，感受中华传统节日文化。 **教学重点**：理解诗意，背诵默写，体会三首诗的情感。 **教学难点**：理解《寒食》的暗讽意味；体会《迢迢牵牛星》叠词与借景抒情的妙处。 **教学方法**：节日文化导入、诵读感悟、品词析句、对比阅读、拓展积累。 **教学准备**：课件（寒食节、七夕、中秋节日图片）、牛郎织女故事视频、三首诗配乐朗读。 **课时安排**：3 课时（第 1 课时：《寒食》；第 2 课时：《迢迢牵牛星》；第 3 课时：《十五夜望月》与节日诗歌总结）

📖 课堂讲义 · 核心知识点

**一、三首诗与三个传统节日** - 《寒食》写的是**寒食节**（清明前一两天，禁火、吃冷食，纪念介子推）。 - 《迢迢牵牛星》取材于**七夕**（牛郎织女鹊桥相会的民间传说）。 - 《十五夜望月》写的是**中秋**（八月十五赏月、思亲）。 **二、原文与朗读节奏** 《寒食》（韩翃）： 春城/无处/不飞花， 寒食/东风/御柳斜。 日暮/汉宫/传蜡烛， 轻烟/散入/五侯家。 《迢迢牵牛星》（《古诗十九首》）： 迢迢/牵牛星，皎皎/河汉女。 纤纤/擢素手，札札/弄机杼。 终日/不成章，泣涕/零如雨。 河汉/清且浅，相去/复几许？ 盈盈/一水间，脉脉/不得语。 《十五夜望月》（王建）： 中庭/地白/树栖鸦， 冷露/无声/湿桂花。 今夜/月明/人尽望， 不知/秋思/落谁家。 **三、字词释义** | 词语 | 释义 | |---|---| | 春城 | 春天的京城（长安） | | 御柳 | 皇宫里的柳树 | | 汉宫 | 这里借指唐朝皇宫 | | 五侯 | 这里指皇帝的宠臣、权贵之家 | | 迢迢 | 遥远 | | 皎皎 | 明亮 | | 河汉女 | 织女（河汉：银河） | | 纤纤 | 细柔 | | 擢 | 伸出、举起 | | 札札 | 织布机的声音 | | 机杼 | 织布机 | | 不成章 | 织不成整幅的布帛 | | 泣涕 | 流泪 | | 盈盈 | 水清澈的样子 | | 脉脉 | 相视无言的样子 | | 中庭 | 庭院中 | | 地白 | 月光照地，地面一片白色 | | 秋思 | 秋天的情思（思念） | **四、诗句翻译与画面还原** - 《寒食》：春天的长安城里到处飞舞着柳絮落花，寒食节的东风吹斜了皇宫里的柳枝。傍晚时分，皇宫中传出蜡烛分赐给权贵之家，缕缕轻烟飘散到五侯的家中。 - 《迢迢牵牛星》：牵牛星在银河那边多么遥远，织女星在银河这边多么明亮。织女伸出细柔洁白的手，札札地摆弄着织布机。一整天也织不成布匹，眼泪像雨水一样往下淌。银河又清又浅，相隔能有多远呢？可就是这一水之隔，两人只能含情相望，无法说话。 - 《十五夜望月》：庭院中月光照地，白花花一片，树上栖息着乌鸦；清冷的露水无声地打湿了桂花。今夜人人都仰望明月，不知这秋思会落到谁家。 **五、写作手法与赏析** 1. **《寒食》**：前两句写寒食节长安城的春景，后两句写"日暮传蜡烛"的宫廷特权。表面写景叙事，实则借"汉宫传蜡烛"暗讽**封建特权**（百姓禁火，权贵却可点烛），含蓄而深刻。 2. **《迢迢牵牛星》**：大量使用**叠词**（迢迢、皎皎、纤纤、札札、盈盈、脉脉），音韵和谐，朗朗上口；借织女"终日不成章，泣涕零如雨"的动作和心理，写出相思之苦；"盈盈一水间，脉脉不得语"以水之近反衬离别之远，深化悲剧。 3. **《十五夜望月》**：前两句写景（地白、栖鸦、冷露、桂花），营造清冷寂寥的氛围；后两句由己及人，"不知秋思落谁家"不直说自己思念，却说不知秋思落在谁家，含蓄隽永，把思乡之情写得意境悠远。 **六、主题思想** - 《寒食》借寒食节的见闻，含蓄讽刺了封建统治者的特权。 - 《迢迢牵牛星》借牛郎织女的故事，抒写了相思离别之苦。 - 《十五夜望月》借中秋望月，表达了思念故乡、思念亲人的情感。

🔍 课堂讲义 · 重点难点解析

**重点一：理解《寒食》的言外之意** - 例题：《寒食》后两句"日暮汉宫传蜡烛，轻烟散入五侯家"只是在写景吗？它还有什么深意？ 分析：寒食节全国禁火，唯独皇宫可以点蜡烛，还赐给权贵之家，说明特权阶层的特殊待遇。 参考答案：不只是写景。诗人借"传蜡烛"这件事，含蓄地讽刺了封建统治者享有的特权，表达了委婉的批评。 小结：读诗要"透过字面看深意"，联系节日习俗（禁火）与史实（赐烛）理解。 **重点二：赏析《迢迢牵牛星》的叠词** - 例题：这首诗用了很多叠词，如"迢迢""皎皎""盈盈""脉脉"，它们有什么作用？ 分析：叠词增强了节奏感，也各有所指：写星、写手、写水、写情。 参考答案：叠词使诗句音韵和谐、朗朗上口；同时生动形象——"迢迢"写距离远，"皎皎"写织女星明亮，"盈盈"写银河清澈，"脉脉"写含情无言，增强了抒情效果。 小结：赏析叠词要"先指出用了叠词，再说音韵效果，再说表达内容"。 **难点一：理解"盈盈一水间，脉脉不得语"** - 例题：银河"清且浅"，两人为什么不能相会？ 分析：这不是写实的距离问题，而是象征：清浅的银河却成为无法跨越的阻隔。 参考答案：用水的"清浅"反衬阻隔的"无情"，明明近在咫尺却无法相会、只能相望无言，更显得相思之苦深沉、无奈，具有震撼人心的悲剧力量。 小结：理解"以近衬远、以乐景写哀情"的反衬手法。 **难点二：体会《十五夜望月》的"含蓄"** - 例题："不知秋思落谁家"，诗人为什么不直接说自己思念家乡？ 分析：诗人由自己的望月思乡，推想到天下人都在望月、都有秋思。 参考答案：不说自己思念，却说"不知秋思落谁家"，把个人的思念扩大到天下所有人，含蓄而深沉，意境更广阔，也更耐人寻味。 小结：体会"不直说、让读者自己品味"的含蓄之美。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（理解诗意）** 用自己的话说说"春城无处不飞花，寒食东风御柳斜"的意思。 - 分析：解词"春城""飞花""御柳"。 - 参考答案：春天的长安城里，处处飞舞着柳絮落花；寒食节的东风吹过，皇宫里的柳枝轻轻斜拂。 - 方法小结：注意"无处不飞花"是双重否定，表示"处处都飞花"。 **例题 2（名句赏析）** 赏析"盈盈一水间，脉脉不得语"。 - 分析：从"叠词＋反衬＋情感"角度作答。 - 参考答案：运用叠词，写出银河清澈、二人含情对视却无法交谈的情景。"清且浅"的银河却成为无法跨越的阻隔，以近衬远，把相思之苦写得深沉无奈，极具感染力。 - 方法小结：赏析名句按"手法＋内容＋情感"三步作答。 **例题 3（联系生活）** 三首诗都和传统节日有关，你还能说出哪些和节日有关的古诗名句？ - 分析：联系学过的节日诗，如春节、清明、重阳。 - 参考答案：示例：独在异乡为异客，每逢佳节倍思亲。（王维《九月九日忆山东兄弟》，重阳节）；爆竹声中一岁除，春风送暖入屠苏。（王安石《元日》，春节）。 - 方法小结：积累节日诗要"记住节日＋记住名句＋记住作者"。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 背诵默写

  1. 1. 默写《寒食》。
    答：春城无处不飞花，寒食东风御柳斜。日暮汉宫传蜡烛，轻烟散入五侯家。（注意"御""侯"的写法）
  2. 2. 默写《迢迢牵牛星》。
    答：迢迢牵牛星，皎皎河汉女。纤纤擢素手，札札弄机杼。终日不成章，泣涕零如雨。河汉清且浅，相去复几许？盈盈一水间，脉脉不得语。（注意"擢""杼""涕"的写法）
  3. 3. 默写《十五夜望月》。
    答：中庭地白树栖鸦，冷露无声湿桂花。今夜月明人尽望，不知秋思落谁家。（注意"栖""鸦"的写法）

中等 · 节日与诗意

  1. 1. 《寒食》《迢迢牵牛星》《十五夜望月》分别和哪些传统节日有关？
    答：寒食节（清明前）、七夕（牛郎织女）、中秋（八月十五）。
  2. 2. 寒食节有什么习俗？《寒食》后两句写了什么特权现象？
    答：寒食节禁火、吃冷食。后两句写皇宫傍晚传赐蜡烛给权贵之家，暗讽特权。
  3. 3. "纤纤擢素手，札札弄机杼"写出了织女怎样的形象？
    答：写出织女勤劳（织布）的形象，双手细柔洁白、摆弄织机，但实际是因为思念而无心织布。

难 · 赏析品悟

  1. 1. 《迢迢牵牛星》用了哪些叠词？它们有什么表达效果？
    答：叠词有：迢迢、皎皎、纤纤、札札、盈盈、脉脉。作用：增强音韵美和节奏感，生动地写出距离远、星光亮、手指柔、机声忙、水清浅、情无言，渲染了相思之苦。
  2. 2. "不知秋思落谁家"好在哪里？
    答：不直接说自己的思念，而是由己及人，推想天下望月之人都有秋思，含蓄深沉，意境开阔，更耐人寻味。
  3. 3. 《寒食》表面写景，实则讽刺，说说你的理解。
    答：寒食节全国禁火，宫中却传蜡烛分赐权贵，诗人借这个细节含蓄讽刺了封建特权阶层的特殊待遇，表达委婉的批评。

综合 · 节日古诗拓展

  1. 1. 写出两句与春节有关的古诗名句并注明作者。
    答：示例：爆竹声中一岁除，春风送暖入屠苏。（王安石《元日》）；千门万户曈曈日，总把新桃换旧符。（王安石《元日》）。
  2. 2. 写出两句与重阳节有关的古诗名句并注明作者。
    答：示例：独在异乡为异客，每逢佳节倍思亲。遥知兄弟登高处，遍插茱萸少一人。（王维《九月九日忆山东兄弟》）。
  3. 3. 你的家乡过中秋节有什么习俗？请写一段话介绍（不少于 30 字）。
    答：示例：我们家乡过中秋，一家人晚上围坐在一起吃月饼、赏月亮，还会在院子里摆上水果祭月。老人们会讲嫦娥奔月的故事，孩子们提着灯笼在院子里跑来跑去。习俗介绍清楚、语句通顺即可。

💬 课后反馈

**学生常见错误** 1. 不理解《寒食》的讽刺意味，只当写景诗读。 2. 《迢迢牵牛星》中"河汉女""不成章""盈盈""脉脉"等词理解有困难，影响全诗理解。 3. 背诵时把《迢迢牵牛星》的叠词顺序记乱，如"盈盈"与"皎皎"用混。 4. 赏析"秋思落谁家"时只写"表达思念"，说不出"由己及人、含蓄深沉"。 **教学改进建议** 1. 讲《寒食》前先补充寒食节习俗与"传蜡烛"典故，否则学生无法理解言外之意。 2. 用"牛郎织女"故事导入《迢迢牵牛星》，再抓叠词反复诵读。 3. 三首诗按"节日—习俗—情感"列表整理，帮助学生建立节日古诗的知识结构。 **分层辅导** - 基础弱：以背诵默写和字词解释为主，《寒食》的讽刺含义由教师讲清即可。 - 学有余力：比较三首诗"借景抒情、借事抒情、借传说抒情"的不同抒情方式。 **给家长的建议** 中秋节、七夕、寒食清明前后，和孩子一起背一背对应古诗，讲讲节日来历；赏月时问问孩子"你想到'不知秋思落谁家'了吗"，让古诗走进节日生活。
