小学三年级语文《古诗：望洞庭》教案

小学三年级语文古诗：望洞庭

📝 备课方案

**教学目标** 1. 认识诗人刘禹锡，了解本诗写作背景；认识生字"庭、镜、螺"等，会正确、流利、有感情地朗读并背诵、默写全诗。 2. 借助注释理解诗句意思，能用自己的话说出诗中描绘的洞庭湖秋夜美景。 3. 体会"镜未磨""白银盘""青螺"等比喻的精妙，感受诗人的丰富想象。 4. 感受祖国山河的壮美，激发热爱大自然、热爱祖国河山的情感。 **教学重点**：理解诗意，想象画面，背诵默写全诗。 **教学难点**：体会两个比喻的妙处；理解"潭面无风镜未磨"为什么用"未磨"的镜子作比。 **教学方法**：诵读感悟、画面想象、比喻品析、图片辅助、资料补充。 **教学准备**：课件（洞庭湖秋夜图片、白银盘青螺实物图）、诗人背景资料、配乐朗读。 **课时安排**：2 课时（第 1 课时：读通理解诗意；第 2 课时：品析比喻、背诵默写）

📖 课堂讲义 · 核心知识点

**一、诗人与创作背景** 刘禹锡（772—842），字梦得，唐代文学家、哲学家，有"诗豪"之称，与白居易并称"刘白"。 《望洞庭》写于唐穆宗长庆四年（824 年）秋，刘禹锡赴和州任刺史途经洞庭湖时。诗人远望洞庭湖秋夜景色的壮丽，写下此诗。诗中"湖光秋月两相和"等句，可见诗人被贬多年后依然乐观开朗的胸襟。 **二、原文与朗读节奏** 湖光/秋月/两相和， 潭面/无风/镜未磨。 遥望/洞庭/山水翠， 白银盘里/一青螺。 **三、字词释义** | 词语 | 释义 | |---|---| | 和 | 和谐、协调（湖光与月色交融） | | 潭面 | 湖面（"潭"指洞庭湖） | | 镜未磨 | 古镜用铜制成，磨过才光亮；未磨则模模糊糊。此处指湖面迷蒙，像没打磨的铜镜 | | 遥望 | 远远地看 | | 翠 | 青绿色 | | 白银盘 | 比喻平静澄澈的洞庭湖面 | | 青螺 | 青绿色的田螺。这里比喻湖中的君山 | **四、诗句翻译与画面还原** - **湖光秋月两相和**：洞庭湖的水光与秋夜的月色交融在一起，和谐美好。 - **潭面无风镜未磨**：湖面没有风，平静得像一面没有打磨过的铜镜。 - **遥望洞庭山水翠**：远远望去，洞庭湖的山水一片青翠。 - **白银盘里一青螺**：湖中的君山，就像白银盘里托着的一只青螺。 - 画面想象：秋夜，月光洒在平静的湖面上，水光月色融为一体；远看整个洞庭湖就像一只巨大的白银盘，而君山就像盘中一只小巧的青螺，整个画面宁静、和谐、优美。 **五、写作手法与赏析** 1. **比喻"镜未磨"**：把平静无风的湖面比作铜镜。用"未磨"的镜子，写出月光下湖面迷迷蒙蒙、隐隐约约的朦胧美，比"明亮的镜子"更符合月夜的意境。 2. **比喻"白银盘里一青螺"**：把洞庭湖比作白银盘，把君山比作青螺，一大一小，一白一青，色彩对比鲜明，想象奇特，写出了洞庭湖的宁静和君山的秀美。 3. **"和"字之妙**："两相和"写出湖光与月色相互交融、不分彼此的和谐之美。 4. **观察角度**：题目是"望"，全诗都从远处眺望的角度写，所以湖面像"盘"、君山像"螺"，都是远看才有的整体印象。 **六、主题思想** 全诗描绘了秋夜月光下洞庭湖平静秀美的景色，表现了诗人对洞庭湖美景的喜爱和赞美，也流露了诗人乐观豁达的情怀。

🔍 课堂讲义 · 重点难点解析

**重点一：理解"镜未磨"的比喻** - 例题：湖面平静，为什么诗人不说"镜已磨"而说"镜未磨"？ 分析：古代铜镜要打磨光亮才能照人。如果是白天，湖面明亮如磨过的铜镜；但这是在秋夜月光下，湖面朦胧迷蒙，像一面还没有打磨的铜镜，模糊、柔和。 解答：因为写的是月夜，月光下的湖面迷迷蒙蒙，像没打磨的铜镜，正好写出洞庭湖夜色的朦胧美。 小结：赏析比喻要回到诗句的情境（时间、光线）中去理解。 **重点二：体会"白银盘里一青螺"的想象** - 例题：这个比喻妙在哪里？ 分析：诗人站在远处，把整个洞庭湖看成一只白银盘，把湖中的君山看成盘中的青螺。白银盘与青螺，一大一小、一白一青，对比鲜明，画面宁静优美。 解答：这个比喻想象奇特，生动形象地写出了洞庭湖的平静开阔和君山的秀美小巧，色彩和谐，画面优美。 小结：品比喻要说出"把什么比作什么"以及"写出了什么特点"。 **难点一：抓住"望"字理解全诗** - 例题：为什么诗人看到的湖面像"盘"、君山像"螺"？ 分析：题目是"望洞庭"，"望"是远远地看。从远处整体眺望，湖面才呈现出"盘"的圆形轮廓，君山才显得小巧如"螺"。 解答：因为诗人是远望，所以能整体看到湖的轮廓和君山的形状，产生"白银盘里一青螺"的整体联想。 小结：理解写景诗要抓住题目中的观察角度（望、登、游等）。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（理解诗意）** 用自己的话说说"湖光秋月两相和，潭面无风镜未磨"描绘的画面。 - 分析：抓住"湖光""秋月""无风""镜未磨"等词，说清时间和景物的样子。 - 参考答案：秋天的夜晚，月光洒在洞庭湖上，湖水的波光与月色交融在一起，十分和谐；湖面没有一丝风，平静得像一面没有打磨过的铜镜，迷迷蒙蒙。 - 方法小结：描绘画面要说清"什么时候、什么景物、什么样子"。 **例题 2（比喻赏析）** "遥望洞庭山水翠，白银盘里一青螺"运用了什么修辞手法？有什么表达效果？ - 分析：把洞庭湖比作"白银盘"，把君山比作"青螺"，是比喻。 - 参考答案：运用了比喻的修辞手法，把平静的洞庭湖比作白银盘，把湖中的君山比作青螺，生动形象地写出了洞庭湖的宁静开阔和君山的秀美，想象奇特，画面优美。 - 方法小结：答比喻题按"把…比作…，生动形象地写出了…的特点"的格式作答。 **例题 3（比较阅读）** 《望洞庭》和《暮江吟》都描写了月夜景色，它们有什么相同和不同？ - 分析：两首诗都写了月夜和水，都运用了比喻。不同在于《暮江吟》写了夕阳和夜晚两个时间，《望洞庭》只写秋夜；《暮江吟》写的是江，《望洞庭》写的是湖。 - 参考答案：相同点：都写了月夜景色，都运用了比喻。不同点：《暮江吟》从黄昏写到入夜，写的是江景；《望洞庭》只写秋夜月色下的湖景，突出宁静之美。 - 方法小结：比较阅读要从"内容、时间、修辞、情感"等角度找异同。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 默写与释义

  1. 1. 默写《望洞庭》全诗。
    答：湖光秋月两相和，潭面无风镜未磨。遥望洞庭山水翠，白银盘里一青螺。（注意"潭""螺"的写法）
  2. 2. 解释加点词：潭面无风镜未磨（磨）；遥望洞庭山水翠（遥望）。
    答：磨：打磨（铜镜）；遥望：远远地看。
  3. 3. "白银盘"在诗中指（ ），"青螺"指（ ）。
    答：洞庭湖（平静的湖面）；湖中的君山。

中等 · 理解赏析

  1. 1. 为什么说湖面像"镜未磨"而不是"镜已磨"？
    答：因为这是秋夜月光下的湖面，迷迷蒙蒙，像没有打磨过的铜镜，写出了月夜湖面的朦胧美。
  2. 2. 诗中哪个字写出湖光与月色融为一体？
    答："和"字。"湖光秋月两相和"的"和"是和谐、交融的意思。
  3. 3. 这首诗写了什么季节、什么时间的景色？从哪些词可以看出？
    答：写了秋天的夜晚。"秋月"点明季节和时间，"潭面无风""镜未磨"写出夜色中湖面的平静朦胧。

难 · 语言品析

  1. 1. "白银盘里一青螺"把洞庭湖和君山分别比作什么？这个比喻妙在哪里？
    答：把洞庭湖比作白银盘，把君山比作青螺。妙在一大一小、一白一青，对比鲜明，想象奇特，写出了洞庭湖的宁静开阔和君山的秀美小巧。
  2. 2. 本诗的题目是"望洞庭"，"望"字对全诗有什么作用？
    答："望"点明了观察方式是远望，正因为是远望，才能整体看到洞庭湖的轮廓和君山的形状，产生"白银盘里一青螺"的整体想象。
  3. 3. 请你发挥想象，用两三句话写一写你"望"到的洞庭湖秋夜美景。
    答：示例：秋夜，皎洁的月光洒在洞庭湖上，湖面平静得像一面朦胧的铜镜。远远望去，湖中的君山翠绿秀美，就像白银盘里托着的一只青螺，真是美极了！

综合 · 拓展积累

  1. 1. 你还知道哪些描写祖国湖光山色的古诗名句？写出两句并注明作者。
    答：示例：水光潋滟晴方好，山色空蒙雨亦奇。（苏轼《饮湖上初晴后雨》）；欲把西湖比西子，淡妆浓抹总相宜。（苏轼）。写出符合要求的即可。
  2. 2. 刘禹锡被称为"诗豪"，结合本诗说说你从诗中感受到他怎样的情怀。
    答：示例：诗人被贬多年，但诗中写的是宁静美好的湖光山色，表现了乐观豁达、热爱生活的情怀。言之有理即可。
  3. 3. 为《望洞庭》配一幅画，你会安排哪些景物？请按由远到近的顺序写一写。
    答：示例：远处是天边的一轮秋月，月光洒在湖面上；湖面平静如镜，泛着朦胧的光；湖中央有一座青翠的君山；近处是波光粼粼的湖水。按"月—湖—君山—近水"的顺序安排即可。

💬 课后反馈

**学生常见错误** 1. 把"镜未磨"理解成"镜子没有擦干净"，没有联系古代铜镜的知识。 2. 把"白银盘里一青螺"误以为是真实的白银盘和青螺，不理解是比喻。 3. 默写时"潭"字写错（少写"氵"旁），"螺"字结构写错。 4. 赏析比喻只会说"用了比喻"，说不出比喻的本体和喻体，更说不出表达效果。 **教学改进建议** 1. 出示"铜镜（磨与未磨）""白银盘托青螺"的图片，帮助学生直观理解比喻。 2. 采用"找本体—找喻体—说特点"三步法训练比喻赏析。 3. 与《暮江吟》对比教学，两首都是写水景月夜，可组织对比阅读讨论。 **分层辅导** - 基础弱：以朗读、背诵、默写和字词解释为主，比喻赏析先由教师示范再说。 - 学有余力：尝试用"白银盘里一青螺"这样的句式，仿写一个比喻句描写身边的景物。 **给家长的建议** 带孩子去湖边或公园水边赏月时，问问孩子"水面像什么"，鼓励孩子用比喻表达；也可以一起背诵《望洞庭》，边看边想。
