小学三年级数学《万以内的加减法》教案

小学三年级数学万以内的加减法

📝 备课方案

**教学目标** 1. 掌握整十、整百数及两位数加、减两位数的口算方法，能正确、熟练地口算。 2. 理解并掌握三位数加、减法的笔算方法，能正确计算连续进位加法和连续退位减法。 3. 学会加、减法的验算方法，养成自觉验算的习惯；能根据情境合理估算。 4. 能运用加、减法解决购物、比较等生活中的实际问题，感受计算的价值。 **教学重点**：掌握三位数加、减法的笔算法则，会正确计算并进行验算。 **教学难点**：连续进位加法和连续退位减法（尤其是个位不够减、十位是 0 的情形）的正确计算。 **教学方法**：迁移类推、对比辨析、分层练习、创设生活情境。 **教学准备**：课件、计数器、口算卡片、购物情境图。 **课时安排**：4 课时（第 1 课时：口算两位数加减法；第 2 课时：笔算加法与验算；第 3 课时：笔算减法与验算；第 4 课时：估算与解决问题）

📖 课堂讲义 · 核心知识点

**一、口算整十、整百数的加减法** 口算时把整十、整百数看成几个十、几个百来想。如 50 + 30，想 5 个十加 3 个十是 8 个十，就是 80；700 − 200，想 7 个百减 2 个百是 5 个百，就是 500。两位数加、减两位数口算可用"拆数"法：46 + 25，先算 40 + 20 = 60，再算 6 + 5 = 11，最后 60 + 11 = 71。 **二、笔算加法的计算法则** 1. 相同数位对齐，从个位加起。 2. 哪一位上的数相加满十，就向前一位进 1，进上来的 1 要加到前一位上。 3. 连续进位时，每一步都要先加上进上来的 1，可点小圆点作记号，防止漏加。 **三、笔算减法的计算法则** 1. 相同数位对齐，从个位减起。 2. 哪一位上的数不够减，就从前一位退 1 当 10，加上本位上的数再减。 3. 前一位是 0 时，要再向前一位退位（连续退位），退位后 0 变成 9。 4. 退位处要点上退位点，提醒自己这里退过位。 **四、加减法的验算方法** | 算式 | 验算方法 | 检验标准 | |---|---|---| | 加法 349 + 286 | 交换加数位置再算一遍：286 + 349 | 和不变，计算正确 | | 加法 | 用和减一个加数：635 − 349 | 等于另一个加数，计算正确 | | 减法 900 − 246 | 用差加减数：654 + 246 | 等于被减数，计算正确 | | 减法 | 用被减数减差：900 − 654 | 等于减数，计算正确 | **五、估算** 估算时把每个数看成与它接近的整十、整百数再计算。如估算 397 + 214，把 397 看成 400，214 看成 200，得 400 + 200 = 600，写作 397 + 214 ≈ 600。解决"够不够"的问题时，把数估大一些更保险。 **六、解决问题的一般步骤** 先读题找条件和问题，再想"求什么、用什么方法"，列式计算并写单位、答语，最后检验。求"一共"用加法，求"多多少、少多少、还剩多少"用减法。 **易错提醒** 1. 笔算时数位没对齐，个、十、百位要分别对齐。 2. 进位加法漏加进上来的 1；退位减法忘点退位点，或退位后忘把本位加 10。 3. 被减数中间有 0 时退位出错，如 603 − 297，个位不够减向十位借，十位是 0 要先向百位借。

🔍 课堂讲义 · 重点难点解析

**重点一：连续进位加法** - 例题：计算 586 + 347 = ? - 分析：相同数位对齐，从个位加起，哪一位满十就向前一位进 1。 - 解答：个位 6 + 7 = 13，写 3 进 1；十位 8 + 4 = 12，加进上来的 1 得 13，写 3 进 1；百位 5 + 3 = 8，再加进上来的 1 得 9。结果是 933。验算：347 + 586 = 933，正确。 - 小结：连续进位时每一步都要加上进上来的 1，进位的 1 可以点小圆点作记号，防止漏加。 **重点二：连续退位减法** - 例题：计算 903 − 468 = ? - 分析：个位 3 减 8 不够减，向十位借，十位是 0，要再向百位借。 - 解答：百位退 1 当 10 给十位，十位变 10，个位再向十位借 1 变 13，13 − 8 = 5；十位剩 9，9 − 6 = 3；百位剩 8，8 − 4 = 4。结果是 435。验算：435 + 468 = 903，正确。 - 小结：中间是 0 的退位是难点，记住"0 退 1 变 9"，即借位后十位由 10 变成 9，再往下借。 **难点一：加法的验算** - 例题：小丽算得 482 + 319 = 801，怎样验算她算得对不对？ - 分析：验算加法可以用"和减一个加数"。 - 解答：用 801 − 482 = 319，正好等于另一个加数 319，说明 801 是正确的；也可以交换加数位置再算一遍来检验。 - 小结：加法用减法验算、减法用加法验算，养成"算完就验算"的好习惯。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（连续进位加法）** 笔算：349 + 286。 - 分析：相同数位对齐，从个位加起，哪一位满十向前一位进 1。 - 解答：个位 9 + 6 = 15，写 5 进 1；十位 4 + 8 = 12，加进上来的 1 得 13，写 3 进 1；百位 3 + 2 = 5，加 1 得 6。结果是 635。验算：286 + 349 = 635，正确。 - 方法小结：进位加法"满十进一"，进位的 1 一定要加到前一位上，可以在进位数旁点小圆点提醒自己。 **例题 2（连续退位减法）** 笔算：518 − 349。 - 分析：个位 8 减 9 不够减，向十位借 1，十位是 1，借走后变 0，0 不够减 4，还要再向百位借。 - 解答：个位 18 − 9 = 9；十位 0 减 4 不够减，向百位借 1 当 10，10 − 4 = 6；百位 5 被借走 1 剩 4，4 − 3 = 1。结果是 169。验算：169 + 349 = 518，正确。 - 方法小结：连续退位时从高位一路借下来，借一位就点一个退位点，防止漏退、错退。 **例题 3（估算与解决问题）** 妈妈带 900 元去买两件电器：洗衣机 498 元，电饭煲 395 元，带的钱够吗？ - 分析：求"够不够"，可以先估算：把 498 看成 500，395 看成 400。 - 解答：500 + 400 = 900（元），两个数都估大了才刚好是 900，所以 498 + 395 一定小于 900，够。精确计算验证：498 + 395 = 893（元），893 < 900，确实够。 - 方法小结：解决"够不够"时把数估大一点比较最稳妥；估完后最好再用精确计算验证。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 口算与不进位不退位笔算

  1. 1. 口算：340 + 220 = ；560 − 330 = ；40 + 60 = 。
    答：560、230、100。整十、整百数可以想成几个十、几个百来算。
  2. 2. 用竖式计算：325 + 214 = ；786 − 342 = 。
    答：539；444。注意相同数位对齐，从个位算起。
  3. 3. 判断：笔算加法时，哪一位相加满十，就要向前一位进 1。（ ）
    答：正确。满十进一是加法笔算的基本法则。
  4. 4. 一个加数是 360，另一个加数是 130，和是多少？
    答：360 + 130 = 490。答：和是 490。

中等 · 竖式计算与验算

  1. 1. 用竖式计算并验算：468 + 527 = 。
    答：995。验算：527 + 468 = 995，或 995 − 468 = 527，结果一致，正确。
  2. 2. 用竖式计算并验算：810 − 463 = 。
    答：347。验算：347 + 463 = 810，等于被减数，正确。
  3. 3. 在□里填上合适的数：4□6 + 358 = 804。
    答：□ = 4。个位 6 + 8 = 14，写 4 进 1；十位 □ + 5 + 1 要等于 10 并向前进位，所以 □ = 4；检验：446 + 358 = 804。
  4. 4. 学校图书馆原有图书 620 本，又买来 285 本，现在一共有多少本？
    答：620 + 285 = 905（本）。答：现在一共有 905 本。

难 · 连续进位与连续退位

  1. 1. 用竖式计算：389 + 615 = ；1000 − 356 = 。
    答：389 + 615 = 1004（连续三次进位）；1000 − 356 = 644（连续退位，0 退 1 变 9）。验算：356 + 644 = 1000，正确。
  2. 2. 计算 603 − 297，并说一说个位不够减时是怎样退位的。
    答：603 − 297 = 306。个位 3 减 7 不够减，向十位借，十位是 0，再向百位借 1 当 10 给十位，十位变 10，个位再借 1 变 13，13 − 7 = 6；十位剩 9，9 − 9 = 0；百位剩 5，5 − 2 = 3。结果是 306。
  3. 3. 超市运来苹果 528 箱，梨比苹果少 199 箱，梨有多少箱？两种水果一共有多少箱？
    答：梨：528 − 199 = 329（箱）；一共：528 + 329 = 857（箱）。答：梨有 329 箱，一共有 857 箱。
  4. 4. 一个数减去 456 得 344，这个数是多少？
    答：已知减数和差求被减数，用加法：456 + 344 = 800。答：这个数是 800。

综合 · 生活应用

  1. 1. 三（1）班有男生 27 人、女生 25 人；三（2）班有男生 26 人、女生 28 人。两个班一共有多少人？哪个班人多？多几人？
    答：三（1）班 27 + 25 = 52 人，三（2）班 26 + 28 = 54 人，一共 52 + 54 = 106 人；三（2）班多，多 54 − 52 = 2 人。
  2. 2. 一台电视 1998 元，一辆自行车 468 元。买这两样大约需要多少元？先估一估，再算一算。
    答：估算：1998 ≈ 2000，468 ≈ 500，2000 + 500 = 2500（元），大约需要 2500 元。精确：1998 + 468 = 2466（元）。
  3. 3. 从 356、289、712 三个数中任选两个数求出它们的和与差，再编一道用减法解决的应用题并解答。
    答：示例：356 + 289 = 645，712 − 356 = 356。编题：果园有苹果树 712 棵，梨树 356 棵，苹果树比梨树多多少棵？712 − 356 = 356（棵）。编题合理、解答正确即可。

💬 课后反馈

**学生常见错误** 1. 笔算时数位没有对齐，或"满十进一"后忘记把进上来的 1 加上。 2. 退位减法忘点退位点，或被减数中间是 0 时连续退位出错（如 603 − 297）。 3. 验算方法记混：加法用加法验算、减法用减法验算，使验算失去意义。 4. 解决"够不够"的问题时不会合理估算，把数估小导致判断错误。 **教学改进建议** 1. 用计数器拨珠演示进位、退位的过程，让学生理解"满十进一""退一当十"的算理。 2. 先练"带着进、退位点算"，再逐步放手，每道竖式都要求验算。 3. 每天安排 5 分钟口算训练，提高口算正确率和速度，为笔算打基础。 **分层辅导** - 基础弱：先补两位数加减法的口算和笔算，再过渡到三位数；可用"数位对齐表"辅助对齐。 - 学有余力：增加四位数加减、竖式谜、连加连减等变式题，鼓励一题多解。 **给家长的建议** 购物付款时让孩子参与口算总价、估算够不够、核对找零；在家玩"竖式小医生"游戏，让孩子检查大人故意写错的竖式哪里"生病"了，在游戏中巩固算法。
