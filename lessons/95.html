初中九年级化学《质量守恒定律与化学计算》教案

初中九年级化学质量守恒定律与化学计算

📝 备课方案

**教学目标** 1. 理解质量守恒定律的内容及适用范围（一切化学变化）。 2. 从微观角度解释质量守恒的原因（原子三不变）。 3. 会设计实验验证质量守恒定律，能分析实验误差。 4. 掌握化学方程式的书写步骤与配平方法。 5. 能根据化学方程式进行简单的质量计算。 **教学重点**：质量守恒定律的内容与微观解释；化学方程式的书写与配平；简单计算。 **教学难点**：验证实验的设计与误差分析；配平方法；利用质量守恒定律进行推断计算。 **教学方法**：实验探究、推导分析、分层练习。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、质量守恒定律** - 内容：**参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和**。 - 适用范围：一切**化学变化**（不适用于物理变化）。 - 关键词："参加反应的"——反应物有剩余时，剩余部分不计入；"生成的"——没有参加反应、散逸到空气中的生成物（如气体）也要计入。 **二、质量守恒的微观解释（原子三不变）** - 化学变化的实质：分子破裂成原子，原子重新组合成新的分子。 - 反应前后**原子的种类不变、原子的数目不变、原子的质量不变**——所以参加反应的各物质的质量总和必然等于生成物的质量总和。 - 总结"六个不变、两个一定变"：六个不变——原子的种类、数目、质量，元素的种类、质量，物质的总质量；两个一定变——物质的种类、分子的种类一定改变；可能变——分子的数目可能改变，元素的化合价可能改变。 **三、验证质量守恒定律的实验** - 适用实验（密闭容器或敞口但无气体参与）：红磷燃烧（密闭锥形瓶）、铁钉与硫酸铜溶液反应、碳酸钠与稀盐酸在密闭装置中反应。 - 不适用实验（敞开容器中有气体参与）：碳酸钠与稀盐酸敞口反应（生成的 CO2 逸出，质量减小）；镁条在空气中燃烧（生成的氧化镁质量大于镁条，因为吸收了氧气，且镁也能与氮气反应）。 - 分析要点：若有气体参加或生成，必须用**密闭容器**进行实验，才能保证总质量不变。 **四、化学方程式的书写** - 书写原则：①以**客观事实**为依据，不能臆造化学式；②遵守**质量守恒定律**，各物质化学式前的化 学计量数之和满足反应前后各原子数目相等。 - 书写步骤："**写、配、注、等**"——写出反应物和生成物的化学式、配平、注明反应条件（点燃、加热、高温、催化剂等）和生成物的状态符号（气体"$\uparrow$"、沉淀"$\downarrow$"）、将短线改为等号。 - 配平方法：最小公倍数法（如 $C + O_2 \xrightarrow{点燃} CO_2$ 配平）、观察法（如 $4P + 5O_2 \xrightarrow{点燃} 2P_2O_5$）。 - 配平口诀："配平先找变价，再定系数，原子守衡"。 **五、根据化学方程式的计算** - 解题步骤："**设、写、找、列、解、答**"——设未知量、写出化学方程式、找出已知量和未知量的关系（相关物质的相对分子质量 × 系数）、列比例式、求解、作答。 - 计算依据：化学方程式中各物质之间的**质量比**（相对分子质量 × 化学计量数之比）等于实际质量之比。 - 注意事项：①代入计算的必须是**纯净物**的质量（含杂质要换算）；②相对分子质量要乘以化学计量数；③单位要统一；④气体、液体体积要先换算成质量。

🔍 课堂讲义 · 重点难点解析

**重点一：质量守恒定律中"参加反应"的理解** 定律说的是"参加反应的各物质的质量总和"，不是"反应前所有物质的总质量"。如果反应物有剩余，剩余部分没有参加反应，不能计入；同样，生成物必须是"生成的"，反应前容器中已有的物质不计入。例如 10 g 碳和 20 g 氧气反应，碳不一定用完，计算时要用实际参加反应的量。典型陷阱题：A + B = C + D 中，若有 10 g A 和 5 g B 恰好完全反应生成 3 g C，则生成 D 的质量 = 10 + 5 - 3 = 12 g。判断是否"恰好完全反应"是解题关键。 **重点二：验证实验的误差分析** 红磷燃烧（密闭）：反应生成固体 P2O5，无气体逸出，质量不变，可以验证。镁条燃烧：生成的氧化镁质量大于镁条原质量（吸收了空气中的氧气），学生常误以为"质量不守恒"——其实遵守，只是因为吸收了氧气使反应物总质量增大。碳酸钠 + 稀盐酸敞口：生成 CO2 逸出，总质量减小，不能验证。答题模板：先用定律内容判断，再说明"是否密闭、有无气体逸出或进入"。学生常把"质量守恒"和"天平读数不变"等同，忽视了装置气密性的影响。 **难点：化学方程式计算与配平** 配平要先找"含某元素个数不对称"的化学式，用最小公倍数确定其系数，再逐一配平其他物质。计算题最易出错的地方：①化学方程式没配平或没写条件；②相对分子质量算错或忘乘化学计量数；③把不纯物的质量直接代入；④列比例式时上下单位不统一。计算格式要按"设、写、找、列、解、答"六步完整书写，每一步都要规范，防止过程分丢失。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：10 g 氢气和 80 g 氧气混合点燃，恰好完全反应生成多少克水？ 解析：化学方程式 $2H_2 + O_2 \xrightarrow{点燃} 2H_2O$。恰好完全反应，说明氢气和氧气都无剩余。相对质量：$2 \times 2 = 4$（H2），$32$（O2），$2 \times 18 = 36$（H2O）。生成水的质量 = 10 + 80 = 90 g（质量守恒定律：参加反应的两物质质量总和等于生成物质量）。也可列比例式验证：$\\frac{4}{10} = \\frac{36}{x}$，$x = 90$ g。 关键：恰好完全反应时，生成物质量 = 各反应物质量之和，直接用质量守恒定律最简。 **例 2**：在反应 A + 2B = 2C + D 中，若 14 g A 与足量 B 完全反应生成 22 g C 和 4 g D，求参加反应的 B 的质量。 解析：根据质量守恒定律，参加反应的 A 与 B 的质量总和 = 生成的 C 与 D 的质量总和。设参加反应的 B 的质量为 x，则 14 + x = 22 + 4，解得 x = 12 g。参加反应的 B 的质量为 12 g。 关键：质量守恒定律的简单应用——"反应物总质量 = 生成物总质量"，设未知数列方程。 **例 3**：实验室用高锰酸钾制取氧气，若要得到 3.2 g 氧气，需要高锰酸钾的质量是多少？ 解析：化学方程式 $2KMnO_4 \xrightarrow{\Delta} K_2MnO_4 + MnO_2 + O_2 \uparrow$。相对质量：$2 \times 158 = 316$（KMnO4），$32$（O2）。设需 KMnO4 质量为 x，列比例式：$\\frac{316}{x} = \\frac{32}{3.2}$，解得 $x = 31.6$ g。答：需要高锰酸钾 31.6 g。 关键：代入纯物质质量，相对分子质量乘系数，比例式上下对应、单位统一。 **例 4**：某化合物在氧气中充分燃烧只生成二氧化碳和水。已知该化合物中只含碳、氢元素，且生成 8.8 g CO2 和 3.6 g H2O。求该化合物中碳、氢元素的质量比。 解析：8.8 g CO2 中碳元素质量 = $8.8 \times \\frac{12}{44} = 2.4$ g；3.6 g H2O 中氢元素质量 = $3.6 \times \\frac{2}{18} = 0.4$ g。化合物中碳、氢元素质量比 = 2.4 : 0.4 = 6 : 1。因为反应前后元素种类和质量都不变，生成物中的碳、氢元素全部来自该化合物。 关键：元素质量 = 化合物质量 × 元素质量分数；利用"元素守恒"推断元素组成及比例。 **例 5**：某含杂质 5% 的石灰石样品 100 g（杂质不参与反应），高温煅烧后求可生成 CO2 的质量。 解析：纯 CaCO3 质量 = 100 × (1 − 5%) = 95 g。方程式 $CaCO_3 \xrightarrow{高温} CaO + CO_2 \uparrow$，相对质量 100（CaCO3）、44（CO2）。设生成 CO2 质量为 x，列比例：$\\frac{100}{95} = \\frac{44}{x}$，解得 $x = 41.8$ g。 关键：计算前必须把含杂质的样品质量换算成纯净物质量，杂质质量 = 样品质量 × 杂质质量分数。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 定律内容与微观解释

  1. 1. 质量守恒定律的内容是什么？它的适用范围是什么？
    答：质量守恒定律：参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和。适用范围是一切化学变化（化学反应），不适用于物理变化。注意"参加反应的"这一限定——反应物若有剩余，剩余部分不能计入；同时反应前容器中已有的非生成物也不能计入。
  2. 2. 为什么化学反应遵守质量守恒定律？请从微观角度解释。
    答：因为化学变化的实质是分子破裂成原子，原子重新组合成新的分子。在化学变化中，原子的种类不变、原子的数目不变、原子的质量不变（原子三不变），因此反应前后各原子的总质量不变，参加反应的各物质的质量总和就等于生成物的质量总和。分子种类一定改变，但原子只是重新组合，没有增减。
  3. 3. 根据质量守恒定律，"6 个不变、2 个一定变"分别指什么？
    答：六个不变：①原子的种类、②原子的数目、③原子的质量、④元素的种类、⑤元素的质量、⑥物质的总质量都不变。两个一定变：①物质的种类（宏观上反应物变为生成物）一定改变；②分子的种类一定改变。可能变：分子的数目可能改变（如反应前后分子总数可能不同），元素的化合价可能改变。

中等 · 验证实验与分析

  1. 1. 为什么镁条在空气中燃烧后，生成的氧化镁质量大于镁条的质量？该实验能否验证质量守恒定律？
    答：镁条燃烧是镁与空气中的氧气（还有少量氮气）反应生成氧化镁：$2Mg + O_2 \xrightarrow{点燃} 2MgO$。反应中参加反应的氧气质量也计入，所以生成的氧化镁质量 = 镁条质量 + 参加反应的氧气质量，大于镁条原质量。该反应遵守质量守恒定律，但在敞口容器中由于吸收了空气中的氧气，天平读数会增大，不能用来验证"反应前后总质量不变"，验证时需在密闭容器中进行。
  2. 2. 某同学在敞口容器中将碳酸钠与稀盐酸混合，发现天平读数减小。这是否说明质量不守恒？为什么？
    答：不说明质量不守恒。因为碳酸钠与稀盐酸反应生成氯化钠、水和二氧化碳：$Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow$，生成的二氧化碳气体逸散到空气中，使容器内剩余物质的总质量减小。若在密闭容器中反应，CO2 不能逸出，天平读数不变。所以验证质量守恒定律时，凡有气体参加或生成的反应，都必须在密闭容器中进行。
  3. 3. 红磷在密闭锥形瓶中燃烧，反应前后锥形瓶及其中物质的总质量不变。请解释原因。
    答：红磷在密闭锥形瓶中燃烧：$4P + 5O_2 \xrightarrow{点燃} 2P_2O_5$。反应中磷与氧气都是密闭瓶内的物质，生成物五氧化二磷是固体，仍留在瓶内，没有气体进入也没有气体逸出。反应前后原子的种类、数目、质量不变，物质总质量不变，所以锥形瓶及其中物质的总质量不变。该实验能在密闭容器中验证质量守恒定律。

难 · 推断与计算

  1. 1. 在反应 2A + B = 2C 中，若 6 g A 与足量 B 完全反应生成 22 g C，求参加反应的 B 的质量。
    答：根据质量守恒定律，参加反应的 A 与 B 的质量总和等于生成的 C 的质量。设参加反应的 B 的质量为 x，则 6 + x = 22，解得 x = 16 g。所以参加反应的 B 的质量为 16 g。此题只用到质量守恒定律的简单应用，不需要配平后的相对分子质量关系（本题中 C 的质量与 A、B 之和相等是定律的直接结论）。
  2. 2. 某有机物在氧气中完全燃烧生成 8.8 g 二氧化碳和 5.4 g 水。①该有机物中一定含有哪些元素？②求该有机物中碳、氢元素的质量比。③判断该有机物中是否含有氧元素并说明理由。
    答：①一定含有碳元素和氢元素。②8.8 g CO2 中碳元素质量 = $8.8 \times \\frac{12}{44} = 2.4$ g；5.4 g H2O 中氢元素质量 = $5.4 \times \\frac{2}{18} = 0.6$ g，碳氢质量比 = 2.4 : 0.6 = 4 : 1。③需要判断：生成物中氧元素总质量 = 8.8 − 2.4 + 5.4 − 0.6 = 6.4 + 4.8 = 11.2 g，这部分氧可能全部来自氧气，也可能一部分来自有机物。仅凭生成物质量无法判断，必须知道消耗的氧气质量：若有机物质量 + 消耗氧气质量 = 11.2 g 则不含氧；若有机物质量大于（有机物+氧气生成物总氧减）等，则含氧。本题未给氧气质量，所以只能判断一定含 C、H，是否含 O 需补充氧气质量数据。

综合 · 化学方程式计算

  1. 1. 实验室用 15.8 g 高锰酸钾加热制取氧气，充分反应后，求生成氧气的质量。（相对原子质量：K=39，Mn=55，O=16）
    答：解：设生成氧气的质量为 x。化学方程式 $2KMnO_4 \xrightarrow{\Delta} K_2MnO_4 + MnO_2 + O_2 \uparrow$。KMnO4 相对分子质量 = 39 + 55 + 4×16 = 158；2 个 KMnO4 的相对质量 = 2 × 158 = 316；O2 相对分子质量 = 2×16 = 32。列比例式：$\\frac{316}{15.8} = \\frac{32}{x}$，解得 $x = \\frac{15.8 \times 32}{316} = 1.6$ g。答：生成氧气 1.6 g。
  2. 2. 含杂质 10% 的石灰石样品 50 g 高温煅烧（杂质不反应），求最多可制得氧化钙和二氧化碳各多少克。（相对原子质量：Ca=40，C=12，O=16）
    答：解：纯 CaCO3 质量 = 50 × (1 − 10%) = 45 g。设生成 CaO 质量为 x、CO2 质量为 y。方程式 $CaCO_3 \xrightarrow{高温} CaO + CO_2 \uparrow$，CaCO3 相对分子质量 = 40 + 12 + 48 = 100，CaO = 56，CO2 = 44。列比例：$\\frac{100}{45} = \\frac{56}{x}$，$x = 25.2$ g；$\\frac{100}{45} = \\frac{44}{y}$，$y = 19.8$ g。答：可制得 CaO 25.2 g、CO2 19.8 g。（也可用质量守恒验证：45 = 25.2 + 19.8。）

💬 课后反馈

本课是九年级化学计算的奠基章。常见错误：把"参加反应的质量"与"反应前质量"混为一谈；忽略密闭容器要求；配平后忘写反应条件；相对分子质量忘乘化学计量数；把含杂质样品的质量直接代入计算。建议分层训练：先练"已知一种反应物求生成物"，再练"含杂质换算"和"元素守恒推断"，每个计算题都按"设、写、找、列、解、答"六步规范书写。中考计算题常考含杂质和质量守恒推断，务必让学生养成先换算纯量再代入的习惯。
