小学一年级语文《拼音：声母》教案

小学一年级语文拼音：声母

📝 备课方案

**教学目标** 1. 能正确认读 23 个声母，读准音、认清形、记牢序，能按顺序背诵并默写声母表。 2. 能区分形近声母 b 和 d、p 和 q、n 和 l，分清平舌音 z、c、s 与翘舌音 zh、ch、sh，读准字音。 3. 掌握两拼音节的拼读方法，能正确拼读声母和单韵母组成的音节，做到"前音轻短后音重，两音相连猛一碰"。 4. 掌握声母在四线格中的占格位置和书写笔顺，把字写得规范、端正、整洁，并在趣味活动中体验拼音学习的快乐。 **教学重点**：23 个声母的正确认读、按序记忆和两拼音节的拼读。 **教学难点**：形近声母 b、d、p、q 的辨析；平舌音与翘舌音的发音区别。 **教学方法**：口诀记忆法、对比辨析法、游戏教学法、直观演示法。 **教学准备**：拼音卡片、四线格小黑板、拼音转盘、儿歌节奏图、奖励贴纸、多媒体课件。 **课时安排**：2 课时（第 1 课时：认读声母、辨析易混声母；第 2 课时：两拼音节拼读与书写训练）。

📖 课堂讲义 · 核心知识点

**一、声母大家庭：23 个声母排好队** 声母是音节开头的字母，一共有 23 个。按顺序是： b、p、m、f、d、t、n、l、g、k、h、j、q、x、zh、ch、sh、r、z、c、s、y、w。 为了记牢顺序，可以把它们分成 7 个小组，一组一组背： | 组别 | 声母 | 图形口诀 | |---|---|---| | 1 | b p m f | 右下半圆 b b b，右上半圆 p p p，两个门洞 m m m，一根拐棍 f f f | | 2 | d t n l | 左下半圆 d d d，像个伞把 t t t，一个门洞 n n n，一根小棍 l l l | | 3 | g k h | 鸽子衔枝 g g g，蝌蚪水草 k k k，把水喝下 h h h | | 4 | j q x | 鸡捉蝴蝶 j j j，九个气球 q q q，刀切西瓜 x x x | | 5 | zh ch sh r | 织毛衣 zh zh zh，吃野果 ch ch ch，小狮子 sh sh sh，日头照 r r r | | 6 | z c s | 像个 2 字 z z z，刺猬拱土 c c c，半个 8 字 s s s | | 7 | y w | 像个树杈 y y y，屋顶相连 w w w | **二、易混声母找不同** | 易混声母 | 分辨方法 | |---|---| | b 和 d | 看半圆在哪边：半圆在右下是 b，半圆在左下是 d。口诀"右下半圆 b b b，左下半圆 d d d" | | p 和 q | 看半圆在哪边：半圆在右上是 p，半圆在左上是 q。q 的样子和数字 9 很像 | | n 和 l | 一个门洞 n n n，一根小棍 l l l。n 有弯弯的门洞，l 是直直的小棍 | | f 和 t | f 像一根拐棍，竖的顶端向右弯一弯；t 的竖是直直的，像一把伞的伞把 | | z c s 和 zh ch sh | 平舌音舌尖放平，抵住或接近上齿背；翘舌音舌尖翘起，对着上腭前部。口诀"z c s 舌放平，zh ch sh 舌头翘" | **三、两拼音节：两音相连猛一碰** 声母和韵母拼在一起读，就是两拼音节。拼读口诀：**前音轻短后音重，两音相连猛一碰**。 - 前音（声母）读得又轻又短，一带而过；后音（韵母）读得响亮饱满。 - 例如：b-a→ba（八），m-o→mo（摸），d-i→di（滴），t-u→tu（兔），n-ü→nü（女）。 - "碰碰车"练法：把声母当小车头，韵母当车厢，车头轻快一带，"猛一碰"就挂上车厢，读成一个音节。 - 注意：拼读时声母不要拖长读"重"了，比如 b 不要读成 bo，要轻短地带过再碰韵母。 **四、声母的书写占格** 拼音格是四线三格：从上往下依次叫上格、中格、下格。书写口诀："四线三格记心间，中格写满不出线，上格下格留空间。" | 占格 | 声母 | 书写要点 | |---|---|---| | 只占中格 | m、n、r、x、z、c、w | 把中格写满，不碰上下线 | | 占上格和中格 | b、d、f、h、k、l、t | 竖要写直，上格不顶第一线 | | 占中格和下格 | p、q、y、g | 竖或尾巴伸到下格，不碰第四线 | | 占上、中、下三格 | j | 点写在上面，竖弯钩伸到下格 | zh、ch、sh 由 z、c、s（占中格）和 h（占上中格）组成，书写时两部分要靠拢，不分家。 **五、趣味拼读游戏** 1. 卡片抽读：同桌一人举卡，一人快读，读对得一颗星。 2. 拼音转盘：转动转盘，把指针指到的声母和韵母拼成音节读出来。 3. 找朋友：声母卡找韵母卡，碰上就读，读对了就"牵手"。 4. 生活小侦探：认读包装袋、招牌、课本封面上的音节，拼对了就是"拼音小侦探"。 **易错提醒** 1. b、d、p、q 四兄弟认反：记牢"半圆朝哪边、偏上还是偏下"。 2. 平舌音、翘舌音读混：发音时想口诀，舌头位置摆对。 3. 默写声母表漏掉 y、w，或把 zh、ch、sh 写成 z、c、s。 4. 书写占格错位：把 p 写到上格、把 b 的竖写短，中格要写满、不顶线。

🔍 课堂讲义 · 重点难点解析

**重点一：按顺序记牢 23 个声母** 例题：老师打乱顺序出示卡片 b、zh、m、y、s，请你快速认读，并说出它在声母表中的后一个声母是什么。 分析：认读要又快又准，关键是记住声母表的固定顺序，把 23 个声母分成 7 个小组记。 解答：b 是第一个，后一个是 p；zh 的后一个是 ch；m 的后一个是 f；y 的后一个是 w；s 的后一个是 y。 小结：分小组背（b p m f 一组、d t n l 一组……），每天按顺序齐读两遍、打乱抽读三遍，顺序就记牢了。 **难点一：辨析 b 和 d、p 和 q** 例题：判断下面说法对不对，错的改过来："半圆在左下方的声母是 b。" 分析：先想口诀"右下半圆 b b b，左下半圆 d d d"，再看说法里半圆的位置。 解答：不对。半圆在右下才是 b，半圆在左下是 d。 小结：辨析 b、d、p、q 只抓两点——半圆朝哪边、偏上还是偏下。半圆朝右是 b 和 p，朝左是 d 和 q；再看位置：右下 b、右上 p，左下 d、左上 q。 **难点二：读准平舌音和翘舌音** 例题：把 z、c、s、zh、ch、sh 分成两类，说说每类发音时舌尖的位置。 分析：它们字形相近，区别就在发音时舌尖是平的还是翘的。 解答：z、c、s 是平舌音，舌尖放平，抵住或接近上齿背；zh、ch、sh 是翘舌音，舌尖向上翘，对着上腭前部。 小结：照着镜子练发音，看得到舌尖放平、翘起，就知道读得对不对。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：打乱顺序认读声母** 题目：认读卡片：f、b、n、sh、q、y、c、g。读出字母，并说出它的形状口诀。 分析：先看清字形（半圆、门洞、小棍、树杈），再想对应的口诀，最后读准音。 解答：f——一根拐棍 f f f；b——右下半圆 b b b；n——一个门洞 n n n；sh——翘舌音，舌头翘起来；q——左上半圆 q q q；y——像个树杈 y y y；c——刺猬拱土 c c c；g——鸽子衔枝 g g g。 方法小结：看形想口诀，口诀帮记音，认读又准又快。 **例题二（提高）：拼读两拼音节** 题目：拼一拼，读一读：b-a→（ ），m-o→（ ），d-i→（ ），t-u→（ ）。 分析：用口诀"前音轻短后音重，两音相连猛一碰"：声母轻短带过，韵母响亮读出，中间不停顿。 解答：b-a→ba，m-o→mo，d-i→di，t-u→tu。 方法小结：先摆好声母的口形，再一口气滑到韵母，两音碰成一个音节。 **例题三（综合）：生活中的拼读** 题目：卡片上写着 bà ba、mā ma。拼一拼这些音节，再说说卡片上写的是谁。 分析：把每个音节拆成声母和韵母来拼：b-a 拼出 ba，m-a 拼出 ma，然后连词读一读。 解答：b-a→bà、b-a→ba，合起来是"爸爸"；m-a→mā、m-a→ma，合起来是"妈妈"。 方法小结：词语里有几个音节就拼几次，拼完连起来读，就是词语的读音。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 认一认、写一写

  1. 1. 按顺序填一填：b、（ ）、（ ）、f、d、（ ）、（ ）、l。
    答：依次填 p、m、t、n。即 b、p、m、f、d、t、n、l。可边写边念口诀：右下半圆 b，右上半圆 p，两个门洞 m，一根拐棍 f，左下半圆 d，像个伞把 t，一个门洞 n，一根小棍 l。
  2. 2. 填口诀：右下半圆（ ），左下半圆（ ），右上半圆（ ），左上半圆（ ）。
    答：依次是 b、d、p、q。记住：半圆朝右是 b 和 p，朝左是 d 和 q；再分位置，下为 b 和 d，上为 p 和 q。
  3. 3. 拼一拼，读三遍：b-a→（ ）、p-o→（ ）、m-i→（ ）、f-u→（ ）。
    答：b-a→ba，p-o→po，m-i→mi，f-u→fu。拼读时声母读得轻而短，韵母读得响亮，两音相连猛一碰。

中等 · 辨一辨、分一分

  1. 1. 把下面的声母分成两类：z、zh、c、ch、s、sh、r。
    答：平舌音一组：z、c、s；翘舌音一组：zh、ch、sh、r。注意 r 也是翘舌音，舌尖要翘起来。
  2. 2. 圈出下面音节里的声母：bà、mō、dì、tù、lǜ。
    答：声母依次是 b、m、d、t、l。音节开头的字母是声母，后面的 a、o、i、u、ü 是韵母。
  3. 3. 判断对错，错的改正："左上半圆 q q q""一个门洞 l l l"。
    答：第一句对，q 是左上半圆；第二句错，一个门洞是 n，l 是一根小棍。

难 · 易混声母大挑战

  1. 1. 同桌互考：一人打乱举出 b、d、p、q 四张卡片，另一人快速认读，全对得一颗星；轮流三次，记录成绩。
    答：操作要点：读卡前先看半圆朝向和位置——右下 b、右上 p、左下 d、左上 q。互考三组，读错的字母当场用口诀正音，再多读五遍。
  2. 2. 照样子写出占格相同的声母：占上格和中格的：b、d、（ ）、（ ）、（ ）；占中格和下格的：p、（ ）、（ ）、（ ）。
    答：占上中格的还有 f、h、k、l、t（写出其中三个即可）；占中下格的还有 q、y、g。书写时记住：中格写满不出线，上格下格留空间。
  3. 3. 拼一拼，把音节送回家：zì、zhǐ、sì、shì、cè、chē。平舌家（声母是 z、c、s）和翘舌家（声母是 zh、ch、sh、r）各收哪些？
    答：平舌家：zì、sì、cè；翘舌家：zhǐ、shì、chē。先看音节开头的声母是平舌还是翘舌，再送进对应的家。

综合 · 生活中的拼音

  1. 1. 拼读小卡片：bà ba（爸爸）、mā ma（妈妈）、gē ge（哥哥）、dì di（弟弟）。拼一拼，读给家人听，说说这些都是谁。
    答：b-a→bà、b-a→ba 是爸爸；m-a→mā、m-a→ma 是妈妈；g-e→gē、g-e→ge 是哥哥；d-i→dì、d-i→di 是弟弟。几个音节拼完连起来读，就是词语。
  2. 2. 和家人玩"转转盘"游戏：盘边写 b、p、m、f、d、t，中间写 a、o、i、u。指针转到哪两个字母，就快速拼成音节读出来，读对得 1 分，比比谁先得 5 分。
    答：游戏要点：先读声母（轻短），再碰韵母（响亮），连成一个音节。如 b 和 u 碰出 bu，t 和 i 碰出 ti，m 和 a 碰出 ma。读错了互相纠正，再继续。
  3. 3. 拼音小侦探：在商品包装、招牌或课外书上找一找认识的声母，圈出三个，读给家人听，并说说它住在拼音格的哪几格里。
    答：示例：在包装上找到 m（只占中格）、b（占上格和中格）、p（占中格和下格）。说占格时记住口诀：中格写满不出线，上格下格留空间。

💬 课后反馈

**学生常见错误** 1. b、d、p、q 认反、写反：默写时把 b 写成 d，根源是没有形成"先看半圆朝向"的观察习惯。 2. 平舌音、翘舌音读混：受方言影响，把翘舌读成平舌、把平舌读成翘舌，需要反复正音。 3. 默写声母表顺序错乱：背到 d t n l 之后容易跳组，漏掉 g k h 或 y、w。 4. 拼读"卡壳"：声母读得太重太长，和韵母"断开"拼不成音节；或书写时占格错位，把 p 写到上格。 **教学改进建议** 1. 坚持每天 5 分钟卡片抽读，重点盯 b、d、p、q 和平翘舌音，读错当场用口诀正音。 2. 把辨析变成手脑记忆：边书空边说口诀，手、口、脑同步，写一遍胜过看十遍。 3. 拼读教学"先慢后快"：先一个音节一个音节示范"声母轻短＋韵母响亮"，再连读提速，不抢进度。 **分层辅导建议** - 基础层：只要求按顺序认读 23 个声母，借助口诀卡片逐个过关。 - 提高层：b、d、p、q 打乱抽读全部正确，能独立拼读常见两拼音节。 - 拓展层：尝试拼读简单儿歌中的音节，当"小老师"帮同学正音。 **给家长的建议** 1. 用卡片和孩子玩"抽读闯关"，每天 5 分钟，全对就给一个小奖励，让孩子在游戏中巩固。 2. 生活中随机练：看到包装上的拼音让孩子拼一拼；孩子读错时不批评，提醒口诀让他自己改正。
