初中九年级物理《磁现象 磁场》教案

初中九年级物理磁现象 磁场

📝 备课方案

**教材分析** 本节是人教版《物理》九年级全一册第二十章第一节，内容包括磁现象（磁性、磁体、磁极、磁化）、磁场与磁感线、地磁场，是电与磁板块的起始课，为后续电生磁、电磁铁、电动机、发电机奠定基础。 **教学目标** 1. 知道磁性、磁体、磁极、磁化等现象，掌握磁极间相互作用规律。 2. 知道磁体周围存在磁场，知道磁场方向的规定，会用小磁针判断磁场方向。 3. 知道磁感线可形象描述磁场，会画条形磁体的磁感线，理解疏密表示强弱。 4. 了解地磁场与磁偏角，知道我国宋代沈括最早记述磁偏角。 **教学重点** 磁极作用规律；磁场方向的规定；磁感线的分布特点。 **教学难点** 磁场真实存在而磁感线是假想模型；地磁南北极与地理南北极的区别。 **课时** 1 课时 **教学过程** 磁现象展示→磁体磁极磁化→磁极作用规律→磁场方向探测→磁感线建模→地磁场。

📖 课堂讲义 · 核心知识点

**一、磁现象** - 磁性：物体吸引铁、钴、镍等物质的性质；具有磁性的物体叫磁体。 - 磁极：磁体两端磁性最强的部分。每个磁体都有 N（北）、S（南）两极；自由转动的小磁针静止时指南的一端为 S 极，指北的一端为 N 极。 - 磁极作用规律：同名磁极相互排斥，异名磁极相互吸引。 - 磁化：原来没有磁性的物体在磁体或电流作用下获得磁性的过程。软铁易磁化也易失磁，钢磁化后磁性可保持。 - 应用辨析：磁体两端磁性最强、中间最弱，指南针（司南）利用磁体指南北的性质指示方向，这两点常是鉴别磁性与解释定向问题的依据。 **二、磁场** - 磁体周围存在看不见、摸不着但真实存在的特殊物质——磁场；磁场对放入其中的磁体产生力的作用。 - 磁场方向：小磁针静止时北极所指方向即该点磁场方向（也是小磁针 N 极受力方向）。 - 磁体间作用通过磁场发生，不接触也能施力。 **三、磁感线** - 为形象描述磁场而假想出来的曲线（实际不存在）；磁感线上某点切线方向与该点磁场方向一致。 - 磁体外部磁感线从 N 极出发回到 S 极；疏密表示强弱，越密磁场越强；任意两条磁感线不相交。 **四、地磁场** - 地球是个大磁体，周围存在地磁场；地磁北极在地理南极附近，地磁南极在地理北极附近。 - 地磁南北极与地理南北极不重合，夹角叫磁偏角，我国宋代沈括最早记述。 - 指南针指南北，是受地磁场作用。

🔍 课堂讲义 · 重点难点解析

**难点一：磁场真实存在，磁感线只是模型** 磁场客观存在，依据是它对磁体有力的作用、能被小磁针感知；磁感线只是描述磁场的假想曲线，并不存在。类比：风看不见，可通过树叶摇动感知；磁场看不见，可通过小磁针偏转感知。 **难点二：方向"三统一"** 某点磁场方向＝该点小磁针 N 极指向＝过该点磁感线的切线方向。做题时先由磁体 N、S 极确定磁感线方向（外部 N→S），再推小磁针指向。 **难点三：地磁极与地理极相反** 地磁北极在地理南极附近、地磁南极在地理北极附近。指南针 N 极指北，是被地理北极附近的地磁 S 极吸引（异名相吸）。 **常见失误** 1. 误以为磁感线真实存在。 2. 磁感线方向画反（外部应 N→S）。 3. 把地磁北极标在地理北极附近。

✏️ 课堂讲义 · 典型例题精讲

**例1（磁性判断）** 钢棒靠近小磁针 N 极被吸引，能否断定钢棒有磁性？ 解析：不能。磁体能吸铁磁性材料，无磁性钢棒也会被吸引；只有表现为排斥时才能断定钢棒有磁性——同名相斥只发生在两磁体之间。 **例2（磁场方向）** 怎样确定磁场中某点的磁场方向？ 解析：在该点放一小磁针，静止时 N 极所指方向即该点磁场方向；也可由磁感线判断：磁体外部从 N 到 S，该点切向即磁场方向。 **例3（磁感线）** 条形磁体磁感线如何分布？怎样从图上看磁场强弱？ 解析：外部磁感线从 N 极出发回到 S 极，两极附近最密、磁场最强，离磁体越远越疏越弱；磁感线不相交。 **例4（地磁场）** 指南针为什么总是一端指南、一端指北？ 解析：地球周围存在地磁场，地磁南极在地理北极附近。指南针 N 极受地磁 S 极吸引指向地理北方，S 极指向地理南方。磁偏角说明地磁极与地理极不重合。 **例5（磁极性质）** 把条形磁铁断成两段，每一段还有 N、S 两极吗？为什么？ 解析：有。任何磁体都同时具有两个磁极，把一个磁体分成任意多段，每一小段两端依然是 N、S 两极，自然界不存在只有一个磁极的磁体；断口两端为异名磁极，靠近时相互吸引。关键：磁极总是成对存在。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 什么叫磁性、磁体、磁极？
    答：物体能吸引铁、钴、镍等物质的性质叫磁性；具有磁性的物体叫磁体；磁体两端磁性最强的部分叫磁极，分 N、S 两极。
  2. 2. 磁极间相互作用规律是什么？
    答：同名磁极相互排斥，异名磁极相互吸引。

中等 · 辨析理解

  1. 1. 两个磁体靠近相互吸引，能否断定是异名磁极？为什么？
    答：不能。吸引可能是异名磁极相吸，也可能是磁极吸引铁磁性材料（磁化后被吸引）。要断定二者都是磁体，须观察到排斥现象。
  2. 2. 什么叫磁化？举一个磁化应用的例子。
    答：使原来没有磁性的物体获得磁性的过程叫磁化。如钢针在磁体上沿同一方向摩擦后可吸起小铁屑（制成磁针）；软铁易磁化也易失磁，钢可长期保持磁性。

难 · 模型运用

  1. 1. 磁感线是真实存在的吗？它的切线方向与疏密各表示什么？
    答：磁感线是假想模型，实际不存在。切线方向表示该点磁场方向；疏密表示强弱，越密磁场越强。外部磁感线从 N 到 S，任意两条不相交。
  2. 2. 地磁北极在哪里？指南针为什么能指南北？
    答：地磁北极在地理南极附近。指南针受地磁场作用，N 极被地磁 S 极吸引指向地理北方，故能指示南北；地磁极与地理极不重合，存在磁偏角。

综合 · 探究实验

  1. 1. 两根外形相同的钢棒一有磁性一无磁性，不借助其他器材如何鉴别？
    答：用甲棒一端接触乙棒中部：磁体中部磁性最弱。若甲端能明显吸住乙中部，说明甲有磁性（其端部磁性强）；若吸不住，则甲无磁性、乙有磁性，可用乙端靠近甲中部验证。
  2. 2. 条形磁铁摔成两段，每段还有两个磁极吗？为什么？
    答：有。每段仍是独立磁体，两端各有 N、S 极——磁极总是成对存在，自然界没有单极磁体，断口处靠近会相吸（为异名磁极）。

💬 课后反馈

本课核心是建立磁场概念、用磁感线描述磁场。学生易错：以为磁感线真实存在；外部磁感线方向标反；地磁两极与地理两极混淆。建议用铁粉或小磁针阵列演示磁场分布，反复强化"磁场方向＝小磁针 N 极指向＝磁感线切线方向"，结合司南与沈括故事渗透科学史。
