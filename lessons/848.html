高中高二生物《DNA 是主要的遗传物质》教案

高中高二生物DNA 是主要的遗传物质

📝 备课方案

**教学目标** 1. 概述人类对遗传物质的探索过程，说出肺炎双球菌转化实验（格里菲思体内转化、艾弗里体外转化）与噬菌体侵染细菌实验（赫尔希与蔡斯）的实验思路、方法、结果与结论。 2. 尝试进行 DNA 的粗提取与鉴定，说出实验原理与操作要点，能用二苯胺试剂检测 DNA。 3. 概述 DNA 分子双螺旋结构的主要特点，阐明碱基互补配对原则，能进行简单的碱基比例计算。 4. 认同"实验证据是科学结论的前提"，体会科学家的探究精神与严谨的实验设计思路。 **教学重点**：肺炎双球菌转化实验和噬菌体侵染细菌实验的过程与结论；DNA 双螺旋结构要点与碱基互补配对原则。 **教学难点**：艾弗里体外转化实验的变量控制思路；噬菌体侵染实验中放射性标记技术的原理与误差分析；碱基比例的计算规律。 **教学方法**：科学史探究法、问题引导法、小组讨论法、实验演示法。 **教学准备**：科学史资料卡片、实验流程动画课件、DNA 双螺旋结构模型、DNA 粗提取实验器材（鸡血细胞液、2 mol/L NaCl 溶液、二苯胺试剂、酒精等）。 **课时安排**：3 课时（第 1 课时：肺炎双球菌转化实验；第 2 课时：噬菌体侵染实验与 DNA 粗提取鉴定；第 3 课时：DNA 双螺旋结构与碱基计算）。

📖 课堂讲义 · 核心知识点

**一、对遗传物质的早期推测** 20 世纪 30 年代以前，人们认为蛋白质是遗传物质，理由：蛋白质由 20 种氨基酸组成，结构多样，似乎能储存丰富信息；而 DNA 只含 4 种脱氧核苷酸，被认为过于单调。结论必须依靠实验证据来检验。 **二、肺炎双球菌转化实验** 肺炎双球菌有两种类型：S 型细菌菌落光滑、有荚膜、有毒性；R 型细菌菌落粗糙、无荚膜、无毒性。 1. 格里菲思的体内转化实验（1928 年）： | 组别 | 处理 | 小鼠结果 | |---|---|---| | 第 1 组 | 注射 R 型活细菌 | 不死亡 | | 第 2 组 | 注射 S 型活细菌 | 死亡（分离出活的 S 型菌） | | 第 3 组 | 注射加热杀死的 S 型细菌 | 不死亡 | | 第 4 组 | 注射 R 型活细菌 + 加热杀死的 S 型细菌 | 死亡（分离出活的 S 型菌） | 结论：加热杀死的 S 型细菌中含有某种"转化因子"，能把 R 型活细菌转化为 S 型活细菌。 2. 艾弗里的体外转化实验（1944 年）：将 S 型细菌的 DNA、蛋白质、多糖等物质分离提纯，分别加入 R 型活细菌培养液中。只有加入 DNA 的组出现了 S 型活细菌；若加入 DNA 的同时加入 DNA 酶，DNA 被水解，则不出现转化。 结论：DNA 才是使 R 型细菌产生稳定遗传变化的物质，即 DNA 是转化因子，是遗传物质。蛋白质等物质不是遗传物质。 **变量控制思想**：自变量是加入物质的种类，因变量是 R 型细菌是否转化为 S 型细菌，DNA 酶处理组是重要的对照。 **三、噬菌体侵染细菌实验（赫尔希与蔡斯，1952 年）** T2 噬菌体由 DNA 和蛋白质组成，侵染大肠杆菌时只把 DNA 注入细菌体内。 1. 标记方法：因蛋白质含 S 而不含 P，DNA 含 P 而不含 S，故分别用 35S 标记蛋白质、32P 标记 DNA。方法是先用含放射性同位素的培养基培养大肠杆菌，再用噬菌体侵染这些细菌，得到标记的噬菌体。 2. 结果： | 组别 | 标记对象 | 搅拌离心后放射性分布 | |---|---|---| | 35S 组 | 蛋白质外壳 | 放射性主要在上清液 | | 32P 组 | DNA | 放射性主要在沉淀物 | 结论：噬菌体侵染细菌时，DNA 进入细菌并指导子代噬菌体的合成，蛋白质外壳留在外面。由此证明 DNA 是遗传物质。此实验不能证明蛋白质不是遗传物质（蛋白质未进入细菌，未参与对照检验）。 **四、RNA 病毒的遗传物质** 烟草花叶病毒等 RNA 病毒不含 DNA，其遗传物质是 RNA。因此总结：**细胞生物的遗传物质都是 DNA，DNA 病毒的遗传物质是 DNA，RNA 病毒的遗传物质是 RNA。由于绝大多数生物的遗传物质是 DNA，所以说 DNA 是主要的遗传物质。** **五、DNA 的粗提取与鉴定** 1. 材料选择：选用鸡血细胞液（鸡的红细胞有细胞核、含 DNA 丰富）；哺乳动物成熟的红细胞无细胞核，不能作为材料。 2. 原理：DNA 在 2 mol/L NaCl 溶液中溶解度较大，在 0.14 mol/L NaCl 溶液中溶解度最低；DNA 不溶于酒精溶液；二苯胺试剂在沸水浴条件下与 DNA 反应变蓝色。 3. 主要步骤：加蒸馏水破碎细胞释放核物质 → 过滤取滤液 → 加 2 mol/L NaCl 溶解 DNA → 加蒸馏水稀释至 0.14 mol/L 析出 DNA → 过滤取黏稠物 → 用浓盐溶液再溶解 → 加体积分数 95% 的冷酒精析出较纯 DNA → 取少量用二苯胺试剂沸水浴鉴定，溶液变蓝说明含 DNA。 **六、DNA 双螺旋结构（沃森和克里克，1953 年）** 1. 结构要点：DNA 由两条脱氧核苷酸链组成，两条链反向平行盘旋成双螺旋结构；脱氧核糖与磷酸交替连接排列在外侧，构成基本骨架；碱基排列在内侧；两条链上的碱基通过氢键连接成碱基对，遵循**碱基互补配对原则**：A（腺嘌呤）一定与 T（胸腺嘧啶）配对，G（鸟嘌呤）一定与 C（胞嘧啶）配对，A 与 T 之间 2 个氢键，G 与 C 之间 3 个氢键。 2. 碱基计算规律（设双链 DNA 中 A、T、G、C 的数量为已知）： - 双链中：A = T，G = C，A + G = T + C，即嘌呤总数等于嘧啶总数，(A + G)/(T + C) = 1。 - 双链中 (A + T)/(G + C) 的比值与任意一条单链中该比值相等。 - 一条链中 (A + G)/(T + C) 的比值，与互补链中该比值互为倒数。 - 双链 DNA 中若一条链上某碱基数量已知，乘以 2 即为双链中该碱基数量（指与另一链配对合成后）。

🔍 课堂讲义 · 重点难点解析

**重点一：艾弗里体外转化实验的变量控制** 例题：艾弗里在证明"转化因子是 DNA"时，为什么还要设计"加入 DNA 的同时加入 DNA 酶"这一组实验？ 分析：该实验的关键是排除干扰、增强说服力。加入 DNA 组能发生转化，说明 DNA 可能是转化因子；而 DNA 酶能特异性水解 DNA。 解答：加入 DNA 组出现 S 型活细菌，说明 DNA 可能使 R 型细菌转化；加入 DNA 和 DNA 酶后，DNA 被水解，R 型细菌不发生转化，说明被水解破坏的 DNA 正是起转化作用的物质。两组对照，进一步确认 DNA 是转化因子。 小结：设置"破坏某一物质后现象消失"的对照组，是确证因果关系的经典实验设计思路。 **重点二：噬菌体侵染实验的误差分析** 例题：在 32P 标记组中，保温时间过短或过长，都会使上清液放射性偏高，原因分别是什么？ 分析：上清液中出现放射性，说明标记的 DNA 没有随噬菌体进入细菌或子代噬菌体已释放出来。 解答：保温时间过短，部分噬菌体尚未侵染（吸附注入）细菌，离心后 DNA 随噬菌体分布在上清液中；保温时间过长，细菌裂解，子代噬菌体释放到培养液中，离心后分布在上清液中，使上清液放射性偏高。 小结：保温时间要适中，这正是本实验对操作严谨性的要求；误差分析题要从"进不去"和"出来了"两个角度作答。 **难点一：碱基比例计算** 例题：某双链 DNA 分子中，G 占全部碱基的 20%，其中一条链上 A 占该链碱基总数的 30%，求互补链中 A 占该链的比例。 分析：先求双链中 A + T 的比例，再推出单链比例关系。双链中 G = C = 20%，则 A = T = 30%，A + T 占 60%。双链中 (A + T) 的比例等于每条单链中 (A + T) 的比例，故每条链上 A + T 均占该链的 60%。 解答：已知一条链上 A 占该链 30%，则该链 T 占 60% - 30% = 30%，互补链上 A 与该链 T 配对相等，故互补链上 A 占该链的 30%。 小结：抓住 A = T、G = C 与"双链比值等于单链 A + T 比值"两条规律，碱基计算就有章可循。 **难点二："DNA 是主要的遗传物质"的表述依据** 例题：为什么说"DNA 是主要的遗传物质"，而不说"DNA 是一切生物的遗传物质"？ 分析：统计各类生物的遗传物质种类。 解答：细胞生物（包括原核生物和真核生物）的遗传物质都是 DNA；DNA 病毒的遗传物质是 DNA；只有少数 RNA 病毒（如烟草花叶病毒、HIV、流感病毒、SARS 病毒）的遗传物质是 RNA。绝大多数生物以 DNA 作为遗传物质，故说 DNA 是主要的遗传物质。 小结：科学结论的表述必须与证据范围一致，体现科学的严谨性。

✏️ 课堂讲义 · 典型例题精讲

**例题一（实验设计）：格里菲思体内转化实验的推理** 题目：将加热杀死的 S 型细菌与 R 型活细菌混合注射到小鼠体内，小鼠死亡，从死鼠体内分离出了活的 S 型细菌和活的 R 型细菌。请分析：S 型活细菌从何而来？该实验证明了什么？还有什么不足？ 分析：加热杀死的 S 型细菌已无毒性，不能直接使小鼠死亡；S 型活细菌的出现说明 R 型细菌发生了转化。 解答：S 型活细菌是由 R 型活细菌转化而来的，加热杀死的 S 型细菌中存在某种促使 R 型细菌转化的"转化因子"。该实验证明了存在转化因子，但没有证明转化因子是什么物质，这是它的不足之处。 方法小结：体内转化实验的现象与结论之间要区分层次——"有转化现象"与"转化因子是什么"是两个问题。 **例题二（实验分析）：噬菌体侵染实验的标记选择** 题目：为什么赫尔希与蔡斯分别用 35S 和 32P 标记噬菌体，而不直接用 14C 或 18O 标记？ 分析：标记的目的在于把 DNA 与蛋白质"区分开"，分别追踪。 解答：蛋白质含 S 而不含 P，DNA 含 P 而不含 S，用 35S 标记可专一追踪蛋白质，用 32P 标记可专一追踪 DNA，二者能完全分开。而 C、O 是 DNA 和蛋白质共有的元素，无法据此区分二者，故不能选用。 方法小结：同位素标记的前提是元素具有专一性，能将待研究的两种成分分开。 **例题三（计算）：双链 DNA 碱基比例** 题目：某双链 DNA 分子共有 400 个碱基对，其中一条链上 A + G 占该链碱基总数的 45%，求该 DNA 分子中 C 的数量。 分析：一条链上 A + G 占 45%，则 T + C 占 55%。互补链上 A + G 与该链的 T + C 相等，故双链中 (A + G) 占双链碱基总数的 (45% + 55%) ÷ 2 = 50%，符合嘌呤总数等于嘧啶总数的规律。 解答：双链中 A + G 共占 50%，则 T + C 共占 50%，即 T = C。双链碱基总数为 400 × 2 = 800 个，故 C = 800 × 50% ÷ 2 = 200 个。 方法小结：先由单链比值推双链比值，再利用嘌呤等于嘧啶求具体碱基数目，注意"碱基对"与"碱基个数"的换算。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 科学史基本事实

  1. 1. 肺炎双球菌的 S 型细菌与 R 型细菌相比，在菌落特点和毒性上有什么不同？
    答：S 型细菌菌落光滑、有荚膜、有毒性，能使小鼠患败血症死亡；R 型细菌菌落粗糙、无荚膜、无毒性，不能使小鼠死亡。
  2. 2. 格里菲思的体内转化实验（四组注射实验）得出的结论是什么？
    答：结论：加热杀死的 S 型细菌中含有某种"转化因子"，能将 R 型活细菌转化为 S 型活细菌。该实验没有证明转化因子的化学本质。
  3. 3. 赫尔希与蔡斯用 35S 和 32P 分别标记噬菌体的什么成分？依据是什么？
    答：35S 标记蛋白质外壳，32P 标记 DNA。依据是蛋白质含 S 不含 P，DNA 含 P 不含 S，两种元素具有专一性，可将 DNA 与蛋白质分开追踪。

中等 · 实验过程与结果分析

  1. 1. 噬菌体侵染实验中，35S 组和 32P 组搅拌离心后放射性分布分别在哪里？各说明什么？
    答：35S 组放射性主要在上清液，说明蛋白质外壳未进入细菌，留在细胞外；32P 组放射性主要在沉淀物，说明 DNA 进入细菌体内并起指导作用。
  2. 2. 艾弗里实验中，在 S 型细菌 DNA 溶液中加入 DNA 酶后与 R 型细菌混合培养，结果如何？为什么？
    答：结果不出现转化，只有 R 型细菌生长。因为 DNA 酶将 DNA 水解为脱氧核苷酸，破坏了转化因子，说明 DNA 是转化因子，即遗传物质。
  3. 3. 噬菌体侵染实验能否证明蛋白质不是噬菌体的遗传物质？请说明理由。
    答：不能。该实验只追踪了 DNA 的去向，证明 DNA 是遗传物质；蛋白质外壳没有进入细菌体内，未参与子代噬菌体的合成检验，因此不能据此证明蛋白质不是遗传物质。

难 · 误差分析与变量控制

  1. 1. 32P 标记组保温时间过短，上清液放射性会偏高还是偏低？原因是什么？
    答：偏高。保温时间过短，部分噬菌体尚未吸附或注入 DNA，离心时这些未侵染的噬菌体（含 32P 标记的 DNA）分布在上清液中，使上清液放射性偏高。
  2. 2. 35S 标记组搅拌不充分，沉淀物放射性会怎样变化？为什么？
    答：偏高。搅拌的目的是使蛋白质外壳与细菌分离，搅拌不充分时部分蛋白质外壳仍吸附在细菌表面，离心后随细菌进入沉淀物，使沉淀物中放射性偏高。
  3. 3. 用 DNA 粗提取实验回答：为什么不能用哺乳动物成熟红细胞作为提取材料？实验中二苯胺试剂的作用是什么？
    答：哺乳动物成熟红细胞没有细胞核和细胞器，不含 DNA（无遗传物质），不能提取到 DNA。二苯胺试剂在沸水浴条件下与 DNA 反应生成蓝色物质，用于鉴定 DNA 的存在。

综合 · 碱基计算与实验设计综合

  1. 1. 某双链 DNA 分子中，A 占全部碱基的 25%，共 600 个碱基。求该 DNA 分子中 G 的数量和碱基对数。
    答：双链中 A = T = 25%，则 G + C = 50%，G = C = 25%，即 G = 600 个（与 A 数量相等，各占 25%）。碱基总数为 600 ÷ 25% = 2400 个，故碱基对数为 2400 ÷ 2 = 1200 对。G 为 600 个。
  2. 2. 一条双链 DNA 中，一条链上 (A + G)/(T + C) = 0.8，求互补链上 (A + G)/(T + C) 的值及整个双链中该比值。
    答：互补链上该比值为原链的倒数，即 1 ÷ 0.8 = 1.25。整个双链中 A + G 等于 T + C（嘌呤总数等于嘧啶总数），比值为 1。
  3. 3. 设计一个简要方案，验证某 RNA 病毒的遗传物质是 RNA（要求写出实验思路和预期结果）。
    答：思路：将 RNA 病毒的 RNA 和蛋白质分离，分别侵染（接种）宿主细胞。预期结果：单独接种 RNA 的细胞中出现子代病毒且宿主被感染，单独接种蛋白质的不出现子代病毒，说明 RNA 是该病毒的遗传物质。（或用 RNA 酶处理 RNA 后再接种，感染性消失，同理可证。）

💬 课后反馈

**学生常见错误** 1. 混淆两组科学史实验的结论：把格里菲思的结论说成"DNA 是遗传物质"，实际上他只证明了转化因子的存在；艾弗里实验才证明 DNA 是转化因子。 2. 噬菌体标记原理不清：误认为可以用 32P 标记蛋白质，或误以为噬菌体整体进入细菌，不理解"只注入 DNA"这一关键事实。 3. 碱基计算中"碱基对"与"碱基个数"混淆，或忘记双链与单链比值关系，导致数量算错。 4. 对"DNA 是主要的遗传物质"表述不准确，写成"DNA 是一切生物的遗传物质"。 **教学改进建议** 1. 用科学史主线串联教学，让学生先预测、再对照史实，体验实验设计的逻辑，而不是直接给结论。 2. 借助动画演示噬菌体侵染与离心过程，把"吸附—注入—合成—释放"与"上清液、沉淀物"的位置关系讲透。 3. 碱基计算归纳成"两条规律 + 三类题型"，配合变式训练，让学生熟练运用规律而非死记公式。 **分层辅导建议** - 基础层：熟记四组体内转化实验现象、噬菌体实验结论和双螺旋结构要点，能复述。 - 提高层：重点练艾弗里实验的变量控制分析和噬菌体实验误差分析。 - 拓展层：完成单链、互补链、双链碱基比例的综合计算，并尝试设计验证 RNA 病毒遗传物质的方案。 **给家长的建议** 1. 鼓励孩子用讲故事的方式复述几位科学家的实验过程，讲清"实验—现象—结论"三步，检验理解程度。 2. 提醒孩子整理科学史时间轴（1928、1944、1952、1953），把人物、方法、结论对应记忆。
