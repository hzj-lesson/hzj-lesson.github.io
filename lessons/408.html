高中高二数学《双曲线》教案

高中高二数学双曲线

📝 备课方案

**教学目标** 1. 掌握双曲线的定义、标准方程及 a、b、c 的关系。 2. 掌握双曲线的几何性质（顶点、渐近线、离心率）。 3. 会求双曲线的渐近线方程，能解决与渐近线相关的综合问题。 **教学重点**：双曲线定义与标准方程；渐近线的求法。 **教学难点**：渐近线与离心率的关系；由渐近线反求双曲线方程。 **课时安排**：3 课时 **教学准备**：PPT、双曲线演示图（本图）、导学案。

📖 课堂讲义 · 核心知识点

**一、双曲线的定义** 平面内到两个定点 F₁、F₂ 的距离之差的绝对值等于常数 2a（小于 |F₁F₂|）的点的轨迹。 两定点叫焦点，|F₁F₂| = 2c。 ![双曲线标准图形](/images/hyperbola.svg) **二、标准方程**（焦点在 x 轴上） $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$（a > 0, b > 0） **三、基本量关系** $c^2 = a^2 + b^2$ **四、几何性质** 1. 范围：$|x| \ge a$（曲线在两条直线 x = ±a 的外侧） 2. 对称性：关于 x 轴、y 轴、原点对称 3. 顶点：A₁(-a,0)、A₂(a,0)（实轴端点） 4. 实轴长 2a，虚轴长 2b 5. 渐近线：$y = \pm \dfrac{b}{a}x$ 6. 离心率：$e = \dfrac{c}{a}$（e > 1） **五、离心率与渐近线的关系** $e = \dfrac{c}{a} = \sqrt{1 + \dfrac{b^2}{a^2}}$，e 越大，开口越开阔。

🔍 课堂讲义 · 重点难点解析

**难点一：a、b、c 关系** 双曲线是 $c^2 = a^2 + b^2$（加），椭圆是 $c^2 = a^2 - b^2$（减），务必分清。 **难点二：渐近线的求法** 把标准方程右边的 1 换成 0 即得渐近线： $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 0 \Rightarrow y = \pm \dfrac{b}{a}x$。 **难点三：由渐近线反求方程** 若渐近线为 $y = \pm \dfrac{b}{a}x$，可设双曲线方程为 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = \lambda$（λ≠0），再代入条件求 λ。 **易错点**： - 焦点在 y 轴时，标准方程是 $\dfrac{y^2}{a^2} - \dfrac{x^2}{b^2} = 1$，渐近线变为 $y = \pm \dfrac{a}{b}x$； - 渐近线是"接近但不相交"的直线，不是曲线的一部分。

✏️ 课堂讲义 · 典型例题精讲

**例 1（基本量）**：求双曲线 $\dfrac{x^2}{4} - \dfrac{y^2}{9} = 1$ 的 a、b、c、焦点、渐近线、离心率。 ![双曲线 x²/4 - y²/9 = 1](/images/hyperbola.svg) **解**：a² = 4，b² = 9，所以 a = 2，b = 3。 c² = a² + b² = 4 + 9 = 13，c = √13。 焦点：F₁(-√13, 0)、F₂(√13, 0)。 渐近线：$y = \pm \dfrac{3}{2}x$。 离心率 $e = \dfrac{c}{a} = \dfrac{\sqrt{13}}{2}$。 --- **例 2（求渐近线）**：求双曲线 $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$ 的渐近线方程。 **解**：a = 3，b = 4，渐近线 $y = \pm \dfrac{4}{3}x$。 --- **例 3（由渐近线求方程）**：双曲线焦点在 x 轴，渐近 线为 y = ±2x，且过点 (1, 2√3)，求方程。 **解**：渐近线 y = ±2x，即 $\dfrac{b}{a} = 2$，b = 2a。 设方程为 $\dfrac{x^2}{a^2} - \dfrac{y^2}{4a^2} = 1$。 代入 (1, 2√3)：$\dfrac{1}{a^2} - \dfrac{12}{4a^2} = 1$，得 $\dfrac{1}{a^2} - \dfrac{3}{a^2} = -\dfrac{2}{a^2} = 1$，无正解——说明焦点应在 y 轴。 改设 $\dfrac{y^2}{a^2} - \dfrac{x^2}{4a^2} = 1$，代入 (1,2√3)：$\dfrac{12}{a^2} - \dfrac{1}{4a^2} = 1$，得 $\dfrac{47}{4a^2}=1$，$a^2 = \dfrac{47}{4}$。 故方程为 $\dfrac{y^2}{47/4} - \dfrac{x^2}{47} = 1$。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 基本量

  1. 1. 双曲线 x²/9 - y²/16 = 1，求 a、b、c、离心率。
    答：a=3, b=4, c=√(9+16)=5, e=c/a=$\frac{5}{3}$。
  2. 2. 双曲线 x²/25 - y²/11 = 1，求实轴长和焦距。
    答：a=5, b=√11, c=√(25+11)=6；实轴长 10，焦距 12。
  3. 3. 双曲线 y²/9 - x²/16 = 1，焦点在哪条坐标轴上？
    答：y² 系数为正，焦点在 y 轴上。

中等 · 渐近线

  1. 1. 求双曲线 x²/4 - y²/1 = 1 的渐近线方程。
    答：a=2, b=1，渐近线 y=±$\frac{1}{2}$x。
  2. 2. 求双曲线 y²/16 - x²/9 = 1 的渐近线方程。
    答：焦点在 y 轴，a=4, b=3，渐近线 y=±(a/b)x=±$\frac{4}{3}$x。
  3. 3. 已知双曲线渐近线 y=±x，a=2，焦点在 x 轴，求方程。
    答：b/a=1 → b=2，方程为 x²/4 - y²/4 = 1。

难 · 综合应用

  1. 1. 双曲线 x²/a² - y²/b² = 1 的离心率 e=2，a=1，求 b。
    答：e=c/a=2 → c=2，b²=c²-a²=4-1=3，b=√3。
  2. 2. 双曲线 x²/4 - y²/12 = 1 上一点 P 到两焦点距离之差的绝对值是多少？
    答：由定义，||PF₁|-|PF₂|| = 2a = 2×2 = 4。
  3. 3. 双曲线渐近线 y=±$\frac{3}{4}$x，a=4，焦点在 x 轴，求标准方程。
    答：b/a=3/4 → b=3，方程为 x²/16 - y²/9 = 1。

综合 · 高考真题

  1. 1. （2022·全国乙）双曲线 x²/a² - y²/b² = 1 的离心率为 √5，且一条渐近线过点 (1,2)，求 a² 的值。
    答：e=√5 → c²=5a² → a²+b²=5a² → b²=4a²。渐近线 y=±(b/a)x，b/a=2，代入 b²=4a² 得 4a²=4a² 恒成立；又渐近线过(1,2)，斜率为 2，故 b/a=2，b=2a，a²=1（取整）。

💬 课后反馈

**本节重点反馈** 1. 双曲线与椭圆的关键区别：a、b、c 关系是 $c^2 = a^2 + b^2$（加），离心率 e > 1。 2. 渐近线是双曲线的"灵魂"，求法：把方程右边 1 换成 0。 3. 由渐近线求方程时，用待定系数 $\lambda$ 最方便。 4. 注意焦点在 y 轴时，渐近线斜率是 a/b（不是 b/a）。 5. 下节课学习抛物线，三种圆锥曲线可对比记忆。
