高中高二数学《椭圆》教案

高中高二数学椭圆

📝 备课方案

**教学目标** 1. 掌握椭圆的定义、标准方程及 a、b、c 的关系。 2. 掌握椭圆的几何性质（范围、对称性、顶点、离心率）。 3. 会用待定系数法求椭圆方程，并能解决焦点三角形等综合问题。 **教学重点**：椭圆定义与标准方程；离心率的几何意义。 **教学难点**：由条件建立椭圆方程；离心率与几何性质的灵活应用。 **课时安排**：3 课时（第 1 课时定义与方程；第 2 课时几何性质；第 3 课时综合应用） **教学准备**：PPT、椭圆演示教具（或 GeoGebra）、配套导学案。

📖 课堂讲义 · 核心知识点

**一、椭圆的定义** 平面内到两个定点 F₁、F₂ 的距离之和等于常数 2a（大于 |F₁F₂|）的点的 轨迹叫做椭圆。 两定点 F₁、F₂ 叫焦点，|F₁F₂| = 2c 叫焦距。 ![椭圆标准图形](/images/ellipse.svg) **二、标准方程**（焦点在 x 轴上） $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（a > b > 0） **三、基本量关系** $c^2 = a^2 - b^2$ **四、几何性质** 1. 范围：$|x| \le a$，$|y| \le b$（椭圆位于矩形内） 2. 对称性：关于 x 轴、y 轴、原点都对称 3. 顶点：A₁(-a,0)、A₂(a,0)、B₁(0,-b)、B₂(0,b)，共 4 个顶点 4. 长轴长 2a，短轴长 2b 5. 焦点：F₁(-c,0)、F₂(c,0) 6. 离心率：$e = \dfrac{c}{a}$（0 < e < 1） **五、离心率的几何意义** - e 越接近 0，椭圆越圆； - e 越接近 1，椭圆越扁。

🔍 课堂讲义 · 重点难点解析

**难点一：由 a、b、c 关系求参数** 牢记 $c^2 = a^2 - b^2$（注意是"减"，与双曲线的"加"相反）。 例：已知 a=5、b=3，则 $c = \sqrt{25-9} = 4$，$e = \dfrac{4}{5}$。 **难点二：焦点位置判断** 看分母大小：谁的分母大，焦点就在谁所在的坐标轴上。 - 若 $\dfrac{x^2}{m} + \dfrac{y^2}{n} = 1$ 中 m > n，焦点在 x 轴； - 若 n > m，焦点在 y 轴。 **难点三：用定义解题** 椭圆上任意一点 P 满足 $|PF_1| + |PF_2| = 2a$，这是解决"焦点三角形"问题的关键。 焦点三角形周长 $= 2a + 2c$。 **易错点**： - 求方程前先判断焦点在哪个轴，避免套错标准式； - 离心率 e 的分母是 a（长半轴），不是 c； - 椭圆上点的横、纵坐标绝对值分别不超过 a、b。

✏️ 课堂讲义 · 典型例题精讲

**例 1（基本量）**：求椭圆 $\dfrac{x^2}{9} + \dfrac{y^2}{4} = 1$ 的 a、b、c、焦点、顶点、离心率。 ![椭圆 x²/9 + y²/4 = 1](/images/ellipse.svg) **解**：a² = 9，b² = 4，所以 a = 3，b = 2。 c² = a² - b² = 9 - 4 = 5，c = √5。 焦点：F₁(-√5, 0)、F₂(√5, 0)。 顶点：A₁(-3,0)、A₂(3,0)、B₁(0,-2)、B₂(0,2)。 离心率 $e = \dfrac{c}{a} = \dfrac{\sqrt{5}}{3}$。 --- **例 2（求标准方程）**：长轴长为 10，焦距为 8，焦点在 x 轴上，求椭圆方程。 **解**：2a = 10 → a = 5；2c = 8 → c = 4。 b² = a² - c² = 25 - 16 = 9，b = 3。 所以方程为 $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$。 --- **例 3（焦点三角形）**：P 是椭圆 $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$ 上一点，求 $|PF_1| + |PF_2|$。 **解**：由定义，$|PF_1| + |PF_2| = 2a = 2 \times 5 = 10$。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 基本量

  1. 1. 椭圆 x²/16 + y²/7 = 1，求 a、b、c、离心率。
    答：a=4, b=√7, c=√(16-7)=3, e=c/a=$\frac{3}{4}$。
  2. 2. 椭圆 x²/100 + y²/36 = 1，求长轴长和焦距。
    答：a=10, b=6, c=√(100-36)=8；长轴长 20，焦距 16。
  3. 3. 椭圆 x²/25 + y²/16 = 1，焦点在哪条坐标轴上？
    答：25>16，焦点在 x 轴上，F(±3,0)。

中等 · 求方程

  1. 1. 长轴长 12，焦距 6，焦点在 x 轴，求椭圆方程。
    答：a=6, c=3, b²=36-9=27，方程为 x²/36 + y²/27 = 1。
  2. 2. 已知 a=4, b=2，焦点在 y 轴，求椭圆方程。
    答：焦点在 y 轴，a 对应 y 的分母，方程为 x²/4 + y²/16 = 1。
  3. 3. 椭圆过点 (3,0)、(0,2)，且焦点在 x 轴，求方程。
    答：a=3, b=2，方程为 x²/9 + y²/4 = 1。

难 · 离心率与综合

  1. 1. 椭圆 x²/a² + y²/b² = 1 的离心率 e=$\frac{1}{2}$，且 a=4，求 b。
    答：e=c/a=$\frac{1}{2}$ → c=2，b²=a²-c²=16-4=12，b=2√3。
  2. 2. P 是椭圆 x²/49 + y²/24 = 1 上一点，F₁、F₂ 为焦点，求 △PF₁F₂ 的周长。
    答：a=7, c=√(49-24)=5；周长=2a+2c=14+10=24。
  3. 3. 椭圆中心在原点、焦点在 x 轴，长轴长 8，离心率 e=$\frac{\sqrt{3}}{2}$，求方程。
    答：a=4, e=c/a=$\frac{\sqrt{3}}{2}$ → c=2√3，b²=16-12=4，方程为 x²/16 + y²/4 = 1。

综合 · 高考真题

  1. 1. （2023·新课标 I）已知椭圆 C：x²/a² + y²/b² = 1 (a>b>0) 的离心率为 $\frac{\sqrt{3}}{2}$，且过点 (2, √3/2)，求 C 的方程。
    答：e=$\frac{\sqrt{3}}{2}$ → c²/a²=$\frac{3}{4}$ → b²/a²=$\frac{1}{4}$ → b²=a²/4。代入点(2,√3/2)：4/a² + (3/4)/(a²/4) = 1 → 4/a² + 3/a² = 1 → a²=7，b²=7/4。方程为 x²/7 + y²/(7/4) = 1。

💬 课后反馈

**本节重点反馈** 1. 椭圆核心是 a、b、c 三者关系 $c^2 = a^2 - b^2$，务必与双曲线区分（双曲线是加）。 2. 求方程题先判断焦点位置，再设标准式，用待定系数法。 3. 离心率是区分椭圆"圆"与"扁"的关键，注意 e 范围 (0,1)。 4. 焦点三角形问题牢记 $|PF_1| + |PF_2| = 2a$。 5. 下节课引入双曲线，可对比记忆。
