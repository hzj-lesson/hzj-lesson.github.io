小学二年级数学《100 以内的加减法（进位/退位）》教案

小学二年级数学100 以内的加减法（进位/退位）

📝 备课方案

**教学目标** 1. 经历用小棒、计数器操作的过程，理解两位数加两位数进位加法中"个位满十向十位进一"的算理，掌握进位加法的竖式计算方法。 2. 理解两位数减两位数退位减法中"个位不够减，从十位退一当十"的算理，掌握退位减法的竖式计算方法，会点退位点、会规范书写。 3. 在对比中弄清进位加法与退位减法的联系和区别，养成先估算、再计算、后检验的好习惯。 4. 能运用进位加法和退位减法解决购物、图书借阅等生活中的实际问题，感受数学与生活的密切联系。 **教学重点** 掌握两位数加减两位数的竖式写法，做到数位对齐、从个位算起、结果正确。 **教学难点** 理解"满十进一"和"退一当十"的算理，正确处理进位的1与退位的1。 **教学方法** 操作演示法、对比分析法、分层练习法。 **教学准备** 小棒（每捆10根）、计数器、数位卡片、多媒体课件、口算题卡。 **课时安排** 4课时：进位加法2课时（第一课时讲算理学竖式，第二课时练习与应用），退位减法2课时（第三课时讲算理学竖式，第四课时练习与混合运算）。

📖 课堂讲义 · 核心知识点

一、进位加法的算理与算法 先摆小棒算一算：36加47等于多少？把36根小棒摆成3捆零6根，47根摆成4捆零7根。个位6根加7根等于13根，10根正好捆成新的一捆，还剩3根；十位3捆加4捆等于7捆，再加上新捆成的1捆，一共8捆。8捆3根就是83。小棒操作告诉我们：个位相加满十了，就要把10个一变成1个十，向十位进一。这就是"个位满十，向十位进一"的算理。 竖式计算要注意三点：第一，相同数位对齐，个位对个位，十位对十位；第二，从个位加起，先算6加7等于13，个位写3，向十位进1；第三，十位相加时别忘了加上进上来的1，算3加4再加1等于8。口算和竖式可以互相配合，对比如下： | 口算方法 | 竖式方法 | | --- | --- | | 先把两个加数的个位相加，满十记下进位的1 | 相同数位对齐，从个位加起 | | 再把十位相加，并加上进位的1 | 个位满十，向十位进1 | | 最后把两部分合起来写出结果 | 十位相加要加上进位的1 | 二、退位减法的算理与算法 62减27，个位2不够减7，怎么办？还是请小棒帮忙：把62根小棒中的1捆拆开，变成10根单根，和原来的2根合起来是12根，12根减7根剩5根；十位本来有6捆，拆掉1捆后剩5捆，5捆减2捆剩3捆。3捆5根就是35。拆开的这一捆，就是"从十位退一当十"，退下来的10和个位上的2合成12再减，算理就讲清楚了。 竖式退位减法也有三步：第一，数位对齐，从个位减起；第二，个位不够减，从十位退1当10，和个位上的数合起来再减，十位上要记得点上退位点；第三，十位相减时，先去掉退走的1再减。进位加法与退位减法对比如下： | 进位加法 | 退位减法 | | --- | --- | | 个位满十，向十位进一 | 个位不够减，从十位退一当十 | | 个位写和，进位的1要加到十位 | 退位点记在十位，提醒十位少了1 | | 十位＝十位加十位再加1 | 十位＝十位减1再减十位 | 三、常见易错提醒 1. 数位没对齐，把个位和十位相加，结果必错。写竖式时先把数位对整齐。 2. 进位加法忘了加进位的1。算完个位满十后，十位一定多算一个1。 3. 退位减法退位后十位忘了先减1。看到退位点就要想起十位已经少了1。 4. 把"满十进一"和"退一当十"记反。个位相加超过9才进1，个位不够减才退位。

🔍 课堂讲义 · 重点难点解析

重点一：进位加法中"满十进一"的处理 题目：用竖式计算58加37。 分析：个位8加7等于15，已经满十。满十就要向十位进1，个位只写5，进位的1记在十位的位置上。十位上是5加3，再加进上来的1，等于9。 解答：58加37等于95。竖式：个位8加7等于15，写5进1；十位5加3加1等于9。 小结：个位满十向十位进一，进位的1必须加进十位的计算结果里，这是进位加法最容易出错的地方。也可以在竖式上进位的1旁先点个记号，防止漏加。 重点二：退位减法中"退一当十"的运用 题目：用竖式计算43减26。 分析：个位3不够减6，从十位退1当10，退到个位变成13，13减6等于7；十位被退走1后剩3，3减2等于1。 解答：43减26等于17。竖式：个位13减6得7，十位3减2得1，别忘了在十位点上退位点。 小结：退位后十位要先减1再减十位，做到"退了就要减"。 难点：个位是0的退位减法 题目：用竖式计算90减34。 分析：个位0不够减4，从十位退1当10，10减4等于6；十位9退1后剩8，8减3等于5。个位上是0时特别容易出错，退下来的10要先减去4，千万别直接在个位写0。 解答：90减34等于56。 小结：个位不够减时，哪怕个位是0也要果断退位，退一当十后再减。

✏️ 课堂讲义 · 典型例题精讲

例题一：进位加法的竖式计算 题目：学校图书角原来有45本书，又买来38本，现在一共有多少本？ 分析：求"一共有多少本"，用加法计算，列式45加38。个位5加8等于13，满十向十位进1，个位写3；十位4加3再加1等于8。计算时要养成先看个位的习惯，个位满十先做好进位标记，再算十位。 解答：45加38等于83（本）。答：现在一共有83本。 方法小结：遇到"一共有多少"用加法；个位满十要进位，十位别忘了加进位的1，进位的1千万别漏加。 例题二：退位减法的竖式计算 题目：妈妈带100元买了一件68元的衣服，还剩多少元？ 分析：用带的钱减去花掉的钱，列式100减68。个位0不够减8，从十位退1当10，可十位也是0，还要继续从百位退1当10，十位得10，再退1给个位，个位10减8等于2，十位剩9减6等于3。 解答：100减68等于32（元）。答：还剩32元。 方法小结：遇到连续退位，要一步一步退到位，个位、十位都要算清楚，不能跳步。检验时用差加上减数，正好等于被减数，说明算对了。 例题三：改错题 题目：下面的竖式对吗？不对的请改正。56加37算成了83。 分析：个位6加7等于13，满十应进1，个位写3，十位5加3再加进位的1等于9，正确结果是93。原来的竖式十位忘加进位的1，算成了8。 解答：改正后56加37等于93。 方法小结：做完竖式可以用估算检验，50加40大约等于90，结果应在90左右，明显偏小说明算错了。估算和还原检验双管齐下，错误一眼就能看出来。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 口算与竖式

  1. 1. 口算：36加47等于多少？
    答：36加47等于83。个位6加7等于13，写3进1；十位3加4加1等于8。
  2. 2. 口算：82减45等于多少？
    答：82减45等于37。个位2不够减5，从十位退1当10，12减5等于7；十位8退1剩7，7减4等于3。
  3. 3. 竖式计算：54加28。
    答：54加28等于82。个位4加8等于12，写2进1；十位5加2加1等于8。
  4. 4. 竖式计算：71减36。
    答：71减36等于35。个位1不够减6，退1当10，11减6等于5；十位7退1剩6，6减3等于3。

中等 · 改错与填数

  1. 1. 下面的竖式对吗？36加47算成了73。
    答：不对。个位6加7等于13，满十应进1，十位3加4加1等于8，正确结果是83。
  2. 2. 填数：方框加25等于71，方框里填几？
    答：方框里填46。用71减25计算，个位11减5等于6，十位6减2等于4。
  3. 3. 竖式计算：90减36。
    答：90减36等于54。个位0不够减6，从十位退1当10，10减6等于4；十位9退1剩8，8减3等于5。
  4. 4. 两个加数分别是28和35，它们的和是多少？
    答：28加35等于63。个位8加5等于13，写3进1；十位2加3加1等于6。

难 · 生活应用

  1. 1. 小红有58张邮票，小明有67张，两人一共有多少张？
    答：58加67等于125（张）。个位8加7等于15，写5进1；十位5加6加1等于12。答：两人一共有125张。
  2. 2. 一本故事书有90页，小刚第一天看了34页，第二天看了28页，还剩多少页没看？
    答：90减34等于56，56减28等于28（页）。也可以先算34加28等于62，再算90减62等于28。答：还剩28页。
  3. 3. 商店有86个气球，上午卖出39个，下午又卖出28个，还剩多少个？
    答：86减39等于47，47减28等于19（个）。答：还剩19个。

综合 · 拓展提升

  1. 1. 用45、27和18写出一道进位加法和一道退位减法，并计算。
    答：如45加27等于72（个位5加7等于12，写2进1；十位4加2加1等于7）；45减18等于27（个位5不够减8，退1当10，15减8等于7；十位4退1剩3，3减1等于2）。
  2. 2. 小明做加法时，把加数36看成了63，算得91，正确结果是多少？
    答：先求另一个加数：91减63等于28；再算正确结果：36加28等于64。答：正确结果是64。
  3. 3. 一根绳子长100米，第一次用去42米，第二次用去38米，两次共用去多少米？还剩多少米？
    答：两次共用去42加38等于80（米）；还剩100减80等于20（米）。答：两次共用去80米，还剩20米。

💬 课后反馈

从本单元作业看，学生主要存在四个问题：一是进位加法漏加进位的1，如把56加37算成83，十位忘加进位；二是退位减法退位后十位忘减1，如把43减26算成27；三是数位没有对齐，把"个位加个位"写成"个位加十位"；四是遇到个位是0的退位减法不会处理。 改进建议：第一，计算前先组织学生摆小棒、拨计数器，边说操作边写竖式，让算理和算法同步；第二，用"先估算、再计算、后检验"三步规范练习，估算能快速发现明显错误；第三，针对进位忘加1、退位忘减1开展专项改错训练，让学生当"小医生"找病根；第四，把口算训练纳入每课前三分钟，由易到难滚动练习。 分层辅导：基础薄弱的学生每天练10道口算，先练不进位不退位，再练进位退位；学有余力的学生练习连加连减和加减混合运算。给家长的建议：在家让孩子帮忙算购物找零，多说说"满十进一""退一当十"的道理，把计算当成游戏，不要一味追求速度而忽略算理。
