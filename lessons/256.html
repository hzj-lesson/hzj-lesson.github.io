初中九年级物理《焦耳定律》教案

初中九年级物理焦耳定律

📝 备课方案

**教材分析** 本课是人教版《物理》九年级全一册第十八章第四节。学生在学习电能、电功率后，进一步探究电流通过导体时的发热规律，建立焦耳定律 $Q=I^2Rt$，并认识电热的利用与防止。本课是欧姆定律、电功率知识的综合应用，也为理解家庭电路保险装置、安全用电提供依据。 **教学目标** 1. 认识电流的热效应，知道电能可以转化为内能。 2. 通过实验探究电流产生的热量与电流、电阻、通电时间的关系，体会控制变量法与转换法。 3. 理解焦耳定律的内容与公式 $Q = I^2Rt$，会进行简单计算。 4. 知道纯电阻电路中 $Q=W$，能区分电功与电热；了解电热的利用与防止。 **教学重点** 焦耳定律的内容与公式；实验探究的设计思路。 **教学难点** 实验设计（控制变量与转换热量）；纯电阻与非纯电阻电路 $Q$ 与 $W$ 的区别。 **课时** 1 课时 **教学过程** "导线热、电炉红"现象导入→电流热效应→实验探究（$Q$ 与 $R$、$I$、$t$ 关系）→焦耳定律公式→电热利用与防止→例题小结。

📖 课堂讲义 · 核心知识点

**一、电流的热效应** 电流通过导体时，电能转化为内能的现象叫电流的热效应。如电灯丝发热发光、电炉丝烧红。任何导体通电都会发热。 **二、焦耳定律** - 内容：电流通过导体产生的热量跟电流的二次方成正比，跟导体的电阻成正比，跟通电时间成正比。 - 公式：$Q = I^2Rt$。单位：热量 $Q$——焦耳（$J$），电流 $I$——安培（$A$），电阻 $R$——欧姆（$\Omega$），时间 $t$——秒（$s$）。 - 说明：焦耳定律适用于任何用电器的发热计算（包括电动机等非纯电阻电路）。 **三、电热与电功的关系** - 纯电阻电路（电能全部转化为内能）：$Q = W = UIt = I^2Rt = \frac{U^2}{R}t$，此时 $Q=W$。 - 非纯电阻电路（如电动机）：电能一部分转化为机械能、一部分转化为内能，$W = UIt$，发热仍为 $Q = I^2Rt$，且 $W > Q$。此时欧姆定律形式 $U=IR$ 不适用。 **四、电热的利用与防止** - 利用：电热器（电热水器、电饭锅、电熨斗、电取暖器、电烙铁等）——发热体由电阻率大、熔点高的合金丝制成，把电能全部转化为内能。 - 防止：电视机的散热窗、电脑 CPU 上的散热风扇、电风扇高速转动同时散热，都是为了把热及时散走，防止温度过高损坏设备、引发火灾。

🔍 课堂讲义 · 重点难点解析

**难点一：实验探究热量与哪些因素有关（控制变量 + 转换）** 热量多少不能直接观察，用转换法：让电阻丝给等质量、同种液体（如煤油）加热，观察温度计示数（或液体膨胀高度）比较产热多少。 - 探究 $Q$ 与 $R$ 的关系：两根阻值不同的电阻丝串联在同一电路（保证 $I$、$t$ 相同），比较两烧瓶中煤油升温快慢，发现电阻大的产热多。 - 探究 $Q$ 与 $I$ 的关系：控制 $R$、$t$ 相同，把两电阻并联在干路与支路（或串入变阻器改变电流），比较不同电流下的升温。 - 探究 $Q$ 与 $t$ 的关系：同一电阻丝，通电时间越长升温越多。 结论：$Q$ 与 $I^2$、$R$、$t$ 均成正比，写成 $Q = I^2Rt$。 **难点二：串联与并联中产热的比较** 串联：电流 $I$ 相同，由 $Q=I^2Rt$，$Q$ 与 $R$ 成正比——电炉丝与导线串联，电炉丝电阻大得多，故热得发红而导线几乎不热。并联：电压 $U$ 相同，由 $Q = \frac{U^2}{R}t$，$Q$ 与 $R$ 成反比——家庭电路中各用电器并联，正常工作时电阻小（功率大）的电器产热多。比较前先分清串并联。 **难点三：$Q=I^2Rt$ 与 $Q=UIt$ 的选择** 纯电阻电路两式等价；非纯电阻（电动机）只能先用 $Q=I^2Rt$ 求发热，$UIt$ 是总电功，不能当热量，二者之差是转化的机械能。 **常见失误** 1. 电动机等非纯电阻电路中误用 $Q=UIt$ 求热量。 2. 比较产热多寡时未先判断串并联关系就乱套公式。 3. 忽略 $Q=I^2Rt$ 中各量的单位对应。

✏️ 课堂讲义 · 典型例题精讲

**例1（基本计算）** 一根电阻为 $50\,\Omega$ 的电热丝，通以 $2\,A$ 的电流，通电 $10\,s$，产生多少热量？ 解析：由焦耳定律 $Q = I^2Rt = 2^2\times50\times10 = 2000\,J$。 关键：直接代入 $Q=I^2Rt$。 **例2（生活现象解释）** 电炉丝通过导线连入电路，为什么电炉丝热得发红，而与之串联的导线却几乎不热？ 解析：电炉丝与导线串联，通过它们的电流 $I$ 相等、通电时间 $t$ 相同，由 $Q=I^2Rt$，产生热量与电阻成正比。电炉丝电阻远大于导线电阻，故电炉丝产热多而导线产热很少。 关键：串联电路比产热看电阻。 **例3（纯电阻电热）** 额定电压 $220\,V$、额定功率 $1000\,W$ 的电水壶正常工作 $7$ 分钟，产生的热量是多少？ 解析：电水壶是纯电阻，正常工作，$Q = W = Pt = 1000\times(7\times60) = 4.2\times10^5\,J$。 关键：纯电阻用电器电能全部转化为内能，$Q=W=Pt$。 **例4（非纯电阻辨析）** 某电动机两端电压 $220\,V$，线圈电阻 $2\,\Omega$，工作电流 $5\,A$，通电 $1\,s$，求电功与线圈发热量，并说明差值去向。 解析：电功 $W = UIt = 220\times5\times1 = 1100\,J$；发热 $Q = I^2Rt = 5^2\times2\times1 = 50\,J$。$W > Q$，差值 $1050\,J$ 转化为电动机输出的机械能。 关键：非纯电阻电路 $Q=I^2Rt$ 仍成立，但不能用 $Q=UIt$。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 什么是电流的热效应？请举出两个利用电热和两个防止电热的实例。
    答：电流通过导体时电能转化为内能的现象叫电流的热效应。利用电热：电热水器、电饭锅、电熨斗等电热器；防止电热：电视机的散热窗、电脑 CPU 的散热风扇（防止温度过高损坏元件）。
  2. 2. 焦耳定律的内容和公式是什么？各物理量用什么单位？
    答：电流通过导体产生的热量跟电流的二次方成正比，跟导体的电阻成正比，跟通电时间成正比。公式 $Q=I^2Rt$，$Q$ 用焦耳（$J$），$I$ 用安培（$A$），$R$ 用欧姆（$\Omega$），$t$ 用秒（$s$）。

中等 · 定量计算

  1. 1. 某电热器电阻为 $55\,\Omega$，接在 $220\,V$ 电路中，通电 $2$ 分钟产生多少热量？
    答：电流 $I = \frac{U}{R} = \frac{220}{55} = 4\,A$。$Q = I^2Rt = 4^2\times55\times120 = 1.056\times10^5\,J$。（也可用 $Q=\frac{U^2}{R}t=\frac{220^2}{55}\times120=1.056\times10^5\,J$）
  2. 2. 输电导线电阻为 $0.5\,\Omega$，输电线中的电流为 $50\,A$，每小时导线产生多少热量？
    答：$t=1\,h = 3600\,s$。$Q = I^2Rt = 50^2\times0.5\times3600 = 4.5\times10^6\,J$。可见远距离输电要减小电流与导线电阻以降低线损（这正是采用高压输电的原因之一）。

难 · 电路与辨析

  1. 1. 两个电阻 $R_1=5\,\Omega$、$R_2=10\,\Omega$，先后串联再并联接入同一电源，在相同时间内哪种接法产热多？为什么？
    答：电源电压一定：串联时总电阻 $R_{串}=15\,\Omega$，产热 $Q_串=\frac{U^2}{15}t$；并联时总电阻 $R_{并}=\frac{5\times10}{5+10}=\frac{10}{3}\approx3.3\,\Omega$，产热 $Q_并=\frac{U^2}{3.3}t$。因为并联总电阻小，由 $Q=\frac{U^2}{R}t$ 知并联产热多（约为串联的 $4.5$ 倍）。家庭电路用电器并联，同时使用越多总电阻越小、总功率与产热越大。
  2. 2. 某电动机线圈电阻 $1\,\Omega$，接在 $220\,V$ 电源上电流 $10\,A$，工作 $10\,s$。求：①电功；②发热；③机械能；④若误用 $Q=UIt$ 会错在哪里？
    答：①$W=UIt=220\times10\times10=2.2\times10^4\,J$；②$Q=I^2Rt=10^2\times1\times10=10^3\,J$；③机械能 $W-Q=2.2\times10^4-10^3=2.1\times10^4\,J$。④若用 $Q=UIt$ 得 $2.2\times10^4\,J$，把总电功当成了热量，夸大了发热；电动机中 $U\neq IR$（有反电动势），故只有 $Q=I^2Rt$ 正确。

综合 · 生活与探究

  1. 1. 设计实验探究"电流通过导体产生的热量与电阻的关系"，写出器材、电路与判断方法。
    答：器材：电源、开关、滑动变阻器、电流表、两个烧瓶（各装等质量煤油与温度计）、两根阻值不同的电阻丝（如 $5\,\Omega$ 与 $10\,\Omega$）。电路：两电阻丝串联（保证 $I$、$t$ 相同），分别浸入煤油。判断：通电相同时间，比较两温度计升高的示数，升得高的说明该电阻丝产热多。结论：$I$、$t$ 一定时，电阻越大产热越多（控制变量法与转换法）。
  2. 2. 从焦耳定律角度解释：为什么家庭电路中同时使用多个大功率电器容易使导线过热甚至起火？
    答：家庭电路电压 $220\,V$ 不变，各用电器并联，同时使用大功率电器越多，干路电流 $I=\frac{P_总}{U}$ 越大。导线电阻 $R$ 虽小但固定，由 $Q=I^2Rt$，电流增大使导线产热按电流平方急剧增大，时间一长导线及接头温度过高，烧坏绝缘层引发火灾。故应错峰用电、不超负荷，这正是空气开关、保险丝存在的意义。

💬 课后反馈

焦耳定律 $Q=I^2Rt$ 是电学与热学结合的重点。学生易错点集中在：①把电动机等非纯电阻电路的 $Q=UIt$ 当热量；②比较产热时不分串并联盲目套公式。建议用"电炉丝与导线""高压输电减小线损"两个真实情境讲透定律应用，并安排电动机类对比题强化 $W>Q$ 的辨析，同时通过实验让学生体验控制变量与转换思想。
