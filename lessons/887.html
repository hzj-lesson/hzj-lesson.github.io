高中高二化学《化学反应原理》教案

高中高二化学化学反应原理

📝 备课方案

**教学目标** 1. 能从化学键断裂与形成、反应物与生成物总能量两个角度理解化学反应中的能量变化，掌握焓变ΔH的含义，会判断放热反应与吸热反应。 2. 学会正确书写热化学方程式，掌握书写要领；理解并会应用盖斯定律进行反应热的计算。 3. 理解化学反应速率的含义与表示方法，掌握用不同物质表示速率的换算，掌握浓度、温度、压强、催化剂对反应速率的影响规律。 4. 理解化学平衡状态的建立与特征，掌握平衡常数K的含义，能运用勒夏特列原理分析平衡移动；了解弱电解质电离平衡、水的离子积与pH计算、沉淀溶解平衡的初步知识。 **教学重点**：热化学方程式的书写与盖斯定律应用；化学反应速率的表示与计算；化学平衡常数及平衡移动规律。 **教学难点**：从多个角度判断化学平衡状态；勒夏特列原理中压强影响的判断；pH与水电离的综合计算。 **教学方法**：讲授法与讨论法结合、实验演示法、对比归纳法、典型习题强化训练法。 **教学准备**：多媒体课件（吸热放热实验视频、平衡移动动画）、铁粉与硫粉混合加热实验器材、碳酸氢钠与稀盐酸反应器材、温度计、恒温槽。 **课时安排**：4课时（第1课时：化学反应与能量、焓变与热化学方程式；第2课时：盖斯定律、化学反应速率及其影响因素；第3课时：化学平衡状态、平衡常数与平衡移动；第4课时：电离平衡、水的离子积、pH计算与沉淀溶解平衡初步）。

📖 课堂讲义 · 核心知识点

**一、化学反应与能量：焓变ΔH** 化学反应的实质是旧化学键断裂、新化学键形成的过程。断键需要吸收能量，成键会放出能量，二者之差决定反应是吸热还是放热。 - 放热反应：反应物总能量大于生成物总能量，反应过程放出热量，ΔH 小于 0。常见如燃烧反应、中和反应、金属与酸的反应、大多数化合反应。 - 吸热反应：反应物总能量小于生成物总能量，反应过程吸收热量，ΔH 大于 0。常见如碳与二氧化碳的反应、碳酸钙高温分解、Ba(OH)2·8H2O 与 NH4Cl 的反应、大多数分解反应。 | 比较 | 放热反应 | 吸热反应 | |---|---|---| | 反应物与生成物总能量 | 反应物总能量大于生成物总能量 | 反应物总能量小于生成物总能量 | | 断键与成键能量 | 断键吸收的能量小于成键放出的能量 | 断键吸收的能量大于成键放出的能量 | | ΔH 符号 | ΔH 小于 0 | ΔH 大于 0 | | 常见例子 | 燃烧、中和、金属与酸反应 | 碳酸钙分解、碳与二氧化碳反应 | 焓变的计算：ΔH = 生成物总能量 - 反应物总能量 = 反应物键能总和 - 生成物键能总和。 热化学方程式的书写要领： 1. 注明各物质的状态（s 固体、l 液体、g 气体、aq 水溶液）； 2. 在方程式右边注明 ΔH 的数值、单位（kJ/mol）与正负号； 3. 化学计量数只表示物质的量，可以写成整数，也可以写成分数； 4. 化学计量数加倍，ΔH 数值也加倍；逆反应的 ΔH 与正反应数值相等、符号相反。 例：H2(g) + 1/2O2(g) = H2O(l) ΔH = -285.8 kJ/mol；2H2(g) + O2(g) = 2H2O(l) ΔH = -571.6 kJ/mol。 **二、盖斯定律** 盖斯定律：化学反应的反应热只与反应体系的始态和终态有关，而与反应的途径无关。应用时把几个已知的热化学方程式通过相加、相减、乘除组合成目标方程式，对应的 ΔH 也进行同样的组合。 例：已知 C(s) + O2(g) = CO2(g) ΔH1 = -393.5 kJ/mol，CO(g) + 1/2O2(g) = CO2(g) ΔH2 = -283.0 kJ/mol，求 C(s) + 1/2O2(g) = CO(g) 的 ΔH。用①减②：ΔH = ΔH1 - ΔH2 = -393.5 - (-283.0) = -110.5 kJ/mol。 **三、化学反应速率** 化学反应速率用单位时间内反应物浓度的减少或生成物浓度的增加来表示，v = Δc÷Δt，单位常用 mol/(L·s) 或 mol/(L·min)。 注意： 1. 固体和纯液体的浓度视为常数，一般不用它们表示速率； 2. 同一反应用不同物质表示的速率数值可能不同，但速率之比等于化学计量数之比。如 aA + bB = cC，则 v(A):v(B):v(C) = a:b:c； 3. 比较不同反应或不同物质的反应快慢时，要先换算成同一种物质表示的速率再比较。 | 影响因素 | 规律 | 原因 | |---|---|---| | 浓度 | 增大反应物浓度，速率加快 | 单位体积内活化分子数增多 | | 温度 | 升高温度，速率加快 | 活化分子百分数增大 | | 压强 | 有气体参加的反应，增大压强（缩小体积），速率加快 | 气体浓度增大 | | 催化剂 | 改变化学反应速率 | 降低活化能，增大活化分子百分数 | **四、化学平衡** 可逆反应在相同条件下既能向正反应方向进行，又能向逆反应方向进行。当正反应速率等于逆反应速率时，各组分浓度不再改变，即达到化学平衡状态。平衡特征概括为"逆、等、动、定、变"。 平衡常数 K：对可逆反应 aA + bB ⇌ cC + dD，K = c(C)的c次方乘以c(D)的d次方，再除以c(A)的a次方乘以c(B)的b次方（各物质浓度的幂之积之比）。K 只与温度有关，K 越大表示反应进行得越完全。 勒夏特列原理：如果改变影响平衡的一个条件（如浓度、温度、压强），平衡就向能够减弱这种改变的方向移动。增大反应物浓度或减小生成物浓度，平衡向正反应方向移动；升高温度，平衡向吸热方向移动；增大压强，平衡向气体分子数减小的方向移动。 **五、电离平衡、水的离子积与 pH 计算** 强电解质（强酸、强碱、大多数盐）在水中完全电离；弱电解质（弱酸、弱碱、水）部分电离，存在电离平衡，如 CH3COOH ⇌ CH3COO⁻ + H⁺。 水的电离：H2O ⇌ H⁺ + OH⁻，水的离子积 Kw = c(H⁺)×c(OH⁻)，25℃ 时 Kw = 1×10⁻¹⁴，Kw 只随温度升高而增大。 pH = -lg c(H⁺)（c(H⁺) 单位为 mol/L）。pH 小于 7 显酸性，pH = 7 显中性，pH 大于 7 显碱性。 例：25℃ 时，0.01 mol/L 盐酸中 c(H⁺) = 0.01 mol/L，pH = 2。 **六、沉淀溶解平衡初步** 难溶电解质如 AgCl 在水中存在溶解平衡：AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)。达到平衡时各离子浓度幂的乘积为溶度积 Ksp，Ksp 只与温度有关。比较同类型难溶电解质时，Ksp 越小越难溶。利用 Ksp 与离子积 Q 的关系可以判断沉淀的生成与溶解：Q 大于 Ksp 生成沉淀，Q = Ksp 处于平衡，Q 小于 Ksp 沉淀溶解。 **拓展**：化学平衡、电离平衡、溶解平衡都属于动态平衡，勒夏特列原理对它们都适用，可以类比学习、触类旁通。

🔍 课堂讲义 · 重点难点解析

**重点一：热化学方程式的书写与盖斯定律应用** 例题：已知 2H2(g) + O2(g) = 2H2O(l) ΔH = -571.6 kJ/mol，写出 1 mol H2 完全燃烧生成液态水的热化学方程式。 分析：571.6 kJ 对应 2 mol H2 燃烧放出的热量，1 mol H2 燃烧放热 571.6÷2 = 285.8 kJ，放热反应的 ΔH 为负值。 解答：H2(g) + 1/2O2(g) = H2O(l) ΔH = -285.8 kJ/mol。 小结：书写热化学方程式时，ΔH 数值必须与化学计量数一一对应，系数减半则 ΔH 也减半，并注意标注各物质的状态。 **难点一：判断化学平衡状态** 例题：恒温恒容条件下，反应 N2 + 3H2 ⇌ 2NH3 已达平衡。下列说法中，能说明反应达到平衡状态的是（ ） A. N2、H2、NH3 的浓度之比为 1:3:2； B. 单位时间内消耗 1 mol N2 的同时生成 2 mol NH3； C. 容器内混合气体的总压强不再改变。 分析：A 中浓度比恰好等于化学计量数之比，只是某一时刻的巧合，并不说明各组分浓度不再改变；B 中"消耗 N2"和"生成 NH3"都是正反应方向，不能说明正逆反应速率相等；该反应是气体分子数减小的反应，总压强不变说明各组分浓度不再改变。 解答：选 C。 小结：判断化学平衡要抓住"正逆反应速率相等"和"各组分浓度不再改变"两条核心标准。 **难点二：pH 的计算** 例题：25℃ 时，0.1 mol/L NaOH 溶液中的 c(H⁺) 是多少？pH 是多少？ 分析：NaOH 完全电离，c(OH⁻) = 0.1 mol/L，由 Kw = c(H⁺)×c(OH⁻) 求出 c(H⁺)。 解答：c(H⁺) = Kw÷c(OH⁻) = 1×10⁻¹⁴÷0.1 = 1×10⁻¹³ mol/L；pH = -lg(1×10⁻¹³) = 13。 小结：计算碱溶液的 pH，要先用水的离子积求出 c(H⁺)，再取负对数；计算酸溶液时则直接用 c(H⁺) 求 pH。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：放热反应与热化学方程式** 题目：已知碳完全燃烧生成 CO2 气体时放出 393.5 kJ 的热量，写出 1 mol 碳完全燃烧的热化学方程式。 分析：反应放热，ΔH 为负值；1 mol 碳对应放出 393.5 kJ 热量。 解答：C(s) + O2(g) = CO2(g) ΔH = -393.5 kJ/mol。 方法小结：先判断反应吸热还是放热确定 ΔH 符号，再写出配平的方程式，并标注物质状态与 ΔH。 **例题二（提高）：化学反应速率的计算** 题目：在 2 L 密闭容器中，氮气与氢气反应生成氨：N2 + 3H2 ⇌ 2NH3，5 s 内 N2 的物质的量由 2 mol 减少到 1 mol，求用 N2 和 H2 表示的反应速率。 分析：先计算 N2 浓度的变化量 Δc(N2) = (2 - 1)÷2 = 0.5 mol/L，再除以时间。 解答：v(N2) = 0.5÷5 = 0.1 mol/(L·s)；由速率之比等于化学计量数之比，v(H2) = 3×v(N2) = 0.3 mol/(L·s)。 方法小结：用不同物质表示的速率之比等于化学计量数之比，可以先求出 N2 的速率再换算成其他物质的速率。 **例题三（综合）：勒夏特列原理与平衡移动** 题目：反应 2SO2(g) + O2(g) ⇌ 2SO3(g) 的 ΔH 小于 0。分别增大 O2 浓度、升高温度、增大压强，平衡分别如何移动？ 分析：增大 O2 浓度，平衡向减小 O2 浓度的方向即正反应方向移动；升高温度，平衡向吸热方向即逆反应方向移动；增大压强，平衡向气体分子数减小的方向即正反应方向移动。 解答：增大 O2 浓度，平衡正向移动；升高温度，平衡逆向移动；增大压强，平衡正向移动。 方法小结：运用勒夏特列原理时抓住"减弱这种改变"这一关键，先判断条件改变的方向，再判断平衡向哪个方向移动。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 焓变与热化学方程式

  1. 1. 判断正误并说明理由：放热反应的 ΔH 大于 0。
    答：错误。放热反应放出热量，ΔH 小于 0；吸热反应的 ΔH 才大于 0。判断时记住"放热为负、吸热为正"。
  2. 2. 下列反应中属于吸热反应的是（ ）A. 氢气在氧气中燃烧；B. 镁与稀盐酸反应；C. 碳酸钙高温分解；D. 盐酸与氢氧化钠溶液中和反应。
    答：选 C。碳酸钙高温分解是分解反应，吸收热量。燃烧、金属与酸反应、中和反应均为放热反应。
  3. 3. 已知 1 mol CH4 完全燃烧生成 CO2 和液态水时放出 890.3 kJ 热量，写出该反应的热化学方程式。
    答：CH4(g) + 2O2(g) = CO2(g) + 2H2O(l) ΔH = -890.3 kJ/mol。注意标注各物质状态，放热反应的 ΔH 为负值。

中等 · 盖斯定律与速率计算

  1. 1. 已知 C(s) + O2(g) = CO2(g) ΔH1 = -393.5 kJ/mol，CO(g) + 1/2O2(g) = CO2(g) ΔH2 = -283.0 kJ/mol，求 C(s) + 1/2O2(g) = CO(g) 的 ΔH。
    答：用①减②得目标反应，ΔH = ΔH1 - ΔH2 = -393.5 - (-283.0) = -110.5 kJ/mol。计算时减去负数要注意变号。
  2. 2. 在 2 L 密闭容器中发生反应 A + 3B = 2C，2 min 内 A 的浓度由 1.0 mol/L 变为 0.4 mol/L，求 v(A)、v(B)、v(C)。
    答：v(A) = (1.0 - 0.4)÷2 = 0.3 mol/(L·min)；由速率之比等于计量数之比，v(B) = 3×0.3 = 0.9 mol/(L·min)，v(C) = 2×0.3 = 0.6 mol/(L·min)。
  3. 3. 反应 N2 + 3H2 ⇌ 2NH3 达到平衡后，其他条件不变，增大压强，平衡向哪个方向移动？为什么？
    答：向正反应方向移动。增大压强时平衡向气体分子数减小的方向移动，正反应方向气体分子数由 4 变为 2，是减小的方向。

难 · 平衡判断与 pH 计算

  1. 1. 恒温恒容下，能说明反应 2HI(g) ⇌ H2(g) + I2(g) 达到平衡状态的是（ ）A. 混合气体颜色不再改变；B. 气体总压强不再改变；C. HI、H2、I2 的浓度之比为 2:1:1。
    答：选 A。I2 蒸气呈紫色，颜色不再改变说明 I2 浓度不再改变，反应达到平衡。该反应前后气体分子数相等，总压强始终不变，B 不能判断；C 中浓度比等于计量数之比不等于平衡状态，平衡时浓度比不一定是 2:1:1。
  2. 2. 25℃ 时，某溶液中 c(OH⁻) = 1×10⁻³ mol/L，求该溶液中的 c(H⁺) 和 pH，并判断溶液酸碱性。
    答：由 Kw = c(H⁺)×c(OH⁻)，c(H⁺) = 1×10⁻¹⁴÷(1×10⁻³) = 1×10⁻¹¹ mol/L；pH = -lg(1×10⁻¹¹) = 11，溶液显碱性。
  3. 3. 某温度下，可逆反应 A(g) + B(g) ⇌ 2C(g) 达到平衡时，测得 c(A) = 0.5 mol/L，c(B) = 0.5 mol/L，c(C) = 1.0 mol/L，计算该温度下的平衡常数 K。
    答：K = c²(C)÷[c(A)×c(B)] = 1.0²÷(0.5×0.5) = 4。注意 K 的表达式中各物质浓度的指数等于其化学计量数。

综合 · 原理综合应用

  1. 1. 已知 N2(g) + 3H2(g) ⇌ 2NH3(g) 的 ΔH 小于 0。合成氨工业生产采用高温高压，请从反应速率与化学平衡两个角度分析采用高温和高压的原因。
    答：从速率角度，升高温度、增大压强都能加快反应速率，缩短达到平衡所需时间；从平衡角度，该反应放热且气体分子数减小，升高温度平衡逆向移动、不利于氨的生成，但工业上还要兼顾速率，故选用合适的温度并用催化剂加快反应，而增大压强既加快速率又使平衡正向移动、提高氨的产率。可见高压对速率和平衡都有利，高温只对速率有利而对平衡不利，实际生产中要兼顾两方面的矛盾，选择适宜条件。
  2. 2. 计算题：0.1 mol 某烃完全燃烧生成 CO2 和水，放出 890.3 kJ 热量，该烃的摩尔质量为 16 g/mol。求：①该烃的相对分子质量；②该烃的分子式。
    答：①摩尔质量为 16 g/mol，相对分子质量在数值上等于摩尔质量，为 16；②设分子式为 CxHy，则 12x + y = 16，只有 CH4 符合（12 + 4 = 16），所以分子式为 CH4。其热化学方程式为 CH4(g) + 2O2(g) = CO2(g) + 2H2O(l) ΔH = -890.3 kJ/mol（对应 1 mol）。
  3. 3. 实验分析：在两支试管中各加入 5 mL 相同浓度的稀盐酸，再分别放入大小相同的锌粒和铜片，观察到只有放入锌粒的试管产生气泡。结合金属活动性和反应速率说明原因，并写出有关化学方程式。
    答：锌比铜活泼，锌能与稀盐酸发生置换反应产生氢气，铜位于金属活动性顺序中氢之后、不与稀盐酸反应，所以只有锌粒试管产生气泡。化学方程式：Zn + 2HCl = ZnCl2 + H2↑。这说明不同金属与同种酸反应的速率不同，本质是金属活动性强弱不同。

💬 课后反馈

**学生常见错误** 1. 把 ΔH 的符号写反，误以为放热反应的 ΔH 为正，应牢记"放热为负、吸热为正"。 2. 书写热化学方程式漏标物质状态，或 ΔH 与化学计量数不对应，系数加倍了 ΔH 却忘记加倍。 3. 判断平衡状态时，只看到浓度之比等于计量数之比就下结论，没有抓住"正逆速率相等、浓度不再改变"的本质。 4. 运用勒夏特列原理时，增大压强没有先判断反应前后气体分子数的变化就盲目下结论。 5. 计算碱溶液 pH 时直接套 lg 公式，忘记先由 Kw 求 c(H⁺)。 **教学改进建议** 1. 用"能量图"直观展示放热与吸热，帮助学生建立 ΔH 符号与能量高低的关系。 2. 热化学方程式书写采用"分步模板"训练，每一步骤提出固定要求，反复订正。 3. 化学平衡判断采用"反例辨析法"，列举似是而非的说法逐条分析。 4. 勒夏特列原理配合动画演示，先看现象再归纳规律，最后迁移到电离平衡与溶解平衡。 **分层辅导建议** - 基础层：重点掌握 ΔH 符号判断与热化学方程式的基本书写，熟记常见放热反应和吸热反应。 - 提高层：训练盖斯定律计算与速率换算，学会把不同物质表示的速率统一后比较快慢。 - 拓展层：综合运用平衡移动原理分析合成氨等实际问题，尝试 Ksp 的简单计算与判断。 **给家长的建议** 1. 孩子计算 ΔH 反复出错时，请提醒他"先判断放热还是吸热，再写正负号"。 2. 鼓励孩子把化学方程式当作"化学语言"来读，每天默写 2 至 3 个，配平与条件一样都不能少。 3. 学完化学平衡后，可让孩子用"动态平衡"的思想解释生活中的现象，如密封水杯中水的蒸发与凝结达到平衡，帮助建立理解。
