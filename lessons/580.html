高中高一化学物质的量浓度与溶液配制

📝 备课方案

**教学目标** 1. 掌握物质的量浓度的概念、公式及单位。 2. 学会一定物质的量浓度溶液的配制（容量瓶使用）。 3. 掌握溶液稀释、混合与误差分析。 **教学重点**：溶液配制操作与误差分析。 **教学难点**：配制过程中的误差分析。 **教学方法**：实验演示、操作规范训练、误差归类。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、物质的量浓度** - 定义：单位体积溶液中所含溶质的物质的量。 - 公式：$c=\\frac{n}{V}$，单位 mol/L。 - 注意：V 是溶液的体积，不是溶剂的体积。 **二、有关计算** - 由质量求浓度：$c=\\frac{m}{MV}$。 - 稀释定律：$c_1V_1=c_2V_2$（稀释前后溶质物质的量不变）。 - 混合（无化学反应）：$c_混V_混=c_1V_1+c_2V_2$。 - 由密度与质量分数转化：$c=\\frac{1000\rho w}{M}$。 **三、配制的仪器** - 托盘天平（量筒）、烧杯、玻璃棒、容量瓶（规格 100、250、500、1000mL）、胶头滴管。 - 容量瓶使用注意：只能配制指定规格溶液；不能加热、不能长期存放溶液；使用前检查是否漏水。 **四、配制步骤** - 计算 → 称量（量取）→ 溶解（冷却至室温）→ 转移（玻璃棒引流）→ 洗涤（烧杯与玻璃棒 2 至 3 次，洗涤液转入容量瓶）→ 定容（胶头滴管加水至刻度线）→ 摇匀 → 装瓶贴签。 **五、误差分析** - 依据 $c=\\frac{n}{V}$，n 偏大或 V 偏小则 c 偏大，反之偏小。 - 未冷却就转移，冷却后 V 偏小，c 偏大；洗涤液未转入，n 偏小，c 偏小；定容俯视 V 偏小 c 偏大、仰视 V 偏大 c 偏小。 **六、定容操作** - 加水至刻度线以下 1 至 2cm 处改用胶头滴管滴加。 - 视线应与刻度线相平，俯视读数 c 偏大、仰视 c 偏小。 **七、质量分数与物质的量浓度** - 质量分数 $w=\\frac{m_{溶质}}{m_{溶液}}$。 - 密度 $\rho$、质量分数 w、物质的量浓度 c 之间的换算关系 $c=\\frac{1000\rho w}{M}$。

🔍 课堂讲义 · 重点难点解析

**重点：溶液配制操作流程** 配制的核心是"计算→称量→溶解→转移→洗涤→定容→摇匀"。特别强调：溶解后必须冷却到室温再转移，否则热胀冷缩使溶液体积不准且损伤容量瓶；转移必须用玻璃棒引流；烧杯和玻璃棒必须洗涤，洗涤液一并转入，否则溶质损失使浓度偏小；定容时视线要与刻度线相平，俯视、仰视均产生偏差。每一步操作的规范直接决定误差方向。 **难点：误差分析** 误差分析的本质是判断操作对 n（溶质物质的量）与 V（溶液体积）的影响。n 偏大则 c 偏大（如称量时砝码生锈），n 偏小则 c 偏小（如洗涤液未转移）；V 偏大则 c 偏小（如仰视定容），V 偏小则 c 偏大（如俯视定容）。建议按"影响因素—偏大偏小—结果"三步列表分析，理清因果。 **易错提醒**：容量瓶只有一个刻度线，不能配制任意体积的溶液；摇匀后液面低于刻度线属正常现象，不能再加水；固体用托盘天平称量、液体用量筒量取，不可混用；配制 NaOH 溶液时应将固体放在烧杯中称量（易潮解且腐蚀托盘）。

✏️ 课堂讲义 · 典型例题精讲

**例1**：配制 500mL 0.1mol/L 的 NaCl 溶液，需称取 NaCl 多少克？（M=58.5g/mol） 解：$n=cV=0.1\times0.5=0.05$mol，$m=nM=0.05\times58.5=2.925$g。 **例2**：把 4.0g NaOH 固体溶于水配成 500mL 溶液，求该溶液的物质的量浓度。 解：$n=\\frac{4.0}{40}=0.1$mol，$c=\\frac{n}{V}=\\frac{0.1}{0.5}=0.2$mol/L。 **例3**：取 10mL 0.2mol/L 的 H2SO4 溶液加水稀释至 100mL，求稀释后溶液的浓度。 解：$c_1V_1=c_2V_2$，$0.2\times10=c_2\times100$，$c_2=0.02$mol/L。 **例4**：配制 250mL 0.5mol/L 的 CuSO4 溶液，应称取 CuSO4·5H2O 的质量。（M=250g/mol） 解：$n=0.5\times0.25=0.125$mol，$m=0.125\times250=31.25$g。 **例5**：配制一定物质的量浓度溶液时，①烧杯未洗涤；②定容时俯视刻度线。判断浓度偏差。 解：①烧杯中残留溶质未转入，n 偏小，c 偏小；②俯视定容，加水偏少，V 偏小，c 偏大。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 基本概念

  1. 1. 写出物质的量浓度的定义与公式。
    答：单位体积溶液中所含溶质的物质的量，$c=\\frac{n}{V}$，单位 mol/L。注意 V 为溶液的体积而非溶剂体积。
  2. 2. 配制 200mL 0.5mol/L 的 NaOH 溶液，需称取 NaOH 多少克？（M=40g/mol）
    答：$n=0.5\times0.2=0.1$mol，$m=0.1\times40=4.0$g。

中等 · 稀释与换算

  1. 1. 把 0.1mol NaCl 固体配成 250mL 溶液，浓度是多少？
    答：$c=\\frac{n}{V}=\\frac{0.1}{0.25}=0.4$mol/L。
  2. 2. 100mL 6mol/L 的盐酸加水稀释到 1L，稀释后浓度为多少？
    答：$c_1V_1=c_2V_2$，$6\times0.1=c_2\times1$，$c_2=0.6$mol/L。
  3. 3. 计算质量分数 98%、密度 1.84g/mL 的浓硫酸的物质的量浓度。（M=98g/mol）
    答：$c=\\frac{1000\rho w}{M}=\\frac{1000\times1.84\times0.98}{98}=18.4$mol/L。

难 · 容量瓶与误差

  1. 1. 配制 480mL 0.1mol/L 的 NaCl 溶液，应选用什么规格的容量瓶？需称取 NaCl 多少克？
    答：容量瓶没有 480mL 规格，应选用 500mL 容量瓶。$n=0.1\times0.5=0.05$mol，$m=0.05\times58.5=2.925$g。
  2. 2. 配制 250mL 0.1mol/L NaOH 溶液，若①称量时 NaOH 放在纸上称量（吸潮）；②溶解后未冷却即转移定容。分别判断浓度偏差。
    答：①NaOH 在纸上称量会吸潮，实际有效质量偏小，n 偏小，c 偏小；②未冷却即转移定容，液体热胀，冷却后体积收缩，V 偏小，c 偏大。

综合 · 综合计算

  1. 1. 将 100mL 0.3mol/L 与 300mL 0.1mol/L 的 NaCl 溶液混合（忽略体积变化），求混合后溶液的浓度。
    答：$n_总=0.3\times0.1+0.1\times0.3=0.03+0.03=0.06$mol，$V_总=0.4$L，$c=\\frac{0.06}{0.4}=0.15$mol/L。
  2. 2. 配制 500mL 0.1mol/L 的稀硫酸，需 18.4mol/L 的浓硫酸多少毫升？稀释时应如何操作？
    答：$18.4\times V=0.1\times0.5$，$V=0.00272$L=2.72mL。稀释时把浓硫酸沿器壁缓缓倒入水中并不断搅拌（酸入水），切不可将水倒入浓硫酸中，防止放出大量热引起液体飞溅。

💬 课后反馈

学生对物质的量浓度公式及稀释定律应用熟练，基本操作流程记忆清楚，但容量瓶规格选择、误差分析（俯视仰视方向）失分较多，浓硫酸稀释的规范操作易忽略。建议安排一次完整配制实验，用实际误差分析练习巩固"n、V 谁变"的分析思路。
