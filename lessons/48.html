初中九年级化学《常见的酸》教案

初中九年级化学常见的酸

📝 备课方案

**教学目标** 1. 了解盐酸、硫酸、硝酸的物理性质，知道浓盐酸有挥发性、浓硫酸有吸水性、浓硝酸见光易分解等特性。 2. 掌握酸的化学性质通性：酸能与酸碱指示剂、活泼金属、金属氧化物、碱、某些盐反应，并能正确书写相关化学方程式。 3. 掌握浓硫酸稀释的正确操作及注意事项，理解浓硫酸的吸水性、脱水性与强腐蚀性。 4. 了解溶液酸碱性的强弱可用 pH 表示，会用 pH 试纸测定溶液的酸碱度，知道 pH 与溶液酸碱性的关系。 5. 认识酸在生活生产中的应用，培养安全规范实验的意识。 **教学重点**：酸的化学性质通性；浓硫酸的稀释方法。 **教学难点**：根据酸的化学性质书写化学方程式；浓硫酸吸水性与脱水性的区别。 **教学方法**：实验探究法、比较归纳法、多媒体演示法、生活情境教学法。 **教学准备**：稀盐酸、稀硫酸、浓硫酸、紫色石蕊试液、无色酚酞试液、锌粒、铁钉、氧化铜、氢氧化钠溶液、碳酸钠粉末、pH 试纸、试管、玻璃棒、烧杯等。 **课时安排**：3课时（第1课时：盐酸、硫酸、硝酸的物理性质；第2课时：酸的化学性质通性；第3课时：浓硫酸的特性、pH 与溶液酸碱性）。

📖 课堂讲义 · 核心知识点

**一、常见的酸** 盐酸：HCl 气体的水溶液。纯净的盐酸无色，工业盐酸因含有铁离子等杂质呈黄色；有刺激性气味；有挥发性，打开瓶盖时瓶口出现白雾（挥发出的 HCl 气体与空气中水蒸气结合形成盐酸小液滴）。 硫酸：H2SO4。纯净的硫酸是无色、黏稠的油状液体，不易挥发；浓硫酸具有吸水性，可作某些气体的干燥剂。 硝酸：HNO3。无色液体，有刺激性气味，有挥发性；见光或受热易分解，因此保存在棕色瓶中并密封避光放置。 | 酸 | 颜色与状态 | 气味 | 挥发性 | 保存方法 | |---|---|---|---|---| | 盐酸 | 无色液体（工业盐酸黄色） | 有刺激性气味 | 易挥发，瓶口有白雾 | 密封保存 | | 硫酸 | 无色黏稠油状液体 | 无味 | 不易挥发 | 密封保存 | | 硝酸 | 无色液体 | 有刺激性气味 | 易挥发 | 棕色瓶避光保存 | **二、酸的化学性质通性** 1. 酸与酸碱指示剂作用：紫色石蕊试液遇酸变红色，无色酚酞试液遇酸不变色。 2. 酸与活泼金属反应（置换反应）：酸 + 活泼金属 = 盐 + 氢气 Zn + H2SO4 = ZnSO4 + H2↑；Zn + 2HCl = ZnCl2 + H2↑；Fe + 2HCl = FeCl2 + H2↑。 注意：只有排在金属活动性顺序中氢之前的金属才能与稀盐酸、稀硫酸反应放出氢气；铁与稀盐酸、稀硫酸反应生成亚铁盐（溶液显浅绿色），不是铁盐。 3. 酸与金属氧化物反应：酸 + 金属氧化物 = 盐 + 水 Fe2O3 + 6HCl = 2FeCl3 + 3H2O（用于除去铁锈，溶液变黄色）；CuO + H2SO4 = CuSO4 + H2O（黑色氧化铜溶解，溶液变蓝色）。 4. 酸与碱反应（中和反应）：酸 + 碱 = 盐 + 水 HCl + NaOH = NaCl + H2O；H2SO4 + 2NaOH = Na2SO4 + 2H2O。 5. 酸与某些盐反应：酸 + 盐 = 新盐 + 新酸 Na2CO3 + 2HCl = 2NaCl + H2O + CO2↑（有气泡产生）；HCl + AgNO3 = AgCl↓ + HNO3（检验氯离子，生成白色沉淀）；H2SO4 + BaCl2 = BaSO4↓ + 2HCl（检验硫酸根离子，生成白色沉淀）。 **三、浓硫酸的特性** 1. 吸水性：浓硫酸能吸收空气中的水分和气体中的水蒸气，可用作干燥剂（不能干燥氨气等碱性气体）。 2. 脱水性：浓硫酸能把纸张、木材、蔗糖等有机物中的氢、氧元素按水的组成脱去，使其炭化变黑，如 C12H22O11 = 12C + 11H2O。 3. 强腐蚀性：浓硫酸有很强的腐蚀性，使用时要格外小心，若溅到皮肤上，应立即用大量水冲洗，再涂上 3% 至 5% 的碳酸氢钠溶液。 4. 浓硫酸的稀释：一定要把浓硫酸沿器壁缓缓注入水中，并用玻璃棒不断搅拌，切不可把水倒入浓硫酸中。因为水的密度比浓硫酸小，水会浮在浓硫酸上面，稀释时放出大量热会使水剧烈沸腾，酸液飞溅伤人。 **四、pH 与溶液酸碱性** pH 用于表示溶液酸碱性的强弱，范围通常在 0 至 14 之间。 pH 小于 7 显酸性，pH 越小酸性越强；pH = 7 显中性；pH 大于 7 显碱性，pH 越大碱性越强。 测定方法：用洁净的玻璃棒蘸取少量待测液，滴在 pH 试纸上，与标准比色卡对照读出 pH。注意：pH 试纸不能直接伸入待测液，不能先用水润湿，否则会稀释溶液使读数不准。 应用：测定雨水 pH 可判断是否形成酸雨（pH 小于 5.6 的降水称为酸雨）。 **拓展**：酸的化学性质通性，本质上是酸在水溶液中都能电离出氢离子（H⁺），所以五条通性都与 H⁺ 有关，只要抓住了"酸 = H⁺ + 酸根离子"这一本质，就抓住了酸的通性。

🔍 课堂讲义 · 重点难点解析

**重点一：酸的化学性质通性** 例题：将一枚生锈的铁钉放入足量稀硫酸中，写出有关反应的化学方程式，并描述观察到的现象。 分析：铁锈的主要成分是 Fe2O3，先与稀硫酸反应除去铁锈，铁露出来后继续与稀硫酸反应放出氢气。 解答：Fe2O3 + 3H2SO4 = Fe2(SO4)3 + 3H2O，现象是铁锈逐渐溶解，溶液由无色变为黄色；然后 Fe + H2SO4 = FeSO4 + H2↑，现象是铁钉表面有气泡产生，溶液由黄色逐渐变为浅绿色。 小结：分析"除锈"类问题要分两步：先除氧化膜，后金属与酸反应，注意铁与酸反应生成亚铁盐。 **难点一：浓硫酸的吸水性与脱水性** 例题：浓硫酸敞口放置一段时间后质量增大；把浓硫酸滴到蔗糖上，蔗糖逐渐变黑。两种现象分别体现浓硫酸的什么性质？ 分析：敞口放置是吸收了空气中的水分，属于吸水性；蔗糖变黑是浓硫酸把蔗糖中的氢、氧元素按水的组成脱去，剩下碳，属于脱水性。 解答：质量增大体现吸水性；蔗糖变黑体现脱水性。吸水性是吸收现成的水分子，脱水性是改变物质的化学组成、夺取其中氢氧元素。 小结：区分关键看"是否有现成的液态水被吸收"和"是否改变了物质本身的化学组成"。 **难点二：pH 与酸碱性的判断** 例题：向稀盐酸中不断加水稀释，pH 如何变化？向稀盐酸中加入过量的氢氧化钠溶液，pH 如何变化？ 分析：稀释使 c(H⁺) 减小，pH 逐渐增大，但只会无限接近 7，不会大于 7；加入氢氧化钠与盐酸中和，pH 增大到 7，碱过量后继续增大到大于 7。 解答：加水稀释，pH 逐渐增大、接近 7；加过量氢氧化钠，pH 逐渐增大，先到 7，再增大到大于 7。 小结：稀释酸只能使溶液接近中性，只有加碱过量才能使溶液显碱性。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：酸的物理性质** 题目：打开盛浓盐酸的试剂瓶瓶塞，看到瓶口有白雾，这是为什么？ 分析：浓盐酸有挥发性，挥发出的氯化氢气体在瓶口与空气中的水蒸气结合成盐酸小液滴。 解答：浓盐酸易挥发，挥发出的 HCl 气体遇空气中水蒸气形成盐酸小液滴，悬浮在瓶口形成白雾。白雾是液体小液滴，与白烟（固体小颗粒）不同。 方法小结：挥发性是浓盐酸和浓硝酸共有的性质，注意区分"白雾"与"白烟"。 **例题二（提高）：酸的化学性质** 题目：写出稀盐酸分别与铁、氧化铜、氢氧化钠、碳酸钙反应的化学方程式。 分析：按酸的通性逐条书写，注意配平、反应条件与气体沉淀箭头的标注。 解答：Fe + 2HCl = FeCl2 + H2↑；CuO + 2HCl = CuCl2 + H2O；HCl + NaOH = NaCl + H2O；CaCO3 + 2HCl = CaCl2 + H2O + CO2↑。 方法小结：书写酸与盐的反应，要熟记常见盐的溶解性，牢记"碳酸盐 + 酸 = 盐 + 水 + 二氧化碳"。 **例题三（综合）：鉴别与检验** 题目：有两瓶无色溶液，分别可能是稀盐酸和稀硫酸，如何鉴别？写出有关化学方程式。 分析：稀盐酸与稀硫酸都含 H⁺，鉴别它们要靠阴离子的特征反应，可用含钡离子的溶液检验硫酸根离子。 解答：各取少量溶液，分别滴加氯化钡溶液，产生白色沉淀的是稀硫酸：H2SO4 + BaCl2 = BaSO4↓ + 2HCl；无明显现象的是稀盐酸。 方法小结：鉴别酸的关键是利用阴离子的特征反应：氯离子用硝酸银溶液检验，硫酸根离子用氯化钡（含 Ba²⁺）溶液检验。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 物理性质与酸的通性

  1. 1. 填空：纯净的盐酸是（ ）色液体，有（ ）气味，具有（ ）性，打开瓶盖瓶口会出现（ ）。
    答：无色；刺激性；挥发；白雾。白雾是挥发出的 HCl 气体与水蒸气结合成的盐酸小液滴。
  2. 2. 紫色石蕊试液遇稀盐酸变（ ）色，无色酚酞试液遇稀硫酸（ ）（填"变"或"不变"）色。
    答：红色；不变。酸都能使紫色石蕊试液变红，都不能使无色酚酞试液变色。
  3. 3. 写出锌与稀硫酸反应的化学方程式，并指出反应类型。
    答：Zn + H2SO4 = ZnSO4 + H2↑，属于置换反应。锌排在金属活动性顺序中氢之前，能与稀硫酸反应放出氢气。

中等 · 方程式书写与稀释操作

  1. 1. 写出稀盐酸与氧化铜、稀盐酸与氢氧化钠溶液反应的化学方程式。
    答：CuO + 2HCl = CuCl2 + H2O（黑色氧化铜溶解，溶液变蓝色）；HCl + NaOH = NaCl + H2O（中和反应，无现象，可借助酚酞判断反应是否发生）。
  2. 2. 将生锈的铁钉放入过量的稀盐酸中，观察到的现象是（ ）A. 铁锈逐渐溶解，溶液变黄色；B. 有气泡产生；C. 先看到铁锈溶解、溶液变黄，后有气泡产生、溶液变浅绿色。
    答：选 C。先发生 Fe2O3 + 6HCl = 2FeCl3 + 3H2O，溶液变黄色；铁锈除尽后发生 Fe + 2HCl = FeCl2 + H2↑，有气泡产生，溶液变浅绿色。
  3. 3. 实验室稀释浓硫酸时，正确的操作是什么？为什么不能把水倒入浓硫酸中？
    答：把浓硫酸沿器壁缓缓注入水中，并用玻璃棒不断搅拌。若把水倒入浓硫酸中，水的密度小浮在浓硫酸表面，稀释时放出大量热使水剧烈沸腾，酸液飞溅伤人。

难 · pH 变化、鉴别与计算

  1. 1. 某溶液的 pH = 3，要使它变成 pH = 4，可采取下列哪种方法？（ ）A. 加少量水；B. 加少量稀盐酸；C. 加少量氢氧化钠溶液。
    答：选 A 或 C。pH 由 3 变 4，酸性减弱：加水稀释可降低 c(H⁺)；加少量氢氧化钠溶液可中和部分 H⁺。加稀盐酸会使酸性增强、pH 更小，错误。
  2. 2. 鉴别稀盐酸和蒸馏水，下列试剂中不能达到目的的是（ ）A. 紫色石蕊试液；B. 无色酚酞试液；C. 锌粒。
    答：选 B。稀盐酸使石蕊变红、锌粒与其反应放出气泡，蒸馏水都无此现象，A、C 可以鉴别；酚酞遇酸不变色、遇蒸馏水也不变色，不能鉴别。
  3. 3. 计算：6.5 g 锌与足量稀硫酸反应，可生成氢气多少克？（写出完整计算过程）
    答：设生成氢气质量为 x。Zn + H2SO4 = ZnSO4 + H2↑，65 比 2 = 6.5 g 比 x，解得 x = 0.2 g。答：可生成氢气 0.2 g。计算要体现设、写、算、答四步。

综合 · 实际应用与实验探究

  1. 1. 某工厂排放的废水中含有盐酸，为使废水达标排放，可向废水中加入什么物质？写出反应的化学方程式。
    答：可加入熟石灰（氢氧化钙）：2HCl + Ca(OH)2 = CaCl2 + 2H2O。中和反应把酸性废水处理成接近中性，生成的氯化钙无毒无害。
  2. 2. 完成下列转化，写出每一步的化学方程式：CaCO3 → CaCl2 → CaCO3。
    答：CaCO3 + 2HCl = CaCl2 + H2O + CO2↑；CaCl2 + Na2CO3 = CaCO3↓ + 2NaCl。第一个反应体现酸与盐的反应，第二个体现可溶性盐与盐的复分解反应。
  3. 3. 实验探究：向盛有少量碳酸钠粉末的试管中滴加稀盐酸，观察到什么现象？写出化学方程式。再向反应后的溶液中滴加澄清石灰水，若出现白色浑浊，说明反应后溶液中存在什么离子？
    答：现象：有大量气泡产生。化学方程式：Na2CO3 + 2HCl = 2NaCl + H2O + CO2↑。向反应后溶液中滴加澄清石灰水出现白色沉淀（碳酸钙），说明反应后溶液中存在 CO3²⁻，即碳酸钠过量，与盐酸反应后仍有剩余。

💬 课后反馈

**学生常见错误** 1. 把浓盐酸瓶口的"白雾"误写成"白烟"，分不清液体小液滴与固体小颗粒。 2. 书写金属与酸反应方程式时，铁生成物错写成 FeCl3，实际上铁与稀盐酸、稀硫酸反应生成亚铁盐 FeCl2、FeSO4。 3. 稀释浓硫酸时把水倒入浓硫酸，操作顺序记反，这是最大的安全隐患。 4. 判断 pH 变化时认为向酸中加水稀释 pH 能变成大于 7，不理解稀释只能使 pH 无限接近 7。 5. 中和反应无明显现象，忘记借助指示剂判断反应是否恰好完全进行。 **教学改进建议** 1. 用"性质卡片"进行多轮记忆：每种酸的物理性质、化学性质、用途各一张卡，随时抽测。 2. 酸的化学性质通性编成口诀："酸通性有五条，指示剂变红，金属换氢气，氧化物成盐加水，碱中和，盐置换。" 3. 浓硫酸稀释操作要求学生边操作边背口诀："酸入水、沿器壁、慢慢倒、不断搅"，并模拟错误操作说明危害。 4. 加强"书写方程式三步自查"：一查配平、二查条件、三查气体沉淀箭头。 **分层辅导建议** - 基础层：熟记三种酸的物理性质与五条通性，能补全简单化学方程式。 - 提高层：会写完整方程式并配平，掌握鉴别与除杂的基本方法。 - 拓展层：会进行含杂质的计算，会设计实验探究酸的化学性质。 **给家长的建议** 1. 提醒孩子浓硫酸安全第一，稀释操作口诀要牢记。 2. 鼓励孩子在家里寻找含酸的物质（如食醋含醋酸、柠檬含柠檬酸），说说它们的用途。 3. 方程式是化学的"语言"，请孩子每天默写 2 个方程式，特别注意反应条件、气体沉淀箭头。
