高中高三语文《论述类文本阅读方法》教案

高中高三语文论述类文本阅读方法

📝 备课方案

**教学目标** 1. 掌握论述类文本的文体特征，能快速把握文章的中心论点、分论点、论据类型与论证方法，读懂"文章写了什么、怎么写的"。 2. 熟悉高考论述类文本选择题的命题方式，重点识别"偷换概念、以偏概全、无中生有、强加因果、混淆时态、曲解文意"等六类陷阱。 3. 学会运用"定位原文—比对分析—辨析正误"的三步解题法，提高选项判断的准确率与速度。 4. 能对文本观点进行合理推断，掌握推断题的"依托文本、合乎逻辑、适度延伸"原则，区分合理推断与无据推断。 **教学重点**：中心论点与论证结构的把握；六类命题陷阱的识别与排除。 **教学难点**：推断题中"合理推断"与"过度推断"的界限判断；选项与原文"词语置换"背后的语义辨析。 **教学方法**：原文对照法、题组分类训练法、错因归类法，突出"理清脉络、精确定位"。 **教学准备**：多媒体课件、高考论述类真题汇编、常见命题陷阱对照表、限时阅读训练学案。 **课时安排**：共 2 课时。第 1 课时文体特征与阅读方法（论点论据论证、圈点勾画），第 2 课时选择题陷阱辨析与推断题策略（真题实战、错因归类），并完成限时训练与小结。

📖 课堂讲义 · 核心知识点

**一、文体特征与阅读方法** 论述类文本由论点、论据、论证构成。中心论点常在标题、开头或结尾直接呈现，也可分析归纳得出；论据分事实论据（事例、数据、史实）与道理论据（名言、原理）；论证方法有举例、道理、对比、比喻、引用论证等，结构常见总分式、并列式、递进式、对照式。阅读三步：通读全文圈点各段中心句，理清段落逻辑；整合信息概括大意，把握中心论点；带着问题回读原文精确定位。对"都、全、最、必然、有些、因为"等限定词与逻辑词要格外敏感，它们常是设陷处。 **二、选择题六类陷阱与排除** 一是偷换概念，换成内涵不同的相近概念；二是以偏概全，把"部分"说成"全部"；三是无中生有，选项无原文依据；四是强加因果，无因果关系说成因果或颠倒；五是混淆时态，把"已然"说成"未然"；六是曲解文意，断章取义。排除技巧：逐项回原文定位，与原文句逐句比对，重点查限定词、程度词、范围词与逻辑关系；选项含"全部、一定、必然"等绝对化表述须警惕；原文有"可能、大多"而选项删去的多为扩大范围。 **三、推断题策略** 推断须有原文依据、合乎逻辑、适度延伸，不改变原文观点与前提。错误选项多属"过度推断"（把可能说成必然）或"反向推断"（否定改成肯定）。先明确原文观点与条件，再查选项前提是否一致、推断方向是否相悖。

🔍 课堂讲义 · 重点难点解析

**重点一：概括中心论点** 例题：某文本各段首句分别谈家国情怀、家庭伦理、责任担当、新时代新内涵，请概括中心论点。 分析：前三个分论点层层递进，末段作时代延伸。 解答：中国传统文化中的家国情怀内涵丰富、层层递进，并在新时代获得新发展。 小结：抓段首句与段末总结句，梳理分论点逻辑再整合。 **重点二：选择题陷阱识别** 例题：原文说"汉代经学在一定程度上推动了文字学研究的进步"，选项说"完全决定了文字学研究的进步"。 分析：把"在一定程度上推动"偷换为"完全决定"，程度词被改动。 解答：判错。比对时注意程度与范围的悬殊。 小结：绝对化词语都要回原文核查。 **难点一：合理推断与过度推断** 例题：原文说"古代书院注重学术自由的传统值得今人借鉴"，选项说"当代教育应当完全恢复古代书院的办学模式"。 分析：只说"值得借鉴"，选项推进为"完全恢复"，属过度推断。 解答：判错。推断须与原文观点方向一致。 小结：沾边不算对，有据才成立。 **难点二：词语置换辨析** 例题：原文说"儒家经典保存了大量珍贵资料"，选项说"完整记录了全部细节"。 分析："大量珍贵资料"被置换成"完整记录全部细节"，数量范围被夸大。 解答：判错。逐一核对数量词、范围词、程度词。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（选择题比对）** 题目：原文："中国古代的游观传统起源于上古的祭祀与巡狩活动，至两汉发展为文人登高览胜的风气。游观不仅是身体的游历，更是心灵的安顿。" 选项：A 游观传统可上溯至上古祭祀巡狩；B 两汉登高览胜已成文人普遍风气；C 游观只关注身体层面，与心灵安顿无关；D 文人在自然与人文对照中安放精神世界。 解析：A 对应"起源于上古祭祀与巡狩"；B 对应"至两汉发展为风气"；C 把"不仅……更是"的递进曲解为"只……没有"，属曲解文意；D 对应末句。故答案 C。 方法小结：重点看"不仅……更是"等关联词的语义重心。 **例题 2（推断题）** 题目：原文："数字技术使知识获取空前便捷，但信息碎片化带来深度思考下降的隐忧，因此重建深度阅读习惯尤为必要。"推断符合原文的一项是：A 数字技术已使深度思考能力完全丧失；B 便捷化是数字技术唯一正面影响；C 为应对碎片化隐忧，重建深度阅读习惯很有必要；D 只要普及数字技术，注意力问题就自动解决。 解析：A 把"隐忧"说成"完全丧失"，过度且绝对；B"唯一"缩小范围；C 与原文直接对应，正确；D"只要……就"属强加因果。故答案 C。 方法小结：先找依据句，再查绝对化与因果。 **例题 3（论证思路）** 题目：原文围绕"城市更新中的文化记忆"从物质遗存、生活气息、数字手段三方面展开，分析论证方法与思路。 解析：三层并列属并列结构；列举举措属举例论证；各有侧重含对比。思路为先提总观点，再分层论述，由实到虚，最后综合强调意义。 方法小结：按"提出观点—分层论证—总结提升"组织。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 基础巩固

  1. 1. 阅读下文，完成选择。原文："读书足以怡情，足以博彩，足以长才。其怡情也，最见于独处幽居之时；其博彩也，最见于高谈阔论之中；其长才也，最见于处世判事之际。"下列对"读书"三种作用的理解，正确的一项是：A. 怡情只适用于独处时，与外界无关；B. 博彩专指获得物质财富；C. 怡情、博彩、长才分别见于独处、交谈与办事之时；D. 长才与读书无关，全靠实践。
    答：C。原文分别以"最见于独处幽居之时""最见于高谈阔论之中""最见于处世判事之际"对应怡情、博彩、长才，A 项"只适用于"以偏概全，B 项把"博彩"曲解为物质财富，D 项与原文矛盾。
  2. 2. 阅读下文，完成选择。原文："实践是检验真理的唯一标准，这是由真理的本性和实践的特点决定的。"下列理解正确的一项是：A. 检验真理的标准可以是多重的；B. 实践是检验真理的唯一标准；C. 真理的本性决定了实践可有可无；D. 只要实践就能产生真理。
    答：B。原文明确说"唯一标准"，A 项"多重"与之矛盾，C 项"可有可无"曲解原文，D 项"只要实践就能"属强加因果。
  3. 3. 判断下列说法的正误并说明理由："文章标题有时能直接揭示中心论点。"
    答：正确。标题是文章的旗帜，许多论述类文本的标题就是中心论点的概括，如《拿来主义》等，读文时先看标题可快速把握论述方向。
  4. 4. 下列句子中，属于道理论据的一项是：A. 司马迁忍辱负重写成《史记》；B. 牛顿从苹果落地发现万有引力；C. 荀子说"不积跬步，无以至千里"；D. 全国脱贫人口数据统计。
    答：C。C 是引用名人名言，属道理论据；A、B 是事例，D 是数据，均属事实论据。

中等 · 能力提升

  1. 1. 阅读下文，完成选择。原文："人工智能的发展在带来生产效率跃升的同时，也引发了就业结构变化的隐忧。研究表明，重复性岗位所受冲击最大，而创造性岗位反而可能迎来新的机遇。"下列理解正确的一项是：A. 人工智能将消除所有重复性岗位；B. 创造性岗位必然不受任何影响；C. 重复性岗位受冲击大，创造性岗位或迎来新机遇；D. 就业结构的变化完全由人工智能引起。
    答：C。A 项"所有"绝对化，原文只说"冲击最大"；B 项"必然不受影响"过度推断；D 项"完全由"以偏概全；C 项忠实于原文。
  2. 2. 原文说"传统村落保护的核心不在于建筑的翻新，而在于生活方式的延续"，据此推断正确的一项是：A. 建筑翻新对传统村落毫无意义；B. 只要生活方式延续，村落就必然兴旺；C. 保护传统村落应把生活方式的延续放在重要位置；D. 建筑翻新必然破坏生活方式。
    答：C。原文强调"核心在于生活方式的延续"，C 项与原文一致；A、D 属极端化推断，B 项"必然兴旺"过度推断。
  3. 3. 请辨析下列选项的设错类型："原文说学者们「多数认为」某史料可信，选项说「所有学者都认为」该史料可信。"
    答：属以偏概全（扩大范围）。原文的"多数认为"是部分情况，选项改为"所有学者都认为"，把部分说成全称，扩大了论述范围。
  4. 4. 阅读下文，完成选择。原文："文学的想象看似天马行空，实则根植于现实生活的土壤，任何脱离现实的想象都会因缺乏根基而失去感染力。"下列理解不正确的一项是：A. 文学想象与现实生活密不可分；B. 脱离现实的想象缺少感染力；C. 文学的想象可以完全脱离现实而独立存在；D. 有现实根基的想象才有感染力。
    答：C。原文明确说想象"根植于现实生活的土壤"，C 项与之直接矛盾；A、B、D 均符合原文。

难 · 综合挑战

  1. 1. 阅读下文，完成选择。原文："学术创新并非凭空创造，它一方面建立在前人研究的基础上，另一方面又必须突破前人结论的局限。可见，继承与突破是学术创新不可分割的两个侧面。"下列推断正确的一项是：A. 完全没有继承的成果就不可能是学术创新；B. 只要突破前人结论，就一定是学术创新；C. 学术创新可以完全无视前人研究；D. 继承与突破相互矛盾，不可兼得。
    答：A。由"建立在前人研究的基础上"可知创新离不开继承，A 项推断成立；B 项"只要……就"把必要条件当充分条件，过度推断；C 项与原文矛盾；D 项否认二者的统一，曲解原文。
  2. 2. 阅读下文，完成选择。原文："宋代书院以自由讲学、门户开放著称，学者往来论辩，学风活跃，这与当时宽松的文化政策密不可分。"下列理解不正确的一项是：A. 宋代书院讲学较为自由；B. 文化政策的宽松对书院学风有重要影响；C. 宽松的文化政策是书院学风活跃的唯一原因；D. 书院之间常有学术论辩。
    答：C。原文说"密不可分"，只是强调关系密切，未说"唯一原因"，C 项绝对化；A、B、D 均符合原文。
  3. 3. 请指出下列表述的设错类型并改正："原文提出「传统戏曲应借助新媒体扩大传播」，选项表述为「传统戏曲只有借助新媒体才能获得生存」。"
    答：属曲解文意加过度推断。原文只说应"借助新媒体扩大传播"，选项改成"只有……才能获得生存"，既改变了观点表述，又引入绝对化条件。改正：传统戏曲可借助新媒体扩大传播，从而获得更广泛的受众。
  4. 4. 阅读下文，完成选择。原文："在快速城镇化的背景下，乡村文化并非日渐消亡，而是在城乡互动中经历着「创造性转化」，其内涵不断被重新激活。"下列推断符合原文意思的一项是：A. 乡村文化在城镇化中完全消亡；B. 乡村文化只是被动接受城镇化的改造而失去自身特点；C. 乡村文化在城乡互动中可实现创造性转化；D. 城镇化必然导致乡村文化传统断裂。
    答：C。原文直接说乡村文化"经历着创造性转化，内涵不断被重新激活"，C 项与之吻合；A、D 与原文"并非日渐消亡"矛盾；B 项"失去自身特点"原文未提及。

综合 · 高考真题对接

  1. 1. （2023 年高考改编）阅读下文，完成选择。原文："《史记》的叙事艺术之所以达到后世难以企及的高度，一方面得益于司马迁「究天人之际，通古今之变」的史学视野，另一方面在于他善于通过细节描写与人物对话呈现历史现场的生动性。"下列理解和分析，不正确的一项是：A. 《史记》叙事艺术的高度离不开宏阔的史学视野；B. 细节描写与人物对话是《史记》叙事的显著特点；C. 《史记》的叙事艺术成就完全取决于司马迁的个人才华；D. 司马迁的史学视野与其叙事艺术相辅相成。
    答：C。原文从"视野"与"笔法"两方面归因，C 项"完全取决于个人才华"既绝对化又遗漏视野因素，属以偏概全；A、B、D 均符合原文。
  2. 2. （2022 年高考改编）原文："关于汉字起源的「仓颉造字」传说虽不足为信，但其中蕴含的「文字源于社会生活的需要」这一朴素的合理内核却值得肯定。"据此推断正确的一项是：A. 仓颉确实创造了汉字；B. 传说虽虚构，但其中关于文字源于生活需要的认识有合理成分；C. 汉字起源于个人的天才创造；D. 汉字产生与社会生活毫无关系。
    答：B。原文承认传说"蕴含合理内核"即"文字源于社会生活需要"，B 项与之一致；A、C 为无中生有；D 与原文相反。
  3. 3. （2021 年高考改编）原文论述："文学经典之所以历久弥新，在于它总能与不同时代的读者展开对话，被不断重新阐释，从而获得超越时代的生命力。"下列推断符合文意的一项是：A. 经典的价值一旦定型就一成不变；B. 经典的生命力来自它与各时代读者的持续对话与再阐释；C. 只有现代作品才可能与读者对话；D. 重新阐释会使经典丧失本来面目。
    答：B。原文明确指出经典"被不断重新阐释，从而获得超越时代的生命力"，B 项与之一致；A、C 为无中生有；D 项与原文"历久弥新"相悖。
  4. 4. 请依据材料概括中心论点。材料："创新是一个民族进步的灵魂，是国家兴旺发达的不竭动力。创新需要打破思维定势，需要宽容失败的社会氛围，更需要脚踏实地的持续积累。对于青年一代而言，培养创新精神既是时代的要求，也是个人成长的内在需要。"
    答：中心论点：创新是民族进步的灵魂与国家兴旺的不竭动力，而培养创新精神需要打破定势、宽容失败、持续积累，青年一代尤应重视之。概括时抓住首句总提、中间三句分述、末句落脚青年，三者整合即为完整论点。

💬 课后反馈

**常见错误** 1 选项比对只看大意，忽视"部分、所有、必然"等限定词。2 脱离原文凭常识做题。3 推断题把"值得借鉴"推成"必须照搬"。4 论证方法识别混淆。 **教学改进建议** 1 制作"六类陷阱对照表"，对号归因。2 坚持"先圈点勾画再做题"。3 每周限时 15 分钟真题一篇。 **分层辅导** 学困生先过"论点—论据—论证"关；学优生挑战推断题，训练严谨表述。
