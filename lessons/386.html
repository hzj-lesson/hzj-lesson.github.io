小学一年级科学《水的认识》教案

小学一年级科学水的认识

📝 备课方案

**教学目标** 1. 通过观察与比较，认识水的基本特征：无色、无味、透明、会流动。 2. 通过实验发现水没有固定形状，盛在什么容器里就是什么形状；了解水能溶解一些物质。 3. 初步了解水的三态变化：水遇冷变冰、冰遇热变水、水受热变成水蒸气。 4. 知道水是生命之源，养成节约用水、不浪费水的习惯。 **教学重点**：水的特征（无色、无味、透明、会流动、无固定形状）。 **教学难点**：理解"水没有固定形状"；初步理解水的三态变化。 **教学方法**：观察比较、动手实验、游戏体验（玩水）、联系生活。 **教学准备**：透明杯、牛奶、白醋、白糖水、不同形状的容器（圆形、方形、三角形）、吸管、冰块、温水。 **课时安排**：2 课时（第 1 课时：水的特征；第 2 课时：水的三态变化与节约用水）

📖 课堂讲义 · 核心知识点

**一、水在哪里** 水在我们的生活中无处不在：江河湖海里有水，自来水管道里有水，天空中的云是水蒸气变的，我们身体里也有大量的水。人、动物、植物都离不开水。 **二、水的特征（用眼睛看、鼻子闻、手摸）** - **无色**：水没有颜色（和牛奶比，牛奶是白色的，水是透明的）。 - **无味**：水没有气味、没有味道（和醋比，醋是酸的，水没有味道）。 - **透明**：透过水可以清楚地看到杯底的物体（和牛奶比，透过牛奶看不清）。 - **会流动**：把杯子斜过来，水会流出来；水没有固定形状。 **三、水没有固定形状（重要）** 把水倒进圆形杯，水是圆形的；倒进方形盒，水是方形的；倒进三角形瓶，水是三角形的。 - 结论：**水没有固定的形状**，它的形状随容器变化。 **四、水能溶解一些物质** 把一小勺白糖放进水里，搅拌后白糖"不见了"——这叫**溶解**。盐、糖能溶解在水里，沙子不能溶解（会沉在杯底）。 **五、水的三态变化** | 变化 | 条件 | 结果 | |---|---|---| | 水 → 冰 | 放到很冷的地方（0℃以下） | 水结冰，冰是固态的水 | | 冰 → 水 | 放到温暖处加热 | 冰融化变成水 | | 水 → 水蒸气 | 加热到沸腾 | 变成看不见的水蒸气跑到空气中 | | 水蒸气 → 水 | 遇冷 | 变成小水珠（如锅盖上的水滴、夏天冰饮料瓶外的水珠） | **六、水的用处与节约用水** - 水可以用来喝、洗衣服、做饭、浇花、发电、养鱼…… - 淡水是宝贵的资源，我们要节约用水：用完水关紧水龙头、用洗菜水浇花、洗澡水冲厕所等。

🔍 课堂讲义 · 重点难点解析

**重点一：用比较的方法认识水** - 例题：桌上放着一杯水和一杯牛奶，不用尝，怎样区分它们？ 分析：用看（颜色、透明）、闻（气味）的方法比较。 解答：看颜色——水无色透明，牛奶是乳白色不透明；透过杯子看——能透过水看清后面的东西，透过牛奶看不清。所以不用尝也能区分。 小结：认识物体的特征可以用"看一看、闻一闻、摸一摸"等方法，比较着看更容易发现不同。 **重点二：水没有固定形状** - 例题：把水倒进圆形杯是圆形，倒进方盒是方形，说明水有固定形状吗？ 分析：水盛在什么容器里就是什么形状。 解答：没有固定形状。水的形状会随着容器的形状改变。 小结："没有固定形状、会流动"是液体（水）的重要特征。 **难点一：水的三态变化** - 例题：夏天，冰镇饮料的瓶子外面有很多小水珠，这些小水珠是从哪里来的？ 分析：空气中的水蒸气遇到冰冷的瓶子，遇冷凝结成小水珠。 解答：是空气中的水蒸气遇冷变成的小水珠，不是瓶子漏出来的水。 小结：水蒸气看不见，遇冷会变成看得见的小水珠，这叫凝结。 **难点二：冰是水变的** - 例题：把一杯水放进冰箱冷冻室，第二天它变成了什么？为什么？ 分析：水在很冷（0℃以下）的地方会结冰。 解答：变成冰。水遇冷结成冰，冰是固态的水。 小结：水、冰、水蒸气都是同一种物质（水）的不同状态，可以互相变化。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（区分水与其他液体）** 怎样区分一杯水和一杯白醋？（不尝） - 分析：用鼻子闻——水没有气味，白醋有酸酸的气味。 - 解答：分别闻一闻，有酸味的是白醋，没有气味的是水。 - 方法小结：区分液体可以用看、闻等方法，注意安全，实验室的液体不能随便尝。 **例题 2（水的形状）** 把水倒进不同的容器，水的形状一样吗？这说明什么？ - 分析：倒进圆杯成圆形，倒进方盒成方形。 - 解答：形状不一样，说明水没有固定形状，形状随容器变化。 - 方法小结：液体没有固定形状、会流动，这是它与固体（如冰块有固定形状）的重要区别。 **例题 3（三态变化）** 烧开水时，壶嘴冒出的"白气"是什么？是水蒸气吗？ - 分析：水蒸气是看不见的；壶嘴冒出的"白气"是水蒸气遇冷变成的许多小水珠。 - 解答："白气"不是水蒸气，是水蒸气遇冷凝结成的小水珠（小水滴）。 - 方法小结：看得见的"白气"是小水珠，看不见的才是水蒸气。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 水的特征

  1. 1. 水是（ ）色、（ ）味、（ ）明的。
    答：无；无；透（无色、无味、透明）。
  2. 2. 水会（ ）动，没有固定的（ ）。
    答：流；形状。
  3. 3. 判断：水是白色的。（ ）
    答：错误。水是无色透明的，不是白色。

中等 · 比较与溶解

  1. 1. 水和牛奶比，有什么不同？
    答：水无色透明，牛奶乳白色不透明；透过水能看清东西，透过牛奶看不清。
  2. 2. 把白糖放进水里搅拌后"不见了"，这种现象叫（ ）。
    答：溶解。
  3. 3. 下面哪种物质不能溶解在水里？糖、盐、沙子。
    答：沙子。糖和盐能溶解，沙子会沉在杯底。

难 · 三态变化

  1. 1. 水在什么条件下会变成冰？
    答：温度降到 0℃以下（放到很冷的地方）时，水会结冰。
  2. 2. 夏天冰镇饮料瓶外面为什么会有小水珠？
    答：空气中的水蒸气遇到冰冷的瓶子，遇冷凝结成小水珠。
  3. 3. 判断：水蒸气是看得见的白气。（ ）
    答：错误。水蒸气是看不见的；看得见的"白气"是水蒸气遇冷变成的小水珠。

综合 · 节约用水

  1. 1. 水有哪些用处？至少写出三种。
    答：示例：喝、做饭、洗衣服、浇花、发电、养鱼。写出三种合理答案即可。
  2. 2. 请你写出两种节约用水的好办法。
    答：示例：用完水及时关紧水龙头；用洗菜的水浇花；用淘米水擦桌子。写出两种合理办法即可。
  3. 3. 想一想：如果地球上没有水，会怎样？用一两句话说一说。
    答：示例：人和动物会渴死，植物会枯死，地球上就没有生命了。言之有理即可。

💬 课后反馈

**学生常见错误** 1. 认为水是白色的（把"透明"与"白色"混淆），需要用实物对比纠正。 2. 认为水有固定形状，以为"杯子里的水是圆形的"就是水的形状。 3. 把"白气"当作水蒸气，不理解水蒸气是看不见的。 4. 认为冰不是水，不理解冰、水、水蒸气是同一种物质的不同状态。 **教学改进建议** 1. 多准备对比材料（水、牛奶、白醋、糖水），用"比较"认识特征。 2. 让每个学生动手倒水、装水，亲身体验"水随容器变形状"。 3. 三态变化结合生活现象讲：烧水冒白气、冰棍化水、湿衣服晾干。 **分层辅导** - 基础弱：只要求掌握"无色、无味、透明、会流动"四个特征。 - 学有余力：观察记录"冰块融化成水"的过程，画一画变化图。 **给家长的建议** 洗碗、洗澡时和孩子聊"水去哪里了"（蒸发）、"冰箱里的冰怎么来的"（结冰），把科学课上的知识带进日常生活。
