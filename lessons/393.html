高中高二数学导数及其应用

📝 备课方案

**教学目标** 1. 理解导数的定义及其几何意义，会用导数的几何意义求曲线在一点处的切线方程。 2. 掌握基本初等函数的求导公式及四则运算法则，会求简单函数与复合函数的导数。 3. 会利用导数判断函数的单调性，能正确利用 f′(x) = 0 判定并求出函数的极值与最值。 4. 会利用导数解决恒成立与参数取值范围问题，并能利用导数证明简单的不等式，体会导数在研究函数中的工具作用。 **教学重点**：基本求导公式与运算法则；利用导数研究函数的单调性、极值与最值。 **教学难点**：含参数的单调区间与极值讨论；恒成立问题向函数最值问题的转化；导数与不等式证明的结合。 **教学方法**：数形结合法、变式训练法、分类讨论法、讲练结合法。 **教学准备**：函数图像动态演示软件、导数概念课件、典型例题学案、近五年高考导数真题汇编。 **课时安排**：4 课时（第 1 课时：导数的定义、几何意义与求导公式；第 2 课时：复合函数求导与单调性；第 3 课时：极值与最值；第 4 课时：恒成立、参数范围与不等式证明）。

📖 课堂讲义 · 核心知识点

**一、导数的定义与几何意义** 函数 y = f(x) 在 x = x0 处的导数定义为 f′(x0) = lim(Δx→0) [f(x0 + Δx) − f(x0)] ÷ Δx，它刻画了函数在 x0 处变化的快慢，即瞬时变化率。 **几何意义**：曲线 y = f(x) 在点 (x0, f(x0)) 处的切线斜率等于 f′(x0)。因此切线方程为 y − f(x0) = f′(x0)(x − x0)。当求曲线过某点的切线时，要区分"在点处"（该点即切点）与"过点"（切点待求）两种情形。 **二、基本求导公式与四则运算** 基本初等函数的导数： - (C)′ = 0（C 为常数）； - (x^n)′ = n·x^(n−1)（n 为实数），如 (x²)′ = 2x，x⁻¹ 的导数 = −x⁻²； - (sinx)′ = cosx；(cosx)′ = −sinx； - (e^x)′ = e^x；(a^x)′ = a^x·lna； - (lnx)′ = 1/x；(log_a x)′ = 1 ÷ (x·lna)。 四则运算法则（u、v 均可导）： - [u(x) ± v(x)]′ = u′(x) ± v′(x)； - [u(x)·v(x)]′ = u′(x)·v(x) + u(x)·v′(x)（乘积的导数等于"前导后不导加后导前不导"）； - [u(x) ÷ v(x)]′ = [u′(x)·v(x) − u(x)·v′(x)] ÷ v²(x)（v ≠ 0）； - [C·u(x)]′ = C·u′(x)。 **三、复合函数求导** 形如 y = f(g(x)) 的复合函数，其导数 y′ = f′(g(x))·g′(x)，即"外层函数的导数乘以内层函数的导数"。例如 (sin2x)′ = cos2x × (2x)′ = 2cos2x；[e^(3x)]′ = e^(3x) × 3 = 3e^(3x)。 **四、利用导数研究单调性** 在区间 D 上，若 f′(x) > 0，则 f(x) 在 D 上单调递增；若 f′(x) < 0，则 f(x) 在 D 上单调递减；若 f′(x) = 0 恒成立，则 f(x) 为常数。求单调区间的一般步骤：求定义域 → 求 f′(x) → 解 f′(x) = 0 得临界点 → 列表判断各区间内 f′(x) 的符号 → 写出单调区间。 **五、极值与最值** - 极值：若 f′(x0) = 0，且 x0 左侧 f′(x) > 0、右侧 f′(x) < 0，则 f(x0) 为极大值；若左侧 f′(x) < 0、右侧 f′(x) > 0，则 f(x0) 为极小值。注意 f′(x0) = 0 只是取极值的必要条件，还要检查左右两侧导数符号是否改变。 - 最值：闭区间 [a, b] 上的最值在极值点或区间端点处取得，方法是先求极值，再与 f(a)、f(b) 比较大小。 **六、恒成立与参数范围** 求解"恒成立"问题的基本思想是转化为最值问题： - 若对任意 x，f(x) ≥ a 恒成立，则 a ≤ f(x) 的最小值； - 若对任意 x，f(x) ≤ a 恒成立，则 a ≥ f(x) 的最大值。 当分离参数不方便时，可把含参函数整理为一边是参数、一边是函数，利用导数求该函数的最值；必要时需分类讨论。 **七、导数与不等式证明** 用导数证明不等式的常用思路：作差构造函数。如证 f(x) > g(x)，令 h(x) = f(x) − g(x)，求 h′(x)，判断 h(x) 的单调性，求出 h(x) 的最小值，若最小值大于 0 则原不等式成立。常用结论：e^x ≥ x + 1（x ∈ R），lnx ≤ x − 1（x > 0），x > 0 时 sinx < x，这些结论可直接用导数证明并作为证明其他不等式的跳板。 **易错提醒** 1. 求单调区间前必须先求定义域，对含对数、分式的函数尤其重要。 2. f′(x0) = 0 不一定取极值，如 y = x³ 在 x = 0 处导数为 0 但无极值，要检查符号变化。 3. 复合函数求导漏乘内层导数，是求导最常见的失分点。

🔍 课堂讲义 · 重点难点解析

**重点一：导数的几何意义与切线方程** 例题：求曲线 f(x) = x³ − 2x + 1 在点 (1, 0) 处的切线方程；再求过点 (1, 0) 且与该曲线相切的另一条切线。 分析：先求导得斜率，再写"在点处"的切线；"过点"时设切点为 (x0, f(x0))，利用切点在曲线上且切线过给定点列方程。 解答：(1) f′(x) = 3x² − 2，k = f′(1) = 1，切线方程为 y − 0 = 1×(x − 1)，即 y = x − 1。(2) 设切点横坐标为 t，则切点纵坐标 t³ − 2t + 1，切线斜率 k = 3t² − 2。切线过 (1, 0)，由斜率公式 (t³ − 2t + 1 − 0) ÷ (t − 1) = 3t² − 2。化简得 t³ − 2t + 1 = (3t² − 2)(t − 1)，展开整理得 (t − 1)²(2t + 1) = 0，t = 1（即已求切线）或 t = −1/2。当 t = −1/2 时，k = 3×(1/4) − 2 = −5/4，切线方程 y = (−5/4)(x − 1)。 小结："在点处"的切线切点为已知点；"过点"的切线切点待求，需列关于切点横坐标的方程。 **难点一：含参数的单调性与极值讨论** 例题：设函数 f(x) = x³ − 3ax + 1，讨论 a > 0 时 f(x) 的单调区间与极值。 分析：求导后令 f′(x) = 0，解出的临界点含参数 a，需根据 a 的符号与零的大小分类讨论。 解答：f′(x) = 3x² − 3a = 3(x² − a)。当 a > 0 时，令 f′(x) = 0 得 x = √a 或 x = −√a。x < −√a 时 f′(x) > 0，−√a < x < √a 时 f′(x) < 0，x > √a 时 f′(x) > 0。所以增区间为 (−∞, −√a) 和 (√a, +∞)，减区间为 (−√a, √a)。x = −√a 处取极大值 f(−√a) = 2a√a + 1；x = √a 处取极小值 f(√a) = 1 − 2a√a。 小结：含参讨论的通用流程是"求导 → 因式分解 → 比较临界点与定义域端点 → 分类列表"。 **难点二：恒成立问题转化为最值** 例题：已知 f(x) = x − lnx，若对任意 x > 0，f(x) ≥ a 恒成立，求实数 a 的最大值。 分析：问题转化为求 f(x) 在 (0, +∞) 上的最小值，a 不超过该最小值。 解答：f′(x) = 1 − 1/x = (x − 1)/x。当 0 < x < 1 时 f′(x) < 0，f(x) 递减；当 x > 1 时 f′(x) > 0，f(x) 递增。所以 x = 1 时取最小值 f(1) = 1 − 0 = 1。因此 a ≤ 1，a 的最大值为 1。 小结：恒成立问题先分离目标（一边是 a，一边是函数），再用导数求另一边的最值，最后取"≤ 最小值"或"≥ 最大值"。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：基本求导公式与切线** 题目：已知函数 f(x) = x² + 2x·lnx，求 f′(1)，并求曲线 y = f(x) 在 x = 1 处的切线方程。 分析：先求导，再代入 x = 1 求斜率，最后写切线方程。 解答：f′(x) = 2x + 2(1·lnx + x·(1/x)) = 2x + 2lnx + 2，所以 f′(1) = 2 + 0 + 2 = 4。f(1) = 1 + 0 = 1，切线方程为 y − 1 = 4(x − 1)，即 y = 4x − 3。 方法小结：含乘积项用乘积法则求导；写切线方程按"求点 → 求斜率 → 写方程"三步走。 **例题二（提高）：利用导数求单调区间与极值** 题目：求函数 f(x) = x³ − 3x² − 9x + 2 的单调区间和极值。 分析：求导后解方程，列表判断符号。 解答：f′(x) = 3x² − 6x − 9 = 3(x − 3)(x + 1)。令 f′(x) = 0 得 x = −1 或 x = 3。当 x < −1 时 f′(x) > 0，f(x) 递增；当 −1 < x < 3 时 f′(x) < 0，f(x) 递减；当 x > 3 时 f′(x) > 0，f(x) 递增。增区间 (−∞, −1) 和 (3, +∞)，减区间 (−1, 3)。x = −1 处极大值 f(−1) = −1 − 3 + 9 + 2 = 7；x = 3 处极小值 f(3) = 27 − 27 − 27 + 2 = −25。 方法小结：列表法是规范解答单调性与极值问题的标准格式，能直观看出极值点的两侧符号变化。 **例题三（综合）：导数与不等式证明** 题目：证明：当 x > 0 时，x − sinx > 0。 分析：作差构造 h(x) = x − sinx，用导数证明 h(x) 在 (0, +∞) 上单调递增且 h(0) = 0。 解答：设 h(x) = x − sinx，则 h′(x) = 1 − cosx。因为 cosx ≤ 1，所以 h′(x) ≥ 0 恒成立，且仅在 x = 2kπ 处取等号，故 h(x) 在 R 上单调递增。又 h(0) = 0，所以当 x > 0 时 h(x) > h(0) = 0，即 x − sinx > 0。 方法小结：作差构造函数后用导数判断单调性，再利用端点值定号，这是证明函数不等式的基本套路。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 求导公式与运算法则

  1. 1. 求下列函数的导数：(1) f(x) = x⁵；(2) f(x) = 3x² − 2x + 7；(3) f(x) = sinx + e^x。
    答：(1) (x⁵)′ = 5x⁴。(2) f′(x) = 3×(2x) − 2 = 6x − 2（常数 7 的导数为 0）。(3) f′(x) = cosx + e^x。
  2. 2. 求函数 f(x) = x²·e^x 和 g(x) = (x² + 1) ÷ x 的导数。
    答：f′(x) = (x²)′·e^x + x²·(e^x)′ = 2x·e^x + x²·e^x = e^x(x² + 2x)。g(x) = x + 1/x，g′(x) = 1 − 1/x²（也可用商的法则计算，结果相同）。
  3. 3. 求 f(x) = sin2x 和 g(x) = ln(3x + 1) 的导数（复合函数求导）。
    答：f′(x) = cos2x × 2 = 2cos2x。g′(x) = [1/(3x + 1)] × 3 = 3/(3x + 1)。复合函数求导注意乘以内层导数。

中等 · 切线方程与单调区间

  1. 1. 求曲线 y = x³ 在点 (2, 8) 处的切线方程，并求该切线与 x 轴交点的横坐标。
    答：y′ = 3x²，k = 3×4 = 12，切线方程 y − 8 = 12(x − 2)，即 y = 12x − 16。令 y = 0 得 12x − 16 = 0，x = 4/3，所以与 x 轴交点的横坐标为 4/3。
  2. 2. 求函数 f(x) = x² − 4x + 3 的单调区间和极值。
    答：f′(x) = 2x − 4。令 f′(x) = 0 得 x = 2。当 x < 2 时 f′(x) < 0，递减；当 x > 2 时 f′(x) > 0，递增。减区间 (−∞, 2)，增区间 (2, +∞)，在 x = 2 处取极小值 f(2) = 4 − 8 + 3 = −1。
  3. 3. 已知 f(x) = 2x³ + ax² + 1，且 f′(1) = 12，求 a 的值。
    答：f′(x) = 6x² + 2ax，f′(1) = 6 + 2a = 12，解得 a = 3。

难 · 含参讨论与恒成立求范围

  1. 1. 设 f(x) = x³ − 3x² + a（a 为常数），求 f(x) 在区间 [0, 3] 上的最大值与最小值（用 a 表示）。
    答：f′(x) = 3x² − 6x = 3x(x − 2)。在 [0, 3] 内令 f′(x) = 0 得 x = 0 或 x = 2。f(0) = a，f(2) = 8 − 12 + a = a − 4，f(3) = 27 − 27 + a = a。比较得最大值 f(3) = f(0) = a，最小值 f(2) = a − 4。
  2. 2. 已知函数 f(x) = x² − 2x + a，若对任意 x ∈ [1, 3]，f(x) ≥ 0 恒成立，求实数 a 的取值范围。
    答：分离参数：a ≥ −x² + 2x 对 x ∈ [1, 3] 恒成立，即 a ≥ (−x² + 2x) 的最大值。设 g(x) = −x² + 2x = −(x − 1)² + 1，开口向下，对称轴 x = 1。g(x) 在 [1, 3] 上单调递减，最大值 g(1) = 1，所以 a ≥ 1。
  3. 3. 设函数 f(x) = lnx − ax（a > 0），求 f(x) 的单调区间，并求 f(x) 在 x = 1 处取得极大值时 a 的值。
    答：定义域 x > 0，f′(x) = 1/x − a = (1 − ax)/x。令 f′(x) = 0 得 x = 1/a。当 0 < x < 1/a 时 f′(x) > 0，递增；当 x > 1/a 时 f′(x) < 0，递减。增区间 (0, 1/a)，减区间 (1/a, +∞)，在 x = 1/a 处取极大值。若极大值在 x = 1 处取得，则 1/a = 1，a = 1。

综合 · 导数综合应用与不等式证明

  1. 1. 已知 f(x) = x² − 2ax + 2，当 x ∈ [0, 2] 时 f(x) ≥ 0 恒成立，求 a 的取值范围。
    答：分对称轴位置讨论。f′(x) = 2x − 2a，对称轴 x = a。① 当 a ≤ 0 时，f(x) 在 [0, 2] 上递增，最小值 f(0) = 2 > 0，满足。② 当 0 < a < 2 时，最小值 f(a) = −a² + 2，需 −a² + 2 ≥ 0，得 a ≤ √2，即 0 < a ≤ √2。③ 当 a ≥ 2 时，f(x) 在 [0, 2] 上递减，最小值 f(2) = 6 − 4a，需 6 − 4a ≥ 0，得 a ≤ 3/2，与 a ≥ 2 矛盾，无解。综上 a ≤ √2。
  2. 2. 证明：当 x > 0 时，lnx ≤ x − 1，并指出何时取等号。
    答：作差构造 h(x) = lnx − x + 1，h′(x) = 1/x − 1 = (1 − x)/x。当 0 < x < 1 时 h′(x) > 0，递增；当 x > 1 时 h′(x) < 0，递减。故 h(x) 在 x = 1 处取最大值 h(1) = 0，所以 h(x) ≤ 0，即 lnx ≤ x − 1，当且仅当 x = 1 时取等号。
  3. 3. 某工厂生产某种产品，总成本 C(x) = 0.01x² + 2x + 100（万元），产品单价为 8 万元。求产量 x 为多少时利润最大，最大利润是多少？
    答：利润 L(x) = 8x − C(x) = 8x − 0.01x² − 2x − 100 = −0.01x² + 6x − 100。L′(x) = −0.02x + 6，令 L′(x) = 0 得 x = 300。当 x < 300 时 L′(x) > 0，递增；当 x > 300 时 L′(x) < 0，递减。所以 x = 300 时利润最大，L(300) = −0.01×90000 + 1800 − 100 = −900 + 1800 − 100 = 800（万元）。

💬 课后反馈

**学生常见错误** 1. 求导公式记错，如把 (x^n)′ 写成 n·x^n，或把 (lnx)′ 记成 1 ÷ x²，复合函数漏乘内层导数。 2. 求单调区间时不先求定义域，导致区间超出定义域范围，如对 lnx 的函数解出负区间。 3. 把 f′(x0) = 0 当成取极值的充要条件，不检查左右导数符号，遇到 y = x³ 型函数就出错。 4. 恒成立问题不会转化，直接代入端点值求范围，或者分离参数后最值取反方向。 **教学改进建议** 1. 建立"求导 → 定义域 → 列表 → 结论"的规范流程，要求学生每一步都写清楚，从格式上杜绝漏定义域、漏讨论。 2. 用图像演示 y = x³ 在 x = 0 处的情况，让学生直观理解"导数为 0 未必有极值"。 3. 把恒成立问题整理为"分离参数型、构造最值型、含参讨论型"三类，逐一训练转化思路。 **分层辅导建议** - 基础层：主抓基本求导公式和四则运算法则，反复练习直代公式的简单求导。 - 提高层：练切线方程、单调区间、极值最值的完整书写，养成列表习惯。 - 拓展层：练含参分类讨论、恒成立求参数范围、导数证明不等式等综合问题。 **给家长的建议** 1. 导数章节对书写规范要求高，可提醒孩子每题都用"定义域 → 求导 → 列表 → 结论"的格式，减少无谓失分。 2. 鼓励孩子把做错的求导题收集起来，一周后重做一遍，重点看是否还在同样的步骤上出错。
