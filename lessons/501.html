高中高二地理《农业与工业》教案

高中高二地理农业与工业

📝 备课方案

**教学目标** 1. 结合实例分析影响农业区位的自然因素与社会经济因素，理解区位因素的变化对农业生产的影响。 2. 说出主要农业地域类型（季风水田农业、商品谷物农业、大牧场放牧业、乳畜业、混合农业）的分布与生产特点。 3. 归纳影响工业区位的主要因素，判断工业部门的导向类型，理解环境因素对工业布局的影响。 4. 结合案例说明产业集聚的意义与产业转移的原因及影响，理解区域产业联系与发展。 **教学重点**：农业区位因素及其变化；工业区位因素与导向类型判断。 **教学难点**：区位因素的动态变化分析（市场、交通、技术改变农业区位）；产业转移对转入地与转出地的双向影响。 **教学方法**：案例分析法（新疆棉花、海南反季瓜菜、墨累—达令盆地）、比较法（农业地域类型对比表）、思维导图法。 **教学准备**：农业区位因素示意图、农业地域类型分布图、工业导向类型案例卡、产业转移材料。 **课时安排**：3 课时（第 1 课时：农业区位因素；第 2 课时：农业地域类型与工业区位因素；第 3 课时：工业布局、产业集聚与转移）。

📖 课堂讲义 · 核心知识点

**一、农业区位因素** 农业区位选择的实质是对土地的合理利用。 | 因素类别 | 具体因素 | 影响举例 | |---|---|---| | 自然因素 | 气候（光照、热量、降水） | 南方水稻、北方小麦；新疆瓜果甜（光照强、昼夜温差大） | | 自然因素 | 地形 | 平原宜耕作、山地宜林牧；山地垂直立体农业 | | 自然因素 | 土壤 | 江南丘陵酸性红壤适宜种茶 | | 自然因素 | 水源 | 干旱区依靠灌溉发展绿洲农业（河西走廊、宁夏平原） | | 社会经济因素 | 市场 | 决定农业生产的类型与规模；城郊乳畜业、园艺业 | | 社会经济因素 | 交通运输 | 园艺业、乳畜业等产品易腐，需便捷交通；冷藏保鲜技术扩大销售范围 | | 社会经济因素 | 政策法规 | 补贴、规划影响种植结构 | | 社会经济因素 | 劳动力、科技 | 水稻种植业需劳动力多；温室大棚、无土栽培改造自然条件 | 规律总结：自然因素相对稳定，社会经济因素变化较快。**科技的进步可以改造不利的自然因素**（温室调节热量、喷灌滴灌节约水源、培育良种），使农业区位选择的范围扩大。 **二、主要农业地域类型** | 类型 | 主要分布 | 生产特点 | |---|---|---| | 季风水田农业（水稻种植业） | 东亚、南亚、东南亚季风区 | 小农经营；单位面积产量高但商品率低；机械化、科技水平较低；水利工程量大 | | 商品谷物农业 | 美国、加拿大、澳大利亚等（地广人稀） | 以小麦、玉米为主；生产规模大、机械化程度高、商品率高 | | 大牧场放牧业 | 美国、阿根廷（潘帕斯草原）等干旱半干旱区 | 生产规模大、专业化程度高；潘帕斯草原靠培育良种牛、改善交通、开辟水源、围栏放牧发展起来 | | 乳畜业 | 北美五大湖地区、西欧等 | 面向城市市场，生产牛奶及乳制品，紧邻消费市场，集约化程度高 | | 混合农业 | 澳大利亚墨累—达令盆地（小麦—牧羊） | 良性生态系统；有效安排农事活动；对市场适应性强 | 混合农业的优点是高频考点：小麦收割后的秸秆可作牧草、羊粪肥田，形成良性生态循环；小麦种植与牧羊忙闲错开，合理安排农事；可根据市场价格灵活调整麦羊比例，市场适应性强。 **三、工业区位因素与导向类型** 工业区位选择要考虑土地（地价）、水源、原料、动力（能源）、交通、劳动力、市场、技术、政策、环境等因素。按主导因素分五类： | 导向类型 | 工业特点 | 代表部门 | |---|---|---| | 原料导向 | 原料不便长途运输或运输成本高（易变质、失重） | 制糖厂、水产品加工厂、水果罐头厂 | | 市场导向 | 产品不便长途运输或运输成本高 | 啤酒厂、家具厂、印刷厂 | | 动力导向 | 需消耗大量能源 | 有色金属冶炼（如炼铝厂） | | 劳动力导向 | 需大量劳动力 | 服装厂、电子装配厂、制鞋厂 | | 技术导向 | 技术要求高 | 集成电路、精密仪表、飞机制造 | 环境因素对工业布局的要求：大气污染企业布局在盛行风下风向或最小风频上风向；水源污染企业（印染厂、造纸厂）布局在河流下游，自来水厂布局在河流上游；固废污染企业远离居民区和农田。 **四、产业集聚与产业转移** 1. 产业集聚：具有联系的工厂在地理上靠近布局。优点：共用基础设施，节约生产建设投资；加强企业间信息交流与技术协作；降低中间产品运费和能源消耗，取得规模效益。 2. 产业转移：企业将产品生产的部分或全部由原生产地转移到其他地区，多为**劳动密集型产业和资源密集型产业**从经济发达地区向欠发达地区（如由沿海向中西部、由发达国家向发展中国家）转移。 3. 影响（以沿海向内地转移为例）：对转出地——腾出土地空间，集中发展高新技术产业，促进产业升级；环境质量改善；但就业机会减少、可能出现"产业空心化"。对承接地——加快工业化城市化进程，增加就业机会，促进经济发展；但可能承接高耗能、高污染环节，加大环境压力。 **五、区位因素的变化** 社会经济因素是变化的：市场需求变化引导种植结构调整（如大城市周边蔬菜花卉基地扩大）；交通条件改善扩大农产品的市场范围；技术进步改造自然限制（大棚蔬菜突破热量限制）；劳动力成本上升推动劳动密集型产业转移。区位分析要"因时因地制宜"。

🔍 课堂讲义 · 重点难点解析

**重点一：农业区位因素的案例分析** 例题：新疆瓜果特别甜，海南能利用冬季种植瓜菜供应北方市场。分别分析两地农业区位的优势。 分析：新疆抓光照和温差；海南抓热量优势与市场需求。 解答：新疆属于温带大陆性气候，深居内陆、降水少，光照强、昼夜温差大，有利于瓜果糖分积累，瓜果特别甜；海南地处热带，冬季气温较高，热量充足，可利用冬闲田种植反季节瓜菜，加之交通便利和北方冬季市场需求大，形成冬季瓜菜生产基地。 小结：区位优势分析"对号入座"——光照温差对应甜度，热量对应熟制与反季节，市场交通对应销售范围。 **重点二：工业导向类型的判断** 例题：将下列工厂按导向类型归类并说明理由：①甘蔗制糖厂 ②瓶装啤酒厂 ③电解铝厂 ④普通服装厂 ⑤集成电路工厂。 分析：抓"原料失重、产品易碎不便运、耗能大、用工多、技术高"等关键词。 解答：①甘蔗失重大且易变质，原料导向；②啤酒瓶装后重量体积大、不便长途运输，市场导向；③电解铝耗电量大，动力导向；④服装加工需大量劳动力，劳动力导向；⑤集成电路技术要求高，技术导向。 小结：判断口诀——"易腐失重找原料，笨重易碎近市场，耗能大户靠电站，用工成群近人烟，高精尖处要技术"。 **难点一：农业区位因素的变化** 例题：某城市郊区原为水稻种植区，近年来蔬菜、花卉种植面积迅速扩大。分析发生这一变化的主要原因。 分析：变化的主导因素是城市发展与市场需求。 解答：①城市规模扩大，城市化水平提高，对蔬菜、花卉的市场需求量大增，而其经济效益高于水稻；②交通条件改善和冷藏保鲜技术发展，缩短了产品运达市场的时间、扩大了销售范围；③近郊地价上涨，单位面积产值高的蔬菜花卉比水稻更具竞争力。 小结：农业区位变化题常答三点——市场需求变化（决定类型规模）、交通技术进步（扩大范围）、经济效益比较（调整动力）。 **难点二：产业转移的双向影响** 例题：近年来我国东部沿海一些劳动密集型工厂迁往中西部或东南亚。分析产业转移对东部沿海地区和承接地的影响。 分析：对两地分别从经济、就业、环境三方面辩证分析。 解答：对东部沿海——有利：土地和劳动力资源向更高附加值的产业集中，促进产业升级；改善环境质量。不利：短期内部分就业岗位减少。对承接地——有利：加快工业化进程，增加就业和收入，带动基础设施建设和相关产业发展。不利：若承接高耗能高污染环节，会加大资源环境压力。 小结：产业转移影响题模板——"对转出地、对承接地"分别答"有利＋不利"，落脚点在产业升级与环境。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：水稻种植业特点** 题目：说明亚洲季风水田农业的主要特点，并解释其形成的区位条件。 分析：特点从"经营规模、单产与商品率、机械化、水利、科技"五方面概括；区位条件与特点对应。 解答：特点：小农经营，生产规模小；单位面积产量高，但商品率低；机械化水平低（日本较高）；科技水平较低；水利工程量大。区位条件：季风气候雨热同期，水热条件适合水稻生长；地形平坦、土壤肥沃；人口稠密，劳动力丰富；水稻单产高，可缓解人口对土地的压力；种植历史悠久、经验丰富。 方法小结：先背熟五个特点，答题时再"特点＋原因"两两对应。 **例题二（提高）：乳畜业区位分析** 题目：西欧是世界乳畜业发达地区。从市场和饲料两方面分析西欧发展乳畜业的区位优势。 分析：乳畜业是面向城市市场的集约化农业，两大条件是市场与饲料。 解答：市场方面：西欧经济发达、城市化水平高，人口稠密，居民有食用乳制品的习惯，市场需求量大。饲料方面：西欧以温带海洋性气候为主，气候温凉潮湿，多雨多雾，不利于谷物成熟但适宜多汁牧草生长，为乳畜业提供优质饲料。 方法小结："市场＋饲料"是乳畜业区位题的固定框架，气候分析要说明"不利于粮食、利于牧草"的对比关系。 **例题三（综合）：工业布局综合分析** 题目：某城市规划建设：①炼铝厂（耗电大）②自来水厂 ③服装厂 ④印染厂（水污染）。城市河流自北向南流，流经城区，城区北部上游有大型水电站。请为四个工厂选择合适的位置并说明理由（备选方位：城北上游、城南下游、城内居民区附近、电站附近）。 分析：逐个工厂匹配主导因素与环境要求。 解答：炼铝厂—电站附近，靠近能源地，属于动力导向；自来水厂—城北上游，河流上游水质清洁；服装厂—城内居民区附近，劳动力导向且基本无污染，便于就近上下班；印染厂—城南下游，水污染企业布局在河流下游，减轻对城区水源的污染。 方法小结：工业布局题先分类——"污染类"看风与水，"成本类"看原料市场能源，"用工类"看劳动力分布，再逐一落实方位。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 农业区位因素

  1. 1. 影响农业区位的自然因素有哪些？其中决定农业类型与生产规模的最主要社会经济因素是什么？
    答：自然因素：气候（光照、热量、降水）、地形、土壤、水源等。决定农业类型与规模的最主要社会经济因素是市场。
  2. 2. 为什么江南丘陵的酸性红壤适宜种植茶树？
    答：茶树喜酸性土壤和排水良好的坡地，江南丘陵广泛分布酸性红壤，且丘陵地形排水良好、云雾较多，适宜茶树生长，形成著名的茶叶产区。
  3. 3. 简答：为什么干旱地区的农业多分布在绿洲或有灌溉水源的河谷地带？
    答：干旱地区降水稀少，水分成为农业发展的限制性因素；绿洲和河谷有高山冰雪融水、河水或地下水灌溉，水源较充足，土壤较肥沃，因此农业（绿洲农业、灌溉农业）集中分布于此。

中等 · 农业地域类型

  1. 1. 季风水田农业有哪些主要生产特点？
    答：小农经营；单位面积产量高，但商品率低；机械化水平低；水利工程量大；科技水平较低。这些特点与其人多地少、季风降水不稳定等条件有关。
  2. 2. 澳大利亚墨累—达令盆地的混合农业有哪些优点？
    答：①种植业与畜牧业结合，形成良性生态系统（秸秆作饲料、羊粪肥田）；②小麦耕作与牧羊活动在时间上互补，可有效安排农事；③可根据市场需求灵活调整小麦与牧羊的比例，对市场适应性强。
  3. 3. 商品谷农业和大牧场放牧业一般分布在地广人稀的地区，这与它们的生产特点有何关系？
    答：地广人稀地区土地租金低，便于实行大规模经营；劳动力相对不足，推动机械化程度提高；大面积生产的农产品（小麦、玉米、畜产品）商品率高，便于商品化经营。因此大规模、高机械化、高商品率正是这类地区区位条件与生产特点相互适应的结果。

难 · 工业区位与导向

  1. 1. 判断下列工业的导向类型：①水果罐头厂 ②家具厂 ③炼铝厂 ④飞机制造厂。
    答：①水果易变质、原料失重大，原料导向；②家具产品体积大、不便长途运输，市场导向；③炼铝耗电量大，动力导向；④飞机制造技术要求高，技术导向。
  2. 2. 啤酒厂为什么多建在大城市附近？水产品加工厂为什么建在沿海渔港？
    答：啤酒产品瓶装后重量大、易碎，不便长途运输，且面向城市消费市场，属于市场导向，多建在大城市附近；水产品原料易腐烂变质、不便长途运输，且加工后重量减轻，属于原料导向，建在沿海渔港可就近加工保鲜。
  3. 3. 某城市常年盛行西南风。有大气污染的钢铁厂应布局在城市的哪个方位？说明理由。
    答：应布局在盛行风（西南风）的下风向，即城市的东北郊；这样工厂排放的废气随盛行风吹向城市外围，可减少对城区的大气污染（若有最小风频资料，也可布局在最小风频的上风向）。

综合 · 材料综合分析题

  1. 1. 阅读材料：某大城市郊区原来种植水稻，近十年大量发展草莓采摘园和蔬菜大棚，并依托高速公路将产品销往周边城市。分析该地农业结构变化的原因。
    答：①市场：城市化发展，城市人口增加，对草莓、蔬菜等鲜活农产品需求量大，经济效益高于水稻；②交通：高速公路等交通条件改善，缩短了运达时间，扩大了市场范围；③技术：大棚技术突破了冬季热量限制，实现反季节生产；④政策与观光休闲需求（采摘园）进一步促进结构调整。体现了市场、交通、技术等社会经济因素对农业区位的深刻影响。
  2. 2. 阅读材料：20 世纪 90 年代以来，一些跨国公司将电子装配、服装加工等工厂从发达国家迁往东南亚等地。分析产业转移的原因及其对东南亚地区的影响。
    答：原因：东南亚劳动力价格低廉、土地租金低，可降低生产成本；发达国家劳动力成本上升，产业结构向高新技术方向调整；当地政策优惠、市场潜力大。影响（对东南亚承接地）：有利——增加就业机会，促进工业化和城市化，带动经济发展和相关产业配套；不利——以劳动密集型环节为主，附加值低，若盲目承接还可能带来环境污染和生态破坏。
  3. 3. 综合题：某地区计划发展制糖工业，本地甜菜产量大但糖厂规模小、分布散。该地区提出"关停小厂、集中建设大型糖厂并发展糖业深加工"。从产业集聚角度分析该方案的合理性。
    答：①集中建设大型糖厂可获得规模效益，降低单位产品成本；②集聚发展便于共用基础设施（交通、水电、仓储），节约建设投资；③制糖与深加工企业集聚，加强信息交流与技术协作，延长产业链（糖—食品—饲料等），提高附加值；④统一治污降低环境治理成本。方案符合产业集聚与延长产业链的发展思路，合理可行。

💬 课后反馈

**学生常见错误** 1. 农业区位分析套路化：不结合具体案例，把自然、社会经济因素全部罗列，抓不住主导因素（如新疆瓜果甜的关键是光照与温差）。 2. 农业地域类型特点张冠李戴：把商品谷物农业"商品率低"、季风水田农业"商品率高"写反。 3. 工业导向类型判断错误：把炼铝厂当成原料导向（实际是动力导向），把家具厂当成原料导向（实际是市场导向）。 4. 产业转移影响不辩证：只写对承接地的利，不写转出地的得与失，缺"双向＋利弊"的完整框架。 **教学改进建议** 1. 用"案例卡"教学：每个农业地域类型配一个真实区域案例，先分析案例再归纳特点，避免死记硬背。 2. 工业导向类型编成判断口诀并结合本地工厂实例调查，让学生给身边工厂"归类"。 3. 产业转移教学引入表格对比（转出地与承接地的经济、就业、环境变化），训练辩证答题框架。 **分层辅导建议** - 基础层：过关农业区位因素分类、五大工业导向类型及代表部门。 - 提高层：强化"主导因素＋限制性因素"分析训练，规范案例题的因果表述。 - 拓展层：调查本地某种农产品或工厂的区位条件，撰写小型区位分析报告。 **给家长的建议** 1. 购物时与孩子讨论"这种水果为什么产自这里、如何运来"，把市场、交通等区位因素生活化。 2. 关注本地工业园、特色农产品的新闻，引导孩子用课堂的区位理论解释家乡产业。
