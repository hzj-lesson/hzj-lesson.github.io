高中高一化学《金属及其化合物》教案

高中高一化学金属及其化合物

📝 备课方案

**教学目标** 1. 掌握钠的物理性质与化学性质，能写出钠与氧气、水反应的方程式，理解钠的保存方法，能对比 Na₂O 与 Na₂O₂ 的组成和性质。 2. 掌握 Na₂CO₃ 与 NaHCO₃ 的性质差异（溶解性、热稳定性、与酸反应），会鉴别两者和实现相互转化，理解焰色试验的操作与结论。 3. 认识铝的两性，能写出铝、氧化铝、氢氧化铝分别与酸和碱反应的方程式，理解「两性」的含义与应用。 4. 掌握铁的氧化物、氢氧化物的重要性质，能写出 Fe²⁺ 与 Fe³⁺ 相互转化的方程式，会用 KSCN 溶液检验 Fe³⁺，能设计 Fe²⁺ 的检验方案。 **教学重点**：钠与水的反应；Na₂CO₃ 与 NaHCO₃ 的比较；Fe²⁺ 与 Fe³⁺ 的转化与检验。 **教学难点**：Na₂O₂ 与水反应的电子转移分析；铝的两性及图像问题；Fe²⁺ 检验方案的设计（排除 Fe³⁺ 干扰）。 **教学方法**：实验探究法、对比归纳法、问题驱动法、小组合作法。 **教学准备**：金属钠、酚酞、Na₂CO₃ 与 NaHCO₃ 固体及溶液、铝箔、盐酸、NaOH 溶液、FeSO₄ 与 FeCl₃ 溶液、KSCN 溶液、氯水、铂丝（或铁丝圈）、蓝色钴玻璃、课件与任务单。 **课时安排**：3 课时（第 1 课时：钠及其重要化合物；第 2 课时：铝的两性与焰色试验；第 3 课时：铁及其化合物、Fe²⁺ 与 Fe³⁺ 转化）。

📖 课堂讲义 · 核心知识点

**一、钠及其重要化合物** 钠的物理性质：银白色金属、质软（可用小刀切割）、密度比水小、熔点低、是热和电的良导体。钠化学性质极活泼，保存在煤油中隔绝空气和水。 与氧气反应：常温下 4Na + O₂ = 2Na₂O（白色）；点燃条件下 2Na + O₂ =（点燃）Na₂O₂（淡黄色）。 与水反应：2Na + 2H₂O = 2NaOH + H₂↑。实验现象口诀「浮、熔、游、响、红」：钠浮在水面（密度小于水）、熔成小球（反应放热且钠熔点低）、四处游动（产生气体推动）、发出嘶嘶声（气体逸出）、滴酚酞变红（生成 NaOH）。 Na₂O 与 Na₂O₂ 对比： | 项目 | Na₂O | Na₂O₂ | |---|---|---| | 颜色状态 | 白色固体 | 淡黄色固体 | | 氧元素价态 | -2 价 | -1 价 | | 与水反应 | Na₂O + H₂O = 2NaOH | 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ | | 与 CO₂ 反应 | Na₂O + CO₂ = Na₂CO₃ | 2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂ | | 类别 | 碱性氧化物 | 过氧化物（不属于碱性氧化物） | Na₂O₂ 与水、CO₂ 反应都有 O₂ 放出，可用作呼吸面具和潜水艇中的供氧剂；这两个反应都是歧化反应，Na₂O₂ 既是氧化剂又是还原剂。 碳酸钠与碳酸氢钠对比： | 项目 | Na₂CO₃（纯碱、苏打） | NaHCO₃（小苏打） | |---|---|---| | 溶解性 | 易溶 | 可溶（同温下溶解度较小） | | 热稳定性 | 稳定，受热不分解 | 不稳定：2NaHCO₃ =（△）Na₂CO₃ + H₂O + CO₂↑ | | 与盐酸反应 | Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑（分步，较快） | NaHCO₃ + HCl = NaCl + H₂O + CO₂↑（更剧烈） | | 与 NaOH 反应 | 不反应 | NaHCO₃ + NaOH = Na₂CO₃ + H₂O | | 相互转化 | Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃ | 加热或加 NaOH 转化为 Na₂CO₃ | 鉴别方法：加热有气体放出的为 NaHCO₃；或滴加热盐酸反应更剧烈的是 NaHCO₃；或向溶液中滴加 BaCl₂（或 CaCl₂）溶液，生成白色沉淀的是 Na₂CO₃（NaHCO₃ 不与 BaCl₂ 反应）。 **二、铝及其化合物** 铝是活泼金属，表面易生成致密的 Al₂O₃ 薄膜，因此抗腐蚀性能好。 与氧气：4Al + 3O₂ = 2Al₂O₃。铝箔在空气中加热熔化但不滴落，就是因为氧化膜包裹。 与酸：2Al + 6HCl = 2AlCl₃ + 3H₂↑；常温下铝在浓硫酸、浓硝酸中钝化。 与碱：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑（铝既能与酸又能与强碱反应，是典型的两性金属表现）。 Al₂O₃ 是两性氧化物：Al₂O₃ + 6HCl = 2AlCl₃ + 3H₂O；Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O。 Al(OH)₃ 是两性氢氧化物，既能与强酸反应又能与强碱反应：Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O；Al(OH)₃ + NaOH = NaAlO₂ + 2H₂O。 实验室用氨水制备 Al(OH)₃：AlCl₃ + 3NH₃·H₂O = Al(OH)₃↓ + 3NH₄Cl。不用 NaOH 的原因是 Al(OH)₃ 会溶于过量强碱。 **三、铁及其化合物** 铁与水蒸气在高温下反应：3Fe + 4H₂O(g) =（高温）Fe₃O₄ + 4H₂。 铁的氧化物对比： | 氧化物 | 俗名 | 颜色状态 | 铁的价态 | |---|---|---|---| | FeO | — | 黑色粉末 | +2 | | Fe₂O₃ | 铁红 | 红棕色粉末 | +3 | | Fe₃O₄ | 磁性氧化铁 | 黑色晶体 | +2 和 +3 | 氢氧化物：Fe(OH)₂ 是白色沉淀，极易被氧化。向 FeSO₄ 溶液中滴加 NaOH 溶液：FeSO₄ + 2NaOH = Fe(OH)₂↓ + Na₂SO₄；现象为先生成白色沉淀，迅速变为灰绿色，最终变为红褐色：4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃。 Fe³⁺ 的检验：滴加 KSCN 溶液，溶液变红（Fe³⁺ + 3SCN⁻ = Fe(SCN)₃），灵敏且现象明显。 Fe²⁺ 的检验：先滴加 KSCN 溶液不变色，再滴加氯水变红，则含 Fe²⁺。 铁三角转化关系： - Fe²⁺ → Fe³⁺（被氧化）：2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻ - Fe³⁺ → Fe²⁺（被还原）：2Fe³⁺ + Fe = 3Fe²⁺；2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺ - 除杂应用：FeCl₂ 溶液中混有 FeCl₃，加足量铁粉过滤；FeCl₃ 溶液中混有 FeCl₂，通入足量氯气。 **四、焰色试验** 焰色试验是检验某些金属元素的物理方法。操作：将铂丝（或洁净铁丝）用盐酸洗涤后灼烧，反复至火焰无色；再蘸取待测液灼烧观察颜色。钠——黄色；钾——紫色（需透过蓝色钴玻璃滤去黄光）。焰色试验每次用完都要用盐酸洗净，原因是盐酸能溶解金属氧化物或盐且易挥发。

🔍 课堂讲义 · 重点难点解析

**重点一：钠与水反应的现象与方程式** 例题：将一小块金属钠投入滴有酚酞的水中，描述现象并解释，写出方程式。 分析：从密度、熔点、反应放热、产物气体与碱五个角度逐条对应现象。 解答：钠浮在水面（密度比水小）、熔成闪亮小球（熔点低、反应放热）、四处游动并发出嘶嘶声（生成 H₂ 推动）、溶液变红（生成 NaOH）。方程式：2Na + 2H₂O = 2NaOH + H₂↑。 小结：现象与性质一一对应记忆，浮熔游响红五个字背后各有一个性质或产物。 **难点一：Na₂O₂ 与水反应的电子转移分析** 例题：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ 中，氧化剂和还原剂分别是什么？每生成 1 mol O₂ 转移多少电子？ 分析：Na₂O₂ 中 O 为 -1 价，反应后一部分降到 NaOH 中 -2 价，一部分升到 O₂ 中 0 价，属于歧化反应。 解答：Na₂O₂ 既是氧化剂又是还原剂，H₂O 既不是氧化剂也不是还原剂。每生成 1 mol O₂ 有 2 mol 氧原子失去 2 mol 电子，同时有 2 mol 氧原子得到 2 mol 电子，即转移电子 2 mol。 小结：歧化反应中同一物质兼任氧化剂与还原剂，电子转移数目按「升价部分」计算即可。 **难点二：Fe²⁺ 检验方案的设计** 例题：某溶液可能含 Fe²⁺ 或 Fe³⁺，请设计实验确定其成分。 分析：Fe³⁺ 遇 KSCN 变红非常灵敏；Fe²⁺ 遇 KSCN 不变色，但能被氯水氧化为 Fe³⁺。 解答：取溶液两份。第一份滴加 KSCN 溶液，若变红则含 Fe³⁺；第二份先滴 KSCN 不变色，再滴加氯水后变红，则原溶液含 Fe²⁺。 小结：Fe²⁺ 检验必须「先 KSCN 后氯水」，顺序颠倒则无法区分原溶液中是否已有 Fe³⁺。 **易错警示：铝与强碱反应的方程式配平** 例题：写出铝与 NaOH 溶液反应的化学方程式并配平。 解答：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑。注意水是反应物且参与电子转移（H 由 +1 降为 0），不能漏写；配平时先定 Al 和 NaAlO₂，再定 NaOH，最后补 H₂O。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：钠的化合物性质对比** 题目：有两瓶白色粉末，分别是 Na₂CO₃ 和 NaHCO₃。请用两种方法鉴别，并写出有关方程式。 分析：利用二者热稳定性差异或与酸反应剧烈程度差异。 解答：方法一（加热法）：各取少量于试管中加热，产生能使澄清石灰水变浑浊气体的原试样是 NaHCO₃：2NaHCO₃ =（△）Na₂CO₃ + H₂O + CO₂↑。方法二（盐酸法）：分别滴入稀盐酸，反应更剧烈的是 NaHCO₃：NaHCO₃ + HCl = NaCl + H₂O + CO₂↑。 方法小结：鉴别题优先利用性质的显著差异——热稳定性、与酸反应速率、沉淀反应。 **例题二（提高）：铝的两性与图像理解** 题目：向 AlCl₃ 溶液中逐滴加入 NaOH 溶液至过量，描述实验现象，写出两阶段离子方程式。 分析：NaOH 少量时生成 Al(OH)₃ 沉淀，NaOH 过量时两性的 Al(OH)₃ 溶解。 解答：现象为「先产生白色沉淀，沉淀逐渐增多，后逐渐溶解直至消失」。第一阶段：Al³⁺ + 3OH⁻ = Al(OH)₃↓；第二阶段：Al(OH)₃ + OH⁻ = AlO₂⁻ + 2H₂O。 方法小结：两性物质「遇强酸显碱性、遇强碱显酸性」，滴加顺序不同现象不同，是图像题的核心考点。 **例题三（综合）：铁三角转化与计算** 题目：向 100 mL FeCl₃ 溶液中加入过量铁粉，充分反应后过滤，得 200 mL 溶液（假设体积不变），其中 c(Fe²⁺) = 1.5 mol/L。(1) 写出离子方程式；(2) 求原 FeCl₃ 溶液的物质的量浓度。 分析：反应为 2Fe³⁺ + Fe = 3Fe²⁺，铁粉过量说明 Fe³⁺ 完全转化。溶液中 n(Fe²⁺) = 0.2 L × 1.5 mol/L = 0.3 mol。 解答： (1) 2Fe³⁺ + Fe = 3Fe²⁺。 (2) 设原溶液中 n(FeCl₃) = x。由方程式 2Fe³⁺ ~ 3Fe²⁺，得 x = 0.3 mol × 2/3 = 0.2 mol。c(FeCl₃) = 0.2 mol ÷ 0.1 L = 2 mol/L。 答：原 FeCl₃ 溶液的物质的量浓度为 2 mol/L。 方法小结：铁三角计算先判断「谁过量、谁耗尽」，再按方程式比例换算，注意溶液体积是否变化。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 钠及其化合物识记

  1. 1. 填空：金属钠保存在________中；钠与水反应的现象可概括为「浮、熔、游、响、红」，其中「熔」说明________，「红」说明产物中有________。写出钠与水反应的化学方程式。
    答：保存在煤油中（隔绝空气和水）。「熔」说明反应放热且钠熔点低；「红」说明生成了碱性的 NaOH（酚酞变红）。方程式：2Na + 2H₂O = 2NaOH + H₂↑。
  2. 2. 完成下列方程式：(1) 钠在氧气中点燃；(2) 过氧化钠与二氧化碳反应；(3) 碳酸氢钠受热分解。
    答：(1) 2Na + O₂ =（点燃）Na₂O₂；(2) 2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂；(3) 2NaHCO₃ =（△）Na₂CO₃ + H₂O + CO₂↑。
  3. 3. 填空：焰色试验中，钠元素的火焰呈________色；钾元素的火焰呈________色，观察时需透过________玻璃。
    答：钠呈黄色；钾呈紫色，需透过蓝色钴玻璃（滤去黄光干扰）。焰色试验是物理方法，检验的是元素而非离子。

中等 · 性质运用与鉴别

  1. 1. 设计两种方法鉴别 Na₂CO₃ 和 NaHCO₃ 的无色溶液，并说明理由（写方程式）。
    答：方法一：分别滴加稀盐酸，反应剧烈、立即产生大量气泡的是 NaHCO₃（NaHCO₃ + HCl = NaCl + H₂O + CO₂↑），较缓和的是 Na₂CO₃（分步反应）。方法二：分别滴加 BaCl₂ 溶液，产生白色沉淀的是 Na₂CO₃（Ba²⁺ + CO₃²⁻ = BaCO₃↓），NaHCO₃ 与 BaCl₂ 不反应。注意：Na₂CO₃ 热稳定性好不能分解，加热法只适用于固体鉴别。
  2. 2. 铝制餐具不宜长时间盛放酸性或碱性食物。用化学方程式说明原因。
    答：铝是两性金属，既能与酸反应：2Al + 6HCl = 2AlCl₃ + 3H₂↑，又能与强碱反应：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑。酸、碱都会破坏表面的 Al₂O₃ 保护膜并继续与铝反应，使餐具被腐蚀。
  3. 3. 现有 FeCl₂ 溶液（含少量 FeCl₃）和 FeCl₃ 溶液（含少量 FeCl₂）两瓶试剂，如何分别除去杂质？写出离子方程式。
    答：FeCl₂ 中除 FeCl₃：加足量铁粉后过滤，2Fe³⁺ + Fe = 3Fe²⁺。FeCl₃ 中除 FeCl₂：通入足量氯气，2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻。除杂原则：不引入新杂质、不损失主物质。

难 · 推断与计算

  1. 1. 计算：将 27.4 g Na₂CO₃ 与 NaHCO₃ 的混合物加热至质量不再减少，冷却称重得固体 21.2 g。求原混合物中 Na₂CO₃ 的质量分数（写出设、写、算、答）。
    答：设混合物中 NaHCO₃ 为 x mol。加热时只有 NaHCO₃ 分解：2NaHCO₃ =（△）Na₂CO₃ + H₂O + CO₂↑，固体质量减少 = 生成的水与二氧化碳质量。减重 = 27.4 - 21.2 = 6.2 g，即每 2 mol NaHCO₃ 减重 18 + 44 = 62 g。6.2 ÷ 62 = 0.1（组），故 n(NaHCO₃) = 0.2 mol，质量 = 0.2 × 84 = 16.8 g。m(Na₂CO₃) = 27.4 - 16.8 = 10.6 g，质量分数 = 10.6 ÷ 27.4 × 100% ≈ 38.7%。答：Na₂CO₃ 质量分数约 38.7%。
  2. 2. 推断：A 是淡黄色固体，与水反应生成含 B 的溶液和无色气体 C，C 能使带火星的木条复燃；向 B 溶液中通入过量 CO₂ 生成白色固体 D。(1) 写出 A、B、C、D 的化学式；(2) 写出 A 与水、B 溶液与 CO₂ 的化学方程式，并指出 A 与水反应的氧化剂。
    答：(1) A 是 Na₂O₂，C 是 O₂，B 是 NaOH，D 是 NaHCO₃。(2) A 与水：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑；B 溶液中通入过量 CO₂：NaOH + CO₂ = NaHCO₃（CO₂ 过量时生成酸式盐）。A 与水反应中 Na₂O₂ 里的氧（-1 价）一部分升到 0 价、一部分降到 -2 价，Na₂O₂ 既是氧化剂又是还原剂（歧化反应）。
  3. 3. 计算：7.8 g Na₂O₂ 与足量 CO₂ 完全反应（2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂）。求标准状况下生成 O₂ 的体积和转移电子的物质的量（写出设、写、算、答）。
    答：设生成 O₂ 为 x mol。n(Na₂O₂) = 7.8 g ÷ 78 g/mol = 0.1 mol，由 2Na₂O₂ ~ 1 O₂ 得 x = 0.05 mol，V = 0.05 × 22.4 = 1.12 L。Na₂O₂ 中氧为 -1 价，歧化生成 O₂ 的部分失电子，每 2 mol Na₂O₂ 转移 2 mol 电子，故转移电子 0.1 mol。答：O₂ 体积 1.12 L，转移电子 0.1 mol。

综合 · 实验与工业应用

  1. 1. 实验综合：某同学向 FeSO₄ 溶液中滴加 NaOH 溶液，观察到白色沉淀迅速变灰绿、最终变红褐色。(1) 解释颜色变化原因并写方程式；(2) 若想让白色 Fe(OH)₂ 保持更久，实验操作上可以怎样改进（至少两条）。
    答：(1) FeSO₄ + 2NaOH = Fe(OH)₂↓ + Na₂SO₄ 生成白色沉淀；Fe(OH)₂ 极易被空气中的氧气氧化：4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃，出现灰绿色过渡色，最终全部变为红褐色 Fe(OH)₃。(2) 改进措施：所用 NaOH 溶液先煮沸除氧；用长胶头滴管伸入液面以下滴加；在溶液表面覆盖一层苯（或植物油）隔绝空气；配制的 FeSO₄ 溶液中加少量铁粉防止氧化。
  2. 2. 工业流程：从铝土矿（主要成分 Al₂O₃，含 Fe₂O₃ 杂质）提取铝的简化流程：铝土矿加足量 NaOH 溶液溶解、过滤；滤液通入足量 CO₂ 得白色沉淀；过滤灼烧得 Al₂O₃；熔融电解得铝。(1) 写出 Al₂O₃ 溶于 NaOH 的方程式；(2) 写出通 CO₂ 和灼烧两步的方程式；(3) 写电解的方程式。
    答：(1) Al₂O₃ + 2NaOH = 2NaAlO₂ + H₂O（Fe₂O₃ 不与 NaOH 反应，过滤除去）。(2) NaAlO₂ + CO₂ + 2H₂O = Al(OH)₃↓ + NaHCO₃；2Al(OH)₃ =（△）Al₂O₃ + 3H₂O。(3) 2Al₂O₃ =（通电，熔融）4Al + 3O₂↑。该流程利用了氧化铝的两性。
  3. 3. 综合计算：将 5.4 g 铝粉加入足量 NaOH 溶液中充分反应。(1) 写出化学方程式；(2) 求标准状况下生成氢气的体积；(3) 若将这些铝粉改为与足量稀盐酸反应，生成氢气的体积与前者相比如何（写出设、写、算、答）。
    答：(1) 2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑。(2) 设生成 H₂ 为 x mol。n(Al) = 5.4 g ÷ 27 g/mol = 0.2 mol，由 2Al ~ 3H₂ 得 x = 0.3 mol，V = 0.3 × 22.4 = 6.72 L。(3) 与盐酸反应：2Al + 6HCl = 2AlCl₃ + 3H₂↑，H₂ 与 Al 的比例同样是 3:2，故生成 H₂ 仍为 0.3 mol，体积 6.72 L，两者相等。答：均为 6.72 L，相等（氢气量由铝决定，与酸碱种类无关）。

💬 课后反馈

**学生常见错误** 1. 钠与水反应现象背得出但对不上性质：说不清「熔」对应钠熔点低、「游」对应生成气体，遇到新情境实验题无从下手。 2. Na₂CO₃ 与 NaHCO₃ 性质混淆：误认为两者热稳定性相同、误用 BaCl₂ 鉴别固体、忘记 NaHCO₃ 与盐酸反应更剧烈。 3. 铝的方程式配平出错：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑ 常漏写水或配错氢气系数；对 Al(OH)₃ 能溶于过量 NaOH 记不牢。 4. Fe²⁺ 检验顺序颠倒：先加氯水再加 KSCN，无法说明原溶液中是否原本就含 Fe³⁺；除杂时把除 Fe³⁺ 和除 Fe²⁺ 的试剂用反。 **教学改进建议** 1. 钠与水反应先看视频或演示，再用「现象—结论」双栏表让学生逐条对应，把口诀背后的性质讲透。 2. Na₂CO₃ 与 NaHCO₃ 用一张大对比表贯穿课堂，配两组对照实验（加热、滴盐酸），在真实观察中记差异。 3. 铁三角教学先画三角图，再让学生补充每条边的试剂与离子方程式，最后配一道除杂题检验迁移。 **分层辅导建议** - 基础层：过关钠、铝、铁的基本方程式书写与颜色记忆，先会写再谈活用。 - 提高层：训练 Na₂O₂ 歧化反应的电子转移分析与混合物计算。 - 拓展层：完成铁三角推断题、铝盐与碱滴加顺序的图像题和实验方案设计题。 **给家长的建议** 1. 孩子复习时可让其把「浮熔游响红」「铁三角」讲给家长听，用讲代背检验掌握程度。 2. 发现孩子方程式配平频繁出错时，督促其先标化合价再配平，并准备一个方程式默写本每周循环过关。
