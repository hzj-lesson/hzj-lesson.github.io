高中高一数学《三角函数》教案

高中高一数学三角函数

📝 备课方案

**教学目标** 1. 理解任意角与弧度制的概念，掌握角度与弧度的互化，会用弧长公式、扇形面积公式解决问题。 2. 掌握任意角三角函数的定义，理解同角三角函数关系式 sin²α + cos²α = 1 及 tanα = sinα ÷ cosα，会运用其求值与化简。 3. 熟记诱导公式并能灵活运用，掌握正弦函数、余弦函数、正切函数的图像与性质（定义域、值域、周期性、奇偶性、单调性、最值），理解 y = Asin(ωx + φ) 的图像变换规律。 4. 掌握两角和与差公式、二倍角公式及辅助角公式，能进行三角恒等变换；掌握正弦定理、余弦定理，能解三角形并解决实际测量问题。 **教学重点**：三角函数的图像与性质；两角和差与二倍角公式的应用；正弦定理与余弦定理。 **教学难点**：诱导公式的记忆与符号判断；y = Asin(ωx + φ) 的图像变换；解三角形中多解情形的讨论。 **教学方法**：数形结合法、类比探究法、讲练结合法、问题驱动法。 **教学准备**：三角函数单位圆演示课件、图像动态演示软件、学案、三角公式卡片。 **课时安排**：4 课时（第 1 课时：任意角与弧度制、同角关系；第 2 课时：诱导公式与图像性质；第 3 课时：图像变换与两角和差、二倍角；第 4 课时：正弦定理、余弦定理解三角形）。

📖 课堂讲义 · 核心知识点

**一、任意角与弧度制** - 角可以看成平面内一条射线绕端点旋转而成，逆时针旋转为正角，顺时针旋转为负角，不旋转为零角。终边相同的角相差整数个周角：与角 α 终边相同的角可表示为 β = α + k×360°（k 为整数）。 - 弧度制：把等于半径长的弧所对的圆心角定义为 1 弧度的角，记作 1 rad。换算关系 180° = π rad，即 1° = π ÷ 180 rad，1 rad = (180 ÷ π)° ≈ 57.3°。 - 弧长公式 l = |α|·r（α 为弧度制下的圆心角），扇形面积公式 S = (1/2)·l·r = (1/2)·|α|·r²。 **二、任意角的三角函数与同角关系** 在角的终边上任取一点 P(x, y)，令 r = √(x² + y²)，则 sinα = y ÷ r，cosα = x ÷ r，tanα = y ÷ x（x ≠ 0）。在单位圆中可直接读出三角函数值。 同角三角函数基本关系：**sin²α + cos²α = 1**；tanα = sinα ÷ cosα。由这两个关系式，已知一个三角函数值可求其余两个，常配合象限判断符号。 **三、诱导公式** 诱导公式可概括为一句话："**奇变偶不变，符号看象限**"。即把角写成 (kπ ÷ 2) ± α 的形式，k 为奇数时函数名改变（正弦变余弦，正切变余切），k 为偶数时函数名不变；符号则把 α 看作锐角，看原函数在对应象限的符号。 | 公式 | 结果 | |---|---| | sin(2kπ + α) | sinα | | sin(−α) | −sinα | | sin(π − α) | sinα | | cos(π − α) | −cosα | | sin(π + α) | −sinα | | cos(π + α) | −cosα | | sin(π/2 − α) | cosα | | cos(π/2 − α) | sinα | | sin(π/2 + α) | cosα | | cos(π/2 + α) | −sinα | **四、三角函数的图像与性质** - y = sinx：定义域 R，值域 [−1, 1]，最小正周期 2π，奇函数。增区间 [2kπ − π/2, 2kπ + π/2]，减区间 [2kπ + π/2, 2kπ + 3π/2]；x = π/2 + 2kπ 时取最大值 1，x = −π/2 + 2kπ 时取最小值 −1；对称轴 x = π/2 + kπ，对称中心 (kπ, 0)。 - y = cosx：定义域 R，值域 [−1, 1]，最小正周期 2π，偶函数。增区间 [2kπ − π, 2kπ]，减区间 [2kπ, 2kπ + π]；x = 2kπ 时取最大值 1，x = π + 2kπ 时取最小值 −1；对称轴 x = kπ，对称中心 (π/2 + kπ, 0)。 - y = tanx：定义域 {x | x ≠ π/2 + kπ}，值域 R，最小正周期 π，奇函数。在区间 (−π/2 + kπ, π/2 + kπ) 上单调递增，无最值，无对称轴，对称中心 (kπ/2, 0)。图像以直线 x = π/2 + kπ 为渐近线。 **五、y = Asin(ωx + φ) 的图像变换** 设 A > 0，ω > 0。由 y = sinx 变换到 y = Asin(ωx + φ)： 1. 平移变换（相位变换）：y = sinx → y = sin(x + φ)，图像向左（φ > 0）或向右（φ < 0）平移 |φ| 个单位。 2. 伸缩变换（周期变换）：y = sin(x + φ) → y = sin(ωx + φ)，横坐标变为原来的 1/ω 倍（纵坐标不变）。 3. 振幅变换：y = sin(ωx + φ) → y = Asin(ωx + φ)，纵坐标变为原来的 A 倍（横坐标不变）。 若先伸缩后平移，则平移量为 |φ ÷ ω| 个单位。函数 y = Asin(ωx + φ) 的周期 T = 2π ÷ ω，振幅为 A，初相为 φ。 **六、两角和差与二倍角公式** - 两角和与差：sin(α ± β) = sinαcosβ ± cosαsinβ；cos(α ± β) = cosαcosβ ∓ sinαsinβ；tan(α ± β) = (tanα ± tanβ) ÷ (1 ∓ tanα·tanβ)。 - 二倍角：sin2α = 2sinαcosα；cos2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α；tan2α = 2tanα ÷ (1 − tan²α)。 - 降幂公式：sin²α = (1 − cos2α) ÷ 2，cos²α = (1 + cos2α) ÷ 2。 - 辅助角公式：asinx + bcosx = √(a² + b²)·sin(x + φ)，其中 tanφ = b ÷ a（φ 由 a、b 的符号确定所在象限）。 **七、解三角形** - 正弦定理：a ÷ sinA = b ÷ sinB = c ÷ sinC = 2R（R 为外接圆半径）。用于已知两角一边，或已知两边及其中一边的对角（此时要注意解的个数讨论）。 - 余弦定理：a² = b² + c² − 2bc·cosA；变形 cosA = (b² + c² − a²) ÷ (2bc)。用于已知三边或两边一夹角。 - 面积公式：S = (1/2)bc·sinA = (1/2)ac·sinB = (1/2)ab·sinC。 **易错提醒** 1. 诱导公式中函数名变不变、符号定在哪一步，容易混淆，务必按"奇变偶不变，符号看象限"两步走。 2. 弧度制下扇形面积公式 S = (1/2)·|α|·r² 中的角必须是弧度制，混用角度制会算错。 3. 已知两边及一边对角用正弦定理时，可能出现两解、一解、无解三种情形，需用"大边对大角"判断。 ![正弦函数图像](/images/function-trig.svg)

🔍 课堂讲义 · 重点难点解析

**重点一：同角关系与诱导公式求值** 例题：已知 sinα = 3/5，且 α 是第二象限角，求 cosα 与 tanα 的值。 分析：由 sin²α + cos²α = 1 先求 cosα，再根据象限确定符号，最后求 tanα。 解答：因为 sin²α + cos²α = 1，所以 cos²α = 1 − (3/5)² = 1 − 9/25 = 16/25。α 是第二象限角，cosα < 0，故 cosα = −4/5。tanα = sinα ÷ cosα = (3/5) ÷ (−4/5) = −3/4。 小结：用平方关系求值必有两解，必须结合角所在象限定符号，这是本节高频失分点。 **难点一：y = Asin(ωx + φ) 的图像变换** 例题：要得到函数 y = sin(2x + π/3) 的图像，可以由 y = sinx 的图像经过怎样的变换得到？请写出两种顺序不同的变换方案。 分析：两种方案关键是平移量与伸缩的先后顺序，先后不同平移量就不同。 解答：方案一（先平移后伸缩）：y = sinx 向左平移 π/3 个单位得 y = sin(x + π/3)，再把横坐标变为原来的 1/2 倍得 y = sin(2x + π/3)。方案二（先伸缩后平移）：y = sinx 把横坐标变为原来的 1/2 倍得 y = sin2x，再向左平移 π/6 个单位得 y = sin[2(x + π/6)] = sin(2x + π/3)。 小结：先伸缩后平移时，平移量是 φ ÷ ω；平移只针对自变量 x，一定要把 x 的系数提出来再看。 **难点二：正弦定理、余弦定理解三角形** 例题：在三角形 ABC 中，已知 a = √3，b = 1，A = 60°，求角 B 和边 c。 分析：已知两边及一边对角，先用正弦定理求 sinB，再讨论解的个数，最后用余弦定理求 c。 解答：由正弦定理 a ÷ sinA = b ÷ sinB，得 √3 ÷ sin60° = 1 ÷ sinB，即 √3 ÷ (√3/2) = 1 ÷ sinB，解得 sinB = 1/2。因为 b < a，所以 B < A = 60°，B 只能取 30°（不能取 150°）。C = 180° − 60° − 30° = 90°，由余弦定理 c² = a² + b² − 2ab·cosC = 3 + 1 − 0 = 4，故 c = 2。 小结：用正弦定理求角后要检验解的个数："大边对大角"，小边对小角则角为锐角。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：诱导公式化简求值** 题目：求值 sin(−120°) + cos(210°) − tan315°。 分析：先用诱导公式把各角化到锐角，再查特殊角三角函数值。 解答：sin(−120°) = −sin120° = −sin(180° − 60°) = −sin60° = −√3/2；cos210° = cos(180° + 30°) = −cos30° = −√3/2；tan315° = tan(360° − 45°) = −tan45° = −1。原式 = −√3/2 + (−√3/2) − (−1) = 1 − √3。 方法小结：负角化正角、大角化锐角，逐步用诱导公式，符号判断靠"符号看象限"。 **例题二（提高）：二倍角与辅助角公式综合** 题目：已知函数 f(x) = sinx·cosx + √3·cos²x，求 f(x) 的最小正周期和最大值。 分析：先用二倍角公式与降幂公式把 f(x) 化为一个正弦型函数。 解答：sinx·cosx = (1/2)sin2x，cos²x = (1 + cos2x) ÷ 2，所以 f(x) = (1/2)sin2x + (√3/2)(1 + cos2x) = (1/2)sin2x + (√3/2)cos2x + √3/2 = sin(2x + π/3) + √3/2。最小正周期 T = 2π ÷ 2 = π；当 sin(2x + π/3) = 1 时取最大值，f(x)max = 1 + √3/2。 方法小结：把函数统一化为 y = Asin(ωx + φ) + b 的形式是求周期、最值、单调区间的通法，关键步骤是"降幂 + 辅助角"。 **例题三（综合）：解三角形的实际应用** 题目：在距塔底水平距离 60 米的 A 点测得塔顶的仰角为 45°，后退 20 米到 B 点再测，仰角为 30°。求塔的高度。（结果保留一位小数） 分析：设塔高为 h，塔底为 C，由两个直角三角形分别表示 A、B 两点到塔底的水平关系，再列方程求解。 解答：设塔高 h 米。在 A 点：仰角 45°，则 A 到塔底距离 AC = h（因为 tan45° = h ÷ AC = 1）。在 B 点：BC = AC + 20 = h + 20，tan30° = h ÷ (h + 20)，即 √3/3 = h ÷ (h + 20)，去分母得 √3(h + 20) = 3h，解得 h = 20√3 ÷ (3 − √3) ≈ 20×1.732 ÷ 1.268 ≈ 27.3 米。 方法小结：测量类问题关键是画出示意图，把已知量标在直角三角形或斜三角形中，选用正弦定理、余弦定理或三角函数定义列方程。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 角度弧度与公式直接运用

  1. 1. 将下列角度化为弧度，弧度化为角度：(1) 120°；(2) 300°；(3) π/3；(4) 5π/4。
    答：利用 180° = π rad。(1) 120° = 120×π ÷ 180 = 2π/3；(2) 300° = 300×π ÷ 180 = 5π/3；(3) π/3 = 180° ÷ 3 = 60°；(4) 5π/4 = 5×180° ÷ 4 = 225°。
  2. 2. 半径为 4 cm 的圆中，圆心角为 60° 的扇形，其弧长和面积各是多少？
    答：先把 60° 化为弧度：60° = π/3。弧长 l = |α|·r = (π/3)×4 = 4π/3 cm；面积 S = (1/2)·|α|·r² = (1/2)×(π/3)×16 = 8π/3 cm²。
  3. 3. 已知 sinα = 4/5，且 α 是第一象限角，求 cosα 和 tanα 的值。
    答：由 sin²α + cos²α = 1 得 cos²α = 1 − 16/25 = 9/25。α 在第一象限，cosα > 0，故 cosα = 3/5。tanα = sinα ÷ cosα = (4/5) ÷ (3/5) = 4/3。

中等 · 诱导公式化简与图像性质

  1. 1. 化简：sin(π + α)·cos(π/2 − α) + cos(−α)·sin(π/2 + α)。
    答：sin(π + α) = −sinα，cos(π/2 − α) = sinα，cos(−α) = cosα，sin(π/2 + α) = cosα。原式 = (−sinα)·(sinα) + cosα·cosα = −sin²α + cos²α = cos²α − sin²α = cos2α。
  2. 2. 求函数 y = 2sinx − 1 的最大值、最小值，以及取得最大值时 x 的取值集合。
    答：当 sinx = 1 时 y 最大 = 2×1 − 1 = 1，此时 x = π/2 + 2kπ（k 为整数），取值集合为 {x | x = π/2 + 2kπ}。当 sinx = −1 时 y 最小 = 2×(−1) − 1 = −3。
  3. 3. 判断函数 y = sin2x 的周期、奇偶性，并写出它在区间 [0, π] 上的单调递增区间。
    答：y = sin2x 的最小正周期 T = 2π ÷ 2 = π。f(−x) = sin(−2x) = −sin2x = −f(x)，是奇函数。令 2x ∈ [−π/2 + 2kπ, π/2 + 2kπ]，即 x ∈ [−π/4 + kπ, π/4 + kπ]，在 [0, π] 上的增区间为 [0, π/4] 和 [3π/4, π]。

难 · 图像变换与恒等变换综合

  1. 1. 将函数 y = cosx 的图像上所有点的横坐标伸长到原来的 2 倍（纵坐标不变），再把所得图像向右平移 π/3 个单位，求所得函数的解析式。
    答：横坐标伸长到原来的 2 倍：y = cos(x/2)；向右平移 π/3 个单位：y = cos[(x − π/3)/2] = cos(x/2 − π/6)。所得解析式为 y = cos(x/2 − π/6)。
  2. 2. 已知 f(x) = √3sin2x − cos2x，把 f(x) 化为 Asin(2x + φ) 的形式，并求其最小正周期、单调递增区间。
    答：f(x) = √3sin2x − cos2x = 2[(√3/2)sin2x − (1/2)cos2x] = 2sin(2x − π/6)。最小正周期 T = π。令 2x − π/6 ∈ [−π/2 + 2kπ, π/2 + 2kπ]，得 x ∈ [−π/6 + kπ, π/3 + kπ]，即递增区间为 [−π/6 + kπ, π/3 + kπ]（k 为整数）。
  3. 3. 已知 sin(π/4 − α) = 3/5，且 0 < π/4 − α < π/2，求 sinα 的值。
    答：令 β = π/4 − α，则 sinβ = 3/5，且 β 为锐角，故 cosβ = 4/5。α = π/4 − β，sinα = sin(π/4 − β) = sin(π/4)cosβ − cos(π/4)sinβ = (√2/2)(4/5) − (√2/2)(3/5) = √2/10。

综合 · 解三角形实际应用

  1. 1. 在三角形 ABC 中，已知 a = 2，b = 2√3，A = 30°，求角 B、角 C 和边 c。
    答：由正弦定理 2 ÷ sin30° = 2√3 ÷ sinB，得 2 ÷ (1/2) = 2√3 ÷ sinB，即 4 = 2√3 ÷ sinB，sinB = √3/2。因为 b > a，所以 B > A，B = 60° 或 120°。当 B = 60° 时，C = 90°，c = √(a² + b²) = √(4 + 12) = 4；当 B = 120° 时，C = 30°，c = a = 2。所以有两组解：(B, C, c) = (60°, 90°, 4) 或 (120°, 30°, 2)。
  2. 2. 在三角形 ABC 中，已知 a = 7，b = 8，c = 5，求角 A 的大小及三角形面积。
    答：用余弦定理：cosA = (b² + c² − a²) ÷ (2bc) = (64 + 25 − 49) ÷ (2×8×5) = 40 ÷ 80 = 1/2，所以 A = 60°。面积 S = (1/2)bc·sinA = (1/2)×8×5×(√3/2) = 10√3。
  3. 3. 某观测站在点 A 处测得海面上灯塔 B 在正北方向，距离 10 海里；10 分钟后灯塔沿正东方向航行到 C 处，此时测得角 BAC = 45°。求灯塔航行的距离 BC。
    答：在直角三角形 ABC 中，角 A = 45°，AB = 10 海里，则 BC = AB·tan45° = 10 海里，所以灯塔航行了 10 海里。若考虑任意三角形情形，由勾股定理 AC = √(AB² + BC²)，本题 A 为直角顶点，直接用锐角三角函数即可。

💬 课后反馈

**学生常见错误** 1. 诱导公式中函数名变与不变判断失误，或符号定错，比如把 sin(π/2 + α) 的符号取成正值。 2. 弧度制与角度制混用：扇形面积公式中把角度制的角直接代入，导致结果错误。 3. 图像变换中"先伸缩后平移"时平移量算错，把 φ 当成平移量而不是 φ ÷ ω。 4. 已知两边及一边对角用正弦定理时忘记讨论解的个数，漏写或误写多解情形。 **教学改进建议** 1. 用单位圆动态演示法讲透诱导公式，让学生在圆上看到角旋转后三角函数值的符号变化，理解"符号看象限"。 2. 强调解三角形"大边对大角、小边对小角"，凡已知两边一对角必须先讨论解的个数再写答案。 3. 把 y = Asin(ωx + φ) 的变换顺序编成口诀，并配专门训练"先平移后伸缩"与"先伸缩后平移"的对比题。 **分层辅导建议** - 基础层：主抓角度弧度互化、同角关系求值、特殊角三角函数值背诵。 - 提高层：练诱导公式化简、图像性质判断（周期、奇偶、单调、最值）的完整书写。 - 拓展层：练图像变换、二倍角与辅助角综合化简、含多解讨论的解三角形问题。 **给家长的建议** 1. 三角函数公式多，可鼓励孩子制作公式卡片，每天抽查几组，像背单词一样反复巩固。 2. 遇到计算错误，先让孩子说清楚每一步用了哪个公式，再对照判断符号，养成规范书写习惯。
