小学三年级科学《水的循环》教案

小学三年级科学水的循环

📝 备课方案

**教学目标** 1. 通过实验和生活观察，知道水蒸发变成水蒸气、水蒸气遇冷凝结成小水珠的现象，能举例说明蒸发和凝结。 2. 认识水的三种状态（固态、液态、气态）及互相转化的条件，知道温度变化是三态变化的主要原因。 3. 能描述水在自然界中的循环过程：蒸发——上升——凝结——降水——径流，并用箭头图表示。 4. 通过解释云、雨、雾、露、霜的形成，发展运用所学知识解释自然现象的能力，感受自然现象之间的联系。 **教学重点**：蒸发和凝结现象；水的三态变化与温度的关系；水循环的过程。 **教学难点**：理解水蒸气是无色透明、看不见的气体，纠正"白气就是水蒸气"的错误认识；完整描述水循环过程。 **教学方法**：实验探究法、观察比较法、情境教学法、图示讲解法。 **教学准备**：烧杯、热水、玻璃片、冰块、酒精灯（教师演示）、湿布、温度计、水循环示意图课件、任务单。 **课时安排**：2 课时（第 1 课时：蒸发与凝结、水的三态变化；第 2 课时：云雨雾露霜的形成与水循环）。

📖 课堂讲义 · 核心知识点

**一、蒸发：水变成水蒸气** 湿衣服晾一段时间变干了，湿布擦过的黑板过一会儿干了，这是因为水变成了**水蒸气**，飞散到空气中去了。这种现象叫**蒸发**。蒸发随时随地都在发生，温度越高、空气越干燥、水面越大，蒸发越快。 水蒸气是**无色、无味、透明、看不见**的气体。特别注意：烧开水时壶嘴冒出的"白气"不是水蒸气，而是水蒸气冲出壶嘴遇冷后**凝结成的小水滴**，真正的水蒸气在"白气"更靠近壶嘴的地方，是看不见的。 **二、凝结：水蒸气变成水** 水蒸气遇冷会重新变成小水珠，这种现象叫**凝结**。 生活中的凝结现象： - 洗热水澡时浴室的镜子上出现小水珠； - 冬天对着玻璃哈气，玻璃上出现水雾； - 从冰箱拿出的饮料瓶外面"出汗"——那是空气中的水蒸气遇到冷的瓶壁凝结成的。 **三、水的三态变化** 水有三种状态：固态（冰）、液态（水）、气态（水蒸气）。 | 变化 | 从什么到什么 | 条件 | 例子 | |---|---|---|---| | 蒸发、沸腾 | 液态到气态 | 温度升高（受热） | 湿衣服晾干、烧开水 | | 凝结 | 气态到液态 | 温度降低（遇冷） | 镜面起雾、露水形成 | | 结冰 | 液态到固态 | 温度降到 0 摄氏度以下 | 水缸结冰、湖面封冻 | | 融化 | 固态到液态 | 温度升高（0 摄氏度以上） | 冰块化成水、雪化了 | 规律：**受热容易变成气态或液态，遇冷容易变成液态或固态**。温度的变化是水的三态变化的主要原因。 **四、云、雨、雾、露、霜的形成** - **云**：江河湖海的水蒸发成水蒸气升上天空，高空温度低，水蒸气凝结成无数小水滴或小冰晶，聚在一起就是云。 - **雨**：云里的小水滴越聚越大，大到空气托不住时，就落下来成为雨。 - **雾**：低空空气中的水蒸气遇冷凝结成的小水滴，飘浮在近地面空气中就是雾。 - **露**：夏秋清晨，草叶、花瓣上凝着的小水珠，是夜间水蒸气遇到较凉的叶面凝结成的。 - **霜**：秋末冬初的夜晚，温度降到 0 摄氏度以下，空气中的水蒸气直接在冷的物体表面凝成的小冰晶。 **五、水在自然界的循环** 江河湖海里的水——太阳照射**蒸发**成水蒸气——**上升**到高空——遇冷**凝结**成小水滴形成云——聚成大水滴**降水**（雨、雪）落到地面——一部分**径流**流回江河湖海，一部分渗入地下。这个过程循环往复，叫作**水循环**。 水循环让淡水不断得到补充：太阳是水循环的动力。江河湖海、天空、地面上的水都在循环中不断变换位置和状态。 **易错提醒** 1. 把"白气"当成水蒸气，其实水蒸气看不见。 2. 以为霜就是结了冰的露，其实霜是水蒸气直接凝成的，不是露冻成的。 3. 描述水循环时漏掉太阳的作用或漏掉某个环节。

🔍 课堂讲义 · 重点难点解析

**重点一：区分水蒸气与"白气"** 例题：烧开水时壶嘴冒"白气"，有人说"白气就是水蒸气"。对吗？请说明理由。 分析：水蒸气是无色透明的气体，用眼睛是看不见的；"白气"能看见，说明它不是气体，而是悬浮的小水滴。 解答：不对。"白气"是壶里冒出的水蒸气离开壶嘴后遇到较冷的空气，凝结成的许许多多小水滴；水蒸气本身看不见。 小结：判断是不是水蒸气，就看能不能看见——能看见的都不是水蒸气。 **重点二：水的三态变化与温度** 例题：冬天，晾在室外的湿衣服结了冰，过了几天衣服还是干了，这是为什么？ 分析：湿衣服先结冰，是水凝固成冰；冰没有融化成水，衣服却干了，说明冰直接变成了水蒸气。 解答：冰在低温下也能慢慢直接变成水蒸气飞散到空气中（这种现象叫升华），所以冰冻的衣服也会干。 小结：水的三态变化都和温度有关，固态也能直接变成气态，只是过程比较慢。 **难点一：完整描述水循环的过程** 例题：用箭头图表示水循环，并把每个环节的变化名称写出来。 分析：抓住"蒸发——上升——凝结——降水——径流"五个环节，再说明每个环节中水的状态变化。 解答：江河湖海的水（液态）——蒸发——水蒸气（气态）上升——高空遇冷凝结成小水滴形成云（液态小水滴）——聚成大水滴下降形成降水（雨、雪）——水沿地面流回江河湖海（径流）。太阳为整个循环提供能量。 小结：讲水循环要讲全"谁在变、怎么变、变到哪"，别忘了太阳这个动力。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：辨认凝结现象** 题目：下面哪些现象是凝结？①冬天窗玻璃内侧出现水雾；②湿毛巾晾干；③清晨草叶上的露珠。 分析：凝结是水蒸气遇冷变成小水珠的过程，对象是"水蒸气"，结果是"小水珠"。 解答：①和③是凝结，都是空气中的水蒸气遇到较冷的物体表面变成的小水珠。②是蒸发，是液态水变成水蒸气飞散了。 方法小结：先看变化前是水还是水蒸气，再看变化后是水珠还是飞散不见，就能区分蒸发和凝结。 **例题二（提高）：解释霜的形成** 题目：深秋的清晨，屋顶和草地上会出现一层白色的霜。霜是怎样形成的？ 分析：霜出现在 0 摄氏度以下的寒冷夜晚，出现在物体表面，是固态的小冰晶。 解答：夜间气温降到 0 摄氏度以下时，空气中的水蒸气遇到很冷的屋顶、草叶等物体，直接凝结（凝华）成小冰晶，这就是霜。 方法小结：解释现象分三步：找条件（温度）、定变化（什么变成什么）、说结果（形成什么）。 **例题三（综合）：解释下雨的过程** 题目：夏天的午后，天空常常积起乌云并下起雨来。请用所学知识解释雨是怎么形成的。 分析：从蒸发开始，按水循环的顺序推理：蒸发——上升——凝结成云——水滴变大——落下成雨。 解答：太阳照射使江河湖海的水蒸发成水蒸气；水蒸气上升到高空遇冷凝结成小水滴，形成云；云里的小水滴不断聚集变大，大到空气托不住时就落下来，形成雨。 方法小结：解释降水类现象都要顺着水循环链条说，关键环节是"蒸发、凝结、聚大、落下"。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 蒸发与凝结辨一辨

  1. 1. 下列现象属于蒸发还是凝结？①湿手在空中一会儿就干了；②洗澡后浴室镜子上有水珠；③晾晒的粮食越来越干。
    答：①是蒸发，液态水变成水蒸气飞散了；②是凝结，水蒸气遇冷镜子变成小水珠；③是蒸发。
  2. 2. 填一填：水有（ ）种状态，分别是（ ）、（ ）、（ ）。
    答：水有三态：固态（冰）、液态（水）、气态（水蒸气）。
  3. 3. 判断对错：烧开水时壶嘴冒出的"白气"就是水蒸气。
    答：错。水蒸气是无色透明看不见的；"白气"是水蒸气遇冷凝结成的小水滴，能看见的都不是水蒸气。

中等 · 三态变化与温度

  1. 1. 把下列变化和它的条件连一连：水结冰、冰融化、水蒸发、水蒸气凝结。备选：遇冷、受热升温到 0 摄氏度以上、降温到 0 摄氏度以下、受热。
    答：水结冰——降温到 0 摄氏度以下；冰融化——受热升温到 0 摄氏度以上；水蒸发——受热；水蒸气凝结——遇冷。
  2. 2. 从冰箱里拿出一瓶饮料，放在桌上，过一会儿瓶子外壁出现小水珠。这些水珠是从哪里来的？
    答：来自空气中的水蒸气。水蒸气遇到温度很低的瓶壁，凝结成小水珠附着在瓶子外壁上，不是从瓶子里渗出来的。
  3. 3. 为什么夏天把湿衣服晾在太阳下比晾在阴凉处干得快？
    答：太阳下温度高，水分蒸发得快；温度越高蒸发越快，所以太阳下衣服干得快。

难 · 解释云雾露霜

  1. 1. 云和雾都是小水滴聚成的，它们有什么不同？
    答：云在高空，是水蒸气上升到高空遇冷凝结成的小水滴（或小冰晶）；雾在近地面，是低空水蒸气遇冷凝结成的小水滴飘浮在空气中。位置不同，本质都是凝结形成的小水滴。
  2. 2. 有人说"霜是露水冻成的"。这种说法对吗？请说明理由。
    答：不对。霜是空气中的水蒸气在 0 摄氏度以下的低温中直接凝成的小冰晶，不是露水结冰形成的。露是水蒸气凝结成的液态小水珠。
  3. 3. 深秋清晨路边的小草上有露珠，而冬天清晨草上却是白色的霜。结合温度分析两次现象的不同。
    答：有露珠的清晨温度在 0 摄氏度以上，水蒸气遇冷凝结成液态小水珠（露）；结霜的清晨温度降到 0 摄氏度以下，水蒸气直接凝成固态小冰晶（霜）。温度不同造成水的状态不同。

综合 · 水循环全过程

  1. 1. 用箭头写出水循环的主要环节，至少包含：蒸发、上升、凝结、降水、径流五个词。
    答：江河湖海的水——蒸发——水蒸气——上升——高空遇冷凝结成云——云中水滴聚大——降水（雨、雪）——径流流回江河湖海（一部分渗入地下）。循环往复，太阳是动力。
  2. 2. 有人说"地球上的水循环一圈后就变少了"。这种说法对吗？
    答：不对。水循环中水只是变换了位置和状态，总量基本不变。蒸发、降水、径流循环往复，水在自然界不断循环运动，不会越循环越少。
  3. 3. 小实验：在杯中倒入热水，把一块冷玻璃片盖在杯口上方（不接触热水），观察玻璃片下表面。你会看到什么？这个实验模拟了水循环的哪个环节？
    答：玻璃片下表面出现小水珠。热水蒸发产生水蒸气，水蒸气上升遇到冷玻璃片凝结成小水珠，模拟了水循环中"蒸发——上升——凝结"的环节。

💬 课后反馈

**学生常见错误** 1. 把"白气""白雾"当成水蒸气，认为看得见的白气就是水蒸气，这是最普遍的错误。 2. 认为霜是露水冻成的，对"水蒸气直接凝成冰晶"缺乏直观感受，理解困难。 3. 描述水循环时环节残缺，常漏掉"上升""径流"或太阳的作用，箭头图画成单向不闭合。 4. 蒸发和凝结的方向混淆：该说"水变成水蒸气"却说成"水蒸气变成水"。 **教学改进建议** 1. 用"看得见与看不见"作为判断标准反复强化：水蒸气看不见，看得见的白气、雾都是小水滴。 2. 冷玻璃片盖热水杯的小实验效果直观，建议人人动手做一遍，再让学生用自己的话讲凝结。 3. 用封闭环形示意图讲解水循环，让学生用手指着箭头完整说一遍全过程，再互相当"小老师"讲解。 **分层辅导建议** - 基础层：能区分蒸发和凝结，能说出水的三态名称及变化条件。 - 提高层：能独立解释露、霜、雾、雨的形成，画出较完整的水循环图。 - 拓展层：挑战解释"冬天窗玻璃内侧有水雾、外侧没有""冰冻的衣服也会干"等拓展现象。 **给家长的建议** 1. 烧水、洗澡、清晨散步时，引导孩子找一找生活中的蒸发和凝结现象，让孩子当"讲解员"。 2. 和孩子一起把水冻成冰、再观察冰融化，体验三态变化，边做边说出变化条件。
