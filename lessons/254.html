初中九年级物理《电功率》教案

初中九年级物理电功率

📝 备课方案

**教材分析** 本课是人教版《物理》九年级全一册第十八章第二节。学生在电能、电功基础上，需要进一步认识电流做功的快慢。本节建立电功率概念，给出定义式 $P=\frac{W}{t}$ 与计算式 $P=UI$，并引入额定功率与实际功率，是初中电学计算的核心内容，也为下一节伏安法测小灯泡的电功率奠定知识与操作基础。 **教学目标** 1. 知道电功率的物理意义、定义与单位，会换算 $1\,kW = 10^3\,W$。 2. 掌握 $P = \frac{W}{t}$ 与 $P = UI$，会选用适当公式计算电功率、电流、电压。 3. 理解额定电压、额定功率与实际电压、实际功率的区别与联系。 4. 知道灯泡亮度由实际功率决定，能用 $P = \frac{U^2}{R}$ 定性判断实际功率变化。 **教学重点** 电功率概念与 $P=UI$；额定功率与实际功率的辨析。 **教学难点** 额定功率与实际功率的区别；不同条件下公式的选用。 **课时** 1 课时 **教学过程** "做功快慢"类比导入→电功率概念→$P=UI$ 推导→铭牌与额定/实际功率→例题辨析→小结作业。

📖 课堂讲义 · 核心知识点

**一、电功率** - 物理意义：表示电流做功快慢（消耗电能快慢）的物理量，符号 $P$。 - 定义：电流在单位时间内所做的功，$P = \frac{W}{t}$。 - 单位：瓦特（$W$），常用单位千瓦（$kW$），$1\,kW = 10^3\,W$。 - 计算式：由 $W=UIt$ 代入定义式得 $P = UI$，即电功率等于电压与电流的乘积，$1\,W = 1\,V\cdot A$。 - 变形：$W = Pt$。由欧姆定律，纯电阻电路还有 $P = I^2R = \frac{U^2}{R}$。 **二、额定功率与实际功率** - 额定电压：用电器正常工作时的电压，记作 $U_{额}$；额定功率：用电器在额定电压下工作时的功率，记作 $P_{额}$（铭牌上标明的数值）。 - 实际功率：用电器在实际电压下工作时的功率 $P_{实}$。 - 三种情形：$U_{实}=U_{额}$ 时 $P_{实}=P_{额}$，用电器正常发光；$U_{实}<U_{额}$ 时 $P_{实}<P_{额}$，偏暗；$U_{实}>U_{额}$ 时 $P_{实}>P_{额}$，偏亮，可能烧坏。 - 重要结论：灯泡的亮度由实际功率决定，额定功率大不一定更亮。 **三、常见用电器的功率** 空调、电热水器、微波炉约几百至数千瓦；电灯、电视机、电冰箱几十至几百瓦；功率反映耗电快慢。 注意区分两个"千瓦"相关的单位：瓦特、千瓦是功率单位；千瓦时（度）是电能单位，表示 $1\,kW$ 的用电器正常工作 $1\,h$ 消耗的电能，即 $1\,kW\cdot h = 3.6\times10^6\,J$。

🔍 课堂讲义 · 重点难点解析

**难点一：额定功率与实际功率** 额定功率是用电器"出厂设定"的，由用电器自身的电阻与额定电压决定（$P_{额}=\frac{U_{额}^2}{R}$），用电器不变则额定功率不变；而实际功率随实际电压改变。判断亮度一律看实际功率：串联电路中电阻大的灯泡实际功率大（$P=I^2R$，$I$ 相同），并联电路中电阻小的灯泡实际功率大（$P=\frac{U^2}{R}$，$U$ 相同）。 **难点二：$P=\frac{W}{t}$、$P=UI$ 与变形公式的选用** 已知电功与时间用 $P=\frac{W}{t}$；已知电压电流用 $P=UI$；纯电阻电路中已知电流与电阻用 $P=I^2R$，已知电压与电阻用 $P=\frac{U^2}{R}$。求电功的配套写法：$W=UIt$ 单位用 $J$，$W=Pt$ 中若 $P$ 用 $kW$、$t$ 用 $h$，则 $W$ 单位是 $kW\cdot h$。 **难点三：灯泡上"220V 100W"信息的挖掘** $220V$ 是额定电压，$100W$ 是额定功率。可求灯丝电阻 $R = \frac{U_{额}^2}{P_{额}} = \frac{220^2}{100} = 484\,\Omega$；正常工作电流 $I=\frac{P_{额}}{U_{额}}=\frac{100}{220}\approx0.45\,A$。若接 $110\,V$ 电压，认为灯丝电阻不变，则 $P_{实}=\frac{U_{实}^2}{R}=\frac{110^2}{484}=25\,W$——电压减半，实际功率减为原来的四分之一。 **常见失误** 1. 把额定功率当成实际功率代入计算。 2. 用额定电压求出的电阻，在算实际功率时未保持电阻不变。 3. $1\,kW$ 与 $1\,kW\cdot h$ 混淆：前者是功率单位，后者是电能单位。

✏️ 课堂讲义 · 典型例题精讲

**例1（概念理解）** 电功率的物理意义是什么？"220V 40W"的白炽灯正常发光时，每秒消耗多少电能？ 解析：电功率表示电流做功的快慢。由 $P=\frac{W}{t}$，正常工作 $1\,s$ 做功 $W = Pt = 40\times1 = 40\,J$，即每秒消耗电能 $40\,J$。 关键：功率是"每秒钟消耗的电能"。 **例2（P=UI 应用）** 一只标有"220V 100W"的灯泡正常发光，通过灯丝的电流多大？灯丝电阻多大？ 解析：由 $P=UI$ 得 $I = \frac{P}{U} = \frac{100}{220} \approx 0.45\,A$。由 $P = \frac{U^2}{R}$ 得 $R = \frac{U^2}{P} = \frac{220^2}{100} = 484\,\Omega$。 关键：额定电压、额定功率配套使用。 **例3（实际功率）** 把"220V 100W"的灯泡接在 $110\,V$ 电源上（灯丝电阻不变），实际功率是多少？亮度如何变化？ 解析：$R=484\,\Omega$ 不变，$P_{实} = \frac{U_{实}^2}{R} = \frac{110^2}{484} = 25\,W$。电压降为一半，实际功率降为四分之一，灯泡明显变暗。 关键：电阻不变，$P$ 与 $U^2$ 成正比。 **例4（变式综合）** 某电动机正常工作时电压 $220\,V$、电流 $5\,A$，求其电功率；若每天工作 $2\,h$，一月（30 天）耗电多少度？ 解析：$P = UI = 220\times5 = 1100\,W = 1.1\,kW$。$W = Pt = 1.1\,kW\times(2\times30)\,h = 66\,kW\cdot h$，即 $66$ 度。 关键：$P=UI$ 求功率；$W=Pt$ 用 $kW$ 与 $h$ 配套得度。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 电功率的物理意义是什么？单位有哪些？写出其定义式。
    答：电功率表示电流做功的快慢，即单位时间内电流所做的功。单位有瓦特（$W$）和千瓦（$kW$），$1\,kW=10^3\,W$。定义式为 $P=\frac{W}{t}$，计算式为 $P=UI$。
  2. 2. 什么是额定电压与额定功率？灯泡亮度由什么决定？
    答：额定电压是用电器正常工作时的电压，额定功率是用电器在额定电压下工作时的功率（铭牌所标）。灯泡的亮度由实际功率决定，不是由额定功率决定。

中等 · 计算应用

  1. 1. 一只电饭煲正常工作时电压 $220\,V$、电流 $4.5\,A$，求其电功率；工作 $30$ 分钟消耗多少电能（用 $kW\cdot h$ 表示）？
    答：$P = UI = 220\times4.5 = 990\,W = 0.99\,kW$。$t = 30\,min = 0.5\,h$，$W = Pt = 0.99\times0.5 = 0.495\,kW\cdot h$，约 $0.5$ 度。
  2. 2. 标有"220V 40W"的灯泡，正常工作电流多大？灯丝电阻多大？
    答：$I = \frac{P}{U} = \frac{40}{220} \approx 0.18\,A$。$R = \frac{U^2}{P} = \frac{220^2}{40} = 1210\,\Omega$。

难 · 实际功率分析

  1. 1. 把"220V 40W"与"220V 100W"两灯串联接入 $220\,V$ 电路，哪盏更亮？说明理由。
    答：先求电阻：$R_1 = \frac{220^2}{40} = 1210\,\Omega$，$R_2 = \frac{220^2}{100} = 484\,\Omega$。串联时电流相同，由 $P=I^2R$，电阻大的 $40W$ 灯实际功率大，故"220V 40W"灯更亮（实际功率大约为 $\frac{220^2}{(1210+484)^2}\times1210\approx19\,W$，$100W$ 灯仅约 $8\,W$）。关键：串联比亮度看电阻，额定功率小的反而亮。
  2. 2. 一盏灯标有"6V 3W"，接在某电源上实际功率为 $0.75\,W$，求电源电压（灯丝电阻不变）。
    答：灯丝电阻 $R = \frac{U_{额}^2}{P_{额}} = \frac{6^2}{3} = 12\,\Omega$。由 $P_{实} = \frac{U_{实}^2}{R}$ 得 $U_{实} = \sqrt{P_{实}R} = \sqrt{0.75\times12} = \sqrt{9} = 3\,V$。

综合 · 家庭节电

  1. 1. 家中同时使用空调（$1000\,W$）、电热水器（$1500\,W$）、电视机（$100\,W$）、冰箱（$150\,W$），干路电流多大？能否用标"220V 10A"的电能表？
    答：总功率 $P_{总}=1000+1500+100+150=2750\,W$。由 $P=UI$ 得干路电流 $I = \frac{P_{总}}{U} = \frac{2750}{220} = 12.5\,A$。$12.5\,A > 10\,A$，超过标定电流，不能长期使用，应错峰使用大功率电器以免烧坏电能表或线路。
  2. 2. 调查家中空调、电视、冰箱、洗衣机铭牌上的额定功率，估算每天总耗电量并提出两条节电措施（用公式说明）。
    答：示例：空调 $1000\,W$ 用 $3\,h$ 耗电 $3\,kW\cdot h$，冰箱 $150\,W$ 全天约 $1.2\,kW\cdot h$ 等，逐项用 $W=Pt$ 求和得日耗电量。节电措施：①空调温度夏季设 $26\,^{\circ}C$ 以上、减少压缩机运行时间 $t$，由 $W=Pt$ 省电；②电器不用时拔插头，消除待机功率；③冰箱减少开门次数、定期除霜。均依据 $W=Pt$ 与 $P=UI$：功率小、时间短则耗电少。

💬 课后反馈

电功率是电学计算的"重头戏"。学生能较快记住 $P=UI$ 并会代入公式，但常在额定功率与实际功率上"张冠李戴"，把额定功率当实际功率、忽略灯丝电阻不变的条件。建议用不同规格灯泡串联并联的实验或对比题讲清"亮度看实际功率"，并强化 $R=\frac{U^2}{P}$ 求电阻这一隐含技巧，同时注意 $kW$ 与 $kW\cdot h$ 单位的辨析。还可补充"灯丝电阻模型"两步训练：先由额定值求电阻，再由实际电压求实际功率，规范书写、减少跳步；课后让学生对比两只额定电压不同灯泡在串联与并联电路中的亮度，分别用 $P=I^2R$ 与 $P=\frac{U^2}{R}$ 解释，深化对额定功率与实际功率区别的理解，为第三节"测量小灯泡的电功率"储备实验分析能力。额定与实际功率这对概念贯穿整个第十八章，学生在后续实验课与生活用电中还将反复用到，务必在第一遍教学中就建立清晰正确的认识。
