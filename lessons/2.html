初中七年级数学《有理数》教案

初中七年级数学有理数

📝 备课方案

**教学目标** 1. 理解正数、负数及 0 的意义，能正确判断一个数是否为有理数。 2. 掌握数轴的三要素，理解相反数、绝对值的概念及其几何意义。 3. 掌握有理数加、减、乘、除、乘方的运算法则，能按正确顺序进行混合运算。 4. 会用科学记数法表示大数与小数，理解近似数与精确度的含义。 **教学重点**：有理数的加减乘除混合运算。 **教学难点**：异号相加的符号确定、绝对值概念的理解与化简。 **教学方法**：数轴演示、法则归纳、分层计算训练。 **课时安排**：5 课时

📖 课堂讲义 · 核心知识点

**一、正数、负数与 0** - 正数：比 0 大的数，如 $+3$、$+1.5$、$\\frac{1}{2}$，正号「+」通常可省略；负数：比 0 小的数，如 $-3$、$-1.5$，负号「-」不能省略。 - 0：既不是正数也不是负数，是正数与负数的分界，表示「没有」或「基准」。 - 相反意义的量：正、负数常用来表示一对具有相反意义的量，如零上/零下、收入/支出、上升/下降、盈利/亏损、向东/向西。 **二、有理数的概念与分类** - 定义：整数和分数统称为有理数。整数含正整数、0、负整数；分数含正分数、负分数。 - 说明：有限小数（如 0.25）与无限循环小数（如 0.333…）都可化为分数，属于有理数；无限不循环小数（如 $\pi$、$\\sqrt{2}$）不是有理数。 - 分类：按定义分，有理数＝整数∪分数；按符号分，为正有理数、0、负有理数。 **三、数轴** - 三要素：原点、正方向（通常取向右）、单位长度，三者缺一不可。 - 性质与应用：数轴上的点与实数一一对应，右边的数总比左边的大；常用于比较大小、表示相反数与绝对值、直观理解运算法则。 **四、相反数** - 定义：只有符号不同的两个数互为相反数；0 的相反数是 0。几何意义：数轴上位于原点两侧、到原点距离相等的两个点所表示的数。 - 代数性质：数 $a$ 的相反数是 $-a$；若 $a+b=0$，则 $a$、$b$ 互为相反数。 **五、绝对值** - 几何定义：数轴上表示数 $a$ 的点到原点的距离，记作 $|a|$，因此 $|a|\ge0$。 - 代数定义：$|a|=a\ (a\ge0)$；$|a|=-a\ (a<0)$。注意当 $a<0$ 时 $-a$ 是正数。 - 性质：$|a|\ge0$；$|a|=|-a|$；若 $|a|=|b|$，则 $a=b$ 或 $a=-b$；几个非负数之和为 0，则每个非负数都为 0。 **六、有理数加法法则** - 同号相加：取相同的符号，并把绝对值相加；异号相加：取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值。 - 互为相反数的两个数相加得 0；一个数同 0 相加，仍得这个数。 **七、有理数减法法则** - 减去一个数，等于加上这个数的相反数，即 $a-b=a+(-b)$。减法转化为加法后按加法法则计算。 **八、有理数乘法与除法法则** - 乘法：同号得正、异号得负，并把绝对值相乘；任何数与 0 相乘都得 0。倒数：乘积为 1 的两个数互为倒数，0 没有倒数。 - 除法：除以一个不等于 0 的数等于乘这个数的倒数，即 $a\div b=a\times\\frac{1}{b}\ (b\neq0)$；两数相除，同号得正、异号得负，并把绝对值相除；0 除以任何非零数都得 0。 **九、有理数乘方** - 定义：$a^n$ 表示 $n$ 个 $a$ 相乘，其中 $a$ 叫底数，$n$ 叫指数。 - 符号法则：正数的任何次幂都是正数；负数的奇次幂是负数、偶次幂是正数；0 的正整数次幂是 0。注意 $-a^n$ 与 $(-a)^n$ 不同——前者先算乘方再取负，后者把 $-a$ 整体乘方。 **十、有理数混合运算顺序** - 先算乘方，再算乘除，最后算加减；有括号先算括号里面的；同级运算从左到右依次进行。 **十一、科学记数法与近似数** - 科学记数法：把绝对值大于 10 的数写成 $a\times10^n$ 的形式，其中 $1\lea<10$，$n$ 为正整数且等于整数位数减 1；小于 1 的正数写成 $a\times10^{-n}$，$n$ 等于第一个非零数字前面零的个数（含小数点前的那个 0）。 - 近似数：用四舍五入法取近似，要明确精确到哪一位（个位、0.1、0.01 等）或保留几个有效数字。

🔍 课堂讲义 · 重点难点解析

**重点：异号两数相加的符号确定** 异号相加是七年级最容易出错的点。正确做法是「先比绝对值，再定符号，后算差值」：比较两数绝对值的大小，取绝对值较大的那个数的符号作为和的符号，再用较大的绝对值减去较小的绝对值。例如 $(-8)+5$：$|-8|=8>|5|=5$，取负号，$8-5=3$，结果为 $-3$。学生常犯的错误是「符号跟着第一个数走」或「绝对值误用加法 」。教学时务必用数轴演示：从原点向左移 8 个单位，再向右移 5 个单位，停在 $-3$，让「先定符、再算值」成为条件反射。 **难点：绝对值的代数定义与化简** $|a|=-a\ (a<0)$ 中，学生易误以为「$-a$ 是负数」。要点拨：当 $a<0$ 时，$-a$ 是正数（负数的相反数是正数），例如 $a=-3$ 时 $|a|=-(-3)=3$。化简含字母的绝对值（如 $|a-2|$）时，要先根据条件判断绝对值内整体的正负，再脱去绝对值符号；判断不了正负时可分类讨论。这是后续整式、二次根式学习的基础。 **常见错误** - 异号相加符号判反、绝对值误用加法； - 误认为 $|-a|=-a$； - 减法忘记变号成加法（把 $a-b$ 误算为 $a+b$）； - 乘方时把 $-2^2$ 算成 4（应为 $-4$），混淆 $-a^n$ 与 $(-a)^n$； - 科学记数法把 $a$ 的范围写错（须满足 $1\lea<10$）。 **微例**：比较 $-(-3)$ 与 $-|-3|$——前者为 $3$，后者为 $-3$，说明「相反数」与「绝对值后再取相反数」含义不同，化简时切勿混淆。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：计算 $(-3)+(-7)$ 与 $5+(-9)$ 解析：① $(-3)+(-7)$ 为同号相加，取负号，绝对值相加：$-(3+7)=-10$。② $5+(-9)$ 为异号相加，$|-9|=9>|5|=5$，取负号，绝对值相减：$-(9-5)=-4$。 关键：同号相加「符号不变、绝对值相加」；异号相加「比绝对值、定符号、再相减」。 **例 2**：若 $|a-2|+|b-3|=0$，求 $a+b$ 解析：绝对值具有非负性，两个非负数之和为 0，则它们各自为 0，即 $a-2=0$ 且 $b-3=0$，解得 $a=2$、$b=3$，故 $a+b=2+3=5$。 关键：「非负数的和为 0，则每个都为 0」是绝对值的核心结论，常考。 **例 3**：计算 $-2^2-(-2)^2+(-1)^3$ 解析：分步计算——$-2^2=-(2^2)=-4$；$(-2)^2=4$；$(-1)^3=-1$。原式 $=-4-4+(-1)=-9$。 关键：务必区分 $-a^2$ 与 $(-a)^2$：前者先平方再取负，后者整体平方。负数的奇次幂为负。 **例 4**：有理数减法与加法互化 解析：计算 $3-(-5)+(-4)$。先化减为加：$3+5+(-4)$；再算 $3+5=8$，$8+(-4)=4$。也可分步：$3-(-5)=8$，$8+(-4)=4$。 关键：减法口诀「减变加、相反数」，即减去一个数等于加上它的相反数。 **例 5**：科学记数法 解析：光在真空中的速度约为 300 000 000 m/s，写成 $a\times10^n$ 形式：小数点向左移动 8 位得 $a=3$，整数位数为 9，故 $n=8$，即 $3\times10^8$。又如 0.000 032，第一个非零数字 3 前面有 5 个零（含小数点前的 0），写成 $3.2\times10^{-5}$。 关键：大数 $n$ 为正且等于整数位数减 1；小数 $n$ 为负且等于第一个非零数字前零的个数。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念与计算

  1. 1. 判断下列各数哪些是有理数：-3，0，π，0.25，$\\sqrt{2}$
    答：有理数：−3、0、0.25（有限小数，可化为分数）。π 与 $\\sqrt{2}$ 是无限不循环小数，不能化成分数，不是有理数。判断标准：整数和分数统称为有理数。
  2. 2. 计算：(-3)+(-7)；5+(-9)；(-8)+8
    答：(−3)+(−7)=−10（同号相加，符号不变、绝对值相加）；5+(−9)=−4（异号，取绝对值大的负号，9−5=4）；(−8)+8=0（互为相反数的两个数相加得 0）。
  3. 3. 写出 5 与 -5 的相反数，并求 |-5|
    答：5 的相反数是 −5；−5 的相反数是 5。|−5|=5，因为数轴上表示 −5 的点到原点的距离是 5 个单位长度。注意：|−5| 表示 −5 的绝对值，结果为正数 5。

中等 · 数轴与绝对值

  1. 1. 在数轴上表示 -2、0、3，并比较大小
    答：画一条水平直线，取原点并规定向右为正方向，定好单位长度：原点左侧 2 个单位处标 −2，原点处标 0，原点右侧 3 个单位处标 3。数轴上右边的数总比左边的大，故 −2<0<3。
  2. 2. 已知 a<0，化简 |a| 与 |a-1|
    答：由 a<0 知 |a|=−a（a 的相反数，为正数）。又因为 a<0 时 a−1<0，所以 |a−1|=−(a−1)=1−a。化简绝对值的关键：先判断绝对值内整体的正负，再脱去绝对值符号。
  3. 3. 计算：(-12)-(-7)+(-5)-(-3)
    答：化减为加：(−12)+(+7)+(−5)+(+3)。分组计算：(−12)+(−5)=−17；(+7)+(+3)=10；−17+10=−7。所以原式 = −7。

难 · 综合应用

  1. 1. 若 |a-2|+|b-3|=0，求 $a^2-b$ 的值
    答：绝对值非负，两个非负数之和为 0，则每项都为 0：a−2=0，得 a=2；b−3=0，得 b=3。代入 $a^2-b$：$2^2-3=4-3=1$。核心结论：若干非负数之和为 0，则每个都为 0。
  2. 2. 某天温度从 -2℃ 上升 5℃ 后再下降 3℃，最终温度是多少？
    答：列式：(−2)+5+(−3)。先算 (−2)+5=3（异号，取正号，5−2=3）；再算 3+(−3)=0。最终温度为 0℃。也可用数轴理解：从 −2 向右移 5 个单位到 3，再向左移 3 个单位到 0。
  3. 3. 分别计算 $-2^2$、$(-2)^2$、$(-2)^3$、$-2^3$，并说明区别
    答：① $-2^2=-(2\times2)=-4$（先平方后取负）；② $(-2)^2=(-2)\times(-2)=4$（整体乘方，负负得正）；③ $(-2)^3=(-2)(-2)(-2)=-8$（负数的奇次幂为负）；④ $-2^3=-(2\times2\times2)=-8$。区别：$-a^n$ 与 $(-a)^n$ 当 $n$ 为偶数时结果不同，计算时要先看清负号是否在括号内。

综合 · 运算与表达

  1. 1. 计算：$-3^2-(-2)^3\div(-4)+|-6|$
    答：分步计算：① $-3^2=-(3^2)=-9$；② $(-2)^3=-8$；③ $(-8)\div(-4)=2$（同号得正）；④ $|-6|=6$。原式 = −9−2+6=−5。注意：先算乘方，再算乘除，最后算加减，且 $-3^2$ 与 $(-3)^2$ 含义不同。
  2. 2. 用科学记数法表示 0.030 50，并说明其精确度
    答：0.030 50 写成 $3.050\times10^{-2}$，其中 $a=3.050$（满足 $1\lea<10$），$n=-2$。末尾的 0 表示精确到 0.000 01（十万分位），即保留四位有效数字，不能随意舍去。科学记数法中 $a$ 的有效数字位数直接体现精确度。
  3. 3. 某仓库第一天运进货物 +25 吨，第二天运出 12 吨，第三天又运进 8 吨，请用有理数运算表示三天后仓库货物变化总量
    答：列式：(+25)+(−12)+(+8)。计算：25+(−12)=13，13+8=21（吨）。所以三天后仓库货物总量比原来增加了 21 吨。用正数表示运进、负数表示运出，是相反意义的量在实际问题中的应用。

💬 课后反馈

有理数是初中数学的起点，正负数、数轴、相反数、绝对值等概念必须扎实。学生易在「异号相加定符号」「绝对值 $|a|=-a$ 时误判正负」「减法忘变号」「$-2^2$ 与 $(-2)^2$ 混淆」四处出错。建议用数轴直观演示符号确定过程，规范「先定符、再算值」的书写步骤，多做口算与化简训练，为后续整式、方程、不等式打下基础。
