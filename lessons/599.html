高中高三语文《作文审题立意与结构》教案

高中高三语文作文审题立意与结构

📝 备课方案

**教学目标** 1. 掌握材料作文的审题方法，能准确提取材料的核心事件、关键语句与写作指令，做到"读懂材料、扣住中心、不偏不跑"。 2. 学会从"是什么、为什么、怎么办"等维度追问立意，实现立意的深化与升华。 3. 掌握"引—议—联—结"的基本结构，能合理安排开头引材料、中间分层论证、结尾总结提升的篇章布局。 4. 强化思辨意识与素材积累，学会运用正反对照、层层递进、因果分析等方法展开论证。 **教学重点**：材料作文的准确审题与核心立意；"引议联结"结构的搭建与段内论证的展开。 **教学难点**：立意的高远独特（从个人上升到时代国家层面）；论证的思辨性（辩证分析、因果追问）与材料有机结合。 **教学方法**：审题演练法、立意升格法、结构图谱教学法、范文评点法，突出"审题精准、立意深刻、结构清晰"。 **教学准备**：多媒体课件、高考作文真题汇编、立意升格对照表、"引议联结"结构模板、优秀范文与升格范文。 **课时安排**：共 2 课时。第 1 课时审题立意（材料类型、审题步骤、立意升格），第 2 课时结构布局与论证展开（引议联结、段内论证、实战演练），并完成限时写作与评讲。

📖 课堂讲义 · 核心知识点

**一、材料作文审题** 审题三读：读整体把握话题；读关键句，圈出提示语与总结句，"对此你有怎样的思考"中的"此"常是写作中心；读指令，明确文体与角度。材料类型：单则抓核心事件，多则找共同话题或对比，名言类扣核心概念，漫画类理解寓意。审题忌撇开材料另起炉灶或抓细枝末节。步骤：通读材料—抓关键句—明确话题—确定中心—验证切题，其中验证最易被忽略。 **二、立意深化与升华** 好立意应"准、深、新"：准指切合主旨，深指透过现象看本质，新指角度独特。升华三径：由个人到集体，把"我"放入家国背景观照；由现象到本质，追问观念与精神价值；由当下到长远，联系时代历史。升格三步：先写初步立意，再追问"为什么、更深的意义何在"，最后改写。如"谈诚信"可升格为"诚信是现代社会高效运转的信任底座"。立意可高但须从材料中来。 **三、结构"引—议—联—结"** 引：一两句引述材料，亮出中心论点。议：主体分层论证，先析材料本质再论意义，可用并列、递进、对照式，每层有观点、阐释、例证、小结句。联：联系现实与自身，增强针对性。结：总结回扣材料与论点。常见问题：开头过长不点题、主体无层次、有例无析、结尾不回扣。对策：开头 3 行点题，主体 2 至 3 个分论点，结尾回扣。

🔍 课堂讲义 · 重点难点解析

**重点一：准确审题** 例题：材料为"有人说成功要靠拼尽全力；也有人说适当躺平也是智慧。对此你有怎样的思考？"确定中心论点。 分析：两观点对立，关键是找到统一角度而非站队。 解答：拼搏与适度休整并非对立，张弛有度才是可持续的奋斗之道。 小结：双观点材料要在辨析中确立立场并说明理由。 **重点二：引议联结搭建** 例题：为《在流量时代守护内容的重量》列提纲。 解答：引——由流量狂欢入题，提出流量不应稀释内容价值。议——内容之重在于真知与深度不可替代；算法是把双刃剑。联——联系读书博主的坚守，反思自身信息消费。结——让优质内容沉得下、立得住。 小结：提纲每段要有"观点＋材料＋分析"的预安排。 **难点一：立意升格** 例题：将"我感动了"的浅层立意升格。 解答：升格为"个体的微光虽小，却是社会信任与温暖的毛细血管，无数微光汇聚构成文明底色"。 小结：由现象到本质、由个人到时代地追问。 **难点二：思辨性论证** 例题：论证"破旧与立新"的关系。 解答：先论破旧的价值；再论守正的底线，精华之旧要守；最后辩证统一，破的是束缚、立的是新生、守的是根脉。 小结：用"承认对方合理处—指出不足—提出辩证观点"三步展开。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（审题立意）** 题目：材料为"冬奥会上年轻运动员挑战极限绽放光芒，背后是无数普通人的平凡坚守。有人说青春该轰轰烈烈，也有人说平凡值得礼赞。对此你有怎样的思考？"写 800 字文章。 审题分析：呈现"高光"与"平凡"对照，宜辩证立意。 立意参考：高光离不开平凡支撑，平凡亦可孕育高光。 写作思路：引材料点题后分三层——高光背后是千万次平凡练习；平凡岗位书写不凡价值（支教教师、工匠）；辩证统一"伟大与平凡相互成就"。结以"让青春在绽放中发光，在坚守中沉淀"。 方法小结：双面材料用"各取其是、辩证统一"策略。 **例题 2（立意升格）** 题目：材料为"AI 时代重复性劳动被机器取代，有人说人将无事可做，有人说人的创造力更珍贵。"完成立意升格。 升格：浅层为"AI 时代要好好学习"。追问：机器取代了什么？——可复制的重复劳动，而情感共鸣、创造性想象难以复制。人区别于机器的是什么？——共情、追问意义、自由创造。升格为"AI 解放的不仅是双手，更是人的创造力与对意义的追寻"。 方法小结：用"为什么、深层原因是什么"逼出立意高度。 **例题 3（引议联结框架）** 题目：以"可为与有为"为主题列框架。 框架：引——提出"于可为之处，立有为之为"。议——可为是时代舞台（航天人圆梦）；有为是个人应答（黄文秀投身扶贫）；可为有为相互成就。联——反思"躺平"与"内卷"，提出理性作为。结——"以青春之有为，回应时代之可为"。 方法小结：议要有层次有例证，联要落地，结要回扣。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 基础巩固

  1. 1. 作文题目：材料为"一只小蚂蚁爬上了大象的背，蚂蚁高兴地说：「我征服了大象！」大象说：「你只是站在我的背上而已。」"请写出中心论点，并说明审题依据。
    答：写作思路：中心论点可定为"认清自我，不把平台的成就当成自己的能力"。审题依据：蚂蚁把大象的背当台阶，错把借力当实力，材料的寓言指向"平台与个人能力"的关系，写作可延伸到"平台红利下的清醒与自省"。
  2. 2. 作文题目：以"传承"为话题，自拟题目，写一篇议论文的开头段（要求：引材料或现象、点出中心论点）。
    答：写作思路：示例开头——"从甲骨文的刻痕到数字博物馆的像素，文明传承的方式在变，而「传下去、承上来」的使命未变。传承不是简单的复刻，而是让古老的智慧在新时代活起来。"首句点现象，次句亮出中心论点。
  3. 3. 判断下列立意哪一个最切合材料"沙漠中唯一的水源滋养了整片绿洲"：A. 水很重要；B. 稀缺资源更能彰显其价值；C. 绿洲的生命力来自水源的滋养，守护稀缺之物即守护生命之源；D. 沙漠很危险。
    答：写作思路：选 C。A 过于笼统，D 偏离核心意象，B 只谈了"稀缺"，C 既扣住"水源与绿洲"的依存关系，又上升到"守护之源"的高度，最切合材料。
  4. 4. 请用一句话概括"引—议—联—结"四部分各自的任务。
    答：写作思路：引——简述材料、亮出中心论点；议——分层论证，分析道理、展开论据；联——联系现实与自身，增强针对性；结——总结全文、回扣材料、升华主旨。四步缺一不可，环环相扣。

中等 · 能力提升

  1. 1. 作文题目：材料为"有人说，要赢在起跑线上；有人说，人生是一场马拉松，起跑快慢并不决定终点。"请确定立意并列出两个分论点。
    答：写作思路：立意——"人生是长跑，起跑的优势终将被坚持与方向改写"。分论点一：起跑线只是起点，持续的努力才是决定因素；分论点二：比起起跑的先后，选择的方向与奔跑的韧性更重要；可分点后补充辩证：不否定起跑优势，但拒绝被起点定义。
  2. 2. 作文题目：以"坚守"为主题，用"引议联结"结构拟出全文提纲。
    答：写作思路：引——由"快时代里的慢坚守"现象入题，亮出论点"真正的价值经得起坚守的检验"。议——分论点一坚守源于认同（例：文物修复师守一技一生）；分论点二坚守贵在持久（例：袁隆平一生躬耕稻田）；分论点三坚守需智慧辨方向（既守正道，又不抱残守缺）。联——联系学生时代对兴趣、理想、品格的坚守。结——回扣材料，点出坚守让平凡开出不凡之花。
  3. 3. 将浅层立意"读书能改变命运"升格为更有深度与新意的立意，并说明升格思路。
    答：写作思路：升格立意——"读书改变的不只是个人命运，更是命运的「接口」——它让人获得与世界对话的能力，让不同境遇的人拥有平等的精神起点"。升格思路：由"个人收益"追问到"能力获得与精神平等"，由"结果层面"上升到"价值层面"。
  4. 4. 作文题目：材料为"一只木桶的容量取决于最短的那块板，这就是「木桶效应」；但也有人说，若把木桶倾斜，容量则取决于最长的板。"请就此写一段议论性文字（150 字左右）。
    答：写作思路：示例——"「木桶效应」提醒我们补齐短板，夯实基础；而「斜桶」之论则启示我们放大长板，出奇制胜。二者并不矛盾：补短板保底线，扬长板拓上限。于个人，应在夯实基础的同时发展核心优势；于国家，应在统筹协调的前提下锻造关键竞争力。"观点、分析、联系三层齐备。

难 · 综合挑战

  1. 1. 作文题目：材料为"2024 年，中国的航天员在太空过年，深中通道建成通车，人工智能加速融入生活。有人说，这是一个充满可能性的时代；也有人说，不确定性让我们焦虑。对此，你有怎样的思考？"请确定立意，写一个 250 字左右的"议"主体段。
    答：写作思路：立意——"拥抱不确定性，正是当代青年的必修课：于变局中找准定位，于挑战中开创新局"。主体段示例："可能性与不确定性是一体两面。航天员在失重中坚守，恰说明越是广阔的可能，越需要笃定的定力；深中通道在风浪中合龙，正印证越是宏大的工程，越考验攻坚的智慧。人工智能带来的不是「被替代」的恐慌，而是倒逼我们升级能力、重新定义劳动的契机。面对不确定，慌乱者看到风险，笃行者看到路径，而真正的成长，恰在于把未知的焦虑转化为已知的行动。"观点句、例证句、分析句、结论句齐备。
  2. 2. 作文题目：材料为"一位老人种下一棵桃树，有人笑他：「你还能等到吃桃子吗？」老人说：「我种桃树，是为后来的人乘凉。」"请据此立意，写出分论点提纲。
    答：写作思路：立意——"功成不必在我，功成必定有我"。提纲：引——由老人种桃树入题，点出"为后人栽树"的利他精神。议——分论点一：利他之举跨越时间的局限（前人植树、后人乘凉的历史例证，如都江堰、红旗渠）；分论点二：利他即是利己，社会的良性循环在付出与回报间展开（乡村教师、社区志愿者）；分论点三：当代青年当有"栽树"的格局，不做只乘凉的"坐享者"。联——联系校园中的志愿活动与集体协作。结——"每一代人都是前人树下的乘凉者，也应是后人路上的栽树人"。
  3. 3. 下面这段开头在审题上有何问题？"读了这则材料，我深受感动。生活中有很多感动的人和事，比如……"（材料谈的是"独立思考的价值"）
    答：写作思路：问题有二：一是开头未引述材料要点，未点明材料谈的"独立思考"话题，属审题跑偏；二是"感动"情绪与材料主旨不匹配，偏离材料核心，且泛泛而谈未聚焦。改进：直接引述材料中"独立思考"的关键句，亮出中心论点"在众声喧哗中保持独立思考，是当代青年的必备素养"，再展开论证。
  4. 4. 作文题目：以"大与小"为话题，写一篇议论文。请确定立意并完成"结"段（100 字左右）。
    答：写作思路：立意——"于小处见大格局，于大处守小初心"。结尾示例："大与小从来不是对立的两极：宏伟的理想须由细小的行动累积，宏大的时代恰由无数个体的微光点亮。愿我们既仰望星空、志存高远，又脚踏实地、不舍微末，让每一个「小我」的坚守，汇入「大我」的征程。"回扣话题、升华意境。

综合 · 高考真题对接

  1. 1. （2023 年高考）阅读下面的材料，根据要求写作："吹灭别人的灯，并不会让自己更加光明；阻挡别人的路，也不会让自己行得更远。""一花独放不是春，百花齐放春满园。"请据此确定立意，并写出写作思路。
    答：写作思路：两则材料共同指向"合作共赢、命运与共"的主题。立意——"照亮他人亦是照亮自己，百花齐放才能春色满园；在时代洪流中，个体与个体、国家与国家唯有携手同行，方能行稳致远"。思路：引——由材料"灯与花"的比喻入题；议——分论点一损人不利己（正面反面对照论证）；分论点二独行快、众行远（文明交流互鉴例证）；分论点三构建人类命运共同体是时代的必然选择；联——联系一带一路、青年国际交流；结——"点亮灯火彼此辉映，共育满园春色"。
  2. 2. （2022 年高考）阅读下面的材料，根据要求写作：围棋"本手、妙手、俗手"三者的辩证关系。请确定立意，写出提纲。
    答：写作思路：立意——"守本手之正，成妙手之新，戒俗手之急；基础扎实方能创新出彩"。提纲：引——由"本手、妙手、俗手"的棋理入题，提出"先守正后出奇"的中心论点。议——分论点一本手是根基，妙手源于对本手的千锤百炼（例：达芬奇画蛋）；分论点二忽视本手追求妙手，终成俗手（例：急于求成者的教训）；分论点三青年当练好基本功再谈创新。联——联系学习中的基础与拔高。结——"人生如棋，守本而后求妙，方能落子无悔"。
  3. 3. （2021 年高考）阅读下面的材料，根据要求写作："可为与有为"话题。请从"时代可为"与"青年有为"的关系角度，完成主体部分两段论证。
    答：写作思路：第一段（时代可为是前提）："时代为青年搭建舞台。从探月工程到深海探测，从脱贫攻坚到乡村振兴，每一片热土都向奋斗者敞开。没有可为的天地，个人的才华便无处安放。"第二段（青年有为是应答）："但舞台不会自动成就演员。有为者以担当回应时代，把个人的志向嵌入民族的坐标——戍边战士以青春守山河，科研工作者以匠心铸重器。可为是时势，有为是选择，唯有笃行者让时势与选择交相辉映。"两段形成"时势—选择"的递进关系。
  4. 4. （2020 年高考）阅读下面的材料，根据要求写作：围绕"齐桓公、管仲、鲍叔"的选人用人故事谈感受。请确定一个独特角度，写出立意与论据方向。
    答：写作思路：立意——"鲍叔牙的「荐贤之公」：成就他人，亦是成就大局"。论据方向：分论点一鲍叔明知管仲射主之仇仍力荐，其"公心"超越了私怨（古今对比：嫉贤妒能者如庞涓与孙膑）；分论点二齐桓公用人不疑，格局决定高度；分论点三从鲍叔的格局看当代人才观念——让专业的人干专业的事。角度独到在于不写管仲之才而写荐才之德，避开俗套，切中"公心与格局"。

💬 课后反馈

**常见错误** 1 审题只抓材料局部，断章取义跑题。2 立意肤浅，停留在"要努力"等空泛层面。3 结构松散，有例无析。4 开头过长不点题，结尾草率不回扣。5 套作贴标签。 **教学改进建议** 1 每课一次"审题限时训练"，5 分钟写出中心论点并互评。2 坚持"立意升格改写"。3 建立"结构与论证自查清单"。 **分层辅导** 学困生先过审题关，练"扣题、点题、回题"；学优生挑战思辨型材料，打磨立意新度。
