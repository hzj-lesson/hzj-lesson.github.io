高中高三数学《概率与统计》教案

高中高三数学概率与统计

📝 备课方案

**教学目标** 1. 掌握简单随机抽样、系统抽样、分层抽样三种抽样方法及适用条件，能根据实际问题正确选择抽样方法。 2. 会用频率分布直方图、茎叶图整理数据，理解直方图中小矩形面积等于该组频率，能由样本数据求众数、中位数、平均数、方差等数字特征。 3. 理解回归分析的思想，会用最小二乘法求线性回归方程；理解独立性检验的思想，会计算 K² 统计量并与临界值比较作出判断。 4. 掌握古典概型与几何概型的概率计算，理解离散型随机变量分布列、期望与方差，会求二项分布与正态分布的概率，并能用概率统计知识解决实际问题。 **教学重点**：用样本估计总体，频率分布直方图求数字特征；离散型随机变量的分布列与期望方差。 **教学难点**：回归分析与独立性检验中公式的理解与计算；二项分布、正态分布的识别与综合应用。 **教学方法**：讲练结合法、数据分析法、情境教学法、小组合作探究法。 **教学准备**：多媒体课件、统计软件演示、例题学案、近年高考概率统计真题汇编。 **课时安排**：4 课时（第 1 课时：抽样与统计图表；第 2 课时：数字特征与回归分析；第 3 课时：独立性检验与古典、几何概型；第 4 课时：分布列、二项分布与正态分布）。

📖 课堂讲义 · 核心知识点

**一、随机抽样** 抽样的目的是用样本估计总体，前提是样本必须具有代表性。 - 简单随机抽样：总体中每个个体被抽到的机会都相等。常用抽签法（编号、写签、搅拌均匀、逐个抽取）和随机数法（利用随机数表或计算机产生随机数）。适合总体容量较小的情况。 - 系统抽样：当总体容量较大且个体无明显差异时，先把总体编号，再按确定间隔等距抽取，抽样距 k = 总体容量 N ÷ 样本容量 n。比如给全校 5000 名学生编号后每隔 50 人抽 1 人，就是系统抽样。 - 分层抽样：当总体由差异明显的几部分组成（如按年龄、性别分层）时，按各层个体数占总体数的比例抽取，各层比例相同。 | 抽样方法 | 适用条件 | 抽取特点 | |---|---|---| | 简单随机抽样 | 总体容量较小 | 逐个抽取，每个个体机会相等 | | 系统抽样 | 总体容量较大、无显著层次 | 等距抽取，间隔 k = N ÷ n | | 分层抽样 | 总体由差异明显的层组成 | 按比例分层抽取 | **二、用样本估计总体** 频率分布直方图的作图步骤：求极差（最大值减最小值）→ 决定组距与组数（组数一般取 5 至 12 组）→ 将数据分组 → 列频率分布表 → 画直方图。直方图的核心结论：**每个小矩形的面积 = 组距 × 纵坐标（频率 ÷ 组距）= 该组的频率**，所有小矩形面积之和等于 1。 | 数字特征 | 定义 | 在频率分布直方图中的求法 | |---|---|---| | 众数 | 出现次数最多的数 | 最高小矩形底边中点的横坐标 | | 中位数 | 排序后居中间的数（面积等分点） | 使直方图左右两侧面积各占 0.5 的横坐标 | | 平均数 | 各数据与权重乘积之和 | 每组中点横坐标 × 该组面积（频率）再求和 | | 方差 | 反映数据波动大小 | 方差越大波动越大，越小越稳定 | **三、回归分析** 研究两个变量的相关关系时先作散点图，若点大致呈带状分布则两变量线性相关。最小二乘法求回归直线方程 ŷ = bx + a，其中： b = Σ(xi − x̄)(yi − ȳ) ÷ Σ(xi − x̄)²，a = ȳ − b·x̄。 回归直线必过样本中心点 (x̄, ȳ)；斜率 b 表示 x 每增加 1 个单位，y 平均增加 b 个单位。 **四、独立性检验** 用 2×2 列联表研究两个分类变量是否有关系。构造统计量 K² = n(ad − bc)² ÷ [(a + b)(c + d)(a + c)(b + d)]，其中 a、b、c、d 是列联表中的频数，n 为样本总量。将计算出的 K² 与临界值比较：K² > 6.635 时有 99% 的把握认为两变量有关系；K² > 3.841 时有 95% 的把握认为两变量有关系。 **五、古典概型与几何概型** - 古典概型：基本事件有限个且每个事件等可能，P(A) = 事件 A 包含的基本事件数 ÷ 基本事件总数。 - 几何概型：基本事件无限个但具有等可能性，P(A) = 构成事件 A 的区域测度（长度、面积或体积）÷ 全部结果对应的区域测度。 **六、离散型随机变量及其分布** 把随机变量 X 的所有取值 x1, x2, …, xn 及对应概率 p1, p2, …, pn 列成表就是分布列，它满足 pi ≥ 0 且 p1 + p2 + … + pn = 1。期望 E(X) = Σ xi·pi 刻画平均取值水平；方差 D(X) = Σ (xi − E(X))²·pi 刻画波动大小，方差越小越稳定。 **七、二项分布与正态分布** - 二项分布：n 次独立重复试验，每次成功的概率都为 p，记 X ~ B(n, p)，则 P(X = k) = C(n, k)·p^k·(1 − p)^(n−k)（k = 0, 1, …, n），且 E(X) = np，D(X) = np(1 − p)。 - 正态分布：X ~ N(μ, σ²)，密度曲线关于直线 x = μ 对称，呈"中间高、两头低"的钟形，σ 越小曲线越"瘦高"。三个常用概率：P(μ − σ < X < μ + σ) ≈ 0.6827，P(μ − 2σ < X < μ + 2σ) ≈ 0.9545，P(μ − 3σ < X < μ + 3σ) ≈ 0.9973，这就是"3σ 原则"。 **易错提醒** 1. 直方图纵轴是"频率 ÷ 组距"而不是频率，求频率必须用面积（纵坐标乘组距）。 2. 分层抽样各层抽取比例必须相同，且各层抽取人数之和要等于样本容量。 3. 回归方程中 b 的符号应与散点图走向一致；独立性检验中 K² 越大越有把握认为两变量有关。

🔍 课堂讲义 · 重点难点解析

**重点一：频率分布直方图与数字特征** 例题：某校 100 名学生一次数学测试的成绩频率分布直方图按组距 10 分组，各组中点横坐标依次为 55、65、75、85、95，对应小矩形面积依次为 0.05、0.15、0.40、0.30、0.10。求这 100 名学生成绩的平均数、众数、中位数。 分析：平均数用每组中点 × 该组频率（面积）求和；众数取面积最大一组底边中点；中位数是面积累计到 0.5 的横坐标。 解答：平均数 = 55×0.05 + 65×0.15 + 75×0.40 + 85×0.30 + 95×0.10 = 2.75 + 9.75 + 30 + 25.5 + 9.5 = 77.5（分）。众数 = 75（面积最大的第三组底边中点）。求中位数：前两组面积合计 0.05 + 0.15 = 0.20，还差 0.30 到 0.5；第三组组距 10 对应面积 0.40，所以 0.30 对应长度 0.30 ÷ 0.40 × 10 = 7.5，中位数 = 70 + 7.5 = 77.5。 小结：抓住"面积 = 频率"，三个数字特征都能从直方图中直接读出，且中位数是面积的等分点。 **难点一：回归直线方程的求法** 例题：已知 5 组数据 (x, y) 的样本中心点为 (3, 7)，且 Σ(xi − x̄)(yi − ȳ) = 10，Σ(xi − x̄)² = 20。求回归方程 ŷ = bx + a，并预测 x = 6 时 y 的估计值。 分析：先由公式求斜率 b，再用 a = ȳ − b·x̄ 求截距。 解答：b = 10 ÷ 20 = 0.5，a = 7 − 0.5 × 3 = 5.5，所以 ŷ = 0.5x + 5.5。当 x = 6 时，ŷ = 0.5 × 6 + 5.5 = 8.5。 小结：回归直线必过样本中心点 (x̄, ȳ)，用它检验计算是否正确十分方便。 **难点二：独立性检验的计算与判断** 例题：为调查喜爱某运动是否与性别有关，随机调查 200 人。男生中喜爱 60 人、不喜爱 40 人；女生中喜爱 45 人、不喜爱 55 人。计算 K² 并判断是否有 95% 的把握认为喜爱程度与性别有关（临界值 3.841）。 分析：先列出 2×2 列联表，再代入公式计算，最后与临界值比较。 解答：a = 60，b = 40，c = 45，d = 55，n = 200。K² = 200×(60×55 − 40×45)² ÷ [(60 + 40)(45 + 55)(60 + 45)(40 + 55)] = 200×(3300 − 1800)² ÷ (100×100×105×95) = 200×2250000 ÷ 99750000 ≈ 4.51。因为 4.51 > 3.841，所以有 95% 的把握认为喜爱这项运动与性别有关。 小结：K² 越大越有把握认为两变量有关；比较时要看清临界值对应的把握程度。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：抽样方法与古典概型** 题目：某工厂有老年工人 80 人、中年工人 120 人、青年工人 200 人，现要抽取容量为 40 的样本了解职工健康状况。应采用什么抽样方法？各层分别抽取多少人？ 分析：总体由年龄差异明显的三层组成，应采用分层抽样，按各层人数占总体数的比例抽取。 解答：抽样比例 = 40 ÷ (80 + 120 + 200) = 40 ÷ 400 = 1/10。老年层：80 × 1/10 = 8 人；中年层：120 × 1/10 = 12 人；青年层：200 × 1/10 = 20 人。三个数之和 8 + 12 + 20 = 40，正好等于样本容量。 方法小结：分层抽样按比例抽取，各层抽取人数之和必须等于样本容量。 **例题二（提高）：离散型随机变量的分布列与期望** 题目：袋中有 3 个白球、2 个黑球，不放回地依次取出 2 个球。设 X 为取出的 2 个球中黑球的个数，求 X 的分布列与期望 E(X)。 分析：X 可能取 0、1、2，用组合数按古典概型逐个求概率，并验证概率之和为 1。 解答：P(X = 0) = C(3,2) ÷ C(5,2) = 3/10；P(X = 1) = C(3,1)·C(2,1) ÷ C(5,2) = 6/10 = 3/5；P(X = 2) = C(2,2) ÷ C(5,2) = 1/10。分布列：X = 0 概率 3/10，X = 1 概率 3/5，X = 2 概率 1/10（和为 1，正确）。E(X) = 0×3/10 + 1×3/5 + 2×1/10 = 0 + 0.6 + 0.2 = 0.8。 方法小结：不放回抽取用组合数求古典概率；分布列写完后先验证 Σpi = 1 再算期望。 **例题三（综合）：二项分布与实际应用** 题目：某射手每次射击命中目标的概率为 0.6，各次射击相互独立。他连续射击 4 次，求：(1) 恰好命中 2 次的概率；(2) 命中次数 X 的期望与方差。 分析：4 次独立重复试验，每次命中概率恒为 0.6，故 X ~ B(4, 0.6)，可直接套用二项分布公式。 解答：(1) P(X = 2) = C(4,2)×0.6²×0.4² = 6×0.36×0.16 = 0.3456。(2) E(X) = np = 4×0.6 = 2.4；D(X) = np(1 − p) = 4×0.6×0.4 = 0.96。 方法小结：识别"n 次独立重复 + 每次概率不变"即用二项分布，期望方差直接用 E = np、D = np(1 − p) 计算，不必逐项列分布列。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 抽样方法与概率基本运算

  1. 1. 某中学有高中部学生 1200 人、初中部学生 800 人，要抽取容量为 100 的样本了解学生睡眠情况，应采用什么抽样方法？各部分各抽取多少人？
    答：总体由高中生、初中生两组成分差异明显，采用分层抽样。抽样比例 = 100 ÷ (1200 + 800) = 1/20，高中部 1200×1/20 = 60 人，初中部 800×1/20 = 40 人，60 + 40 = 100 人，符合要求。
  2. 2. 一组数据中共有 60 个观测值，频率分布表中某一组的频数为 15，求该组的频率。若组距为 5，频率分布直方图中该小矩形的高（纵坐标）是多少？
    答：频率 = 频数 ÷ 总数 = 15 ÷ 60 = 0.25；纵坐标 = 频率 ÷ 组距 = 0.25 ÷ 5 = 0.05。注意直方图的纵坐标是频率 ÷ 组距。
  3. 3. 同时掷两枚质地均匀的骰子，求朝上一面的点数之和为 5 的概率。
    答：基本事件总数为 6×6 = 36 种，和为 5 的情况有 (1,4)、(2,3)、(3,2)、(4,1) 共 4 种，所以 P = 4/36 = 1/9。

中等 · 数字特征、分布列与期望方差

  1. 1. 某次考试 8 名学生的成绩为：72、78、80、82、85、85、90、96。求这组成绩的众数、中位数和平均数。
    答：众数：85（出现 2 次最多）。中位数：排序后第 4、5 个数为 82 和 85，取平均 (82 + 85) ÷ 2 = 83.5。平均数 = (72 + 78 + 80 + 82 + 85 + 85 + 90 + 96) ÷ 8 = 668 ÷ 8 = 83.5。
  2. 2. 从装有 4 个红球和 1 个白球的不透明袋子中，有放回地摸球 2 次。设 X 为摸到白球的次数，写出 X 的分布列并求期望。
    答：每次摸到白球概率为 1/5，有放回即独立重复，X ~ B(2, 1/5)。P(X=0) = (4/5)² = 16/25；P(X=1) = 2×(1/5)×(4/5) = 8/25；P(X=2) = (1/5)² = 1/25。E(X) = np = 2×1/5 = 0.4。
  3. 3. 甲、乙两名同学 5 次测验成绩的方差分别为 s甲² = 4.2，s乙² = 7.8，且两人平均分相同。判断谁的发挥更稳定，并说明理由。
    答：甲的方差更小，所以甲的成绩更稳定。方差反映数据的波动程度，方差越小说明偏离平均分的程度越小、发挥越稳定。

难 · 回归分析、独立性检验与正态分布

  1. 1. 某车间生产时间 x（小时）与产量 y（件）的 4 组数据为：(1, 3)、(2, 5)、(3, 6)、(4, 8)。求回归直线方程 ŷ = bx + a，并预测生产 5 小时时的产量。
    答：先求 x̄ = (1+2+3+4) ÷ 4 = 2.5，ȳ = (3+5+6+8) ÷ 4 = 5.5。Σ(xi−x̄)(yi−ȳ) = (−1.5)(−2.5) + (−0.5)(−0.5) + 0.5×0.5 + 1.5×2.5 = 3.75 + 0.25 + 0.25 + 3.75 = 8；Σ(xi−x̄)² = 2.25 + 0.25 + 0.25 + 2.25 = 5。所以 b = 8 ÷ 5 = 1.6，a = 5.5 − 1.6×2.5 = 1.5，ŷ = 1.6x + 1.5。当 x = 5 时，ŷ = 1.6×5 + 1.5 = 9.5（件）。
  2. 2. 某市调查性别与是否喜欢网购的关系，数据为：男性喜欢 90 人、不喜欢 60 人；女性喜欢 110 人、不喜欢 40 人。共 300 人，计算 K² 并判断是否有 95% 的把握认为性别与喜欢网购有关（临界值 3.841）。
    答：a = 90，b = 60，c = 110，d = 40，n = 300。K² = 300×(90×40 − 60×110)² ÷ [(90+60)(110+40)(90+110)(60+40)] = 300×(3600 − 6600)² ÷ (150×150×200×100) = 300×9000000 ÷ 450000000 = 6。因为 6 > 3.841，所以有 95% 的把握认为性别与喜欢网购有关。
  3. 3. 某种零件的长度 X ~ N(100, 4)（单位：mm），即 μ = 100，σ = 2。求长度落在区间 [98, 102] 内的概率约是多少？落在 [94, 106] 外的概率约是多少？
    答：[98, 102] 即 μ − σ 到 μ + σ，概率约 0.6827。落在 [94, 106] 外即落在 μ ± 3σ 之外，P ≈ 1 − 0.9973 = 0.0027。

综合 · 概率统计综合应用

  1. 1. 某商场促销活动：顾客掷一枚质地均匀的骰子，掷出 6 点得一等奖（奖金 50 元），掷出 3 或 4 点得二等奖（奖金 20 元），其余情况不得奖。设一次抽奖中商场付出的奖金为 X 元，求 X 的分布列、期望，并判断该活动对顾客是否公平（门票 10 元）。
    答：P(X=50) = 1/6；P(X=20) = 2/6 = 1/3；P(X=0) = 3/6 = 1/2。分布列为 X=0 概率 1/2，X=20 概率 1/3，X=50 概率 1/6。E(X) = 0×1/2 + 20×1/3 + 50×1/6 = 20/3 + 50/6 = 40/6 + 50/6 = 90/6 = 15 元。门票 10 元，而奖金期望 15 元 > 10 元，长期看商场亏损，对顾客有利。
  2. 2. 某工厂生产的电子元件合格率为 0.95，现从一批产品中有放回地抽检 10 件。设 X 为抽到的合格品件数。(1) 写出 X 服从的分布并求 E(X)、D(X)；(2) 求抽到恰有 9 件合格品的概率（结果保留三位小数）。
    答：X ~ B(10, 0.95)。E(X) = 10×0.95 = 9.5；D(X) = 10×0.95×0.05 = 0.475。P(X=9) = C(10,9)×0.95⁹×0.05 ≈ 10×0.6302×0.05 ≈ 0.315。
  3. 3. 某地区调查 200 名高中生的每周课外阅读时间，频率分布直方图中按组距 2 小时分组，各组中点分别为 1、3、5、7、9 小时，对应小矩形面积分别为 0.10、0.25、0.35、0.20、0.10。(1) 求阅读时间的平均数与中位数；(2) 估计阅读时间超过 6 小时的学生约有多少人。
    答：(1) 平均数 = 1×0.10 + 3×0.25 + 5×0.35 + 7×0.20 + 9×0.10 = 0.1 + 0.75 + 1.75 + 1.4 + 0.9 = 4.9 小时。求中位数：前两组面积 0.10 + 0.25 = 0.35，第三组需补 0.15，第三组组距 2 对应面积 0.35，0.15 对应长度 0.15 ÷ 0.35 × 2 ≈ 0.857，中位数 ≈ 4 + 0.857 ≈ 4.86 小时。(2) 超过 6 小时的是后两组，频率 = 0.20 + 0.10 = 0.30，人数 ≈ 200×0.30 = 60 人。

💬 课后反馈

**学生常见错误** 1. 在频率分布直方图中求频率时直接用纵坐标（频率 ÷ 组距），漏乘组距，导致结果错误。 2. 分层抽样比例计算错误，或抽取后忘记检查各层人数之和是否等于样本容量。 3. 独立性检验中 K² 计算容易出错，或比较方向弄反，算出 K² 较大却误判为"无关联"。 4. 分布列漏写取值项或概率之和不等于 1，期望方差公式混用，如把二项分布的 D(X) 记成 np。 **教学改进建议** 1. 组织学生用班级真实数据（如身高、成绩）亲手绘制一次频率分布直方图，把"面积等于频率"落实在操作体验中。 2. 帮助学生建立识别模型："有放回、独立重复、概率不变"用二项分布；"不放回抽取"用古典概型组合数。 3. 讲清独立性检验临界值表的查法，反复强调"K² 越大越有把握认为两变量有关系"这一判断方向。 **分层辅导建议** - 基础层：重点练抽样方法判断、古典概型计数、直方图读频率，先把公式记牢。 - 提高层：重点练直方图求三个数字特征、分布列与期望方差的完整书写过程。 - 拓展层：练回归方程与独立性检验的套公式计算，以及含决策背景的综合应用题。 **给家长的建议** 1. 引导孩子用统计眼光看身边数据，比如全班成绩的众数、中位数、平均分各说明什么，体会统计的价值。 2. 看孩子订正错题时，不要只看答案对错，请孩子口述一遍求概率、求方差的完整步骤，暴露思路漏洞。
