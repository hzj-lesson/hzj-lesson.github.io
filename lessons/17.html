初中七年级生物《细胞的结构》教案

初中七年级生物细胞的结构

📝 备课方案

**教学目标** 1. 说出显微镜的基本结构与使用步骤，能规范使用显微镜观察标本。 2. 描述动物细胞和植物细胞的基本结构及其功能。 3. 比较并说出动植物细胞的主要异同。 **教学重点**：动植物细胞的结构与功能、显微镜的使用。 **教学难点**：区分动植物细胞的结构差异，显微镜的对光、调焦与污点判断。 **教学方法**：显微镜观察、结构图绘制、对比归纳、实验操作。 **课时安排**：2 课时

📖 课堂讲义 · 核心知识点

![细胞的结构示意图](/images/cell.svg) **一、细胞是生命活动的基本单位** 除病毒外，生物都是由细胞构成的；细胞的生活需要物质和能量，能进行物质交换和信息传递。 **二、显微镜的结构与使用** - 主要结构：目镜、物镜（放大）、遮光器（光圈）、反光镜（反光）、粗准焦螺旋/细准焦螺旋（调焦）、载物台、压片夹 - 放大倍数 = 目镜倍数 × 物镜倍数 - 使用步骤：取镜安放 → 对光（看到白亮视野）→ 放置标本 → 调焦观察 → 收镜 - 成像特点：上下左右都颠倒（物像偏哪，装片就向哪移）；污点可能在目镜、物镜或装片上 **三、动物细胞的基本结构（3 部分）** - **细胞膜**：控制物质进出细胞，保护 - **细胞质**：生命活动的主要场所 - **细胞核**：内含遗传物质，控制中心 **四、植物细胞的基本结构（比动物细胞多 3 部分）** - 细胞膜、细胞质、细胞核（同上） - **细胞壁**：位于最外层，支持和保护（植物细胞有，动物没有） - **叶绿体**：进行光合作用，含叶绿素（绿色部分才有） - **液泡**：内含细胞液，储存糖分、色素、水分（切西瓜流出的汁液来自液泡） - 此外动植物细胞都有**线粒体**（呼吸作用的主要场所，动植物都有） **五、临时装片制作** - 洋葱表皮细胞：擦 → 滴清水 → 撕 → 展 → 盖 → 染（碘液）→ 吸 - 口腔上皮细胞：擦 → 滴生理盐水 → 刮 → 涂 → 盖 → 染 → 吸 **六、动植物细胞比较表** | 结构 | 植物细胞 | 动物细胞 | |------|----------|----------| | 细胞壁 | 有 | 无 | | 叶绿体 | 有（绿色部分） | 无 | | 液泡 | 有大液泡 | 无（或小） | | 细胞膜/细胞质/细胞核/线粒体 | 都有 | 都有 |

🔍 课堂讲义 · 重点难点解析

**重点：动植物细胞的结构差异** 相同点：都有细胞膜、细胞质、细胞核、线粒体。 不同点：植物细胞还有细胞壁、叶绿体、液泡，动物细胞没有这三样。 **难点一：显微镜的调焦与污点判断** - 先用低倍镜、粗准焦螺旋找到物像，再用细准焦螺旋微调清晰； - 视野中出现污点，可转动目镜、移动装片判断：动的是目镜或装片，都不动则在物镜上； - 物像若偏左上方，装片应向左上方移动（物像与装片移动方向相反）。 **难点二：叶绿体与叶绿素、细胞壁与细胞膜** - 叶绿体是"场所"，叶绿素是叶绿体里的"色素"，叶肉细胞呈绿色是因为有叶绿体、含叶绿素； - 细胞壁是最外层较厚的结构（支持保护），细胞膜紧贴细胞壁内侧、薄而控制物质进出，二者功能不同。 **常见误区** - 误以为动物细胞没有线粒体（其实有，只是没液泡/叶绿体）； - 误以为所有植物细胞都有叶绿体（只有绿色部位如叶肉、表皮保卫细胞才有）。

✏️ 课堂讲义 · 典型例题精讲

**例1**：切西瓜时流出的红色汁液主要来自细胞的哪一结构？ **解**：西瓜细胞有大液泡，液泡内的细胞液含糖分和色素，切开时液泡破裂，汁液流出。 **答**：液泡。 **关键**：汁液、糖类、色素多储存在液泡中。 **例2**：为什么叶片的叶肉细胞是绿色的？ **解**：叶肉细胞含有叶绿体，叶绿体中含有叶绿素，能吸收光能进行光合作用，所以呈绿色。 **关键**：绿色来自叶绿体中的叶绿素，不是细胞膜。 **例3**：用显微镜观察时，物像偏在视野左上方，应把装片向哪个方向移动？ **解**：显微镜成倒像，物像移动方向与装片移动方向相反，要把物像移到中央，装片应向左上方移动。 **答**：左上方。 **关键**：偏哪移哪（装片移向物像所在方向）。 **例4**：显微镜目镜 10×、物镜 40×，放大倍数是多少？换成 10× 物镜后视野有何变化？ **解**：放大倍数 = 10 × 40 = 400 倍；换成 10× 物镜后总倍数为 100 倍，放大倍数变小，视野变亮、看到的细胞数目变多、单个细胞变小。 **关键**：倍数越大，视野越暗、细胞数越少、细胞越大。 **例5**：用显微镜观察时，发现污点随装片移动而移动，污点在哪里？ **解**：污点可能在目镜、物镜或装片。随装片移动而移动，说明污点在装片上。 **答**：装片。 **关键**：动谁就是谁（转动目镜动→目镜；移装片动→装片；都不动→物镜）。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 结构与绘图

  1. 1. 画出动物细胞结构图并标注三部分。
    答：画出细胞膜围成的轮廓，内部标出细胞质、细胞核即可（动物细胞无细胞壁、叶绿体、液泡）。标注：细胞膜（最外层曲线）、细胞质（内部基质）、细胞核（中央圆圈）。
  2. 2. 写出植物细胞比动物细胞多出的三个结构。
    答：细胞壁、叶绿体、液泡。
  3. 3. 将显微镜使用步骤按正确顺序排列：对光、收镜、放置标本、取镜安放、调焦观察。
    答：正确顺序：取镜安放 → 对光 → 放置标本 → 调焦观察 → 收镜。

中等 · 比较与应用

  1. 1. 比较动植物细胞的相同点与不同点（用表格或文字说明）。
    答：相同点：都有细胞膜、细胞质、细胞核、线粒体。不同点：植物细胞还有细胞壁、叶绿体、液泡；动物细胞没有这三样。注意叶绿体只存在于绿色部位，线粒体动植物都有。
  2. 2. 显微镜目镜 5×、物镜 10×，总放大倍数是多少？若换成 40× 物镜，视野中细胞数目和亮度如何变化？
    答：总倍数 = 5 × 10 = 50 倍。换成 40× 物镜后总倍数为 200 倍，放大倍数增大，视野变暗，看到的细胞数目变少，单个细胞看起来更大。
  3. 3. 制作洋葱表皮临时装片时，为什么要在载玻片中央滴一滴清水？染色用什么？
    答：滴清水是为了保持细胞形态、防止细胞失水皱缩，便于观察。染色用稀碘液，可从盖玻片一侧滴加、另一侧用吸水纸吸引，使染液浸润标本。

难 · 实验分析

  1. 1. 观察时视野中出现污点，你怎样判断它在目镜、物镜还是装片上？
    答：先转动目镜，若污点随之转动则在目镜上；再移动装片，若污点随之移动则在装片上；若转动目镜、移动装片污点都不动，则污点在物镜上。
  2. 2. 为什么说线粒体是动植物细胞都有的"能量转换器"？它与叶绿体有何区别？
    答：线粒体是呼吸作用的主要场所，能将有机物中的化学能释放出来供细胞利用，动植物细胞都要呼吸，所以都有线粒体。叶绿体是光合作用的场所，把光能转变成化学能储存在有机物中，只存在于绿色植物细胞。区别：线粒体动植物都有、与呼吸有关；叶绿体仅植物绿色部分有、与光合有关。

综合 · 综合探究

  1. 1. 材料：小明用显微镜观察自己的口腔上皮细胞，看到细胞重叠、看不清结构。请分析可能的原因并写出改进办法。
    答：原因可能有：①刮取细胞后未在生理盐水中涂抹均匀，导致细胞重叠；②盖盖玻片时未让其一侧先接触液滴、缓慢放下，产生气泡；③取材过多。改进：刮取少量细胞在生理盐水滴中均匀涂抹，用镊子夹起盖玻片使其一侧先接触载玻片上的液滴再缓缓放下，避免气泡；染色后吸去多余染液再观察。
  2. 2. 综合说明：为什么"细胞壁"不能控制物质进出，真正控制物质进出的是"细胞膜"？
    答：细胞壁位于细胞最外层，主要起支持、保护作用，是全透性的，水和溶质可自由通过，不能选择性控制物质进出。细胞膜紧贴细胞壁内侧，具有选择透过性，能控制细胞与外界的物质交换（让有用物质进入、废物排出、有害物质阻挡），因此控制物质进出的是细胞膜而非细胞壁。

💬 课后反馈

细胞结构是生物学的基石，学生需在显微镜观察中建立直观印象。常见问题是把装片移动方向弄反、污点判断不清、误以为动物细胞无线粒体。建议用洋葱表皮、口腔上皮细胞做对比观察，强化"动植物细胞都有细胞膜、细胞质、细胞核、线粒体，植物细胞还有细胞壁、叶绿体、液泡"这一异同点，并规范显微镜操作步骤。
