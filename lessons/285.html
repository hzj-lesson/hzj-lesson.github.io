初中九年级物理《磁场》教案

初中九年级物理磁场

📝 备课方案

**教材分析** 本节是北师大九年级物理第十四章第2节，在"磁现象"基础上引入磁场与磁感线：磁场是磁体周围存在的物质，用磁感线描述其方向与强弱；并认识地磁场。把看不见的"场"用模型方法可视化，是物理观念的重要提升。 **教学目标** 1. 知道磁场是真实存在的物质，磁场有方向（小磁针 N 极受力方向）。 2. 会用磁感线描述条形、蹄形磁体周围的磁场（不相交、从 N 出 S 进）。 3. 知道地磁场及磁偏角。 **教学重点** 磁场方向；磁感线的画法与作用。 **教学难点** 磁场的"物质性"与"模型化"（磁感线非真实存在）；地磁场方向。 **课时** 1 课时 **教学过程** 问题导入（不接触怎相互作用）→磁场→方向→磁感线模型→常见磁体磁感线→地磁场→小结。

📖 课堂讲义 · 核心知识点

**一、磁场** - 磁场：磁体周围存在的一种物质，对放入其中的磁体或电流产生力的作用。 - 基本性质：对磁体有力的作用（同名相斥异名相吸的"远距离"靠磁场传递）。 - 真实存在，是物质的一种形态（不是虚构）。 **二、磁场方向** 规定：小磁针在磁场中静止时 N 极所指的方向为该点磁场方向（或 N 极受力方向）。 **三、磁感线（模型）** - 为形象描述磁场而引入的假想曲线，实际并不存在。 - 方向：磁感线上某点切线方向 = 该点磁场方向。 - 分布：在磁体外部，磁感线从 N 极出发回到 S 极；内部从 S 到 N，形成闭合曲线。 - 特点：不相交；疏密表示磁场强弱（越密越强）。 **四、地磁场** 地球周围存在磁场，地磁北极在地理南极附近、地磁南极在地理北极附近；地磁轴与地理轴有夹角（磁偏角）。

🔍 课堂讲义 · 重点难点解析

**难点一：磁感线是"模型"不是"实物"** 学生易把画出的线当成真实存在。强调：磁感线是为方便而画的曲线，磁场本身是真实物质；就像等高线不是真实山丘。 **难点二：方向与闭合** 外部 N→S、内部 S→N，整体闭合。小磁针 N 极指向 = 磁感线切线方向 = 磁场方向，三者一致。 **常见失误** 1. 说"磁感线从 S 到 N"——外部应 N 出 S 进。 2. 认为两条磁感线可相交——若相交则该点有两方向，矛盾。 3. 把磁场说成"虚构"——磁场真实存在，磁感线才是模型。

✏️ 课堂讲义 · 典型例题精讲

**例1（方向）** 小磁针放在条形磁体 N 极附近，N 极指向哪？ 解析：磁体外部磁感线从 N 出，小磁针 N 极沿磁场方向（离开 N 极）；故小磁针 N 极被推离磁体 N 极（相斥侧）。 关键：N 极受力沿磁感线切线向外。 **例2（画磁感线）** 画出蹄形磁体磁感线大致走向。 解析：从 N 极出，经外部空间回到 S 极，在两极间近似直线；外部 N→S。 关键：外部 N 出 S 进，弧形连接。 **例3（地磁）** 地理北极附近实际是地磁什么极？ 解析：地磁南极在地理北极附近（小磁针 N 极被它吸引而指北），故地理北极附近是地磁 S 极。 关键：地磁极与地理极近似相反。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 磁场方向如何规定？磁感线是真实存在的吗？
    答：小磁针 N 极受力/静止时 N 极所指方向为磁场方向；磁感线是为描述磁场引入的假想曲线，并不真实存在。
  2. 2. 磁体外部磁感线方向？
    答：从 N 极出发，回到 S 极（外部 N→S，内部 S→N，闭合）。

中等 · 作图理解

  1. 1. 为什么磁感线不能相交？
    答：若相交，该点磁场将有两个方向，而磁场中任一点方向唯一，故磁感线不相交。
  2. 2. 磁感线疏密表示什么？
    答：表示磁场强弱：越密磁场越强，越疏越弱。

难 · 辨析

  1. 1. 磁场与磁感线，哪个真实存在？
    答：磁场真实存在（是物质）；磁感线是为可视化引入的模型，不存在。混淆二者是常见错。
  2. 2. 地磁场方向为何与地理轴有偏角？
    答：地磁极与地理极不重合，存在磁偏角；指南针所指并非严格正南正北。

综合 · 综合

  1. 1. 两个条形磁体同名极相对放置，中间磁场方向如何？
    答：两 N 极（或两 S 极）间磁感线相互排开，中点附近磁场方向由中间指向两侧（被推离），该区域磁场弱甚至近零（中点可近似抵消）。

💬 课后反馈

磁场是"场"观念的入门，关键是把看不见的相互作用归因为真实存在的场，并用磁感线模型描述。反复强调"磁场真、磁感线假""外部 N→S、不相交、疏密表强弱"，并用小磁针 N 极指向统一三个方向定义。
