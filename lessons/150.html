初中七年级历史《中国古代史：宋元时期》教案

初中七年级历史中国古代史：宋元时期

📝 备课方案

**教学目标** 1. 了解北宋、南宋的建立与辽、西夏、金的并立，掌握澶渊之盟、岳飞抗金等史实。 2. 理解经济重心南移完成的过程与原因，掌握宋代商业繁荣的表现（交子、市舶司）。 3. 了解元朝的统一、行省制度与民族交融。 4. 掌握三大发明（印刷术、火药、指南针）及宋词、元曲等文化成就。 **教学重点**：经济重心南移、行省制度、三大发明。 **教学难 点**：宋辽金夏并立的复杂政治格局及多民族政权的并立交融。 **教学方法**：地图对比、时间轴、经济史分析。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、北宋的建立与统一（960—1127 年）** - 960 年，赵匡胤发动陈桥兵变，建立北宋，定都开封（东京）。 - 宋太祖加强中央集权：杯酒释兵权（解除禁军将领兵权），实行重文轻武政策，文臣担任地方长官，分化事权。 - 北宋与辽、西夏的并立：辽（契丹族，耶律阿保机建立）；西夏（党项族，元昊建立）。 - 澶渊之盟（1005 年）：宋辽议和，辽撤兵，宋给辽岁币。评价：加重了北宋人民负担，但此后宋辽维持了长期和平，利于经济文化交流。 **二、南宋与金的对峙（1127—1279 年）** - 金（女真族，完颜阿骨打建立）先灭辽，1127 年靖康之变，金灭北宋。 - 1127 年赵构在临安（今杭州）建立南宋。 - 岳飞抗金：郾城大捷，岳飞精忠报国，后被以「莫须有」罪名杀害。1141 年宋金订立绍兴和议，南宋向金称臣、纳贡，宋金对峙局面形成。 **三、经济重心南移（完成于南宋）** - 过程：东晋南朝时期江南初步开发 → 唐朝中后期经济重心开始南移 → 南宋时期经济重心南移完成。 - 原因：① 北方战乱频繁，南方相对安定；② 北人南迁带来劳动力和先进技术；③ 南方自然条件优越；④ 统治者重视发展经济；⑤ 对外贸易的推动。 - 表现：农业（苏州、湖州成为重要粮仓，「苏湖熟，天下足」；水稻产量居首位，占城稻推广）；手工业（南宋时江南丝织业发达，景德镇成为瓷都）；商业（城市繁荣，开封、临安人口超百万）。 **四、宋代商业繁荣与交子** - 宋代商业突破坊市界限，出现了夜市、早市和草市。 - 交子：北宋前期，四川地区出现世界上最早的纸币——交子，便利了商业活动，促进了经济发展。 - 海外贸易：宋朝设立市舶司管理海外贸易，广州、泉州、明州是著名大商港。 **五、元朝的统一与制度（1271—1368 年）** - 成吉思汗（铁木真）统一蒙古，1206 年建立蒙古政权；1271 年忽必烈建立元朝，定都大都（今北京）；1279 年元灭南宋，统一全国。 - 行省制度：在中央设中书省，地方设行中书省（行省），行省制度对后世影响深远，我国省级行政区的设立始于元朝。 - 民族交融：元朝境内各民族交融发展，形成新的民族——回族。 - 元朝重视农业，开凿运河、兴修水利；海上丝绸之路达到鼎盛，意大利人马可·波罗来华，著《马可·波罗行纪》。 **六、宋元科技文化** - 三大发明：① 印刷术——北宋毕昇发明活字印刷术，比欧洲早约 400 年；② 火药——唐朝末年开始应用于军事，宋元时期广泛用于战争（火器）；③ 指南针——北宋开始用于航海，传入欧洲后对世界航海产生重大影响。 - 宋词：苏轼（豪放）、李清照（婉约）、辛弃疾（豪放，爱国）。 - 元曲：关汉卿《窦娥冤》是元杂剧的代表作。 - 史学：司马光《资治通鉴》是编年体通史巨著。

🔍 课堂讲义 · 重点难点解析

**重点：经济重心南移完成于南宋** 经济重心南移是宋元时期最重要的经济史命题，线索是「初步开发（东晋南朝）→开始南移（唐中后期）→完成（南宋）」。原因归纳为「安、人、优、策、贸」五字：南方安定、北人南迁、自然优越、政策支持、外贸推动。表现抓「苏湖熟天下足」、占城稻、景德镇瓷都、交子、市舶司。常考材料题：给《宋书》或宋代文献材料，要求分析南移原因或表现。注意「经济重心南移完成于南宋」是判断性考点。 **难点：多民族政权的并立与交融** 宋元时期辽（契丹）、西夏（党项）、金（女真）、蒙古（元）等民族政权与两宋先后并立，关系复杂。学习要点：① 各族建立者——辽耶律阿保机、西夏元昊、金完颜阿骨打、蒙古铁木真；② 重要事件——澶渊之盟（宋辽）、靖康之变（金灭北宋）、绍兴和议（宋金对峙）；③ 辩证评价——战争带来破坏，但各民族在交往中交融（辽仿汉制、金汉化、元形成回族），中华民族共同发展。判断政权属族别要记牢对应关系。 **常见错误** - 交子误答为南宋出现（是北宋四川）； - 行省制度误答为唐朝开始（始于元朝）； - 活字印刷术误答为雕版印刷术的发明者（毕昇活字，唐朝雕版）； - 岳飞抗金的金政权族属答错（女真族）。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：材料题：「苏湖熟，天下足」「国家根本，仰给东南」。请回答：这些材料反映了什么历史现象？结合所学分析其原因。 解析：反映南宋时期经济重心南移完成，长江下游和太湖流域成为重要粮仓，国家财政经济主要依靠东南地区。原因：北方战乱、南方安定；北人南迁带来劳动力和技术；南方自然条件优越；统治者重视；海外贸易发展。 关键：由谚语判断「经济重心南移完成」，再答原因。 **例 2**：简答：纸币「交子」最早出现在何时何地？它的出现说明了什么？ 解析：交子出现在北宋前期的四川地区，是世界上最早的纸币。说明：宋代商业非常繁荣，金属货币（铁钱）携带不便，适应商品流通需要而产生了纸币；交子的出现便利了商品交易，推动了商业和经济发展。 关键：时间（北宋前期）、地点（四川）、背景（商业繁荣）。 **例 3**：材料题：「舟师识地理，夜则观星，昼则观日，阴晦观指南针」。请回答：材料反映的是什么技术？它有何历史意义？ 解析：反映指南针（罗盘）应用于航海。意义：① 北宋时指南针开始应用于航海事业；② 南宋时广泛用于航海，促进宋代海外贸易发展；③ 后来传入欧洲，为新航路开辟（欧洲人远洋航行）提供了重要条件，对世界历史发展产生重大影响。 关键：由「观指南针」判断航海应用，再答国内与世界的双重意义。 **例 4**：简答：元朝实行行省制度有什么历史意义？ 解析：行省制度：中央设中书省，地方设行中书省（行省），行省长官由朝廷任命。意义：① 加强了中央对地方的控制，有利于统一多民族国家的巩固；② 是我国省 级行政区划的开端，对后世影响深远（我国现行省级行政区大致由此发展而来）。 关键：答「中央集权加强」与「省级行政区划之源」两点。 **例 5**：选择题：元朝时形成了一个新的民族，它是（ ） A. 蒙古族 B. 回族 C. 满族 D. 藏族 解析：元朝统一后，各民族杂居交融，波斯人、阿拉伯人等与汉、蒙等族长期杂居通婚，逐渐融合形成回族。选 B。 关键：回族形成于元朝，是民族交融的典型成果。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 政权并立

  1. 1. 填写辽、西夏、金、蒙古的建立者和所属民族
    答：辽：耶律阿保机，契丹族；西夏：元昊，党项族；金：完颜阿骨打，女真族；蒙古：铁木真（成吉思汗），蒙古族。这四族政权与两宋先后并立，形成多民族政权并存的局面。
  2. 2. 简述北宋建立和加强中央集权的措施
    答：960 年赵匡胤陈桥兵变建立北宋。加强中央集权：杯酒释兵权，解除大将兵权；实行重文轻武政策，抑制武将势力；派文臣担任地方长官，加强中央对地方的控制。这些措施巩固了统治，但也造成积贫积弱的局面。
  3. 3. 简述澶渊之盟的内容及影响
    答：内容：1005 年宋辽议和，辽军撤兵，北宋给辽岁币。影响：① 加重了北宋人民的负担；② 此后宋辽之间维持了百余年的和平，双方边境安定，有利于经济文化交流和人民生产生活。

中等 · 经济重心南移

  1. 1. 我国古代经济重心南移大致经历了哪几个阶段？最终在何时完成？
    答：三个阶段：① 东晋南朝时期，江南地区得到初步开发；② 唐朝中后期，经济重心开始南移；③ 南宋时期，经济重心南移完成（「苏湖熟，天下足」「国家根本，仰给东南」）。经济重心由黄河流域转移到长江流域。
  2. 2. 经济重心南移的原因有哪些？
    答：① 北方长期战乱，南方相对安定，为经济发展提供稳定环境；② 大量北方人口南迁，带来充足的劳动力和先进的生产工具、技术；③ 南方自然条件优越，雨量充沛、土地肥沃、水运便利；④ 南方统治者重视发展经济；⑤ 海外贸易兴盛，带动南方沿海经济发展。
  3. 3. 宋代商业繁荣有哪些表现？
    答：① 城市商业突破坊市界限，出现夜市、早市和草市；② 城市人口众多，开封、临安是百万人口的大都市；③ 出现世界上最早的纸币交子，便利了商业活动；④ 海外贸易发达，设市舶司管理，广州、泉州是著名大商港；⑤ 娱乐场所瓦子出现，市民生活丰富。

难 · 制度与科技

  1. 1. 元朝行省制度的主要内容是什么？对后世有什么影响？
    答：内容：在中央设中书省，总理全国政务；地方设行中书省（简称行省），由中央派官员管理，行省长官由朝廷任命，加强对地方的控制。影响：① 加强了中央集权，巩固了统一的多民族国家；② 是我国省级行政区划的开端，今天的省制源于此，影响深远。
  2. 2. 简述活字印刷术、指南针、火药在宋元时期的发展及世界影响
    答：① 活字印刷术：北宋毕昇发明，比欧洲早约 400 年，经丝绸之路传入欧洲，推动了文化传播和教育普及；② 指南针：北宋用于航海，后传入欧洲，为新航路开辟提供了技术条件，促进了世界远洋航行；③ 火药：唐末用于军事，宋元时期火器广泛应用，后传入欧洲，帮助欧洲资产阶级战胜封建骑士阶层，推动世界历史进程。三大发明是中国对世界文明的重大贡献。
  3. 3. 比较北宋的「重文轻武」与唐朝「重用武将」对王朝统治的不同影响
    答：唐朝前期重用武将、藩镇权力过大，导致安史之乱和藩镇割据，削弱中央集权、加速唐朝衰亡；北宋吸取教训，实行重文轻武，解除武将兵权、文臣掌兵，避免了武将专权，巩固了中央集权、保持了社会稳定。但北宋矫枉过正，造成军事实力薄弱、边防积弱，在与辽、金对峙中处于被动，最终被金所灭。说明治国策略要文武平衡、因地制宜。

综合 · 综合探究

  1. 1. 绘制宋元时期政权并立与统一的时间轴
    答：916 年辽建立（契丹）→ 960 年北宋建立 → 1038 年西夏建立（党项）→ 1005 年澶渊之盟 → 1115 年金建立（女真）→ 1125 年金灭辽 → 1127 年靖康之变金灭北宋、南宋建立 → 1141 年绍兴和议宋金对峙 → 1206 年蒙古政权建立 → 1271 年忽必烈建元 → 1279 年元灭南宋统一全国 → 1368 年元亡明立。
  2. 2. 从政治、经济、民族关系三方面说明宋元时期「中国由分裂走向统一」的历程
    答：政治：北宋结束五代十国分裂，但未实现全国统一，与辽、西夏、金等并立；1279 年元灭南宋，实现全国统一，结束长期分裂割据。经济：宋代经济重心南移完成，元朝统一为南北经济文化交流创造了统一的市场和交通条件。民族关系：辽、宋、夏、金时期各民族政权在战争与和议中交往，元朝统一后民族杂居交融，形成回族等新民族，中华民族的凝聚力进一步增强。宋元时期的统一是经济、民族、制度多方面因素共同推动的结果。
  3. 3. 综合：三大发明对欧洲社会转型产生了哪些影响？结合所学知识回答
    答：① 印刷术传入欧洲后，使书籍大量印制，促进了文化传播、思想解放和文艺复兴运动的兴起；② 火药传入欧洲后，火器帮助新兴资产阶级战胜封建骑士，加速了封建制度的瓦解，推动了资产阶级革命和殖民扩张；③ 指南针传入欧洲后，为远洋航行提供技术保证，直接促成了新航路的开辟和地理大发现，使世界开始连成一个整体。三大发明的西传，对欧洲从封建社会向资本主义社会转型产生了深远影响，是中国对世界文明的伟大贡献。

💬 课后反馈

宋元时期的教学要抓住「政权并立、经济南移、行省制度、三大发明」四大板块。学生易在辽夏金蒙的民族归属、交子出现时间、活字印刷术发明者等细节上出错。建议用时间轴和地图理清政权更替，用「安、人、优、策、贸」概括经济南移原因，结合丝绸之路强调三大发明对世界的贡献，通过岳飞、文天祥等人物落实家国情怀教育。
