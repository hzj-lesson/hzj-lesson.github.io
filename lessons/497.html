高中高二生物《染色体变异与人类遗传病》教案

高中高二生物染色体变异与人类遗传病

📝 备课方案

**教学目标** 1. 掌握染色体结构变异和数目变异的类型，理解染色体组、二倍体、多倍体和单倍体的概念。 2. 掌握人类遗传病的主要类型、病因及遗传特点。 3. 学会遗传系谱图的分析方法，理解遗传病的检测与预防。 **教学重点**：染色体组的概念；多倍体与单倍体的区别；常见遗传病的类型与遗传方式判断。 **教学难点**：染色体组数目的判断；遗传系谱图中遗传方式的判断与概率计算。 **教学方法**：模型建构、系谱图分析训练、列表比较。 **课时安排**：4 课时

📖 课堂讲义 · 核心知识点

**一、染色体结构变异** - 类型：缺失（染色体片段缺失）、重复（片段增加）、倒位（片段颠倒）、易位（非同源染色体间片段移接）。 - 结果：染色体上的基因数目或排列顺序发生改变，导致性状变异，多数对生物有害。 - 注意：易位发生在非同源染色体之间，而交叉互换发生在同源染色体的非姐妹染色单体之间，二者本质不同。 **二、染色体数目变异** - 个别染色体增减：如 21 三体综合征（多一条 21 号染色体）、性腺发育不良（Turner 综合征，少一条 X 染色体）。 - 以染色体组的形式成倍增减：如多倍体、单倍体。 **三、染色体组** - 概念：细胞中的一组非同源染色体，在形态和功能上各不相同，却共同控制着生物的生长、发育、遗传和变异。 - 判断方法：同一形态的染色体出现几次，就有几个染色体组；或看基因型中同一种基因（不区分大小写位置）出现几次。 - 例：AaBb 含 2 个染色体组；AAaBBB 含 3 个染色体组。 **四、二倍体、多倍体和单倍体** - 二倍体：由受精卵发育而来，体细胞含 2 个染色体组（绝大多数动物、一半以上植物）。 - 多倍体：由受精卵发育而来，体细胞含 3 个或以上染色体组（如香蕉 3 倍体、马铃薯 4 倍体、小麦 6 倍体）。 - 单倍体：由配子直接发育而来，体细胞含本物种配子染色体数目的个体，不一定只含 1 个染色体组（如六倍体小麦的单倍体含 3 个染色体组）。 - 判断关键：看发育起点是受精卵还是配子。 **五、多倍体与单倍体育种** - 多倍体育种：用秋水仙素（抑制纺锤体形成，使染色体数目加倍）处理萌发的种子或幼苗，如无子西瓜（三倍体）。 - 单倍体育种：花药离体培养获得单倍体植株，再用秋水仙素使染色体数目加倍，优点是明显缩短育种年限，后代都是纯合子。 **六、人类遗传病** - 单基因遗传病：由一对等位基因控制，如白化病（常染色体隐性）、多指（常染色体显性）、红绿色盲（伴 X 隐性）、抗维生素 D 佝偻病（伴 X 显性）。 - 多基因遗传病：由多对基因控制，易受环境影响，如青少年型糖尿病、冠心病、哮喘。 - 染色体异常遗传病：如 21 三体综合征（常染色体数目异常）、猫叫综合征（5 号染色体缺失）。 **七、遗传病检测与预防** - 手段：遗传咨询、产前诊断（羊水检查、B 超检查、基因诊断）、适龄生育、禁止近亲结婚。 - 基因治疗：把正常基因导入有基因缺陷的细胞中，纠正或补偿缺陷基因的功能。

🔍 课堂讲义 · 重点难点解析

**重点：染色体组的概念与判断**。染色体组的关键是"一组非同源染色体"，一个染色体组内不存在同源染色体，且含有控制该物种生长发育的全部遗传信息。判断染色体组数可用两种方法：一是看形态——细胞内形态相同的染色体有几条就有几个染色体组；二是看基因型——控制同一性状的基因（如 A/a）出现几次就有几个染色体组。例如基因型 AAaBbb 中 A 出现 3 次、B 出现 2 次（注意 B 只出现一次吗？应看同一字母，AaBbb 中 A 有 2 个、a 有 1 个，共 3 个 A 位点，B 有 1 个、b 有 2 个，共 3 个 B 位点），故含 3 个染色体组。 **难点：遗传系谱图的判断**。判断顺序：先判断显隐性（无中生有为隐性，有中生无为显性），再判断是常染色体还是 X 染色体遗传（伴 X 隐性遗传有明显"交叉遗传"特点且男性患者多于女性；伴 X 显性遗传女性患者多于男性）。确定遗传方式后，根据亲代表现型写出基因型，再计算子代患病概率，注意区分"患病男孩"与"男孩患病"（前者需乘 $\\frac{1}{2}$）。 **易错提醒**：单倍体不一定只含一个染色体组，判断依据是发育起点是否为配子；多倍体不一定只由受精卵发育而来，也可能由配子发育后加倍；秋水仙素作用于细胞分裂前期，抑制纺锤体形成，但不影响染色体复制和着丝点分裂，故染色体数目加倍而细胞不分裂。

✏️ 课堂讲义 · 典型例题精讲

**例1**：已知某细胞基因型为 AAaBbb，判断该细胞含有几个染色体组。 解：看同一字母基因出现的次数，A 或 a 共出现 3 次，B 或 b 共出现 3 次，故该细胞含 3 个染色体组，属于三倍体（若由受精卵发育而来）。 **例2**：六倍体小麦体细胞含 42 条染色体。其单倍体体细胞含多少条染色体？含有几个染色体组？ 解：单倍体由配子发育而来，染色体数为配子染色体数，即 42÷2＝21 条。六倍体小麦配子含 3 个染色体组，故其单倍体含 3 个染色体组、21 条染色体。 **例3**：人类红绿色盲是伴 X 隐性遗传病。一对表型正常的夫妇生了一个患色盲的儿子，这对夫妇的基因型分别是什么？若再生一个女儿患色盲的概率 是多少？ 解：儿子患病（XᵇY），Xᵇ 来自母亲，母亲表型正常，故母亲基因型为 XᴮXᵇ，父亲正常为 XᴮY。女儿从父亲得到 Xᴮ，必不患病（XᴮXᵇ 或 XᴮXᴮ），故再生女儿患色盲概率为 0。 **例4**：某遗传病系谱图显示"父母均正常，儿子患病"，该病的遗传方式最可能是什么？简述判断依据。 解：最可能是常染色体隐性遗传。"无中生有"（双亲正常生出患病孩子）判断为隐性遗传；若为伴 X 隐性遗传，则患病儿子的致病基因来自母亲，母亲应为携带者，系谱中无法排除，但常染色体隐性遗传更常见且判断最简单。若系谱中男性患者明显多于女性且呈交叉遗传，则优先考虑伴 X 隐性遗传。 **例5**：无子西瓜是如何培育出来的？为什么西瓜无子？ 解：用秋水仙素处理二倍体西瓜幼苗，获得四倍体西瓜；再让四倍体作母本与二倍体杂交，获得三倍体种子；三倍体植株在减数分裂时同源染色体联会紊乱，不能形成正常配子，故不能受精结实，形成无子西瓜。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念辨析

  1. 1. 判断：单倍体一定含有一个染色体组。
    答：错误。单倍体是由配子直接发育而来的个体，含有的染色体组数等于该物种配子中的染色体组数。例如六倍体小麦的单倍体含 3 个染色体组，二倍体的单倍体才含 1 个染色体组。判断单倍体的关键是发育起点，而不是染色体组数目。
  2. 2. 染色体结构变异有哪四种类型？易位与交叉互换有何本质区别？
    答：四种类型：缺失、重复、倒位、易位。区别：易位发生在非同源染色体之间，属于染色体结构变异，会导致基因排列顺序改变；交叉互换发生在同源染色体的非姐妹染色单体之间，属于基因重组，只交换等位基因对应的片段，基因总数不变。

中等 · 遗传方式判断

  1. 1. 人类白化病是常染色体隐性遗传病。一对表现正常的夫妇生了一个白化病患儿，这对夫妇的基因型是什么？他们再生一个孩子患白化病的概率是多少？
    答：白化病为常染色体隐性遗传（a），患儿为 aa，其 a 基因分别来自父母，父母表现正常，故父母基因型均为 Aa。再生孩子患白化病（aa）的概率为 $\\frac{1}{4}$。
  2. 2. 抗维生素 D 佝偻病是伴 X 染色体显性遗传病。患病男性与正常女性婚配，其子女患病情况如何？
    答：患病男性基因型为 XᴰY，正常女性为 XᵈXᵈ。儿子从父亲获得 Y、从母亲获得 Xᵈ，基因型 XᵈY，全部正常；女儿从父亲获得 Xᴰ、从母亲获得 Xᵈ，基因型 XᴰXᵈ，全部患病。这体现了伴 X 显性遗传"交叉遗传"的特点。
  3. 3. 三倍体西瓜为什么没有种子？能否用三倍体西瓜的种子繁殖后代？
    答：三倍体西瓜（3n=33）在减数分裂时同源染色体联会紊乱，不能产生正常的配子，因而不能受精形成种子，所以无子。三倍体无子西瓜不产生种子，只能用二倍体与四倍体杂交每年制种，不能靠其种子繁殖。

难 · 系谱图分析

  1. 1. 某遗传病系谱：父亲患病、母亲正常，女儿全部患病、儿子全部正常。判断该遗传病的遗传方式，并写出双亲基因型（相关基因用 D/d 表示）。
    答：该病为伴 X 染色体显性遗传。父亲患病为 XᴰY，母亲正常为 XᵈXᵈ。女儿从父亲获得 Xᴰ 均患病（XᴰXᵈ），儿子从父亲获得 Y、从母亲获得 Xᵈ 均正常（XᵈY），符合"父患病、女儿全患病"的伴 X 显性遗传特点。
  2. 2. 一对表型正常的夫妇生了一个既患白化病（常染色体隐性，a）又患红绿色盲（伴 X 隐性，b）的儿子。求该夫妇的基因型，以及他们再生一个两病都不患的儿子的概率。
    答：儿子患白化病为 aa，患色盲为 XᵇY。夫妇表型正常，故父亲基因型 AaXᴮY，母亲基因型 AaXᴮXᵇ。两病都不患且为儿子的概率：白化病正常（AA 或 Aa）概率为 $\\frac{3}{4}$，色盲正常且为儿子：母亲产生 Xᴮ（正常）与 Xᵇ（致病）卵概率各 $\\frac{1}{2}$，父亲提供 Y，儿子正常（XᴮY）概率为 $\\frac{1}{2}$，且儿子性别已确定为 $\\frac{1}{2}$（XᴮY 或 XᵇY 均为男性），故色觉正常的儿子概率为 $\\frac{1}{2}$。两病不患儿子概率＝$\\frac{3}{4}$×$\\frac{1}{2}$＝$\\frac{3}{8}$。

综合 · 综合应用

  1. 1. 秋水仙素为什么能使染色体数目加倍？它在细胞分裂的哪个时期起作用？若秋水仙素处理的是处于间期的细胞，能否使染色体数目加倍？
    答：秋水仙素能抑制纺锤体的形成，导致分裂后期染色体（着丝点分裂后）不能移向细胞两极，细胞不能正常分裂，从而形成染色体数目加倍的细胞。它在分裂前期发挥作用（抑制纺锤体形成）。若处理的是间期细胞，该细胞仍会进行 DNA 复制和着丝点分裂，但由于无纺锤体，染色体不能分配，染色体数目也能加倍，只是需等其进入分裂期发挥作用，故常用秋水仙素处理萌发的种子或幼苗。
  2. 2. 简述单倍体育种的流程，并说明其优点。与杂交育种相比，单倍体育种为什么能明显缩短育种年限？
    答：流程：杂交获得 F₁ → 取 F₁ 花药（花粉）离体培养 → 获得单倍体幼苗 → 用秋水仙素处理使染色体数目加倍 → 得到纯合二倍体植株，从中选出优良品种。优点：能明显缩短育种年限。原因：杂交育种需连续自交、多代筛选才能得到纯合子；单倍体育种经花药离体培养和加倍后，所得植株全部为纯合子，性状稳定，一年内即可获得纯合优良品种。

💬 课后反馈

学生对染色体组数目的判断方法掌握较好，但单倍体与多倍体的判断（发育起点）仍有混淆。系谱图中"患病男孩"与"男孩患病"概率计算易出错，伴 X 遗传的特点理解不深。建议增加不同遗传方式的系谱图对比训练，并强调"先判显隐、再判位置、最后算概率"的解题程序。
