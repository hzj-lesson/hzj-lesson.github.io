小学六年级数学《负数的初步认识》教案

小学六年级数学负数的初步认识

📝 备课方案

**教学目标** 1. 在生活情境中了解负数的意义，能正确读、写正数和负数。 2. 理解 0 既不是正数也不是负数，知道 0 是正数和负数的分界点。 3. 能用正数和负数表示生活中具有相反意义的量（温度、收支、海拔、方向等）。 4. 会在数轴上表示正数、负数和 0，并能比较它们的大小。 **教学重点**：负数的意义与读写方法，用正负数表示相反意义的量。 **教学难点**：理解 0 的特殊地位；负数的大小比较（负号后面数字越大，这个负数反而越小）。 **教学方法**：情境导入（天气预报、家庭账本）、数轴演示、对比归纳、操作活动。 **教学准备**：温度计模型、数轴卡片、城市天气预报图。 **课时安排**：2 课时（第 1 课时：负数的意义与读写；第 2 课时：数轴与大小比较）

📖 课堂讲义 · 核心知识点

**一、为什么要学负数** 生活中存在大量"意义相反"的量：零上温度与零下温度、收入与支出、上升与下降、向东与向西。只用学过的数无法区分它们，于是引入了**负数**。 **二、正数与负数的认识** - **正数**：像 $+3$、$+15$、$+\\frac{1}{2}$、$+8844.43$ 这样的数叫正数，正号"+"可以省略不写（如 3、15） - **负数**：像 $-3$、$-10$、$-155$、$-\\frac{1}{2}$ 这样的数叫负数，负号"−"**不能省略** - **读法**：$+3$ 读作"正三"，$-3$ 读作"负三"，$-10℃$ 读作"零下十摄氏度"或"负十摄氏度" **三、0 的特殊性（重要）** 0 **既不是正数，也不是负数**。它是正数和负数的**分界点**，也是表示"没有"和"基准"的数。 - 例：$0℃$ 不是没有温度，而是淡水开始结冰的温度，是零上与零下的分界 **四、用正负数表示相反意义的量** 先规定哪一个量为正，那么与它**意义相反**的量就记作负。 - 若规定收入为正，则支出 200 元记作 $-200$ 元 - 若规定向东为正，则向西走 50 米记作 $-50$ 米 - 若规定海平面以上为正，则死海湖面低于海平面 400 米记作 $-400$ 米 **五、数轴与大小比较** - 数轴：画一条水平直线，规定原点（0）、正方向（向右）和单位长度 - 规律：**数轴上左边的数总小于右边的数** - 大小关系：负数 < 0 < 正数 - 两个负数比较：**负号后面的数越大，这个负数反而越小** - 例：$-10 < -3$（因为 10 > 3）；$-100 < -1$ **六、常见生活情境** | 情境 | 正数表示 | 负数表示 | |---|---|---| | 气温 | 零上 $8℃$ → $+8℃$ | 零下 $5℃$ → $-5℃$ | | 海拔 | 高于海平面 8844 米 | 低于海平面 155 米 → $-155$ 米 | | 账目 | 收入 500 元 → $+500$ 元 | 支出 300 元 → $-300$ 元 | | 楼层 | 地上 3 层 → $+3$ 层 | 地下 2 层 → $-2$ 层 |

🔍 课堂讲义 · 重点难点解析

**重点一：用正负数表示相反意义的量（两步法）** 第一步：先**规定**哪个方向的量为正（通常规定"上升、收入、向东、零上"为正）； 第二步：与它相反的量就记为负。 - 例题：如果向北走 30 米记作 $+30$ 米，那么向南走 45 米记作什么？ 分析：北为正 → 南为负，答案：$-45$ 米。 **重点二：借助数轴比较大小** 画数轴是理解负数大小最直观的方法： - 在数轴上，越往**右**的数越**大**，越往**左**的数越**小** - 正数都在 0 的右边，负数都在 0 的左边 - 例：把 $-5$、$0$、$3$、$-1$ 按从小到大排列：$-5 < -1 < 0 < 3$ **难点一：0 既不是正数也不是负数** 学生容易把 0 当成"最小的正数"或"最小的数"。要强调： - 0 是正数与负数的**分界线**，它不属于任何一边 - 0 也不是最小的数，因为还有负数（$-1 < 0$） **难点二：负数的大小比较（最易错）** 错误想法："看到 $-10$ 和 $-3$，10 比 3 大，所以 $-10 > -3$"（×） 正确理解： - **用温度计类比**：$-10℃$ 比 $-3℃$ 更冷，温度更低，所以 $-10 < -3$ - **用数轴验证**：$-10$ 在 $-3$ 的左边，左边的数小，所以 $-10 < -3$ - **口诀**：两个负数比大小，**负号后面的数越大，这个负数反而越小** **常见误区** - 把 0 当成正数或负数 - 认为负数都比 0 大（实际负数 < 0） - 两个负数比较时搞反方向 - 写负数时漏掉负号（如把 $-5$ 写成 5）

✏️ 课堂讲义 · 典型例题精讲

**例1（读写）**：读出下面各数，并指出哪些是正数，哪些是负数。 $-8$、 $+15$、 $0$、 $-2.5$、 $100$、 $-\\frac{3}{4}$ **解**：$-8$ 读作负八（负数）；$+15$ 读作正十五（正数）；$0$ 读作零（既不是正数也不是负数）；$-2.5$ 读作负二点五（负数）；$100$ 读作一百（正数）；$-\\frac{3}{4}$ 读作负四分之三（负数）。 **关键**：0 单独分类，不属于正数也不属于负数。 **例2（表示相反意义的量）**：如果规定"上升为正"，那么"下降 12 米"记作什么？"上升 8 米"记作什么？"原地不动"记作什么？ **解**：下降 12 米记作 $-12$ 米；上升 8 米记作 $+8$ 米（或 8 米）；原地不动记作 0 米。 **关键**：先确定正方向，相反方向取负，不动为 0。 **例3（大小比较）**：比较下列各组数的大小。 ① $-3$ 与 $1$ 　② $-7$ 与 $-2$ 　③ $0$ 与 $-5$ 　④ $-\\frac{1}{2}$ 与 $-\\frac{1}{4}$ **解**：① $-3 < 1$（负数小于正数）；② $-7 < -2$（负号后 7>2，所以 $-7$ 更小）；③ $0 > -5$（0 大于一切负数）；④ $-\\frac{1}{2} < -\\frac{1}{4}$（$\\frac{1}{2} > \\frac{1}{4}$，加负号后反而小）。 **关键**：两个负数比较，绝对值大的反而小。 **例4（实际应用）**：小明家这个月收入 3000 元，支出如下：水电费 180 元、伙食费 1200 元、买书 95 元。规定收入为正，支出为负，请用正负数表示，并计算结余。 **解**：收入 $+3000$ 元；支出分别为 $-180$ 元、$-1200$ 元、$-95$ 元。 结余 $= 3000 - 180 - 1200 - 95 = 1525$ 元。 **关键**：正负数相加时，正数表示增加，负数表示减少。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 认识与读写

  1. 1. 读出下面各数：-5、+12、-3.6、0、-100。
    答：-5 读作负五；+12 读作正十二；-3.6 读作负三点六；0 读作零；-100 读作负一百。
  2. 2. 0 是正数吗？是负数吗？它在正负数的关系中起什么作用？
    答：0 既不是正数，也不是负数。它是正数和负数的分界点，也是表示"基准"和"没有"的数。
  3. 3. 写出 3 个正数、3 个负数和 0，并把它们按从大到小的顺序排列。
    答：示例：正数 5、3、1；负数 -1、-3、-5；0。从大到小：5 > 3 > 1 > 0 > -1 > -3 > -5。

中等 · 相反意义的量

  1. 1. 如果向东走 60 米记作 +60 米，那么向西走 40 米记作什么？
    答：记作 -40 米。东为正，西就为负。
  2. 2. 某仓库运进货物 200 箱记作 +200 箱，那么运出 150 箱记作什么？
    答：记作 -150 箱。运进为正，运出为负。
  3. 3. 把下面的温度按从低到高排列：-12℃、0℃、5℃、-3℃、18℃。
    答：-12℃ < -3℃ < 0℃ < 5℃ < 18℃。
  4. 4. 某商店第一季度盈利 5000 元记作 +5000 元，第二季度亏损 1200 元，应记作多少？两个季度合起来是盈利还是亏损？
    答：亏损 1200 元记作 -1200 元。合计 5000-1200=3800 元，为盈利 3800 元。

难 · 数轴与比较

  1. 1. 在数轴上标出 -4、-1、0、3、5 的位置，并按从小到大的顺序排列。
    答：从左到右依次是 -4、-1、0、3、5；从小到大：-4 < -1 < 0 < 3 < 5。
  2. 2. 比较大小（填 > 或 <）：①-9 ___ -3　②-15 ___ -20　③-0.5 ___ 0　④-1 ___ 1
    答：① -9 < -3；② -15 > -20（负号后 15<20，所以 -15 更大）；③ -0.5 < 0；④ -1 < 1。
  3. 3. 大于 -3 且小于 4 的整数有哪些？把它们写出来。
    答：-2、-1、0、1、2、3（注意：-3 和 4 本身不包括在内）。

综合 · 综合应用

  1. 1. 某登山队从海拔 0 米处出发，先上升 1200 米，再下降 350 米，最后又上升 80 米。用正负数表示每次变化，并求最终海拔。
    答：三次变化：+1200 米、-350 米、+80 米。最终海拔 = 1200-350+80 = 930 米。
  2. 2. 潜水艇在海平面下 200 米处，先下潜 80 米，再上浮 150 米，此时潜水艇在什么位置？（规定海平面以上为正）
    答：初始 -200 米，下潜 80 米记作 -80 米，上浮 150 米记作 +150 米。位置 = -200-80+150 = -130 米，即在海平面下 130 米处。
  3. 3. 记录自己家一周的水电费、买菜钱（支出）和零花钱收入，用正负数记录，算出这一周的结余。
    答：提示：先规定收入为正、支出为负，逐项记录后求和。若结果为正表示结余，为负表示超支（答案依实际情况而定）。

💬 课后反馈

负数是学生第一次接触"比 0 小的数"，认知上是一次飞跃。常见问题：一是把 0 归入正数或负数；二是两个负数比较大小时方向搞反（认为 -10 > -3）；三是表示相反意义的量时忘记先"规定正方向"。建议：多用温度计、海拔、账本这三样生活原型帮助学生建立直观；负数大小比较一定要借助数轴，让学生"看到"位置再判断；"负号后面的数越大，这个负数反而越小"这句口诀要反复强化，配合温度高低的生活感受来记忆。
