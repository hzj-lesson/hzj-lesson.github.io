小学五年级语文《古诗：己亥杂诗》教案

小学五年级语文古诗：己亥杂诗

📝 备课方案

**教学目标** 1. 认识诗人龚自珍，了解"己亥杂诗"这一组诗的背景；会认会写本课生字，能正确、流利、有感情地朗读并背诵、默写全诗。 2. 借助注释理解诗句意思，能用自己的话说出诗中的画面和含义。 3. 体会"落红不是无情物，化作春泥更护花"的深刻含义，感受诗人辞官后仍心系国家的爱国情怀。 4. 学习借物抒怀的写法，激发热爱祖国、奉献社会的感情。 **教学重点**：理解诗意，背诵默写，体会比喻（落红—春泥）的深层含义。 **教学难点**：理解"落红不是无情物，化作春泥更护花"的含义；体会诗人复杂的情感（离愁与报国之志）。 **教学方法**：资料补充、诵读感悟、品词析句、联系实际、拓展阅读。 **教学准备**：课件（诗人画像、创作背景资料、落花护花图片）、配乐朗读音频。 **课时安排**：2 课时（第 1 课时：了解背景、读通诗意；第 2 课时：品析名句、背诵默写）

📖 课堂讲义 · 核心知识点

**一、诗人与创作背景** 龚自珍（1792—1841），字璱人，号定盦，清代思想家、文学家。他主张改革，反对闭关锁国，是近代中国思想解放的先驱。 《己亥杂诗》是龚自珍在己亥年（1839 年，道光十九年）辞官南归途中写下的一组大型组诗，共 315 首。本课所选是其中第五首，写于他离开京城、回归故乡的路上。诗人虽然辞官，却仍然关心国家命运，表达了自己即使离开官场也要为国效力的决心。 **二、原文与朗读节奏** 浩荡/离愁/白日斜， 吟鞭/东指/即天涯。 落红/不是/无情物， 化作/春泥/更护花。 **三、字词释义** | 词语 | 释义 | |---|---| | 浩荡 | 形容水势广大，这里形容离愁的深广无边 | | 离愁 | 离别的愁绪 | | 白日斜 | 太阳西斜（黄昏时分） | | 吟鞭 | 诗人的马鞭（"吟"指诗人吟诗） | | 东指 | 向东指去（诗人出京向东而行） | | 天涯 | 天边，指遥远的地方 | | 落红 | 落花（"红"借代花） | | 化作 | 变成 | | 春泥 | 春天的泥土 | **四、诗句翻译与画面还原** - **浩荡离愁白日斜**：离别的愁绪像江水一样浩荡无边，此刻夕阳西斜，天色将晚。 - **吟鞭东指即天涯**：我扬鞭催马向东行去，从此便远离京城，仿佛到了天边。 - **落红不是无情物**：纷纷飘落的红花并不是无情之物。 - **化作春泥更护花**：它化作春天的泥土，还要培育呵护新的花朵。 - 画面想象：黄昏时分，诗人辞别京城，策马东行，望着满地落花，心中翻涌着离愁；但他转念一想，落花化作春泥能滋养来年新花，自己离开官场，也依然可以为国家做贡献。 **五、写作手法与赏析** 1. **借景抒情**：前两句借"白日斜""天涯"等景物，渲染离别的愁绪和前途的苍茫。 2. **借物抒怀（托物言志）**：后两句借"落红化作春泥护花"，比喻自己虽辞官离京，但仍心系国家、甘愿奉献。落红是"花"，也是诗人自己；春泥护花，是诗人报国之志的形象表达。 3. **"落红""春泥"的象征意义**：落红象征辞官离京的自己，春泥护花象征他愿意用余力继续为国家培养人才、贡献力量。 **六、主题思想** 全诗表达了诗人离京时的愁绪，更表达了辞官后仍想为国效力、奉献自己的高尚情怀，展现了诗人宽广的胸怀和深沉的爱国情感。

🔍 课堂讲义 · 重点难点解析

**重点一：理解"落红"的比喻** - 例题："落红不是无情物"中的"落红"指什么？诗人为什么说它"不是无情物"？ 分析："落红"指落花。花虽然落了，但化成春泥后能滋养新花，所以不是无情之物。 解答："落红"指落花。因为它落到地上化为春泥，还能培育新的花朵，所以不是无情之物。 小结：读诗时要抓住事物的象征意义，"落红"既是实写落花，又暗指诗人自己。 **重点二：理解"化作春泥更护花"的含义** - 例题：诗人借"落红化作春泥护花"想表达什么？ 分析：落花→春泥→护花，是一个奉献与再生的过程；诗人借它表达自己辞官后仍愿为国效力的决心。 解答：表达诗人虽然辞官离京，但仍心系国家、甘愿奉献自己、为国家培养人才的高尚情怀。 小结："托物言志"的诗句，要联系诗人经历来理解它表达的志向。 **难点一：体会诗人复杂的情感** - 例题：这首诗表达了诗人哪些情感？是悲伤的还是昂扬的？ 分析：前两句有离愁（浩荡离愁、白日斜、天涯），后两句却昂扬向上（化作春泥更护花）。离愁是真实的，但诗人用奉献之志超越了离愁。 解答：既有辞官离京的淡淡愁绪，更有辞官后仍愿为国奉献的昂扬情怀。整首诗由愁转豪，积极向上。 小结：分析诗歌情感要看全诗，注意情感的变化和转折。 **难点二："吟鞭东指即天涯"的"即"字** - 例题："即"字可以换成"到"字吗？为什么？ 分析："即"是"就、便是"的意思，带有"一转眼就到了"的意味，写出离开京城的决绝和道路的遥远；"到"字太平淡。 解答：不能换。"即"字生动地写出诗人离京远去、一下子就到天边似的感受，语气果断，突出了离别的苍茫。 小结：品字词要比较替换，体会原字在情味上的独到之处。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（理解诗意）** 用自己的话说说"浩荡离愁白日斜，吟鞭东指即天涯"的意思。 - 分析：抓住"浩荡离愁""白日斜""东指""天涯"等关键词。 - 参考答案：黄昏时分，夕阳西斜，我满怀如江水般浩荡的离愁，挥动马鞭策马东行，从此远离京城，仿佛到了天边。 - 方法小结：翻译诗句要先解词再连句，注意语序和画面感。 **例题 2（名句赏析）** 请赏析"落红不是无情物，化作春泥更护花"。 - 分析：从"比喻什么、表达什么感情"两方面入手。 - 参考答案：诗人以落花自比，说落花落入泥土化作春泥，还要滋养新的花朵。诗句借物抒怀，表达了诗人辞官后仍心系国家、甘愿奉献的高尚情怀，语言形象，含义深刻。 - 方法小结：赏析名句按"手法＋内容＋情感"三步作答。 **例题 3（联系实际）** "落红不是无情物，化作春泥更护花"常被用来赞美什么人？结合生活说说你的理解。 - 分析：落红奉献自己滋养新花，就像甘愿付出、培育后人的人。 - 参考答案：常用来赞美默默奉献、甘为人梯的人，比如退休后仍关心学生成长的老师、培养新人的前辈。他们奉献自己，成就了后来者，就像落红化作春泥护花一样。 - 方法小结：联系生活理解名句，先说出诗句本义，再说它的引申义和适用场景。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 默写与释义

  1. 1. 默写《己亥杂诗》。
    答：浩荡离愁白日斜，吟鞭东指即天涯。落红不是无情物，化作春泥更护花。（注意"吟鞭""涯""落红"的写法）
  2. 2. 解释加点词：落红不是无情物（落红）；化作春泥更护花（化作）。
    答：落红：落花；化作：变成。
  3. 3. "己亥"指的是（ ）年，"己亥杂诗"共有（ ）首。
    答：己亥（1839）年；315 首。

中等 · 理解诗句

  1. 1. 前两句写了哪些景物？渲染了怎样的氛围？
    答：写了夕阳西斜、策马东行的景象，渲染了离别的苍茫与愁绪。
  2. 2. "落红不是无情物"中"落红"指的是什么？
    答：落花。这里借指辞官离京的诗人自己。
  3. 3. 判断：这首诗只表达了诗人辞官后的愁绪。（ ）
    答：错误。诗中既有离愁，更有辞官后仍愿为国奉献的昂扬情怀。

难 · 名句赏析

  1. 1. 赏析"落红不是无情物，化作春泥更护花"。
    答：诗人以落花自比，落花化作春泥仍滋养新花。运用托物言志（借物抒怀）的手法，形象地表达了辞官后仍心系国家、甘愿奉献的高尚情怀，含义深刻。
  2. 2. "吟鞭东指即天涯"中的"即"字能否换成"到"？为什么？
    答：不能。"即"有"便是、转眼就到"的意味，写出离京远去、天地苍茫之感，比平淡的"到"更有气势和情味。
  3. 3. 诗人为什么要写"白日斜"？这个景物描写有什么作用？
    答："白日斜"点明时间已是黄昏，渲染了离别的苍茫愁绪，也为后两句由愁转豪、借落花言志做了情感铺垫。

综合 · 拓展运用

  1. 1. "落红不是无情物，化作春泥更护花"可以比喻生活中的哪些人？举例说明。
    答：示例：可以比喻退休后继续辅导青年教师的老师、默默资助贫困学生的爱心人士、甘当配角的幕后工作者。他们奉献自己、成就他人，正像落红护花。
  2. 2. 龚自珍还写过"我劝天公重抖擞，不拘一格降人才"，这两句表达了诗人怎样的愿望？
    答：表达了诗人希望破格选拔人才、改革国家、振兴中华的强烈愿望，体现了他忧国忧民的思想。
  3. 3. 请你用一两句话，写一句类似的"借物言志"的话（可以仿照"落红—春泥"的句式）。
    答：示例：蜡烛不是无情物，燃尽自己照亮人；落叶不是无情物，化作肥料育新苗。想象合理、句式相近即可。

💬 课后反馈

**学生常见错误** 1. 把"落红"理解成"红色的东西"，不理解"红"借代花。 2. 只读出"离愁"，忽略了后两句的昂扬向上，把握不准全诗情感。 3. 默写时"吟鞭"写错（如写成"银鞭"），"涯"与"崖"混淆。 4. 赏析名句时只写"用得好"，说不出手法（托物言志）和具体含义。 **教学改进建议** 1. 先补充龚自珍辞官的时代背景，帮助学生理解"为什么辞官了还要为国效力"。 2. 用"落红—春泥—新花"的图示帮助学生理解奉献与再生的链条。 3. 把本诗与《己亥杂诗》其他名句（如"我劝天公重抖擞"）结合拓展，加深对诗人思想的整体认识。 **分层辅导** - 基础弱：以朗读、背诵、默写和字词解释为主，名句含义先由教师讲透。 - 学有余力：尝试查找《己亥杂诗》组诗中另一首自己喜欢的诗，并作简要赏析。 **给家长的建议** 和孩子聊聊"奉献"的话题：身边有哪些默默付出的人？一起找找生活中"化作春泥更护花"的例子，让古诗名句和生活联系起来。
