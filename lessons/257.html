小学二年级语文《古诗二首：村居/咏柳》教案

小学二年级语文古诗二首：村居/咏柳

📝 备课方案

**教学目标** 1. 认识诗人高鼎、贺知章，认识"莺、拂、堤、醉、妆、绦"等生字，会写本课生字。 2. 能正确、流利、有感情地朗读并背诵、默写两首古诗。 3. 借助插图和生活经验理解诗句意思，想象诗句描绘的春天画面。 4. 感受春天的美好，激发热爱春天、热爱生活的情感；初步学习对比阅读。 **教学重点**：朗读背诵两首诗，理解诗意，想象春天画面。 **教学难点**：体会《村居》中"醉"字的表达效果；理解《咏柳》中"碧玉""剪刀"的比喻。 **教学方法**：图文对照、诵读感悟、动作表演（放风筝、拂柳）、对比阅读。 **教学准备**：课件（春天田野图、柳树图、风筝图）、生字卡片、两首诗配乐朗读。 **课时安排**：2 课时（第 1 课时：学习《村居》；第 2 课时：学习《咏柳》并对比总结）

📖 课堂讲义 · 核心知识点

**一、两位诗人** - **高鼎**：清代诗人，生平资料留存不多。他写的《村居》描绘了乡村早春的景色和儿童放风筝的欢乐情景，是描写春天的名篇。 - **贺知章**（约 659—约 744）：唐代诗人，字季真，自号"四明狂客"。他的《咏柳》借赞美柳树来赞美春天，比喻新奇，广为流传。 **二、原文与朗读节奏** 《村居》（高鼎）： 草长/莺飞/二月天， 拂堤/杨柳/醉春烟。 儿童/散学/归来早， 忙趁/东风/放纸鸢。 《咏柳》（贺知章）： 碧玉/妆成/一树高， 万条/垂下/绿丝绦。 不知/细叶/谁裁出， 二月/春风/似剪刀。 **三、字词释义** | 词语 | 释义 | |---|---| | 拂堤 | 拂拭堤岸。柳枝轻拂着堤岸 | | 醉春烟 | 陶醉在春天的烟雾（水汽）中。此处写杨柳的柔美姿态 | | 散学 | 放学 | | 纸鸢 | 风筝 | | 碧玉 | 绿色的玉。这里比喻嫩绿的柳叶 | | 妆 | 打扮、装饰 | | 丝绦 | 丝线编成的带子。比喻垂下的柳条 | | 裁 | 裁剪 | **四、诗句翻译与画面还原** 《村居》：早春二月，青草长出了嫩芽，黄莺在天空飞翔；堤岸上的杨柳枝条轻拂堤岸，仿佛陶醉在春天的烟雾里。孩子们放学回家早，急忙趁着东风放起风筝。 《咏柳》：高高的柳树像用碧玉装扮而成，千万条柳枝垂下来，像绿色的丝带。不知道这细细的柳叶是谁裁出来的，原来是二月的春风，它就像一把剪刀。 **五、写作手法与赏析** 1. **《村居》**：动静结合。草、莺、杨柳是春天田野的静态美景，儿童放风筝是动态的欢乐场面，一静一动，生机盎然。一个"醉"字把杨柳拟人化，写出柳枝在春风烟雾中轻柔拂动、如痴如醉的姿态。 2. **《咏柳》**：比喻和拟人。把柳树整体比作"碧玉"，把柳条比作"绿丝绦"，把春风比作"剪刀"——"谁裁出"还用拟人手法写春风。三个比喻环环相扣，想象奇特。 **六、主题思想与背诵提示** - 《村居》通过描写早春乡村的景色和儿童放风筝的情景，表达了诗人对春天、对乡村生活的喜爱。 - 《咏柳》通过赞美柳树，赞美了给万物带来生机的春风（春天）。 - 背诵提示：抓住关键词记忆。《村居》记"草长—莺飞—杨柳—儿童—纸鸢"；《咏柳》记"碧玉—丝绦—细叶—剪刀"。

🔍 课堂讲义 · 重点难点解析

**重点一：《村居》中"醉"字的表达效果** - 例题："拂堤杨柳醉春烟"中的"醉"字好在哪里？ 分析："醉"本来形容人喝醉的样子，这里用来写杨柳，是说杨柳的枝条在春风和烟雾中轻柔飘动，好像喝醉了酒一样陶醉、惬意。 解答："醉"字把杨柳当成人来写（拟人），生动地写出了杨柳在春日烟霭中轻柔柔美的姿态，表达了诗人对春天景色的喜爱。 小结：赏析字词，先想字面意思，再想它写出了什么情态、表达了什么情感。 **重点二：《咏柳》中的比喻** - 例题：《咏柳》中"碧玉""绿丝绦""剪刀"分别比喻什么？ 分析：把整棵柳树比作"碧玉"（嫩绿美如玉），把垂下的柳条比作"绿丝绦"（绿丝带），把二月的春风比作"剪刀"（裁出细叶）。 解答：分别比喻柳树、柳条、春风。 小结：找比喻要"先找本体（写的是什么），再找喻体（比作什么）"。 **难点一：两首诗的比较阅读** - 例题：《村居》和《咏柳》都写春天，有什么相同和不同？ 分析：相同——都写了早春景色，都写了柳树，都表达对春天的喜爱。不同——《村居》写乡村田野的景色和儿童活动，有动态的热闹；《咏柳》专写柳树，用一连串比喻赞美春风。 解答：相同：都写春天、都写柳树、都喜爱春天。不同：《村居》写景也写人（放风筝），画面热闹；《咏柳》集中写柳，比喻新奇。 小结：比较两首诗，从"写什么景物、有什么人物活动、表达什么情感"几个方面找异同。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（理解诗意）** 用自己的话说说"儿童散学归来早，忙趁东风放纸鸢"的意思。 - 分析：抓住"散学""归来早""忙趁""东风""纸鸢"这些词。 - 参考答案：孩子们放学回家得早，急忙趁着春风把风筝放上天。 - 方法小结：把诗句中的关键词逐个弄清楚，再连成通顺的话。 **例题 2（字词品析）** "不知细叶谁裁出，二月春风似剪刀"中，把春风比作什么？为什么这样比？ - 分析：把春风比作剪刀。春风一吹，柳树的细叶一片片长出来，就像用剪刀精心裁剪出来的一样。 - 参考答案：把春风比作剪刀。因为细细的柳叶像是被精心裁剪出来的，而裁剪它的正是春风，这个比喻写出了春风的神奇和柳叶的精致。 - 方法小结：体会比喻要联系"像什么、为什么像、写出了什么"。 **例题 3（画面想象）** 读了《村居》，你仿佛看到了怎样的画面？请用两三句话说一说。 - 分析：抓住"草长莺飞""杨柳拂堤""儿童放风筝"三个画面。 - 参考答案：早春二月，小草探出头来，黄莺在天上飞；堤岸的柳枝随风轻拂。放学了，孩子们三三两两跑出校门，趁着春风把风筝放上天空，田野里一片欢声笑语。 - 方法小结：想象画面要把诗句中的景物和人物"演"出来，加上颜色、动作和声音。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 背诵默写

  1. 1. 默写《村居》。
    答：草长莺飞二月天，拂堤杨柳醉春烟。儿童散学归来早，忙趁东风放纸鸢。（注意"莺""拂""鸢"的写法）
  2. 2. 默写《咏柳》。
    答：碧玉妆成一树高，万条垂下绿丝绦。不知细叶谁裁出，二月春风似剪刀。（注意"妆""绦""裁"的写法）
  3. 3. 解释加点词：忙趁东风放纸鸢（纸鸢）；碧玉妆成一树高（妆）。
    答：纸鸢：风筝；妆：打扮、装饰。

中等 · 理解诗句

  1. 1. "拂堤杨柳醉春烟"中"醉"字写出了杨柳怎样的样子？
    答："醉"字把杨柳当成人来写，写出了柳枝在春风烟雾中轻柔飘动、如痴如醉的柔美姿态。
  2. 2. "万条垂下绿丝绦"把（ ）比作（ ）。
    答：把垂下的柳条比作绿色的丝带（绿丝绦）。
  3. 3. 《村居》写的是哪个季节的景色？你是从哪些词看出来的？
    答：早春（二月）。从"草长莺飞二月天""东风"等词可以看出。

难 · 品析鉴赏

  1. 1. "不知细叶谁裁出，二月春风似剪刀"好在哪里？
    答：运用比喻和拟人，把春风比作剪刀，说细叶是春风"裁"出来的，想象新奇，写出了春风的神奇和柳叶的精致，表达了对春天的赞美。
  2. 2. 《村居》中哪些地方写出了"动"，哪些写出了"静"？这样写有什么好处？
    答：静态：草长、莺飞、杨柳拂堤；动态：儿童放风筝。动静结合，让春天的田野既有美景又有活力，画面生动。
  3. 3. 《村居》和《咏柳》都写了柳树，写法有什么不同？
    答：《村居》中柳树是春天田野美景的一部分，用"醉"字拟人；《咏柳》专写柳树，用"碧玉""丝绦""剪刀"一连串比喻，集中赞美春风。

综合 · 拓展实践

  1. 1. 你还知道哪些描写春天的古诗？写出两句并注明诗名和作者。
    答：示例：春眠不觉晓，处处闻啼鸟。（孟浩然《春晓》）；好雨知时节，当春乃发生。（杜甫《春夜喜雨》）。写出符合要求的即可。
  2. 2. 春天来了，请你也像高鼎那样，用两三句话写一写你看到的春天（可以写景物，也可以写活动）。
    答：示例：星期天，我和小伙伴到公园放风筝。春风暖暖的，柳条绿绿的，风筝在天上飞，我们在草地上跑，真开心！内容真实、语句通顺即可。
  3. 3. 《咏柳》说春风是"剪刀"，《村居》说"忙趁东风"，请你想想：春风还像什么？仿照"二月春风似剪刀"写一句。
    答：示例：二月春风似画笔，染绿了田野，染红了桃花；二月春风似妈妈的手，轻轻抚摸着我的脸。想象合理即可。

💬 课后反馈

**学生常见错误** 1. 默写时"莺""拂""鸢""绦"等生字易写错，如把"鸢"写成"鸟"、"绦"写成"条"。 2. 把"碧玉"理解为真的玉石，不知道是比喻嫩绿的柳树和柳叶。 3. 背诵《村居》时把"儿童散学归来早"与"忙趁东风放纸鸢"两句顺序记反。 4. 赏析"醉"字只会说"醉了"，说不清是"谁醉、为什么醉、写出了什么"。 **教学改进建议** 1. 结合插图和生活经验教学：春天你见过杨柳拂堤吗？你放过风筝吗？用体验帮助理解。 2. 用"找比喻"游戏教学《咏柳》：先找"写的是什么"，再找"比作什么"。 3. 两首诗放在一起上对比课，用表格整理"相同点/不同点"，培养对比意识。 **分层辅导** - 基础弱：以正确朗读、背诵和重点字词解释为主，画面想象可借助插图复述。 - 学有余力：尝试背诵贺知章《回乡偶书》、高鼎其他作品，或仿写比喻句。 **给家长的建议** 春天带孩子到户外放一次风筝，看看柳树发芽的样子，一边玩一边背《村居》《咏柳》，让古诗和春天的记忆一起留在孩子心里。
