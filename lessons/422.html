高中高一化学《化学计量与物质的分类》教案

高中高一化学化学计量与物质的分类

📝 备课方案

**教学目标** 1. 理解物质的量、阿伏加德罗常数、摩尔质量、气体摩尔体积、物质的量浓度等基本概念，建立宏观量（质量、体积）与微观粒子数之间的"桥梁"。 2. 掌握 n = N÷NA、m = n×M、V = n×22.4 L/mol（标准状况）、c = n÷V 等基本计算，能熟练进行各物理量之间的换算。 3. 掌握配制一定物质的量浓度溶液的操作步骤，会进行简单的误差分析。 4. 了解胶体及其性质（丁达尔效应），掌握电解质与非电解质、强电解质与弱电解质的判断，能正确书写常见离子反应方程式。 **教学重点**：以物质的量为中心的相关计算；物质的量浓度及溶液的配制；离子方程式的书写。 **教学难点**：以物质的量为中心的多步换算；配制溶液时的误差分析；离子方程式中强弱电解质的"拆与不拆"。 **教学方法**：类比教学法（把"摩尔"类比为"打"）、计算强化训练法、实验演示法、分类归纳法。 **教学准备**：多媒体课件、胶体丁达尔效应演示实验器材、容量瓶（100 mL、250 mL）、托盘天平、量筒、烧杯、玻璃棒、胶头滴管。 **课时安排**：4课时（第1课时：物质的量与摩尔质量；第2课时：气体摩尔体积与物质的量浓度；第3课时：溶液配制实验与胶体；第4课时：电解质与非电解质、离子反应与离子方程式）。

📖 课堂讲义 · 核心知识点

**一、物质的量、阿伏加德罗常数与摩尔质量** 物质的量是表示含有一定数目粒子的集合体的物理量，单位是摩尔（mol）。1 mol 任何粒子所含的粒子数约为 6.02×10²³ 个，这个数值称为阿伏加德罗常数 NA，NA 约等于 6.02×10²³ mol⁻¹。 粒子数 N 与物质的量 n 的关系：n = N÷NA。 摩尔质量：单位物质的量的物质所具有的质量，符号 M，单位 g/mol，在数值上等于该物质的相对分子（原子）质量。质量 m 与物质的量的关系：m = n×M。 例：18 g 水的物质的量 n = 18÷18 = 1 mol，水分子数 N = 1×6.02×10²³ = 6.02×10²³ 个。 | 物理量 | 符号 | 常用单位 | 基本关系 | |---|---|---|---| | 物质的量 | n | mol | n = N÷NA | | 摩尔质量 | M | g/mol | M = m÷n | | 阿伏加德罗常数 | NA | mol⁻¹ | NA 约等于 6.02×10²³ mol⁻¹ | **二、气体摩尔体积** 单位物质的量的气体所占的体积叫做气体摩尔体积，符号 Vm。标准状况（0℃、101 kPa）下，Vm 约等于 22.4 L/mol。 气体体积 V = n×Vm，标准状况下 V = n×22.4 L/mol。 注意：22.4 L/mol 只适用于标准状况下的气体，不适用于固体和液体，也不适用于非标准状况下的气体。 **三、物质的量浓度与溶液的配制** 物质的量浓度 c = n÷V，单位 mol/L（即 mol·L⁻¹）。式中 V 是溶液的体积，不是溶剂的体积。 稀释定律：稀释前后溶质的物质的量不变，c1×V1 = c2×V2。 配制一定物质的量浓度溶液的步骤：计算、称量（或量取）、溶解（或稀释）、冷却、转移（转入容量瓶）、洗涤（烧杯和玻璃棒各洗 2 至 3 次，洗涤液一并转入）、定容（用胶头滴管加水至凹液面最低处与刻度线相切）、摇匀、装瓶贴标签。 误差分析：称量偏小、液体洒出、未洗涤烧杯都会使 n 偏小，浓度偏小；定容时俯视使体积偏小，浓度偏大；未冷却就转移，热胀冷缩使体积偏小，浓度偏大。 **四、胶体及其性质** 分散系按分散质粒子直径大小分为溶液（粒子直径小于 1 nm）、胶体（1 nm 至 100 nm）、浊液（大于 100 nm）。 胶体的重要性质： 1. 丁达尔效应：一束光照射胶体时，侧面看到明亮的光路，这是区分胶体与溶液的重要方法； 2. 布朗运动：胶体粒子不停地做无规则运动； 3. 电泳：胶体粒子带电荷，在电场中定向移动； 4. 聚沉：加入电解质、加热或加入带相反电荷的胶体，可使胶体聚集成沉淀。 应用：豆浆点卤制成豆腐、江河入海口形成三角洲、明矾净水都与胶体聚沉有关。 **五、电解质与非电解质** 电解质：在水溶液里或熔融状态下能够导电的化合物，如酸、碱、盐、金属氧化物（HCl、NaOH、NaCl、CaO 等）。 非电解质：在上述两种状态下都不能导电的化合物，如蔗糖、酒精、CO2、SO2、NH3。注意 CO2 的水溶液能导电，是因为 CO2 与水反应生成的 H2CO3 电离出离子，CO2 本身是非电解质。 强电解质：强酸、强碱、大多数盐，在水溶液中完全电离，如 HCl = H⁺ + Cl⁻。 弱电解质：弱酸、弱碱、水，在水溶液中部分电离，存在电离平衡，如 CH3COOH ⇌ CH3COO⁻ + H⁺。 | 比较 | 强电解质 | 弱电解质 | |---|---|---| | 电离程度 | 完全电离 | 部分电离 | | 存在微粒 | 只有离子 | 离子与分子共存 | | 常见物质 | 强酸、强碱、大多数盐 | 弱酸、弱碱、水 | | 电离方程式 | 用等号 | 用可逆符号 | **六、离子反应与离子方程式** 离子反应发生的条件：生成难溶物（沉淀）、生成气体或生成难电离的物质（水、弱酸、弱碱），满足其一即可。 书写离子方程式的步骤：写（写出化学方程式）→拆（把强酸、强碱和可溶性盐拆写成离子）→删（删去两边不参加反应的离子）→查（检查质量守恒和电荷守恒）。 例：盐酸与氢氧化钠：写 HCl + NaOH = NaCl + H2O；拆 H⁺ + Cl⁻ + Na⁺ + OH⁻ = Na⁺ + Cl⁻ + H2O；删去 Na⁺ 和 Cl⁻；得 H⁺ + OH⁻ = H2O。 例：碳酸钠与盐酸：2H⁺ + CO₃²⁻ = H2O + CO2↑。 **拓展**：物质的量把宏观质量与微观粒子数联系起来，是化学计算的"中心桥梁"，学好它要靠多练、多换算，建议自己画一张以 n 为中心的关系图。

🔍 课堂讲义 · 重点难点解析

**重点一：以物质的量为中心的计算** 例题：计算 0.5 mol H2SO4 的质量，并求其中所含氧原子的物质的量。 分析：H2SO4 的摩尔质量 M = 98 g/mol，由 m = n×M 求质量；1 个 H2SO4 分子含 4 个氧原子，氧原子物质的量是硫酸的 4 倍。 解答：m = 0.5×98 = 49 g；n(O) = 4×n(H2SO4) = 4×0.5 = 2 mol。 小结：抓住 n = m÷M 这一核心公式，微粒个数之比等于其物质的量之比。 **难点一：配制一定物质的量浓度溶液的误差分析** 例题：用 2 mol/L 的浓盐酸配制 250 mL 0.1 mol/L 的稀盐酸，若定容时俯视刻度线，所配溶液浓度偏大还是偏小？为什么？ 分析：定容时俯视，液面还没有真正到达刻度线就停止加水，实际溶液体积偏小。 解答：n 不变而 V 偏小，由 c = n÷V 知浓度偏大。 小结：误差分析关键看操作对 n 和 V 的影响：V 偏小则 c 偏大，n 偏小则 c 偏小，逐一对应判断。 **难点二：离子方程式的书写与正误判断** 例题：写出稀硫酸与氢氧化钡溶液反应的离子方程式。 分析：H2SO4 与 Ba(OH)2 反应既生成 BaSO4 沉淀，又生成水，书写时两个反应都要体现，还要保证电荷守恒。 解答：Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ = BaSO4↓ + 2H2O。 小结：多个反应同时发生时，离子方程式要完整书写，做到质量守恒和电荷守恒同时满足。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：物质的量计算** 题目：求 3.01×10²³ 个 CO2 分子的物质的量及其质量。 分析：由 n = N÷NA 求物质的量，再由 m = n×M 求质量，CO2 的摩尔质量为 44 g/mol。 解答：n = 3.01×10²³÷(6.02×10²³) = 0.5 mol；m = 0.5×44 = 22 g。 方法小结：先由粒子数求物质的量，再由物质的量求质量，n 是换算的"桥梁"。 **例题二（提高）：气体体积与物质的量浓度** 题目：标准状况下，11.2 L HCl 气体溶于水配成 500 mL 溶液，求该盐酸的物质的量浓度。 分析：n(HCl) = 11.2÷22.4 = 0.5 mol，V = 500 mL = 0.5 L，代入 c = n÷V。 解答：c = 0.5÷0.5 = 1 mol/L。 方法小结：气体体积换算物质的量时要先确认是否为标准状况，溶液体积单位要换算成升。 **例题三（综合）：稀释计算** 题目：实验室需 0.1 mol/L 的稀硫酸 500 mL，需量取 18.4 mol/L 的浓硫酸多少毫升？ 分析：稀释前后溶质的物质的量不变，应用 c1×V1 = c2×V2。 解答：V1 = c2×V2÷c1 = 0.1×500÷18.4 约等于 2.7 mL。 方法小结：稀释计算抓住"溶质物质的量不变"，代入 c1V1 = c2V2 求解即可。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念辨析与基本计算

  1. 1. 下列说法正确的是（ ）A. 1 mol 氧的质量是 16 g；B. 阿伏加德罗常数就是 6.02×10²³；C. 1 mol H2O 中含有的分子数约为 6.02×10²³ 个。
    答：选 C。"1 mol 氧"没有指明微粒种类，应说 1 mol O 或 1 mol O2；阿伏加德罗常数的数值约为 6.02×10²³ mol⁻¹，不能说"就是 6.02×10²³"；1 mol H2O 含分子数约为 6.02×10²³ 个，C 正确。
  2. 2. 0.5 mol NaOH 的质量是（ ）g，NaOH 的摩尔质量是（ ）g/mol。
    答：M(NaOH) = 40 g/mol，m = n×M = 0.5×40 = 20 g。答案：质量 20 g，摩尔质量 40 g/mol。
  3. 3. 求 4.9 g H2SO4 的物质的量。
    答：n = m÷M = 4.9÷98 = 0.05 mol。注意 H2SO4 的摩尔质量为 98 g/mol。

中等 · 气体体积与浓度计算

  1. 1. 标准状况下 8.96 L 的 O2 的物质的量是多少？质量是多少？
    答：n = 8.96÷22.4 = 0.4 mol；m = n×M = 0.4×32 = 12.8 g。
  2. 2. 将 4 g NaOH 固体溶于水配成 500 mL 溶液，求该溶液中 NaOH 的物质的量浓度。
    答：n(NaOH) = 4÷40 = 0.1 mol；V = 0.5 L；c = n÷V = 0.1÷0.5 = 0.2 mol/L。
  3. 3. 把 200 mL 2 mol/L 的 NaCl 溶液加水稀释到 800 mL，稀释后溶液中 NaCl 的物质的量浓度是多少？
    答：稀释前后溶质的物质的量不变：2×0.2 = c2×0.8，解得 c2 = 0.5 mol/L。

难 · 胶体、电解质与辨析题

  1. 1. 判断正误并说明理由：标准状况下，1 mol H2O 的体积约为 22.4 L。
    答：错误。22.4 L/mol 只适用于标准状况下的气体，H2O 在标准状况下是液体，不能用气体摩尔体积计算。
  2. 2. 下列关于胶体的说法正确的是（ ）A. 丁达尔效应是胶体特有的性质；B. 将饱和 FeCl3 溶液滴入冷水中可制得 Fe(OH)3 胶体；C. 胶体粒子直径大于 100 nm。
    答：选 A。丁达尔效应是胶体区别于溶液的重要性质，A 正确；制 Fe(OH)3 胶体应将饱和 FeCl3 溶液滴入沸水中并继续煮沸至液体呈红褐色，B 错误；胶体粒子直径在 1 nm 至 100 nm 之间，C 错误。
  3. 3. 判断下列物质属于电解质还是非电解质：①蔗糖；②NaCl；③CO2；④H2SO4。
    答：②④是电解质，①③是非电解质。电解质是化合物，酸、碱、盐和金属氧化物属于电解质；蔗糖、CO2 本身不电离，是非电解质（CO2 的水溶液导电是碳酸电离所致）。

综合 · 综合计算与离子方程式

  1. 1. 计算：多少克碳酸钠（Na2CO3）中所含钠离子数目与 5.85 g 氯化钠中所含钠离子数目相等？
    答：n(NaCl) = 5.85÷58.5 = 0.1 mol，含 Na⁺ 0.1 mol；1 mol Na2CO3 含 2 mol Na⁺，故需 n(Na2CO3) = 0.1÷2 = 0.05 mol，m = 0.05×106 = 5.3 g。
  2. 2. 写出下列反应的离子方程式：①稀盐酸与碳酸钠溶液反应；②锌与稀硫酸反应。
    答：①2H⁺ + CO₃²⁻ = H2O + CO2↑（Na⁺ 和 Cl⁻ 不参加反应，删除）；②Zn + 2H⁺ = Zn²⁺ + H2↑（SO₄²⁻ 不参加反应，删除）。书写时先写化学方程式，再拆、删、查。
  3. 3. 用质量分数为 98% 的浓硫酸（密度 1.84 g/cm³）配制 0.5 mol/L 的稀硫酸 100 mL，计算所需浓硫酸的体积，并简述主要操作步骤。
    答：浓硫酸的物质的量浓度 c = 1000×ρ×w÷M = 1000×1.84×0.98÷98 = 18.4 mol/L；由 c1V1 = c2V2 得 V1 = 0.5×100÷18.4 约等于 2.7 mL。步骤：计算、量取、稀释（浓硫酸沿器壁缓缓注入水中并不断搅拌）、冷却、转移入 100 mL 容量瓶、洗涤烧杯和玻璃棒、定容、摇匀。

💬 课后反馈

**学生常见错误** 1. "1 mol 氧"这类表述不准确，没有指明是原子、分子还是离子，要强调摩尔后面必须指明微粒种类。 2. 忽略标准状况这一前提，把 22.4 L/mol 错误套用到液体和固体上。 3. 配制溶液时忘记洗涤烧杯和玻璃棒，或定容时俯视仰视读数，造成浓度偏差。 4. 书写离子方程式时把弱电解质、难溶物拆开写，或漏写电荷，把 CO3²⁻ 写错。 5. 稀释计算误把溶液体积相加，忽略稀释定律 c1V1 = c2V2。 **教学改进建议** 1. 用"打（12 个）"类比"摩尔"，帮助学生建立集合体计数的观念，再过渡到阿伏加德罗常数。 2. 编制"物质的量换算关系图"，以 n 为中心串联 m、N、V、c，强化换算训练。 3. 溶液配制让学生动手完成全流程，边操作边纠错，把操作规范与误差分析结合起来。 4. 离子方程式采用"口诀法"教学："写拆删查四步走，强电解质才可拆，弱电难溶留原样"。 **分层辅导建议** - 基础层：熟练 n、m、N 之间的两两换算，会判断常见电解质和非电解质。 - 提高层：掌握气体体积、物质的量浓度的换算与稀释计算，熟练书写常见离子方程式。 - 拓展层：进行多步综合计算和配制误差分析，结合化学方程式进行定量计算。 **给家长的建议** 1. 帮孩子准备"化学常数卡片"，把 NA、22.4 L/mol 等记牢，计算时随手可查。 2. 鼓励孩子把每个计算题都写出"已知、公式、代入、结果"的完整过程，减少心算失误。 3. 学习离子方程式阶段，请孩子讲给您听"哪些拆、哪些不拆"，讲一遍胜过写三遍。
