高中高二数学《抛物线》教案

高中高二数学抛物线

📝 备课方案

**教学目标** 1. 掌握抛物线的定义、标准方程及 p 的几何意义。 2. 掌握抛物线的焦点、准线，会用定义解题。 3. 能根据条件求抛物线方程，解决焦半径相关问题。 **教学重点**：抛物线定义；焦点与准线。 **教学难点**：焦半径公式的灵活应用；四种标准形式的区分。 **课时安排**：2 课时 **教学准备**：PPT、抛物线演示图（本图）、导学案。

📖 课堂讲义 · 核心知识点

**一、抛物线的定义** 平面内与一个定点 F 和一条定直线 l 的距离相等的点的轨迹叫做抛物线。 F 叫焦点，l 叫准线。 ![抛物线标准图形](/images/parabola.svg) **二、标准方程**（开口向右） $y^2 = 2px$（p > 0） **三、焦点与准线** - 焦点：$F\left(\dfrac{p}{2}, 0\right)$ - 准线： $x = -\dfrac{p}{2}$ **四、焦半径** 抛物线上一点 P(x₀, y₀) 到焦点 F 的距离： $|PF| = x_0 + \dfrac{p}{2}$ **五、四种标准形式** 1. $y^2 = 2px$：开口向右，焦点 $\left(\dfrac{p}{2}, 0\right)$ 2. $y^2 = -2px$：开口向左，焦点 $\left(-\dfrac{p}{2}, 0\right)$ 3. $x^2 = 2py$：开口向上，焦点 $\left(0, \dfrac{p}{2}\right)$ 4. $x^2 = -2py$：开口向下，焦点 $\left(0, -\dfrac{p}{2}\right)$

🔍 课堂讲义 · 重点难点解析

**难点一：p 的几何意义** p 是焦点到准线的距离。焦点坐标是 (p/2, 0)，准线是 x = -p/2，二者相距 p。 **难点二：开口方向判断** - 一次项是谁（x 或 y），抛物线就沿谁的轴开口； - 系数为正 → 向正方向开口；系数为负 → 向负方向开口。 **难点三：焦半径应用** $|PF| = x_0 + \dfrac{p}{2}$ 是抛物线最常用结论，解题时把"点到焦点的距离"转化为"点到准线的距离"。 **易错点**： - 求焦点/准线前，先把方程化为标准形式； - 焦半径公式中的 x₀ 是横坐标（开口左右）或 y₀（开口上下），别用反。

✏️ 课堂讲义 · 典型例题精讲

**例 1（基本量）**：求抛物线 $y^2 = 8x$ 的焦点和准线。 ![抛物线 y² = 8x](/images/parabola.svg) **解**：$2p = 8$，p = 4。 焦点：$F\left(\dfrac{p}{2}, 0\right) = (2, 0)$。 准线：$x = -\dfrac{p}{2} = -2$。 --- **例 2（求方程）**：抛物线焦点在 x 轴正半轴，焦点到准线距离为 6，求方程。 **解**：p = 6，$2p = 12$，方程为 $y^2 = 12x$。 --- **例 3（焦半径）**：抛物线 $y^2 = 4x$ 上一点 P 的横坐标为 3，求 P 到焦点的距离。 **解**：$2p = 4$，p = 2。$|PF| = x_0 + \dfrac{p}{2} = 3 + 1 = 4$。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 焦点与准线

  1. 1. 求抛物线 y²=4x 的焦点和准线。
    答：2p=4, p=2；焦点 (1,0)，准线 x=-1。
  2. 2. 求抛物线 y²=-8x 的焦点和准线。
    答：2p=8, p=4；开口向左，焦点 (-2,0)，准线 x=2。
  3. 3. 求抛物线 x²=8y 的焦点和准线。
    答：2p=8, p=4；开口向上，焦点 (0,2)，准线 y=-2。

中等 · 求方程

  1. 1. 抛物线焦点为 (3,0)，求标准方程。
    答：$\frac{p}{2}$=3 → p=6，方程为 y²=12x。
  2. 2. 抛物线准线为 x=-5，焦点在 x 轴正半轴，求方程。
    答：$\frac{p}{2}$=5 → p=10，方程为 y²=20x。
  3. 3. 抛物线焦点到准线距离为 4，开口向右，求方程。
    答：p=4，方程为 y²=8x。

难 · 焦半径与综合

  1. 1. 抛物线 y²=12x 上点 P 的横坐标为 2，求 P 到焦点距离。
    答：p=6, |PF|=x₀+$\frac{p}{2}$=2+3=5。
  2. 2. 抛物线 y²=2px 上一点到焦点距离为 4，横坐标为 2，求 p。
    答：|PF|=x₀+$\frac{p}{2}$=2+$\frac{p}{2}$=4 → p=4。
  3. 3. 抛物线 y²=2px 上一点 M 到准线距离为 5，求 M 到焦点距离。
    答：由定义，到焦点距离 = 到准线距离 = 5。

综合 · 高考真题

  1. 1. （2022·全国甲）抛物线 y²=2px (p>0) 的焦点为 F，点 P 在抛物线上，且 |PF|=4，P 的横坐标为 2，求 p。
    答：|PF|=x₀+$\frac{p}{2}$=2+$\frac{p}{2}$=4 → p=4。

💬 课后反馈

**本节重点反馈** 1. 抛物线核心是"定义"：到焦点距离 = 到准线距离，焦半径公式 $|PF| = x_0 + \dfrac{p}{2}$ 由此而来。 2. 求焦点/准线先化标准式，再认 p。 3. 四种开口方向要记熟，一次项和系数的正负决定开口。 4. 三种圆锥曲线到此学完，建议用一张对比表总结（定义、方程、焦点、离心率范围）。
