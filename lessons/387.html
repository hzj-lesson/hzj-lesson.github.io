高中高一数学《平面向量》教案

高中高一数学平面向量

📝 备课方案

**教学目标** 1. 理解向量的概念，掌握向量的几何表示与坐标表示，能区分向量与数量，理解零向量、单位向量、相等向量、共线向量的含义及相互关系。 2. 掌握向量的加法、减法与数乘运算法则及其几何意义，理解向量共线定理，能熟练进行向量的线性运算与化简。 3. 理解平面向量基本定理，掌握平面向量的坐标表示与坐标运算，掌握数量积的定义、坐标表示与运算律。 4. 会用坐标判断向量的平行与垂直，会求向量的模与夹角，能运用向量工具解决平面几何与物理中的相关问题，体会数形结合与化归思想。 **教学重点**：向量的线性运算与坐标运算；数量积及其应用；利用坐标解决平行、垂直、夹角、模长问题。 **教学难点**：向量共线定理与平面向量基本定理的灵活运用；数量积的几何意义；用向量方法解决几何问题时的转化与构造。 **教学方法**：类比迁移法（与实数运算及几何知识类比）、数形结合法、问题驱动法、讲练结合法。 **教学准备**：多媒体课件、几何画板动态演示课件、课堂探究学案、坐标纸、三角板。 **课时安排**：共 4 课时。第 1 课时向量的概念与线性运算，第 2 课时共线定理与平面向量基本定理，第 3 课时平面向量的坐标运算，第 4 课时数量积、夹角与模长及其综合应用，并完成本章小结与课堂检测。

📖 课堂讲义 · 核心知识点

**一、向量的基本概念** 向量：既有大小又有方向的量叫作向量，常用有向线段表示，有向线段的长度表示向量的模，箭头指向表示方向，记作 $\vec{a}$ 或 $\overrightarrow{AB}$。向量是"自由"的，只与大小和方向有关，与起点位置无关，所以平行向量可以平移重合。 数量与向量：数量只有大小没有方向（如长度、质量），向量既有大小又有方向（如位移、速度）。向量不能比较大小，只有模长可以比较大小。 特殊向量：零向量 $\vec{0}$，模为 0，方向任意，规定零向量与任何向量平行；单位向量，模为 1。 相等向量：模相等且方向相同的向量；平行向量（共线向量）：方向相同或相反的非零向量，规定 $\vec{0}$ 与任何向量共线。注意"相等"比"平行"更强：相等必平行，平行不一定相等。 **二、向量的线性运算** 1. 加法：三角形法则（$\vec{a}$、$\vec{b}$ 首尾相连，和向量由起点指向终点）与平行四边形法则（共起点，和向量为共起点对角线对应的向量）。加法满足交换律、结合律。 2. 减法：$\vec{a}-\vec{b}=\vec{a}+(-\vec{b})$，口诀"共起点、连终点、指向被减向量"。 3. 数乘：$\lambda\vec{a}$（$\lambda$ 为实数），模长 $|\lambda\vec{a}|=|\lambda|\cdot|\vec{a}|$；方向：$\lambda>0$ 时与 $\vec{a}$ 同向，$\lambda<0$ 时与 $\vec{a}$ 反向，$\lambda=0$ 时为零向量。数乘满足 $\lambda(\mu\vec{a})=(\lambda\mu)\vec{a}$、$(\lambda+\mu)\vec{a}=\lambda\vec{a}+\mu\vec{a}$、$\lambda(\vec{a}+\vec{b})=\lambda\vec{a}+\lambda\vec{b}$。 线性运算与实数运算的差别在于"方向性"，结果既要看模又要看方向。 **三、向量共线定理与平面向量基本定理** 向量共线定理：向量 $\vec{b}$ 与非零向量 $\vec{a}$ 共线的充要条件是存在唯一实数 $\lambda$，使 $\vec{b}=\lambda\vec{a}$。它沟通了"几何共线"与"代数倍数"。 平面向量基本定理：如果 $\vec{e}_{1}$、$\vec{e}_{2}$ 是同一平面内两个不共线的向量，那么对这一平面内任意向量 $\vec{a}$，有且只有一对实数 $\lambda_{1}$、$\lambda_{2}$，使 $\vec{a}=\lambda_{1}\vec{e}_{1}+\lambda_{2}\vec{e}_{2}$。不共线的 $\vec{e}_{1}$、$\vec{e}_{2}$ 称为基底。推论：A、B、C 三点共线的充要条件是存在实数 x、y 且 x+y=1，使 $\overrightarrow{OC}=x\overrightarrow{OA}+y\overrightarrow{OB}$。 **四、平面向量的坐标运算** 若 $\vec{a}=(x_{1},y_{1})$，$\vec{b}=(x_{2},y_{2})$，则： $\vec{a}+\vec{b}=(x_{1}+x_{2},y_{1}+y_{2})$，$\vec{a}-\vec{b}=(x_{1}-x_{2},y_{1}-y_{2})$，$\lambda\vec{a}=(\lambda x_{1},\lambda y_{1})$。 两点间向量：$\overrightarrow{AB}=(x_{2}-x_{1},y_{2}-y_{1})$（终点坐标减起点坐标），$|\overrightarrow{AB}|=\sqrt{(x_{2}-x_{1})^{2}+(y_{2}-y_{1})^{2}}$。 平行条件：$\vec{a}\parallel\vec{b}$（$\vec{b}\ne\vec{0}$）的充要条件是 $x_{1}y_{2}-x_{2}y_{1}=0$。 垂直条件：$\vec{a}\perp\vec{b}$ 的充要条件是 $x_{1}x_{2}+y_{1}y_{2}=0$。 **五、平面向量的数量积** 定义：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$（$\theta$ 为 $\vec{a}$ 与 $\vec{b}$ 的夹角，$0\le\theta\le\pi$），数量积的结果是一个实数。 几何意义：$\vec{a}\cdot\vec{b}$ 等于 $\vec{a}$ 的模与 $\vec{b}$ 在 $\vec{a}$ 方向上投影的乘积；$\vec{b}$ 在 $\vec{a}$ 方向上的投影为 $|\vec{b}|\cos\theta=\frac{\vec{a}\cdot\vec{b}}{|\vec{a}|}$。 坐标表示：$\vec{a}\cdot\vec{b}=x_{1}x_{2}+y_{1}y_{2}$。 运算律：交换律 $\vec{a}\cdot\vec{b}=\vec{b}\cdot\vec{a}$；分配律 $(\vec{a}+\vec{b})\cdot\vec{c}=\vec{a}\cdot\vec{c}+\vec{b}\cdot\vec{c}$；$(\lambda\vec{a})\cdot\vec{b}=\lambda(\vec{a}\cdot\vec{b})$。 注意：数量积不满足结合律 $(\vec{a}\cdot\vec{b})\vec{c}\ne\vec{a}(\vec{b}\cdot\vec{c})$，也不满足消去律。 重要结论：$\vec{a}\cdot\vec{a}=|\vec{a}|^{2}$（求模工具）；$\vec{a}\perp\vec{b}\Leftrightarrow\vec{a}\cdot\vec{b}=0$；夹角公式 $\cos\theta=\frac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}=\frac{x_{1}x_{2}+y_{1}y_{2}}{\sqrt{x_{1}^{2}+y_{1}^{2}}\cdot\sqrt{x_{2}^{2}+y_{2}^{2}}}$。 **六、向量核心公式对照表** | 名称 | 坐标表示 | 关键结论 | | 加减法 | $\vec{a}\pm\vec{b}=(x_{1}\pm x_{2},y_{1}\pm y_{2})$ | 三角形法则、平行四边形法则 | | 数乘 | $\lambda\vec{a}=(\lambda x_{1},\lambda y_{1})$ | $\vec{b}=\lambda\vec{a}$ 即共线 | | 模长 | $|\vec{a}|=\sqrt{x_{1}^{2}+y_{1}^{2}}$ | $|\vec{a}|^{2}=\vec{a}\cdot\vec{a}$ | | 数量积 | $\vec{a}\cdot\vec{b}=x_{1}x_{2}+y_{1}y_{2}$ | 夹角、垂直判定均由此而来 | | 平行 | $x_{1}y_{2}-x_{2}y_{1}=0$ | 坐标交叉相乘相等 | | 垂直 | $x_{1}x_{2}+y_{1}y_{2}=0$ | 对应乘积之和为零 | **七、易错提醒** 1. 误以为"模相等即向量相等"，向量相等还必须方向相同。 2. 减法方向出错，忘了"指向被减向量"。 3. 混淆平行与方向："方向相同或相反"都叫平行（共线）。 4. 由 $\vec{a}\cdot\vec{b}=0$ 推出 $\vec{a}\perp\vec{b}$ 时，忽略 $\vec{a}=\vec{0}$ 或 $\vec{b}=\vec{0}$ 的情形。 5. 由 $\vec{a}\cdot\vec{b}=\vec{a}\cdot\vec{c}$ 推出 $\vec{b}=\vec{c}$，违反消去律。 6. 坐标运算中把 $\overrightarrow{AB}$ 写成"起点减终点"。

🔍 课堂讲义 · 重点难点解析

**重点一：向量的线性运算与共线定理** 例题：设 $\vec{e}_{1}$、$\vec{e}_{2}$ 是不共线的两个向量，$\vec{a}=\vec{e}_{1}+2\vec{e}_{2}$，$\vec{b}=2\vec{e}_{1}+\lambda\vec{e}_{2}$，若 $\vec{a}$ 与 $\vec{b}$ 共线，求实数 $\lambda$。 分析：$\vec{e}_{1}$、$\vec{e}_{2}$ 不共线可作基底，共线则坐标（系数）成比例。 解答：由共线定理，存在实数 k，使 $\vec{b}=k\vec{a}$，即 $2\vec{e}_{1}+\lambda\vec{e}_{2}=k\vec{e}_{1}+2k\vec{e}_{2}$。由基底表示唯一性，系数对应相等：k=2，$\lambda=2k=4$。故 $\lambda=4$。 小结：用基底表示向量后，"系数成比例"是判断共线的通法；若 $\vec{a}=\vec{0}$ 需单独验证。 **重点二：数量积与夹角、模长的计算** 例题：已知 $|\vec{a}|=2$，$|\vec{b}|=3$，$\vec{a}$ 与 $\vec{b}$ 的夹角为 $60^\circ$，求 $\vec{a}\cdot\vec{b}$ 与 $|\vec{a}+\vec{b}|$。 分析：先算数量积，再利用 $|\vec{a}+\vec{b}|^{2}=(\vec{a}+\vec{b})^{2}$ 化模为积。 解答：$\vec{a}\cdot\vec{b}=2\times3\times\cos60^\circ=6\times\frac{1}{2}=3$。$|\vec{a}+\vec{b}|^{2}=|\vec{a}|^{2}+2\vec{a}\cdot\vec{b}+|\vec{b}|^{2}=4+6+9=19$，故 $|\vec{a}+\vec{b}|=\sqrt{19}$。 小结：求模长"先平方、再展开、后开方"；求夹角则先算数量积与模长再代入夹角公式。 **难点一：坐标形式下的平行、垂直判定** 例题：已知 $\vec{a}=(1,2)$，$\vec{b}=(x,1)$。（1）若 $\vec{a}\parallel\vec{b}$，求 x；（2）若 $\vec{a}\perp\vec{b}$，求 x；（3）若 $(\vec{a}+2\vec{b})\parallel(2\vec{a}-\vec{b})$，求 x。 分析：分别代入平行、垂直的坐标充要条件。 解答：（1）$1\times1-2\times x=0$，得 $x=\frac{1}{2}$。（2）$1\times x+2\times1=0$，得 $x=-2$。（3）$\vec{a}+2\vec{b}=(1+2x,4)$，$2\vec{a}-\vec{b}=(2-x,3)$，平行则 $(1+2x)\times3-4\times(2-x)=0$，即 $3+6x-8+4x=0$，得 $x=\frac{1}{2}$。 小结：平行看"交叉相乘差为零"，垂直看"对应乘积和为零"，两者不可混用；含参向量要先化简再代入条件。 **难点二：平面向量基本定理的应用** 例题：在平行四边形 ABCD 中，E 为 CD 的中点，AC 与 BE 交于点 F，若 $\overrightarrow{AF}=\lambda\overrightarrow{AC}$，求 $\lambda$。 分析：用基底 $\overrightarrow{AB}$、$\overrightarrow{AD}$ 表示相关向量，利用共线关系列方程。 解答：设 $\overrightarrow{AB}=\vec{a}$，$\overrightarrow{AD}=\vec{b}$，则 $\overrightarrow{AC}=\vec{a}+\vec{b}$，$\overrightarrow{BE}=\overrightarrow{BC}+\overrightarrow{CE}=\vec{b}-\frac{1}{2}\vec{a}$。设 $\overrightarrow{BF}=\mu\overrightarrow{BE}$，则 $\overrightarrow{AF}=\overrightarrow{AB}+\overrightarrow{BF}=\vec{a}+\mu(\vec{b}-\frac{1}{2}\vec{a})=(1-\frac{\mu}{2})\vec{a}+\mu\vec{b}$。又 $\overrightarrow{AF}=\lambda(\vec{a}+\vec{b})=\lambda\vec{a}+\lambda\vec{b}$，比较系数得 $\lambda=1-\frac{\mu}{2}$ 且 $\lambda=\mu$，故 $\lambda=1-\frac{\lambda}{2}$，解得 $\lambda=\frac{2}{3}$。 小结：涉及交点与三点共线的问题，优先用基底法；利用"同一向量表示唯一"比较系数列方程求解。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（线性运算与几何应用）** 题目：设 D、E、F 分别为 $\triangle$ABC 的边 BC、CA、AB 的中点，用 $\overrightarrow{AB}=\vec{a}$、$\overrightarrow{AC}=\vec{b}$ 表示 $\overrightarrow{AD}$、$\overrightarrow{BE}$，并证明 $\overrightarrow{AD}+\overrightarrow{BE}+\overrightarrow{CF}=\vec{0}$。 分析：中线向量可用"共起点两向量和的一半"表示。 解答：D 为 BC 中点，$\overrightarrow{AD}=\frac{1}{2}(\overrightarrow{AB}+\overrightarrow{AC})=\frac{1}{2}(\vec{a}+\vec{b})$。$\overrightarrow{BE}=\overrightarrow{BA}+\overrightarrow{AE}=-\vec{a}+\frac{1}{2}\vec{b}$。同理 $\overrightarrow{CF}=\overrightarrow{CA}+\overrightarrow{AF}=-\vec{b}+\frac{1}{2}\vec{a}$。三式相加得 $\overrightarrow{AD}+\overrightarrow{BE}+\overrightarrow{CF}=\frac{1}{2}\vec{a}+\frac{1}{2}\vec{b}-\vec{a}+\frac{1}{2}\vec{b}-\vec{b}+\frac{1}{2}\vec{a}=\vec{0}$。 方法小结：中线向量是两端点向量和的一半；用向量证明几何结论，关键是选好基底并统一表示。 **例题 2（数量积与最值，高考常考）** 题目：已知 $|\vec{a}|=1$，$|\vec{b}|=2$，$\vec{a}$ 与 $\vec{b}$ 的夹角为 $60^\circ$，求 $|t\vec{a}+\vec{b}|$（t 为实数）的最小值。 分析：含参模长的最值，先平方化为关于 t 的二次函数。 解答：$|t\vec{a}+\vec{b}|^{2}=t^{2}|\vec{a}|^{2}+2t\vec{a}\cdot\vec{b}+|\vec{b}|^{2}=t^{2}+2t+4=(t+1)^{2}+3$。当 $t=-1$ 时取最小值 3，故 $|t\vec{a}+\vec{b}|$ 的最小值为 $\sqrt{3}$。 方法小结：含参线性组合的模长最值，一律"平方化"，利用 $\vec{a}\cdot\vec{a}=|\vec{a}|^{2}$ 与配方法转化为二次函数最值。 **例题 3（坐标运算综合）** 题目：已知向量 $\vec{a}=(\sqrt{3}\cos\theta,\sin\theta)$，$\vec{b}=(1,1)$，且 $\vec{a}\perp\vec{b}$，求 $\tan\theta$ 的值。 分析：垂直即数量积为零，列出含 $\theta$ 的方程。 解答：$\vec{a}\cdot\vec{b}=\sqrt{3}\cos\theta+\sin\theta=0$，即 $\sin\theta=-\sqrt{3}\cos\theta$。若 $\cos\theta=0$，则 $\sin\theta=0$，与 $\sin^{2}\theta+\cos^{2}\theta=1$ 矛盾，故 $\cos\theta\ne0$，两边同除以 $\cos\theta$，得 $\tan\theta=-\sqrt{3}$。 方法小结：垂直条件立即写"数量积为 0"，再作三角恒等变形；出现齐次式时两边同除以 $\cos\theta$ 转化为 $\tan\theta$。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 向量的概念与线性运算

  1. 1. 下列命题中正确的是（　）。A. 若 $|\vec{a}|=|\vec{b}|$，则 $\vec{a}=\vec{b}$；B. 若 $\vec{a}=\vec{b}$，则 $\vec{a}$ 与 $\vec{b}$ 方向相同；C. 模相等的向量是相等向量；D. 若 $\vec{a}\parallel\vec{b}$ 且 $\vec{b}\parallel\vec{c}$，则 $\vec{a}\parallel\vec{c}$。
    答：选 B。A、C 中模相等但方向不一定相同；D 中若 $\vec{b}=\vec{0}$，零向量与任何向量平行，不能传递共线关系。
  2. 2. 化简 $\overrightarrow{AB}+\overrightarrow{BC}+\overrightarrow{CD}$。
    答：由三角形法则首尾相连，$\overrightarrow{AB}+\overrightarrow{BC}+\overrightarrow{CD}=\overrightarrow{AD}$。
  3. 3. 已知 $\vec{a}=2\vec{e}_{1}+\vec{e}_{2}$，$\vec{b}=\vec{e}_{1}-3\vec{e}_{2}$，求 $2\vec{a}-\vec{b}$（用 $\vec{e}_{1}$、$\vec{e}_{2}$ 表示）。
    答：$2\vec{a}-\vec{b}=2(2\vec{e}_{1}+\vec{e}_{2})-(\vec{e}_{1}-3\vec{e}_{2})=4\vec{e}_{1}+2\vec{e}_{2}-\vec{e}_{1}+3\vec{e}_{2}=3\vec{e}_{1}+5\vec{e}_{2}$。
  4. 4. 已知 A(1,2)、B(3,4)，求 $\overrightarrow{AB}$ 的坐标与模长。
    答：$\overrightarrow{AB}=(3-1,4-2)=(2,2)$，$|\overrightarrow{AB}|=\sqrt{2^{2}+2^{2}}=2\sqrt{2}$。

中等 · 坐标运算与数量积

  1. 1. 已知 $\vec{a}=(2,-1)$，$\vec{b}=(1,3)$，求 $\vec{a}\cdot\vec{b}$、$|\vec{a}|$、$|\vec{b}|$。
    答：$\vec{a}\cdot\vec{b}=2\times1+(-1)\times3=-1$；$|\vec{a}|=\sqrt{4+1}=\sqrt{5}$；$|\vec{b}|=\sqrt{1+9}=\sqrt{10}$。
  2. 2. 已知 $\vec{a}=(1,2)$，$\vec{b}=(-2,m)$。若 $\vec{a}\parallel\vec{b}$，求 m；若 $\vec{a}\perp\vec{b}$，求 m。
    答：平行时 $1\times m-2\times(-2)=0$，得 m=-4；垂直时 $1\times(-2)+2\times m=0$，得 m=1。
  3. 3. 已知 $|\vec{a}|=4$，$|\vec{b}|=3$，$\vec{a}$ 与 $\vec{b}$ 的夹角为 $120^\circ$，求 $(\vec{a}+\vec{b})\cdot\vec{a}$。
    答：$(\vec{a}+\vec{b})\cdot\vec{a}=|\vec{a}|^{2}+\vec{b}\cdot\vec{a}=16+4\times3\times\cos120^\circ=16-6=10$。
  4. 4. 求向量 $\vec{a}=(1,2)$ 在 $\vec{b}=(2,1)$ 方向上的投影。
    答：投影为 $\frac{\vec{a}\cdot\vec{b}}{|\vec{b}|}=\frac{1\times2+2\times1}{\sqrt{4+1}}=\frac{4}{\sqrt{5}}=\frac{4\sqrt{5}}{5}$。

难 · 数量积、夹角与模长综合

  1. 1. 已知 $|\vec{a}|=|\vec{b}|=2$，$\vec{a}\cdot\vec{b}=-2$，求 $|\vec{a}+\vec{b}|$ 及 $\vec{a}$ 与 $\vec{b}$ 的夹角。
    答：$|\vec{a}+\vec{b}|^{2}=4+2\times(-2)+4=4$，故 $|\vec{a}+\vec{b}|=2$。$\cos\theta=\frac{-2}{2\times2}=-\frac{1}{2}$，夹角为 $120^\circ$。
  2. 2. 向量 $\vec{a}$、$\vec{b}$ 满足 $|\vec{a}|=1$，$|\vec{b}|=2$，$|\vec{a}-\vec{b}|=\sqrt{7}$，求 $\vec{a}$ 与 $\vec{b}$ 的夹角。
    答：$|\vec{a}-\vec{b}|^{2}=1+4-2\vec{a}\cdot\vec{b}=7$，得 $\vec{a}\cdot\vec{b}=-1$。$\cos\theta=\frac{-1}{1\times2}=-\frac{1}{2}$，夹角为 $120^\circ$。
  3. 3. 已知 $\vec{a}=(1,2)$，$\vec{b}=(3,x)$，若 $\vec{a}$ 与 $\vec{b}$ 的夹角为锐角，求 x 的取值范围。
    答：锐角需 $\vec{a}\cdot\vec{b}>0$ 且不共线同向。$\vec{a}\cdot\vec{b}=3+2x>0$，得 $x>-\frac{3}{2}$；排除共线同向：$1\times x-2\times3=0$ 得 x=6（此时 $\vec{b}=3\vec{a}$ 同向，夹角为 0°），故 $x>-\frac{3}{2}$ 且 $x\ne6$。

综合 · 向量法解几何问题

  1. 1. 在 $\triangle$ABC 中，O 满足 $\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}=\vec{0}$，证明 O 是 $\triangle$ABC 的重心。
    答：设 G 为重心，由重心性质 $\overrightarrow{GA}+\overrightarrow{GB}+\overrightarrow{GC}=\vec{0}$。若 O 也满足同一关系，则 $\overrightarrow{OA}+\overrightarrow{OB}+\overrightarrow{OC}=\overrightarrow{GA}+\overrightarrow{GB}+\overrightarrow{GC}$，即 $3\overrightarrow{OG}=\vec{0}$，故 O=G，命题得证。
  2. 2. 已知 A(1,0)、B(0,1)、C(2,5)，求 $\cos A$ 的值。
    答：$\overrightarrow{AB}=(-1,1)$，$\overrightarrow{AC}=(1,5)$，$\cos A=\frac{\overrightarrow{AB}\cdot\overrightarrow{AC}}{|\overrightarrow{AB}||\overrightarrow{AC}|}=\frac{-1+5}{\sqrt{2}\times\sqrt{26}}=\frac{4}{\sqrt{52}}=\frac{2\sqrt{13}}{13}$。
  3. 3. 设 $\vec{a}$、$\vec{b}$ 满足 $|\vec{a}|=|\vec{b}|=1$，且 $|\vec{a}+\vec{b}|=|\vec{a}-\vec{b}|$，求 $\vec{a}$ 与 $\vec{b}$ 的夹角。
    答：两边平方得 $|\vec{a}|^{2}+2\vec{a}\cdot\vec{b}+|\vec{b}|^{2}=|\vec{a}|^{2}-2\vec{a}\cdot\vec{b}+|\vec{b}|^{2}$，故 $\vec{a}\cdot\vec{b}=0$，夹角为 $90^\circ$。
  4. 4. 在边长为 2 的正方形 ABCD 中，E 为 BC 的中点，求 $\overrightarrow{AE}\cdot\overrightarrow{BD}$。
    答：取 $\overrightarrow{AB}=\vec{a}$，$\overrightarrow{AD}=\vec{b}$，则 $\vec{a}\perp\vec{b}$ 且 $|\vec{a}|=|\vec{b}|=2$。$\overrightarrow{AE}=\vec{a}+\frac{1}{2}\vec{b}$，$\overrightarrow{BD}=\vec{b}-\vec{a}$，故 $\overrightarrow{AE}\cdot\overrightarrow{BD}=(\vec{a}+\frac{1}{2}\vec{b})\cdot(\vec{b}-\vec{a})=-|\vec{a}|^{2}+\frac{1}{2}|\vec{b}|^{2}=-4+2=-2$。

**常见错误** 1. 混淆"模相等"与"向量相等"，漏掉方向条件。 2. 减法法则方向记反，忘记"指向被减向量"。 3. 坐标运算中 $\overrightarrow{AB}$ 写成"起点减终点"。 4. 平行与垂直的坐标条件混用（交叉相乘与对应相乘记反）。 5. 由 $\vec{a}\cdot\vec{b}=0$ 只得出垂直，忽略零向量情形；由 $\vec{a}\cdot\vec{b}=\vec{a}\cdot\vec{c}$ 误推 $\vec{b}=\vec{c}$。 6. 求夹角时忘记夹角范围 $[0,\pi]$，把钝角算成锐角。 **教学改进建议** 1. 用几何画板演示向量加减的三角形、平行四边形法则，强化方向记忆。 2. 编制"概念辨析判断题"专项，逐条辨析易混概念。 3. 坐标运算规范训练：先写公式再代入，要求每一步有据可依。 4. 结合投影的几何意义讲解数量积，帮助学生理解"向量乘向量得数"。 **分层辅导** 学困生：熟记线性运算口诀与坐标公式，能独立完成概念辨析与基本运算；学优生：挑战数量积最值、平面向量基本定理的应用及向量法证明几何结论，尝试一题多解。 **给家长的建议** 1. 让孩子借助"位移"（家到学校的方向与距离）理解向量的物理背景。 2. 鼓励孩子用坐标纸画图验证向量运算结果，体会数形结合。 3. 提醒孩子建立"易混概念对比表"，把模、相等、共线、垂直等概念对照记忆。
