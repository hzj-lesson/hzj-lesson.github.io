初中七年级生物《人体的营养（消化系统）》教案

初中七年级生物人体的营养（消化系统）

📝 备课方案

**教学目标** 1. 说出人体需要的主要营养物质及其作用、食物来源。 2. 记住常见无机盐和维生素缺乏时的症状，联系生活合理膳食。 3. 描述消化系统的组成，概述食物在口腔、胃、小肠中的消化过程。 4. 阐明小肠适于消化和吸收的结构特点，树立结构与功能相适应的观念。 **教学重点**：营养物质的种类与作用、消化系统的组成与消化过程。 **教学难点**：三大营养物质的消化终产物及小肠适于消化吸收的结构特点。 **教学方法**：实验演示（馒头在口腔中的变化）、图片讲解、生活实例分析。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、食物中的营养物质（六大类）** - 糖类：主要的供能物质，如葡萄糖、淀粉。食物来源：米饭、馒头、面包。 - 脂肪：重要的储能物质，含能量最多。来源：食用油、肥肉。 - 蛋白质：建造和修复身体的重要原料，也能供能。来源：鱼、肉、蛋、奶、豆类。 - 水：细胞的主要组成成分，参与代谢，约占体重 60%-70%。 - 无机盐：如钙（骨、牙）、铁（血红蛋白）、碘（甲状腺激素）。 - 维生素：需量很少但作用大，多数不能由人体合成，须从食物获取。 **二、无机盐与维生素缺乏症（记忆重点）** - 缺钙 → 佝偻病（儿童）、骨质疏松（老人）；缺铁 → 缺铁性贫血；缺碘 → 地方性甲状腺肿（大脖子病）；缺锌 → 生长发育不良、味觉障碍。 - 缺维生素 A → 夜盲症、干眼症；缺维生素 B₁ → 脚气病（不是脚气！）；缺维生素 C → 坏血病、抵抗力下降；缺维生素 D → 佝偻病（促进钙吸收）。 **三、消化系统的组成** - 消化道：口腔 → 咽 → 食道 → 胃 → 小肠 → 大肠 → 肛门。 - 消化腺：唾液腺、胃腺、肠腺（在消化道壁内）、肝脏、胰腺。肝脏分泌胆汁（不含消化酶，乳化脂肪）。 **四、食物的消化过程（核心）** - 淀粉：口腔中唾液淀粉酶分解为麦芽糖 → 小肠中被彻底分解为葡萄糖。 - 蛋白质：胃中胃蛋白酶初步分解 → 小肠中被分解为氨基酸。 - 脂肪：小肠中被胆汁乳化（物理性消化）→ 肠液、胰液中的脂肪酶分解为甘油和脂肪酸。 - 三大营养物质消化的最终产物：淀粉 → 葡萄糖；蛋白质 → 氨基酸；脂肪 → 甘油 + 脂肪酸。 - 小结：口腔和胃只进行初步消化，食物彻底消化和营养吸收的主要场所是小肠。 **五、小肠适于消化和吸收的结构特点** - 长：小肠长 5-6 米，消化吸收面积大； - 大：内壁有环形皱襞和小肠绒毛，使面积增大 600 多倍； - 全：含肠液、胰液、胆汁等多种消化液，消化酶种类全； - 薄：绒毛壁和毛细血管壁都很薄（一层上皮细胞），只由一层细胞构成，利于营养物质吸收进入血液。 **六、合理营养与食品安全** - 平衡膳食宝塔：谷类（最多）→ 蔬菜水果 → 畜禽鱼蛋奶 → 豆类坚果 → 油脂（最少）。 - 一日三餐能量比例约为 3 : 4 : 3。 - 关注食品安全：不买三无产品、不食用变质食品、洗净果蔬、生熟分开。 **七、易错提醒** - 胆汁不含消化酶，只能乳化脂肪（物理消化）； - 消化主要场所是小肠而非胃； - 维生素 B₁ 缺乏是脚气病，不是脚气（真菌感染）； - 缺维生素 D 也导致佝偻病（影响钙吸收）。

🔍 课堂讲义 · 重点难点解析

**重点：三大营养物质的消化与终产物** 三大营养物质消化的「起点—终点」要理清：淀粉从口腔开始消化，到小肠彻底分解为葡萄糖；蛋白质从胃开始消化，到小肠分解为氨基酸；脂肪从小肠才开始消化（经胆汁乳化），最终分解为甘油和脂肪酸。判断一道食物在消化道某段「还能被消化什么」，就看该段有没有对应的酶：口腔只有唾液淀粉酶，只能消化淀粉；胃只有胃蛋白酶，只能消化蛋白质；小肠有肠液、胰液（含多种酶），三大物质都能彻底消化。这是中考选择题和图表题的高频考查。 **难点：小肠的结构与功能相适应** 小肠是消化吸收主要场所，四个特点对应两种功能：长、皱襞、绒毛→增大面积（利于吸收）；多种消化液→消化酶齐全（利于消化）；绒毛壁、毛细血管壁薄→利于物质穿透进入血液。考查方式多为「小肠结构特点与功能连线」或「壁薄为什么利于吸收」。教学时用「面积大、酶全、壁薄」三个关键词概括，并强调血液运输吸收的营养物质。 **常见错误** - 胆汁误认为含消化酶； - 认为 脂肪在口腔或胃开始消化； - 把消化场所误答为胃； - 维生素缺乏症记混（A 夜盲、B₁ 脚气病、C 坏血病、D 佝偻病）。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：填空：人体最重要的供能物质是__；建造和修复身体的重要原料是__。 解析：糖类是主要的供能物质；蛋白质是建造和修复身体的重要原料。答案：糖类、蛋白质。 关键：糖类供能、蛋白质修复、脂肪储能。 **例 2**：填空：缺乏维生素 A 会患__；缺乏维生素 C 会患__；缺乏含__的无机盐会患贫血。 解析：缺维生素 A → 夜盲症；缺维生素 C → 坏血病；缺铁 → 缺铁性贫血。答案：夜盲症、坏血病、铁。 关键：维生素缺乏症口诀——A 夜盲、B₁ 脚气、C 坏血、D 佝偻。 **例 3**：实验分析：取两支试管，分别加入等量的馒头碎屑和馒头块，各滴加 2 毫升唾液，37℃ 水浴 10 分钟后滴加碘液。预测哪支试管不变蓝？为什么？ 解析：馒头碎屑试管不变蓝。因为馒头碎屑与唾液充分混合，唾液淀粉酶将淀粉充分分解为麦芽糖，麦芽糖遇碘不变蓝；馒头块内部淀粉未被酶分解，仍遇碘变蓝。该实验说明牙齿的咀嚼、舌的搅拌（物理性消化）有助于化学性消化。 关键：实验变量是馒头颗粒大小，对照说明「充分混合利于消化」。 **例 4**：简答：为什么小肠是消化和吸收的主要场所？ 解析：① 小肠长 5-6 米，内壁有环形皱襞和小肠绒毛，吸收面积大大增加；② 小肠内有肠液、胰液、胆汁等多种消化液，消化酶种类齐全，食物被彻底消化；③ 小肠绒毛壁和毛细血管壁很薄、只由一层上皮细胞构成，有利于营养物质被吸收进入血液。因此小肠是消化吸收的主要场所。 关键：答出「长、大、全、薄」四个要点。 **例 5**：判断：胆汁中含有消化脂肪的酶。（对/错）并说明。 解析：错误。胆汁由肝脏分泌、储存在胆囊中，不含消化酶，其作用是把脂肪乳化成细小的脂肪微粒，增大脂肪与酶的接触面积，属于物理性消化。真正分解脂肪的是肠液、胰液中的脂肪酶。 关键：胆汁只乳化、不分解，乳化是物理变化。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 营养物质

  1. 1. 说出人体需要的六大营养物质，并指出各举两例食物来源
    答：① 糖类：米饭、馒头；② 脂肪：食用油、肥肉；③ 蛋白质：鸡蛋、牛奶；④ 水：饮水、汤；⑤ 无机盐：蔬菜、海带；⑥ 维生素：水果、蔬菜。其中糖类是主要供能物质，蛋白质是建造修复身体的重要原料。
  2. 2. 连线题：维生素 A—坏血病；维生素 B₁—夜盲症；维生素 C—脚气病；维生素 D—佝偻病。请改正
    答：正确连线为：维生素 A → 夜盲症；维生素 B₁ → 脚气病；维生素 C → 坏血病；维生素 D → 佝偻病（并促进钙的吸收）。记忆口诀：A 夜盲 B 脚气 C 坏血 D 佝偻。
  3. 3. 填空：缺__的无机盐易患缺铁性贫血；缺__的无机盐易患地方性甲状腺肿；儿童缺__易患佝偻病。
    答：缺铁 → 缺铁性贫血；缺碘 → 地方性甲状腺肿（大脖子病）；缺钙 → 佝偻病。此外缺维生素 D 也会导致佝偻病，因为它影响钙的吸收。

中等 · 消化过程

  1. 1. 淀粉、蛋白质、脂肪分别在哪个部位开始消化？最终消化产物各是什么？
    答：淀粉在口腔开始消化（唾液淀粉酶），最终在小肠分解为葡萄糖；蛋白质在胃开始消化（胃蛋白酶），最终在小肠分解为氨基酸；脂肪在小肠开始消化（胆汁乳化 + 脂肪酶），最终分解为甘油和脂肪酸。三大物质的消化终点都在小肠。
  2. 2. 唾液在馒头消化中起什么作用？可以用什么方法检测淀粉是否被分解？
    答：唾液含唾液淀粉酶，能将馒头中的淀粉初步分解为麦芽糖。检测方法：滴加碘液——淀粉遇碘变蓝，若变蓝说明淀粉未被（完全）分解，若不变蓝说明淀粉已被分解。实验中需保持 37℃ 水浴，模拟人体口腔温度，保证酶活性最强。
  3. 3. 肝脏分泌的胆汁起什么作用？胆汁中含有消化酶吗？
    答：胆汁的作用是把脂肪乳化成细小的脂肪微粒，增大脂肪与脂肪酶的接触面积，便于脂肪的消化。胆汁不含消化酶，它进行的乳化作用是物理性消化。消化脂肪的酶存在于肠液和胰液中。

难 · 结构与功能

  1. 1. 小肠有哪些结构特点使其成为消化和吸收的主要场所？请分条说明
    答：① 小肠长约 5-6 米，是消化道中最长的一段，延长了食物停留时间；② 小肠内壁有环形皱襞，皱襞表面有大量小肠绒毛，吸收面积增大 600 多倍；③ 小肠内有肠液、胰液、胆汁等多种消化液，含消化淀粉、蛋白质、脂肪的多种酶，消化能力强；④ 小肠绒毛壁和绒毛内的毛细血管壁都很薄，只由一层上皮细胞构成，利于营养物质被吸收进入血液。
  2. 2. 营养物质吸收进入血液后，主要经过哪条途径输送到全身？哪些物质不需要消化就能被直接吸收？
    答：小肠绒毛内的毛细血管吸收水、无机盐、维生素、葡萄糖、氨基酸等小分子物质，进入血液后经血液循环输送到全身各处细胞。不需要消化即可直接被吸收的物质是：水、无机盐、维生素（它们本身就是小分子物质）；甘油和脂肪酸被毛细淋巴管吸收。
  3. 3. 实验设计：探究「唾液对淀粉的消化作用」，写出假设、材料、步骤、预期结果与结论
    答：假设：唾液对淀粉有消化作用（能分解淀粉）。材料：馒头碎屑、两支试管、唾液、清水、碘液、37℃ 水浴箱。步骤：① 两支试管各加入等量馒头碎屑；② 甲试管加 2 mL 唾液，乙试管加 2 mL 清水（变量是唾液，其余相同）；③ 同时放入 37℃ 水浴 10 分钟；④ 各滴 2 滴碘液观察。预期：甲试管不变蓝（淀粉被分解），乙试管变蓝（淀粉未被分解）。结论：唾液中的唾液淀粉酶能消化分解淀粉。注意：控制单一变量，37℃ 保证酶活性。

综合 · 合理营养与综合

  1. 1. 某同学长期不吃新鲜蔬菜水果，出现牙龈出血、皮肤瘀斑症状，最可能缺乏什么？应如何调理？
    答：最可能缺乏维生素 C（新鲜蔬菜水果富含维生素 C），其缺乏会导致坏血病，表现为牙龈出血、皮下出血等。调理方法：多吃新鲜的蔬菜和水果，如橙子、猕猴桃、番茄、菠菜等，同时注意合理搭配膳食，保证营养均衡。
  2. 2. 根据平衡膳食宝塔，分析「只吃肉不吃蔬菜」的饮食结构有什么危害，并提出建议
    答：危害：① 缺少维生素和膳食纤维，易患坏血病、便秘等；② 油脂和蛋白质摄入过多，增加消化负担、易肥胖，增加心血管疾病风险；③ 营养不均衡，影响正常生长发育。建议：按平衡膳食宝塔合理搭配，主食（谷类）为主，多吃蔬菜水果，适量摄入肉蛋奶，控制油脂，做到食物多样化、三餐规律、比例合理（3:4:3）。
  3. 3. 综合：食物进入人体后，从口腔到肛门经历了哪些消化器官？各器官分别进行了哪些主要消化活动？
    答：口腔：牙齿咀嚼、舌搅拌（物理消化），唾液淀粉酶初步消化淀粉为麦芽糖；咽、食道：食物通道，无消化作用；胃：胃蠕动和胃蛋白酶初步消化蛋白质，同时吸收少量水和酒精；小肠：三大营养物质彻底消化的场所（葡萄糖、氨基酸、甘油和脂肪酸），是吸收的主要场所；大肠：吸收少量水、无机盐和维生素，形成粪便；肛门：排出粪便。其中不直接参与消化的器官还有咽、食道、肛门等。

💬 课后反馈

人体的营养一章要抓住「六大营养物质 + 缺乏症 + 消化过程 + 小肠特点」四条主线。学生易在胆汁是否含酶、三大营养物质消化起点、维生素缺乏症对应关系上出错。建议通过「馒头在口腔中的变化」实验建立消化的直观认识，用消化道行程图串联消化过程，用小肠「长、大、全、薄」四字诀巩固结构与功能相适应，并联系平衡膳食宝塔落实合理营养观念。
