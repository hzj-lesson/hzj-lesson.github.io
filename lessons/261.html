初中九年级物理《电生磁》教案

初中九年级物理电生磁

📝 备课方案

**教材分析** 本节是人教版《物理》九年级全一册第二十章第二节，通过奥斯特实验揭示"电生磁"，再学习通电螺线管的磁场与安培定则。它是电与磁联系的首次确立，为电磁铁、电动机、继电器、发电机学习奠定基础。 **教学目标** 1. 通过奥斯特实验知道通电导线周围存在磁场，知道磁场方向与电流方向有关。 2. 知道通电螺线管外部的磁场与条形磁体相似，磁极性质由电流方向决定。 3. 会用安培定则判断通电螺线管的 N、S 极，能反推电流方向与电源正负极。 **教学重点** 通电螺线管的磁场；安培定则的内容与运用。 **教学难点** 四指弯曲方向与电流环绕方向的空间对应；由磁极反推电流方向与电源极性。 **课时** 1 课时 **教学过程** 奥斯特故事导入→电流的磁效应→通电螺线管磁场探究→安培定则三步训练→反推变式。

📖 课堂讲义 · 核心知识点

**一、电流的磁效应（奥斯特实验）** - 1820 年奥斯特发现：通电导线周围存在磁场；电流的磁场方向与电流方向有关，电流反向则磁场方向改变。 - 意义：第一次揭示电与磁的联系。实验中导线沿南北方向放置，下方放小磁针，便于与地磁场区分；断电后小磁针恢复指南北，说明磁场由电流产生。 **二、通电螺线管的磁场** - 通电螺线管外部的磁场与条形磁体的磁场相似，有 N、S 两极。 - 磁极性质跟电流方向有关：改变电流方向，两端磁极对调。 - 内部磁感线从 S 极指向 N 极，与外部闭合。 **三、安培定则（右手螺旋定则）** - 内容：用右手握住螺线管，让四指弯向螺线管中电流的方向，则大拇指所指的那端就是螺线管的 N 极。 - 三步用法：①沿线圈标出电流环绕方向；②右手握管，四指弯向与环绕方向一致；③拇指指向即 N 极。 - 反向应用：拇指指向 N 极，四指弯向即电流方向，进而判电源正负极与绕法。 - 通电直导线的磁场方向也用安培定则（握直导线式）判断，两类用法统一于"用右手判断电流的磁场"。

🔍 课堂讲义 · 重点难点解析

**难点一：导线为何沿南北方向放置** 小磁针静止时指南北；导线沿南北放置时，其电流磁场方向大致沿东西，与地磁场方向区分明显，通电后小磁针偏转显著。 **难点二：安培定则的规范操作** 四指必须沿电流在螺线管中的环绕方向弯曲（沿箭头绕），拇指端即 N 极。反推时：由磁极定拇指→四指方向定电流环绕方向→沿线圈找电流流入、流出端→结合"外部电流从正极流出"定电源极性。注意判磁场用右手，与判磁场力的左手（电动机一节）区分；做变式题时先确认线圈绕向，再判断电流从哪端流入线圈，避免看错接线而误判磁极。 **难点三：与条形磁体的类比** 外部磁场分布相似，但条形磁体磁性天然存在，通电螺线管的磁性由电流产生、受电流控制，改变电流方向可对调磁极。 **常见失误** 1. 用左手或四指绕向与电流环绕方向相反。 2. 反推电源极性时忘记"外部电流从正极流出"。 3. 内部磁感线方向标成 N→S。

✏️ 课堂讲义 · 典型例题精讲

**例1（实验）** 简述奥斯特实验的做法与结论。 解析：导线沿南北方向放置，下方放小磁针，通电瞬间小磁针偏转，说明通电导线周围存在磁场；对调电源正负极，偏转方向相反，说明磁场方向与电流方向有关。 **例2（磁极判断）** 通电螺线管正面线圈电流方向如何决定磁极？ 解析：用安培定则：右手握管，四指沿正面电流方向（即线圈环绕方向）弯曲，拇指指向端为 N 极，另一端为 S 极。 **例3（反推）** 已知通电螺线管右端为 N 极，如何判断电源正负极？ 解析：拇指指向右端 N 极，四指弯向即电流环绕方向；沿线圈找出电流流入、流出的接线柱，接"电流流入端"的电源端为正极，另一端为负极。 **例4（直导线）** 通电直导线周围的磁场方向怎样判断？ 解析：右手握住直导线，拇指指向电流方向，四指弯曲所指方向即磁场环绕方向；磁感线是以导线为圆心的同心圆，越近越密。 **例5（灵活应用）** 某通电螺线管正面线圈电流自下而上，其左端是什么极？要使两端磁极对调应怎样操作？ 解析：由安培定则，右手握管、四指沿电流环绕方向自下而上弯曲，拇指指向左端，故左端为 N 极、右端为 S 极。要使磁极对调，只需对调电源正负极使线圈中电流方向反向即可。关键：磁极由电流方向决定，安培定则可正用也可反用。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 奥斯特实验说明了什么？意义何在？
    答：通电导线周围存在磁场，磁场方向与电流方向有关。意义：第一次揭示电与磁的联系，发现电流的磁效应。
  2. 2. 通电螺线管外部磁场与哪种磁体相似？磁极由什么决定？
    答：与条形磁体相似。两端磁极由线圈中电流方向决定，改变电流方向磁极对调。

中等 · 定则运用

  1. 1. 写出安培定则的内容。
    答：用右手握住螺线管，让四指弯向螺线管中电流的方向，则大拇指所指的那端就是螺线管的 N 极。
  2. 2. 通电螺线管正面线圈电流自上而下，两端分别是什么极？
    答：用安培定则，四指沿电流环绕方向弯曲，拇指指向右端，故右端为 N 极、左端为 S 极。

难 · 综合推理

  1. 1. 写出由 N 极反推电源正负极的完整步骤。
    答：①拇指指向 N 极端；②四指弯向即电流环绕方向；③沿线圈找电流流入、流出端；④按"外部电流从正极流出"确定正负极。
  2. 2. 通电直导线磁感线分布有何特点？方向如何判断？
    答：磁感线是以导线为圆心的同心圆，越近越密、磁场越强。方向用安培定则：右手握导线，拇指指电流方向，四指弯曲方向即磁场环绕方向。

综合 · 探究设计

  1. 1. 设计实验验证"通电螺线管的磁场方向与电流方向有关"。
    答：把螺线管接电源，两端放小磁针，闭合开关记录 N 极指向、判断磁极；对调电源正负极再观察。磁极随电流反向而对调，说明磁场方向与电流方向有关，可用安培定则预测。
  2. 2. 通电直导线与通电螺线管的磁场有何联系？
    答：螺线管由直导线绕成，其磁场是多匝电流磁场叠加的结果，整体与条形磁体相似、有明确 N、S 极；直导线磁场是环绕导线的同心圆。两者都由电流产生，方向都随电流方向改变。

💬 课后反馈

奥斯特实验是"电与磁的第一次握手"。学生易用错手、四指绕反；反推电源时漏掉"电流从正极流出"。建议用"标环绕箭头→握右手→指 N 极"三步训练，配改变绕向与接线的变式题强化，并明确"判磁用右手、判磁场力用左手"的分工；可在下次课前安排两分钟小测，检验安培定则是否熟练。
