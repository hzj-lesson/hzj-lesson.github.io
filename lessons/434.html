高中高三化学《有机化学基础》教案

高中高三化学有机化学基础

📝 备课方案

**教学目标** 1. 理解碳原子的成键特点（四价碳、共价键、链状与环状结构），认识同系物与同分异构体的概念，会书写简单分子（如 C₅H₁₂、C₄H₈）的同分异构体。 2. 掌握典型官能团（碳碳双键、羟基、醛基、羧基、酯基）的结构与性质，会用银镜反应、新制氢氧化铜等方法检验官能团。 3. 掌握取代、加成、酯化、水解、氧化等典型有机反应类型，能正确书写相关化学方程式并注明反应条件。 4. 了解甲烷、乙烯、乙醇、乙酸、葡萄糖、油脂、蛋白质等重要有机物的性质与用途，能设计简单的鉴别实验方案。 **教学重点**：官能团与性质的关系；典型有机反应类型及条件；重要有机物的检验。 **教学难点**：同分异构体的系统书写；多官能团物质的性质判断（如葡萄糖兼有醛基和羟基）；有机实验条件与操作细节（酯化反应装置、银镜反应条件）。 **教学方法**：模型建构法（球棍模型）、结构决定性质分析法、实验探究法、对比归纳法。 **教学准备**：球棍模型、溴的四氯化碳溶液（或溴水）、酸性 KMnO₄ 溶液、乙醇、乙醛、乙酸、葡萄糖、新制 Cu(OH)₂ 悬浊液、银氨溶液、饱和 Na₂CO₃ 溶液、浓硫酸、试管与酒精灯、课件。 **课时安排**：4 课时（第 1 课时：碳的成键特点与同分异构体；第 2 课时：烃及其衍生物的性质；第 3 课时：糖类、油脂、蛋白质；第 4 课时：有机鉴别与综合训练）。

📖 课堂讲义 · 核心知识点

**一、碳原子的成键特点与有机物结构** 碳原子最外层 4 个电子，易形成 4 个共价键，可形成单键、双键、三键，可连成链状或环状，这使有机物种类繁多。 表示方法：分子式、结构式、结构简式（如 CH₃CH₂OH）、键线式。 分子式相同、结构不同的化合物互称同分异构体。同分异构包括：碳链异构、位置异构、官能团异构。 - C₄H₁₀（丁烷）有 2 种：正丁烷、异丁烷； - C₅H₁₂（戊烷）有 3 种：正戊烷、异戊烷、新戊烷； - C₄H₈ 的烯烃有 3 种：1-丁烯、2-丁烯、2-甲基丙烯（另有环烷烃异构）。 同系物：结构相似（官能团种类与数目相同）、分子组成相差若干个 CH₂ 的有机物。 **二、典型官能团与性质** | 官能团 | 名称 | 代表物 | 主要性质与检验 | |---|---|---|---| | C=C | 碳碳双键 | 乙烯 | 加成（使溴水或溴的四氯化碳溶液褪色）、加聚；被酸性 KMnO₄ 氧化使其褪色 | | —OH | 羟基 | 乙醇 | 与 Na 反应放出 H₂；催化氧化生成醛；与羧酸酯化 | | —CHO | 醛基 | 乙醛 | 银镜反应；与新制 Cu(OH)₂ 加热生成砖红色沉淀 Cu₂O；易被氧化为羧酸 | | —COOH | 羧基 | 乙酸 | 弱酸性（比碳酸强）；与醇发生酯化 | | —COO— | 酯基 | 乙酸乙酯 | 水解生成羧酸和醇（酸性水解可逆、碱性水解趋于完全） | **三、典型有机反应类型（附方程式）** 1. 取代反应（光照、逐步进行）： CH₄ + Cl₂ —光照→ CH₃Cl + HCl，可继续取代生成 CH₂Cl₂、CHCl₃、CCl₄。 苯的硝化：苯 + 浓硝酸 —浓硫酸、加热→ 硝基苯 + H₂O。 2. 加成反应：CH₂=CH₂ + Br₂ → CH₂BrCH₂Br（1,2-二溴乙烷）；CH₂=CH₂ + H₂O —催化剂、加热、加压→ CH₃CH₂OH。 3. 加聚反应：n CH₂=CH₂ —催化剂→ 聚乙烯（高分子化合物，主链为碳链）。 4. 酯化反应（酸脱羟基、醇脱氢，浓硫酸作催化剂和吸水剂，加热）： CH₃COOH + C₂H₅OH ⇌（浓硫酸、加热）CH₃COOC₂H₅ + H₂O。 5. 水解反应：CH₃COOC₂H₅ + H₂O ⇌（稀硫酸、加热）CH₃COOH + C₂H₅OH；碱性条件下（NaOH）水解趋于完全，皂化反应即油脂在碱性条件下的水解。 6. 氧化反应：燃烧，如 CH₄ + 2O₂ —点燃→ CO₂ + 2H₂O；催化氧化，2CH₃CH₂OH + O₂ —Cu、加热→ 2CH₃CHO + 2H₂O；醛基被弱氧化剂氧化（银镜反应、与新制 Cu(OH)₂ 反应）。 **四、常见有机物要点** - 甲烷：正四面体结构，天然气主要成分；光照下与氯气取代；点燃前须验纯。 - 乙烯：平面结构，植物生长调节剂（催熟果实）；加成、加聚是制乙醇和聚乙烯的基础。 - 乙醇：与水任意比互溶；与钠反应放出氢气（比水与钠反应缓和）；催化氧化得乙醛。 - 乙酸：有强刺激性气味，弱酸，酸性比碳酸强，能与 NaOH、Na₂CO₃ 反应；酯化需浓硫酸并加热。 - 葡萄糖：多羟基醛（C₆H₁₂O₆），还原性糖，能发生银镜反应、与新制 Cu(OH)₂ 加热生成砖红色沉淀，医学上用于检验尿糖；体内缓慢氧化供能：C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O。 - 油脂：高级脂肪酸与甘油形成的酯，水解得高级脂肪酸（或高级脂肪酸钠）与甘油；与 NaOH 的皂化反应制肥皂；不饱和油脂可与 H₂ 加成（硬化制人造脂肪）。 - 蛋白质：由氨基酸缩聚而成；盐析（可逆，用于分离提纯）与变性（不可逆，加热、紫外线、重金属盐等）；颜色反应（遇浓硝酸变黄）；灼烧有烧焦羽毛的气味（与合成纤维区别）。 **易错提醒** 1. 有机方程式漏写反应条件（光照、催化剂、浓硫酸、加热）或漏写小分子（H₂O）。 2. 把「使溴水褪色」一律写成「萃取褪色」，混淆加成褪色（乙烯）与萃取褪色（苯、汽油）。 3. 同分异构体漏写或多写（把同一物质的不同写法当成异构体）。 4. 银镜反应用酸性环境或直接加热，忽视「碱性、水浴」的条件要求。

🔍 课堂讲义 · 重点难点解析

**重点一：同分异构体的系统书写** 例题：写出 C₅H₁₂ 的所有同分异构体的结构简式并命名。 分析：用「减链法」——按主链从长到短依次减少碳原子，把减下的碳作为支链取代基。 解答：①主链 5 个碳：CH₃CH₂CH₂CH₂CH₃，正戊烷；②主链 4 个碳、1 个甲基支链：CH₃CH(CH₃)CH₂CH₃，异戊烷（2-甲基丁烷）；③主链 3 个碳、2 个甲基支链：C(CH₃)₃H，即 (CH₃)₃CH，新戊烷（2,2-二甲基丙烷）。共 3 种。 小结：书写顺序「由长到短、支链由中到边」，写完用「先中心后旁边」原则检查重复，注意氢原子数不能超过 4 价。 **重点二：官能团的检验方案设计** 例题：只用一种试剂鉴别乙醇、乙醛、乙酸三种无色溶液，写出试剂与现象。 分析：三者分别含羟基、醛基、羧基；醛基有特征还原性，羧基有酸性。 解答：用新制 Cu(OH)₂ 悬浊液。①与乙醇混合无明显现象；②与乙醛混合后加热产生砖红色沉淀（Cu₂O）；③与乙酸混合后沉淀溶解，得蓝色乙酸铜溶液。 小结：醛基检验——银氨溶液水浴加热出现银镜，或新制 Cu(OH)₂ 加热出现砖红色沉淀；检验时注意碱性环境是必要条件。 **难点一：酯化反应的机理与实验细节** 例题：实验室制备乙酸乙酯：（1）写出化学方程式并标明条件；（2）浓硫酸和饱和 Na₂CO₃ 溶液各起什么作用？（3）导气管为什么不能插入液面以下？ 分析：从平衡移动与防倒吸两方面考虑。 解答：（1）CH₃COOH + C₂H₅OH ⇌（浓硫酸、加热）CH₃COOC₂H₅ + H₂O；（2）浓硫酸起催化剂和吸水剂作用（吸收生成的水，促进平衡正向移动提高产率）；饱和 Na₂CO₃ 溶液吸收挥发出的乙醇、除去（中和）乙酸、并降低乙酸乙酯的溶解度便于分层；（3）防止加热不均引起倒吸，导管口应在液面以上。 小结：酯化反应记忆口诀「酸脱羟基、醇脱氢」；产物中的水由「酸中的羟基与醇中的氢」结合而成。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：官能团与性质对应** 题目：下列物质分别能使溴水褪色、能使酸性 KMnO₄ 溶液褪色的有哪些：甲烷、乙烯、乙醇、乙酸、乙醛？ 分析：使溴水褪色看能否加成（或被溴氧化）；使酸性 KMnO₄ 褪色看能否被氧化（双键、羟基、醛基均可）。 解答：使溴水褪色：乙烯（加成褪色）；使酸性 KMnO₄ 褪色：乙烯（C=C 被氧化）、乙醇（—OH 被氧化）、乙醛（—CHO 被氧化）；甲烷、乙酸均不能使两者褪色。 方法小结：官能团是「性质的路标」——看到 C=C 想加成与氧化，看到 —CHO 想银镜与砖红色沉淀，看到 —COOH 想酸性与酯化。 **例题二（提高）：有机推断** 题目：有机物 A（C₂H₆O）与金属钠反应放出氢气；A 在 Cu 作催化剂并加热的条件下被氧气氧化生成 B（C₂H₄O）；B 能与新制 Cu(OH)₂ 加热反应生成砖红色沉淀并转化为 C（C₂H₄O₂）；B 与 C 在浓硫酸、加热条件下反应生成有香味的 D。写出 A、B、C、D 的结构简式及相关方程式。 分析：A 含羟基；A 氧化得醛、醛氧化得酸；酸与醇生成酯。 解答：A 为 CH₃CH₂OH（乙醇）；B 为 CH₃CHO（乙醛）；C 为 CH₃COOH（乙酸）；D 为 CH₃COOC₂H₅（乙酸乙酯）。 2CH₃CH₂OH + O₂ —Cu、加热→ 2CH₃CHO + 2H₂O； CH₃COOH + C₂H₅OH ⇌（浓硫酸、加热）CH₃COOC₂H₅ + H₂O。 方法小结：推断题抓「转化链」：醇 → 醛 → 羧酸 → 酯，每一步的试剂与条件要写全。 **例题三（综合）：燃烧法确定组成** 题目：0.1 mol 有机物 A 完全燃烧，生成 0.4 mol CO₂ 和 0.5 mol H₂O。求 A 的实验式；若 A 常温下为气体且只有两种同分异构体，写出 A 的分子式和两种结构简式。 分析：由产物量反推 C、H 原子的物质的量之比。 解答：n(C) = n(CO₂) = 0.4 mol；n(H) = 2 × n(H₂O) = 2 × 0.5 = 1.0 mol。n(C) : n(H) = 0.4 : 1.0 = 2 : 5，实验式为 C₂H₅。若 A 为烃，氢已饱和（符合 CnH2n+2 型），则分子式为 C₄H₁₀。两种同分异构体：CH₃CH₂CH₂CH₃（正丁烷）、CH₃CH(CH₃)CH₃（异丁烷）。 方法小结：燃烧法三步——由 CO₂ 定 C、由 H₂O 定 H、再看是否含 O（用质量守恒差量判断）；本题产物只含碳氢两种元素来源，A 不含氧。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 结构与官能团识记

  1. 1. 甲烷分子是什么空间构型？它与氯气发生取代反应需要什么条件？
    答：正四面体结构（碳原子在中心，4 个氢原子位于四面体顶点）。需要光照条件，产物逐步为 CH₃Cl、CH₂Cl₂、CHCl₃、CCl₄ 的混合物，同时生成 HCl。
  2. 2. C₅H₁₂ 有几种同分异构体？分别写出结构简式。
    答：3 种：CH₃CH₂CH₂CH₂CH₃（正戊烷）、CH₃CH(CH₃)CH₂CH₃（异戊烷，2-甲基丁烷）、(CH₃)₃CH（新戊烷，2,2-二甲基丙烷）。
  3. 3. 写出下列官能团的名称和一种代表性有机物：—OH、—CHO、—COOH、—COO—、C=C。
    答：—OH 羟基（乙醇）；—CHO 醛基（乙醛）；—COOH 羧基（乙酸）；—COO— 酯基（乙酸乙酯）；C=C 碳碳双键（乙烯）。

中等 · 性质运用与方程式书写

  1. 1. 写出乙烯与溴水发生反应的化学方程式，指出反应类型；并说明为什么乙烯能使酸性 KMnO₄ 溶液褪色。
    答：CH₂=CH₂ + Br₂ → CH₂BrCH₂Br（1,2-二溴乙烷），加成反应。乙烯中碳碳双键不稳定，能被酸性 KMnO₄ 氧化，从而使紫色褪去——这是氧化褪色，与加成褪色机理不同。
  2. 2. 写出乙醇在 Cu 作催化剂条件下与氧气反应的化学方程式，注明条件。
    答：2CH₃CH₂OH + O₂ —Cu、加热→ 2CH₃CHO + 2H₂O。现象：铜丝先变黑（生成 CuO）、插入乙醇后变红（CuO 被还原为 Cu），可循环进行，说明 Cu 作催化剂。
  3. 3. 只用新制 Cu(OH)₂ 悬浊液如何鉴别乙醇、乙醛、乙酸三种溶液？写出操作与现象。
    答：分别取样，加入新制 Cu(OH)₂ 悬浊液并加热：产生砖红色沉淀的是乙醛（—CHO 被氧化，Cu(OH)₂ 还原为 Cu₂O）；沉淀溶解得蓝色澄清溶液的是乙酸（羧酸发生中和反应）；无明显现象（无明显溶解、无沉淀）的是乙醇。

难 · 同分异构与酯化实验

  1. 1. 分子式为 C₄H₈ 的烯烃（不考虑环烷烃）有几种同分异构体？写出结构简式。
    答：3 种：CH₂=CHCH₂CH₃（1-丁烯）、CH₃CH=CHCH₃（2-丁烯）、CH₂=C(CH₃)₂（2-甲基丙烯，异丁烯）。书写时按「主链减短、支链移动」逐一排查，防止漏写。
  2. 2. 实验室用乙酸和乙醇制备乙酸乙酯：写出化学方程式（注明条件），并回答浓硫酸、饱和 Na₂CO₃ 溶液的作用，以及导管不能插入液面以下的原因。
    答：CH₃COOH + C₂H₅OH ⇌（浓硫酸、加热）CH₃COOC₂H₅ + H₂O。浓硫酸：催化剂、吸水剂（吸水促进平衡正移，提高产率）；饱和 Na₂CO₃ 溶液：吸收乙醇、中和（除去）乙酸、降低乙酸乙酯溶解度使其分层便于收集；导管不插入液面以下是防止发生倒吸。
  3. 3. 0.1 mol 有机物 A 完全燃烧生成 0.4 mol CO₂ 和 0.5 mol H₂O。求 A 的实验式；结合「氢已饱和」判断 A 的分子式。
    答：n(C) = 0.4 mol，n(H) = 1.0 mol，n(C) : n(H) = 2 : 5，实验式 C₂H₅。因产物只含碳、氢两种元素来源，A 不含氧；实验式 C₂H₅ 中氢为奇数，不符合碳四价的稳定烃分子组成，分子式应为实验式的 2 倍，即 C₄H₁₀（符合 CnH2n+2 型，n = 4）。A 为丁烷，有正丁烷、异丁烷两种同分异构体。

综合 · 糖类油脂蛋白质与推断

  1. 1. 医院常用什么反应检验尿液中是否含葡萄糖？写出操作要点与现象；并说明葡萄糖被氧化的产物是什么。
    答：利用葡萄糖分子中醛基的还原性：取尿液样品加入新制 Cu(OH)₂ 悬浊液并加热（或用银氨溶液水浴加热）。若生成砖红色沉淀（Cu₂O）（或出现银镜），说明含葡萄糖，医学检验尿糖即据此原理（家用试纸利用类似氧化还原显色反应）。葡萄糖被氧化生成葡萄糖酸（—CHO 被氧化为 —COOH），加热条件下反应生成砖红色 Cu₂O。
  2. 2. 油脂在 NaOH 溶液中水解（皂化反应）得到什么产物？肥皂去污的原理是什么？
    答：油脂（高级脂肪酸甘油酯）在 NaOH 溶液中水解生成高级脂肪酸钠和甘油。高级脂肪酸钠是肥皂的主要成分：其分子一端是亲水的羧酸钠基团（溶于水），另一端是亲油的长烃基（溶于油污）。洗涤时亲油基插入油污、亲水基朝向水，经搓揉振荡后油污被包围形成乳浊液随水离开衣物。
  3. 3. 有机推断：A 是常见有机物，能发生银镜反应；A 与 H₂ 加成生成 B；B 与过量乙酸在浓硫酸加热下反应生成 C；C 不与 Na 反应。若 A 为最简单的醛（甲醛），请写出 B 的结构简式、B 与乙酸反应的化学方程式，并说明「C 不与 Na 反应」的原因。
    答：A 为甲醛 HCHO，与 H₂ 加成后 B 为甲醇 CH₃OH。B 与乙酸酯化：CH₃COOH + CH₃OH ⇌（浓硫酸、加热）CH₃COOCH₃ + H₂O，C 为乙酸甲酯。C 分子中的羟基已全部转化为酯基，不存在 O—H 键，不能与 Na 反应放出氢气——能与钠反应的本质是分子中含羟基（或羧基）中的活泼氢。

💬 课后反馈

**学生常见错误** 1. 方程式条件缺失或产物漏写：酯化反应漏写浓硫酸与「⇌」及 H₂O；取代反应漏写「光照」；催化氧化漏写 Cu 与加热。 2. 官能团检验条件错：银镜反应用酒精灯直接加热试管壁或忘了先把试管水浴预热、忘记碱性环境，导致看不到银镜。 3. 同分异构体漏写与重写：支链位置只考虑端位不考虑中间位，或把「同一物质的不同展开写法」当成不同异构体。 4. 推断题不会抓转化链：面对多步转化无从下手，根源是对「醇—醛—酸—酯」主线和「结构决定性质」不熟。 **教学改进建议** 1. 建立「官能团性质卡」：每种官能团一张卡，正反面分别写「能与谁反应、如何检验、典型方程式」，把零散性质结构化。 2. 同分异构体训练用球棍模型动手摆：C₄H₁₀、C₅H₁₂、C₄H₈ 逐一构建，用「减链法」规范书写流程，减少漏写。 3. 酯化、银镜两个实验必须人人动手：操作录像对照自查表（水浴、碱性、试管洁净、导管位置），把细节变成得分点。 **分层辅导建议** - 基础层：过关官能团名称、代表物性质与基础方程式书写（条件齐全）。 - 提高层：完成同分异构体书写、单一试剂鉴别方案、酯化实验分析。 - 拓展层：训练多官能团推断题（糖类、油脂、蛋白质综合）、燃烧法确定分子式、简单合成路线题。 **给家长的建议** 1. 请孩子当一次「小老师」，讲讲「酒精消毒、醋酸除垢、油脂变肥皂」背后的有机反应，讲得顺说明主线掌握了。 2. 帮孩子检查方程式默写时，重点看「条件写全了没有、水写漏了没有」，这两个细节是有机方程式最常丢分的地方。
