初中九年级物理《电流的磁场》教案

初中九年级物理电流的磁场

📝 备课方案

**教材分析** 本节是北师大九年级物理第十四章在"磁现象、磁场"之后的核心内容，研究电与磁的联系：奥斯特实验揭示"电生磁"，通电导线周围存在磁场；通电螺线管的磁场分布与条形磁体相似，并用安培定则（右手螺旋定则）判定极性。这是电磁学承上启下的关键节点。 **教学目标** 1. 知道奥斯特实验表明通电导体周围存在磁场，磁场方向与电流方向有关。 2. 描述通电螺线管外部磁场与条形磁体相似。 3. 会用安培定则判定通电螺线管的磁极或电流方向。 **教学重点** 奥斯特实验；通电螺线管的磁场；安培定则的应用。 **教学难点** 安培定则的空间想象与判断（绕向、电流方向、磁极三者互推）。 **课时** 1 课时 **教学过程** 设问导入（电能否生磁）→奥斯特实验→通电直导线磁场→通电螺线管→安培定则→练习→小结。

📖 课堂讲义 · 核心知识点

**一、奥斯特实验（电生磁）** 1820年奥斯特发现：通电导线下方小磁针发生偏转，说明通电导体周围存在磁场。 - 磁场方向与电流方向有关：改变电流方向，小磁针偏转方向随之改变。 - 意义：首次揭示电与磁的联系（电→磁）。 **二、通电螺线管的磁场** - 把导线绕成螺线管，通电后磁场比直导线强且集中，外部磁场与条形磁体相似（两端磁性最强，有 N、S 极）。 - 极性由电流绕向决定。 **三、安培定则（右手螺旋定则）** 判定通电螺线管极性： - 用右手握住螺线管，四指弯曲指向螺线管中的电流方向； - 大拇指所指的一端就是螺线管的 N 极。 （也可记为：四指电流、拇指 N 极） **四、应用** 电磁铁、电磁继电器、电动机等均以"电生磁"为基础。

🔍 课堂讲义 · 重点难点解析

**难点一：安培定则的三要素互推** 已知任意两个可求第三个：①已知电流绕向→判 N/S 极；②已知 N 极→反推电流绕向；③已知绕向与极→验证。关键是"右手四指顺着电流弯、拇指指 N"。 **难点二：螺线管电流方向的"前后"判定** 从一端看截面，电流是"流入"（⊗）还是"流出"（⊙）决定四指弯曲方向。学生常在立体图与平面图转换时出错，建议用实物线圈比划。 **常见失误** 1. 用左手代替右手——错，安培定则用右手。 2. 认为电流方向改了磁场方向不变——错，磁场方向随电流方向变。 3. 把螺线管与条形磁体混淆为"完全相同"——外部相似，但螺线管磁性有无可控。

✏️ 课堂讲义 · 典型例题精讲

**例1（奥斯特）** 奥斯特实验说明了什么？ 解析：通电导体周围存在磁场，即电可以生磁；且磁场方向与电流方向有关。 关键：电→磁的联系。 **例2（安培定则）** 通电螺线管正面电流向上，背面电流向下，判断两端极性。 解析：右手四指沿电流方向（正面向上绕），拇指指向螺线管某一端为 N 极；另一端为 S 极。具体：正面电流向上时，从右端看为逆时针，右端为 N。 关键：右手四指顺电流、拇指指 N。 **例3（互推）** 已知螺线管左端为 N 极，标出电源正负极。 解析：左端 N→右手拇指指左→四指弯曲方向确定电流从哪端流入；电流流入端接电源正极。据此标出正负极。 关键：由极反推电流、再连电源。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 奥斯特实验得出了什么结论？
    答：通电导体周围存在磁场（电生磁），磁场方向与电流方向有关。
  2. 2. 安培定则怎么用？
    答：右手握螺线管，四指弯向电流方向，大拇指所指一端为 N 极。

中等 · 判定

  1. 1. 通电螺线管外部磁场与什么相似？怎样判断它的 N、S 极？
    答：与条形磁体相似；用安培定则（右手四指顺电流、拇指指 N 极）判断。
  2. 2. 改变螺线管中的电流方向，它的磁极会怎样？
    答：磁极对调（N、S 互换），因为磁场方向随电流方向改变。

难 · 作图

  1. 1. 画出通电螺线管（已知电流从左端流入、右端流出）的 N、S 极。
    答：电流沿螺线管绕行，右手四指顺电流，拇指指右端为 N 极，左端为 S 极。
  2. 2. 请标出使螺线管左端为 N 极时，电源该接正还是负在左？
    答：左端 N→拇指指左→四指弯曲方向确定电流从左端流入螺线管，故左端接电源正极。

综合 · 综合

  1. 1. 为什么通电螺线管比通电直导线磁场更强、更集中？
    答：螺线管把多匝导线的磁场叠加并约束在管内，磁场增强且集中，外部近似条形磁体。

💬 课后反馈

安培定则是本节核心工具，学生易"左右手不分"或立体图转平面图错乱。用实物线圈+右手比划建立空间感；反复练"电流绕向↔磁极"互推。强调奥斯特实验的划时代意义：电与磁首次被联系起来。
