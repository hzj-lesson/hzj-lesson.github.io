高中高三化学《电化学：原电池与电解池》教案

高中高三化学电化学：原电池与电解池

📝 备课方案

**教学目标** 1. 理解原电池的工作原理与构成条件，能准确判断正、负极并书写电极反应式，会用电子守恒检查。 2. 了解常见化学电源（一次电池、二次电池、燃料电池）的结构与原理，能书写铅蓄电池、氢氧燃料电池在不同介质中的电极反应式。 3. 理解电解池的工作原理，掌握阴、阳极的放电顺序，能判断常见电解质溶液的电解产物并书写电极反应式，了解氯碱工业、电镀、电解精炼铜等应用。 4. 了解金属电化学腐蚀（析氢腐蚀与吸氧腐蚀）的原理及常用防护方法，建立「能量转化—电极反应—生活应用」的知识主线。 **教学重点**：原电池与电解池的原理；电极反应式的书写（注意介质环境与电子守恒）；电解应用与金属腐蚀防护。 **教学难点**：不同介质（酸性、碱性、熔融）中电极反应式的书写；电解产物判断（含活性阳极）；串联装置的电化学计算。 **教学方法**：实验探究法、对比归纳法、模型建构法、讲练结合法。 **教学准备**：铜锌原电池实验装置（含电流计、盐桥）、电解饱和食盐水与电解硫酸铜溶液演示装置、铅蓄电池与燃料电池结构图、课件、学案。 **课时安排**：3 课时（第 1 课时：原电池原理与电极反应式；第 2 课时：化学电源与电解池；第 3 课时：电解应用、金属腐蚀与综合计算）。

📖 课堂讲义 · 核心知识点

**一、原电池：化学能转化为电能** 构成条件：①能自发进行的氧化还原反应；②两个活泼性不同的电极；③电解质溶液；④形成闭合回路。 铜锌稀硫酸原电池： - 负极（Zn，较活泼，氧化反应）：Zn - 2e⁻ = Zn²⁺； - 正极（Cu，还原反应）：2H⁺ + 2e⁻ = H₂↑； - 总反应：Zn + H₂SO₄ = ZnSO₄ + H₂↑。 双液盐桥原电池（如 Zn 与 CuSO₄ 溶液）：氧化剂与还原剂分开存放，盐桥维持电荷平衡，电流更稳定、效率更高。 **二、电极反应式书写要领** 1. 负极（阳极类）失电子发生氧化反应，正极（阴极类）得电子发生还原反应； 2. 两个电极反应得失电子数必须相等（电子守恒），相加得总反应； 3. 注意介质环境：酸性介质中不能出现 OH⁻ 作为反应物大量参与；碱性介质中不能出现 H⁺，配平用 OH⁻ 与 H₂O； 4. 检查：质量守恒、电荷守恒、电子守恒「三守恒」逐一核对。 **三、常见化学电源** | 类型 | 举例 | 特点 | |---|---|---| | 一次电池 | 锌锰干电池 | 用完即废，不能充电 | | 二次电池 | 铅蓄电池、锂电池 | 可反复充放电 | | 燃料电池 | 氢氧燃料电池、甲烷燃料电池 | 连续通入燃料与氧化剂，能量转化率高 | 铅蓄电池放电：总反应 Pb + PbO₂ + 2H₂SO₄ = 2PbSO₄ + 2H₂O（充电时逆向进行）。 负极：Pb + SO₄²⁻ - 2e⁻ = PbSO₄；正极：PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O。 氢氧燃料电池（碱性介质）： 负极：H₂ + 2OH⁻ - 2e⁻ = 2H₂O；正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻；总反应：2H₂ + O₂ = 2H₂O。 氢氧燃料电池（酸性介质）： 负极：H₂ - 2e⁻ = 2H⁺；正极：O₂ + 4H⁺ + 4e⁻ = 2H₂O。 甲烷燃料电池（碱性介质）负极：CH₄ + 10OH⁻ - 8e⁻ = CO₃²⁻ + 7H₂O。 **四、电解池：电能转化为化学能** 与直流电源连接后，与电源正极相连的是阳极（发生氧化反应，失电子），与电源负极相连的是阴极（发生还原反应，得电子）。 放电顺序（惰性电极）： - 阳极（阴离子放电）：S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根（SO₄²⁻、NO₃⁻ 等）> F⁻； - 阴极（阳离子放电）：Ag⁺ > Cu²⁺ > H⁺（酸中）> Pb²⁺ > Sn²⁺ > Fe²⁺ > Zn²⁺ > Al³⁺ > Mg²⁺ > Na⁺ > Ca²⁺ > K⁺（H⁺ 之后的金属阳离子在水溶液中一般不放电）； - 阳极若为活性电极（金属本身），则电极材料先失电子溶解，而不是溶液中阴离子放电。 **五、电解的应用** 1. 氯碱工业：电解饱和食盐水。阳极：2Cl⁻ - 2e⁻ = Cl₂↑；阴极：2H₂O + 2e⁻ = H₂↑ + 2OH⁻；总反应：2NaCl + 2H₂O —通电→ 2NaOH + H₂↑ + Cl₂↑。用阳离子交换膜阻止 Cl₂ 与 NaOH 接触反应，并防止 H₂ 与 Cl₂ 混合爆炸。 2. 电镀：镀件作阴极，镀层金属作阳极，含镀层金属离子的溶液作电镀液。如镀锌：阴极 Zn²⁺ + 2e⁻ = Zn；阳极 Zn - 2e⁻ = Zn²⁺，电镀液浓度基本不变。 3. 电解精炼铜：粗铜作阳极，纯铜作阴极，CuSO₄ 溶液作电解液。阳极粗铜中的 Zn、Fe 等比 Cu 活泼的金属先溶解；Au、Ag 等不活泼金属沉入底部形成阳极泥；电解液中 c(Cu²⁺) 略有减小。 4. 冶炼活泼金属：电解熔融 NaCl 制钠，电解熔融 Al₂O₃（加冰晶石降低熔点）制铝。 **六、金属的腐蚀与防护** 化学腐蚀：金属与接触的物质直接发生化学反应。 电化学腐蚀：不纯金属与电解质溶液接触构成原电池，较活泼金属失电子被腐蚀，是最主要的腐蚀方式。 - 析氢腐蚀（酸性较强环境）：负极 Fe - 2e⁻ = Fe²⁺；正极 2H⁺ + 2e⁻ = H₂↑； - 吸氧腐蚀（中性或弱酸性环境，更普遍）：负极 2Fe - 4e⁻ = 2Fe²⁺；正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻；总反应 2Fe + O₂ + 2H₂O = 2Fe(OH)₂；继续被氧化：4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃，部分失水后形成铁锈（主要成分 Fe₂O₃·xH₂O）。 防护方法：①牺牲阳极的阴极保护法（连更活泼金属如 Zn）；②外加电流的阴极保护法（被保护金属接电源负极作阴极）；③涂油漆、搪瓷、镀保护层；④改变金属内部结构（制成不锈钢）。 **易错提醒** 1. 电极反应式不看介质，碱性溶液中出现 H⁺、酸性溶液中出现 OH⁻。 2. 活性阳极误判为阴离子放电。 3. 精炼铜时认为电解液中 c(Cu²⁺) 不变。 4. 电化学计算忽略串联电路各电极转移电子数相等。

🔍 课堂讲义 · 重点难点解析

**重点一：原电池的判断与电极反应式书写** 例题：把 Zn 片和 Cu 片用导线连接（串联电流计）插入稀硫酸中。（1）指出正、负极并写出电极反应式；（2）指出电流计偏转与两极现象。 分析：活泼金属作负极失电子，溶液中 H⁺ 在正极得电子。 解答：（1）Zn 为负极：Zn - 2e⁻ = Zn²⁺；Cu 为正极：2H⁺ + 2e⁻ = H₂↑；（2）电流计指针偏转，说明产生电流；负极 Zn 逐渐溶解，正极 Cu 片上有气泡产生。 小结：原电池口诀——「负失氧、正得还」；现象描述要写「谁溶解、谁冒泡」。 **难点一：不同介质中燃料电池电极反应式** 例题：写出氢氧燃料电池在（1）酸性、（2）碱性介质中的负极和正极电极反应式。 分析：负极都是 H₂ 失电子；介质决定「H⁺ 还是 OH⁻ 进出反应式」。 解答：（1）酸性：负极 H₂ - 2e⁻ = 2H⁺；正极 O₂ + 4H⁺ + 4e⁻ = 2H₂O。（2）碱性：负极 H₂ + 2OH⁻ - 2e⁻ = 2H₂O（H₂ 失电子生成的 H⁺ 在碱中立即与 OH⁻ 结合）；正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻。 两式相加均为 2H₂ + O₂ = 2H₂O。 小结：燃料电池中「燃料在负极、氧气在正极」；介质配平法——酸性用 H⁺/H₂O，碱性用 OH⁻/H₂O，最后核对三守恒。 **难点二：电解产物判断与电化学计算** 例题：用惰性电极电解 200 mL 一定浓度的 AgNO₃ 溶液，一段时间后阴极析出 2.16 g Ag。（1）写出两极电极反应式；（2）求转移电子的物质的量；（3）求阳极产生 O₂ 的体积（标准状况）。 分析：Ag⁺ 在阴极放电，OH⁻（实际是水）在阳极放电；串联电路电子守恒。 解答：（1）阴极：Ag⁺ + e⁻ = Ag；阳极：2H₂O - 4e⁻ = O₂↑ + 4H⁺。（2）n(Ag) = 2.16 g ÷ 108 g/mol = 0.02 mol，由 Ag⁺ + e⁻ = Ag 知转移电子 0.02 mol。（3）由 2H₂O - 4e⁻ = O₂↑ + 4H⁺，n(O₂) = 0.02 mol ÷ 4 = 0.005 mol，V(O₂) = 0.005 mol × 22.4 L/mol = 0.112 L。 小结：电化学计算的核心桥梁是「电子的物质的量」：n(e⁻) 定了，各电极产物按计量数比例全都能求出。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：原电池装置分析** 题目：将 Zn 片、Cu 片用导线相连并插入 CuSO₄ 溶液中组成原电池。（1）写出正、负极电极反应式与总反应；（2）说明导线中电子流动方向。 分析：Zn 比 Cu 活泼，Zn 作负极被氧化；Cu²⁺ 在正极得电子。 解答：（1）负极：Zn - 2e⁻ = Zn²⁺；正极：Cu²⁺ + 2e⁻ = Cu；总反应：Zn + CuSO₄ = ZnSO₄ + Cu。（2）电子由负极（Zn）经导线流向正极（Cu）；电流方向相反。 方法小结：写原电池三步——判活泼定正负、按介质写电极式、加和验总反应。 **例题二（提高）：电解硫酸铜溶液** 题目：用惰性电极电解 CuSO₄ 溶液。（1）写出阴、阳极电极反应式与总反应；（2）判断电解过程中溶液 pH 如何变化。 分析：阳离子中 Cu²⁺ 优先于 H⁺ 放电；阴离子中 OH⁻ 优先于 SO₄²⁻ 放电。 解答：（1）阴极：2Cu²⁺ + 4e⁻ = 2Cu；阳极：2H₂O - 4e⁻ = O₂↑ + 4H⁺；总反应：2CuSO₄ + 2H₂O —通电→ 2Cu + O₂↑ + 2H₂SO₄。（2）反应生成 H₂SO₄，c(H⁺) 增大，pH 减小。 方法小结：判断电解产物「两比」——阳离子比还原性（阴极）、阴离子比还原性（阳极）；溶液变化看「生成了什么」。 **例题三（综合）：燃料电池与电解联合计算** 题目：用氢氧燃料电池（碱性介质）作电源电解饱和食盐水。当电路中通过 0.4 mol 电子时：（1）燃料电池中消耗 H₂ 多少克？（2）电解槽阴极放出 H₂ 多少升（标准状况）？（3）写出燃料电池正极的电极反应式。 分析：串联装置中各处转移电子数相等，均为 0.4 mol。 解答：（1）负极 H₂ + 2OH⁻ - 2e⁻ = 2H₂O，n(H₂) = 0.4 ÷ 2 = 0.2 mol，m(H₂) = 0.2 mol × 2 g/mol = 0.4 g。（2）电解槽阴极 2H₂O + 2e⁻ = H₂↑ + 2OH⁻，n(H₂) = 0.4 ÷ 2 = 0.2 mol，V(H₂) = 0.2 mol × 22.4 L/mol = 4.48 L。（3）正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻。 方法小结：多装置串联，抓住「电子守恒」一条主线，把燃料电池与电解槽用 n(e⁻) 串起来逐段计算。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 原电池与电解池基础概念

  1. 1. 铜锌稀硫酸原电池中，负极和正极分别是什么材料？写出两个电极反应式。
    答：Zn 为负极：Zn - 2e⁻ = Zn²⁺（氧化反应）；Cu 为正极：2H⁺ + 2e⁻ = H₂↑（还原反应）。总反应 Zn + H₂SO₄ = ZnSO₄ + H₂↑。
  2. 2. 电解池中，与电源正极相连的是哪一极？该极发生什么反应？与电源负极相连的一极呢？
    答：与电源正极相连的是阳极，发生氧化反应（失电子）；与电源负极相连的是阴极，发生还原反应（得电子）。记忆：阳氧阴还。
  3. 3. 判断正误并说明理由：（1）原电池是把化学能转化为电能的装置；（2）使用催化剂能提高燃料电池的能量转化效率从而改变电极反应；（3）电解池是把电能转化为化学能的装置。
    答：（1）对；（2）错，燃料电池的电极反应由燃料、氧化剂和介质决定，催化剂只是加快电极反应速率，不改变电极反应式本身；（3）对。

中等 · 电极反应式书写

  1. 1. 写出用惰性电极电解饱和食盐水的阴、阳极电极反应式及总化学方程式。
    答：阳极：2Cl⁻ - 2e⁻ = Cl₂↑；阴极：2H₂O + 2e⁻ = H₂↑ + 2OH⁻；总反应：2NaCl + 2H₂O —通电→ 2NaOH + H₂↑ + Cl₂↑。工业上用阳离子交换膜把 Cl₂、H₂ 隔开并防止 NaOH 与 Cl₂ 反应。
  2. 2. 写出氢氧燃料电池在碱性介质中的负极电极反应式。
    答：H₂ + 2OH⁻ - 2e⁻ = 2H₂O。H₂ 失电子生成的 H⁺ 在碱性环境中立即与 OH⁻ 结合为水，所以配平用 OH⁻；碱性介质中电极反应式不能出现 H⁺。
  3. 3. 电镀锌时，镀件应接电源哪一极？镀层金属（锌板）接哪一极？电镀液中含有哪种主要阳离子？
    答：镀件作阴极接电源负极，发生 Zn²⁺ + 2e⁻ = Zn，锌沉积在镀件表面；锌板作阳极接电源正极，发生 Zn - 2e⁻ = Zn²⁺ 补充离子；电镀液是含 Zn²⁺ 的溶液（如 ZnSO₄ 溶液），浓度基本保持不变。

难 · 电解产物判断与电极方程式

  1. 1. 用惰性电极电解 CuSO₄ 溶液，写出两极反应式和总反应，并说明电解过程中溶液 pH 的变化。
    答：阴极：2Cu²⁺ + 4e⁻ = 2Cu；阳极：2H₂O - 4e⁻ = O₂↑ + 4H⁺；总反应：2CuSO₄ + 2H₂O —通电→ 2Cu + O₂↑ + 2H₂SO₄。生成硫酸使 c(H⁺) 增大，pH 减小。
  2. 2. 铅蓄电池放电时，写出负极和正极的电极反应式，并写出放电总反应。
    答：负极：Pb + SO₄²⁻ - 2e⁻ = PbSO₄；正极：PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O；总反应：Pb + PbO₂ + 2H₂SO₄ = 2PbSO₄ + 2H₂O。放电时硫酸被消耗，电解液密度减小，可用密度计粗略判断电量。
  3. 3. 用惰性电极电解 AgNO₃ 溶液，阴极析出 2.16 g Ag。求电路中转移电子的物质的量和阳极生成 O₂ 的体积（标准状况）。
    答：n(Ag) = 2.16 ÷ 108 = 0.02 mol；由 Ag⁺ + e⁻ = Ag 得转移电子 0.02 mol。阳极 2H₂O - 4e⁻ = O₂↑ + 4H⁺，n(O₂) = 0.02 ÷ 4 = 0.005 mol，V(O₂) = 0.005 × 22.4 = 0.112 L。

综合 · 腐蚀防护与综合应用

  1. 1. 钢铁在中性或弱酸性环境中主要发生吸氧腐蚀。写出正、负极电极反应式、总反应式，并说明铁锈是如何形成的。
    答：负极：2Fe - 4e⁻ = 2Fe²⁺；正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻；总反应：2Fe + O₂ + 2H₂O = 2Fe(OH)₂。Fe(OH)₂ 继续被氧气氧化：4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃，Fe(OH)₃ 部分失水形成疏松的铁锈（主要成分 Fe₂O₃·xH₂O），铁锈不保护内部金属，腐蚀继续深入。
  2. 2. 电解精炼铜时：（1）阳极、阴极分别用什么材料？（2）电解液中的 c(Cu²⁺) 在电解过程中如何变化？（3）阳极泥里可能含有哪些金属？
    答：（1）阳极为粗铜，阴极为纯铜，电解液为 CuSO₄ 溶液；（2）粗铜中的 Zn、Fe 等比 Cu 活泼的金属先失电子溶解，而阴极只有 Cu²⁺ 放电，溶解下来的 Cu²⁺ 少、析出的 Cu²⁺ 多，故 c(Cu²⁺) 略有减小；（3）比铜不活泼的 Au、Ag 等不溶解，沉积在阳极底部形成阳极泥，可回收贵重金属。
  3. 3. 设计实验验证原电池原理：提供电流计、锌片、铜片、稀硫酸、导线和烧杯。简述操作步骤、观察到的现象及结论。
    答：步骤：①把 Zn 片和 Cu 片分别插入盛稀硫酸的烧杯中，观察各自现象；②用导线把两金属片与电流计串联起来再插入稀硫酸中。现象：①单独插入时，Zn 片上有少量气泡（Zn 与酸直接反应），Cu 片上无气泡；②连接后电流计指针偏转，Zn 片逐渐溶解，Cu 片上产生大量气泡。结论：连接后构成原电池，化学能转化为电能；Zn 作负极失电子被氧化，H⁺ 在正极（Cu）得电子被还原为 H₂。

💬 课后反馈

**学生常见错误** 1. 电极反应式忽视介质：在碱性燃料电池电极式中保留 H⁺，或在酸性介质中写出 OH⁻ 参与反应，导致电荷不守恒。 2. 正负极与阴阳极混用：把电解池的「阳极」说成「正极」，暴露出对「能量转化方向决定装置、电源连接决定极名」理解不深。 3. 电解产物判断失误：忽略阳极是活性电极时电极本身先溶解（如用 Cu 作阳极电解 CuSO₄ 溶液，阳极是 Cu 溶解而不是 OH⁻ 放电）。 4. 计算桥梁缺失：串联装置不会用「转移电子数相等」来串联各段计算，常把各装置数据孤立处理。 **教学改进建议** 1. 电极反应式教学坚持「三步检查」：质量守恒 → 电荷守恒 → 电子守恒，把检查变成肌肉记忆；配平练习按「酸、碱、熔融」三类介质分组专项训练。 2. 用对比表格固化两大装置：从「能量转化、电极名称、电极反应、判断依据」四栏对比原电池与电解池，配合真实装置演示。 3. 计算题先画「电子流示意图」：标出每一段的 n(e⁻)，再按计量数换算产物，减少思维跳跃带来的错误。 **分层辅导建议** - 基础层：过关铜锌原电池、电解食盐水的电极反应式与现象描述。 - 提高层：掌握放电顺序判断产物、书写酸性/碱性燃料电池电极式、完成单装置电化学计算。 - 拓展层：训练串联综合计算、精炼铜与电镀的分析、新型电池信息题的迁移应用。 **给家长的建议** 1. 请孩子对照家里的干电池、手机电池说说「哪类是一次电池、哪类是二次电池」，并复述铅蓄电池充放电总反应，检验记忆效果。 2. 提醒孩子整理「电极反应式集锦」：每种电源、每种介质一例，考前只看这一页，效率最高。
