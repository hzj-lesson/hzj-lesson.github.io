初中九年级化学《酸和碱》教案

初中九年级化学酸和碱

📝 备课方案

**教学目标** 1. 认识常见酸（盐酸、硫酸）和碱（氢氧化钠、氢氧化钙），掌握指示剂变色规律。 2. 掌握酸、碱的化学通性，能正确书写相关化学方程式。 3. 理解中和反应的实质，了解其在生活和生产中的应用。 4. 掌握 pH 的含义与测定方法，会用酸碱指示剂检验溶液的酸碱性。 **教学重点**：酸、碱的化学性质与化学方程式的书写、中和反应。 **教学难点**：酸碱反应的判断与化学方程式的配平、pH 试纸的使用。 **教学方法**：实验探究、现象分析、方程式书写训练。 **课时安排**：5 课时

📖 课堂讲义 · 核心知识点

**一、酸碱指示剂** - 紫色石蕊溶液：遇酸变红，遇碱变蓝，遇中性溶液（如食盐水）不变色（仍为紫色）。 - 无色酚酞溶液：遇酸不变色，遇碱变红，遇中性溶液不变色。 - 用途：用指示剂检验溶液的酸碱性（注意：指示剂只验「酸碱性」，不能测「酸碱度」pH 值）。 **二、常见的酸** - 盐酸 HCl（有挥发性，敞口有白雾）、硫酸 H₂SO₄、硝酸 HNO₃、碳酸 H₂CO₃。 - 浓硫酸的特性：吸水性（可作干燥剂）、脱水性、强腐蚀性；稀释浓硫酸必须「酸入水、沿杯壁、慢搅拌」，切不可水入酸。 - 酸的组成：由氢元素和酸根组成，电离时产生的阳离子全部是氢离子（$H^+$）。 **三、酸的化学通性（五条）** 1. 与指示剂作用：使紫色石蕊变红，无色酚酞不变色。 2. 与活泼金属反应生成盐和氢气：排在金属活动性顺序 H 前的金属能与酸反应，如 $Zn+H_2SO_4=ZnSO_4+H_2↑$。 3. 与金属氧化物（碱性氧化物）反应生成盐和水：如 $Fe_2O_3+6HCl=2FeCl_3+3H_2O$（用于除铁锈，溶液变黄）。 4. 与碱发生中和反应生成盐和水：$HCl+NaOH=NaCl+H_2O$。 5. 与部分盐反应（如碳酸盐）：$2HCl+CaCO_3=CaCl_2+H_2O+CO_2↑$。 **四、常见的碱** - 氢氧化钠 NaOH（烧碱、火碱、苛性钠）：易潮解、有强腐蚀性，可作干燥剂；须密封保存。 - 氢氧化钙 Ca(OH)₂（熟石灰、消石灰）：微溶于水，其澄清溶液即澄清石灰水，用于检验二氧化碳。 - 氨水 NH₃·H₂O（易挥发）。碱的组成：金属离子（或铵根）＋氢氧根，电离时产生的阴离子全部是 $OH^-$。 **五、碱的化学通性（四条）** 1. 与指示剂作用：使紫色石蕊变蓝，无色酚酞变红。 2. 与非金属氧化物（酸性氧化物）反应生成盐和水：如 $CO_2+2NaOH=Na_2CO_3+H_2O$、$CO_2+Ca(OH)_2=CaCO_3↓+H_2O$（检验 CO₂ 的特征反应，现象为澄清石灰水变浑浊）。 3. 与酸发生中和反应生成盐和水。 4. 与部分盐反应生成新盐和新碱：如 $2NaOH+CuSO_4=Cu(OH)_2↓+Na_2SO_4$（产生蓝色沉淀）。 **六、中和反应** - 定义：酸与碱作用生成盐和水的反应，专指「酸＋碱」。 - 实质：$H^+ + OH^- = H_2O$，即氢离子与氢氧根结合成水。 - 应用：① 改良酸性土壤——撒熟石灰；② 处理酸性工业废水——加碱中和；③ 医药——用 Al(OH)₃ 或 Mg(OH)₂ 治疗胃酸过多；④ 蚊虫叮咬——涂肥皂水等弱碱性物质。 **七、溶液的酸碱度——pH** - 范围：0–14。pH=7 显中性；pH<7 显酸性，pH 越小酸性越强；pH>7 显碱性，pH 越大碱性越强。 - 测定方法：用玻璃棒蘸取少量待测液，滴在 pH 试纸上，与标准比色卡对比读数。 - 操作禁忌：不能把 pH 试纸直接浸入待测液（污染溶液）；不能先用水润湿试纸（稀释待测液，使读数不准）。 - 酸碱性（指示剂）与酸碱度（pH）是两个不同概念：指示剂看「酸还是碱」，pH 看「酸性/碱性的强弱」。 **八、易错提醒** - 指示剂只验酸碱性，pH 才测酸碱度； - 生成盐和水的反应不一定是中和反应（如 $CO_2+2NaOH=Na_2CO_3+H_2O$ 不是中和）； - 浓硫酸稀释必须「酸入水」； - 除铁锈反应生成 $FeCl_3$（+3 价），不是 $FeCl_2$； - 写方程式要注意配平与沉淀↓、气体↑符号。

🔍 课堂讲义 · 重点难点解析

**重点：酸、碱的通性及化学方程式的书写** 酸的五条、碱的四条通性要背熟并能对应到具体反应，这是全章核心。学生最大的难点是写方程式配平与价态判断：如除铁锈 $Fe_2O_3+6HCl=2FeCl_3+3H_2O$，Fe₂O₃ 中铁为 +3 价，产物必须是 $FeCl_3$（溶液呈黄色），学生常误写成 $FeCl_2$；而铁与稀盐酸反应（置换）则生成 $FeCl_2$（浅绿色），两者价态不同，要对照记忆。书写方程式按四步走：写对反应物和生成物的化学式→配平→标条件→标↑↓符号。 **难点：中和反应的判断与实质** 学生易误以为「生成盐和水的反应都是中和反应」。必须强调：中和反应专指「酸＋碱」的反应。如 $CO_2+2NaOH=Na_2CO_3+H_2O$ 虽然生成盐和水，但反应物是非金属氧化物与碱，不是中和。判断方法：看反应物是否同 时是酸和碱。中和反应的实质是 $H^+$ 与 $OH^-$ 结合生成水。pH 变化规律：往酸性溶液中加碱，pH 逐渐升高趋近 7；恰好完全中和时 pH=7（强酸强碱），继续加碱 pH>7。 **常见错误** - 铁锈反应写成 $FeCl_2$（应为 $FeCl_3$）； - 把「碱＋非金属氧化物」误当中和反应； - pH 试纸先润湿再测，导致读数不准； - 浓硫酸稀释「水入酸」（危险）； - 氢氧化钠敞口放置忽略其潮解与吸收 CO₂ 变质。 **微例**：用熟石灰改良酸性土壤，原理是 $Ca(OH)_2$ 与土壤中的酸发生中和反应，实质 $H^+ + OH^- = H_2O$，使土壤酸性减弱。

✏️ 课堂讲义 · 典型例题精讲

**例 1**：用指示剂区分盐酸、氢氧化钠溶液和食盐水 解析：分别取少量三种无色溶液于试管中，各滴入几滴紫色石蕊溶液：变红的是盐酸（酸性）；变蓝的是氢氧化钠溶液（碱性）；仍为紫色不变色的是食盐水（中性）。也可改用酚酞：变红的是 NaOH，另外两瓶不变色，需再用石蕊区分。 关键：石蕊遇酸红、遇碱蓝、中性紫，一次实验即可区分酸、碱、盐三类溶液。 **例 2**：写出稀盐酸除铁锈的化学方程式并描述现象 解析：铁锈主要成分是 $Fe_2O_3$，反应为 $Fe_2O_3+6HCl=2FeCl_3+3H_2O$。现象：红褐色的铁锈逐渐溶解，溶液由无色变为黄色（$Fe^{3+}$ 的颜色）。这是酸与金属氧化物反应的典型应用。 关键：金属氧化物＋酸→盐＋水；铁显 +3 价生成 $FeCl_3$，溶液呈黄色。 **例 3**：中和反应的实质 解析：NaOH 与 HCl 反应：$NaOH+HCl=NaCl+H_2O$。从微观看，$Na^+$ 与 $Cl^-$ 没有参加反应，实质是 $H^+ + OH^- = H_2O$。所以中和反应的微观实质是氢离子与氢氧根结合生成水分子。 关键：生成盐和水不一定是中和，判断要看反应物是否同时为酸和碱。 **例 4**：检验二氧化碳为什么用澄清石灰水 解析：二氧化碳通入澄清石灰水发生反应 $CO_2+Ca(OH)_2=CaCO_3↓+H_2O$，生成白色碳酸钙沉淀使石灰水变浑浊，这是检验 CO₂ 的特征现象。注意：此反应是碱与非金属氧化物的反应，不是中和反应。 关键：碱＋非金属氧化物→盐＋水；「变浑浊」是 CO₂ 检验的判断依据。 **例 5**：测定土壤 pH 的方法与注意事项 解析：取少量土壤加水充分搅拌后静置，取上层清液；用干燥洁净的玻璃棒蘸取待测液，滴在 pH 试纸上；把试纸显示的颜色与标准比色卡对比，读出 pH。注意：pH 试纸不能直接浸入溶液中（污染原液），不能先润湿（稀释会改变 pH）。若测得 pH<7，说明土壤显酸性，可施用熟石灰改良。 关键：pH 测酸碱度，操作要点「蘸—滴—比」，忌润湿、忌浸入。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念与指示剂

  1. 1. 紫色石蕊、无色酚酞遇酸、碱、中性溶液分别显什么颜色？
    答：石蕊：遇酸变红、遇碱变蓝、遇中性溶液不变色（仍紫）。酚酞：遇酸不变色、遇碱变红、遇中性溶液不变色。两者都只验酸碱性，不能测酸碱度（pH）。
  2. 2. 写出常见两种酸和两种碱的化学式
    答：酸：盐酸 HCl、硫酸 H₂SO₄（还有硝酸 HNO₃、碳酸 H₂CO₃）。碱：氢氧化钠 NaOH、氢氧化钙 Ca(OH)₂（还有氢氧化钾 KOH、氨水 NH₃·H₂O）。
  3. 3. 稀释浓硫酸的正确操作是什么？为什么？
    答：把浓硫酸沿烧杯壁缓缓倒入水中，并用玻璃棒不断搅拌（即「酸入水、沿杯壁、慢搅拌」）。因为浓硫酸溶于水会放出大量热，若把水倒入浓硫酸，水密度小浮在液面，放热使水局部沸腾，酸液会飞溅伤人，非常危险。

中等 · 化学方程式

  1. 1. 写出 NaOH 与 HCl 中和、以及 Ca(OH)₂ 与 H₂SO₄ 中和的化学方程式并配平
    答：① $NaOH+HCl=NaCl+H_2O$（已配平）；② $Ca(OH)_2+H_2SO_4=CaSO_4+2H_2O$。配平要点：Ca(OH)₂ 提供 2 个 OH⁻，需 2 个 H⁺，故 H₂SO₄ 的系数为 1，生成 2 个水分子。
  2. 2. 用化学方程式表示稀盐酸除铁锈，并描述实验现象
    答：$Fe_2O_3+6HCl=2FeCl_3+3H_2O$。现象：红褐色铁锈逐渐溶解，溶液由无色变为黄色（Fe³⁺ 使溶液显黄色）。这属于酸与金属氧化物的反应。
  3. 3. 为什么 CO₂ 能使澄清石灰水变浑浊？写出反应方程式
    答：因为二氧化碳与氢氧化钙反应生成难溶于水的碳酸钙白色沉淀：$CO_2+Ca(OH)_2=CaCO_3↓+H_2O$，沉淀使溶液变浑浊。这是检验二氧化碳的特征反应，属于碱与非金属氧化物的反应（不是中和）。

难 · 判断与计算

  1. 1. 判断：「生成盐和水的反应一定是中和反应」对吗？请说明理由并举例
    答：不对。中和反应特指酸与碱作用生成盐和水的反应。有些反应也生成盐和水，但反应物不是酸和碱，如 $CO_2+2NaOH=Na_2CO_3+H_2O$（非金属氧化物与碱）、$Fe_2O_3+6HCl=2FeCl_3+3H_2O$（金属氧化物与酸）。判断中和反应必须看反应物是否同时为酸和碱。
  2. 2. 含 9.8 g H₂SO₄ 的稀硫酸与足量 NaOH 溶液完全中和，生成 Na₂SO₄ 多少克？
    答：化学方程式：$H_2SO_4+2NaOH=Na_2SO_4+2H_2O$。H₂SO₄ 的相对分子质量为 1×2+32+16×4=98，Na₂SO₄ 的相对分子质量为 23×2+32+16×4=142。由方程式知 98 g H₂SO₄ 生成 142 g Na₂SO₄，设生成 x g，则 $\\frac{98}{142}=\\frac{9.8}{x}$，解得 $x=\\frac{142\times9.8}{98}=14.2$ g。

综合 · 应用与探究

  1. 1. 列举中和反应在生活和工业中的 3 项应用并简述原理
    答：① 改良酸性土壤：撒熟石灰 Ca(OH)₂，与土壤中的酸发生中和反应；② 处理酸性工业废水：加碱液（如 NaOH 或熟石灰）中和，使废水达标排放；③ 医药：用 Al(OH)₃ 或 Mg(OH)₂ 中和胃酸过多，如 $3HCl+Al(OH)_3=AlCl_3+3H_2O$；④ 蚊虫叮咬：涂肥皂水等弱碱性物质中和蚁酸。原理均为 $H^+ + OH^- = H_2O$。
  2. 2. 设计实验证明 NaOH 溶液与稀盐酸恰好完全反应
    答：方法一（酚酞指示法）：向 NaOH 溶液中滴入几滴酚酞，溶液变红；用胶头滴管逐滴加入稀盐酸并不断搅拌，当红色恰好褪去时，说明 H⁺ 与 OH⁻ 恰好完全中和（pH=7）。方法二（pH 试纸法）：边滴加稀盐酸边用玻璃棒蘸取溶液测 pH，当 pH 由大于 7 降至等于 7 时即恰好中和。注意事项：要逐滴加入、边加边搅，防止盐酸过量。

💬 课后反馈

酸和碱的性质需结合实验现象记忆，学生要掌握指示剂变色规律、酸五条/碱四条通性及中和反应。常见错误是铁锈反应写错价态（$FeCl_2$ 应为 $FeCl_3$）、把碱＋非金属氧化物误当中和、pH 试纸润湿致读数偏差、浓硫酸稀释「水入酸」。建议通过「除铁锈」「测 pH」「中和滴定」等实验强化方程式书写与配平，理解酸碱性（指示剂）与酸碱度（pH）的区别，做到灵活运用而非死记。
