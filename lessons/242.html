初中九年级物理《两种电荷》教案

初中九年级物理两种电荷

📝 备课方案

**教材分析** 本节是电学学习的起点，内容包括摩擦起电、两种电荷及其相互作用、验电器、电荷量与元电荷、摩擦起电的实质、导体与绝缘体。认识"电"首先要认识"电荷"，本节为后续电流、电路的学习提供最基础的观念准备，是电学的第一块基石。 **教学目标** 1. 知道摩擦起电现象，知道两种电荷的规定及同种相斥、异种相吸的规律。 2. 了解验电器的构造、原理（同种电荷相斥）及其作用。 3. 知道电荷量的概念与单位库仑，知道元电荷 $e=1.6\times10^{-19}\,C$。 4. 知道摩擦起电的实质是电荷（电子）的转移；了解导体与绝缘体的区别。 **教学重点** 两种电荷及其相互作用规律；验电器原理。 **教学难点** 摩擦起电的实质（电子转移而非创造电荷）；用相互作用规律判断物体带电情况。 **课时** 1 课时 **教学过程** 摩擦起电小实验引入→规定两种电荷→电荷间相互作用→验电器探究→电荷量与元电荷→摩擦起电本质剖析→导体绝缘体举例。

📖 课堂讲义 · 核心知识点

**一、摩擦起电** 用摩擦的方法使物体带电，叫摩擦起电。带电体具有吸引轻小物体的性质，可用它检验物体是否带电。 生活实例：干燥冬天脱毛衣有"噼啪"声和火花、用塑料梳子梳头后能吸引纸屑、摩擦过的气球能吸在墙上。 **二、两种电荷** 人们规定：用丝绸摩擦过的玻璃棒所带的电荷叫正电荷，用毛皮摩擦过的橡胶棒所带的电荷叫负电荷。 电荷间的相互作用规律：同种电荷互相排斥，异种电荷互相吸引。 （玻璃棒带正电、橡胶棒带负电是"规定"的，要牢记。） **三、验电器** 构造：金属球、金属杆、金属箔（两片）等。原理：同种电荷互相排斥。 作用：检验物体是否带电——把物体接触金属球，若金属箔张开则物体带电（张角越大，带电越多）；还能粗略比较带电的多少。 注意：验电器只能检验物体"是否带电"、比较带电多少，不能直接判断带的是正电还是负电。 **四、电荷量** 电荷的多少叫电荷量，符号 $Q$，单位是库仑，简称库，符号 $C$。$1\,C$ 是较大的电荷量，摩擦起电所带的电荷量通常远小于 $1\,C$。 元电荷：自然界中最小的电荷量叫元电荷 $e$，$e=1.6\times10^{-19}\,C$。质子带正电、电子带负电，质子与电子所带电荷量都等于 $e$。$1\,C$ 的电荷量约需 $6.25\times10^{18}$ 个电子。 **五、摩擦起电的实质** 摩擦起电并不是创造了电荷，只是电荷发生了转移：不同物体的原子核对电子的束缚本领不同，摩擦时束缚本领弱的物体失去电子而带正电，束缚本领强的物体得到电子而带负电。摩擦双方总是同时带上等量异种电荷。 **六、导体与绝缘体** 导体：善于导电的物体，如金属、石墨、人体、大地、食盐水及酸碱盐溶液等——内部有大量能自由移动的电荷（金属中是自由电子）。 绝缘体：不善于导电的物体，如橡胶、玻璃、塑料、陶瓷、干燥的木材——内部几乎没有自由电荷。 导体与绝缘体没有绝对界限，条件改变时可能相互转化（如干燥玻璃加热到红炽状态会变导体）。

🔍 课堂讲义 · 重点难点解析

**难点一：摩擦起电的实质是"电子转移"而非"创造电荷"** 摩擦起电的过程是电子从一个物体转移到另一个物体：失电子的一方带正电、得电子的一方带负电，两个物体带等量异种电荷，电荷总量不变。因此不能说"摩擦产生了电"。判断口诀：谁束缚电子本领弱，谁失电子带正电。 **难点二：用相互作用规律推断带电情况** 判断小球的带电情况要分情形：两带电体间——同种相斥、异种相吸；带电体能吸引轻小不带电物体，所以"吸引"不等于"一定带异种电荷"。例：甲带正电、乙被甲吸引，乙可能带负电，也可能不带电（轻小物体），单凭"吸引"不能唯一确定。 **难点三：验电器只能判断"是否带电"** 验电器金属箔张开说明物体带电，但无法判断正负；若想判断电荷种类，需用已知带电体（如带正电的玻璃棒）靠近或接触，根据张角变化推断。 **常见失误** 1. 记反玻璃棒与橡胶棒带电符号——丝绸摩擦玻璃棒→正电，毛皮摩擦橡胶棒→负电。 2. 说摩擦起电"创造了电荷"——应说"电荷发生转移"。 3. 把"吸引"误判为异种电荷——带电体能吸引轻小不带电物体。

✏️ 课堂讲义 · 典型例题精讲

**例1（概念）** 用丝绸摩擦过的玻璃棒带什么电？用毛皮摩擦过的橡胶棒带什么电？摩擦起电的实质是什么？ 解析：丝绸摩擦玻璃棒，玻璃棒失去电子带正电；毛皮摩擦橡胶棒，橡胶棒得到电子带负电。摩擦起电的实质是电子（电荷）从一个物体转移到另一个物体，电荷并未被创造。 关键：失电子带正电，得电子带负电。 **例2（相互作用）** 有 A、B、C 三个轻质小球。A 与 B 互相吸引，B 与 C 互相排斥，已知 C 带正电，试判断 A 的带电情况。 解析：B 与 C 互相排斥且 C 带正电，说明 B 也带正电（同种相斥）；A 与 B 互相吸引，A 可能带负电，也可能不带电（轻小球被带电体吸引）。 关键："排斥"能确定同种，"吸引"不能唯一确定异种。 **例3（电荷量计算）** 一个带电体带有 $2\,C$ 的电荷量，它约含有多少个元电荷？（$e=1.6\times10^{-19}\,C$） 解析：$n=\frac{Q}{e}=\frac{2}{1.6\times10^{-19}}=1.25\times10^{19}$（个）。 关键：电荷量是元电荷的整数倍，利用 $Q=ne$ 可互算。 **例4（验电器）** 用带电体接触验电器的金属球，金属箔为什么会张开？ 解析：带电体接触金属球后，电荷沿金属杆传到两片金属箔上，两片金属箔带同种电荷，因同种电荷互相排斥而张开。带电越多，排斥力越大，张角越大。 关键：验电器原理是同种电荷互相排斥。 **例5（导体绝缘体辨析）** 为什么铜导线容易导电，而塑料外皮不容易导电？摩擦起电实验中为什么用橡胶棒而不用金属棒？ 解析：铜导线内部有大量能自由移动的自由电子，故容易导电；塑料内部几乎没有自由电荷，故不易导电。若用金属棒做摩擦起电实验，摩擦所带的电荷会通过金属棒和手（导体）迅速转移走，无法检验带电；用橡胶（绝缘体）能把电荷"留住"。 关键：导体有自由电荷能导电，绝缘体没有，二者用途不同。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念识记

  1. 1. 自然界有几种电荷？它们分别如何规定？电荷间相互作用的规律是什么？
    答：自然界只有正、负两种电荷。规定：用丝绸摩擦过的玻璃棒所带的电荷叫正电荷，用毛皮摩擦过的橡胶棒所带的电荷叫负电荷。规律：同种电荷互相排斥，异种电荷互相吸引。
  2. 2. 验电器是根据什么原理工作的？它有什么作用？
    答：验电器是根据"同种电荷互相排斥"的原理工作的。作用：检验物体是否带电（接触金属球，金属箔张开说明物体带电），并能通过张角大小粗略比较带电的多少；它不能直接判断电荷的种类。

中等 · 现象解释

  1. 1. 为什么用塑料梳子梳干燥的头发后，梳子能吸引碎纸屑？
    答：梳头时梳子与头发摩擦，发生电子的转移，梳子带上电荷成为带电体；带电体具有吸引轻小物体的性质，故能吸引碎纸屑。头发与梳子带异种电荷，头发有时还会被梳子吸引竖起。
  2. 2. 金属棒、橡胶棒、石墨、塑料、人体、食盐水、干燥空气、玻璃中哪些是导体？为什么金属容易导电而橡胶不容易导电？
    答：导体：金属棒、石墨、人体、食盐水。绝缘体：橡胶棒、塑料、干燥空气（潮湿空气可变导体）、玻璃。金属容易导电是因为内部有大量可自由移动的自由电子；橡胶不容易导电是因为内部几乎没有能自由移动的电荷。

难 · 推理判断

  1. 1. 甲、乙、丙三个带电小球，甲与乙相斥，乙与丙相吸。若甲带负电，判断乙、丙各带什么电。
    答：甲与乙相斥，说明甲、乙带同种电荷，甲带负电，则乙带负电；乙与丙相吸，说明乙、丙带异种电荷，则丙带正电。所以乙带负电、丙带正电。
  2. 2. 一带正电的验电器，用一物体接触其金属球后，金属箔张角先变小再变大。试分析该物体带什么电，并说明判断过程。
    答：该物体带负电。判断过程：物体先接触时带负电的电荷与金属箔上的正电荷中和，张角变小；若物体带电量足够大，中和后有多余负电荷传到金属箔，两片箔带同种负电荷，张角又变大。若物体不带电，张角只会变小而不会重新变大；若带正电，张角会增大。

综合 · 实验探究

  1. 1. 设计实验比较塑料梳子与玻璃棒哪个对电子束缚本领强，并预测结果。
    答：方案：用丝绸摩擦玻璃棒、用毛皮摩擦塑料梳子（或二者互相摩擦），分别靠近带电的已知物体（如丝绸摩擦过的玻璃棒）判断带电种类；也可将二者互相摩擦后靠近，观察相互作用。若玻璃棒与梳子摩擦，玻璃棒得电子则说明梳子束缚电子本领强。更规范做法：取丝绸摩擦过的玻璃棒（已知带正电），将塑料梳子摩擦头发后靠近它，若相吸则梳子带负电，说明梳子束缚电子的本领比玻璃棒强。
  2. 2. 生活中的静电：干燥冬天摸金属门把手常被"电"一下。用摩擦起电知识解释该现象，并说明怎样减少静电危害。
    答：人在走动、穿衣时，鞋底与地面、衣服与衣服摩擦，使人体带上静电；人靠近接地的金属门把手时，电荷发生转移（放电），使人感到"电"击。减少静电危害的方法：①保持环境湿润，减少摩擦起电与电荷积累；②穿棉质衣物、少穿化纤；③触摸金属前先用手接触墙壁等放掉静电，或使用防静电的钥匙等导体放电。

💬 课后反馈

两种电荷是电学入门关键。学生易错点集中：记反丝绸玻璃棒（正）与毛皮橡胶棒（负）；误以为摩擦起电"创造"了电荷；把"吸引"一律当成异种电荷相吸，忽略了带电体能吸引轻小物体。建议用大量演示实验与小实验（梳子吸纸屑、气球摩擦吸附）建立感性认识，再通过推理题强化"排斥定同种、吸引不一定异种"的逻辑，并用电子得失模型讲清摩擦起电实质。
