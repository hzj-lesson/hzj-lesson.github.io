初中八年级语文《古诗：钱塘湖春行》教案

初中八年级语文古诗：钱塘湖春行

📝 备课方案

**教学目标** 1. 有感情地诵读并背诵《钱塘湖春行》，能准确默写全诗，读准「没」「贾」等易错字音。 2. 理解诗意，抓住「早莺」「新燕」「浅草」「乱花」等意象，把握西湖早春的景物特征。 3. 学习诗人「移步换景」的写法，赏析「争」「啄」「没」等炼字之妙，体会诗歌的语言美。 4. 感受诗人对西湖早春景色的喜爱与赞美之情，培养热爱自然、热爱生活的情怀。 **教学重点**：把握早春景物的特征，理解诗歌的思想感情。 **教学难点**：赏析「移步换景」的构思与「炼字」艺术，体会情景交融的写法。 **教学方法**：诵读法、品读法、想象联想法、比较阅读法。 **教学准备**：西湖春景图片或视频、课文朗读音频、多媒体课件、预习学案。 **课时安排**：1 课时（诵读感知—品析景物—探究手法—拓展迁移）。

📖 课堂讲义 · 核心知识点

**一、作者简介与创作背景** 白居易（772-846），字乐天，晚号香山居士，祖籍太原，生于河南新郑，唐代伟大的现实主义诗人。他是新乐府运动的倡导者，主张「文章合为时而著，歌诗合为事而作」，诗风平易通俗、明白晓畅，与元稹并称「元白」。长庆二年（822）秋，白居易出任杭州刺史，长庆三年（823）早春，他游览西湖，写下《钱塘湖春行》。钱塘湖即今杭州西湖。「春行」点明诗的内容与方式：在春天里信步游赏，边走边看，移步换景。 **二、诵读全诗，读准字音** 孤山寺北贾亭西，水面初平云脚低。 几处早莺争暖树，谁家新燕啄春泥。 乱花渐欲迷人眼，浅草才能没马蹄。 最爱湖东行不足，绿杨阴里白沙堤。 注音：贾亭的「贾」读 jiǎ（贾公亭）；「没马蹄」的「没」读 mò，意为遮没、盖过；「堤」读 dī，不读 tí；「啄」读 zhuó。 译文参考：从孤山寺的北面到贾公亭的西面，春水初涨，水面与堤岸齐平，空中云气低垂，与水面相接。几处早出的黄莺争着飞向向阳的树枝，谁家新归的燕子正在衔泥筑巢。繁花渐渐要让人眼花缭乱，浅草刚刚能够遮没马蹄。我最爱西湖东边的美景，总也游赏不够，杨柳成荫下的白沙堤让人流连忘返。 **三、整体把握：早春的「早」字诀** 全诗紧扣一个「早」字，写尽早春独有的景物特征：水面「初平」，是春水初涨尚未大涨；「早莺」是初春才来的黄莺；「新燕」是开春刚归的燕子，「啄春泥」正是它们忙碌筑巢之时；「乱花」是春花初放、渐多而未盛；「浅草」是草刚长出、短浅未深，「才能没马蹄」恰好写出草之浅——若草深了，马蹄便看不见了。诗中所写，是早春，不是仲春、暮春，处处扣住「初」「早」「新」「渐」「才」这些暗示时间的字眼，季节特征极为鲜明。 **四、结构梳理：移步换景，行云流水** 诗人从「孤山寺北」出发，行至「贾亭西」，一路赏玩；颔联写空中与树上的莺燕，颈联写脚下的花草，最后行至「湖东」「白沙堤」，以「最爱」收束。全诗以游踪为线索，随着脚步的移动，画面一一展开：远处是「水面初平云脚低」的湖面，近处是「争暖树」「啄春泥」的莺燕，脚下是「渐欲迷人眼」的花、「才能没马蹄」的草，最后定格在「绿杨阴里白沙堤」。一路行来，一路景，处处有诗人的身影与视线，这就是「移步换景」。 **五、逐联赏析：景中含情，字字传神** 1. 首联「孤山寺北贾亭西，水面初平云脚低」：交代游踪起点，勾勒湖上远景。「初平」写春水初涨、与堤岸齐平，「云脚低」写云气低垂、仿佛贴着湖面。水天一色、云水相连，是早春特有的湖光，气象开阔而宁静。 2. 颔联「几处早莺争暖树，谁家新燕啄春泥」：由面到点，写禽鸟报春。「争」字写黄莺争飞向向阳的树枝，将莺儿抢暖的活泼情态写得栩栩如生；「啄」字写燕子衔泥筑巢，忙碌而欣喜。一个「几处」一个「谁家」，表明莺燕尚少，正是早春；而「早莺」「新燕」的「早」「新」二字，又把春的讯息点得明明白白。「争暖树」「啄春泥」一上一下、一在空中一在檐下，俯仰生姿。 3. 颈联「乱花渐欲迷人眼，浅草才能没马蹄」：由高到低，写花草初盛。「乱花」指春花繁多、开得繁盛而纷杂，「渐欲迷人眼」写出花由少渐多、使人应接不暇的过程，一个「渐」字暗示春意日浓；「浅草才能没马蹄」写草刚能遮没马蹄，以马的蹄子作参照，把「浅」写得具体可感。花的繁丽与草的浅嫩，一纵一收，正是早春的平衡之美。 4. 尾联「最爱湖东行不足，绿杨阴里白沙堤」：直抒胸臆，点明主旨。「最爱」二字是全诗感情的喷口，「行不足」言游赏不尽、流连忘返；「绿杨阴里白沙堤」以绿柳白堤收束画面，色彩明净，余韵悠长，诗人陶醉于春光的形象呼之欲出。 **六、炼字艺术举隅** | 字词 | 妙处 | |---|---| | 初平 | 「初」写水刚涨，「平」写水与堤岸齐平，早春湖水的特征尽出 | | 争 | 拟人化，写黄莺抢飞向阳暖枝，写出春的生机与热闹 | | 啄 | 写燕子衔泥筑巢的忙碌，动态传神，透出新春的忙碌与欢欣 | | 渐欲 | 「渐」写春花由少而多、由疏而密的过程，照应「早春」 | | 没 | 写浅草遮没马蹄，以马蹄为参照物，浅草之「浅」具体可感 | | 行不足 | 「不足」即不够，直言游赏不尽，情深意切 | **七、思想感情：最爱，最是深情** 全诗无一句脱离景物，却处处见情：早莺争树、新燕啄泥是诗人眼中欣悦的春讯，乱花浅草是诗人脚下轻快的美景，「最爱湖东行不足」更将这份喜爱之情直陈而出。诗人写早春，不只是写风景，更是写一种对生活、对自然由衷的热恋。这种「借景抒情、情景交融」的写法，使诗虽无一句议论，却让人感到诗人满满的爱意。 **八、拓展积累** 1. 白堤与西湖：白沙堤即白堤，又名「白公堤」，相传白居易任杭州刺史时主持修筑（今考与白堤为后人附会，一说为纪念白居易）。诗中的孤山寺、贾亭、湖东、白沙堤，今均为西湖著名景致。 2. 西湖咏春名句比较：苏轼「欲把西湖比西子，淡妆浓抹总相宜」写西湖之空灵；杨万里「接天莲叶无穷碧，映日荷花别样红」写夏荷之绚烂；白居易本诗则专写早春之清新，三者可对照品读。 3. 读诗方法提示：读律诗宜「起承转合」地看——首联起（游踪总起）、颔联承（承接细写）、颈联转（换角度转写）、尾联合（直抒收束），把握结构能更快读懂诗意。

🔍 课堂讲义 · 重点难点解析

**重点一：把握早春景物的特征** 例题：《钱塘湖春行》所写是西湖的「早春」之景，请结合诗句具体说说诗人是如何写出「早」的特点的。 分析：抓住诗中暗示季节的词语（初、早、新、渐、才、浅）及典型景物逐句分析。 解答：诗人从多个角度扣「早」：首联「水面初平」写春水初涨，一个「初」字点出早春；颔联「早莺」「新燕」直点「早」「新」，黄莺初啼、燕子新归，且「几处」「谁家」说明莺燕尚少、只是报春之初；颈联「乱花渐欲迷人眼」以「渐欲」写春花由少变多的过程，「浅草才能没马蹄」写草尚短浅，「才」「浅」二字更是早春的铁证。诗中没有一处写「早」，却处处是早春之景，季节感极强。 小结：答「如何写出早春」要「列意象—扣字眼—说特征」，条理清晰。 **难点一：理解「移步换景」的写法** 例题：题目中的「行」字，有人认为不只是「行走」之意，还暗含诗歌的结构线索。请结合全诗谈谈你的理解。 分析：抓住地点词（孤山寺北、贾亭西、湖东、白沙堤）与动作描写的次序，说明「行」如何贯穿全篇。 解答：全诗以「行」为线索，移步换景：诗人从孤山寺北出发，走到贾亭之西，一路所见由远及近、由高到低——先是湖面云脚，再是树上莺燕，然后是脚下花草，最后行至湖东白沙堤，为绿杨阴里之美所陶醉，「行不足」直言游兴未尽。诗中地点词如镜头分镜，一步一景、步步有景，诗人的身影始终在画面中，「行」既是动作，更是结构上的线索，把分散的景物串成一条流动的风景线。 小结：分析结构线索要「标出地点词—理顺游踪—说明怎样串景」。 **难点二：赏析「几处早莺争暖树」中「争」字的妙处** 例题：「争」字是这首律诗诗眼式的字，请赏析其表达效果。 分析：从「拟人手法」「动态画面」「早春生机」「情感投射」四层分析。 解答：「争」字将黄莺人格化：初春料峭，几只早莺争着飞向朝阳的暖枝，仿佛在竞抢春光。一个「争」字，写出了莺儿活泼好胜的情态，化静为动、化景为活；同时「争」暗含时间的紧迫与春意的萌动，黄莺尚少（几处）却已争抢暖树，恰是早春生机初发的写照；诗人以欣赏的眼光写这场「争」，喜悦之情也隐含其中。可谓一字之中，景、情、季三得。 小结：赏析动词「诗眼」采用「释字义—写画面—点手法—说情感」的固定思路。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：理解诗意，落实字词** 题目：解释下列加点的词语。（1）水面初平（初： ）（2）云脚低（云脚： ）（3）早莺争暖树（暖树： ）（4）浅草才能没马蹄（没： ）（5）最爱湖东行不足（行不足： ） 分析：结合课下注释，注意「没」是多音多义字，此处读 mò。 解答：（1）初：刚刚。（2）云脚：接近地面的云气。（3）暖树：向阳的树。（4）没：遮没，盖过。（5）行不足：游赏不尽，不够。 方法小结：古诗词词语理解要依托注释、紧扣语境，多音字依义定音。 **例题二（提高）：赏析颈联「乱花渐欲迷人眼，浅草才能没马蹄」** 题目：这首诗颈联是千古名句，请从炼字角度赏析「乱」「浅」「渐」「才」等字的妙处。 分析：逐字赏析要有分工：「乱」「浅」写景物状态，「渐」「才」写变化分寸，最后落到早春特征与诗人的喜悦上。 解答：「乱花」指春花繁盛纷杂，「乱」写出花之繁多、浓密，是视觉上的目不暇接；「渐欲迷人眼」的「渐」暗示花是由少到多、渐渐繁盛的，正扣「早春」；「浅草」写草之短嫩，「才能没马蹄」的「才」字极妙——草刚够遮没马蹄，再多一分草就深了，再少一分又遮不住，「才」精确地写出了早春之草不深不浅的分寸感，也借马蹄这一参照物使「浅」具体可感。一花一草、一繁一浅，相映成趣，诗人的欣赏与喜悦溢于言表。 方法小结：多字炼字赏析宜分组分析，每个字都要「落回全诗」，点出与「早春」主题的关联。 **例题三（综合）：比较阅读，品味不同的西湖** 题目：比较阅读白居易《钱塘湖春行》与苏轼《饮湖上初晴后雨》，说说两位诗人笔下的西湖有何不同。 分析：从季节、景物侧重、表现手法、情感格调四方面比较，先各自归纳再对照。 解答：白居易写的是早春的西湖，以「行」为线移步换景，聚焦莺燕花草等具体物候，工于炼字，风格平易清新，情感是直白的喜爱（「最爱」）；苏轼写的是晴雨中的西湖，以比喻统摄全湖，「欲把西湖比西子，淡妆浓抹总相宜」，虚写湖的光影气象，风格空灵含蓄，情感是抽象的赞叹。一个以实景见长，一个以神韵取胜，恰如西湖的两种名片。 方法小结：比较诗歌先选准比较点（季节、意象、手法、情感、语言），再逐项对照，忌笼统空泛。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 默写、字音与文学常识

  1. 1. 默写《钱塘湖春行》全诗，要求字迹工整、一字不差。
    答：孤山寺北贾亭西，水面初平云脚低。几处早莺争暖树，谁家新燕啄春泥。乱花渐欲迷人眼，浅草才能没马蹄。最爱湖东行不足，绿杨阴里白沙堤。注意「贾亭」的「贾」读 jiǎ；「没马蹄」的「没」读 mò。
  2. 2. 按原文填空：几处早莺争暖树，（ ）。乱花渐欲迷人眼，（ ）。
    答：谁家新燕啄春泥；浅草才能没马蹄。注意「啄」字写法，右边是「啄」不能丢一点。
  3. 3. 给加点字注音：贾亭（ ） 啄春泥（ ） 没马蹄（ ） 白沙堤（ ）
    答：贾 jiǎ；啄 zhuó；没 mò；堤 dī。注意「堤」不读 tí，「没」此处不读 méi。
  4. 4. 填空：《钱塘湖春行》的作者是（ ）代诗人（ ），字乐天，号（ ），他是（ ）运动的倡导者。诗题中的「钱塘湖」即今（ ）。
    答：唐；白居易；香山居士；新乐府运动；杭州西湖。「钱塘湖」是西湖的古称。

中等 · 诗意理解与早春特征

  1. 1. 诗中哪些词语直接或间接表明所写是「早春」？请至少找出四处并简要说明。
    答：①「水面初平」——「初」写水刚涨；②「早莺」——早出的黄莺，报春之鸟；③「新燕」「啄春泥」——燕刚归来即衔泥筑巢，正是开春景象；④「浅草才能没马蹄」——草尚短浅，「才」写草刚刚没过马蹄；⑤「乱花渐欲迷人眼」——「渐」写花由少渐多。任选四处即可。
  2. 2. 颔联「几处早莺争暖树，谁家新燕啄春泥」中，诗人为什么要用「几处」而不用「处处」？
    答：因为所写是早春：早春时莺燕尚少，只是「几处」黄莺、「谁家」新燕，还远远不到「处处」「家家」的暮春热闹；用「几处」「谁家」既准确写出早春禽鸟稀疏的特征，又留有悬念、耐人寻味，透出诗人细察春讯的欣喜。
  3. 3. 「最爱湖东行不足」一句在全诗中起什么作用？
    答：结构上收束全诗，点明行踪终点在「湖东白沙堤」，与首联的游踪起点呼应，完成移步换景的完整路线；内容上直抒胸臆，用「最爱」二字把前面写景中蕴含的喜爱之情明朗化，「行不足」写流连忘返之态，是全诗情感的喷口与主旨所在。

难 · 炼字与手法鉴赏

  1. 1. 赏析「谁家新燕啄春泥」中「啄」字的表达效果。
    答：「啄」字写燕子衔泥筑巢的动作：春燕初归，正忙碌地啄取春泥垒窝。一个「啄」字把燕子筑巢的动态写得具体真切，有声音、有画面；它与「争暖树」的「争」上下呼应，黄莺争树、燕子啄泥，一上一下，共同渲染出早春万物复苏、忙碌而欢欣的生机，也含蓄传达出诗人对新春的欣喜之情。
  2. 2. 这首诗在写法上主要运用了「移步换景」，请结合诗句梳理诗人的游踪并说说这样写的好处。
    答：游踪：孤山寺北—贾亭西—湖上（水面云脚）—树上（早莺）—檐下（新燕）—脚下（花草）—湖东白沙堤。好处：以「行」为线索串联各景，一步一景、景随步移，画面层次分明、开阔有致（由远及近、由高到低、由面到点），使诗歌结构清晰、浑然一体；同时处处保留诗人的视角与身影，便于在写景中自然流露「最爱」之情。
  3. 3. 有人认为《钱塘湖春行》的妙处在于「无一字不言早春」，请结合全诗任选三个字词加以印证。
    答：示例：①「初」——「水面初平」写春水初涨，是早春水态；②「早」「新」——「早莺」「新燕」直点季节，莺燕初到；③「渐」——「乱花渐欲」写花由少到多，是早春进行时；④「才」——「才能没马蹄」写草刚没过马蹄，浅草初生；⑤「低」——「云脚低」写早春水气上升、云气低垂贴水。任选三处，能点明其「早春」含义并分析表达效果即可。

综合 · 情境运用与微写作

  1. 1. 情境默写：①春天校园里，几只黄莺在朝阳的树枝上跳跃鸣叫，你想用《钱塘湖春行》中的句子来描绘，可用（ ）。②小明写作文《春游西湖》，结尾想引用一句表达对西湖美景流连忘返的诗句，可用（ ）。
    答：①「几处早莺争暖树」；②「最爱湖东行不足，绿杨阴里白沙堤」或「最爱湖东行不足」。引用须与原句一字不差，注意与情境匹配。
  2. 2. 微写作：请你以「春游」为题，用一段 120 字左右的文字，模仿《钱塘湖春行》「移步换景」的写法，记录你的一次游春见闻，并至少用上两个本诗中学到的炼字（如「争」「啄」「没」等）。
    答：示例：出了校门向东，拐上河堤。河水初涨，漫到堤脚，一两只燕子低飞，掠着水面啄起细泥。转过柳丛，一片早樱正开，花密处几乎迷了眼；脚下草芽才冒头，刚够没过鞋面。再往前是田埂，两头小牛在渠边抢着新草，你争我夺，好不热闹。最爱的还是堤尽头的菜畦，风过处绿浪起起伏伏，让我怎么也走不够。评分要点：移步换景线索清晰、炼字使用恰当、语言通顺有画面感。
  3. 3. 微写作：白居易眼中的西湖早春「草长莺飞」，请为西湖早春设计一句宣传语，要求化用本诗中的意象，并说明你的设计理由（80 字左右）。
    答：示例：宣传语「早莺争暖树，春水绿如蓝——西湖邀您赶一场最早的春天」。理由：化用「早莺争暖树」的意象，突出「早春」这一西湖旅游的独特卖点；「争暖树」写出春的生机，与「水面初平」的宁静水景形成动静对比，既有画面又有号召力。评分要点：化用恰当、突出早春特色、理由表述清楚。

💬 课后反馈

**学生常见错误** 1. 默写错别字：「贾亭」误作「假亭」「甲亭」；「啄春泥」的「啄」误作「琢」「琢」；「白沙堤」的「堤」误作「提」；「绿杨阴里」误作「荫里」（教材用「阴」）。 2. 读音不准：「贾亭」读成 jiǎ 或 gǔ 混淆；「没马蹄」读成 méi；「白沙堤」读成 tí。 3. 概念混淆：「移步换景」与「借景抒情」混用，答题时不说明游踪只谈情感；「炼字」题只答「用得好」不说清好在哪里。 4. 早春特征把握不准：把「乱花渐欲迷人眼」理解成百花盛开、浓艳无比，忽略「渐欲」「才能」中「由少到多、恰到好处」的分寸感。 5. 情感单一化：只说「喜爱西湖」，说不清「早春」与「喜爱」之间的关系，也答不出「行不足」中游兴与春意的交织。 **教学改进建议** 1. 用「画游踪」法教结构：让学生在诗中圈出地点词，画出诗人的行走路线图，直观理解「移步换景」。 2. 用「换字比较」法教炼字：把「争」换成「飞」、「没」换成「盖」、「才」换成「刚能」，比较高下，让学生自己悟出原字的妙处。 3. 补充物候知识：结合早莺、新燕、浅草的物候特征讲解，帮助学生建立「诗中季节」的意识。 **分层辅导建议** - 基础层：重点抓背诵默写、字音字词与诗句翻译，用挖空默写滚动过关。 - 提高层：重点练炼字题与移步换景题，按「释字—画面—手法—情感」规范作答。 - 拓展层：比较《钱塘湖春行》与白居易《暮江吟》《忆江南》，归纳白诗语言风格，写比较赏析。 **给家长的建议** 1. 若有机会带孩子游西湖或其他公园，让孩子边逛边说「走到哪里看到什么」，练习移步换景的表达，回家再用本诗句式写一写。 2. 请孩子当「小老师」，把「早春为什么用『早莺』『新燕』『浅草』」讲给您听，讲清楚了才算真懂。
