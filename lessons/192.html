初中七年级数学相交线与平行线

📝 备课方案

**教学目标** 1. 理解邻补角、对顶角的概念，掌握对顶角相等的性质。 2. 掌握垂线、垂线段最短及点到直线距离的概念。 3. 掌握平行线的判定与性质，并能综合运用。 **教学重点**：平行线的判定与性质。 **教学难点**：判定与性质的条件、结论互逆关系的区分。 **教学方法**：动手操作（三角尺推平行线）、分类对比、变式训练。 **课时安排**：3 课时

📖 课堂讲义 · 核心知识点

**一、两条直线相交** - 两条直线相交形成 4 个角。 - 对顶角：两边互为反向延长线的两个角，对顶角相等。 - 邻补角：有一条公共边、另一边互为反向延长线，邻补角互补（和为 $180^\circ$）。 **二、垂线** - 垂线：两条直线相交成直角，其中一条是另一条的垂线，交点为垂足。 - 垂线公理：过一点有且只有一条直线与已知直线垂直。 - 垂线段最短：连接直线外一点与直线上各点的线段中，垂线段最短。 - 点到直线的距离：直线外一点到这条直线的垂线段的长度。 **三、同位角、内错角、同旁内角** - 两条直线被第三条直线所截形成 8 个角： - 同位角：在截线同旁、两直线同侧，形如"F"型，如 $\angle1$ 与 $\angle5$。 - 内错角：在截线两旁、两直线之间，形如"Z"型，如 $\angle3$ 与 $\angle5$。 - 同旁内角：在截线同旁、两直线之间，形如"U"型，如 $\angle4$ 与 $\angle5$。 **四、平行线** - 定义：在同一平面内，不相交的两条直线。 - 平行公理：经过直线外一点，有且只有一条直线与这条直线平行。 - 推论：如果两条直线都与第三条直线平行，那么这两条直线互相平行。 **五、平行线的判定（由角定线）** - 同位角相等，两直线平行。 - 内错角相等，两直线平行。 - 同旁内角互补，两直线平行。 - 平行于同一条直线的两条直线平行。 **六、平行线的性质（由线定角）** - 两直线平行，同位角相等。 - 两直线平行，内错角相等。 - 两直线平行，同旁内角互补。 **七、命题、定理与平移** - 命题：判断一件事情的语句，由题设和结论组成。 - 平移：把一个图形整体沿某一直线方向移动，平移前后对应点连线平行且相等，图形形状大小不变。

🔍 课堂讲义 · 重点难点解析

**重点：平行线的判定与性质的综合运用** 解题通法：① 由"已知角相等/互补"推出"两线平行"用判定；② 由"两线平行"推出"角相等/互补"用性质。注意判定与性质的条件与结论正好相反，可通过一句口诀记忆："由角推线用判定，由线推角用性质"。 **难点一：三种角的识别** 学生常混淆同位角、内错角、同旁内角。纠正方法：先找"截线"（与两直线都相交的第三条线），再观察两角相对于截线和被截线的位置，用"F""Z""U"三种基本图形帮助记忆。 **难点二：规范书写推理过程** 几何证明要求"∵（因为）… ∴（所以）…"的规范格式，每一步都要有依据。常见错误是跳步或把判定当性质混用。教学中应示范完整的推理格式，并要求学生每一步注明理由。 **迷你示例**：如图，直线 $a\parallel b$，$\angle1=60^\circ$，则 $\angle2=60^\circ$（同位角相等），$\angle3=120^\circ$（同旁内角互补，$180^\circ-60^\circ$）。

✏️ 课堂讲义 · 典型例题精讲

**例1**：如图，直线 AB、CD 相交于点 O，$\angle AOC=35^\circ$，求 $\angle BOD$ 与 $\angle BOC$。 解：$\angle BOD$ 与 $\angle AOC$ 是对顶角，所以 $\angle BOD=\angle AOC=35^\circ$；$\angle BOC$ 与 $\angle AOC$ 是邻补角，$\angle BOC=180^\circ-35^\circ=145^\circ$。 关键：对顶角相等、邻补角互补。 **例2**：如图，$\angle1=70^\circ$，$\angle2=70^\circ$，试说明 $a\parallel b$。 解：因为 $\angle1=\angle2=70^\circ$，而 $\angle1$ 与 $\angle2$ 是同位角，所以由"同位角相等，两直线平行"得 $a\parallel b$。 关键：先判断角的类型，再选用对应判定定理。 **例3**：如图，$a\parallel b$，$\angle1=50^\circ$，求 $\angle2$。 解：因为 $a\parallel b$，所以同位角相等，$\angle2=\angle1=50^\circ$。 关键：两直线平行是已知，用性质求角。 **例4**：如图，$AB\parallel CD$，$\angle1=110^\circ$，求 $\angle2$ 与 $\angle3$。 解：因为 $AB\parallel CD$，$\angle1$ 与 $\angle2$ 是同旁内角，所以 $\angle2=180^\circ-\angle1=70^\circ$；$\angle3$ 与 $\angle1$ 是内错角（或对顶角与 $\angle2$ 互补），所以 $\angle3=\angle1=110^\circ$。 关键：同旁内角互补，内错角相等，灵活转化角的位置关系。 **例5**：已知 $\angle1=\angle2$，试说明 $AB\parallel CD$（写出完整推理过程）。 解：因为 $\angle1=\angle2$（已知），又 $\angle2$ 与 $\angle3$ 是对顶角，所以 $\angle2=\angle3$（对顶角相等），于是 $\angle1=\angle3$（等量代换），所以 $AB\parallel CD$（内错角相等，两直线平行）。 关键：当两角不是"三线八角"中的直接角时，常需借助对顶角、邻补角进行等量代换。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 概念辨析

  1. 1. 填空：两条直线被第三条直线所截，若同位角相等，则两直线____；若两直线平行，则同旁内角____。
    答：平行；互补。理由是"同位角相等，两直线平行"是判定定理；"两直线平行，同旁内角互补"是性质定理。
  2. 2. 点到直线的距离是指什么？它与垂线段有什么关系？
    答：点到直线的距离是指从直线外一点到这条直线的垂线段的长度，是一个数值；垂线段是图形本身。距离是垂线段的长度，二者联系是"距离就是垂线段的长"。

中等 · 角度计算

  1. 1. ![平行线求角示意图](/images/hw-parallel-1.svg) 如图，$a\parallel b$，$\angle1=45^\circ$，求 $\angle2$、$\angle3$。
    答：因为 $a\parallel b$，$\angle1$ 与 $\angle2$ 是内错角，所以 $\angle2=\angle1=45^\circ$；$\angle3$ 与 $\angle1$ 是同位角（或 $\angle2$ 的邻补角），$\angle3=\angle1=45^\circ$。
  2. 2. ![平行线判定示意图](/images/hw-parallel-2.svg) 如图，$\angle1+\angle2=180^\circ$，且 $\angle1=60^\circ$，$\angle3=120^\circ$，试说明 $l_1\parallel l_2$。
    答：因为 $\angle1+\angle2=180^\circ$，所以 $\angle2=180^\circ-60^\circ=120^\circ$；又 $\angle3=120^\circ$，所以 $\angle2=\angle3$，而 $\angle2$ 与 $\angle3$ 是同位角，故 $l_1\parallel l_2$（同位角相等，两直线平行）。

难 · 推理证明

  1. 1. ![平行线折角示意图](/images/hw-parallel-3.svg) 如图，$AB\parallel CD$，$\angle B=40^\circ$，$\angle D=50^\circ$，过点 E 作 $EF\parallel AB$，求 $\angle BED$。
    答：因为 $EF\parallel AB$ 且 $AB\parallel CD$，所以 $EF\parallel CD$。因为 $EF\parallel AB$，$\angle B$ 与 $\angle BEF$ 是内错角，$\angle BEF=40^\circ$；因为 $EF\parallel CD$，$\angle D$ 与 $\angle DEF$ 是内错角，$\angle DEF=50^\circ$。所以 $\angle BED=\angle BEF+\angle DEF=40^\circ+50^\circ=90^\circ$。关键：过拐点作平行线，把角"转移"到两条平行线之间。
  2. 2. ![平行线折角示意图](/images/hw-parallel-4.svg) 如图，$AB\parallel CD$，点 E 在 AB、CD 之间，$\angle A=35^\circ$，$\angle C=50^\circ$，过点 E 作 $EF\parallel AB$，求 $\angle AEC$。
    答：因为 $EF\parallel AB$ 且 $AB\parallel CD$，所以 $EF\parallel CD$。$\angle A$ 与 $\angle AEF$ 是内错角，$\angle AEF=\angle A=35^\circ$；$\angle C$ 与 $\angle CEF$ 是内错角，$\angle CEF=\angle C=50^\circ$。所以 $\angle AEC=\angle AEF+\angle CEF=35^\circ+50^\circ=85^\circ$。

综合 · 综合应用

  1. 1. 把命题"对顶角相等"写成"如果…那么…"的形式，并判断其真假。
    答：写成：如果两个角是对顶角，那么这两个角相等。该命题是真命题，因为两条直线相交所成的对顶角一定相等。
  2. 2. 三角形 ABC 平移到三角形 A′B′C′，点 A 移到点 A′，已知 AA′=5 cm，则 BB′ 与 CC′ 的长度各是多少？为什么？
    答：$BB'=5$ cm，$CC'=5$ cm。因为平移只改变图形位置，不改变形状大小，且平移前后对应点的连线平行且相等，所以 $BB'=CC'=AA'=5$ cm。

💬 课后反馈

相交线与平行线是初中几何推理的入门，学生初次接触"因为…所以…"的证明格式，需要大量规范示范。教学中应强调判定与性质的条件结论互逆关系，借助"F、Z、U"图形识别三类角，并通过添加辅助线（过拐点作平行线）体会转化的思想。
