初中九年级语文《古诗：行香子·树绕村庄》教案

初中九年级语文古诗：行香子·树绕村庄

📝 备课方案

**教学目标** 1. 反复诵读《行香子·树绕村庄》，读出词作的节奏与韵律，能熟练背诵并准确默写。 2. 理解词的内容，抓住「树绕村庄，水满陂塘」等画面，体会词人对田园春光的热爱与流连。 3. 学习白描手法，品味「有桃花红，李花白，菜花黄」「正莺儿啼，燕儿舞，蝶儿忙」等句在色彩、动静上的表现力。 4. 了解词牌「行香子」的一般知识，初步感受婉约词清新明快的风格，提高词作鉴赏能力。 **教学重点**：理解词意，赏析白描手法与画面中的色彩、动静之美。 **教学难点**：体会「一切景语皆情语」——从纯写景中读出词人的心情；辨析上下片写景视角的变化。 **教学方法**：诵读法、想象画面法、点拨赏析法、比较阅读法。 **教学准备**：课文朗读音频、春日田园图片或视频、多媒体课件、预习学案。 **课时安排**：1 课时（诵读—析景—悟情—拓展）。

📖 课堂讲义 · 核心知识点

**一、作者简介** 秦观（1049-1100），字少游，又字太虚，号淮海居士，高邮（今江苏扬州）人，北宋词人。他是「苏门四学士」之一，与黄庭坚、晁补之、张耒齐名。秦观的词多写男女恋情、离愁别恨，风格委婉含蓄、清丽淡雅，是婉约派的代表词人，有「山抹微云学士」之称。这首《行香子》却一洗他惯常的婉约凄清，写得轻快明朗、情趣盎然，表现了他词风多样的一面。 **二、词牌小知识** 「行香子」是词牌名，双调六十六字，上片五平韵，下片五平韵（上下片各五句四平韵，另有变格）。词牌规定了词的句式、字数与平仄，是词的音乐格式的标记，与词的内容没有必然联系。本词上下片都以三组三字句（如「桃花红，李花白，菜花黄」）作结，两两相对，读来节奏明快、朗朗上口，是「行香子」词牌的典型句法。 **三、诵读全词，把握节奏** 树绕村庄，水满陂塘。倚东风、豪兴徜徉。小园几许，收尽春光。有桃花红，李花白，菜花黄。 远远围墙，隐隐茅堂。飏青旗、流水桥旁。偶然乘兴、步过东冈。正莺儿啼，燕儿舞，蝶儿忙。 注音：「陂塘」的「陂」读 bēi；「徜徉」读 cháng yáng；「几许」的「几」读 jǐ；「飏」读 yáng，同「扬」；「东冈」的「冈」读 gāng。 诵读时注意：上片「有」字领起三个三字句，一气贯通；下片「正」字领起三个三字句，轻快上扬，要读出春日生机跃动之感。 **四、疏通词意** 绿树环绕着村庄，春水溢满了池塘。迎着春风，乘着兴致，自在闲游。小小的园子装不满春意，却把大好春光都收进了门里：有粉红的桃花，雪白的李花，金黄的菜花。 远远地望见围墙，隐约有几间茅屋。春风中飘扬着一面青布酒旗，流水潺潺，横跨小桥。我乘着兴致，步过东边的山冈。正好有黄莺在啼唱，燕子在飞舞，蝴蝶在忙碌。 **五、上片赏析：村野春色，满目春光** 1. 开篇两句「树绕村庄，水满陂塘」以白描勾勒大环境：绿树环抱村庄，春水涨满池塘，「绕」「满」二字写出春的丰盈与安详，一个「满」字尤其精妙，既写水，更暗写春雨绵绵、春水充沛的时节特征。 2. 「倚东风、豪兴徜徉」由景及人：词人迎着东风、乘兴闲游，「豪兴」点明游兴之浓，「徜徉」写从容自在的步态，情与景会，一派轻快。 3. 「小园几许，收尽春光」由大及小：园子虽小，却「收尽春光」，极言园中春色之盛、之全，是全词的点睛之笔，为下文铺陈园中花草蓄势。 4. 「有桃花红，李花白，菜花黄」色彩铺陈：三个三字句，名词加颜色词，纯用白描、不施藻饰，红、白、黄三色交相辉映，明丽鲜艳，是视觉上的盛筵。三句排比，节奏短促轻快，与游园赏春的欢快心情相合。 **六、下片赏析：远村闲趣，莺燕蝶忙** 1. 「远远围墙，隐隐茅堂」由近及远：视线越过墙垣，望见茅屋，「远远」「隐隐」两个叠词写出景物的隐约朦胧，层次分明，仿佛镜头缓缓推远。 2. 「飏青旗、流水桥旁」动静结合：青旗在风中飞扬，流水映着小桥，一静一动，把村落的烟火气与灵动感都写了出来。「青旗」即酒旗，暗示村野人家的闲适生活。 3. 「偶然乘兴、步过东冈」点出词人行踪：上片之「徜徉」是园内之游，此句「步过东冈」则走出园子，进一步将视野引向更广阔的田野。 4. 「正莺儿啼，燕儿舞，蝶儿忙」以声写动：三个三字句，黄莺啼、燕子舞、蝴蝶忙，「啼」「舞」「忙」三个动词把春天的生命活力写得灵动传神，虫鸟竞逐的热闹与上片花草的明丽相映成趣，词人对春光的喜爱也在这一片生机中自然流露。 **七、白描手法的艺术魅力** 白描原指中国画的绘画技法，即不用浓彩重墨渲染，只用简练的线条勾勒物象。本词全篇纯用白描：写村庄是「树绕村庄，水满陂塘」，写园中是「桃花红，李花白，菜花黄」，写村落是「远远围墙，隐隐茅堂」，写田野是「莺儿啼，燕儿舞，蝶儿忙」。词人几乎不用比喻、不用典故、不加修饰语，只把眼前景物如实排列，却色、声、动、静兼备，画面清晰如在目前。白描不等于简单，简淡的笔墨背后是词人对田园生活的熟悉与热爱，正所谓「看似寻常最奇崛」。 **八、景与情：一切景语皆情语** 这首词没有一句直接抒情，但处处是情：「豪兴徜徉」是情，「乘兴步过东冈」是情，「收尽春光」的欣喜是情，「莺儿啼，燕儿舞，蝶儿忙」的欢快更是情的投射。词人借明媚的春光、热闹的生机，含蓄地表达了厌倦尘嚣、热爱田园、向往恬淡闲适生活的情怀。与秦观其他多写愁绪的词相比，此词别开生面，可见其性情中明亮旷达的一面。 **九、拓展积累** 1. 田园春景的名句：孟浩然「绿树村边合，青山郭外斜」；王维「漠漠水田飞白鹭，阴阴夏木啭黄鹂」；辛弃疾「稻花香里说丰年，听取蛙声一片」。可与本词比照，感受不同诗人笔下的乡村之美。 2. 色彩铺陈的写法：《忆江南》「日出江花红胜火，春来江水绿如蓝」；杜甫「两个黄鹂鸣翠柳，一行白鹭上青天」，都以鲜明的色彩对比写景，与「桃花红，李花白，菜花黄」异曲同工。

🔍 课堂讲义 · 重点难点解析

**重点一：赏析上片「有桃花红，李花白，菜花黄」的表达效果** 例题：「有桃花红，李花白，菜花黄」三句历来为人称道，请从手法和语言两方面赏析其妙处。 分析：抓住「白描」「色彩」「排比短句」三个关键词，从修辞、句式、画面效果逐层分析。 解答：手法上，三句运用白描，不加修饰，只以「花名+颜色」直陈，如画家的调色盘，红、白、黄三种明艳的色彩并置，形成强烈的视觉冲击；句式上，三个三字句构成排比，节奏短促明快，读来朗朗上口，与游园赏春的轻快心情相应；效果上，「桃花红」「李花白」「菜花黄」由近到远、由园内到园外，层层铺开，把「小园收尽春光」的「收尽」二字落到实处，春色之盛、之全如在目前。 小结：赏析三字句要答出「白描+色彩+排比节奏」，并回扣「收尽春光」的线索作用。 **难点一：赏析下片「正莺儿啼，燕儿舞，蝶儿忙」与上片的关系** 例题：词下片以「正莺儿啼，燕儿舞，蝶儿忙」收束全篇，它与上片的花草描写构成怎样的呼应？ 分析：从动静关系、视听结合、生机呼应三个角度分析上下片的联系。 解答：上片写花，是静止的、视觉的画面，色彩明丽但无声音无动态；下片写虫鸟，是动态的、听觉与视觉结合的画面，「啼」「舞」「忙」三个动词让春天活了起来。上下片一动一静、一色一声，互相映衬：花的静衬出鸟蝶的动，鸟蝶的动又让花显得更精神。二者共同渲染了春日的繁荣生机，也完整地表达了词人对春光的热爱——他不仅爱其色，更爱其活力。 小结：分析上下片关系要抓住「动静」「视听」「色彩与生机」的对比与互补。 **难点二：体会「一切景语皆情语」** 例题：这首词通篇写景，没有一句直接抒情，为什么我们仍能感受到词人愉快的心情？ 分析：从词中表情的词语（豪兴、徜徉、乘兴）、景物的选择（都是美好的意象）、画面的整体氛围三方面作答。 解答：其一，词中直接出现「豪兴」「徜徉」「乘兴」等语，点明词人游春时兴致高昂；其二，词人选景处处透出喜悦——「满」的春水、「收尽春光」的小园、红白黄的明艳、啼舞忙的热闹，无不是令人赏心悦目之景，词人只写美景，正是因为他满心欢喜；其三，整个画面的基调是明快的，色彩亮丽、声响热闹、动静和谐，这样的景就是词人心情的外化。可见写景即写情，情景交融，含蓄隽永。 小结：体会「情」要「找关键词、看景物选择、品整体氛围」三步走。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：理解词意，落实字词** 题目：解释下列加点的词语。（1）水满陂塘（陂塘： ）（2）豪兴徜徉（徜徉： ）（3）小园几许（几许： ）（4）飏青旗（飏： ）（5）步过东冈（冈： ） 分析：结合语境与课下注释理解，注意「飏」为通「扬」。 解答：（1）陂塘：池塘。（2）徜徉：闲游，安闲自在地步行。（3）几许：多少，这里指范围小。（4）飏：飞扬，同「扬」。（5）冈：山冈。 方法小结：词中词语理解与古诗一致，重在结合语境、记牢课下注释。 **例题二（提高）：赏析画面与炼字** 题目：「水满陂塘」的「满」字、「绕树村庄」的「绕」字用得巧妙，请分别赏析。 分析：炼字赏析要「先释字义、再描画面、后说效果」。 解答：「绕」字写绿树环抱村庄之状，以静写动、化景为势，村落在绿树拱卫中显得安详宁静，透出家园的亲切感；「满」字写春水盈塘之状，既见春水充沛、池塘将溢的景象，又暗示春雨滋润、春意浓烈，仿佛能看见水波荡漾。「绕」是静的安详，「满」是盈的富足，二字一出，村庄的春光便有了魂。 方法小结：炼字题固定答法——释义（含活用/通假）→还原画面→点出手法→说效果（情或境）。 **例题三（综合）：比较阅读，品味不同的春日** 题目：《行香子·树绕村庄》与白居易《钱塘湖春行》都写春天的明媚生机，试从描写对象和抒情方式两方面比较二者的异同。 分析：分别概括两首诗词的描写对象与抒情方式，再对比异同。 解答：描写对象上，相同的是都写春日风光——秦观写村庄田园，白居易写西湖山水，都选取了富有春意的典型景物；不同的是秦观更重「面」的铺陈，花草虫鸟尽收笔底，白居易更重「点」的刻画，早莺、新燕、乱花、浅草各具早春特征。抒情方式上，二者都以景写情、情景交融，均无一句直露的抒情；但秦观以「豪兴」「乘兴」透出游兴，白居易则以「最爱湖东行不足」明言爱意，一含蓄一明朗，各得其妙。 方法小结：比较阅读按「同—异」两分作答，先定比较点（对象、手法、情感、风格），再逐项对应。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 默写、字音与词牌知识

  1. 1. 默写《行香子·树绕村庄》的上片：树绕村庄，（ ）。倚东风、（ ）。小园几许，（ ）。有（ ），（ ），（ ）。
    答：水满陂塘；豪兴徜徉；收尽春光；桃花红，李花白，菜花黄。注意「陂塘」的「陂」读 bēi、写法不可错，「徜徉」二字不能写反。
  2. 2. 默写《行香子·树绕村庄》的下片：远远围墙，（ ）。飏青旗、（ ）。偶然乘兴、（ ）。正（ ），（ ），（ ）。
    答：隐隐茅堂；流水桥旁；步过东冈；莺儿啼，燕儿舞，蝶儿忙。注意「飏」的写法（与「扬」通用）及「冈」不可误作「岗」。
  3. 3. 给加点字注音：陂塘（ ） 徜徉（ ） 几许（ ） 飏青旗（ ） 东冈（ ）
    答：陂 bēi；徜徉 cháng yáng；几 jǐ；飏 yáng；冈 gāng。注意「徜徉」不读 tǎng yáng。
  4. 4. 填空：这首词的作者是（ ）（朝代）词人（ ），字少游，号（ ），是「苏门四学士」之一。「行香子」是（ ）。
    答：北宋；秦观；淮海居士；词牌名。词牌规定词的句式、字数与平仄，与内容没有必然联系。

中等 · 词意理解与画面赏析

  1. 1. 词的上片写了哪些景物？请用简洁的语言描述这幅画面。
    答：上片写了绿树、村庄、春水、池塘、东风、小园以及桃花、李花、菜花。画面示例：绿树环抱着村庄，春水涨满了池塘，我迎着东风自在闲游；小小的园子却收尽了春光，粉红的桃花、雪白的李花、金黄的菜花开得正盛。
  2. 2. 「小园几许，收尽春光」中的「收尽」二字好在哪里？
    答：「收尽」意为全部收纳。园子虽小（「几许」言其小），却装下了全部的春光，以「小」衬「全」、以「少」写「多」，极言园中春色之丰富集中，为下文铺写桃花、李花、菜花蓄势，也透出词人赏春时的欣喜与满足。
  3. 3. 下片「远远围墙，隐隐茅堂」中连用「远远」「隐隐」两个叠词，有何表达效果？
    答：「远远」写墙与茅堂之远，「隐隐」写其朦胧隐约，两个叠词既使景物层次分明、空间感强，仿佛镜头由近及远缓缓推移，又渲染出村落古朴宁静的意境，音韵上也绵长舒缓，与全词明快之中见恬淡的情调相合。

难 · 手法鉴赏与炼字探究

  1. 1. 这首词在描写春天时主要运用了什么手法？请结合词句具体分析。
    答：主要运用白描手法，同时结合排比、动静结合。白描：如「树绕村庄，水满陂塘」「远远围墙，隐隐茅堂」，不用比喻修饰，只以简练线条勾勒景物；排比：「桃花红，李花白，菜花黄」「莺儿啼，燕儿舞，蝶儿忙」两组三字句，节奏明快；动静结合：上片花草是静态视觉，下片莺啼燕舞蝶忙是动态声像，一动一静相映成趣。词人几乎不着一字抒情，纯以白描造境，让春天本身的生机说话。
  2. 2. 「正莺儿啼，燕儿舞，蝶儿忙」三个动词「啼、舞、忙」各妙在哪里？
    答：「啼」写声音，黄莺鸣啭，以声入画；「舞」写姿态，燕子翻飞轻盈；「忙」写神情，蝴蝶穿梭采蜜，忙碌而欢快。三个动词分别从听觉、视觉与情态三个角度写虫鸟，把静止的春景写活、写闹，呈现出万物竞生的勃勃生机，也含蓄传出词人欣赏此景时内心的欢愉。
  3. 3. 有人认为末句「蝶儿忙」的「忙」字是点睛之笔，也有人认为整首词的妙处在于「不着一字，尽得风流」。请结合全词谈谈你的理解。
    答：两种说法并不矛盾，可以统一理解。「忙」字确实传神：一个「忙」字让蝴蝶有了人格化的情态，与前文「豪兴徜徉」的词人形成对照——连蝴蝶都在为春光忙碌，词人却从容闲游，越发显出他对田园闲适生活的珍爱。而全词又确实通篇白描，不直抒胸臆，只让景物自己呈现生机，让读者从画面中自行体会词人恬淡喜悦的心情，这正是「尽得风流」。可以说「忙」字点睛，使「风流」有了着落；白描造境，使「忙」字有了依托。

综合 · 情境运用与微写作

  1. 1. 情境默写：①小明到乡下姥姥家，看到绿树环村、春水满塘的景象，想引用《行香子》中的句子发朋友圈，可用（ ）。②学校广播站要播送一首描写春日田园热闹生机的词，请你从本词中选两句作为结语。
    答：①可用「树绕村庄，水满陂塘」或「有桃花红，李花白，菜花黄」；②可用「正莺儿啼，燕儿舞，蝶儿忙」或「小园几许，收尽春光」。答题注意引用与原句一字不差。
  2. 2. 微写作：请你仿照「有桃花红，李花白，菜花黄」的句式，为校园的秋天写三句景物描写，要求句式一致、色彩鲜明。
    答：示例：有枫叶红，银杏黄，菊花开（或「有梧桐黄，柿子红，桂花香」等）。仿写要点：采用「有+名词+颜色/状态」的三字句排比，景物有代表性，色彩突出，节奏明快。评分以句式、色彩、通顺为据。
  3. 3. 微写作：词人「偶然乘兴、步过东冈」，一路看尽春光。请你以词人的视角，为这次春日游写一段 120 字左右的游记，至少化用一处本词中的句子，写出所见与心情。
    答：示例：午后东风正好，我乘着兴致信步出园。回头看，小园虽小，却收尽春光——桃花红，李花白，菜花黄，好不热闹。抬眼望，远远的围墙边隐隐立着几间茅堂，青布酒旗在桥头风里飘摇。我步过东冈，忽听得黄莺脆啼，又见燕子翻飞、蝴蝶忙碌，仿佛整个春天都在我眼前活了过来。这样的光景，怎不叫人心旷神怡！评分要点：化用恰当、视角一致、景物与心情交融。

💬 课后反馈

**学生常见错误** 1. 默写错别字：「陂塘」误作「披塘」「波塘」；「徜徉」二字写反或误作「倘佯」；「飏青旗」误写「扬」或漏写；「东冈」误作「岗」。 2. 读音不准：「陂」读成 pí；「徜徉」读成 tǎng yáng；「几许」读成 jǐ 还是 jì 分不清（此处读 jǐ）。 3. 概念混淆：把「白描」说成「比喻」「拟人」；分不清「上片」与「下片」；误把「词牌名」当成「题目」。 4. 赏析空泛：分析「桃花红，李花白，菜花黄」只说「很美」，说不清白描、色彩并置与排比节奏的具体效果。 5. 情感把握偏差：因秦观词多写愁绪，有学生误以为此词也含淡淡的愁，读不出「豪兴」「乘兴」里的明朗欢快。 **教学改进建议** 1. 用「画中读词」法：让学生闭眼听读，把词中画面画出来或说出来，先建画面再析手法，避免架空分析。 2. 建立「白描与比喻、拟人」的对比表：给三组例句，让学生判断手法并说理由，强化概念辨析。 3. 抓住两组三字句做朗读训练：「有」字「正」字领起处重读，句与句之间快读连读，以声传情，读出欢快。 **分层辅导建议** - 基础层：重点抓背诵默写与字音字词，用挖空默写滚动巩固。 - 提高层：重点练画面描述与白描手法赏析，按「释词—析句—说效果」规范答题。 - 拓展层：比较秦观《行香子》与辛弃疾《西江月·夜行黄沙道中》的乡村夜昼之别，写比较短评。 **给家长的建议** 1. 周末带孩子去郊外或公园踏青，让孩子用词中的句子描述眼前春景，做不到就用「有……红，……白，……黄」的句式仿写，把课堂所学用进生活。 2. 请孩子把这首词背给您听，并讲一讲「词牌」和「白描」是怎么回事，当「小老师」最有利于巩固知识。
