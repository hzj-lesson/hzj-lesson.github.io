高中高三语文《文言文阅读与翻译》教案

高中高三语文文言文阅读与翻译

📝 备课方案

**教学目标** 1. 掌握高考文言文 18 个虚词的典型用法与意义，能结合语境辨析，扫清虚词理解障碍。 2. 积累并巩固 120 个常见文言实词的高频义项，学会运用语境推断、成语印证、语法分析等方法推断词义。 3. 掌握判断句、被动句、宾语前置、定语后置、状语后置、省略句等特殊句式，并能识别其标志性结构。 4. 熟练运用翻译"六字法"（留、删、补、换、调、贯）直译文言文，做到字字落实、句式调整、语意通顺。 **教学重点**：常见虚词的意义与用法辨析；特殊句式识别与翻译；翻译六字法的规范运用。 **教学难点**：一词多义的语境判定；省略成分的准确补充；偏义复词、词类活用与固定结构在翻译中的处理。 **教学方法**：知识梳理归纳法、语境推断训练法、翻译实操批改法，突出"积累为本、语境为纲、直译为主"。 **教学准备**：多媒体课件、18 虚词速记表、120 实词高频义项卡、近五年高考文言文真题与名家译文对照。 **课时安排**：共 2 课时。第 1 课时虚词实词与特殊句式梳理（归纳表、推断法），第 2 课时文言文翻译六字法专项训练（真题演练、译文批改、错译归类），并完成限时检测与小结。

📖 课堂讲义 · 核心知识点

**一、18 个虚词梳理** 18 虚词：而、何、乎、乃、其、且、若、所、为、焉、也、以、因、于、与、则、者、之。用"一虚一词卡"记用法再结合语境判定。如"而"可表并列（又）、承接（就）、递进（而且）、转折（却）、假设（如果）、修饰（地）；"以"作介词表工具（用）、凭借、原因，作连词表目的（来）、结果。辨析先看位置："以"后接名词多为介词，接动词多为连词。虚词题常考"意义和用法相同的一项"，须逐一比对。 **二、120 实词高频义项与推断** 高频义项集中在上古常用义。如"信"有诚信、使者、确实等义，"行李之往来"中"行李"指使者；"绝"有断绝、横渡、极等义，"而绝江河"中为横渡。推断四法：语境推断（看文意是否贯通）、语法推断（按成分定词性义项）、成语印证（借成语古义）、对文推断（对偶句对应词义相近相反）。 **三、特殊句式与翻译六字法** 判断句标志"……者……也""乃、即、为、是"；被动句标志"见……于""为……所""被"；宾语前置标志"疑问代词前置""否定句代词前置""之、是作标志"；定语后置标志"之……者"；状语后置标志"于、以"后置；省略句常省主语、宾语、介词。六字法："留"（专名不译）、"删"（删无义虚词）、"补"（补省略）、"换"（古今异义与活用换今语）、"调"（调倒装语序）、"贯"（意译贯通）。原则：字字落实，直译为主。

🔍 课堂讲义 · 重点难点解析

**重点一：虚词"其"的辨析** 例题：比较"其"意义用法，不同的一项：A 吾其还也；B 其皆出于此乎；C 其孰能讥之乎；D 尔其无忘乃父之志。 分析：四句"其"都在句首或谓语前，须结合语气判断。 解答：A 表商量（还是），B 表推测（大概），C 表反问（难道），D 表祈使（可要）。B 表推测，故答案 B。 小结：句首"其"多表语气，具体类别看语境。 **重点二：特殊句式** 例题：翻译"古之人不余欺也"。 分析："不余欺"为否定句代词宾语前置，正常语序"不欺余"。 解答：古代的人没有欺骗我啊。 小结：先找否定词与代词宾语，再还原语序。 **难点一：词义语境推断** 例题：翻译"衡下车，治威严……阴知奸党名姓"。 分析："下车"表到任，"阴"表暗中。 解答：张衡一到任就治理严厉……暗中查知奸党姓名。 小结：结合语境推断古今异义与副词义。 **难点二：偏义复词** 例题：翻译"昼夜勤作息"。 分析："作息"义偏在"作"，属偏义复词。 解答：日夜勤劳劳作。 小结：偏义复词只译意义实在的一方。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（虚词辨析）** 题目：意义和用法相同的一组：A 因击沛公于坐／相如因持璧却立；B 以勇气闻于诸侯／赵王岂以一璧之故欺秦邪；C 其闻道也固先乎吾／吾未见其明也；D 蚓无爪牙之利／句读之不知。 解析：A"因"分别为趁机、于是；B"以"分别为凭借、因为；C 两"其"均为代词，用法相同；D"之"分别为定语后置与宾语前置标志。故答案 C。 方法小结：先分别翻译确认，再比较。 **例题 2（实词与翻译）** 题目：翻译"后刺史臣荣举臣秀才，臣以供养无主，辞不赴命"，解释"举"。 解析："举"为举荐；"供养"指奉养祖母；"辞"为推辞；"举臣秀才"为省略句。 解答：后来刺史名荣的人举荐我做秀才，我因祖母无人奉养，推辞了任命，没有赴命。 方法小结：官职任免词与省略成分要准确处理。 **例题 3（综合翻译）** 题目：翻译"使天下之人，不敢言而敢怒，独夫之心，日益骄固"。 解析："独夫"指丧失人心的暴君；"日益"为一天比一天；"骄固"为骄横顽固。 解答：使得天下百姓，嘴上不敢说而心里敢愤怒，暴君的心一天比一天骄横顽固。 方法小结：议论句注意语气保留与情感传达，字字落实。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 基础巩固

  1. 1. 解释下列句中加点虚词"以"的意义与用法：（1）以刀劈狼首；（2）愿以十五城请易璧；（3）以是人多以书假余；（4）作《师说》以贻之。
    答：（1）用，介词，表工具；（2）用、拿，介词，表工具；（3）"以是"为"因此"，介词表原因；（4）来，连词，表目的。判定"以"的词性要看其后所接成分：接名词性成分多为介词，接动词性成分多为连词。
  2. 2. 解释下列句中加点实词"绝"的意义：（1）非能水也，而绝江河；（2）率妻子邑人来此绝境；（3）以为妙绝；（4）佛印绝类弥勒。
    答：（1）横渡；（2）与世隔绝的；（3）极、非常；（4）极、完全。"绝"在传记与论说文中高频出现，依语境取义。
  3. 3. 判断下列句子属于哪种特殊句式，并说明标志：（1）此天子气也；（2）身死人手，为天下笑；（3）句读之不知，惑之不解。
    答：（1）判断句，标志为"……也"；（2）被动句，标志为"为"；（3）宾语前置句，标志为"之"作宾语前置标志，正常语序为"不知句读，不解惑"。
  4. 4. 用"留、删、补、换、调、贯"分析翻译"永和九年，岁在癸丑，暮春之初"，应重点运用哪一步？
    答：重点运用"留"与"换"。"永和九年、癸丑、暮春"等年号、干支、时令词为专有名词可保留，其中"岁""之"可删或换，"暮春之初"换成现代说法"晚春三月初"，整句译为"永和九年，正是癸丑年，暮春三月初"。

中等 · 能力提升

  1. 1. 翻译下列句子并指出其中词类活用现象：（1）沛公军霸上；（2）项伯杀人，臣活之；（3）吾从而师之。
    答：（1）"军"名作动，驻军，译为"沛公在霸上驻军"；（2）"活"使动用法，使……活，译为"项伯杀了人，我使他活了下来"；（3）"师"意动用法，以……为师，译为"我跟从他并把他当作老师"。
  2. 2. 翻译："何陋之有？"并指出句式特点。
    答：译文为"有什么简陋的呢？"句中"何陋之有"是"之"作标志的宾语前置，正常语序为"有何陋"，疑问句中代词宾语"何陋"前置。
  3. 3. 辨析下列句中"乃"的意义：（1）设九宾于廷，臣乃敢上璧；（2）乃不知有汉，无论魏晋；（3）家祭无忘告乃翁；（4）度我至军中，公乃入。
    答：（1）才，副词，表条件；（2）竟然，副词，表出乎意料；（3）你的，代词；（4）才、再，副词。"乃"作副词常见"才、竟然、于是"，作代词表"你的"。
  4. 4. 翻译下面句子，注意补出省略成分："（烛之武）夜缒而出，见秦伯。"
    答：译文为"（烛之武）在夜里被人用绳子从城上放下来，出了城，拜见秦伯"。句中省略主语"烛之武"，翻译时应补出；"夜"为名词作状语，译为"在夜里"。

难 · 综合挑战

  1. 1. 翻译并分析句式："蚓无爪牙之利，筋骨之强，上食埃土，下饮黄泉，用心一也。"
    答：译文为"蚯蚓没有锋利的爪牙、强健的筋骨，却向上能吃到泥土，向下能喝到地下的泉水，这是因为它用心专一"。"爪牙之利、筋骨之强"为定语后置，正常语序为"利之爪牙、强之筋骨"；"上、下"为名词作状语；"用心一也"为判断句。
  2. 2. 解释下列句中"所以"的意义：（1）师者，所以传道受业解惑也；（2）所以遣将守关者，备他盗之出入与非常也。
    答：（1）"用来……的人（工具）"，表凭借，译为"老师，是用来传授道理、教授学业、解答疑难的人"；（2）"……的原因"，表原因，译为"派遣将领把守函谷关的原因，是防备其他盗贼进入和意外的变故"。"所以"两义不可混淆，看后文是陈述目的还是原因。
  3. 3. 翻译："求木之长者，必固其根本；欲流之远者，必浚其泉源。"并说明其论证手法。
    答：译文为"想要树木长得好，一定要使它的根牢固；想要河水流得远，一定要疏通它的源头"。两句对偶，先喻后理，为比喻论证（设喻说理），以"固本、浚源"喻指治国当"思国之安者，必积其德义"，语意层递。
  4. 4. 翻译下面文段中画线句并解释加点词："廉颇闻之，肉袒负荆，因宾客至蔺相如门谢罪。"（句中加点词为"因"）
    答："因"为经由、通过，介词，译为"廉颇听到这些话，就脱去上衣、背着荆条，通过门客引导到蔺相如门前请罪"。此处"因"作"经由"讲，表途径，与"因击沛公于坐"的"趁机"义不同。

综合 · 高考真题对接

  1. 1. （2023 年高考改编）翻译："其辱人贱行，视五人之死，轻重固何如哉？"（张溥《五人墓碑记》）
    答：译文为"他们这种可耻的人格、卑贱的行为，比起这五个人的死，轻重究竟怎么样呢？"句中"辱人贱行"为偏正结构，"视"为比照、比较，"固"为究竟、到底，反问语气要译出。
  2. 2. （2022 年高考改编）翻译："吾社之行为士先者，为之声义。"并解释"行为"与"先"的含义。
    答：译文为"我们社里那些道德品行可以作为读书人表率的人，替他伸张正义"。"行为"是"行（品行）+为（作为）"的短语，非现代汉语之"行为"；"先"为先导、表率；"为之声义"中"为"读四声，表替、给。
  3. 3. （2021 年高考改编）翻译："越国以鄙远，君知其难也。"（《烛之武退秦师》）
    答：译文为"越过别的国家把远方的郑国作为边邑，您知道这是困难的"。"鄙"名作动，把……当作边邑；"远"形容词作名词，远方的国家；"其"为代词，指代"越国以鄙远"这件事。
  4. 4. （2020 年高考改编）请用"六字法"翻译下面句子，并指出每一步的处理："廉颇者，赵之良将也。"
    答：译文为"廉颇是赵国的优秀将领"。"廉颇"为专名保留（留）；"者、也"为判断句标志，删去"者"，用"是"贯通（删、贯）；"赵之良将"中"之"表领属，换为"的"（换）。三字并用，译文信达。

💬 课后反馈

**常见错误** 1 虚词只记孤立释义，不放回语境。2 实词靠猜，忽视语境推断与成语印证。3 宾语前置、定语后置识别不出。4 省略成分不补，译文不通。5 偏义复词处理不当。 **教学改进建议** 1 坚持"一日一词"积累打卡。2 翻译做到"逐字落实、写出译文、对照批改"。3 建立"错译归因本"分类记录。 **分层辅导** 学困生先过 18 虚词与句式标志关；学优生挑战传记综合翻译，训练规范表述。
