高中高二语文《古诗文：蜀道难》教案

高中高二语文古诗文：蜀道难

📝 备课方案

**教学目标** 1. 诵读全诗，感受其奔放恣肆的节奏与雄奇飘逸的风格，能背诵全文。 2. 梳理「蜀道之难，难于上青天」三次咏叹的位置与作用，把握「叹高—叹险—叹战祸之危」的层次结构。 3. 品析夸张、想象与神话传说（蚕丛鱼凫、五丁开山、六龙回日）相结合的浪漫主义手法，积累「扪参历井」「一夫当关，万夫莫开」等重点词句。 4. 理解诗人借蜀道艰险所寄寓的对友人入蜀的关切与对国事的隐忧，初步认识李白浪漫主义诗风的形成。 **教学重点**：把握三次咏叹的结构作用；赏析夸张想象与神话传说的结合。 **教学难点**：理解诗中「劝人归家」与「忧国隐忧」的双重意蕴；体会杂言体句式长短错落与情感奔放的关系。 **教学方法**：诵读法、结构梳理法、字词归纳法、知人论世法。 **教学准备**：多媒体课件（蜀道栈道图片、名家朗诵音频）、李白生平资料、蜀道地理资料、文言字词卡片。 **课时安排**：3 课时（第 1 课时：诵读感知、梳理三次咏叹；第 2 课时：字词落实、精读三段；第 3 课时：手法鉴赏、主题探究与背诵过关）。

📖 课堂讲义 · 核心知识点

**一、作者与背景** 李白（701-762），字太白，号青莲居士，唐代伟大的浪漫主义诗人，被誉为「诗仙」，与杜甫并称「李杜」。幼年随父迁居绵州昌隆（今四川江油），蜀地是他的成长之地。诗风豪放飘逸、想象瑰奇，代表作有《将进酒》《行路难》《梦游天姥吟留别》等。 《蜀道难》是乐府旧题，属《相和歌辞·瑟调曲》，历代拟作者多写蜀道之险。一般认为本诗作于天宝初年李白在长安之时，为送友人王炎入蜀而作。唐人殷璠《河岳英灵集》评此诗「可谓奇之又奇，然自骚人以还，鲜有此体调也」。 **二、三次咏叹与结构层次** 「蜀道之难，难于上青天」全诗出现三次，是贯穿全篇的主线： | 位置 | 原句 | 作用 | |---|---|---| | 开篇 | 噫吁嚱，危乎高哉！蜀道之难，难于上青天！ | 惊叹起势，奠定雄放基调，领起「叹高」 | | 中间 | 蜀道之难，难于上青天，使人听此凋朱颜！ | 承上启下，由叹高转入叹险，加强悲凉气氛 | | 结尾 | 蜀道之难，难于上青天，侧身西望长咨嗟！ | 收束全篇，叹战祸之危，言尽而意无穷 | 三次咏叹一唱三叹，感情层层加深，如乐曲的主旋律反复回响，使长诗散而不乱。 **三、内容层次** 1. **第一层（叹高）**：从远古写起——蚕丛、鱼凫开国茫然，「尔来四万八千岁，不与秦塞通人烟」以时间之长衬隔绝之深；「西当太白有鸟道」言无路可通；「地崩山摧壮士死」用五丁开山神话写天梯石栈来之不易。继而「上有六龙回日之高标」用六龙回日神话写山高入天，连黄鹤、猿猱也难以飞越攀援；青泥岭「百步九折」，行人「扪参历井仰胁息」，以手抚膺、徒然长叹。 2. **第二层（叹险）**：「但见悲鸟号古木，雄飞雌从绕林间。又闻子规啼夜月，愁空山」，以悲鸟、子规渲染凄清氛围；「连峰去天不盈尺，枯松倒挂倚绝壁」极言其高险；「飞湍瀑流争喧豗，砯崖转石万壑雷」写急流瀑布如万壑雷霆，声势骇人。 3. **第三层（叹战祸之危）**：写剑阁「一夫当关，万夫莫开」，若守将非亲信便「化为狼与豺」；「朝避猛虎，夕避长蛇；磨牙吮血，杀人如麻」暗喻据险作乱之害；「锦城虽云乐，不如早还家」点明劝归之意。 **四、浪漫主义手法** 1. **夸张**：「尔来四万八千岁」「连峰去天不盈尺」「黄鹤之飞尚不得过」，以夸大之辞极言其高、其险、其久。 2. **想象奇特**：人可「扪参历井」、仰面而「胁息」，人行天梯如上青天，虚实相生。 3. **神话传说入诗**：蚕丛鱼凫、五丁开山、六龙回日，为蜀道蒙上神奇色彩。 4. **句式自由**：三言、四言、五言、七言、九言错落并用，随情感起伏伸缩，打破乐府旧题的拘束，最能体现李白奔放的诗风。 5. **衬托**：以「黄鹤」「猿猱」之不能过反衬山之高危，以悲鸟、子规之声反衬空山之愁。 **五、重点字词与文言现象** | 类别 | 例句 | 讲解 | |---|---|---| | 通假字 | 所守或匪亲 | 「匪」通「非」，不是 | | 词类活用 | 使人听此凋朱颜 | 凋：使动用法，使……凋谢（暗淡） | | 词类活用 | 上有六龙回日之高标 | 回：使动用法，使……回转 | | 词类活用 | 侧身西望长咨嗟 | 西：名词作状语，向西 | | 重点实词 | 危乎高哉 | 危：高（非今义「危险」） | | 重点实词 | 以手抚膺坐长叹 | 膺：胸；坐：徒、空 | | 重点实词 | 但见悲鸟号古木 | 但：只 | | 重点实词 | 连峰去天不盈尺 | 去：距离；盈：满、足 | | 重点虚词 | 难于上青天 | 于：介词，比 | | 重点虚词 | 胡为乎来哉 | 胡：何，为什么；乎：语气助词 |

🔍 课堂讲义 · 重点难点解析

**重点一：三次咏叹的结构作用** 例题：「蜀道之难，难于上青天」三次出现，位置与语气各有何不同？对全诗结构有何作用？ 分析：三次咏叹分别在开篇、中段、结尾，须结合前后文看其层次功能。 解答：开篇「噫吁嚱，危乎高哉」连声惊叹后抛出此句，如奇峰突起，奠定基调并领起叹高；中段于悲鸟子规之后复出，将见闻之险收拢为一叹，由景入情、承上启下；结尾「侧身西望长咨嗟」与之相伴，余音袅袅，把叹险升为忧时。三次咏叹一唱三叹、层层加深，像主旋律贯穿全曲，使内容繁多的长诗结构谨严、气脉贯通。 小结：咏叹句的作用题从「位置功能＋情感层次＋结构线索」三方面作答。 **重点二：夸张与想象结合的浪漫主义笔法** 例题：「连峰去天不盈尺」与「扪参历井仰胁息」两句夸张方式有何不同？ 分析：前者是数字夸张（距离不足一尺），后者是把不可能之事写实（摸到星宿）。 解答：「连峰去天不盈尺」以极言距离之小夸张山峰之高，属数字式夸张；「扪参历井仰胁息」想象行人登山可手扪参星、历经井宿，因天近星宿而屏住呼吸，把山高化为可感的神话式场景，属想象性夸张。二者一实一虚，共同营造「山与天齐」的奇险境界，尽显浪漫主义本色。 小结：夸张分数字夸张与情境想象夸张，答题须分型取证。 **难点一：主题的多重解读** 例题：本诗「送友人入蜀」与「忧国隐忧」两种主题解读是否矛盾？ 分析：从「问君西游何时还」「锦城虽云乐，不如早还家」看劝归之意；从剑阁一段「所守或匪亲，化为狼与豺」看时局之忧。 解答：不矛盾。送友入蜀，故极力铺写蜀道之高险凶危，劝其早去早回，这是表层；剑阁易守难攻，「一夫当关，万夫莫开」，若据险者非亲信必成割据之患，诗人由友人入蜀推及蜀地安危、国家局势，忧惧之情溢于言表，这是深层。个人关切与时代忧患在诗中融为一体，正是其厚重所在。 小结：主题题分「表层—深层」两层作答，均需文本依据。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：重点句子翻译** 题目：翻译「上有六龙回日之高标，下有冲波逆折之回川」。 分析：注意「回日」（使太阳回转）的使动意味与「逆折」（回旋）的表达。 解答：山高如天柱，上有迫使六龙驾日车回转的高峻山峰，下有波涛回旋奔涌的急流。翻译要点：「高标」指高耸的山峰，可作蜀山最高处；「冲波逆折」写激浪回旋。句中「上」「下」对举，先仰后俯，极写蜀道上下之奇险。 方法小结：翻译神话意象句，先落实实词，再保留想象之美。 **例题二（提高）：意境与手法综合** 题目：赏析「但见悲鸟号古木，雄飞雌从绕林间。又闻子规啼夜月，愁空山」的意境营造。 分析：抓住悲鸟、古木、子规、夜月、空山等意象与「愁」字。 解答：古木苍苍，悲鸟号鸣，雄飞雌从更显孤寂；子规（杜鹃）夜啼，声声「不如归去」，啼于冷月空山，凄清彻骨。视听结合、以声衬静，一个「愁」字移情于物，连空山也染上愁绪。诗人借凄迷声景渲染蜀道之险，为「使人听此凋朱颜」蓄势，尽显以景写情之功。 方法小结：意境题=意象叠加＋氛围概括＋情感指向三步走。 **例题三（综合）：结构探究** 题目：诗人写「剑阁峥嵘而崔嵬，一夫当关，万夫莫开」一段，与「蜀道之难」的主题有何关联？ 分析：剑阁是蜀道之险的地理要冲，也是蜀地政治安危的象征。 解答：剑阁为入蜀咽喉，地势险绝，一夫当关、万夫莫开；「所守或匪亲，化为狼与豺」「磨牙吮血，杀人如麻」，以猛虎长蛇喻据险作乱之徒，写出蜀地潜在的动乱之危。这一段把自然之险推进到人事之危，使「蜀道之难」由行路之难升华为忧时之叹，主题因此深厚。 方法小结：探究段落的主题关联，要看到意象从「自然」到「人事」的转换。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 名句默写与字词释义

  1. 1. 默写全诗开篇四句。
    答：噫吁嚱，危乎高哉！蜀道之难，难于上青天！蚕丛及鱼凫，开国何茫然！注意「吁嚱」「蚕丛」「鱼凫」的写法。
  2. 2. 解释加点词：①危乎高哉（危）②以手抚膺坐长叹（膺、坐）③但见悲鸟号古木（但）④连峰去天不盈尺（去、盈）。
    答：①危：高；②膺：胸；坐：徒、空；③但：只；④去：距离；盈：满、足。
  3. 3. 默写「剑阁峥嵘而崔嵬」至「不如早还家」。
    答：剑阁峥嵘而崔嵬，一夫当关，万夫莫开。所守或匪亲，化为狼与豺。朝避猛虎，夕避长蛇；磨牙吮血，杀人如麻。锦城虽云乐，不如早还家。注意「崔嵬」「吮」的写法。

中等 · 课内翻译与文言现象

  1. 1. 翻译：扪参历井仰胁息，以手抚膺坐长叹。
    答：（山路高峻）伸手可以摸到参、井二星，屏住呼吸仰头而行，用手抚着胸口徒然长叹。要点：扪，摸；历，经过；胁息，屏息；坐，徒然。
  2. 2. 指出下列句中的通假字与词类活用并释义：①所守或匪亲 ②使人听此凋朱颜 ③侧身西望长咨嗟。
    答：①「匪」通「非」，不是；②「凋」为使动用法，使……凋谢（黯淡）；③「西」为名词作状语，向西。
  3. 3. 翻译：其险也如此，嗟尔远道之人胡为乎来哉！
    答：蜀道竟如此艰险，唉，你这远道之人为什么还要来这里呢！要点：「也……如此」表判断兼感叹；「胡为乎」，为什么；「哉」，感叹语气。

难 · 手法鉴赏与结构分析

  1. 1. 「黄鹤之飞尚不得过，猿猱欲度愁攀援」运用了什么表现手法？有什么效果？
    答：运用了衬托（反衬）手法。黄鹤善飞尚且不能飞过，猿猱善攀尚且愁于攀援，以最善飞、最善攀的两类动物的「不能」，反衬蜀道山势之高危峥嵘，比直接写山更进一层，奇险如在目前。
  2. 2. 「蜀道之难，难于上青天」三次出现的位置、语气与作用各是什么？请分条说明。
    答：（1）开篇：紧承「噫吁嚱，危乎高哉」，惊呼起势，奠定雄放基调，总领叹高；（2）中间：继悲鸟子规、愁空山之后，由写景转入抒情，承上启下，增添凄凉气氛；（3）结尾：与「侧身西望长咨嗟」相伴，收束全篇，由叹险转为忧时，言尽而意无穷。三次咏叹层层加深，如主旋律回环贯穿，使全诗气脉贯通。
  3. 3. 本诗句式参差错落（有三言、四言、五言、七言、九言等），这对表达情感有什么作用？试举例说明。
    答：开篇「噫吁嚱，危乎高哉」（三言、四言连用）短促急切，如惊呼破空而来，与惊叹之情相合；「蜀道之难，难于上青天」七言回环，长于咏叹；「扪参历井仰胁息，以手抚膺坐长叹」舒缓绵长，如喘息未定；「锦城虽云乐，不如早还家」平缓恳切，如叮咛劝归。句式随情感伸缩，自由奔放，尽显浪漫主义豪情。

综合 · 主题探究与迁移写作

  1. 1. 结合「锦城虽云乐，不如早还家」与剑阁一段，谈谈你对本诗主题的理解（可综合「送友」「忧时」两说）。
    答：表层：诗为送友人王炎入蜀而作，历数蜀道高险凶危，苦口劝其「不如早还家」，见故人深情；深层：剑阁「一夫当关，万夫莫开」「所守或匪亲，化为狼与豺」，暗含对藩镇据险割据、时局动荡的忧虑。个人关怀与家国之忧交织，使这首奇险之歌有了沉甸甸的现实分量。
  2. 2. 比较阅读：《蜀道难》与《梦游天姥吟留别》同属李白浪漫主义名篇，试从想象方式与语言风格两方面比较其异同。
    答：同：都借助神话传说与大胆夸张，想象飞动，句式自由，气势奔放。异：《蜀道难》想象围绕「高险」展开，以奇险壮阔取胜，情感是惊叹与忧惧；《梦游天姥吟留别》想象围绕「梦游」展开，以瑰丽幻境取胜，情感归宿是「安能摧眉折腰事权贵」的傲岸。一险一幻，各极其妙。
  3. 3. 微写作（150 字左右）：以「我想对入蜀的友人说」为题，化用诗中两句原句，写一段劝勉或关怀友人的文字。
    答：示例：朋友，我知道锦城繁华，你怀揣壮志西去。但请记住——「蜀道之难，难于上青天」，那险峰激流会试炼你的脚步；也请记得——「锦城虽云乐，不如早还家」，无论成败，故园永远有等你归来的人。（化用原句、情感真挚即可酌情给分）

💬 课后反馈

**学生常见错误** 1. 默写失分多：「噫吁嚱」「鱼凫」「崔嵬」「喧豗」「砯」等字难写，「不与秦塞通人烟」易漏「秦塞」。 2. 文言词义混淆：「危」误译为「危险」（应为「高」），「坐」误译为「坐下」（应为「徒、空」），「去」误译为「前往」。 3. 通感与衬托不分：把「黄鹤猿猱不得过」答成夸张而漏掉「衬托」这一关键手法。 4. 三次咏叹只会背位置，说不出各处「语气、功能」的不同，结构分析流于表面。 **教学改进建议** 1. 先诵后析：用名家范读与学生分句接读结合，重点体会开篇三连叹的急切与结尾长叹的悠远，以声音带出结构。 2. 文言字词采用「归类卡片」法，通假、活用、古今异义分三摞卡片，课前五分钟轮抽检查，日积月累。 3. 结构教学画「三次咏叹位置图」，让学生在图上标注每段层次与情感走向，直观理解一唱三叹之妙。 **分层辅导建议** - 基础层：过关默写、重点实词虚词与翻译，达到背诵流畅。 - 提高层：掌握衬托、夸张等手法的辨析与咏叹句作用题的答题规范。 - 拓展层：读《将进酒》与本诗对读，写一篇「李白笔下的夸张」短评，理解浪漫主义诗风的多样面貌。 **给家长的建议** 1. 请孩子分段背诵，家长每两天抽查一段，一个月内完成全文背诵过关。 2. 有条件可与孩子聊一聊地图上的蜀道（金牛道、剑门关），把「一夫当关，万夫莫开」与真实地理对应，加深理解。
