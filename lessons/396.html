高中高一化学《非金属及其化合物》教案

高中高一化学非金属及其化合物

📝 备课方案

**教学目标** 1. 掌握氯气的物理性质和化学性质，能写出氯气与金属、氢气、水、碱反应的方程式；认识氯水的成分，理解次氯酸的漂白性与不稳定性，知道漂白粉、84 消毒液的制备与成分。 2. 掌握二氧化硫的酸性氧化物通性、还原性与漂白性，能区分 SO₂ 漂白与氯水漂白的原理差异；掌握浓硫酸的吸水性、脱水性、强氧化性三大特性及 SO₄²⁻ 的检验方法。 3. 认识氮的氧化物（NO、NO₂）的性质与相互转化，掌握氨的性质、喷泉实验原理与铵盐的性质，会用离子方程式表示 NH₄⁺ 的检验。 4. 掌握硝酸的强氧化性，能写出浓、稀硝酸与铜反应的方程式，理解常温下铁、铝在冷浓硝酸中的钝化现象；了解酸雨的成因与防治。 **教学重点**：氯气与水、碱的反应；SO₂ 的性质；硝酸与铜的反应。 **教学难点**：氯水成分的多样性及各成分性质对应；SO₂ 漂白与 HClO 漂白的区别；硝酸与金属反应中氮的价态判断。 **教学方法**：实验探究法、对比归纳法、情境教学法、模型建构法。 **教学准备**：氯气样品（视频资料）、氯水、品红溶液、SO₂ 与溴水、蔗糖与浓硫酸、铜片与浓稀硝酸、喷泉实验装置、课件与任务单。 **课时安排**：3 课时（第 1 课时：氯及其化合物；第 2 课时：硫的化合物与浓硫酸；第 3 课时：氮的化合物与硝酸、酸雨）。

📖 课堂讲义 · 核心知识点

**一、氯及其化合物** 氯气物理性质：黄绿色、有强烈刺激性气味的有毒气体，能溶于水（1 体积水约溶 2 体积氯气）。 化学性质（氯原子最外层 7 个电子，易得 1 个电子，是活泼的非金属）： 与金属：2Na + Cl₂ =（点燃）2NaCl（白烟）；2Fe + 3Cl₂ =（点燃）2FeCl₃（棕褐色烟，铁被氧化到 +3 价）；Cu + Cl₂ =（点燃）CuCl₂（棕黄色烟）。 与氢气：Cl₂ + H₂ =（点燃或光照）2HCl，点燃时发出苍白色火焰，工业制盐酸的原理。 与水：Cl₂ + H₂O ⇌ HCl + HClO（可逆反应）。新制氯水的成分复杂： | 微粒 | 来源 | 性质表现 | |---|---|---| | Cl₂、HClO、H₂O | 三种分子 | Cl₂ 黄绿色、强氧化性；HClO 漂白、杀菌 | | H⁺、Cl⁻、ClO⁻、OH⁻ | 四种离子 | H⁺ 酸性；Cl⁻ 沉淀 Ag⁺；ClO⁻ 漂白 | 次氯酸三性质：弱酸性（比碳酸还弱）、强氧化性（漂白、杀菌消毒）、不稳定性（HClO =（光照）HCl + O₂↑，故氯水需避光新制）。 与碱：Cl₂ + 2NaOH = NaCl + NaClO + H₂O（84 消毒液有效成分 NaClO）；2Cl₂ + 2Ca(OH)₂ = Ca(ClO)₂ + CaCl₂ + 2H₂O（漂白粉有效成分 Ca(ClO)₂）。 Cl⁻ 的检验：先加稀硝酸排除干扰，再加 AgNO₃ 溶液，生成不溶于稀硝酸的白色沉淀（Ag⁺ + Cl⁻ = AgCl↓）。 **二、二氧化硫与硫酸** SO₂：无色、有刺激性气味的有毒气体，密度比空气大，易溶于水。硫元素的 +4 价是中间价态，决定了 SO₂ 既有氧化性又有还原性。 三重性质： 1. 酸性氧化物通性：SO₂ + H₂O ⇌ H₂SO₃；SO₂ + 2NaOH = Na₂SO₃ + H₂O。 2. 还原性：SO₂ 能使溴水、酸性 KMnO₄ 溶液褪色（褪色原理是氧化还原，不是漂白）。SO₂ + Br₂ + 2H₂O = H₂SO₄ + 2HBr。 3. 漂白性：与有色物质化合生成不稳定的无色物质，加热或久置后恢复原色（如品红溶液先褪色，加热又变红）。 浓硫酸三大特性： 1. 吸水性：吸收现成的水分子，作干燥剂（不能干燥 NH₃）。 2. 脱水性：把有机物中的 H、O 按 2:1 脱去（蔗糖被炭化变黑）。 3. 强氧化性：Cu + 2H₂SO₄（浓）=（△）CuSO₄ + SO₂↑ + 2H₂O；常温下使 Fe、Al 钝化，故可用铁罐或铝罐运输浓硫酸；C + 2H₂SO₄（浓）=（△）CO₂↑ + 2SO₂↑ + 2H₂O。 SO₄²⁻ 检验：先加足量稀盐酸（排除 CO₃²⁻、SO₃²⁻、Ag⁺ 等干扰），无沉淀，再加 BaCl₂ 溶液，生成白色沉淀则含 SO₄²⁻（Ba²⁺ + SO₄²⁻ = BaSO₄↓）。 **三、氮的氧化物与氨** N₂ + O₂ =（放电或高温）2NO（无色、不溶于水、有毒，与血红蛋白结合）；2NO + O₂ = 2NO₂；NO₂ 是红棕色、有刺激性气味的有毒气体；3NO₂ + H₂O = 2HNO₃ + NO（工业制硝酸的基础）。 氨的物理性质：无色、有刺激性气味，密度比空气小，极易溶于水（1 体积水约溶解 700 体积氨），易液化。 喷泉实验：挤压胶头滴管，少量水溶解大量 NH₃，烧瓶内压强骤减，外界大气压把烧杯中的水压入烧瓶形成红色喷泉（氨水显碱性使酚酞变红）。形成喷泉的关键是容器内外产生足够大的压强差。 化学性质： 与水：NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻（一水合氨是弱碱）。 与酸：NH₃ + HCl = NH₄Cl（白烟，可互检）。 催化氧化：4NH₃ + 5O₂ =（催化剂，△）4NO + 6H₂O（工业制硝酸第一步）。 NH₄⁺ 检验：取样品加 NaOH 溶液并加热，产生能使湿润红色石蕊试纸变蓝的气体，则含 NH₄⁺（NH₄⁺ + OH⁻ =（△）NH₃↑ + H₂O）。 **四、硝酸与酸雨** 硝酸是强酸，不稳定：4HNO₃ =（光照或△）4NO₂↑ + O₂↑ + 2H₂O，故盛放在棕色瓶中避光。 强氧化性：浓硝酸被还原为 NO₂，稀硝酸被还原为 NO。 Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O； 3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。 常温下浓硝酸使 Fe、Al 钝化。王水（浓硝酸与浓盐酸体积比 1:3）能溶解金、铂。 酸雨：pH 小于 5.6 的降水。硫酸型：SO₂ 经两条途径转化为硫酸（SO₂ + H₂O ⇌ H₂SO₃，2H₂SO₃ + O₂ = 2H₂SO₄；或 2SO₂ + O₂ ⇌ 2SO₃，SO₃ + H₂O = H₂SO₄）。硝酸型：NO₂ 与水反应。防治：燃煤脱硫（2CaCO₃ + 2SO₂ + O₂ = 2CaSO₄ + 2CO₂）、尾气净化、开发清洁能源。

🔍 课堂讲义 · 重点难点解析

**重点一：氯水成分与性质对应** 例题：将干燥的有色布条和湿润的有色布条分别放入盛氯气的集气瓶中，现象如何？说明了什么？ 分析：Cl₂ 本身没有漂白性，与水反应生成的 HClO 才有漂白性。 解答：干燥布条不褪色，湿润布条褪色。说明 Cl₂ 无漂白性，Cl₂ 与 H₂O 反应生成的 HClO 具有漂白性。 小结：氯水的成分决定性质——漂白靠 HClO/ClO⁻，酸性靠 H⁺，白色沉淀靠 Cl⁻，黄绿色靠 Cl₂。分析氯水问题先列成分再找对应。 **难点一：SO₂ 漂白与氯水漂白的区别** 例题：向品红溶液中分别通入 SO₂ 和氯水，都褪色了。两者原理相同吗？如何用实验验证？ 分析：SO₂ 漂白是与有色物质化合生成不稳定无色物（可逆），HClO 漂白是氧化破坏发色结构（不可逆）。 解答：原理不同。SO₂ 是化合型（暂时性）漂白，加热可恢复红色；HClO 是氧化型（永久性）漂白，加热不恢复。验证：将褪色后的两份溶液分别加热，SO₂ 漂白的恢复红色，HClO 漂白的不恢复。 小结：三种漂白原理要分清——HClO 氧化漂白（不可逆）、SO₂ 化合漂白（可逆）、活性炭吸附漂白（物理）。 **难点二：硝酸与金属反应中还原产物的判断** 例题：分别写出浓硝酸、稀硝酸与铜反应的方程式，指出还原剂与氧化剂，说明「被还原的硝酸」与「起酸性作用的硝酸」的关系。 分析：HNO₃ 中 N 为 +5 价，浓硝酸还原产物 NO₂（+4 价），稀硝酸还原产物 NO（+2 价）。 解答：Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O；3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。还原剂是 Cu，氧化剂是 HNO₃。浓硝酸中 4 份 HNO₃ 只有 2 份被还原（进入 NO₂），另 2 份起酸的作用生成 Cu(NO₃)₂，被还原的占一半；稀硝酸中 8 份只有 2 份被还原。 小结：硝酸与金属反应时一部分作氧化剂被还原、一部分成盐，比例随浓度变化，计算题常考。 **易错警示：铁与氯气、铁与盐酸的产物差异** 例题：铁与氯气反应和铁与盐酸反应的产物中铁的价态相同吗？ 解答：不同。Cl₂ 氧化性强，把 Fe 氧化为 +3 价：2Fe + 3Cl₂ =（点燃）2FeCl₃；盐酸是弱氧化性酸，只把 Fe 氧化为 +2 价：Fe + 2HCl = FeCl₂ + H₂↑。氧化剂氧化性强弱决定变价金属的价态。

✏️ 课堂讲义 · 典型例题精讲

**例题一（基础）：氯水成分分析** 题目：向新制氯水中滴加 AgNO₃ 溶液产生白色沉淀；光照新制氯水，黄绿色逐渐变浅并产生气泡。分别解释现象并写方程式。 分析：氯水中存在 Cl₂ + H₂O ⇌ HCl + HClO；HClO 见光分解使平衡右移。 解答：滴 AgNO₃ 产生 AgCl 白色沉淀，证明氯水中含 Cl⁻：Ag⁺ + Cl⁻ = AgCl↓。光照时 HClO 分解：2HClO =（光照）2HCl + O₂↑，HClO 浓度减小促使 Cl₂ 继续与水反应，故黄绿色（Cl₂）变浅，逸出的气泡是 O₂。 方法小结：氯水问题抓住「平衡移动」——消耗某种微粒，平衡向生成它的方向移动。 **例题二（提高）：SO₂ 性质的综合运用** 题目：将 SO₂ 通入溴水中，溴水褪色；将 SO₂ 通入品红溶液中，品红也褪色。两个褪色的本质相同吗？写出 SO₂ 与溴水反应的方程式。 分析：判断是氧化还原褪色还是化合漂白褪色，看溴（+1 价溴? 不，溴单质 0 价）是否被还原。 解答：本质不同。SO₂ 通入溴水是 SO₂ 的还原性使溴还原褪色：SO₂ + Br₂ + 2H₂O = H₂SO₄ + 2HBr（S 从 +4 升到 +6，Br 从 0 降到 -1，有电子转移）；通入品红是 SO₂ 的漂白性（化合型，可逆）。 方法小结：同一物质的不同褪色现象对应不同性质，判断依据是褪色过程是否发生氧化还原、是否可逆。 **例题三（综合）：硝酸与铜的计算** 题目：3.84 g 铜与足量浓硝酸反应。(1) 写出化学方程式；(2) 求标准状况下生成气体的体积；(3) 求被还原的硝酸的物质的量（写出设、写、算、答）。 分析：Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O，4 份 HNO₃ 中 2 份被还原、2 份成盐。 解答： (1) Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O。 (2) 设生成 NO₂ 为 x mol。n(Cu) = 3.84 g ÷ 64 g/mol = 0.06 mol，由 Cu ~ 2NO₂ 得 x = 0.12 mol，V = 0.12 × 22.4 = 2.688 L。 (3) 被还原的 HNO₃ 即进入 NO₂ 的部分，n = 0.12 mol（恰为消耗 HNO₃ 总量 0.24 mol 的一半）。 答：生成 NO₂ 气体 2.688 L，被还原的硝酸 0.12 mol。 方法小结：硝酸与金属计算抓住两条线——按方程式比例算气体量，按「进入气体的硝酸=被还原的硝酸」拆分总耗酸量。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 氯及其化合物识记

  1. 1. 填空：氯气是________色、有________气味的有毒气体；新制氯水中含有的三种分子是________，四种离子是________。
    答：黄绿色、刺激性气味。三种分子：Cl₂、H₂O、HClO；四种离子：H⁺、Cl⁻、ClO⁻、OH⁻。记忆口诀「三分子四离子」。
  2. 2. 完成方程式：(1) 铁在氯气中点燃；(2) 氯气与氢氧化钠溶液反应；(3) 次氯酸见光分解。
    答：(1) 2Fe + 3Cl₂ =（点燃）2FeCl₃；(2) Cl₂ + 2NaOH = NaCl + NaClO + H₂O；(3) 2HClO =（光照）2HCl + O₂↑。
  3. 3. 填空：漂白粉的有效成分是________；检验某溶液中是否含 Cl⁻，应先加________排除干扰，再加________溶液，观察是否生成不溶于稀硝酸的________色沉淀。
    答：有效成分是 Ca(ClO)₂（漂白粉的主要成分还有 CaCl₂）。先加足量稀硝酸，再加 AgNO₃ 溶液，生成不溶于稀硝酸的白色沉淀（AgCl）。

中等 · 硫、氮性质运用

  1. 1. 现有浓硫酸、氯水、SO₂ 三种试剂，判断下列现象各体现浓硫酸的哪种性质：(1) 敞口放置的浓硫酸质量增加；(2) 蔗糖中加入浓硫酸后变黑、体积膨胀；(3) 常温下可用铁罐运输浓硫酸。
    答：(1) 吸水性（吸收空气中的水蒸气）；(2) 脱水性（把蔗糖中的 H、O 按 2:1 脱去使有机物炭化）；(3) 强氧化性（常温下使铁表面生成致密氧化膜而钝化）。
  2. 2. 完成氮氧化物的转化方程式：(1) N₂ 与 O₂ 在放电条件下；(2) NO 与 O₂ 常温化合；(3) NO₂ 与水反应。
    答：(1) N₂ + O₂ =（放电或高温）2NO；(2) 2NO + O₂ = 2NO₂；(3) 3NO₂ + H₂O = 2HNO₃ + NO。这三步是雷雨固氮和工业制硝酸的核心转化。
  3. 3. 某溶液中可能含 SO₄²⁻，某同学取样先滴加 BaCl₂ 溶液产生白色沉淀，便断定含 SO₄²⁻。该方案是否严谨？说明理由并写出正确方案。
    答：不严谨。若溶液中含 CO₃²⁻、SO₃²⁻ 或 Ag⁺，滴加 BaCl₂ 同样产生白色沉淀（BaCO₃、BaSO₃、AgCl），无法排除干扰。正确方案：先加足量稀盐酸（排除 CO₃²⁻、SO₃²⁻、Ag⁺ 干扰），若无沉淀，再加 BaCl₂ 溶液，生成白色沉淀则含 SO₄²⁻。

难 · 推断与计算

  1. 1. 计算：将 3.84 g 铜片投入足量稀硝酸中完全反应（3Cu + 8HNO₃ = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O）。求：(1) 生成 NO 的体积（标准状况）；(2) 被还原的 HNO₃ 的物质的量；(3) 转移电子的物质的量（写出设、写、算、答）。
    答：设生成 NO 为 x mol。n(Cu) = 3.84 g ÷ 64 g/mol = 0.06 mol。(1) 由 3Cu ~ 2NO 得 x = 0.04 mol，V = 0.04 × 22.4 = 0.896 L。(2) 被还原的 HNO₃ 即进入 NO 的部分，n = 0.04 mol。(3) 每个 Cu 失 2 个电子，n(e⁻) = 0.06 × 2 = 0.12 mol（也可由 0.04 mol NO 中 N 从 +5 降到 +2 得 0.04 × 3 = 0.12 mol，电子守恒验证）。答：NO 0.896 L，被还原硝酸 0.04 mol，转移电子 0.12 mol。
  2. 2. 推断：无色混合气体 X 可能含 NO、CO₂、SO₂ 中的一种或几种。将 X 通入足量溴水中，溴水褪色且无气体剩余；再向所得溶液中加入 BaCl₂ 溶液，产生白色沉淀。(1) 确定 X 的组成并说明理由；(2) 写出 X 使溴水褪色的方程式。
    答：(1) X 中含 SO₂ 和 CO₂。SO₂ 使溴水褪色（还原性）；反应后「无气体剩余」说明 CO₂ 也被溶液完全吸收（溴水中还有水与酸，足量吸收）；加 BaCl₂ 产生白色沉淀为 BaSO₄，证明 SO₂ 被氧化为 SO₄²⁻。X 不含 NO（NO 无色不与溴水反应，若有会剩余气体且遇空气变红棕色可佐证）。注意推理要点：溴水褪色对应 SO₂ 的还原性，BaSO₄ 沉淀对应 SO₄²⁻ 的生成。
  3. 3. 喷泉实验分析：烧瓶中充满氨气，胶头滴管中挤入少量水，烧杯中是滴有酚酞的水。解释喷泉形成的原因，说明喷泉的颜色，并写出生成氨水的电离方程式。
    答：氨气极易溶于水（1 体积水溶解约 700 体积氨），挤入的少量水溶解大量氨气，使烧瓶内气体压强急剧减小，远低于外界大气压，烧杯中的水被大气压压入烧瓶形成喷泉。因氨水显碱性使酚酞变红，喷泉为红色。电离：NH₃·H₂O ⇌ NH₄⁺ + OH⁻。形成喷泉的本质条件：容器内压强急剧减小且压强差足够大。

综合 · 实验与工业环保

  1. 1. 生活安全：家庭中 84 消毒液（有效成分 NaClO）与洁厕灵（主要成分盐酸）混合使用会产生有毒气体，方程式为 NaClO + 2HCl = NaCl + Cl₂↑ + H₂O。(1) 指出氧化剂和还原剂；(2) 若产生 2.24 L（标准状况）Cl₂，计算消耗 NaClO 的质量（写出设、写、算、答）；(3) 由此给家庭消毒提出一条建议。
    答：(1) Cl 元素从 +1 价（NaClO）降到 0 价，NaClO 是氧化剂；盐酸中 Cl 从 -1 价升到 0 价，HCl 是还原剂（部分 HCl 起酸的作用）。(2) 设消耗 NaClO 为 x mol。n(Cl₂) = 2.24 L ÷ 22.4 L/mol = 0.1 mol，由方程式 NaClO ~ Cl₂ 得 x = 0.1 mol，m = 0.1 × 74.5 = 7.45 g。(3) 建议：84 消毒液与洁厕灵严禁混合使用，消毒后充分通风。答：消耗 NaClO 7.45 g。
  2. 2. 工业流程：接触法制硫酸的简化流程为：硫铁矿（FeS₂）煅烧得 SO₂；SO₂ 催化氧化为 SO₃；SO₃ 用 98.3% 浓硫酸吸收。(1) 写出 SO₂ 催化氧化的方程式；(2) 为什么用浓硫酸吸收 SO₃ 而不用水？(3) 写出尾气中 SO₂ 用氨水吸收的方程式。
    答：(1) 2SO₂ + O₂ ⇌（催化剂，△）2SO₃（可逆反应，工业上控制条件提高转化率）。(2) 用水直接吸收 SO₃ 会形成酸雾，阻碍吸收且腐蚀设备；用 98.3% 浓硫酸吸收不形成酸雾，效率高。(3) SO₂ + 2NH₃·H₂O = (NH₄)₂SO₃ + H₂O（或 SO₂ + 2NH₃ + H₂O = (NH₄)₂SO₃），吸收产物可再利用，减少污染。
  3. 3. 环保综合：某地区降水 pH 为 4.5，属于酸雨。(1) 写出硫酸型酸雨形成的两条主要途径（用方程式表示）；(2) 燃煤电厂常用石灰石-石膏法脱硫，写出总反应方程式；(3) 提出两条减少酸雨的社会性措施。
    答：(1) 途径一（液相氧化）：SO₂ + H₂O ⇌ H₂SO₃，2H₂SO₃ + O₂ = 2H₂SO₄；途径二（气相氧化）：2SO₂ + O₂ ⇌（催化剂/粉尘）2SO₃，SO₃ + H₂O = H₂SO₄。(2) 2CaCO₃ + 2SO₂ + O₂ = 2CaSO₄ + 2CO₂。(3) 措施：燃煤脱硫、推广清洁能源（水电、风电）、汽车尾气催化净化、植树造林等（答出两条即可）。

💬 课后反馈

**学生常见错误** 1. 氯水成分记不全或张冠李戴：漂白对应 HClO/ClO⁻ 而不是 Cl₂，氯水光照实验中气泡误认为是氯气逸出。 2. SO₂ 漂白与还原性混淆：见到「褪色」就答漂白性，没区分 SO₂ 使溴水褪色是还原性、使品红褪色才是漂白性。 3. 硝酸与金属反应记不住价态规律：浓硝酸生成 NO₂、稀硝酸生成 NO 常写反，被还原的硝酸与总耗酸量的比例算错。 4. 铵盐与硝酸的保存忽视：硝酸见光分解应避光保存、铵盐受热易分解，检验 NH₄⁺ 时忘记加热或不写「湿润红色石蕊试纸变蓝」的完整表述。 **教学改进建议** 1. 氯水教学用「成分—性质—现象」三列表格逐项挂钩，配合干燥与湿润布条对比实验，把抽象成分落到现象上。 2. 漂白原理专题化：用 HClO、SO₂、活性炭三种漂白对比表格加实验（加热是否恢复颜色），一次讲透、避免反复混淆。 3. 硝酸与金属反应先标化合价再写方程式，归纳「浓酸出 NO₂、稀酸出 NO」的价态规律，配合计算例题训练比例拆分。 **分层辅导建议** - 基础层：过关氯、硫、氮重要方程式书写与颜色记忆，规范「↑↓」与条件标注。 - 提高层：强化氯水成分分析、SO₂ 多重性质的情境判断和 SO₄²⁻、NH₄⁺ 检验方案设计。 - 拓展层：完成硝酸与铜的多步计算、气体推断题和工业流程题，训练信息提取能力。 **给家长的建议** 1. 鼓励孩子把「氯水三分子四离子」「浓硫酸三特性」整理成卡片，用自测的方式反复过关。 2. 家庭消毒时可以和孩子讨论 84 消毒液不能与洁厕灵混用的化学原因，把安全常识与课堂知识结合起来。
