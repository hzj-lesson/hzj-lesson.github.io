小学四年级数学《三位数乘两位数》教案

小学四年级数学三位数乘两位数

📝 备课方案

**教学目标** 1. 掌握三位数乘两位数的笔算方法，理解算理，能正确、熟练地进行计算。 2. 掌握因数中间或末尾有 0 的乘法的简便算法，能正确口算整十、整百数乘整十数的乘法。 3. 能用估算检验计算结果，会选择合适的估算方法解决实际问题。 4. 在计算和解决问题中理解"单价、数量、总价"和"速度、时间、路程"等数量关系，感受数学与生活的紧密联系。 **教学重点**：掌握三位数乘两位数的笔算方法，理解算理。 **教学难点**：因数中间或末尾有 0 时竖式的简便写法；第二层积的正确对位。 **教学方法**：迁移类推法、讲解与练习结合、小组合作交流。 **教学准备**：多媒体课件、竖式练习卡、口算卡、超市购物情境图。 **课时安排**：本单元共 4 课时，其中口算乘法 1 课时，笔算乘法 2 课时，解决问题 1 课时。本课为笔算乘法第 1 课时，重点解决"因数中间或末尾有 0"以外的常规笔算。

📖 课堂讲义 · 核心知识点

一、口算乘法 整十、整百数乘整十数：先把 0 前面的数相乘，再在积的末尾添上相应个数的 0。 例如：30×50，先算 3×5 得 15，两个因数末尾一共有两个 0，所以积是 1500；120×30，先算 12×3 得 36，再添两个 0，得 3600。 二、三位数乘两位数的笔算方法 以 145×12 为例，分三步： 1. 先用第二个因数个位上的 2 去乘 145，得 290，表示 290 个一，积的末位与个位对齐。 2. 再用第二个因数十位上的 1 去乘 145，得 145 个十，即 1450，积的末位与十位对齐。 3. 最后把两次乘得的积加起来，290 加 1450 得 1740。 算理说明：145×12 就是 145×10 加上 145×2，也就是 1450 加 290，等于 1740。竖式其实把这一步一步的口算过程记录了下来。 三、因数末尾有 0 的乘法 可以先算 0 前面的数，再在积的末尾添 0，把竖式写得简便。例如 260×30：先算 26×3 得 78，两个因数末尾一共有两个 0，在 78 后面添两个 0，得 7800。注意：添 0 的个数是两个因数末尾 0 的总个数。 四、因数中间有 0 的乘法 因数中间的 0 也要参与运算，不能省略。例如 206×4，个位 4 乘 206 得 824，其中十位上的 0 也要乘：4×0 得 0，写 0 占位。不要跳过去直接写 224。 五、估算 把因数看作与它接近的整十、整百数，再口算，得到积的大致范围。例如学校组织研学，每张门票 48 元，28 人参加，大约需要多少元？把 48 看作 50，把 28 看作 30，50×30 得 1500 元，所以大约需要 1500 元。 六、常用的数量关系 | 数量关系 | 字母表示 | 举例 | |----------|----------|------| | 单价×数量=总价 | 每件商品的价格×买的件数 | 每本故事书 15 元，买 12 本，共 15×12 元 | | 速度×时间=路程 | 每小时行的路程×行驶时间 | 汽车每小时行 80 千米，3 小时行 240 千米 | | 工作效率×工作时间=工作总量 | 每小时做的件数×时间 | 每小时装 120 件，装 5 小时共 600 件 | 七、易错提醒 1. 第二层积的末位没有对准十位，是竖式计算最常见的错误。 2. 因数末尾有 0 时忘记在积的末尾添 0。 3. 因数中间有 0 时漏乘，把 0 跳过。 4. 估算结果要用"约等于"符号表示，不能写成等号。

🔍 课堂讲义 · 重点难点解析

重点一：三位数乘两位数的算理与对位 分析：学生知道"先乘个位，再乘十位"的步骤，但说不清道理，第二层积经常对错位。 解答：结合口算 145×12 等于 145×10 加 145×2 说明：用十位上的 1 去乘，得到的 145 表示 145 个十，所以它的末位要写在十位下面。位置对了，结果才正确。 小结：竖式是口算的另一种写法，第二层积表示"几个十"，末位对齐十位，位置决定了它的价值。 难点一：因数末尾有 0 的简便写法 分析：学生会用简便写法，但容易少添 0，例如把 260×30 算成 780 或 7800 之外的其他结果。 解答：先算 0 前面的数的积，再数一数两个因数末尾一共有几个 0，就在积的末尾添几个 0。260×30 中，26×3 得 78，末尾一共有两个 0，添上得 7800。 小结：养成"算完数一数"的习惯，先数 0 的个数再添 0，就能避免漏添。 难点二：因数中间有 0 的乘法 分析：学生误以为 0 可以不乘，出现漏位，例如把 305×24 的中间一步算错。 解答：305×24 先用 4 乘 305 得 1220，再用 2 乘 305 得 610 个十，即 6100，相加得 7320。中间十位上的 0 也要乘，乘得的积满几十就向高位进几。 小结：0 也是数字，中间的 0 必须参与每一次乘法运算，用"0 也要乘"来提醒学生不要跳步。

✏️ 课堂讲义 · 典型例题精讲

例题一：用竖式计算 145×12。 分析：按照三位数乘两位数的笔算步骤，先用个位上的 2 乘，再用十位上的 1 乘，最后把两次的积相加。 解答：先用 2 乘 145 得 290；再用十位上的 1 乘 145 得 145 个十，末位写在十位下面；290 加 1450 得 1740。所以 145×12 等于 1740。 方法小结：笔算乘法要"对位、分乘、相加"，第二层积的末位必须对准十位。 例题二：用竖式计算 305×24。 分析：第二个因数 24 的个位是 4，先算 4 乘 305；十位是 2，再算 2 乘 305。注意 305 中间的 0 要参与运算。 解答：4×305 得 1220，2×305 得 610 个十，即 6100，相加得 7320。所以 305×24 等于 7320。 方法小结：因数中间有 0 时，0 也要乘，不能省略，否则积会出错。 例题三：解决实际问题。 学校给图书角购书，每套《科学探秘》128 元，共买 25 套，一共需要多少元？ 分析：每套 128 元，买 25 套，求总价，用乘法，列式为 128×25。 解答：128×25：先用 5 乘 128 得 640，再用 2 乘 128 得 256 个十，即 2560，相加得 3200。答：一共需要 3200 元。 方法小结：单价乘数量等于总价，笔算后还要检查积的位数，并用估算验证结果的大致范围。 例题四：下面的竖式计算对吗？如果不对，请改正。 计算 145×13 时，小林先算 3×145 得 435，再算 1×145 得 145，最后把两次的积相加得 580。 分析：小林错在第二层积的对位。用十位上的 1 去乘，得到的 145 表示 145 个十，即 1450，末位应写在十位下面，不能和 435 的个位对齐。 解答：正确写法是 435 加 1450 得 1885，所以 145×13 等于 1885。小林的算法漏掉了一个十位的 0，少了 1300。 方法小结：第二层积的末位必须对准十位。判断竖式正误时，可以先估算，看看结果是否在合理范围内。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 口算与竖式起步

  1. 1. 口算：20×40、300×30、110×50、25×40。
    答：20×40 等于 800；300×30 等于 9000；110×50 等于 5500；25×40 等于 1000。
  2. 2. 用竖式计算：124×23。
    答：124×23：3×124 得 372，2×124 得 248 个十，相加得 2852。
  3. 3. 用竖式计算：321×15。
    答：321×15：5×321 得 1605，1×321 得 321 个十，相加得 4815。

中等 · 因数中间或末尾有 0

  1. 1. 用竖式计算：360×25。
    答：360×25：先算 36×25 得 900，因数末尾有一个 0，在积的末尾添一个 0，得 9000。
  2. 2. 用竖式计算：408×32。
    答：408×32：2×408 得 816，3×408 得 1224 个十，相加得 13056。注意 408 中间的 0 也要乘。
  3. 3. 口算：50×80、460×30、200×40。
    答：50×80 等于 4000；460×30 等于 13800；200×40 等于 8000。

难 · 改错与生活应用

  1. 1. 下面的竖式错在哪里？请改正：计算 45×12 时，写成先算 45×1 得 45，再算 45×2 得 90，结果写成 495。
    答：错在乘的顺序：应先算个位上的 2 乘 45 得 90，再算十位上的 1 乘 45 得 45 个十，相加得 540，而不是 495。
  2. 2. 一辆客车每小时行 96 千米，行驶了 14 小时，一共行了多少千米？
    答：96×14：4×96 得 384，1×96 得 96 个十，相加得 1344。答：一共行了 1344 千米。
  3. 3. 服装厂每天生产童装 325 套，照这样计算，30 天一共生产多少套？
    答：325×30：先算 325×3 得 975，因数末尾有一个 0，添 0 得 9750。答：30 天一共生产 9750 套。

综合 · 估算与拓展

  1. 1. 李阿姨带 3000 元去批发市场买毛巾，每条毛巾 48 元，要买 62 条，钱够吗？用估算解决。
    答：把 48 看作 50，把 62 看作 60，50×60 得 3000。实际每条的价钱比 50 元少，条数比 60 条多，无法直接判断，应把 62 看作 60、48 看作 50，3000 元是估算下限，还需要精确计算：48×62 等于 2976，小于 3000，钱够。
  2. 2. 一列火车 3 小时行 360 千米，照这样的速度，行驶 12 小时能行多少千米？
    答：先求速度：360÷3 得 120 千米每小时；再求 12 小时的路程：120×12 得 1440 千米。答：能行 1440 千米。
  3. 3. 在 1、2、3、4、5、6、7、8、9 中任选数字组成一个三位数和一个两位数，使它们的积最大，你能写出这个算式吗？
    答：答案不唯一，积最大的一种是 951×87 等于 82737（把较大的数字放在高位，接近的两个数相乘积更大，可以让学生多试几组比较）。

💬 课后反馈

一、常见错误 1. 第二层积末位对错位，导致积的数位出错。 2. 因数末尾有 0 时漏添 0，如 260×50 算成 1300。 3. 因数中间有 0 时漏乘，跳步计算。 4. 估算结果误用等号连接，或用"四舍五入"后的数进行精确计算。 二、教学改进建议 1. 用"数位板"辅助：先标清每一步乘的是哪个数位，再写竖式。 2. 设计"竖式改错"专项练习，让学生当小老师找错误，加深对算理的理解。 3. 强调"算完想一想"：用估算检查结果的范围，用积的位数检查对位。 三、分层辅导 对学困生：先练两位数乘两位数的竖式，再迁移到三位数乘两位数，逐步放手。 对学优生：增加"积的变化规律"探究和开放题，鼓励一题多解，比如用简便方法计算末尾有 0 的乘法。 四、给家长的建议 1. 让孩子讲一讲竖式每一步表示什么意思，讲得清才算真会。 2. 购物时让孩子算总价、算零钱，把笔算用到生活里。 3. 发现孩子经常漏 0 或对错位，不必急着批评，陪他一起按"数一数、对一对"的步骤重做一遍。
