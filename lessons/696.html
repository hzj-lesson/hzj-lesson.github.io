小学五年级语文《古诗三首：四时田园杂兴/稚子弄冰/村晚》教案

小学五年级语文古诗三首：四时田园杂兴/稚子弄冰/村晚

📝 备课方案

**教学目标** 1. 认识诗人范成大、杨万里、雷震，会认会写本课生字，能正确、流利、有感情地朗读并背诵、默写三首古诗。 2. 借助注释理解三首诗的诗意，能用自己的话说出诗中的画面。 3. 体会三首诗中描写儿童生活的乐趣，感受诗人对田园生活和儿童的喜爱。 4. 学习抓住关键词想象画面的方法，感受古诗中"儿童形象"的趣味。 **教学重点**：理解诗意，想象画面，背诵默写三首诗。 **教学难点**：体会诗中儿童的天真可爱；理解《四时田园杂兴》中"也傍桑阴学种瓜"的意蕴。 **教学方法**：诵读感悟、想象画面、对比阅读（三首诗都写儿童）、图文结合。 **教学准备**：课件（田园风光图、儿童学种瓜/玩冰/骑牛图）、三首诗配乐朗读、作者资料。 **课时安排**：3 课时（每首 1 课时，或第 1、2 课时学诗，第 3 课时对比总结）

📖 课堂讲义 · 核心知识点

**一、三位诗人** - **范成大**（1126—1193）：南宋诗人，他的《四时田园杂兴》共 60 首，描写了农村春、夏、秋、冬四季的生活，本课选的是"其三十一"。 - **杨万里**（1127—1206）：南宋诗人，诗风活泼自然、通俗晓畅，善写儿童和自然景物，人称"诚斋体"。 - **雷震**：宋代诗人，生平资料不多，《村晚》是他传世的名作。 **二、原文与朗读节奏** 《四时田园杂兴（其三十一）》（范成大）： 昼出/耘田/夜绩麻， 村庄/儿女/各当家。 童孙/未解/供耕织， 也傍/桑阴/学种瓜。 《稚子弄冰》（杨万里）： 稚子/金盆/脱晓冰， 彩丝/穿取/当银钲。 敲成/玉磬/穿林响， 忽作/玻璃/碎地声。 《村晚》（雷震）： 草满/池塘/水满陂， 山衔/落日/浸寒漪。 牧童/归去/横牛背， 短笛/无腔/信口吹。 **三、字词释义** | 词语 | 释义 | |---|---| | 耘田 | 在田间除草 | | 绩麻 | 把麻搓成线 | | 各当家 | 各人都担任一定的工作 | | 童孙 | 小孙子（泛指孩子们） | | 未解 | 不懂、不会 | | 供 | 从事、参加 | | 傍 | 靠近、依着 | | 桑阴 | 桑树荫下 | | 稚子 | 幼小的孩子 | | 脱晓冰 | 从盆中取出清晨结的冰 | | 银钲 | 银做的打击乐器（钲，古代乐器） | | 玉磬 | 玉制的打击乐器（磬） | | 陂 | 池塘、水岸 | | 衔 | 含着（山好像含着落日） | | 浸寒漪 | 倒映在寒凉的水波中 | | 横牛背 | 横坐在牛背上 | | 无腔 | 不成曲调 | | 信口吹 | 随口吹 | **四、诗句翻译与画面还原** - 《四时田园杂兴》：白天出去锄草，夜里搓麻线，村子里的男男女女各自承担着农活。小孩子们虽然还不会耕田织布，也在桑树荫下学着大人的样子种瓜。 - 《稚子弄冰》：清晨，小孩子从铜盆里取出冻好的冰块，用彩色的丝线穿起来，当作银钲来敲。敲出的声音像玉磬一样清脆，穿过树林传出老远；忽然冰块落地，发出像玻璃破碎一样的声音。 - 《村晚》：池塘里长满了青草，池水涨得满满的，远山衔着西沉的落日，倒映在清凉的水波中。放牛的孩子横坐在牛背上回家去，拿着一支短笛随口吹着，不成曲调却自在悠然。 **五、写作手法与赏析** 1. **《四时田园杂兴》**：以"学种瓜"写儿童——童孙"未解供耕织"却"也傍桑阴学种瓜"，一个"学"字写出儿童模仿大人劳作的天真可爱，也侧面写出农家繁忙、人人勤劳。 2. **《稚子弄冰》**：全诗写"玩冰"全过程——取冰、穿线、敲打、破碎，充满童趣。声音描写传神：清脆的"玉磬声"突然变成"玻璃碎地声"，惊喜与惋惜交织，写出稚子的天真。 3. **《村晚》**：前两句写景（草、水、山、落日、寒漪），后两句写人（牧童横牛背、短笛信口吹），景美人和，恬静悠然，是一幅"牧童晚归图"。 **六、主题思想与对比** 三首诗都描写了**儿童**的生活，都表现了儿童的天真可爱，都流露出诗人对儿童、对田园生活的喜爱。不同的是：《四时田园杂兴》写儿童劳动（学种瓜），《稚子弄冰》写儿童游戏（玩冰），《村晚》写儿童放牧（横牛背吹笛）。

🔍 课堂讲义 · 重点难点解析

**重点一：想象画面（把诗读成画）** - 例题：读了"童孙未解供耕织，也傍桑阴学种瓜"，你仿佛看到了什么？ 分析：抓住"童孙""傍桑阴""学种瓜"，想象孩子动作和神情。 参考答案：我看到几个小孩子学着大人的样子，蹲在桑树荫下，有模有样地挖坑、放瓜种、盖土，虽然笨手笨脚，却认认真真，可爱极了。 小结：想象画面要说清"谁、在哪、做什么、什么样子"。 **重点二：体会《稚子弄冰》的童趣** - 例题：稚子"敲成玉磬穿林响，忽作玻璃碎地声"，冰碎了，孩子会怎样？ 分析：前句是清脆悦耳的敲击声，后句突然"啪"的一声碎地，从高兴到惋惜。 参考答案：冰块碎了一地，孩子先是一愣，然后又惋惜又懊恼，不过很快又可能破涕为笑。全诗通过声音的变化写出了孩子玩冰的乐趣和天真的情态。 小结：抓住"声音的变化"和"情绪的变化"体会童趣。 **难点一：理解《村晚》的"静"与"闲"** - 例题：《村晚》前两句写景，后两句写人，这样安排有什么好处？ 分析：草满、水满、山衔落日是静态美景；牧童横坐牛背、信口吹笛是悠闲的动态。动静结合，景与人和谐。 参考答案：前两句描绘傍晚池塘边的宁静美景，后两句写牧童悠然归家，动静结合，共同构成一幅恬静自在的田园晚归图，表达了诗人对这种生活的向往。 小结：分析"景＋人"的诗，要看景物氛围和人物状态是否和谐统一。

✏️ 课堂讲义 · 典型例题精讲

**例题 1（理解诗意）** 用自己的话说说"童孙未解供耕织，也傍桑阴学种瓜"的意思。 - 分析：解词"未解""供""傍""桑阴"。 - 参考答案：小孩子还不会耕田织布，也学着大人的样子，在桑树荫下种瓜。 - 方法小结：先逐词理解，再连成通顺的句子。 **例题 2（赏析童趣）** 《稚子弄冰》中，从"敲成玉磬穿林响"到"忽作玻璃碎地声"，孩子的心情有什么变化？ - 分析：前句声音清脆悦耳，孩子敲得开心；后句冰块突然碎地，孩子从惊喜变成惋惜。 - 参考答案：孩子先为自己敲出清脆的"玉磬声"而得意开心，忽然冰块碎了，心情由喜转惊、由惊转惜。声音的突变写出玩冰的乐趣和稚子的天真。 - 方法小结：抓住诗中"声音、动作、神态"的变化，体会人物心情。 **例题 3（对比阅读）** 三首诗都写了儿童，它们写的儿童活动有什么不同？ - 分析：比较三首诗中儿童做的事。 - 参考答案：《四时田园杂兴》写儿童学种瓜（劳动），《稚子弄冰》写儿童玩冰（游戏），《村晚》写牧童骑牛吹笛（放牧）。三首诗从不同角度写出了儿童的天真可爱。 - 方法小结：对比阅读先分别概括"写了什么"，再找相同点和不同点。

📋 分层作业（基础 / 中等 / 难 / 综合）

基础 · 背诵默写

  1. 1. 默写《四时田园杂兴（其三十一）》。
    答：昼出耘田夜绩麻，村庄儿女各当家。童孙未解供耕织，也傍桑阴学种瓜。（注意"耘""绩""傍"的写法）
  2. 2. 默写《稚子弄冰》。
    答：稚子金盆脱晓冰，彩丝穿取当银钲。敲成玉磬穿林响，忽作玻璃碎地声。（注意"钲""磬"的写法）
  3. 3. 默写《村晚》。
    答：草满池塘水满陂，山衔落日浸寒漪。牧童归去横牛背，短笛无腔信口吹。（注意"陂""漪"的写法）

中等 · 理解诗句

  1. 1. "童孙未解供耕织"中"未解"是什么意思？
    答：不懂、不会。孩子们还不懂得耕田织布。
  2. 2. 《稚子弄冰》中，孩子把冰块当成了什么来敲？
    答：把冰块当作银钲（打击乐器）来敲，敲出的声音像玉磬一样清脆。
  3. 3. 《村晚》描写的是什么季节、什么时间的景色？
    答：夏季（池塘草满水满）傍晚（山衔落日）的景色。

难 · 赏析与想象

  1. 1. "也傍桑阴学种瓜"中"学"字妙在哪里？
    答："学"字写出孩子们模仿大人劳动的天真可爱，也侧面烘托出农家生活的忙碌和勤劳，充满生活气息。
  2. 2. 《稚子弄冰》中"忽作玻璃碎地声"的"忽"字有什么表达效果？
    答："忽"字写出冰块破碎的突然，声音由清脆转为碎裂，节奏陡变，生动地写出了孩子的意外和惋惜，更显童趣。
  3. 3. 请用自己的话描绘《村晚》的画面（不少于 40 字）。
    答：示例：池塘边青草茂盛，池水满满的；远处青山衔着将要落下的太阳，倒映在清凉的水波里。牧童横坐在牛背上慢悠悠地回家，手里拿着一支短笛，随口吹出不成调的小曲，悠闲极了。

综合 · 对比与拓展

  1. 1. 三首诗都写了儿童，它们的相同点和不同点是什么？
    答：相同点：都写儿童，都表现儿童的天真可爱，都表达对田园/乡村生活的喜爱。不同点：活动不同——学种瓜（劳动）、玩冰（游戏）、骑牛吹笛（放牧）。
  2. 2. 你还知道哪些描写儿童生活的古诗？写出两句并注明作者。
    答：示例：蓬头稚子学垂纶，侧坐莓苔草映身。（胡令能《小儿垂钓》）；儿童急走追黄蝶，飞入菜花无处寻。（杨万里《宿新市徐公店》）。写出符合要求的即可。
  3. 3. 如果让你为《稚子弄冰》配一幅画，你会画什么？写一写画面内容。
    答：示例：清晨的院子里，一个小孩双手捧着从金盆里脱出的冰块，正用彩色丝线穿它；旁边散落着几块碎冰，孩子脸上带着又惊喜又惋惜的表情。画面以孩子的动作和表情为中心。

💬 课后反馈

**学生常见错误** 1. 把"供"理解成"供给、供应"，不知道在诗中作"从事、参加"讲。 2. 背诵《稚子弄冰》时把"敲成玉磬穿林响"和"忽作玻璃碎地声"两句顺序记反。 3. 想象画面时只罗列景物，不会加上人物的动作、神态和声音。 4. 三首诗记混：分不清哪首是范成大、哪首是杨万里、哪首是雷震写的。 **教学改进建议** 1. 三首诗按"劳动—游戏—放牧"分类记忆，用表格对比诗人、内容、儿童活动。 2. 用"演一演"的方式教学：学种瓜的动作、敲冰的声音、骑牛吹笛的姿态，让童趣"活"起来。 3. 每首诗都训练"解词—连句—想象画面"三步法，规范答题。 **分层辅导** - 基础弱：以背诵默写和字词解释为主，画面想象先借助插图说。 - 学有余力：尝试背诵范成大《四时田园杂兴》另一首、杨万里《宿新市徐公店》并对比。 **给家长的建议** 带孩子到乡下或公园感受田园风光，看看池塘、牛羊；和孩子一起背诵这三首诗，让孩子把诗中画面画下来，诗画结合加深记忆。
